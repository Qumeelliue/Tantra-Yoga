# Tantra Yoga — Telegram-мини-апп (рогалик-колодостроитель)

> Игра-учение Ананда Марги: колода = ум, забег = жизнь, смерть = перерождение,
> знание из 218 книг Шастры переживает смерть. Полный дизайн — [SPEC.md](SPEC.md).

## Что за проект

«Tantra Yoga» — рогалик-колодостроитель в Telegram Mini App. Ваша колода карт — это
ваш ум: в начале она «грязная» (вртти и оковы), в процессе вы превращаете её в
«саттвичную» (практики, мантры, служение). Вместо маны — три гуны (Саттва/Раджас/Тамас),
равновесие (прама) даёт бонус. Каждого врага-Акову можно успокоить (ахимса) — мирный
путь даёт истинный финал. Игра реально учит Шастрам: каждая карта/враг/реликвия —
термин со ссылкой на книгу и главу, а «якоря памяти» переносят практику в жизнь
(пример: уныние → кииртан).

```bash
npm install        # зависимости
npm run dev        # dev-сервер Vite (localhost:5173)
npm test           # юнит-тесты движка и забега

npm run build      # продакшн-сборка в dist/
```

## Источники истины

- **Дизайн игры:** `SPEC.md` — единый источник (механики, числа, фазы, черновики на подпись).
- **Методика обучения:** `design/edu-game-engine.md` + `design/game-mechanics-pipeline.md`.
- **Платформа:** `design/miniapp-vision.md` (§9 — Telegram Mini App) + образец `webapp/`
  + паттерн «бот открывает мини-апп» `design/bot-door-pattern-reference.py`.

  218 книг, только чтение), `.opencode/skills/` (база знаний, только чтение),
  `sources/` (первоисточники, только чтение). Правило: цитаты только сверенные
  (книга → глава), без выдумок.
- **OKF-концепт-слой (копия из RAG):** `notes/rag-okf/` — атомарные понятия Ананда
  Марги с определениями и источниками (справочник терминов для контента игры),
  `notes/rag-okf/discourses_index.md` — индекс 1615 дискурсов для сверки цитат.
