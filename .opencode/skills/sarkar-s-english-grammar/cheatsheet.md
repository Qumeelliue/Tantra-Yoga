# Читшит — правила решений (Sarkar's English Grammar)

## Части речи

| Ситуация | Правило |
|---|---|
| Глагол повторяется | Замени pro-verb'ом (does вместо kill) |
| Действие как имя | Verbal noun: Running is good exercise |
| Глагол-квалификатор | Verbal adjective: a running panorama |
| Квалификация с особой идеей | Gerund: the gurgling sound |

## Множественное число

| Ситуация | Правило |
|---|---|
| Обычное существительное | +s (dogs) |
| -ss/sh/ch/x/z | +es (classes, boxes) |
| -y после согласной | -ies (fly→flies); после гласной +s (days) |
| -o после согласной | -es (heroes); исключ.: solos, pianos, provisos |
| -f/-fe | -ves (life→lives); исключ.: chief, cliff, proof |
| man/foot/tooth/goose/mouse/louse/dormouse | men/feet/teeth/geese/mice/lice/dormice |
| child, ox | children, oxen |
| Сложные слова | -s к главному: fathers-in-law |
| Латинское -um | -a: datum→data, microvitum→microvita |
| Латинское -us | -i: radius→radii, cactus→cacti |

## Глаголы и времена

| Ситуация | Правило |
|---|---|
| Главный глагол, число | Нет форм множественного числа |
| be/have | Единственные с ед./мн.: am/is/was → are/were; has → have |
| Привычка в прошлом | used to (нет настоящей формы) |
| Условие | would |
| Сомнение | might |
| Косвенная речь | Сдвиг: shall→would; tomorrow→the next day |

## Наклонение и залог

| Ситуация | Правило |
|---|---|
| Приказ/просьба | Imperative (Do it.) |
| Факт | Indicative |
| to + глагол | Infinitive (словесное существительное) |
| Гипотеза о прошлом | Subjunctive (Had I been… I would have…) |
| Кто делает | Active (Rama killed Ravana) |
| Объект главный | Passive (Ravana was killed by Rama) |

## Предлоги

| Ситуация | Правило |
|---|---|
| Контакт | on (glass on table) |
| Зазор | upon (ceiling upon table) |
| Нематериальное | above (above all prejudice) |
| Сторона света, внутри | in the west |
| Сторона света, касается | on the west |
| Сторона света, не касается | to the west |
| Двое | between |
| Больше двух | among/amongst |
| «In between» | Ошибка (двойственность) |

## Произношение

| Ситуация | Правило |
|---|---|
| d в середине | Norman: d; Anglo-Saxon: j (education/ejucation) — оба корректны |
| g перед e/i/y | «j» (general, gist); gaol = jail |
| c перед e/i/y | «s» (cinema); иначе «k» (cat) |
| h немое (франц.) | an historian; hotel = «otel» |
| r перед согласной в слоге | Немое (forty → fau-au-ty) |
| Французские конечные | Немы, кроме c/f/l/r |
| of / off | of = «ov», off = «of» |

## Правописание

| Ситуация | Правило |
|---|---|
| Приставка на a/o | Двойной согласный: account, occult |
| Приставка на e | Один: require, resemble |
| i и e рядом | i первым (chief); исключ.: receive, perceive, leisure, counterfeit |
| benefitted | Правильно: benefited |
| full в соединении | -ful: beautiful, handful |

## Пары слов (Ch15)

| Ситуация | Правило |
|---|---|
| «стакан воды» | a tumbler of water (не glass of water) |
| «альтернативы нет» | no alternative (не no other alternative) |
| Автор книг | author; writer = clerk |
| Покупать | shopping; продавать = marketing |
| Сходство | compare with; контраст = compare to |
| Далеко/близко | bring (на расстоянии); fetch = go and bring |
| Золото из золота | a gold ring; golden = цвета золота |
| Положит./отриц. | childlike/rural (положит.); childish/rustic (отриц.) |
| Двое/много | each other (двое); one another (много) |

## Формы писем

| Ситуация | Правило |
|---|---|
| Близкий друг | My dear Basu → Yours affectionately |
| Мало знакомый | Dear Mr. Basu → Yours sincerely |
| Официальное | Sir/Madame → Yours faithfully |
| Полуофициальное (D.O.) | Личное обращение + Yours sincerely, без частного |

## Быстрые сигналы («tells»)

- Видишь «no other alternative» или «in between» — ошибка двойственности.
- «glass of water» — неверно: правильный стакан — tumbler.
- «spareable» — не существует; spare.
- «spousal» — ошибка; espousal.
- Автор использует «writer» для автора — ошибка; writer = clerk.
- Этимологии owl/mango/OK — фольклор, ⚠ не лингвистика.
