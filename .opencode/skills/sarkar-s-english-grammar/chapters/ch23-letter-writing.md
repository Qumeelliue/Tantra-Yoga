# Chapter 23: Letter-Writing

## Core Idea

Три типа писем: личные, официальные (организационные/коммерческие/правительственные), полуофициальные (demi-official, D.O.). Каждый тип — своё обращение и завершение.

## Frameworks Introduced

- **Три типа**: (1) private/personal; (2) organizational, commercial, official, gubernatorial; (3) demi-official (D.O.).
- **Private letters**: Mr. обычно не пишется перед именем/фамилией (но можно для малоизвестного адресата). Близкий друг/родственник — «My dear Basu»; мало знакомый — «Dear Mr. Basu». Завершение — по степени близости: Yours sincerely, Yours affectionately, Yours lovingly.
- **Official letters**: начало — Sir или Madame; завершение — Yours faithfully.
- **Demi-Official letters**: пишутся как личные (обращение по личным отношениям, завершение — Yours sincerely); но личные/частные дела в них не включаются.

## Key Concepts

- **Private** — личное письмо.
- **Official** — служебное (Sir/Madame → Yours faithfully).
- **Demi-official (D.O.)** — полуофициальное (обращение личное, Yours sincerely, без частного).

## Mental Models

- «Выбирай форму по степени формальности: личное (My dear → Yours affectionately), официальное (Sir → Yours faithfully), полуофициальное (личное обращение + Yours sincerely + деловое содержание)».

## Anti-patterns

- **В официальном письме писать личное обращение** — нужно Sir/Madame и Yours faithfully.
- **В D.O. включать частные дела** — нельзя, хотя форма личная.
- **Путать завершения**: affectionately (близкие) vs sincerely (обычное) vs faithfully (официальное).

## Worked Example

*Три адресата.* Близкий друг Мистер Басу → «My dear Basu» → «Yours affectionately». Мало знакомый Мистер Басу → «Dear Mr. Basu» → «Yours sincerely». Правительственному чиновнику → «Sir» → «Yours faithfully». D.O. чиновнику по делу с личным обращением → «Dear Mr. X» → «Yours sincerely», но только деловое содержание.

## Key Takeaways

1. Три типа писем: private, official, demi-official.
2. Private: обращение по близости, завершение по близости.
3. Official: Sir/Madame → Yours faithfully.
4. D.O.: личное обращение + Yours sincerely, без частных дел.
5. Форма письма — функция формальности отношений.
