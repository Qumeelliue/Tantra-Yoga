# Chapter 17: Diminutives

## Core Idea

Деминутивы (уменьшительные) образуются суффиксами -let, -kin, -et, -ock, -ling, -ule.

## Frameworks Introduced

Таблица noun → diminutive:

| Noun | Diminutive |
|---|---|
| hill | hillock |
| book | booklet |
| duck | duckling |
| river | rivulet |
| goose | gosling |
| arm | armlet |
| leaf | leaflet |
| ankle | anklet |
| cut | cutlet |
| man | mankin |
| helm | helmet |
| globe | globule |
| grain | granule |

## Key Concepts

- **Суффиксы деминутивов**: -let, -kin, -et, -ock, -ling, -ule.
- **armlet/anklet** — маленькие предметы, связанные с рукой/лодыжкой.

## Mental Models

- «Уменьшительное = маленькая версия объекта: book→booklet, river→rivulet, duck→duckling».
- «Выбирай суффикс по устоявшейся форме слова, а не по правилу».

## Anti-patterns

- **Придумывать формы** — деминутивы узуальные (принятые), не продуктивные на все случаи.

## Worked Example

*Leaflet.* Лист → leaflet (маленький лист/листовка). Книга → booklet. Река → rivulet. Гусь → gosling (птенец). Слова фиксированы словарём, а не выводимы механически.

## Key Takeaways

1. Суффиксы: -let, -kin, -et, -ock, -ling, -ule.
2. Деминутивы — узуальные формы (booklet, rivulet, duckling).
3. armlet/anklet — предметы, связанные с рукой/лодыжкой.
