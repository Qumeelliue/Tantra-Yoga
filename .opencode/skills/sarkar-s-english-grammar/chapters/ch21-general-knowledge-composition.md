# Chapter 21: General Knowledge on Composition

## Core Idea

Модель композиции на примере Бурдвана: passage (отрывок) + general knowledge (фоновые знания) + разбор этимологии названий (Vardhamána, Ráŕh, Damodara) + грамматические замечания (krśaka vs karśaka) + исторические личности + география района.

## Frameworks Introduced

- **Модель композиции**: показать, как развивать тему — от короткого отрывка к развёрнутому описанию с историей, этимологией, личностями, географией.
- **Passage**: Бурдван — древний город Бенгалии, окружной центр, университетский город на реке Дамодара; мост Krśak Setu (но правильно — Karśaka, от корня krś + -nak/-kan).
- **General Knowledge**: Бурдван = Vardhamána (санскр.); древнейший город мира; столица древнейшей цивилизации — Ráŕh.
- **Этимологии**:
  - **Capital** = «concerning the capita/head» — Бурдван «как голова для земли Ráŕh».
  - **Ráŕh** = «земля латеритной (красной) почвы».
  - **Burdwan**: сначала Ástikanagar («город, уважающий Бога»), затем Atthinagara (Prakrtа), затем Vardhamána (по имени Вардхаманы Махавиры, проповедовавшего 7 лет).
  - **Bengal** — древнее почтенное имя.
  - **Bhukti / zilla / district**: bhukti (как графство, до Pathan); zilla (Pathan/Mughal); district (британцы).
  - **Damodara**: dáma (огонь) + udara (живот) = «где огонь в животе»; дно Дамодары богато углём.
  - **Krśaka**: неверно; правильно karśaka (как ákarśaka, vikarśaka, saḿkarśaka).
- **Личности Бурдвана**: Maharshi Patanjali (Yoga Darshana, село Patun); Jimutabahana Bhattacarya (бенгальская школа наследства Dayábhága); Raghunath Shiromani (Navyanyaya); Kavikankana Mukundaram (Chandimangal); Krishnadas Kaviraja (Caetanya Caritámrta); Kashirama Das (бенгальская Mahábhárata); Kumudranjan Mallik; Kalidas Roy; Satyendranath Datta; Kazi Nazrul Islam (Churulia); Maladhar Basu (Bhágavata, предок Нетаджи Субхаса Чандры Боса); Rashbehari Basu (президент Azad Hind в Японии); Rev. Lalbihari Dey (Folktales of Bengal); Rashbehari Ghosh; Rajashekhar Basu (Parashurama); Swami Vivekananda (Dattadereton); Bengal Gazette — первая бенгальская ежедневная газета (Бахарха, чуть раньше Samachar Darpan).
- **География**: Бурдван — самый богатый округ Бенгалии по сельскому хозяйству и минералам; три города (1989, рекорд); соседи: Birbhum, Santhal Parganas, Dhanbad, Purulia, Bankura, Hooghly, Nadia, Murshidabad.

## Key Concepts

- **Bhukti / zilla / district** — эволюция административных терминов.
- **Karśaka** — правильная форма «земледелец» (не krśaka).
- **Ráŕh** — латеритная земля.
- **Damodara** — «огонь в животе» (уголь).

## Mental Models

- «Развивай тему как автор: короткий отрывок → историческое/этимологическое обогащение → личности → география → грамматические точности».
- «Проверяй словообразование в композиции (krśaka/karśaka) — точность терминов».

## Anti-patterns

- **Писать krśaka** — правильно karśaka.
- **Считать Бурдван «молодым»** — древнейший город мира, столица Ráŕh.

## Worked Example

*Корректное словообразование.* Krśa — корень «пахать». С суффиксом -nak/-kan правильная форма — karśaka (как ákarśaka, vikarśaka, saḿkarśaka), а не krśaka. Мост Krśak Setu поэтому назван с грамматической ошибкой.

## Key Takeaways

1. Модель композиции: passage + knowledge + этимология + личности + география.
2. Burdwan = Vardhamána; Ráŕh = «латеритная земля».
3. Damodara = «огонь в животе» (уголь в дне).
4. Правильно karśaka, не krśaka.
5. Богатая история имён: Астиканагар → Аттхинагара → Вардхамана.
