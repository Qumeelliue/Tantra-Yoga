# Chapter 4: Plural Forms of Nouns

## Core Idea

Singular — одно, plural — больше одного. 12 правил образования множественного числа + система латинских форм (-um → -a, -us → -i).

## Frameworks Introduced

- **Rule 1**: +s (dog→dogs). Исключения: -ss/-sh/-ch/-x/-z → +es (class, bench, brush, box, topaz).
- **Rule 2**: -y после согласной → -ies (fly→flies, lady→ladies); -y после гласной → +s (day, tray, key, boy).
- **Rule 3**: -o после согласной → -es (hero, buffalo, echo, mango, potato); исключения: cantos, mementos, solos, pianos, provisos; -oo/-io/-eo/-yo → +s (bamboo, portfolio, cameo, embryo).
- **Rule 4**: -f/-fe → -ves (life, wife, calf, knife, leaf, wolf, thief); исключения: -ief/-ff/-oof/-rf/-eef → +s (chief, cliff, proof, dwarf, reef).
- **Rule 5**: восемь с изменением внутренней гласной: man/men, woman/women, foot/feet, tooth/teeth, goose/geese, mouse/mice, louse/lice, dormouse/dormice.
- **Rule 6**: +en: child→children, ox→oxen, brother→brethren (brothers).
- **Rule 7**: сложные — -s к главному слову: father-in-law → fathers-in-law, passer-by → passers-by, commander-in-chief → commanders-in-chief (но step-brother → step-brothers).
- **Rule 8**: singular-форма, plural-значение: cattle, people, swine, vermin, gentry, nobility, aristocracy, clergy, folk.
- **Rule 9**: plural-форма, singular-значение: mathematics, physics, politics, economics, whereabouts, gallows, ethics.
- **Rule 10**: без множественного: alphabet, furniture, poetry, scenery, offspring, luggage, expenditure, issue.
- **Rule 11**: только plural: alms, annals, assets, bellows, riches; plural-форма, singular-употребление: means, news, innings.
- **Rule 12**: двойные формы с разными значениями: fish (одного вида) / fishes (разных видов); people (люди) / peoples (народы).
- **Латинские**: -um → -a: datum→data, stratum→strata, memorandum→memoranda, **microvitum→microvita**, medium→media, quantum→quanta, corrigendum→corrigenda, agendum→agenda, desideratum→desiderata. -us → -i: radius→radii, lotus→loti, cactus→cacti, genius→genii, alumnus→alumni.

## Key Concepts

- **Singular / plural** — единственное/множественное число.
- **Внутренняя гласная (mutation)** — man/men, foot/feet.
- **Сложные существительные** — множественное к главному слову.
- **Collective singular** — cattle, people, folk.
- **Латинские окончания** — -um/-us.

## Mental Models

- «Думай о множественном как о наборе «фильтров»: сначала окончание (s/es), потом гласная (-y, -o, -f), потом корневая мутация, потом исключения-списки».
- «Для латинских слов применяй машинное правило: -um → -a, -us → -i».
- «Проверяй «двойные формы»: изменилось ли значение (fish/fishes, people/peoples)».

## Anti-patterns

- **Склонять по одному правилу все слова** — набор исключений обязателен.
- **Не различать singular-по-форме / plural-по-значению** (cattle) и наоборот (mathematics).
- **Игнорировать латинские формы** (data, memoranda, microvita).

## Worked Example

*Слово с двойной формой.* fish — много рыбы одного вида; fishes — рыбы разных видов. people — люди в городе; peoples — народы мира (nations). Выбор формы меняет смысл.

*Латинская форма.* microvitum (един.) → microvita (мн.): модель -um → -a, как datum→data, memorandum→memoranda.

## Key Takeaways

1. 12 правил образования plural с чёткими исключениями.
2. Латинские: -um → -a, -us → -i (microvita, radii).
3. Двойные формы меняют значение (fish/fishes, people/peoples).
4. Singular-форма с plural-значением: cattle, people.
5. Plural-форма с singular-значением: mathematics, news.
