# Chapter 11: Verb Contractions

## Core Idea

В письменном языке пишем полные формы глаголов, а не сокращения. В разговорной речи, в объявлениях, драме — используем сокращения. Таблица соответствий письменных и разговорных форм.

## Frameworks Introduced

- **Правило**: письмо — полные формы; устная речь/объявления/драма — сокращения.

| Письменная | Разговорная |
|---|---|
| will not | won't |
| should not | shouldn't |
| would not | wouldn't |
| could not | couldn't |
| has not | hasn't |
| have not | haven't |
| had not | hadn't |
| was not | wasn't |
| were not | weren't |
| is not | isn't |
| are not | aren't |
| do not | don't |

## Key Concepts

- **Full forms** — для письма.
- **Contractions** — для устной речи.

## Mental Models

- «Думай о регистре: письмо = полные формы, устная речь = сокращения».
- «Не переноси разговорные сокращения в официальный письменный текст».

## Anti-patterns

- **Использовать won't/don't в письменных документах** — автор требует полные формы.
- **Путать пары**: is not = isn't (не don't), are not = aren't (не isn't).

## Worked Example

*Регистр.* В драме персонаж говорит: «Don't worry!». В письменном документе: «Do not worry.» Выбор формы — функция регистра (письмо vs устная речь), не смысла.

## Key Takeaways

1. Письмо — полные формы.
2. Устная речь/объявления/драма — сокращения.
3. 12 базовых пар (will not/won't … do not/don't).
4. Выбор по регистру, не по смыслу.
