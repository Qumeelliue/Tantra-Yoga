# Chapter 15: Some Definitions: Avoiding Common Errors

## Core Idea

Самая большая глава: ~40 пар/групп слов с авторскими различениями. Цель — избегать распространённых ошибок через точные определения.

## Frameworks Introduced

- **patriarchal / patrilineal / patrimony / patrilateral / patricidal**: patriarchal — порядок от отца к сыну; patrilineal — линия наследования от отца; patrimony — «отцовское имущество» (материнское — не matrimony!); patrilateral — «со стороны отца»; patricide — убийство отца (matricide — матери, fratricide — брата, infanticide — детей, homicide — человека, suicide — себя, pesticide/insecticide — вредителей/насекомых).
- **special / especial**: special = extra (дополнительный); especial = particular (особенный); especially = particularly.
- **far / farther / further**: far — далеко; farther — дальше (сравнит. степень); further — «более вперёд/дальше по развитию».
- **spirituality / spiritualism**: духовность vs культ духов (спиритизм).
- **veracity / voracity**: правдивость vs обжорство.
- **observation / observance**: наблюдение vs обряд/церемония.
- **school** — «переформировать» (от франц. école).
- **duty** — «то, что должно быть сделано» (всегда singular в традиционном смысле); «налог» — и plural.
- **mercenary / missionary**: mercenary — работающий за деньги; missionary — за благородное дело. Словообразование: -sion для глаголов на согласную кроме -t; -tion для -t; исключение mit → mission.
- **vernacular / colloquial**: vernacular — неразвитый язык местных (уничижительно); colloquial — разговорный.
- **doldrums / pell-mell**: doldrums — состояние, где ничего не функционирует; pell-mell — беспорядок.
- **old / antique / ancient**: old — почтенный; antique — почтенный, но нежелательный; ancient — почтенный и уважаемый.
- **little / a little / the little progress**: little — «нет прогресса»; a little — «некоторый прогресс»; the little — конкретизированный, но негативный.
- **many / many a**: many — больше двух, трудно пересчитать; many a — во множественном употреблении, но глагол в единственном («Many a youth … Dancing»).
- **corporal / corporeal**: corporal — «телесный» (лат. corpus); corporeal — телесный вне физического восприятия.
- **aquatic / aqueous**: aquatic — водный (животное); aqueous — водный по свойствам (эксперимент).
- **marine / maritime**: морской (обучение) vs морской вне восприятия (климат).
- **financial / economic / pecuniary / fiscal / monetary / exchequer**: все «о денежных делах», но: financial — общий; economic — приход/расход; pecuniary — способность тратить; fiscal — правительственные финансы; monetary — деньги (t́ákápaysá); exchequer — госказна.
- **native** — этимологически «местный», но колонизаторы придали уничижительный смысл.
- **use / usage**: use — «употребление в моде»; usage — система, применяемая долго.
- **one another / each other**: one another — больше двух; each other — двое.
- **punishment / atonement / disciplinary action**: punishment — от суда; atonement — самонаказание (моральное); disciplinary action — за неудовлетворительную работу.
- **childish / childlike**: childish — отрицательное; childlike — положительное.
- **rural / rustic**: rural — положительное (банк); rustic — отрицательное (человек).
- **appreciation / depreciation**: признание/цена вверх vs цена вниз.
- **irregular / inefficient account**: irregular — неавторизованный расход; inefficient — баланс, который нельзя закрыть без списания.
- **abound in / with**: контейнер — оба; содержимое — только in.
- **historical / universal truth**: исторический факт (может измениться) vs всеобщая истина (непоколебима).
- **bring / fetch**: bring — на расстоянии; fetch = «go and bring».
- **compare with / to**: with — сходство; to — контраст.
- **tumbler / glass**: «glass of water» неверно; правильно tumbler of water (tumbler = стакан; glass — материал).
- **you / thou**: thou — архаизм (только к Богу); you — современное.
- **quarter / quarters**: четверть vs жильё.
- **author / writer**: author — автор книг; writer = clerk (канцелярист); Writers' Building = здание клерков.
- **marketing / shopping**: marketing — продавать; shopping — покупать.
- **taught / touched**: toutch (знание) → teach/taught; touch — тактильность.
- **«no other alternative»** — ошибка: alternative = other way; «other alternative» = «other other way» — двойственность.
- **put on / put off**: put on — начинать/надевать; put off — заканчивать/тушить.
- **spare / spareable**: spare — и прилагательное, и глагол; spareable — ошибка.
- **similar / identical**: почти одно vs точно одно.
- **trinity / trio**: одно в трёх формах vs три разных.
- **popular / populous**: любимый vs густонаселённый.
- **industrious / industrial**: трудолюбивый vs промышленный.
- **farm / firm**: сельское хозяйство vs промышленность/коммерция.
- **cannibal / carnivorous**: человек ест человека vs любой плотоядный.
- **wood / woods**: дрова vs лес.
- **effect / effects**: результат vs личные вещи.
- **enquire / inquire**: синонимы; inquire старше, enquire популярнее.
- **unsatisfactory / dissatisfactory**: неудовлетворительный vs был удовлетворительным, но вышел из сферы.
- **contiguity / continuity**: соприкосновение (земля) vs продолжение (идеи).
- **rudimental / fundamental**: корневой vs базовый.
- **The three R's**: Reading, 'riting, 'rithmetic.

## Key Concepts

- **Точные различения пар** — главный инструмент главы.
- **Уничижительные слова** — vernacular, native, rustic, childish.
- **Ошибки двойственности** — in between, no other alternative.
- **Латинские корни** — cide, ceive, mit.

## Mental Models

- «При выборе слова проверяй оттенок: положительный/отрицательный (childlike/childish, rural/rustic), объект (сходство/контраст → with/to), движение (bring/fetch)».
- «Проверяй на "двойственность": если фраза повторяет смысл (other alternative, in between) — ошибка».
- «Помни фольклорные этимологии как мнемонику, но не как лингвистику».

## Anti-patterns

- **«Bring me a glass of water»** — верно: a tumbler of water.
- **«No other alternative»** — верно: «no alternative».
- **writer для автора** — writer = clerk.
- **spareable** — не существует; spare.
- **Акцент на маркетинг как покупки** — marketing = продажа.

## Worked Example

*Финансовые слова.* Financial — общие денежные дела; economic — приход/расход; pecuniary — способность тратить; fiscal — государственные финансы; monetary — деньги; exchequer — госказна. Выбор термина зависит от аспекта денег, о котором речь.

*Моральные слова.* punishment (суд), atonement (моральное самонаказание), disciplinary action (за неудовлетворительную работу в организации). Каждый — своя категория наказания.

## Key Takeaways

1. ~40 пар слов с точными авторскими различениями.
2. Проверяй оттенок (positive/negative): childish/childlike, rural/rustic.
3. Ошибки двойственности: «no other alternative», «in between».
4. Привязка к контексту: bring/fetch, with/to, tumblеr/glass.
5. Фольклорные этимологии — мнемоника, не наука.
