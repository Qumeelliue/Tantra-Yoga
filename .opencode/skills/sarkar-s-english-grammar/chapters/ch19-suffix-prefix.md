# Chapter 19: Structural Formula: Suffix and Prefix

## Core Idea

Prefix (активирующая идея) — «закреплённое перед» (pre); suffix (активированная способность) — «закреплённое после» (sub). Во всех классических языках слова создаются комбинацией prefix + root verb + suffix. В санскрите: upasarga (префикс, 20 фиксированных) и pratyaya (суффикс, ≈722).

## Frameworks Introduced

- **Определения**: активирующая идея (activating idea) отделена от глагола — это prefix; активированная способность (activated faculty) соединена с глаголом — это suffix.
- **Suffix (sub + fix)**: «после» корня. Примеры: act+ion=action, opt+ion=option, remove+al=removal, propose+al=proposal, punish+ment=punishment, govern+ment=government, advertise+ment=advertisement, rectify+tion=rectification, read+ing=reading.
- **Санскрит**: pratyaya (суффикс = «вера»; синоним vishvása) — ≈722 суффикса (tvác, lyap, lyút, ghaiṋ, kta). Пример: sic (лить) + lyut́ = secana; sic + ghaiṋ = seka/seca (abhiśeka); sic + kta = sikta («политый»); niśikta («введённый»); upasecana; parisikta.
- **Модель звука → слова**: цвет/ощущение → вибрация → корень → слово: dhav-dhav-dhav → dhav → dhavala (белый); t́ak-t́ak → t́akt́ake lál (ярко-красный); cand (успокаивать) + rak = candra; ind (высоко) + rak = indra; ind + un = indu (луна).
- **Prefix (pre + fix)**: «перед» корнем. В санскрите — upasarga; 20 фиксированных: pra, pará, apa, sam, anu, ava, nir, dur, abhi, vi, adhi, su, ut, ati, ni, prati, pari, upa, áun (и т.д.).
- **Латинский ceive** («обменивать/получать взамен»): re-ceive (получать), de-ceive (обманом забирать), con-ceive (принять в ум/зачать), per-ceive (субъективизировать объективное через пять органов чувств и нервы). Имена: receipt, deceit, concept/conception, perception.
- **i before e**: chief, thief, brief, friend (i первым); исключения: ceive/ceipt, seizure, leisure, counterfeit.
- **fuse** («смешивать»): infuse, refuse, confuse, profuse, suffuse, defuse.
- **Санскритский bha**: bhá + kta = bháta («просвещённый»); pra + bháta = prabháta («должным образом просвещённый» — «рассвет»).
- **Дальнейшее использование**: locus → dislocate, local train; board (boad) → body → embodiment (em-/en-); personified («purity personified» / «an embodiment of honesty»); en-: enable, enlarge, enact, encage, enclose, engolden, envelop.
- **a/o перед каузативами удваивают согласный**: aggrandize, account, accredit, occult; но resemble (re-).
- **Правописание**: assume/resume, acquire/require, acquisition/requisition.

## Key Concepts

- **Prefix (activating idea)** — «перед» (pre); 20 upasarga в санскрите.
- **Suffix (activated faculty)** — «после» (sub); pratyaya ≈722 в санскрите.
- **Слово из звука** — вибрация → корень → суффикс (dhavala, indra).
- **Латинский ceive** — модель приставок re-/de-/con-/per-.
- **a/o удваивают** — аккаунт, occult; e — нет.
- **embodiment/personified** — для абстрактного «принял форму».

## Mental Models

- «Думай о слове как о конструкторе: prefix (направление идеи) + корень (значение) + suffix (функция)».
- «Из звука в слово: ощущение → вибрация → корень → суффикс (dhavala, indra)».
- «Проверяй приставки латинского ceive: re=получить, de=забрать обманом, con=принять в ум, per=субъективизировать».

## Anti-patterns

- **Путать pre- и sub-** — prefix «перед», suffix «после».
- **Считать, что все слова делятся на prefix+root+suffix** — в некоторых языках глагол требует суффикс, но может работать без префикса.
- **Двойной согласный после e** (require, resemble) — только a/o.
- **Путать l в -ful** — суффикс с одним l.

## Worked Example

*Слова из звука.* Белый цвет производит вибрацию dhav-dhav-dhav → корень dhav; dhav + ac + la + d́a = dhavala (белый). Красный — t́ak-t́ak → t́akt́ake lál. Луна «успокаивает» — cand; cand + rak = candra. Высокий — ind; ind + rak = indra (великий, высокий), ind + un = indu (луна). Вербальное восприятие становится словом.

*Ceive.* ceive = «обменивать, получать взамен». receive — получить; deceive — забрать обманом; conceive — принять в ум (или зачать); perceive — субъективизировать объективное. Имена: receipt, deceit, concept/conception, perception.

## Key Takeaways

1. Prefix (активирующая идея) — «перед»; suffix (активированная способность) — «после».
2. Санскрит: 20 upasarga, ≈722 pratyaya.
3. Модель dhavala: звук → корень → слово.
4. Латинский ceive: re-/de-/con-/per-.
5. a/o удваивают согласный (account, occult); i-before-e с исключениями.
