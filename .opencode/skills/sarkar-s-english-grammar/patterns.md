# Паттерны — Sarkar's English Grammar

## Анализ предложения по частям речи
**Когда использовать**: разбор любого предложения.
**Как**: определи 8 частей + авторские (pro-verb — замена глагола; verbal noun — действие как имя; verbal adjective — глагол-квалификатор; gerund — квалификация с особой идеей). Затем падежи и связи.
**Компромиссы**: авторские категории (pro-verb) нестандартны — для общей грамматики применяй стандартные; авторские — как дополнительные фильтры.

## Образование множественного числа
**Когда использовать**: сомнение в plural формы существительного.
**Как**: пройди фильтры по порядку: (1) +s; (2) -ss/sh/ch/x/z → +es; (3) -y после согласной → -ies, после гласной → +s; (4) -o после согласной → -es (искл. solos, pianos, provisos); (5) -f/-fe → -ves (искл. -ief/-ff/-oof/-rf/-eef); (6) внутренняя мутация (man/men, foot/feet); (7) +en (child/ox); (8) сложные — к главному слову; (9) singular-форма/plural-значение (cattle); (10) plural-форма/singular-значение (mathematics); (11) только plural (alms); (12) двойные формы (fish/fishes). Латинские: -um→-a, -us→-i.
**Компромиссы**: исключений много — для редких слов проверяй по словарю.

## Согласование времени (tense agreement)
**Когда использовать**: перевод прямой речи в косвенную, сдвиг времён.
**Как**: главное прошедшее → сдвиг на шаг назад (shall→would); наречия → the next day и т.п.; местоимения под передающего.
**Компромиссы**: в разговорной речи сдвиг смягчается; автор даёт строгую письменную норму.

## Выбор наклонения
**Когда использовать**: приказ/факт/имя действия/гипотеза.
**Как**: приказ/просьба/убеждение → imperative; факт → indicative; «to + глагол» → infinitive; гипотеза о прошлом («Had I been… I would have visited») → subjunctive.
**Компромиссы**: границы наклонений в английском размыты; автор даёт консервативную норму.

## Выбор предлога по геометрии
**Когда использовать**: on/upon/above, in/on/to (стороны света), in/into, between/among.
**Как**: контакт → on; зазор → upon; нематериальное → above; внутри → in; касается границы → on; не касается → to; двое → between; больше двух → among; «in between» — ошибка.
**Компромиссы**: правила для «исходных смыслов»; переносные употребления могут отклоняться.

## Проверка произношения по происхождению
**Когда использовать**: сомнение в произношении заимствованных/двусмысленных слов.
**Как**: определи происхождение: Anglo-Saxon (d→j: education→ejucation) vs Norman (d→d); французские (h немая, конечные согласные немы кроме c/f/l/r, an перед немой h); r-правила (немая перед согласной в слоге).
**Компромиссы**: обе школы равнозначны — выбор региональный/личный.

## Проверка «двойственности» фраз
**Когда использовать**: редактирование текста.
**Как**: ищи повторение смысла: «no other alternative» (alternative = other way), «in between» (between = in the two) — двойственность, ошибка. Упрощай: «no alternative», «between».
**Компромиссы**: иногда устойчивые фразы противоречат логике — но автор требует точности.

## Точный термин по оттенку
**Когда использовать**: выбор слова из близких по смыслу.
**Как**: проверь оттенок: положительный/отрицательный (childlike/childish, rural/rustic, amiable/amicable); сходство/контраст (compare with/to); движение (bring/fetch); материал/цвет (gold/golden); уровень (punishment/atonement/disciplinary action).
**Компромиссы**: оттенки культурно обусловлены; проверяй контекст.

## Слово из звука (этимология)
**Когда использовать**: объяснение происхождения слов.
**Как**: ощущение → вибрация → корень → суффикс (dhav-dhav → dhavala; t́ak-t́ak → t́akt́ake lál; cand → candra; ind → indra). Латинские приставки ceive: re- (получить), de- (забрать обманом), con- (принять в ум), per- (субъективизировать).
**Компромиссы**: некоторые этимологии фольклорны (owl/mango/OK) ⚠ — не для научного использования.

## Формы писем
**Когда использовать**: написание письма.
**Как**: private — обращение/завершение по близости (My dear Basu → Yours affectionately; Dear Mr. Basu → Yours sincerely); official — Sir/Madame → Yours faithfully; D.O. — личное обращение + Yours sincerely + деловое содержание.
**Компромиссы**: современные стандарты могут отличаться; автор — консервативная британская школа.

## Сжатие (précis)
**Когда использовать**: резюме, пересказ, конспект.
**Как**: сохраняй суть (кто, что, куда, результат), убирай детали; абзацы → абзац (para-précis); переписка → одно предложение (letter-précis).
**Компромиссы**: сжатие теряет нюансы — определяй границу «сути» по цели.
