# Глоссарий — Idea and Ideology (1959)

**Ава́тара (avatára)** — «нисхождение»; теория инкарнации отвергается как нелогичная догма, эксплуатирующая суеверия (Ch 6).

**А́тман** — единичное сознание, свидетель ума; конечное знание/делание/существование в нём, а не в уме (Ch 7, 6).

**Ахам́таттва (Ahaḿtattva)** — «Я делаю», второе субъективное «Я», активированное mutative-гуной (Ch 1, 4).

**Бала (bala)** — внешнее давление static-принципа на пять факторов; источник interial/exterial сил (Ch 1).

**Бха́ва (bháva)** — «идея»: психо-духовный параллелизм ментальных волн с волнами а́тмана (Ch 9).

**Бха́ва са́дхана́** — духовная практика самовнушения при действии (Ch 9).

**Биджа (biija / kámabiija / icchábiija)** — точка выхода результирующей сил = «семя/желание творения» (Ch 8).

**Брахма чакра (Brahma Cakra)** — космический круг/танец творения; коллективное имя saiṋcara + pratisaiṋcara (Ch 3, 8).

**Вртти (vrtti)** — «занятие/способ выражения ума» (любовь, ненависть, страх); выражается через железы; 50 грубых → 1000 в sahasrára (Ch 4).

**Гуна (guńa)** — связывающий принцип: sattva (sentient), rajah (mutative), tamah (static); их перекос = проявленный мир (Ch 4).

**Джада (jad́a)** — сгущённая энергия, твёрдая материя; негативный полюс пратисаинчары (Ch 2, 7).

**Джада́сфот́а (jad́asphot́a)** — взрыв/расщепление мёртвого тела на пять факторов; «негативный saiṋcara» (Ch 1, 3).

**Ишвара прани́дха́на (Iishvara prańidhána)** — медитативное самоотречение; урок медитации Ананда Марги (Ch 2, 10).

**Кала (kalá)** — первая кривизна потока (kriyá shakti) после прямой нада; начало волн (Ch 8).

**Кос (kośa)** — «оболочка»: пять плотностей citta — hirańmaya, vijiṋánamaya, atimánasa, manomaya, kámamaya (Ch 5).

**Кулакун́да́лини (kulakuńd́alinii)** — «свернувшаяся змея»: негативная сила единицы из múládhára, ведёт к mokśa (Ch 8).

**Лока (loka)** — «мир»; только для макрокосма: bhur→bhuvah→svah→mahah→janah→tapah→satya (Ch 5).

**Маха́пуруша (Mahápuruśa)** — возвышенное психическое существо; образец для человечества (Ch 6).

**Ма́нуша (mánuśa)** — человек: стадия, где развитое эго может выбирать направление (в т.ч. негативное) (Ch 2).

**Мах́аттаттва (Mahattattva)** — «Я есть», первая теоретическая связь, чистое «Я» под sentient-гуной (Ch 1, 4).

**Мокша (mokśa)** — слияние в Nirguńa Brahma; достигается негативной силой (кулакун́да́лини, тангенциальный выход) (Ch 6, 8).

**Мукти (mukti)** — ментальное освобождение: слияние микрокосма в Макрокосм при сближении с Puruśottama (Ch 2, 6).

**Нада (náda, jinánashakti náda)** — прямая линия первого выражения результирующей сил (sentient-доминанта) (Ch 8).

**Ниргуна (Nirguńa Brahma)** — Брахман с дремлющей/балансной Prakrti, объектное состояние (Ch 1, 4, 8).

**Ота / прота йога (ota / prota yoga)** — ассоциация Puruśottama: с каждым отдельным умом (ota) / с макрокосмом и совокупностью (prota) (Ch 6).

**Пан́чабху́ты (paiṋcabhútas)** — пять факторов: эфир, воздух, свет, жидкость, твёрдое (Ch 1, 3).

**Параматман (Paramátman)** — «сознающий создания»: Puruśottama + его связи (prota/ota); макро- и микрокосмы не входят (Ch 6).

**Пра́н́а (práńa)** — «энергия»: коллективная сила interial/exterial в структуре (ед.ч.) (Ch 1).

**Пра́н́а́х (práńáh)** — «жизненная энергия» (всегда мн.ч.): коллекция десяти ва́ю; результат-interial при благоприятной среде (Ch 1, 7).

**Пра́н́ендрия (práńendriya)** — «шестой орган» в йогическом сердце (anáhata cakra): пульсативный гейт восприятия (Ch 4).

**Пратисаинчара (pratisaiṋcara)** — центростремительный синтез: грубое→тонкое, к Puruśottama (Ch 2).

**Пуруша (Puruśa)** — чистое Сознание (Citishakti), фундаментальная сущность на каждой стадии (Ch 1, 8).

**Пурушоттама (Puruśottama)** — Ядро-сознание, субъективированный Шива; центр творческих принципов и свидетель (Ch 1, 6).

**Садвипра (sadvipra)** — духовный революционер по Yama+Niyama; страж цикла от эксплуатации (Ch 10).

**Са́дхана (sádhaná)** — «устойчивая практика»: ускорение пратисаинчары к цели (Ch 6, 9).

**Саинчара (saiṋcara)** — центробежный анализ: тонкое→грубое, одно→много (Ch 1, 8).

**Сама́джа чакра (samája cakra)** — социальное колесо/цикл четырёх классов (Ch 10).

**Сама́дхи (samádhi)** — выпрямление ментальных волн до бесконечной длины = слияние ума с а́тманом (Ch 9).

**Са́мска́ра (saḿskára)** — «реактивный ментальный момент»; эффект действий прошлых стадий; даёт момент уму (Ch 7, 4).

**Сва́бха́ва (svabháva)** — характеристика, своя природа (Ch 3, 4).

**Та́нма́тра (tanmátra)** — «микроскопическая доля того»: волна-излучение объекта; приём = восприятие (Ch 3).

**Читта (citta)** — «сделанное Я», объективированное состояние ума; материал-база ума (Ch 1, 4).

**Ша́бда / а́ртха (shabda / artha)** — слово (психическая волна) / значение (психо-физический параллелизм) (Ch 9).

**Ю́га сан̇кра́нти (yuga saḿkránti)** — переходный период между эпохами социального цикла (Ch 10).

**Яма / Нияма (Yama / Niyama)** — десять морально-духовных заповедей: ahimśa, satya, asteya, aparigraha, Brahmacarya; shaoca, santośa, tapah, svádhyáya, Iishvara prańidhána (Ch 10).
