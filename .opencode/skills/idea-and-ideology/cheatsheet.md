# Читшит — правила решений по Саркару (Idea and Ideology)

## Космология и циклы

| Ситуация | Правило |
|---|---|
| Определить фазу системы | Два полукруга: saiṋcara (тонкое→грубое, центробежно) и pratisaiṋcara (грубое→тонкое, центростремительно); это не реверсы друг друга |
| Почему система распалась | Jad́asphot́a: победившее ядро без благоприятной среды → расщепление на частицы |
| «Что держит вещь целой» | Победа центростремительной (interial) силы над центробежной (exterial) |
| Что такое творение | Биджа желания (kámabiija): выход результирующей трёх гун из равновесия |

## Ум и восприятие

| Ситуация | Правило |
|---|---|
| Устройство ума | Mahattattva («Я есть») + Ahaḿtattva («Я делаю») + citta («сделанное Я»); без объективности ума нет |
| Проверить качество восприятия | Тракт из 6 звеньев: объект→врата→нерв→мозг→citta→эго; дефект любого звена = искажение |
| Почему «не чувствую вкус на бегу» | Пра́н́ендрия в активной фазе блокирует приём танма́тр; пауза = восприятие |
| Куда уходит внимание | Вртти: 50 грубых → 1000 полных; контроль всех (sahasrára) = nirvikalpa samádhi = конец самска́р |
| Грубый или тонкий ум | Kámamaya = грубый (связь с факторами); manomaya = тонкий (вспоминание/размышление); выше — каузальный, один на всех |

## Жизнь, смерть, эволюция

| Ситуация | Правило |
|---|---|
| Жизнь / смерть | Жизнь = параллелизм психических и физических волн + пра́н́а́х; смерть = рассинхронизация (смена оболочки) |
| Траектория эволюции | Высокий контакт тоньше волну (вверх), низкий — грубит (вниз, вплоть до камня) |
| Кто решает в конечном счёте | А́тман-свидетель, а не ум: знание/делание/существование — в нём |
| Что движет умом | Са́мска́ра — накопленный момент; у человека «приобретён» (может быть негативным) |

## Духовная практика и идеология

| Ситуация | Правило |
|---|---|
| Что такое идея / идеология | Идея = психо-духовный параллелизм (bháva); идеология = его зачатие на психическом уровне — духовна по определению |
| Значение слова | Artha = психо-физический параллелизм слова с объектом (прямой или косвенный) |
| Что такое Brahmacarya | Не целомудрие, а ассимиляция психической волны в волны Макрокосма |
| Условие духовной реализации | Полное развитие трёх тел: jad́ádhára (физика), bhávádhára (ментал), cetanádhára (дух) |

## Общество и Prout

| Ситуация | Правило |
|---|---|
| Кто сейчас доминирует | Социальный цикл: shúdra→kśatriya→vipra→vaeshya→шудра-революция; остановка невозможна |
| Как противодействовать эксплуатации | Бей по источнику силы: сила — против силы, интеллект — против интеллекта, демократия — против демократии (выборы) |
| Чем руководствуется страж | Yama (ahimśa, satya, asteya, aparigraha, Brahmacarya) + Niyama (shaoca, santośa, tapah, svádhyáya, Iishvara prańidhána) |
| Минимумы братства | Общая философия жизни + единая конституция + общий уголовный кодекс + гарантированный минимум (пища/одежда/медицина/жильё) |
| Накопление богатства | Запрещено без одобрения коллектива (принцип 1 Prout) |
| Как устроить экономику по Prout | Максимальное использование всех потенциальностей + рациональное распределение + согласование + прогрессивный метод по времени-пространству-личности |

## Быстрые сигналы («tells»)

- Термин «идеология» про материалистическую/политическую доктрину → в словаре Саркара это неправильное употребление.
- Кто-то объясняет «инкарнацию» как прямое нисхождение Бога → отвергаемая догма (Ch 6), за ней часто интерес «интеллектуальных паразитов».
- Утверждение «надо остановить смену эпох» → противоречит закону цикла («застой = смерть»).
- Гарантия минимума «просто так, без всяких условий» → риск психологии лени; нужны особые вознаграждения таланту.
- «Brahmacarya = целибат» → неверно: это резонанс психической волны с волной Макрокосма.
