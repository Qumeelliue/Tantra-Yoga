# Читшит — правила решений по Саркару (The Great Universe)

## Социально-экономический анализ

| Ситуация | Правило |
|---|---|
| Кто у власти | Спроси: какой класс/ресурс незаменим? (сила → интеллект → деньги → число работников) |
| Класс доминирует | Он эксплуатирует → любой доминант порочен; смена доминанта не решает |
| Как строить справедливую экономику | Общее достояние + минимум всем; существенное — кооперативам, роскошь — рынку |
| Капитализм | Психическая болезнь: лечить давлением + образованием; отнять деньги, но и ментальность |
| Земля | Общая собственность человечества; у людей/гос-ва только право сохранения и пользования |
| Социализация ≠ национализация | Хозяева — люди, не государство; компенсация не рассрочкой, а пенсиями/рабочими местами |

## Лидерство и власть

| Ситуация | Правило |
|---|---|
| Кто достоин власти | Садвипры (Yama-Niyama + Космическая идеация); все четыре варны в одном |
| Класс хочет эксплуатировать | Садвипры создают антитезис: против силы — сила, против интеллекта — интеллект, против денег — выборы |
| Демократия | «Лучшее из плохого»: требует образования, 51% моральных, сознательности; иначе — правление дураков |
| Права и управление | Право пользоваться ресурсами мира ≠ право управлять страной |
| Синтез сегодня | Завтра — тезис: ничто в относительности не вечно |

## Справедливость и грех

| Ситуация | Правило |
|---|---|
| Наказание | Только corrective, не punitive; тюрьма = больница; смертная казнь = «отрубить голову от головной боли» |
| Сомнение в вине | Не наказывай: ошибка против невиновного дороже сбежавшего виновного |
| Преступник | 5 категорий: природа/привычка/среда/бедность/слабость → 5 подходов (лечить/воспитывать/менять среду/лечить экономику) |
| Бедность | Корень большинства преступлений — лечи экономику, а не суди голодного |
| Грех vs преступление | Грех — против кардинальных ценностей (развитие других); преступление — против кодекса |
| Добродетель/порок | Относительны (время-место-личность); мораль — абсолютна |
| Три причины греха | Нехватка / переизбыток без использования / статичность |

## Образование, медиа, культура

| Ситуация | Правило |
|---|---|
| Обучение | Жажда знания, а не страх (страх — знание испарится); дети — игра и истории, подростки — идеалы |
| Учителя | Samája gurus: отбор по характеру, зарплата не ниже судей, право на образовательную политику |
| Кино/радио | Негосударственные культурные советы, не партии и не бизнес |
| Образование | Гуманистическое, без измов; никакой ism кроме универсализма |
| Цивилизация/наука | Вровень; наука выше цивилизации — крах; гармония ускоряет духовный прогресс |

## Прогресс и цель

| Ситуация | Правило |
|---|---|
| «Прогресс» науки | Проверь плюсы/минусы: часто баланс ноль; грубые волны поглощай тонкими |
| Истинный прогресс | Только духовный (нет минусов); физика/интеллект — база, не цель |
| Идеология | Ádarsha (безличная идея) + Iśt́a (любовь): оба; без Iśt́a — «бесплодный философ» |
| Добро и зло | Добро — немедленно; зло — откладывать, намерение увянет |
| Жизнь | Миссия: своё освобождение + благо мира |

## Быстрые сигналы («tells»)

- «Так делали предки» → статичность: садвипры «ударят кувалдой», не отступая.
- Благотворительность ваешьи → смазка машины эксплуатации, инвестиция в продолжение.
- «Всё предопределено судьбой» → пропаганда ваешьев, парализующая массы.
- Премии/награды творцам от государства/бизнеса → покупка талантов (эксплуатация).
- Возбуждающие «A»-фильмы и дешёвые детективы → дурная компания, лишающая здравого суждения.
- Политик, обещающий с платформы → не может создать садвипр речами.
- Национальный лозунг «только наше хорошо» → образование не гуманистическое.
