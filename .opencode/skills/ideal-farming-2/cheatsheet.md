# Читшит — правила решений (Ideal Farming 2)

## Вода и орошение

| Ситуация | Правило |
|---|---|
| Выбрать источник орошения | Поверхностная вода (пруды/каналы/дамбы/озёра) всегда предпочтительнее грунтовой |
| Водная таблица ниже 50 футов | Опустынивание близко — срочно прекратить скважины, собирать поверхностную воду ⚠ |
| Построить резервуар в холмистой местности | Не один большой — много малых дамб/прудов (большие каналы теряют давление) |
| Орошать дождевую тень | Туннель сквозь хребет, не каскад насосов ⚠ |
| Увеличить запасы воды | Удвоить→удесятерить: углубить, расширить, умножить посадки вокруг (5× рядов) |

## Возделывание

| Ситуация | Правило |
|---|---|
| Цель — самодостаточность фермы | Чек-лист 13 блоков интегрированной фермы + экстренный минимум (овощи, бобовые, картофель, корм) |
| Занять поле весь год | Севооборот: áus → áman → early boro → late boro (4 урожая риса) через питомник 1 мес. |
| Две культуры одновременно | Mixed (все главные) или supplementary (главная + опора) |
| Улучшить зерновые | + до 10% бобовых (азот); 20% горчицы к пшенице ↑150% ⚠ |
| Посев культуры с сортами | Каскад: ранний → средний → поздний (страховка сезона) |
| Второстепенная культура в поле риса | Pigeon crop (бросить без вспашки): бобовые/rái горчица — только 3 урожая риса в год |

## Агрономия

| Ситуация | Правило |
|---|---|
| Семена для посева | Привозить издалека (редис ≥3 миль, тростник ≥20 км ⚠); жаркий климат — семена из холодных зон |
| Уборка лука/имбиря | Скрутить стебель → макс. размер клубня за ~15 дней |
| Бобовые перед цветением | Остановить обрывание листьев за 1 месяц до цветения |
| Удобрение | Органические предпочтительно; биошлам (slurry) — самый быстрый; овечий навоз — лучший |
| Химические удобрения | Только через кооператив + исследования (иначе земля «как цемент») |
| Пестициды в рисовых полях с рыбой | Только неядовитые: паста нима + мочевина; медь минимально |
| Выбор дерева для берегов | Волокнистые корни (баниан, тамаринд, neem); eucalyptus — только в паре |
| Посадки на склоне | Строго горизонтальные линии, никогда вертикальные |

## Вода у озера/реки

| Ситуация | Правило |
|---|---|
| Создать озеро | Глубина 5 футов (жаркий сухой климат 10 ⚠); 5 типов посадок; таблички; рыба + птицы |
| Выбрать пальму для берега | Кокос–A озеро, пальмира–B, бетелевый орех–C, финиковая–D, банан–E (по ёмкости ⚠) |
| Водные растения | Колючие (лотос, makhana) и неколючие (лилия, каштан) — раздельно |
| Восстановить обезлесенный регион | Двухфазная аффорестация: быстрые (6 мес.–2 г.) + медленные; рубить быстрые через 3–7 лет |
| Управлять трансграничной рекой | Совет всех трёх стадий (холмистая/равнинная/дельтовая); консультации обязательны |

## Быстрые сигналы («tells»)

- Ферма без пруда/озера и рыбы — игнорирует принцип поверхностной воды.
- Глубокие скважины как «основной метод» — маркер будущей пустыни (30–45 лет).
- Смесь бобовых с пшеницей видна по 9:1 — классический приём; khesári в еде — тревожный сигнал (токсична).
- Меню садхака без лука/чеснока/betel nut — соблюдение sentient-диеты.
- Поле пустует после уборки — нарушение принципа «максимум в минимум».
- Саженец с обрезанным на 1 дюйм главным корнем + замоченными корнями — фирменный метод раздачи растений (крупные сладкие плоды).
- Наркотические растения на ферме — нарушение: их место — только у государства.
