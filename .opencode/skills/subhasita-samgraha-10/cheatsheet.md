# Читшит — Subháśita Saḿgraha Part 10

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Ищешь корневую причину | Прогони 6 кандидатов (время/природа/судьба/случай/материя/unit-сознание) → если все отвергнуты, переходи к синтезу (ch01) |
| Перед действием колеблешься | Спроси «праведно ли?», а не «успею ли?»; при подтверждении совести — действуй сразу (ch02) |
| Решаешь, что снимает проблему | Временное снятие = artha; постоянное = paramártha; не путай средство и цель (ch03) |
| Вовлекаешь людей в ценность | Доводи до категории (1): «ценность — моё личное сокровище» (ch03) |
| Настраиваешь коммуникацию под человека | Подбирай форму под его опыт (saḿskára); не бей по чужому ритму (ch04) |
| Реагируешь на гнев/ложь/жадность | Побеждай противоположным: терпение/правда/щедрость (ch05) |
| Замечаешь уязвлённую гордость | Это abhimána; лечение — уважать тех, кого не уважают (ch05) |
| Решаешь прощать в конфликте | Лично — прощай максимально; коллективно — твёрдость (ch05) |
| Оцениваешь целостность | Меньше разрыва мысль↔действие = лучше; split personality — дефект (ch06) |
| Просят «помоги сдать экзамен» как devotion | Это aparábhakti; парабхакти просит только Самого (ch05) |
| Видишь «случайность» | Нет случайностей — есть невидимые причины (ch01) |

## Мини-справочник «четыре kleśa-класса» (ch06)

| Класс | Боль во время | Боль в конце | Пример |
|---|---|---|---|
| kliśt́ávrtti | да | да | 5 кг rasogollas на спор |
| kliśt́ákliśt́avrtti | да | нет | честный путь, трудности → славная смерть |
| akliśt́ákliśt́avrtti | нет | да | безбилетники первого класса |
| akliśt́ávrtti | нет | нет | садхана (общее с Богом) |

## Мини-справочник «противоположные позиции» (ch05)

| Порок | Противоположная добродетель |
|---|---|
| Гнев | Терпение (akkodhena jine kodham) |
| Нечестность | Честность |
| Жадность | Щедрость (dana) |
| Ложь | Правда (satya) |
| Зависть к счастливому | maetrii (дружелюбие) |
| Равнодушие к несчастному | karuńa (сострадание) |
| Обесценивание доброго | muditá (поощрение) |
| Ненависть к злому | upekśa (не замечать пороки) |

## Мини-справочник «три тщеславия» (ch05)

| Термин | Смысл | Образ у автора |
|---|---|---|
| abhimána | уязвлённая честь | «как вино» |
| gaorava | самовосхваление | «в глубочайший ад» |
| pratiśt́há | гонка за престижем | «как свиной помёт» |
