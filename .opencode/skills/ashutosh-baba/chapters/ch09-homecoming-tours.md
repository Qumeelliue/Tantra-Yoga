# Chapter 9: Homecoming Tours

*Октябрь–ноябрь 1979: возвращение в Джамалпур, Гадапур, Хиссар, Пуна.*

## Core Idea
Сентиментальные возвращения: первое возвращение в Джамалпур за 13 лет (правила «сломаны» для земляков), «игры» с ачарьями Музаффарпура (DMC в Гадапуре), посещение родителей bhukti pradhan (Пуна) и эпизод «Am I a Tiger?».

## Key Events & People
- **Jamalpur**: первый прилёт с 1966; инструкция PA: «не будь строг с маргами Джамалпура; это моё детское место»; омовение ног молоком (вера «я — Шива»); «я обещал вернуться и сдержал слово».
- **Gadopur**: марги Музаффарпура → отказ (14 ачарьев «не работают, жуют бетель»); через Чандранатха — «не могу сказать нет»; DMC в Гадапуре (дом Чандранатха) — «один из лучших»; семья: «я как дома»; комната-святилище; ачарьи после — активизировались.
- **Ramchandra Reddy** (Hyderabad): строгий моралист-главный инженер; «был великим садхакой в прошлой жизни»; дом — святилище; свадьбы — клятвы на местном языке.
- **Hissar**: профессор Mallik; Баба на поле с директором университета — знает растения лучше специалиста («7–8 минут на каждое»).
- **Pune**: Paradeshi (директор телеком) устроил гостевой дом, а родители-немарги обиделись → Баба приехал к родителям, «шубхамасту», запах сандала месяц.
- **Am I a Tiger?**: профессор Nilam боится PC → «я не тигр; для плохих — тигр, для тебя — нет»; лёгкое касание; «самскары сожжены; новая жизнь».

## Frameworks & Teachings
- **«Сломанные правила» для земляков**: гибкость протокола в родном городе.
- **Любовь к старым**: «не могу сказать нет» — дисциплина уступает связи.
- **«Игра» с ачарьями**: публичный разбор → исправление → активность.

## Worked Example
Гадапур-двойной ход: (1) отказ маргам Музаффарпура → (2) согласие Чандранатху («не могу отказать») → (3) «DMC не в городе, а в Гадапуре» → (4) разбор ачарьев за неделю до → (5) отличная организация → (6) «вы теперь работаете». Урок: требование результата через личную связь + публичный контроль.

## Key Takeaways
1. Первое возвращение в Джамалпур — «я обещал и вернулся»; правила смягчены.
2. DMC в Гадапуре — образец организации «по любви».
3. Посещение родителей (Пуна) — сентиментальный жест гуру.
4. Знание растений/истории мест — часть полевых уроков.
5. «Я не тигр для тебя» — PC без страха для искренних.
