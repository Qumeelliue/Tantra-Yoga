# Глоссарий — Ashutosh Baba

**Авадхута (avadhuta)** — монах Ananda Marga (Ch 4–5).

**AMURT** — Ananda Marga Universal Relief Team — рельефная команда (Ch 2, 11).

**Ачарья (acharya)** — духовный учитель с правом инициации (Ch 1–2).

**Бутермilk** — «пахта»: йогурт с водой (3:1); единственная пища Бабы в голодовке, две чашки в день (Ch 5).

**Варабхайя-мудра** — жест благословения; кульминация DMC (Ch 11).

**Гуру-дакшина** — традиционное подношение гуру после инициации; в Ananda Marga — «отдай себя», не деньги (Ch 7).

**Дха́рма Самикша (Dharma Samiksha)** — коллективный разбор практик с наказаниями для очищения (Ch 10–11).

**Дхияна (dhyana)** — глубокая медитация (Ch 1).

**Иммолация** — самосожжение в протест; практиковали некоторые марги при отравлении гуру (Ch 5).

**Иста-мантра** — личная мантра (Ch 1, 5).

**Калаватар (kalpataru)** — «исполняющее желания древо» (Ch 12 в Jamalpur Years).

**Каосаки (kaoshiki)** — «лунная» танцевальная практика (Ch 10).

**Капалик (kapalik)** — практик капалик-медитации (Ch 2, 11).

**Киртан** — коллективное пение-мантра (Ch 5, 10).

**Лакшманананда** — подпольное имя Рамананды (Ch 5).

**«Мать» (Mother)** — жена Анандамурти Ума Деви; ушла в 1971 с 37 работниками (Ch 3).

**Марг / марги** — последователь Ananda Marga (Ch 2).

**Панья (paniya)** — заключённый-помощник в тюрьме (Ch 5).

**PA (personal assistant)** — личный помощник гуру; Рамананда с 1971 (Ch 3).

**Прасад** — освящённая пища/предмет (Ch 2, 10).

**Прабхат Самгита (Prabhat Samgiita)** — 5018 песен Бабы (с 1982) (Ch 11).

**Садхана** — духовная практика (Ch 2).

**Самскара** — реактивный моментум (Ch 2, 5, 7).

**Састаунага-пранам** — полное простирание (Ch 2).

**Тандава** — мужской танец-практика (Ch 2, 6).

**Таттва-сабха** — публичная философская дискуссия (Ch 2).

**Фултаймер (wholetimer)** — полно-временный работник (Ch 5, 11).

**Чха́ндика-шакти** — см. cosmic scissor (Ch 4 Jamalpur Years).

**Экадаши** — постный день; Баба постился 4 раза в месяц (Ch 7, 11).

**Vishesh Yoga** — «специальная» йога; уроки для продвинутых (Ch 5).
