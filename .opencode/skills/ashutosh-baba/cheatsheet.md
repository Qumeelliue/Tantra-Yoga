## Ключевые люди

- **Баба (Анандамурти)** — гуру; «отец».
- **Рамананда** — автор, PA 1971–1984.
- **«Мать» (Ума Деви)** — жена гуру; ушла в 1971.
- **Доктор Каловар** — тюремный врач, союзник.
- **Лалдхари** — неграмотный пастух, «слышит флейту».
- **Джаганатх (Лудхиана)** — простой преданный, «я помню только тебя».
- **Рагхувир Прасад** — принципиальный коллектор.
- **Сатьянанда, Шаши Райнджан** — старшие фигуры.

## PA-протокол (что делать)

| Ситуация | Правило |
|---|---|
| Сборы | Чемодан по системе гуру (всё на своих местах) |
| Напитки | Фляга свежего сока/воды; «свежий» = только что |
| Бутермilk | Ровно 2 чашки, 10:00 и 16:00; опоздал — не примут |
| Лекции/запись | Вода = сигнал смены кассеты |
| Палки | Про запас, в сумке PA |
| Отчёты | Проверь перед докладом; «всё готово?» |
| Гости | Список, порядок, конфиденциальность |

## Ключевые принципы (быстро)

| Принцип | Суть |
|---|---|
| Scold = love | Выговор = забота; «без него я бы не учился» |
| Действие → фонды | Рельеф начинают делом, не сбором |
| Чистота > статус | Выбор по преданности, не по должности |
| Обещание = закон | Слово держится любой ценой |
| Преданность > грамотность | Jaganath/Laldhari — образцы |
| Принцип > жизнь | Голодовка: идеи важнее |
| «Игра» = урок | Ищи причину за театром гуру |
| Не трать секунды | Время = ресурс служения |

## Быстрые сигналы («tells»)

- «Завтрак отложен» → «кто-то опоздал/пришёл» — ищи получателя.
- «Поезд/самолёт не летит» → ждёт человека с гирляндой/желанием.
- «Левый/правый» → выбор по чистоте, не по статусу.
- «Обещал» → будет исполнено (Vizag, Una, Джамалпур).
- Неизвестный у ворот «меня позвали» → «неизвестный ученик», встречать лично.
