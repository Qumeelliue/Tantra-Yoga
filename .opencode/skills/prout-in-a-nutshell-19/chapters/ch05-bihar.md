# Chapter 5: Bihar

*Дискурс 21 апреля 1989, Calcutta.*

## Core Idea

Здоровая экономика строится на местном сырье; Бихару нужна не гигантская индустрия, а планирование по пяти socio-economic units с учётом почв, вод, языков и «сентиментального наследия». Основа — Неогуманизм (универсальный гуманизм).

## Frameworks Introduced

- **Неогуманизм = универсальный гуманизм**: человек универсален, никого нельзя ограничивать территорией; PROUT — практический подход.
- **Планирование по socio-economic units**: регион делится по общности языка, почвы, экономики, не по границам штатов. Bihar → Mithila, Magadh, Nagpuri, Angadesh, Bhojpuri.
- **Здоровая vs больная экономика**: сырьё из местной зоны; отрасли на импортном сырье — «слабы, больны, глупы» (Barauni). Гигантских заводов избегать — «местным людям там нет места».
- **Энергия из местного сырья**: спирт из свёклы/тростника заменяет ископаемое топливо.
- **Языковые права**: материнские языки Бихара не признаны — «если твой родной язык не признан, тебя никто не признает»; начальное образование на родном языке.
- **Кооперативы в сельском хозяйстве**: консолидация земли, малые дешёвые ирригационные проекты, смешанное хозяйство и ротация.

## Key Concepts

- **Пять socio-economic units Бихара**:
  - *Mithila* — 8 дистриктов Индии + 4 Непала; Maethilii литература 900 лет; аллювий для садоводства.
  - *Magadh* — Magahii 5000 лет, ~30 млн; 10 миль от Ганга — аллювий для манго/личи/лимона, дальше глина, потом латерит.
  - *Nagpuri* — Gumla/Chotanagpur; уголь в долине Дамодар, боксит в Lohardaga; Kuruk (Dravidian).
  - *Angadesh* — самая угнетённая зона; язык Angika не признан; каш-культуры: Kerala-кокос (яма 3 фута, 5 кг соли), перец по кокосам, areca nut, ананасы, красный перец (Kalna), манго; термальная энергия из местного угля; дренаж (Kosi).
  - *Bhojpuri* — Gorakhpur/Deoria; 3 скрипта (Nagari, Sháradá, Kut́ila); индустрии в руках чужих эксплуататоров.
- **Типы земли по удержанию воды**: высокая сухая (бесплодна без орошения) → бесплодная равнина (с орошением продуктивна) → средняя → влажная плодородная (лучшая).
- **Защита от эксплуатации**: в Angadesh/Assam — худшие эксплуатации; деньги на выборы от капиталистов; призыв к polarization.

## Mental Models

- «Дели регион по языку и почве, а не по карте штатов».
- «Перед отраслью проверь сырьё: своё — здоровая, чужое — больная».
- «Язык — ворота признания».
- «Кооператив делает то, что не может одиночка».

## Anti-patterns

- **Гигантские заводы вместо местной промышленности** («местным нет места»).
- **Нефтепереработка/сталь на привозном сырье** — «глупая отрасль».
- **Признавать чужие языки, но не свои** — граждане второго сорта.
- **Подавление материнского языка и культуры**.
- **Игнорировать тип земли** при планировании культур.

## Worked Example

Планирование Bihar: разделить на 5 единиц. Mithila — садоводство на аллювии (манго, личи, дыни), jute не поощрять → remi silk. Magadh — манго/личи/лимон до 10 миль от Ганга, папайя южнее; классификация земли → орошение. Nagpuri — уголь, боксит→алюминий, лесовосстановление. Angadesh — план каш-культур, местный уголь, дренаж Kosi. Bhojpuri — садоводство в радиусе городов. Плюс: спирт из свёклы, образование на родном языке, кооперативы.

## Key Takeaways

1. Неогуманизм требует гарантий для всех (PROUT); человек универсален.
2. Регион планируется по socio-economic units, а не по границам.
3. Отрасль на импортном сырье — «больная»: не строить.
4. Языковые права — базовое достоинство; начальное образование на родном языке.
5. Тип земли определяет культуры и орошение.
6. Кооперативы усиливают сельское хозяйство.
7. Энергия из местного сырья (спирт) заменяет ископаемое топливо.
