# Читшит — правила решений по Саркару (Prout 4/19)

## Экономика и производство

| Ситуация | Правило |
|---|---|
| Оценить проект | Тест «больной отрасли»: сырьё из зоны? рынок свой? не заменит синтетика? |
| Сырьё импортное | «Больная» отрасль — не строить |
| Страна бедная, без промышленности | Бартер — лучшая торговля |
| Экспорт сырья без переработки | Колониальный паттерн — грабёж зоны |
| Нет энергии | Сначала энергия: дельта→приливная/солнечная |

## Диагностика эксплуатации

| Ситуация | Правило |
|---|---|
| Прибыль в экономике | Сама по себе не эксплуатация (отказ от Маркса) |
| Оценить эксплуатацию | Грабёж физического + психического труда + ресурсов общины |
| Рынок + монополия + чужие фабрики | Колониальная эксплуатация |
| Политвласть + налоги + ростовщики | Империалистическая эксплуатация |
| Национализм + подавление языка/культуры | Фашистская (психо-экономическая) |
| Доля прибыли остаётся в зоне | ≈0% → эксплуатация (Samatat) |

## Планирование зоны

| Ситуация | Правило |
|---|---|
| Деление региона | Socio-economic units по языку/почве/культуре |
| Старт плана района | Вопросник: города, вода, доход, гигиена |
| Планировать издалека | Нельзя: сначала знание местности |
| Экономика централизована | Децентрализация + блочное планирование |
| Подбор культур | Тип земли + почва + осадки + рынок |

## Общество и права

| Ситуация | Правило |
|---|---|
| Сепаратистский вопрос | Проверь: «искусственный», создан партией? |
| Кто автохтон | Плотность поселения + история заселения |
| Права племён | Только племенам, ограничены во времени |
| Язык большинства | Не определяется диалектом меньшинства |
| Родной язык не признан | Гражданин второго сорта: школа на родном языке |
| Региональное развитие | Через автохтонное большинство, в рамках универсальной человечности |

## Поселение и устойчивость

| Ситуация | Правило |
|---|---|
| Переселение людей | Только в свою физико-социо-экономическую зону |
| Блуждающее население | Закрепить на месте или вернуть на родину |
| Проект поселения-модели | Master Unit: пять минимумов из местного сырья |
| Удобрения | Только био; химия исключена |
| Побережье | Лес (jhau) + стены + местный порт |
| Топливо | Спирт из свёклы/тростника |

## Быстрые сигналы («tells»)

- Отрасль на привозном сырье → «больная», вероятна эксплуатация зоны.
- Регион богат, но ≈0% прибыли остаётся → нео-колониальный захват.
- Этнический вопрос, раздутый партией → «искусственный вопрос».
- Пришлые преобладают численно → риск аннексии.
- Народ держат на пособиях → подавление революции.
- Навязывание чужого языка → психическая эксплуатация.
