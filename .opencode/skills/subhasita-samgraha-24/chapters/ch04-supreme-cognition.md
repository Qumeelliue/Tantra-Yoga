# Chapter 4: The Supreme Cognition

*Дискурс 26 сентября 1966, DMC, Сурат. На английском.*

## Core Idea

Supreme Cognition — Трансцендентальная Сущность (Náráyańa = «где укрыта Supreme Operative Principle»). Из тонких волн Оперативного Принципа в первом геометрическом рисунке — три принципа (sentient/mutative/static) → «треугольник сил». Из взаимодействия — 50 пропензиций (50 цветов/звуков, varńamálá). Сущность скрыта во всех существах (Eko Devah); путь — Eka (одна идеация).

## Frameworks Introduced

- **Náráyańa**: Nára (три значения: вода, преданность, Supreme Operative Principle) + ayana (укрытие) = Náráyańa. Познание укрывает Оперативный Принцип.
- **Треугольник сил**: в первом (теоретическом) рисунке творения — три волны по длине (sentient — почти прямые, mutative, static) → треугольник. Меж-трансформации — **svarúpa parińáma**. Вершина треугольника — Kaośikii/Shivánii shakti; свидетели — Shiva.
- **Стадии Оперативного Принципа**: (1) triangle/basic principle (Kaośikii); (2) straight-line/primordial (Bhaeravii) — «всё ещё прямая линия»; (3) vibrational (Bhavánii) — кривизны из clash&cohesion. В (3) — проявленная вселенная.
- **Sadrsha parińáma** — «следующая кривизна следует предыдущей» (сын похож на отца; но A→Z — гульф между австралопитеком и современным человеком).
- **Время = психическое измерение скорости действия** (подтверждается); три относительности — творения Оперативного Принципа, который укрыт Познанием → Познание вне времени/места/личности.
- **Cognition — jiṋána svarúpa** (свидетеля). **Jiṋána** = «знание, что всё — одно»; прочие знания — «тени» (Átmajiṋánam vidurjiṋánam…).
- **Космическая vs единичная causa**: единичный ум — создание материи (quinqfactor balance → ectoplasm → интроверсия → ego/intellect/intuition); не прямое творение Макрокосма.
- **Пятьдесят пропензиций**: 50 желез/поджелудков → 50 гормонов (granthisudhá) → 50 пропензиций → 50 цветов (varńas) и 50 звуков. Варна-мала: a (творение), i, ii, u, uu… Каждая пропензиция — волна со своим wavelength и звуком.
- **«Ека» (Одно)**: Сущность вне eka/aneka (психических проекций); но ŕshi говорит eka, потому что когда ум становится «одним», приходишь в контакт с Ним. 50 пропензиций → свести к одному потоку.
- **Deva**: каждое вибрационное выражение, излучённое из ядра (Парама Пуруша), — deva; 50 букв — devas, mátrka varńa («буквы-матери вселенной»). Дева = divine expression.
- **Mahádeva**: Deva всех дева; «он отец всех отцов». Метафора: Луна — мама́ (дядя) всех; Парама Пита́ — отец всех отцов.
- **Sarva**: sa (посев, sentient — биджа саттвы), ra (энергия — корень), va (характерное свойство — «вont») → sarva = «всё». Этимология — рабочий метод автора.
- **Практические выводы**: тело — 50 пропензиций; контролируй железу (гланд) — контролируешь пропензицию (наука садханы). Машина/воля: энергия — Его. «Ты — машина, не машинист».

## Key Concepts

- **Náráyańa, Nárada** — этимологии.
- **Svarúpa parińáma, sadrsha parińáma** — два типа трансформаций.
- **Granthisudhá / granthirasa** — гормоны желез.
- **Mátrka varńa** — «буквы-матери» (матрица).
- **Jiṋána svarúpa** — Познание как «по природе знание».

## Mental Models

- «Ищи ядро-источник для каждой системы: атом→ядро, земля→луна, солнце→планеты, Парама Пуруша→космос».
- «Ум — создание материи; но Познание — не материя».
- «50 пропензиций — 50 волн; чтобы встретить Единое, сведи их к одному».
- «Контролируя железу (гормон), контролируешь пропензию — садхана научна».
- «Я — машина; энергия — Его; не приписывай себе заслуги».

## Anti-patterns

- **Путать единичный ум с Космическим**: микрокосм — из материи, не прямое творение.
- **Думать, что Познание в времени/месте** — оно вне трёх относительности.
- **Разбрасывать пропензиции по множеству объектов** — разделяет ум; собери в одно.
- **Говорить «я сделал/я достиг»** — машина не владеет энергией.
- **Считать себя знающим через многие знания** — истинное знание одно (átmajiṋána).

## Worked Example

Автор разбирает шлоку «Eko Devah sarvabhúteśu gúd́hah sarvavyápii…». Спрашивает: почему «eka» (один), если «aneka» — тоже психическая проекция? Ответ: когда ум становится «одним» (50 пропензиций сведены к одному потоку через интроверсию), приходит контакт с Ним. Дева: каждое выражение из ядра — deva, счастливое выражение Бога. Иллюстрация: «контролируя гланд, контролируешь пропензицию» — гормоны из 50 желез управляют 50 пропензициями; потому садхана — инженерия ума через тело.

## Key Takeaways

1. Náráyańa = «Познание, укрывающее Оперативный Принцип»; треугольник сил → 50 пропензиций.
2. Два типа трансформаций: svarúpa (меж-принципная) и sadrsha (похожая, кривизна следует кривизне).
3. Познание вне времени/места/личности; единичный ум — из материи.
4. 50 пропензиций = 50 цветов/звуков; сведение их к одному = контакт с Единым (Eka).
5. Каждое выражение ядра — deva; все — его дети.
6. Ты — машина; энергия — Его; садхана — инженерия ума через тело.
