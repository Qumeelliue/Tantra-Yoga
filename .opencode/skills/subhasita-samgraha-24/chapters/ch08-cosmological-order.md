# Chapter 8: The Cosmological Order

*Дискурс 27 июня 1969, DMC, Бангалор. На английском (частично невнятная запись).*

## Core Idea

В космосе везде порядок (system). Парама Пуруша — ядро (nave/hub), всё движется вокруг Него (Brahma Cakra). В каждой структуре — контролирующая часть (para) и контролируемая (apara); ядро даёт жизненность. Силы: центростремительная (vidyá) и центробежная (avidyá). Всё — вибрации ядра (девы); все танцуют в rásaliilá под флейту Кришны.

## Frameworks Introduced

- **Порядок**: «все структуры ведомы законом; имя закона — природа; имя рабочей способности — Prakrti; контролёр — Parama Puruśa».
- **Para/apara**: в каждом атоме ядро — para (контролирующий), электроны — apara. Земля — para для луны; солнце — para для планет. Смерть солнца = смерть планет (thermal death). Аналогия: Парама Пуруша — para вселенной; дживы — apara.
- **Две силы**: центростремительная (vidyá) и центробежная (avidyá). Vidyá — «селектор для центра», avidyá увеличивает радиус. Vidyá: samvit, hládinii. Avidyá: vikśepa, ávarańii (см. Ch1).
- **Взаимовлияние**: «жизнь, движение, мысли муравья влияют на тебя; даже преждевременная смерть муравья нарушила бы равновесие вселенной». Никто не бессмыслен; каждый ценен для баланса.
- **Девы**: волны, эманируемые ядром; «Dyotate kriid́ate… Tasmát deva iti proktah». Девы контролируют все феномены. В человеческом теле — «больше дев, чем нервных волокон и клеток» (пропензиции). Мahádeva = «всевыбражение, бесконечный океан нектара» — Sarvadyotanátmaka akhańd́a cidaekarasah.
- **Shaḿkara** = контролирующий (sham = контролировать); Кришна, Махадева, Шамкара — не различимы.
- **Rasa / rásaliilá**: космос — океан божественного нектара (kśiirasamudra, sudhárasam); вибрации — девы; жизнь дживы — лодка, поднимающаяся по волнам. Контролирующая флейта Кришны — ритм; все танцуют по ритму (rа́saliilá = лила блаженства).
- **Стадии выражения**: basic (около ядра) → bháva (вторая, почти прямая линия; «Shuddhasattvavisheśád́vá… rucibhishcittamásrńya krdasao bháva ucyate») → vibrational (создание квинквелементальной вселенной).
- **Садхана = уменьшение радиуса** через hládinii shakti.
- **Juśt́a = «помощь/благодать»**: devotee уверен, что благодать всегда на всех, но осознают её не любящие (держат «зонтик тщеславия»); убираешь зонтик — намокаешь от благодати. Это и есть садхана.
- **Три вещи, от которых отказаться**: abhimána (раздутое эго = вино), gaorava (само-возвеличение → naraka), pratiśt́há (социальный статус = свиной навоз). После — Hariḿ bhajet.
- **Бессмертие**: mortality = death = change; в относительном мире движение = смерть; ядро — фиксированная точка, там бессмертие (Amrta Puruśa).

## Key Concepts

- **Brahma Cakra** — космологический порядок.
- **Para/apara** — контролирующее/контролируемое.
- **Deva / devatá** — вибрационное выражение ядра / младшее выражение.
- **Sarvadyotanátmaka akhańd́a cidaekarasah** — «всевыбражение, бесконечный нектар».
- **Varńamálá** — «собрание цветов» = алфавит (см. Ch4).

## Mental Models

- «В любой системе ищи para (ядро) и apara (спутники); ядро даёт жизненность».
- «Центростремительное — к цели; центробежное — прочь; осознай, какое действует».
- «Даже муравей важен для равновесия вселенной — никто не бессмыслен».
- «Ты танцуешь под флейту космического ритма, нравится или нет — сдайся в лиле».
- «Зонтик тщеславия блокирует благодать — убери его».

## Anti-patterns

- **Считать себя бессмысленным** — даже муравей важен.
- **Удерживать эго/статус** — abhimána/gaorava/pratiśt́há тянут вниз.
- **Думать, что благодать избирательна** — она на всех; мешает зонтик тщеславия.
- **Думать, что можно выйти из лилы** — движение и танцы вселенские; «одна лишь природа закона».

## Worked Example

Автор разбирает аналог ядра: атом (ядро+электроны) → земля+луна → солнце+планеты → Brahma Cakra (Парама Пуруша+дживы). В каждом случае «para» даёт жизненность (тепло, свет); смерть солнца — смерть планет. Затем проводит связь с «зонтиком тщеславия»: благодать льётся на всех (дождь), но держащие зонтик тщеславия не намокнут. Вывод: садхана = убрать зонтик эго, принять благодать, уменьшить радиус.

## Key Takeaways

1. Везде порядок; Парама Пуруша — ядро; всё движется вокруг.
2. Para (ядро) даёт жизненность; apara зависит.
3. Vidyá (к центру) / avidyá (от центра); влияние на ум (samvit/hládinii, vikśepa/ávarańii).
4. Даже муравей влияет на равновесие вселенной.
5. Девы — вибрационные выражения ядра; все танцуют в rásaliilá.
6. Садхана = уменьшение радиуса; убери зонтик тщеславия — благодать польётся.
