# Chapter 2: What Is the Primary Cause of the Universe and Who Is the Only Object of Ideation?

*Дискурс 23 мая 1965, DMC, Патна. Исходно на хинди («Srśt́icakra and the Dhyeya of the Microcosm»).*

## Core Idea

Ни один относительный фактор не может быть первопричиной творения: ни время, ни природа, ни судьба, ни случай, ни материя, ни единичный атман — ни по отдельности, ни вместе. Единственная причина — Высшее Познание (Supreme Cognition / Causal Matrix). Оно же — единственный dhyeya (объект медитации).

## Frameworks Introduced

- **Шлока «Kálah svabhávo niyatiryadrcchá bhútáni yonih puruśa…»** — перечисление кандидатов в причину. Разбор каждого:
  - **kála (время)** — не независимый фактор: нужно место (без места нет действия) и личность (измеритель скорости). Время = «психическое измерение скорости действия»; относительное, не вечное; «Mahákála/Eternity» как сущность не существует.
  - **svabháva (природа)** — «слепая сила»; не имеет суждения (младенец суёт руку в огонь — природа не «наказывает»); дискриминирующий мир не может произойти из не-дискриминирующей природы.
  - **niyati (судьба)** = adrśt́a («невидимое») — невыполненные самскары (реакции в seed form). НЕ управляет; «люди могут вылепить свою судьбу действиями». Судьба = отражённые реакции прошлого.
  - **yadrcchá (случай/accident)** — нет «accidents»; «случай» = скрытая причина, misnomer для незнания. Всё — incident (происшествие с причиной).
  - **bhúta (материя)** — материализм Charvaka («неперцептируемое не существует»); но ум/воздух неперцептируемы и существуют; из инертной материи не может быть интеллекта.
  - **Prakrti** — не причина: «Shaktih Sá Shivasya Shaktih» — энергия Пракрти — энергия Пуруши; без Его позволения вселенная не возникла бы. Пракрти — вторичная причина, Пуруша — главная.
  - **jiivátmá (единичный атман)** — vulnerable (па́popahatátmá/puńyopahatátmá — атман «подвержен»), как зеркало отражает красное от красного цветка; не может быть причиной.
  - **Saḿyoga (комбинация)** — сумма несовершенных не создаёт бесконечного.
- **Bodha vs jiṋána**: citta pro-phenomenal → bodha (восприятие); citta pro-noumenal, отражение на átmá → jiṋána (знание). Рефлектирующая пластина важнее отражённого.
- **Átmá — subtlest plate**, но shelterless — ищет vast shelter = Supreme Cognition (Causal Matrix).
- **Dhyeya**: только Supreme Cognition — объект идеации. «Tad Brahma» (Veda): из Него всё рождается, в Нём живёт, в Него растворяется.
- **Относительные факторы НЕ бесполезны** — они инструменты parágati (интровертивного движения к Parashiva): время (не трать), природа (изучай — лечение, характеры), судьба (eye-opener: страдание = наказание за прошлое → спокойствие и бдительность), «случай» (возможность садханы = эффект прошлых благодеяний → используй настоящее), материя (проявление Бога — обращайся бережно).
- **Shiva vs Shakti**: Shakti не dhyeya; «Shiva attainable через мысль о Shiva, не через мысль о Shakti». Shaeva в мысли = Shákta в садхане. «Нет повода не поклоняться Шиве за неимением Шакти».
- **Шива не различает грешников и добродетельных**; мать сильнее любит слабого ребёнка; «Shiva протягивает руки первым грешникам». На садхане Шивы не нужны цветы — нужна любовь.

## Key Concepts

- **Causal Matrix** — первопричина (Высшее Познание).
- **Dhyeya** — объект идеации.
- **Adrśt́a** — «невидимое» (причина реакции не видна → судьба).
- **Karmaphala-bhoga** — отработка реакции.
- **Charvaka** — материалистическая школа.

## Mental Models

- «Оценивая первопричину любого явления, проверь 6 кандидатов по одному; ответ обычно "не причина, а инструмент"».
- «Судьба — бухгалтерия реакций, а не воля; влиять можно действиями, не гаданием».
- «"Случайность" — слово для незнания причины».
- «Времени не существует без места+личности: время — производная, не корень».
- «Шива-существительное, Шакти-инструмент: цель — Познание, не сила».

## Anti-patterns

- **Фатализм**: «всё решает судьба» — судьба не управляет; ответственность на действиях.
- **Материализм Charvaka**: «невидимое не существует» — неверно.
- **«Бог накажет/наградит по правилам как судья»** — Он отец, мать, для грешников — первый помощник.
- **Считать «случайностью» недоступную причину** — признак незнания, не сущности.
- **Игнорировать время/природу/материю как «не важные»** — они инструменты парагати.

## Worked Example

Автор разбирает шлоку и поочерёдно «убивает» каждого кандидата: время — относительный (нужны место+личность); природа — слепая (без суждения); судьба — это невыполненные самскары, не воля; случай — скрытая причина; материя — не может дать интеллект; Пракрти — лишь инструмент Пуруши; jiivátmá — зеркало, не источник. Вывод: «Сумма несовершенного не даёт бесконечного» → единственная причина — Supreme Cognition. Но: относительные факторы остаются инструментами движения к цели (парагати), каждому — своя роль (время не тратить, природу изучать, судьбу использовать как зеркало).

## Key Takeaways

1. Время, природа, судьба, случай, материя, единичный атман — не причины; причина — Высшее Познание.
2. Время = психическое измерение скорости; относительное.
3. «Случай» — маска незнания причины.
4. Судьба (niyati/adrśt́a) — не воля, а неотработанные самскары; люди куют судьбу действиями.
5. Dhyeya — единственный: Supreme Cognition; относительные факторы — инструменты движения к Нему.
6. Шива — цель, Шакти — инструмент; для садханы Шивы нужна любовь, не ритуалы.
