# Глоссарий — Subháśita Saḿgraha Part 24

**Abhidhyána (абхидхьяна)** — «медитация на Нём»; два метода: prańidhána и anudhyána (Ch 3).

**Abhinivesha (абхинивеша)** — психическая «болезнь» тяги к грубому даже при знании вреда; гонимая avidyá (Ch 10).

**Apara / para (апара/пара)** — контролируемая / контролирующая часть структуры (ядро — para, спутники — apara) (Ch 8).

**Aparábhakti (апарабхакти)** — «не бхакти»: эгоистичная молитва (тамасик/раджасик/саттвики) (Ch 5, 9).

**Artha (артха)** — временное освобождение (пища, деньги, смысл слова); второй фундамент (Ch 9).

**Ávarańii shakti (аварани-шакти)** — влияние avidyá: «если я не думаю о Боге, Он не думает обо мне» (Ch 1, 8).

**Avidyá (авидья)** — центробежная сила, отталкивающая от ядра (Ch 1, 8).

**Bhaktir Bhagavato sevá** — «бхакти — служение Богу» (Ch 9).

**Brahma Cakra (брахма-чакра)** — Космологический порядок: дживы вращаются вокруг Парама Пуруши (Ch 1, 8).

**Caturvarga (чатурварга)** — четыре фундамента: káma, artha, dharma, mokśa (Ch 9).

**Deva (дева)** — вибрационное выражение, эманируемое из Космического ядра (Ch 4, 8).

**Dhruvásmrti (дхрувасмрити)** — постоянная память/любовь к Богу (Ch 6).

**Dhyeya (дхейя)** — объект медитации; только Supreme Cognition (Ch 2).

**Hládinii shakti (хладини-шакти)** — влияние vidyá: желание к духовному; = Rádhiká shakti (Ch 1, 5).

**Iśt́a mantra (ишта-мантра)** — мантра к высшей цели; тайная, повторяемая мысленно (Ch 10).

**Jñána svarúpa (джняна-сварупа)** — Познание как «по природе знание» (Ch 4).

**Káma / artha / dharma / mokśa** — четыре слоя существования (Ch 9).

**Karmádhyakśa (кармадхьякша)** — Он хозяин действий; ты — машина (Ch 3, 4).

**Kála (кала)** — время = психическое измерение скорости действия (Ch 2, 3).

**Kulakuńd́alinii (кулакундалини)** — дремлющая сила; пробуждается «ударом мантры» (Ch 6).

**Mahákaola (махакаола)** — тантрический гуру, пробуждающий кундалини (Ch 10).

**Mahámáyá / Vishvamáyá** — Оперативный Принцип в фазе творения / в физическом слое (Ch 3, 9).

**Mahápatáka / atipátaka** — тяжёлые грехи без обычного искупления (Ch 6).

**Mantra (мантра)** — «Mananát tárayet yastu sah mantrah» — ведёт к paritráńa (Ch 10).

**Niyati / adrśt́a (нияти/адришта)** — «судьба» = неотработанные самскары (Ch 2, 3).

**Patáka (патака)** — собирательное имя pápa и pratyaváya (Ch 6).

**Parábhakti (парабхакти)** — высшая бхакти: «хочу Тебя»; фаза 2 — «служу, чтобы дать Тебе удовольствие» (Ch 9).

**Prańidhána / anudhyána** — отвод ума к одному / стойкость сердца (Ch 3).

**Pratyaváya (пратьявая)** — «грех несовершения должного» (Ch 6).

**Samvit shakti (самвит-шакти)** — влияние vidyá: «жизнь имеет высшую цель» (Ch 1, 8).

**Siddha mantra (сиддха-мантра)** — совершенная мантра от Mahákaola; только она ведёт ум (Ch 10).

**Sukha / duhkha / ánanda** — параллель вибраций / непараллель / бесконечная параллель (Ch 9).

**Svarúpa parińáma / sadrsha parińáma** — меж-принципная / «похожая» трансформация (Ch 4, 8).

**Tattvabháva (таттвабхава)** — «Thatness»: «всё — То» (Ch 3).

**Tráńa / paritráńa (трана/паритрана)** — временное / постоянное освобождение (Ch 10).

**Varńamálá (варнамала)** — «собрание цветов» = алфавит (50 цветов/звуков) (Ch 4).

**Vidyá / avidyá (видья/авидья)** — центростремительная / центробежная сила (Ch 1, 8).

**Vikśepa shakti (викшепа-шакти)** — влияние avidyá: «если уйду от центра, Он не сможет управлять судьбой» (Ch 1, 8).

**Yadrcchá (ядриччха)** — «случай»; misnomer для скрытой причины (Ch 2, 3).

**Yojanát (йоджанат)** — слияние (yuiṋj), не контакт (yuj) (Ch 3).
