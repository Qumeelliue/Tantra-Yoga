# Читшит — правила решений по Саркару (Subhasita Samgraha 24)

## Причина и судьба

| Ситуация | Правило |
|---|---|
| Искать первопричину | Проверь 6 кандидатов (время/природа/судьба/случай/материя/атман); причина — Высшее Познание |
| «Это судьба» | Судьба = неотработанные самскары; управляй действиями, не гаданием |
| «Это случай» | Misnomer: причина скрыта; ищи её |
| Время как вечное | Время = психическое измерение скорости; нужны место+личность |
| Объект медитации | Только Supreme Cognition (dhyeya); Шакти — инструмент, не цель |

## Силы и движение

| Ситуация | Правило |
|---|---|
| Движение к цели/от цели | Vidyá (к центру) vs avidyá (от центра); уменьшай радиус |
| Мысль «убегу — не заметят» | Vixkśepa shakti (иллюзия) |
| Мысль «закрою глаза — меня не видно» | Ávarańii shakti (иллюзия) |
| «Я должен что-то сделать» | Samvit shakti (здоровое осознание миссии) |
| Ускорение к цели | Hládinii shakti (блаженное продвижение) |
| «Я сам сделал, я владелец» | Ты — машина; энергия — Его |

## Бхакти и мотивация

| Ситуация | Правило |
|---|---|
| Просьба кары/вещей/покоя | Aparábhakti (эгоистичная молитва, не бхакти) |
| «Хочу Тебя» | Parábhakti; высшая фаза — «служу, чтобы дать Тебе удовольствие» |
| Знания vs служение | karma − jñána = bhakti; эрудиту нужно больше служения |
| Оценка глубины вовлечённости | Лестница samádhi: sálokya→sámiipya→sáyujya→sárúpya→sárśt́hi→kaevalya |
| Mukti или Он? | Бхакта: «хочу Тебя, не mukti» |

## Служение и грех

| Ситуация | Правило |
|---|---|
| «Служение» с ценником | Бизнес (vyavasáya), не sevá (односторонняя) |
| Нарушение запрета / неисполнение долга | pápa / pratyaváya — оба грех (pátaka) |
| Тяжёлый грех (атипатака/махапатака) | Искупление: отказ от мирского + служение (+ изобретение постоянного блага) |
| Комплекс «я грешник» | Семейные отношения с Отцом; нет inferiority complex |

## Мантра и цель

| Ситуация | Правило |
|---|---|
| Нужна ли мантра | Для духовного слоя — indispensable; только siddha mantra ведёт ум |
| Движение без цели | Вол в маслобойне: движение ≠ прогресс |
| Жизнь без миссии | «Лучше не жить, чем быть бременем»; Átmamokśárthaḿ jagaddhitáya ca |
| Раскрытие Iśt́a mantra | Храни в тайне, повторяй мысленно |

## Быстрые сигналы («tells»)

- Скрипты разнятся, а сторонники каждого кричат «не оспаривай» — блокируют интеллектуальный прогресс; следовать практику (mahájana).
- «Это судьба / звёзды так расположили» — карма-причина, не воля.
- «Хочу покоя/статуса/спасения» — саттвики-мотивация, не бхакти.
- «Я знаю, я сделал» — тщеславие машины; «Он использовал мою структуру» — смирение.
- Ребёнок просит «маму», не игрушки — parábhakti-уровень.
- Учёный с 400° знания и 500° служения имеет меньше бхакти, чем неграмотный труженик.
