# Читшит — правила решений по Саркару (Subháśita Saḿgraha 16)

## Духовность и неогуманизм

| Ситуация | Правило |
|---|---|
| Проверить садхану/практику на любой фазе | Тест: подход неогуманистический? Догма ломает даже 20 часов садханы |
| Движение к реализации | «Я»-лестница: indriya → citta → aham → mahat → jiivátma → Paramátma |
| Эго-язык («я делаю, я даю») | Ahaḿtattva — дефект; нужен mahattattva (чистое «Я») |
| «Я посланник Бога, остальные прокляты» | Дефект, не-реализация; не универсализм |
| Когда принимать неогуманизм | С первого шага и накануне финального слияния (последнее слово) |
| Проверка «реализованного» | По внешним делам: нет неогуманизма во внешнем — нет реализации |

## Панорамная вселенная

| Ситуация | Правило |
|---|---|
| Движение ядра вселенной | Circum-rotarian; ядро движется без смены места = абсолютная скорость, не пауза |
| Три выражения ядра | Физическое (квинквелементальный мир, в рамках Т-П-Л), психическое (макрокосм), духовное (вне Т-П-Л) |
| Фазы субъективного мира | Физико-психическая → психо-духовная → чисто духовная |
| Отношение к объективному миру | Не иллюзия; корректируй через неогуманизм (субъективный подход через корректировку) |

## Лечение и служение

| Ситуация | Правило |
|---|---|
| Проблема возвращается | Лечи источник (психологию), не симптом; иначе новые страдания вместо старых |
| Планирование в меняющейся среде | Диагноз + прогноз; действуй заранее, чтобы догмы не легли на интеллект |
| Сопротивление боли/гео-сентименту | Сладостью ума; финал — постоянное освобождение людей/животных/растений |
| Как решить проблемы человечества | Неогуманизм; двигатель — любовь к Верховному через садхану |
| Роль киртаны | Очищает ум: 5 минут чистоты → 5 минут сильной садханы → прогресс → служение |

## Быстрые сигналы («tells»)

- Практика длинная, но ум догматичен — «не на правом пути», какой бы долгой ни была.
- Лидер говорит «мой путь единственный» — вероятно, дефектная реализация.
- Облегчение без работы с источником — временное; жди рецидива.
- Никто не планирует будущее (только текущий «фикс») — нарушение диагноз+прогноз.
- Ум «загрязнён», практика короткая — добавь очищение (киртана), а не просто удлинение садханы.
