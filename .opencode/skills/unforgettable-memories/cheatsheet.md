## Правила решений

| Ситуация | Правило |
|---|---|
| Человек «с пороками» хочет учиться | Прими как есть; «добавь прекрасное»; привычки уйдут через садхану |
| Ученик боится наказания | Наказание = лечение (Dukh Haran); «квант любви > кванта наказания» |
| Нарушение «втайне» | Считай, что «глаза видят везде» — нарушение станет явным |
| Задача дана, навыков нет | Иди и делай; вера заменяет скиллы; отчитывайся |
| Что просить у Высшего | Только Parabhakti (преданность); с ней придёт всё |
| Скрытая самскара (старая привычка) | Вскрывается и уходит через мантру Гуру / жезл |
| Спешка к духовной «высоте» | Без преданности — риск «выпадения»; преданность = щит |
| Репрессии/запрет организации | Подполье: снять форму, легенды, местный язык, помогать арестованным |
| Начать работу в новом регионе | Служение (школа/рельеф) — лучшая реклама идеологии |
| Перед санньясой | Нужно письменное согласие семьи (3 условия) |
| Проверка кадра | Dharma-samiksa: скан → выявление → наказание → наставление |
| Диета/пост | Соблюдай шестнадцать пунктов; проверяй состав еды; Nirjala — после разрешения Гуру |

## Ключевые фреймворки одним взглядом

- **PC = скан прошлого + наказание-благодать + обещание** (дхармик).
- **SPT** = подаяние + одна еда + контроль 6 врагов/8 узлов + Ишта-мантра.
- **Emergency-паттерн** = конспирация + садхана-якорь + солидарность кадров.
- **Неогуманизм бытовой** = похороны собаки, лечение буйволицы, кормление ребёнка.
- **PROUT бытовой** = максимальное использование (остаток мыла).
- **Safe distance** = преданность-щит при ускоренном исчерпании самскар.
