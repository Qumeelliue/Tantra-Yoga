# Глава 5: Полевая работа и Керала (1963–1970-е)

## Core Idea

Зрелое служение авадхуты: приём «отверженных» (адвокат-грешник), DMC-анекдоты, капалика-дикша (06.01.1964) и ночная садхана в Death Valley, встречи с Avidya Tantrika, защита при капалике, уроки языков, гуру-падпуджа, а затем Керала: AMURT-flood relief, Trivandrum DMC (1968), атака коммунистов на школу, покупка земли, Рukmini Amma, чудо в Madurai, «казначей» Ramchandra Sethji.

## Frameworks Introduced

- **Приют «denied by all»**: Kanhailal — успешный адвокат с «пороками» (алкоголь, сигареты, азарт, мясоед); другие гуру отказывались учить, пока не бросит привычки. Автор: «Не прошу ничего бросать — добавлю нечто прекраснее» → условие: практиковать ежедневно (даже если ум против) → инициация с запретом оставлять привычки → в ту же ночь рюмка «выпадала» 3 раза → «проснувшаяся совесть» → через 3 месяца все привычки ушли. Урок: начинай с того, что есть; привычки уходят сами через садхану.
- **DMC-анекдот «разбитые очки»**: Бäbä «потерял очки» → беспомощность → Кешава (хозяин) всю дорогу ухаживал → ночью Бäbä прочитал газету в темноте и повторил абзац слово в слово → «Hari ananta, Hare katha ananta — делай больше медитации, поймёшь». Урок: «беспомощность» Гуру — проверка/настройка преданности; знания безграничны.
- **Строгий взгляд (Bhairava Prasad)**: адвокат пообещал не пить, но ночью «втайне» хотел последний стакан → Бäbä знал и вызвал → «мои глаза видят везде» → бросил. Урок: дисциплина не анонимна; зоркость Гуру — часть обучения.
- **Нирджала-пост (сухое голодание)**: автор постился «без воды» в жару, Бäbä заставил выпить лимонный сок («я тоже пощусь, но пью лимонную воду») → позже Бäbä сам ввёл dry-fasting как обязательный (для тех, кто может по медицине). Урок: практика адаптируется под тело; позже — устав.
- **«Кто ачарья?»**: Бäbä — «Я единственный ачарья; остальные — Мои медиумы». Убирает привязанность ученика к личному учителю и эго ачарьи.
- **Капалика-дикша (06.01.1964)**: Бäbä в образе Шивы; три кандидата; «не боишься ли темноты кладбища?» → oath → первая ночная садхана в Death Valley (Jamalpur), 7 дней обязательной практики (сокращено до 3 по разрешению Бäbä при переводе).
- **Avidya Tantrika (Shimoga)**: автор-капалика на кладбище; «враждебный» тёмный тантрик с khappar/тришулом → узнав «сына Анандамурти, Тантра-Гуру» → поклонился: «Он и мой Гуру»; Бäbä потом подтвердил: «Я ходил ругать его; велел помогать vidya-tantrika».
- **Защита при капалике (дождь/град)**: страх → садхана продолжена → «выслал дополнительную защиту» (сиддха-садхака в образе большой собаки).
- **Языки**: Ramchandra (9 языков) — Бäbä ответил на нескольких языках и разбил эго; немецкий профессор-«авторитет» — Бäbä указал ошибку по номеру артикля/страницы в грамматике, лежащей в National Library Calcutta → профессор проверил и смирился; «знания приходят по милости через садхану».
- **Гуру-падпуджа**: желание омыть стопы Гуру — исполнено (дождь, «принеси воды и вымой мои ноги»); семейная пара получила разрешение на ritual-падпуджу.
- **Керала (AMURT flood relief)**: паводок в Trichur → сбор средств märgiis, раздача (5 мешков риса, пульс, масло, свечи) → за 15 дней «Ананда Марга стала популярной» через служение → рост школы.
- **Trivandrum DMC (1968)**: не хватало ресурсов → молитва → всё устроилось; 200 märgiis, 18 wholetimers вернулись в поле с оплатой обратной дороги; требование Бäbä: DS должен сначала открыть школу → школа открыта → DMC состоялся.
- **Атака коммунистов на школу**: группа ~100 человек → учитель вызвал уважаемого местного лидера → «проверьте сами: три года мы живём здесь без единого упрёка» → конфликт снят, школа выросла.
- **Покупка земли**: telegramm Бäbä «купите землю для школы» → казус с «королём кешью» Ravindran Nair (85 000 рупий ⚠) → земля куплена.
- **Рukmini Amma**: желание кормить Бäbä с рук (для женщин запрещено оставаться наедине) → Бäbä зашёл через кухню: «Мать, я голоден, покорми меня» → исполнено.
- **«Sweet & Salty Water»**: забытая вода/плед → Бäbä пил кокосовую воду и сидел на талии-поясе автора → «ошибка человека оказалась благом».
- **Madurai (девочка без речи)**: Бäbä коснулся Vishuddha cakra → девочка заговорила («Рама») → позже стала отличницей.
- **Ramchandra Sethji («казначей»)**: бизнесмен, 1000 рупий/мес ⚠, «я казначей Бабы»; «контракт с Бäbä»: сколько тратит на организацию, столько возвращается за 48 часов (чек 120 000 ⚠); чудесное исцеление бедра после 75 лет.
- **«Baba сошёл с ума»**: автор раздражался от множества программ → Бäbä: «Да, Я сошёл с ума ради Vishva Kalyan; если и ты сойдёшь с ума так же — дело пойдёт. Выбирай программу по вкусу» → снятие напряжения.
- **Семейные обязанности**: автор винил себя за уход из семьи (старший из 16 детей) → через 8 лет младший брат рассказал, что всё устроилось → Бäbä: «Смотри, твои обязанности выполнены; кто разделил Мою работу, у того Я возьму его обязанности».

## Key Concepts

- **Khappar** — полчерепа (атрибут авидya-тантрика).
- **Vidya Tantrika / Avidya Tantrika** — саттвический / тамасический практик; Avidya-тантрик поклонился vidya-тантрику (сыну Тантра-Гуру).
- **Vishuddha cakra** — горловое сплетение (место лечения/заговора речи).
- **Shashtra / Pramana** — (см. глоссарий).
- **AMURT / ERAWS** — организации служения (здесь — flood relief, школы).

## Mental Models

- «Принимай человека как есть; привычки уходят через садхану, а не через требования».
- «Проверка (очки, зоркость) — способ научить, а не унизить».
- «Дикша капалики = готовность к страху и темноте; Тантра-Гуру защищает в пути».
- «Служение (рельеф, школа) — лучшая "реклама" идеологии».
- «У Гуру нет "личных слабостей", есть педагогические сценарии».

## Anti-patterns

- **Отказ людям «с пороками»**: противозачаточный подход «сначала исправься» — теряет людей; правильнее «добавить прекрасное».
- **Чувство вины из-за ухода в санньясу**: бесполезно; обязанности выполнены «по плану».
- **Привязанность к личному ачарье** — растворяется через «Я единственный ачарья».
- **Ожидание «идеальных условий» для старта школы/DMC** — начинай с малым, остальное устроится.

## Worked Example

Капалика-сага: дикша (06.01.1964) → первая ночь в Death Valley (страх, «кто-то с мечом») → перевод в Karnataka (3 ночи + остальное в поле) → Shimoga: встреча с Avidya Tantrika на кладбище → конфликт → поклон после «сын Тантра-Гуру» → Бäbä подтверждает: «Я ходил его ругать». Цикл: инициация → страх → защита → разрешение конфликта → подтверждение Гуру.

## Key Takeaways

1. Инициация возможна для «грешников» — не требуй исправления до старта.
2. Капалика — практика преодоления страха; Гуру защищает и вмешивается.
3. Служение и школы — главный инструмент роста и доверия.
4. «Зоркость» и «беспомощность» Гуру — педагогические инструменты.
5. Садхана/дисциплина адаптируются под тело, затем устаканиваются в правилах.
6. Доверие: кто работает для Гуру — у того Гуру берёт заботы.
