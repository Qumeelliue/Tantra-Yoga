# Глава 1: Первая встреча, инициация и личный контакт

## Core Idea

Начало пути автора: неожиданная встреча с Бäbä на вокзальной платформе (~1958–59), дикша 22.02.1962 через ачарью Вишвамохана, первый Personal Contact (14.04.1962) и недельный Tattvika class в Jamalpur — как запускается духовная жизнь по модели Ананда Марги.

## Frameworks Introduced

- **«Желание увидеть Paramapurusa ломает все правила»**: автор не был märgii и не мог войти на DMC (вход только для членов), поэтому «встретил» Бäbä на перроне, куда уехал поезд — и Бäbä коснулся его щёк через окно. Урок: искреннее сильное стремление открывает путь даже вне формальных рамок.
- **Дикша через посредника (ачарью)**: год общения с Ac. Brahmadeoji (регулярный Sunday-визитёр с журналами) → знакомство с Ac. Vishvamohanji (инженер-ачарья, «знал, что у меня гость») → дикша 22.02.1962 в 14:00. Правило: интерес → регулярные контакты → ачарья как «медиум Гуру».
- **PC (Personal Contact)**: патерн «видение → прошлое → признание → наказание-благодать → обещание». Автор увидел Шиву на кровати вместо Бäbä; затем Бäbä показал «экраном на стене» прошлые жизни (рождение по милости Шивы, защита змеёй, Ом Намах Шивая в лесу); строгий взгляд и лёгкий удар палочкой; «Ты знаешь, я вижу всё»; обещание быть дхармиком; поглаживание щёк и слёзы.
- **Tattvika class + экзамен с «grace mark»**: недельный класс (Jamalpur, 14–21.04.1962), экзамен по философии; непонимание вопросов → «Этот тупой мальчик. Сядь!» → во втором раунде вопрос о Yama/Niyama → «хорошие мальчики, ставлю grace mark — все прошли». Урок: экзамен проверяет базовые принципы и намерение, а не эрудицию.

## Key Concepts

- **Yama / Niyama** — 5 принципов самоконтроля / 5 принципов отношения к другим и внешнему миру; фундамент кодекса.
- **Tattvika** — мирянин, сведущий в философии Ананда Марги.
- **DMC (Dharma Maha Cakra)** — духовная конгрегация; вход для märgiis (в те годы).
- **Первое PC-наказание** — «ударил легко, будто избивал»; метафора: наказание — для формирования характера, а не для мести.
- **Сахадж-йога** — базовая медитация (урок 1–2), практикуется ежедневно в лесу с ачарьей.

## Mental Models

- «Думай о первой встрече как о "посеве": прикосновение к щекам через окно поезда = запуск пути».
- «Правило: вход на конгрегацию — для своих; но искреннее стремление пробивает стены».
- «PC — это не приём, а зеркало: ты видишь себя глазами Гуру (прошлое, ошибки, потенциал)».

## Anti-patterns

- **Скрытность/нечестность в признании**: «не хотел признавать проступки» → Гуру напоминает; честность ускоряет путь.
- **Страх перед наказанием**: наказание здесь — «космическая благодать», а не угроза.
- **Пренебрежение к ачарье**: «Кто ачарья?» — позже (Ch 5) объясняется, что привязанность к личному учителю нужно трансформировать в преданность Гуру.

## Worked Example

Путь до PC: (1) отказ входа на DMC → (2) план «встретить на перроне» → (3) касание щёк → (4) годы: журналы от Brahmadeoji → (5) знакомство с Vishvamohanji → (6) регулярные встречи, дикша 22.02.1962 → (7) PC 14.04.1962 → (8) Tattvika class → (9) wholetimer-путь позже. Иллюстрация всей лестницы кадров Ананда Марги.

## Key Takeaways

1. Искреннее стремление важнее формального статуса — оно открывает путь.
2. Дикша даётся через ачарью-«медиум»; регулярность контактов решает.
3. PC = скан прошлого + наказание-благодать + обещание; ключ — честность.
4. Экзамен в Tattvika class: проверяет Yama/Niyama и намерение, а не зубрёжку.
5. «Grace mark» — модель щадящей оценки для начинающих, которая не обесценивает экзамен.
