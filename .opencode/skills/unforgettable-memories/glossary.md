# Глоссарий — Unforgettable Memories

**Авадхута (avadhüta)** — санньяси, практикующий капалика-садхану; в книге: Бäbä обещал создать 30 авадхутов, автор — 26-й (30.05.1964). ⚠ Числа (Ch 3, 5).

**Авадхута Гуфа (Avadhuta Gufa)** — пещера в Gangotri для интенсивной 3-дневной садханы; вода из Ганга достаётся верёвкой (Ch 4).

**Авидя-тантрик (Avidya Tantrika)** — тамасический практик; встреченный автором на кладбище в Shimoga поклонился «сыну Тантра-Гуру» и был подчинён vidya-тантрике (Ch 5).

**AMURT / ERAWS** — службы Ананда Марги (рельеф/образование); в книге — flood relief в Керале, школы (Ch 5).

**Ачарья (äcärya)** — духовный учитель; «Я единственный ачарья, остальные — Мои медиумы» (Бäbä) (Ch 5).

**Bhagavati / Гуру-падпуджа** — поклонение стопам Гуру (омовение стоп) как акт преданности (Ch 5).

**Darshana (darshan)** — коллективная аудиенция Гуру (Ch 1).

**Death Valley** — место ночной капалика-садханы в Jamalpur (Ch 5).

**Dharma Maha Cakra (DMC)** — духовная конгрегация с Бäbä; вход в ранние годы только для märgiis (Ch 1, 5).

**Dharma-samiksa** — «скан» ученика Гуру (часто через ачарью-медиума), выявление нарушений, коррекционное наказание и руководство (Ch 6).

**Дикша (diksa)** — инициация в медитацию; автор — 22.02.1962 через ачарью Vishvamohan (Ch 1).

**Dukh Haran** — жезл Гуру «снимающий страдания»; после «порки» лихорадка ачарьи прошла (Ch 5, 6).

**Emergency (1975–77)** — National Emergency Индиры Ганди: запрет Ананда Марги, массовые аресты; автор работал подпольно (Ch 3).

**Guru mantra** — мантра, обращённая к Гуру (используется в экстренных ситуациях) (Ch 2, 6).

**Ista mantra** — личная мантра ученика (тайна дикши); повторяется при медитации (Ch 2, 6).

**Kaoshikii / Tandava** — упражнения (упоминаются как часть распорядка ашрамов) (Ch 4).

**Капалика-дикша (kapalika diksa)** — тантрическая инициация для избранных (ночь, кладбище/лес); автор — 06.01.1964 (Ch 5).

**Kiirtan** — коллективное воспевание мантры; «Baba Nam Kevalam» слышится в космосе при совпадении частоты ума (Ch 6).

**Nirjala fast** — сухое голодание (без воды); Бäbä сначала отговорил, позже ввёл как обязательное (Ch 5).

**PC (Personal Contact)** — личная встреча с Гуру; «скан» прошлого, наказание-благодать, обещание (Ch 1).

**Pracar** — пропаганда философии (Ch 2).

**Sadripu / Astapasha** — 6 врагов (kama, krodha, lobha, moha, mad, matsarya) и 8 узлов (kula, mana, shila, irsa, ghrna, lajja, bhaya, yugupsa) ума — контроль в SPT (Ch 6).

**Sahaj Yoga** — базовая медитация (1-й/2-й уроки) (Ch 1).

**Samskara** — реактивный момент прошлых действий; в книге — «подавленные самскары» (sutra/shikha, курение) удаляются Гуру (Ch 6).

**Shastrarth** — философский диспут старших санньяси (Rishikesh) (Ch 4).

**Saincara / Pratisaincara** — эволюция к Сознанию и возвращение к Нему (притча о поезде) (Ch 2).

**SPT (Sadhan Pith Training)** — аскетическая тренировка wholetimers: подаяние, одна еда, контроль чувств (Ch 6).

**Sutra / Shikha** — священный шнур / пучок волос (догматические атрибуты касты) — сняты автором (Ch 6).

**Tattvika class** — недельный класс по философии в Jamalpur (апрель 1962); экзамен с «grace mark» (Ch 1).

**Tantra Abhicara (Abhisheka)** — ритуал передачи shakti авадхутам (Ch 6).

**Vaidya Raj** — «Царь врачей» (Бäbä); лечение коклюша касанием Vishuddha cakra (Ch 2).

**Vishva Kalyan** — всеобщее благо; «Я сошёл с ума ради Vishva Kalyan» (Ch 5).

**Vrittis** — ментальные пропенситы; «пока есть тело, будут vrittis — не волнуйся» (Ch 2).

**Wholetimer** — полный занятостный работник (Ch 3).

**Yama / Niyama** — 5 принципов самоконтроля / 5 принципов отношения к другим (Ch 1).
