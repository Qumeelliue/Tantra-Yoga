# Читшит — правила решений (Ananda Marga Philosophy Part 5)

## Взгляд и цель

| Ситуация | Правило |
|---|---|
| Оценить целостность анализа | Интегральный взгляд: «нет ничего кроме Paramártha»; один источник за разнообразием |
| Выбрать цель | Shreya (вечное) vs preya (временное): анализируй до принятия |
| Любовь к конечному / бесконечному | káma (притяжение конечного) / prema (любовь к Бесконечному) |
| Путь к Верховному | shravana → manana → nididhyásana |

## Самадхи и знание

| Ситуация | Правило |
|---|---|
| Различить самадхи | По saḿkalpa/vikalpa: оба → обычное; vikalpa стоп → samprajiṋáta; saḿkalpa номинален → savikalpa; оба стоп → nirvikalpa |
| Приобрести abhedajiṋána | Abhidhyána: Iishvara prańidhána + anudhyána + милость |
| Внешние обряды как средство | Не дают знания (рыбы купаются в Ганге) |
| Фатализм «так суждено» | Отвергни (prapatti márga): исследуй механику |
| Истинный знак | Универсально + рационально + психологично |

## Бхакти-стадии

| Ситуация | Правило |
|---|---|
| «Хочу вкушать» | Rágánugá: остаться у цели, блаженство близости |
| «Хочу радовать» | Rágátmiká: служение, путь слияния |
| Одна мысль «только Он» | Bháva samádhi (нижние чакры, дрожь) |
| Облако дхармы у сердца | Dharmamegha samádhi (падение на землю) |
| Мотивация удовольствия | Малый «я» (мирское) → большой «Я» (духовное) |

## Психическое здоровье

| Ситуация | Правило |
|---|---|
| Повторный образ из страха | Phobia |
| Повторный образ из слабости | Mania |
| «Меня никто не любит» | Melancholia |
| Раздутое эго | Superiority complex |
| Сужение ума | Inferiority complex |
| Профилактика | Баланс ума: Iishvara prańidhána / dhyána |

## Память и обучение

| Ситуация | Правило |
|---|---|
| Запомнить сложное | Читай вслух (глаза+уши), субдели (ass-ass-i-nation) |
| Сделать знание устойчивым | Ритм, ассонанс, метры; dhruvásmrti |
| Почему не помню | Недостаток внимания при получении; пустой ум = сильная память |

## Свобода и общество

| Ситуация | Правило |
|---|---|
| Порядок свобод | Интеллект → социально-экономическая → психо-экономическая → духовная |
| «Сытая клетка» | Социально-экономическая свобода без интеллектуальной — клетка |
| Два фронта борьбы | Кровососы (экономика) + интеллектуальные сатаны (идеология) |
| Догма «любовь без страха» | Ложь: страх и любовь совместимы, любовь страха не требует |
| Несправедливость | Не терпи: карбункул на теле общества |
| Yatamána — усилие | Только с санкцией ума И Атмана, на всеобщее благо |

## Быстрые сигналы («tells»)

- «Бог чёрный/белый», «300 млн богов» → не-интегральный взгляд, «религиозный торговец».
- «Раздал еду, а бог не явился» → заслуги-ментальность, не-интегрально.
- Слышишь «без страха не полюбишь Бога» → догма эксплуатации.
- «Мы — любимые дети Бога, остальные прокляты» → философия без санкции Атмана.
- Видишь трясущего головой, вспоминающего имя → попытка «встряхнуть мозг» до вибрации.
- Кто-то сжимается «мне и на полу хорошо» → паралич интеллекта, кастовая догма.
- «Не может без Его воли двинуться травинка, поэтому сидим» → фатализм, анти-джаяна.
