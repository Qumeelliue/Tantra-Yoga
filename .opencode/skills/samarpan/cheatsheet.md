## Ключевые люди

- **Бáбá (Anandamurti)** — гуру; лично строил кадры, демонстрации, наказания.
- **Vishokananda** — двоюродный брат автора, ачарья, PA Бáбá; ушёл с Uma Sarkar.
- **Keshavananda** — acting GS при аресте Бáбá (из другой книги; здесь упоминается).
- **Prakash Singh Badal** — сокамерник, сикхский лидер, помогал.
- **Sarveshvarananda / Sarvatmananda** — GS разных лет.
- **Vijayananda** — «ведущий интеллектуал», писец Бáбá, убит позже (сердце).
- **Shraddhananda** — первый Purodha Pramukha после ухода.
- **Asiimänanda** — ачарья-агроном (лишён сана; убит 02.04.1990).

## Быстрые правила

| Ситуация | Правило |
|---|---|
| Новичок у гуру | Послушание + обучение; «не выпрашивай PC» |
| Правило в организации | Рождается из инцидента, у всех есть история |
| Кризис/арест лидера | Работает заранее построенная цепочка командования |
| Отчётность | RDS — «благословение», а не бюрократия |
| Дисциплина | 16 Points до кризиса; «природа накажет строже» |
| Наказание от гуру | «Исчерпание самскар», не произвол; объяснялось |
| Выбор штаб-квартиры | (1) много марги, (2) малый город, (3) открытое пространство |
| Желание не исполнилось | «Отсрочка = подготовка»; продолжай работать |
| Раскол после лидера | Принцип mahagurunipat (стабильность до 10 лет) нарушать нельзя |
| Служение в споре групп | Работай на институт, не на фракцию |
