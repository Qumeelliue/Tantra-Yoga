# Глоссарий — Tattva Kaomudii Part 2

**А́варани́ шакти (ávarańii shakti)** — покрывающая сила авидьи: объект «накрывается», точное знание недоступно (Ch2).

**Аниндьянанда раса самадхи** — «всё сладко»; блаженство от потока pineal-гормона по плекcусам; даётся милостью Гуру (Ch3).

**Апта ва́кья (ápta vákya)** — абсолютное знание, прямое послание от Космического Ума; истинно всегда (Ch12).

**Артха / Парамартха** — временное / постоянное прекращение страданий (Ch10).

**Ахам / махат / читта** — три функциональные камеры ума (Ch9).

**Ва́да / джалпа / витанда** — три фазы логического спора: найти слабость → контраргумент → разгром (Ch12).

**Ваэдики / та́нтрики дикша** — ведическое «очищение» / настоящая тантрическая инициация (Ch2).

**Видехалина** — промежуточное состояние после смерти до нового воплощения (Ch5).

**Ви́кше́пи шакти** — раскидывающая сила авидьи: ум дрейфует к грубому (Ch2).

**Вишвама́йя** — все Майи, кроме Анумайи (Ch2).

**Гопи-бхава / вражда-бхава** — «пребывание рядом» с Брахмой без слияния (Ch11).

**Гун̇аянтрака (guńayantraka)** — треугольник сил (саттва/раджас/тамас), первая причина (Ch9).

**Дарпаха́ри / Маначора** — «похититель тщеславия» / «похититель ума» — эпитеты Пуруши (Ch5).

**Джатисмара (játismara)** — помнящий прошлые жизни (Ch13).

**Доминион-статус** — ограниченный контроль ума над телом (Ch1).

**Ишвара пранидхана** — направление всей психической энергии к Ишваре (см. TK3 ch3).

**Ка́мамая / маномая / атиманас / виджинанамая / хиранмая** — пять кош ума (Ch9).

**Карма / крийа** — действие с идеацией / без идеации (Ch6).

**Ка́ран́а мана** — причинный ум; «долгий сон причинного ума — смерть» (Ch13).

**Каункалама́лини самадхи** — отождествление с Парама Пракрти (легенда Сада́шива/Ка́ли) (Ch4).

**Кшара / акшара** — преходящее / неподверженное метаморфозу (Ch2).

**Майя (шесть форм)** — Махамайя, Вишнумайя, Анумайя, Йогамайя, Авидьямайя, Видьямайя (Ch2).

**Мадхувидья (madhuvidyá)** — отношение к миру как к мёду при правильной идеации (Ch1, Ch3).

**Мадхьямачара** — срединный путь садханы с фиксированной целью; принят Ананда Маргой (Ch2, Ch11).

**Нитья / наэмиттик крийа** — сущностные / случайные-целевые действия (Ch6).

**Ота-йога / прота-йога** — индивидуальная / всеобщая связь макрокосма (Ch7).

**Пара́ / апара́ джинана** — абсолютное / относительное знание (Ch9).

**Парамра́са / свараса** — универсальный / индивидуальный ритм (Ch14).

**Пра́джина** — единичное сознание под влиянием статичной силы (Ch2).

**Прана-дхарма** — внутренняя дисциплина психической сферы личности/нации (Ch8).

**Прапта ва́кья** — относительное знание из внешнего мира (Ch12).

**Ра́га́тмика / ра́га́нуга́ бхакти** — любовь, где главное дать радость / главное получить (Ch11, TK3 ch6).

**Самстха / хамса** — неживые / живые сущности космического цикла (Ch9).

**Са́ру́пья самадхи** — стадия савикальпы, блаженство через танматры (Ch1).

**Та́рака Брахма** — тантрический концепт-мост между Сагун̇а и Ниргун̇а (Ch3, Ch9).

**Танматрика самадхи** — контроль объектов как собраний танматр; точка между мирами (Ch5).

**Универсальный гуманизм** — критерий терпимости относительного знания (Ch12).

**Юкти (yukti)** — разум как согласованность ва́да/джалпа/витанда (Ch12).
