# Chapter 7: Food, Cells, Physical and Mental Development

*Дискурс 14 февраля 1970, Ranchi.*

## Core Idea

Тело — собрание клеток с индивидуальными умами; человеческий ум — коллективный ум. Пища определяет тип клеток, клетки — состояние ума. Поэтому диета — часть духовной практики.

## Frameworks Introduced

- **Клетки и их умы**: тело из протозойных и метазойных клеток; каждая клетка — живое существо с умом, душой, сан̇ска́рами; человеческий ум = единичный микрокосм + собрание клеточных умов (коллективный ум). Умы метазойных клеток развитее протозойных.
- **Связь ума и тела**: единичный ум связан с клетками индивидуально и коллективно (аналог ота-йоги и прота-йоги Макрокосма).
- **Жизненный цикл клеток**: клетка живёт ~21 день ⚠ к калибровке, затем заменяется; «грязь» при растирании кожи — сотни мёртвых клеток. Длительно больным врачи советуют минимум 21 день покоя для роста здоровых клеток ⚠.
- **Пища → клетки → ум**: тамасичная (static) пища → статичные клетки → статичное влияние на ум; саттвичная → саттвичные клетки → любовь к практике, равновесие. Выбор пищи — по времени-месту-личности.
- **Три типа пищи**: **саттвичная** (sentient: рис, пшеница, ячмень, бобовые, фрукты, молоко и молочные продукты) — благо телу и уму; **раджасичная** (mutative: хороша для тела, нейтральна для ума) — не вредна уму; **тамасичная** (static: лук, чеснок, вино, несвежая/гнилая еда, мясо крупных животных, рыба, яйца) — вредит уму.
- **Аура**: сияние тела = коллективное сияние клеток; гнев (кровь к лицу, массовая гибель клеток) и жестокость читаются по лицу; саттвичные клетки + практика → аура (отсюда «радиация» махапуруш).
- **«Áhárashuddhao sattvashuddhih»** — чистая пища → чистота ума.

## Key Concepts

- **Протозойные / метазойные клетки** — элементарные / многоклеточные организмы-клетки.
- **Ота-йога / прота-йога** — индивидуальная/всеобщая связь (макрокосмический аналог клеточной связи).
- **Саттвичная / раджасичная / тамасичная пища** — три категории по действию на клетки и ум.

## Mental Models

- «Ум — это коллектив: думай об изменениях на клеточном уровне как о голосовании клеточных умов».
- «Еда — это строительный материал сознания: что ты ешь, тем становятся твои клетки и ум».
- «Аура — сигнал: светится тот, чьи клетки саттвичны и спокойны».

## Anti-patterns

- **Пренебрежение диетой**: «просто буду делать садхану и есть что попало» — не работает.
- **Есть без знания свойств**: молоко только отелившейся коровы, белые баклажаны, кхесари, горчичные листья, красный пуи — часто из гнилой почвы ⚠ список сомнительный, проверить.
- **Гнев** — массовое убийство клеток лица и тускнение ауры.

## Worked Example

*Авторский тезис о стыке.* Садхак ест статичную пищу → вырастают статичные клетки → ум получает статичное влияние → практика труднее. Садхак ест саттвичную пищу → саттвичные клетки → любовь к садхане и равновесие → аура. Вывод: диету выбирают сознательно, по свойствам, а не по привычке.

## Key Takeaways

1. Человеческий ум — коллектив клеточных умов; тело — не отдельный «носитель».
2. Клетки обновляются ~21 день ⚠; покой важен для регенерации.
3. Пища делится на саттвичную/раджасичную/тамасичную; тамас вредит уму.
4. Пища → клетки → ум: диета — духовный инструмент.
5. Аура и лицо — маркеры клеточного состояния.
