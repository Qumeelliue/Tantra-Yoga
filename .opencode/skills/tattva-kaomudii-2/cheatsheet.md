# Читшит — Tattva Kaomudii Part 2

## Майя и садхана

| Ситуация | Правило |
|---|---|
| Назвать форму Майи | По направлению: наружу/вниз (маха/авидья), вверх (йога/видья), внутрь (анумайя), красота (вишнумайя) |
| Авидья ослепляет | Двумя путями: раскидыванием (викшепи) и покрыванием (аварани) |
| Борьба с Майей | Фиксируй цель перед боем (мадхьямачара); лесть (дакшиначара) — «домин-статус»; слепой бой (вамачара) — деградация |
| Настоящая дикша | Тантрики (с diipanii, mantra caitanya, abhiśeka); ваэдики — только очищение |
| Преодоление Майи | Милость через идеацию на Пурушоттаму (не на кшару-мир) |

## Самадхи и тело

| Ситуация | Правило |
|---|---|
| Инференциальное vs неинференциальное блаженство | Через танматры / напрямую из Космического Ума |
| Контроль тела | «Доминион-статус» ума; прямой контроль — только у Макрокосма |
| «Всё сладко» | Аниндьянанда раса: pineal-гормон через гипофиз вниз; даётся милостью Гуру |
| Танматрика | Мир = вибрации; контроль объектов = контроль вибраций; точка между мирами |
| Пракртилина | Концентрация на грубом = негативная танматрика-самадхи |
| Самадхи обязательно? | Нет: пассажир доезжает и без вида городов |

## Карма и пища

| Ситуация | Правило |
|---|---|
| Карма или крийа? | С идеацией — карма (освобождение); без — крийа (оковы) |
| Нитья vs наэмиттик | Сущностное (еда/омовение/садхана) vs случайное-целевое (работа/праздники) |
| Выбор пищи | Саттвика → саттвичные клетки → ум; тамасика вредит уму |
| Диета и практика | «Áhárashuddhao sattvashuddhih» — чистая пища → чистота ума |

## Общество и знание

| Ситуация | Правило |
|---|---|
| Единство общества | Общая идеология + бескастовость + коллективные функции + без казни |
| Наказание | Временное отстранение + коррекция (10 человек ⚠); порядок: убедить→приказать→предупредить→меры |
| Достоверность знания | Источники прапты (восприятие/инференция/авторитет) ненадёжны; апта — прямое знание |
| Терпимость относительного знания | Пока служит универсальному гуманизму; делит людей — отвергай |
| Спор | Найди слабость (вада) → контраргумент (джалпа) → разгром (витанда); ложная посылка ломает вывод |

## Память и ритм

| Ситуация | Правило |
|---|---|
| Постоянная память | В читте, не в мозге; мозг — «библиотекарь» |
| Память прошлых жизней | Экстрацеребральная, у детей ~5 лет ⚠; джатисмара до ~12 ⚠ |
| Копание в прошлых грехах | Вредно для практики; забвение — милость |
| Различия людей/объектов | Различия ритмов; разнообразие — закон природы |
| Садхана как слияние | Свараса сливается с парамра́сой через инкантативный ритм |

## Быстрые сигналы («tells»)

- «Сначала послушайся, потом предлагай поправки» — рациональность следует за послушанием (Ch10).
- Человек «знает, но не добрался и не постучал» — есть джинана, нет кармы/бхакти (Ch11).
- «Только наша вера правильная» — относительное знание, делящее людей (Ch12).
- Накопление ради накопления — источник несправедливости, а не достатка (Ch10).
- «Я есмь грешник прошлой жизни» — самосаботаж садханы (Ch13).
