# Читшит — правила решений по Саркару (Mahabharata)

## Контент и история

| Ситуация | Правило |
|---|---|
| Оценить текст/историю | itihása-фильтр: даёт ли плоды caturvarga + нормы niiti? Нет → просто хроника (itikathá) |
| Классифицировать произведение | kávya (вымысел) → puráńa (миф с пользой) → itikathá (факты) → itihása (воспитание) |
| Оценить поступок героя прошлого | По социальному dharma его эпохи, не по искусственному dharma сегодняшнего |

## Власть и лидеры

| Ситуация | Правило |
|---|---|
| Кому доверять власть | Sadvipra: духовность + любовь к человечеству + бескорыстие; эгоистам — никогда |
| Оценить «сильного человека» | По kot́i-шкале и по «вибрации» для общества, не по харизме |
| Просить больше ресурсов | Сначала полностью исчерпай данные (правило исчерпанной силы) |
| Против превосходящего противника | Слаб — отступи/прими (Дварака); силён — атакуй и добей (Джарасандха) |
| Прощать | Невинного — да (охотник Джара); неисправимого — нет (Джарасандха); безнравственных своих — не защищать (Ядавы) |

## Мораль

| Ситуация | Правило |
|---|---|
| Конфликт верности и правоты | Духовная мораль побеждает простую; но простую уважай (Кришна кланялся Бхишме) |
| Друг ведёт себя плохо | Хотя бы пытайся изменить его (Бхишма); не изменяющий — соучастник (Карна) |
| Держать ли обещание | Да — социальный капитал эпохи; «сегодняшняя героизация нарушений» — упадок |
| Оценить верность | Статична (простая) или динамична/бьющая (духовная)? Последняя — сильнее |

## Общество и образование

| Ситуация | Правило |
|---|---|
| Финансировать школу/институт | Общественное финансирование (catuspathii) переживает власть; государственное одиночное (vihara) умирает со спонсором |
| Строить систему норм | Не исключай региональные практики (ошибка Manu) — иначе дефект |
| Судить норму | Динамика: «что плохо сегодня — завтра может быть нормой» |
| Оценивать социальные практики | Полиандрия/полигамия при дисбалансе полов — оправданы (пост-военная Германия) |

## Учение и наставничество

| Ситуация | Правило |
|---|---|
| Менторство | Равная любовь ко всем ученикам; пристрастность (Дрона) — проступок со смертельной ценой |
| Просить у Высшего | Только неатрибутивную преданность, не мирские дары (Джаядратха) |
| Путь садханы | Самоотдача (Vidya tantra) сильнее управления железами (hatha, avidya tantra) |

## Быстрые сигналы («tells»)

- Текст «перечисляет даты и события» без вывода — itikathá, не itihása.
- Лидер просит больше ресурсов, не использовав данные — нарушение правила исчерпанной силы.
- Учитель имеет любимчика и «пишет секреты сыну» — предупреждающий знак (Дрона).
- Школа финансируется одним спонсором/государством и только им — высокая хрупкость (vihara).
- Утверждение «это изобрёл Запад» без проверки индийских аналогов — вероятная ошибка приоритета.
- «Эго вокруг Бога» (puśt́imárgii ahaḿkára) — близость к цели, но риск дискриминации; следи за равным притяжением.
