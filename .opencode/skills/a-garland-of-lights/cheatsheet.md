# Читшит — A Garland of Lights (быстрые справки)

## Лидерство и организация

| Ситуация | Правило |
|---|---|
| Отказ/невозможность (виза) | Держись обещания гуру («слово»); ищи легальную зонтичную оболочку; подключи личные связи |
| Неструктурированная территория | Жёсткий дедлайн («100% за 24ч») → декомпозиция на регионы/диоцезы → прими «начало» |
| Смежные отделы врозь | Трио-офис (Prout+VSS+SDM) в каждом диоцезе |
| Проверить команду | Строгость/«гнев» как тест-лила; наблюдай реакцию; раскрой игру |
| Уставшая команда | Лидер сам приходит, снижает нагрузку, даёт заботу |
| Смена руководства | Прими как естественный поворот; новый SS продолжает |

## Обучение

| Ситуация | Правило |
|---|---|
| Сложная тема для новичков | Учи через объект (камень, баниян, цветок) + мимика/жесты + проверка вопросом |
| Иноязычная аудитория | Даршан без перевода не проводится; «записывай и переводи» — иначе учения теряются |
| Личная трансформация | PC: поклон → имя → благословение → вопрос о служении → задача-ориентир |
| «Исправить» близкого человека | Мягкое символическое наказание с передачей намерения (жена Моти) |
| Понять смысл событий | Рамка «причины и следствия»: нет случайностей, корни могут быть в прошлом/другом мире |

## Мировоззрение

| Ситуация | Правило |
|---|---|
| Что такое мистика | «Поиск связи конечного и бесконечного» |
| Moksa vs liberation | Moksa = спасение (salvation); liberation = освобождение — разные слова |
| Парама Пуруша | Не может создать другого Парама Пурушу и не может ненавидеть |
| Тантра и Китай | dhyana→chan→son/zen; tantra→tao/dao; Cinacar (dharana) vs Divyacar (dhyana) |
| Будущее нации | Светлое, если сохранить культурное наследие и не скатиться в материализм |
| Завершение роли/жизни | «Уходи с улыбкой»: оставь пользу людям, пусть они скорбят, а ты спокоен |

## Практики ученика

| Ситуация | Правило |
|---|---|
| Как попасть на field walk | Получить PC, записаться; «камикадзе»-команда догоняла на такси |
| Прогулка с гуру | Слушай всю лекцию, не половину; не «трогай» без разрешения; запоминай, потом записывай |
| Сон для работников | Пиши мантру пальцем «на подушку» (невидимый отпечаток) — сладкие сны |
| Уважение к форме | Гирлянда: важна любовь, а не материал; поклон — sastaunga pranam |
| Не пропусти шанс | PC один раз в жизни (по преданию); пропуск из скромности — сожаление на годы |

## Быстрые сигналы («tells»)

- Гуру «сердится» на близких работников сильнее всех — это часто очищение/тест, не отвержение.
- Лучшие учения утеряны, если их не записать сразу (ответ о переводе санскрита).
- Дом, где был Баба (Гаосюн), «светился» и стал местом силы и детсадом.
- Тайфун ушёл за час до посадки — «условия складываются», если держишь обещание.
- Причина и следствие: «почему ты встретил гуру» — вопрос для размышления, не совпадение.
