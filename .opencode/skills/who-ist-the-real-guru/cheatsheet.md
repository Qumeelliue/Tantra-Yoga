# Cheatsheet

Быстрые правила решений и справки из «Who Is the Real Guru?».

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Кто может быть гуру? | Только Махакаола, рассеивающий тьму во всех трёх пластах (физическом, психическом, духовном). |
| Как проверить гуру? | Духовное знание+практика+шастры+языки; способность учить; ниграха-ануграха (наказание+милость). |
| «Мне не хватает милости» | Убери зонтик тщеславия; притяни силой любви; делай Его волю. Не выпрашивай. |
| Повторяю мантру — не действует | Нужны дипани + мантра-сати + подъём кундалини (пурашчарана). |
| Идолопоклонство как садхана | Низший уровень Тантры; идеация на Брахму лучшая, дхьяна — вторая. |
| Чувствую тягу к «пяти М» | Панча-макара эзотерически — алхимия ума; грубый вариант — для превосхождения, не потакания. |
| Когда придёт Таарака? | Избыток греха, добрым тяжело; 4 критерия: рождённый гуру, миссия, эра, садхана-пример. |
| Садвипра или Махасадвипра? | Садвипра ведёт при изменениях; Махасадвипра инициирует эпоху (Таарака). |
| Вера в аватары-спуски | Нелогично: вся вселенная — инкарнация; возвышение — эволюция + садхана. |
| Получил силы/всезнание желание | Цель садханы — удовлетворить Парама Гуру, а не всезнание; силы — побочные дары. |
| Микро-виты вокруг | Позитивные испускает только Садгуру (мудры); негативные действуют через природу — избегай рсти. |
| Утром после сна | Сразу гуру-шакаш (дхьяна на гуру в гуру-чакре), до всех дел. |
| Оценить состояние преданности | Стадии: сâлокья → сâмипья → сâюджья → саршти → каевалья. |
| Сон мешает практике | 20 из 60 лет — сон ⚠; джапа/дхьяна во сне = аджапа-джапа/дхрувасмрити. |
| Женщины и спасение | Равны: железы (шишковидная, гипофиз) одинаковы; «не имеют права» — ошибка. |
| В каком направлении медитировать | Все направления — самбхути; нет «особого» направления. |

## Ключевые санскритские формулы

| Формула | Смысл |
|---|---|
| `Brahmaeva Gurureka näparah` | «Только Брахма — Гуру, никто иной». |
| `Gurukrpa hi kevalam` | «Только милость гуру» — всё и вся. |
| `Nigrahānugrahe shaktah` | «Гуру владеет наказанием и милостью». |
| `Yadā yadā hi dharmasya glānirbhavati…` | «Когда дхарма искажена, Я творю Себя» (приход Таараки). |
| `Shreyān svadharmo vigunah…` | «Лучше умереть человеком, чем жить животным». |
| `Tattvamasi` | «Ты есть То» — ответ гуру на вопрос «кто я». |
| `Avasya evam bhuktavyam` | «Неотработанное остаётся в запасе» (санскары). |
| `Shubhasya shighram ashubhasya kalaharanam` | «Благое — сразу, дурное — откладывай». |

## Критерии (для быстрой проверки)

- **Реальный гуру?** — Махакаола + три пласта + ниграха-ануграха.
- **Таарака?** — рождённый гуру без гуру; миссия восстановить дхарму; новая эра; садхана-пример; всегда спорен.
- **Самбхути или Махасамбхути?** — обычное творение vs особое проявление при коллективном дисбалансе.
- **Какая крипа?** — рсти (негативные микро-виты, избегай) / крипа (позитивные к оккультному) / каруна (к вершине славы).
- **Дхьяна или джапа?** — дхьяна полнее; джапа — композит; идол — низший.
