# Читшит: правила решений

## Грех

| Ситуация | Правило |
|----------|---------|
| Обычный грех, есть искупление | Pátaka (вернул 5 рупий → свободен) |
| Неискупимый грех | Atipátaka → служение обществу извне |
| Вред повторяется (Равана-садху) | Mahápátaka → искупление повторяющимся добром |
| «Я слишком грешен, будущее запечатано» | Неправда: So’pi pápavinirmukto — освобождение возможно |

## Идеация

| Ситуация | Правило |
|----------|---------|
| Думать о Боге с презрением | Тоже идеация: ум вращается вокруг Него → mokśa |
| Цель идеации | Непрерывность думания, не эмоция |
| Любовь только к Вишну | Iishvaraprema = ananya mamatá |

## Действие

| Ситуация | Правило |
|----------|---------|
| Доброе желание возникло | Shubhasya shiighram — действуй сразу, не спрашивая |
| Злое желание возникло | Ashubhasya kālaharańam — откладывай, спрашивай всех |

## Компания

| Ситуация | Правило |
|----------|---------|
| Слабый перед злодеем | Не вступай в контакт один — бери 2–3 спутников |
| Суммарные градусы | Добро (коллектив) должно превысить зло (одиночку) |
| Для махатмы злодей | Не опасен: контакт поднимает грешника |

## Слова

| Термин | Значение |
|--------|----------|
| upásaná | Приближение к Paramátmá (не «поклонение»-обряд) |
| upavása | Жизнь рядом с Paramátmá (не пост) |
| anaśana | Пост (отказ от пищи) |
| bhava | Остаточные санскары, вызывающие перерождение |
| bhavaságara | Океан перерождений, который надо пересечь |
