# Читшит — правила решений по Саркару (Ananda Marga Nutshell Part 11)

## Причина и бытие

| Ситуация | Правило |
|---|---|
| Найти первопричину | Отбрось 6 кандидатов (время/природа/судьба/случай/материя/единичное сознание) → последняя отражающая пластина = Parama Puruśa |
| Причина видна | Kriiŕá — объяснимо в пределах время/пространство/личность |
| Причина не видна, эффект есть | Liilá — не спорь о ней как о причине |
| «Это случайность» | Аварий нет — всё инцидент; «случайность» = незнание причины |
| Судьба против усилия | Фатализм — заблуждение; судьба = твои самскары; действуй |

## Узлы и освобождение

| Ситуация | Правило |
|---|---|
| Снятие уз временное vs полное | Artha (деньги/информация/комфорт) — временно; Paramártha (реализация) — постоянно |
| Внутренние «защёлки» | Чек-лист восьми паш: ненависть, опасение, страх, застенчивость, скрытность, род, тщеславие культурой/достоинством |
| Оценить «развитость» | По развитию людей, а не по гаджетам (корова в ракете не «развита») |
| Познать и освободиться | Нет другого пути, кроме слияния ума с Космическим (nánya panthá…) |

## Действие

| Ситуация | Правило |
|---|---|
| Взять ли дело | Критерий — праведность и всесторонний прогресс (не «получится ли?»); праведное — делай немедленно |
| Что тебя движет | Momentum (толчок сзади) или attraction (тяга спереди)? Вечен только духовный уровень |
| Кривая боли действия | Целься в akliśt́ávrtti (не больно ни в начале, ни в конце); избегай kliśt́ávrtti |
| Реакция на поступок | Vipáka «равен и противоположен» лишь при тех же время/пространство/личность; задержка = проценты боли |
| Понять, «кто владелец» | Тело — аренда у Iishvara; контролёр всего |

## Конфликт и отношение

| Ситуация | Правило |
|---|---|
| Против злости | Терпение; против бесчестности — честность; жадности — щедрость; лжи — правда |
| Счастливый друг / несчастный / добрый / злой | Майтри (дружелюбие) / каруна (сострадание) / мудита (поощрение) / упекша (обход) |
| Личный вред | Прощай максимально («будь ниже травы») |
| Коллективный/системный вред | Не прощай (дюйм → миля); личное прощение не коллективно |
| Тщеславие | Три формы: абхимана (как вино), гаорава (седьмой ад), пратиштха (как помёт) — брось и пой славу Господу |
| Как говорить с Богом | Не «я грешник» (Он знает лучше), а «я чист и просветлён» |

## Мантра и садхана

| Ситуация | Правило |
|---|---|
| Повторение без результата | Механический отсчёт без пробуждения (caetanya) бесполезен — нужен параллелизм вибраций |
| Пробуждение мантры | Мантра по самскаре + служение миру (не уход от мира); пробуждает только Mahákaola-гуру |
| Три шага возвращения | Shravana (слушай) → manana (идеируй) → nididhyásana (отдай ум) |
| «Я всё отдал» | Сдача неполна, пока остаётся «я»; отдай и его |
| Киirtana или bhajana | Kiirtana (громкое, коллективное) важнее bhajana (личного) |

## Тексты и люди

| Ситуация | Правило |
|---|---|
| Тип текста | Kávya (поэт-самореализованный) / puráńa (миф-урок) / itihása (обучающая история) / itikathá (хроника) |
| Оценить человека | Чем меньше разрыв внутреннего и внешнего, тем лучше человек; раскол — дефект цивилизации |
| Грешник и праведник | Для Parama Puruśa равны; Он не может ненавидеть |
| Смотреть на объекты | Madhuvidyá: всё — выражение Parama Puruśa → нет новых самскар |

## Быстрые сигналы («tells»)

- «Это судьба» — капитуляция; судьба — твои же реакции.
- «Прогресс — в ракетах/изобретениях» — техно-оптимизм без развития людей.
- «Я же сказал, значит знаю» — тщеславие знания; «я построил мост» — тщеславие действия.
- «Начну легко, а там видно» — akliśt́ákliśt́avrtti: расплата в конце.
- «Повторяю мантру тысячу раз — должен помочь» — без caetanya не поможет.
- «Он грешник, ему и поделом» — забыл, что Господь не умеет ненавидеть.
