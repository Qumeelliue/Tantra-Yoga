# Chapter 3: Rádhiká Shakti

*Дискурс от ноября 1966, Ernakulam.*

## Core Idea

Микрокосмы движутся вокруг космологической ступицы (Puruśottama) по своим радиусам; две силы — центростремительная (vidyá shakti) и центробежная (avidyá shakti) — управляют движением. С помощью видья-шакти в её практическом выражении (Rádhiká/hládinii shakti) микрокосм соединяется с Кришной (ступицей). Бхакти = karma − jiṋána; достигается милостью (krpá), а не учёностью.

## Frameworks Introduced

- **Макрокосмическое творение**: ум, единичный ум — творение материи; материя — творение Космического Ума. Для Макрокосма «подушка» — Его ментальная сущность; для нас — внешняя материя (пример с ментальным слоном и погонщиком).
- **Космологический порядок**: микрокосмы вращаются вокруг Puruśottama (Nucleus Consciousness) по своим радиусам; разность радиусов делает микрокосмы разными (мистер X ≠ мистер Y). Везде, где есть сущность, есть система = её dharma (вода мокнет, огонь жжёт — из-за «радиуса»). Научным изменением радиуса/длины волны можно превращать элементы (золото в ртуть, платину в радий).
- **Две силы**: центростремительная = vidyá shakti (к ступице); центробежная = avidyá shakti (от ступицы). Результат борьбы сентиентного/статичного: в пользу сентиентного → vidyá; статичного → avidyá.
- **Под влиянием avidyá**: микрокосм пытается улететь от ступицы (**vikśepa shakti** — центробежное) и спрятаться («ступица не видит меня») — **ávarańii shakti** (покрывающая).
- **Под влиянием vidyá**: внезапно «я должен что-то сделать» — **saḿvit shakti** (совесть); затем «сделать практически» — **hládinii shakti = Rádhiká shakti** (позитивное выразительное выражение видья-шакти, желание действовать к духовной реализации).
- **Krśńa = ступица**: притягивает всех «своей флейтой» (универсальными акустическими волнами). Соединение микрокосма с навой через Rádhiká shakti = «союз Кришны и Радхи» (не Вриндаванский мальчик и не девушка).
- **Формула бхакти**: **karma − jiṋána = bhakti**. Неграмотный: 200 заслуг − 0 = 200 бхакти; учёный (500 знания): нужны 700 заслуг для 200 бхакти — знание стало «обязательством». Поэтому неграмотные развивают бхакти легче.
- **Veda о приобретении**: *Náyamátmá pravacanena labhyah* — не таллаком, не интеллектом, не чтением; только если Он Сам откроется — *Yamevaeśa vrńute tena labhya* — «зависит от божественной милости, Guru krpá».
- **Krpá**: Рамакришна: kr = «karo» (делай садхану), pá = «páo» (получи) — «получи, делая садхану». Милость льётся на всех, но «зонт тщеславия» над головой мешает промокнуть; садхана = снятие зонта тщеславия.
- **Близость**: микро-ступица и макро-ступица — одна; «как драгоценности на одной нити» (*Sútre mańigańá iva*, vaejayantiimálá). Скрыт, как масло в кунжуте/масло в твороге/вода в сухом русле/огонь в кремне; «выжми» садханой — отделятся сущность и примеси (takra; садхаки пьют «масло», пандиты спорят о примесях; Ма́khancora — Кришна-«похититель масла»).

## Key Concepts

- **Puruśottama** — космологическая ступица, Nucleus Consciousness.
- **Vidyá / avidyá shakti** — центростремительная / центробежная силы.
- **Vikśepa / ávarańii shakti** — отлететь / спрятаться (порывы авидьи).
- **Saḿvit shakti** — внезапная совесть «должен что-то сделать».
- **Hládinii / Rádhiká shakti** — желание практического действия к духовной реализации.
- **Karma − jiṋána = bhakti** — формула преданности.
- **Guru krpá** — божественная милость; «получи, делая садхану».
- **Vaejayantiimálá** — «нить» Бога, соединяющая все ступицы.

## Mental Models

- «Твоя уникальность — радиус орбиты: не сравнивай микрокосмы по-разному».
- «Две силы всегда: к ступице (vidyá) или от неё (avidyá); распознавай направление».
- «Знание может быть обязательством: неграмотный быстрее достигает бхакти».
- «Снимай зонт тщеславия — милость уже льётся».
- «Садхана — выжимание масла: отдели сущность от примесей».

## Anti-patterns

- **Прятаться от ступицы** — аварания: «Бог не видит».
- **Таллак, интеллект, чтение вместо милости** — путь к Богу не через речь/ум/книги.
- **Зонт тщеславия** — блокирует дождь милости.
- **Путать бхакти и учёность** — знание без действия = обязательство.

## Worked Example

Автор объясняет макрокосмическое творение (подушка для Него — ментальная, для нас — внешняя). Вводит космологический порядок: микрокосмы вращаются вокруг Puruśottama по своим радиусам; dharma = система каждого радиуса; изменением радиуса меняются элементы. Затем две силы — vidyá/avidyá. Разбирает порывы авидьи (vikśepa, ávarańii) и видьи (saḿvit → hládinii/Rádhiká). Соединение с Кришной-навой через Радхика-шакти. Даёт формулу karma − jiṋána = bhakti с числовым примером (200/0/700). Цитирует Veda о милости; рассказывает историю Рамакришны о kr-pá; метафору зонта тщеславия и «единой нити» (vaejayantiimálá). Завершает примерами скрытости Бога (масло в кунжуте, масло в твороге) и призывом «выжать» садханой.

## Key Takeaways

1. Микрокосм движется по своему радиусу вокруг Puruśottama; dharma — система радиуса.
2. Vidyá shakti (к ступице) против avidyá shakti (от ступицы).
3. Цепочка: saḿvit (совесть) → hládinii/Rádhiká (практическое желание) → союз с Кришной.
4. Karma − jiṋána = bhakti; знание может быть обязательством.
5. Божественная милость (krpá) — «получи, делая садхану»; зонт тщеславия мешает.
6. Садхана — «выжимание масла»: отдели сущность от примесей.
