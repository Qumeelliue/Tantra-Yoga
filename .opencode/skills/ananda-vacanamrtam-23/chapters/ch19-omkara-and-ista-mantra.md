# Chapter 19: Oṋḿkára and Iśt́a Mantra

*Дискурс от 22 ноября 1970 вечер, Hyderabad.*

## Core Idea

Oṋḿkára (prańava) — коллективный звук всех звуков Вселенной, «звук-руководство» к Верховному; его надо слышать, а не произносить. Для каждого садхаки его личная Iśt́a mantra — самое ценное слово во Вселенной; чужие иста-мантры для него бессмысленны (пример Ханумана: Рама ≠ Нараяна для него).

## Frameworks Introduced

- **Все стремятся к Верховному**: сознательно или бессознательно каждое создание хочет быть любимым Верховным; все стремления людей (осознанные или нет) ведут к Нему.
- **Определение онмкары** (Kát́haka Shruti): все веды стремятся к Нему (veda = «знание», от vid); аскеты терпят трудности (tapah = трудности ради облегчения других / удовлетворения Господа); брахмачарии держат кодекс (даже физические объекты при контакте наделяются Брахмой/Нараяной — в этом Brahmacarya). «Вкратце это — он̭m».
- **Природа онмкары**: всё движется (в пределах пространства/времени/личности); движение = вибрация = энергия; энергии взаимно конвертируются (свет↔звук; витальная↔электрическая/свет/звук). Звук рождается из движения; садхана тренирует уши слышать его. **Oṋḿkára — коллективный звук всех звуков** (физических и психических); идя «отрицательным подходом» (к ступице) от множества звуков к одному источнику, движешься к Nave.
- **Четыре фазы (caturvarga)**: движение от ступицы к грубому = «положительное»; возврат — «отрицательное»: káma (физико-психическая), artha (чисто психическая), dharma (психо-духовная), mokśa (чисто духовная).
- **Prańava**: онмкара = prańava (pra + nu + al — «ведёт к высшему статусу»). Его слышат, а не произносят (язык не произнесёт; бесконечный звук); также Shabda Brahma.
- **Iśt́a mantra**: iśt́a = любимый/цель/терминус; mantra = *Mananát tárayet yastu sa mantrah* — «звук, медитация на который освобождает» (manana — внутреннее повторение; та́rayet — освобождение от всех уз). Для садхаки его Iśt́a mantra = prańava (его собственный). Самое ценное слово; чужие иста-мантры бессмысленны.
- **Рама vs Нараяна (Хануман)**: философски нет разницы (оба = Parama Puruśa); Рама = «драгоценнейший объект йогинов»; Нараяна = «прибежище Нары» (nára = вода, бхакти, Пракрти; ayana = прибежище; Nárada = «раздающий бхакти»). Но для Ханумана его иста-мантра — Рама: «для меня только Рама имеет смысл» (*Shriináthe Jánakiináthe cábheda Paramátmani… Tathápi mama sarvasvah Rámah*).

## Key Concepts

- **Oṋḿkára / prańava / Shabda Brahma** — коллективный звук всех звуков; «ведёт к высшему».
- **Káma / artha / dharma / mokśa** — четыре фазы возврата (caturvarga).
- **Iśt́a mantra** — личная мантра садхаки; его «prańava».
- **Mantra** — «медитация, ведущая к освобождению».
- **Manana / tárayet** — внутреннее повторение / освобождение.
- **Nárada / Nára / Náráyańa** — раздача бхакти / (вода, бхакти, Пракрти) / прибежище.

## Mental Models

- «Учись слышать звук-источник за множеством звуков».
- «Четыре фазы возврата: физика → психика → дхарма → мокша».
- «Иста-мантра личная: не сравнивай и не меняй по чужим».
- «Трудность (tapah) — ради блага других, не ради себя».

## Anti-patterns

- **Произносить онмкару вслух** — её слышат, а не произносят.
- **Механическое повторение чужой мантры** — иста-мантра только своя.
- **Сравнение мантр/имён** — для садхаки его мантра — всё.

## Worked Example

Автор открывает: все создания хотят любви Верховного. Даёт определение онмкары (Kát́haka Shruti): все веды, тапы, брахмачарья — к Нему; кратко — он̭м. Объясняет природу: движение→вибрация→энергия→звук; онмкара — коллективный звук; «отрицательный подход» к ступице. Четыре фазы: káma, artha, dharma, mokśa. Prańava — «ведёт к высшему»; слышать, не произносить; Shabda Brahma. Определяет иста-мантру (Mananát tárayet). История Ханумана: философски Рама=Нараяна, но иста-мантра Рамы — только Рама. Вывод: самое ценное слово для садхаки — его личная иста-мантра.

## Key Takeaways

1. Онмкара — коллективный звук всех звуков; садхана тренирует уши слышать его.
2. Prańava слышат, а не произносят; это Shabda Brahma.
3. Четыре фазы возврата: káma, artha, dharma, mokśa.
4. Иста-мантра садхаки — его prańava; чужие — бессмысленны.
5. Философски Рама = Нараяна, но для садхаки его мантра — всё (Хануман).
