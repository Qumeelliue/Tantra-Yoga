# Читшит — правила решений (Ánanda Vacanámrtam Part 23)

## Причинность и цель

| Ситуация | Правило |
|---|---|
| Искать первопричину | Отвергни относительное (время/природа/судьба/случай/материя/Пракрти) → Верховное Сознание |
| Судьба | Накопленные реакции действий; право на действие, не на плоды |
| Цель жизни (dhyeya) | Единственный объект идеации — Supreme Cognition |

## Бхакти и пути

| Ситуация | Правило |
|---|---|
| Оценить путь | karma − jiṋána = bhakti; знание без действия — обязательство |
| Выбор уровня практики | Слияние > медитация > повторение > идол |
| Идеация | Становишься объектом идеации; с верой или без — но с идеацией, не механически |
| Худший грешник | Однонаправленная идеация освобождает даже sudurácára |
| Преданность | Не-атрибутивная (ради Него, не ради блаженства/выгод) |

## Практика и прогресс

| Ситуация | Правило |
|---|---|
| Готовность к начинанию | 6 факторов: решимость, шраддха, гуру, равновесие, контроль органов, диета |
| Судьба ума | Ты становишься тем, о чём медитируешь: «дитя Отца», не «я грешник» |
| Этапы самадхи | sálokya → sámiipya → sáyujya → sárúpya → sárśt́hi → nirvikalpa/kaevalya |
| Физика/психика vs дух | В физике/психике движение без прогресса; прогресс — только духовный |
| Метод движения | Субъективный подход через объективную настройку |

## Этика

| Ситуация | Правило |
|---|---|
| Грех искупим | Pátaka (вернул + прощение) |
| Грех неискупим, одноразов | Atipátaka (отдача себя служению) |
| Грех заразителен | Mahápátaka (искупление — повторяющееся благо, «пенициллин») |
| Невыполнение «делай» | Pratyaváya (тоже па́па) |
| Гордость | Три канала: abhimána / gaorava / pratiśt́há; лечи смирением, терпимостью, киртаном |
| Ачарья нарушает кодекс | Silent action: не признавай роль, не критикуя |

## Космология-шпаргалка

| Термин | Суть |
|---|---|
| Shambhúliuṋga | Фундаментальная позитивность; контрол-точка шишковидной |
| Svayambhúliuṋga | Предельная грубость; спящая kuńd́alinii |
| Oṋḿkára / prańava | Коллективный звук всех звуков; слышать, не произносить |
| Káma / artha / dharma / mokśa | Четыре фазы возврата (caturvarga) |
| Dhruvasmrti | Постоянное осознание «Параматма свидетельствует меня» |
| Dagdhabiija | Сожжённые самскары (цель Dharma Samiikśa) |

## Быстрые сигналы («tells»)

- Практика без преданности — «возделывание пустыни».
- Повторение мантры без идеации — попугай.
- Гордость знанием — confusion of knowledge, не знание.
- «Я сделал столько — дай милость» — блокирует милость (зонт эго).
- Бык мычит «я велик»; струна — «ты велик»: эго не вечно.
