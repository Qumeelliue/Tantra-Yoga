# Читшит — краткая справка (Bábá Loves All 1)

## Обращение к Бабе
| Ситуация | Правило |
|---|---|
| Опасность/авария | Мысленный зов или мантра; потом ищи знак помощи (Jiiten, quicksand) |
| Чувствуешь гордость/храбрость | Жди «проверки» — будь смирен (Shaunkar, Jatāshaunkar) |
| Не получил darshan | Проверь послушание äcärya; попроси прощения (Ratneshvara) |
| Хочешь просить | Духовное — да; материальное «устройство» — риск (доктор, лотерейщик) |
| Сомнение «Он забыл меня» | Идеация и зависимость → сны-ответы (Ch 3) |

## Ключевые уроки
| Тема | Вывод |
|---|---|
| Всеведение (Antaryāmii) | Он знает имя, мысли, прошлое — всегда с заботой (Ch 1) |
| Предупреждения | Не выходи ночью / не веди машину = правила безопасности (Ch 2) |
| Сны | Кто больше идеирует — видит Его во сне; сон = руководство (Ch 3) |
| Страдание | Бог «отнимает», чтобы приблизить; «бритва»→«розы» для преданного (Ch 5) |
| Доверие | Котёнок (полная зависимость) > обезьянка (держусь сам) (Ch 5) |
| Эго | «Эго — пища Парама Пуруши»; убери зонтик эго — милость дождь (Ch 5) |

## Герои и события (справка)
- **Arun'a** — Баба при рождении (рассвет) → Ch 1.
- **Matiläljii / Mohanānanda** — имя, которое Баба знал, не спросив → Ch 1.
- **Sādhanjii** — голос Бабы диктует экзамен; чудо с кровью → Ch 1.
- **Ratneshvara** — урок послушания; тюремный разговор о Дхармагуру → Ch 2.
- **Dasharatha** — демонстрации прошлых жизней; сон о табаке → Ch 2, 3.
- **Kalpataru day** — «древо желаний», «Tathāstu» → Ch 2.
- **Mahāprayān'a** — 21.10.1990; посмертные сны «Я с вами больше» → Ch 3.

## Места
- **Jämālpur** — цех, Tiger's Grave, годы формирования Ананда Марги.
- **Bankipur Jail / Patnā** — тюремный период (Emergency).
- **Ranchi, Änandanagar, Vārāṇasii** — даршаны и демонстрации.
- **Sāhārsā, Monghyr, Bihār** — родина многих героев рассказов.
