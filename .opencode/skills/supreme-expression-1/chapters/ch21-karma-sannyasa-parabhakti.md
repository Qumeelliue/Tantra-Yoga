# Глава 21: The Cardinal Spirit of Action and the Supreme Stance of Devotion (Karma-Sannyása and Parábhakti)

*«Subháśita Saḿgraha Part 9»; DMC 1 января 1968, Allahabad.*

## Core Idea

Karma = относительное изменение положения объектов (в рамках TSP). Karma-sannyása — отождествление с неизменной Сущностью: действие с осознанием, что деятель — не «я», а Космос; единение собственного интеллекта с Космическим. Достижимо через парабхакти (интенсивную любовь к Para Brahma) — «prańipáta»: полное вручение себя мудрому Господу.

## Frameworks Introduced

- **Определение karma**: относительное изменение положения объектов; вне TSP действия нет; у Верховного действия нет (Он вне относительности).
- **Karma-sannyása**: sannyása = saḿ(sat) + nyása = отождествление с неизменяемым. Три интерпретации: (1) полное бездействие — нет; (2) совершенное завершение работы — нет; (3) **унификация с Верховным через karma** — да.
- **Условия karma-sannyása**: время-фактор → Вечная Сущность; пространство → Всепроникающая; личность → Верховный Приют. Это не средство достижения, а состояние вершины.
- **Два деятеля**: только микро- и макрокосм; тело не действует без импульса ума (две причины: притяжение Космического Ума; направление единичным умом других). Ветер/солнце — слепые силы, движутся импульсом Космического Ума (волчок, запускаемый мальчиком).
- **Разница умы**: единичный ум может не осознавать функции Космического (осознаёт на бессознательном уровне); космическое — известно всегда; «Mana eva manuśyánáḿ kárańam bandha-mokśayoh» — ум — причина и оков, и освобождения.
- **Энергия — слепая сила**: нужен интеллект (драйвер); полезное, доступное всем, будет испорчено — интеллектуалы должны контролировать физическую силу масс (буйвол без погонщика). **Урок для управления обществом**.
- **Знание**: субъективизация внешней объективности; без субъективизации — отражение/рефракция, «тень знания», источник эго. **Átmajiṋánam = единственное знание** (другие — umbra и penumbra); в нём знающий, знаемое и знание едины.
- **Aparabhakti vs parábhakti**: привязанность к Apara Brahma (относительный мир) — апарабхакти; интенсивная любовь к Para Brahma — парабхакти. Объект-цель определяет судьбу: цель apara → достигнув, человек игнорирует работу (учёный с дипломом, ставший министром, бросает социальную службу); цель para → слияние.
- **Два течения (átmanepadii / parasmaepadii)**: движение к ограниченному объекту — в конце ум становится объектом; движение к Бесконечному — освобождение.
- **Bhakti = бег ума к Верховной Сущности**: оставив мирские объекты; как гусеница→бабочка, ум преображается незаметно.
- **Prańipáta**: преданный знает, что Paramátmá мудрее его, и оставляет всё Ему. Через парабхакти возможен karma-sannyása; парабхакти делает человека великим деятелем — сила преданности утверждает в действии, принося пользу миру.
- **Вывод**: karma-sannyása — только для тех, чья цель Parabrahma; прогресс знания и действия невозможен без преданности.

## Key Concepts

- **Karma / karma-sannyása** — действие / отождествление с неизменным.
- **Átmajiṋána** — самореализация, единственное знание.
- **Aparábhakti / parábhakti** — любовь к проявленному/непроявленному.
- **Prańipáta** — полное вручение себя.
- **Atmanepadii / parasmaepadii** — движение к себе-объекту / к Бесконечному.
- **Mana eva kárańam bandha-mokśayoh** — ум — причина оков/свободы.

## Mental Models

- «Деятель — не ты: твоё тело действует импульсом ума, ум — импульсом Космоса».
- «Энергия слепа — без интеллекта-драйвера она разрушит».
- «Цель определяет финал: гонись за apara — станешь им и остановишься; за para — сольёшься».
- «Преданность — не просьба, а prańipáta: отдать руль мудрому».

## Anti-patterns

- **Трактовка karma-sannyása как бездействия** — неверна.
- **Учёность ради знания без субъективизации** — «тень знания», эго.
- **Социальная служба ради министерского поста** — цель apara, деградация.
- **Считать себя самодостаточным деятелем** — заблуждение (энергия слепа).
- **Отделять знание/действие от преданности** — без преданности нет прогресса.

## Worked Example

*Реконструкция.* Учитель Бхопала не может сказать, сколько муравьёв в городе — объективность не субъективизирована. Когда субъективизировано — не нужно читать книги: объекты отражены в а́тмане. Но и знание, и действие приходят к своему завершению, когда цель — Parabrahma. Служение обществу без желания поста (как министр) возможно только при парабхакти; она и есть prańipáta — вручение всего мудрому Господу, из которого рождается karma-sannyása.

## Key Takeaways

1. Действие без осознания Космического деятеля — рабство слепой энергии.
2. Единственное знание — átmajiṋána; остальное — тени.
3. Цель определяет судьбу: выбери Parabrahma, а не apara.
4. Парабхакти — и фундамент karma-sannyása, и сила великих деяний.
5. Вручай себя (prańipáta) — Он мудрее.
