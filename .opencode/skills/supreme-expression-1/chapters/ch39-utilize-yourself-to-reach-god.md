# Глава 39: Properly Utilize Yourself to Reach God

*«Ánanda Vacanámrtam Part 23»; 21 мая 1971, Ranchi.*

## Core Idea

Bala (сила) — не «обладание мощью», а «использование имеющейся силы». Слабая белка, несущая камешки для моста Ráma, сильна так же, как Гару́да с горами — каждый работал на полную силу. Используй свою силу для са́дханы и служения — и станешь balaván, достойным достичь Parama Puruśa. Не жди жизней — цель в этой жизни.

## Frameworks Introduced

- **Bala = использование**: упанишадный стих: нельзя достичь Parama Puruśa без силы/энергии. Bala (spiritual force) в единице; обычное «bala» = capacity; но помогает только использованная часть. Гару́да принёс горы, белка — камешки; оба сильны — оба работали на полный максимум.
- **Не отчаивайся**: даже слабый, используя малую энергию, становится balaván; у каждого есть средства достичь Алмиight.
- **Правильное направление**: движение на восток, если нужно на восток; на запад — «prámáda» (безумие). Ананда Марга — правильный путь: субъективный подход (глаза на Абсолюте) + объективная корректировка (не игнорируй относительный мир); самореализация + социальное возвышение.
- **Срок**: не ждать жизнь за жизнью — реализовать цель в этой жизни; не тратить ни мгновения.

## Key Concepts

- **Bala** — сила как использование capacity.
- **Prámáda** — безумие (движение не в том направлении).
- **Subjective approach / objective adjustment** — взгляд на Абсолют + работа с миром.
- **Squárrel и Garuda** — примеры силы по использованию.

## Mental Models

- «Сила — это отдача, а не резерв: используй 100% того, что есть».
- «Каждый имеет достаточно, чтобы достичь Его — нет оснований отчаиваться».
- «Направление важнее величины: верное усилие + верное использование = цель».

## Anti-patterns

- **Откладывать цель на другие жизни** — «почему потратишь хоть мгновение?».
- **Практика без направления** (prámáda) — сила, потраченная впустую.
- **Чувство бессилия из-за сравнения с другими** — сравни с собой-полным-использованием.

## Worked Example

*Реконструкция.* Строится мост через океан: Гару́да приносит горы, белка — камешки. Оба сильны (balaván), потому что каждый работает на полную мощность своих способностей. Значит даже самый «слабый», использующий всю свою энергию для са́дханы и служения, — силён и может достичь Parama Puruśa. Направление должно быть верным (Абсолют + мир), иначе — prámáda.

## Key Takeaways

1. Измеряй силу по использованию, а не по запасу.
2. Используй всю свою энергию для са́дханы и служения.
3. Держи правильное направление (субъект+объект) — иначе безумие.
4. Реализуй цель в этой жизни — не откладывай.
5. Никогда не отчаивайся: у каждого есть средства.
