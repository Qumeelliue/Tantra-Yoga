# Глава 36: Náma and Námii

*«Subháśita Saḿgraha Part 21»; DMC 19 октября 1971, Bombay.*

## Core Idea

Имя (náma) сильнее именуемого (námii): пока энергия имени латентна — она «не энергия»; когда преданные дают Господу имя, Его латентная сила активируется. Для каждого человека единственное настоящее имя — его Iśt́a mantra. Отношения с Богом — личные, вне понятий греха/добродетели; Он — Bhiiśańa (грозный для мироздания) и bhadra (добрый для семьи).

## Frameworks Introduced

- **Имя несёт bháva**: имя — не просто слово; идеация (bháva) объекта идёт вместе с именем; самого себя не нарекаешь — это делает другой.
- **Имя сильнее именуемого**: Hanumán: «Я перепрыгну океан с Твоей силой, взяв Твоё имя». Научное объяснение: шакти имени — kendrita (централизована), stambhita (латентна); наречение активирует её. Ом: точка = потенциальная энергия; полумесяц = выражение. Латентный поэт (Рабиндранат) без выражения — не признан; выраженное имя активирует.
- **Господь без преданных безымянен**: когда не было преданных, у Бога не было имени; преданные дали Ему имя («Господь, ты велик» / «Ты велик» — вечный сладкий спор о том, кто выше).
- **Bábá**: bapra (древний санскрит, «дорогой») → bappa → báppá → bapu → bábá; Он — Bábá для единиц, единицы — Bábá для Него (любовь без высшего/низшего).
- **Iśt́a mantra — единственное имя**: чем более идеационно имя, тем больше блаженства; для человека его Iśt́a mantra — всё; другие имена — не его имена (Hanumán: знаю, что Shriinátha = Jánakiinátha, но Ráma — всё для меня).
- **Обязательность имени**: даже в dhyána хочется обратиться к медитируемому по имени; пока есть имя и нарекающий — имя нужно; в конце останется только именуемый.
- **Liilá**: виден эффект без причины; каузальность работает только в уме/TSP (Кана́да); человеческий ум ограничен — не дотягивается до причины.
- **Наука samádhi**: повторяя имя, достигаешь именуемого — за пределами относительности ум растворяется в samádhi.
- **Язык ограничен**: язык беднее bháva (чувства); bháva беднее mahábháva (блаженства); где максимальное блаженство — молчание (стих Padmadanta: чернильная плита размером с Гималаи, океаны чернил, перо párijáta, земля-бумага — и Са́рада́ не опишет всех качеств).
- **Pápa и pratyaváya**: pápa — сделал то, что не следует (кража); pratyaváya — не сделал то, что следует (служение обществу). Но отношения с Parama Puruśa — вне добродетели/греха (двухлетний ребёнок на коленях отца).
- **Bhiiśańa / bhadra / mrtyurmrtyu**: Он ugra/udagra (впереди всех), viira (храбрый), Maháviśńu (всепроникающий, с потенциалом), jvalantam (сияющий, источник энергии), vishvatomukham (лицо к каждому), nrsiḿha (best, Puruśottama), bhiiśańa (страшный: из страха перед Ним дует ветер, встаёт солнце, приходит смерть; «Binu bhay hoi na piriiti» — без страха нет любви), bhadra (добрый, член семьи), mrtyurmrtyu (смерть смерти — укрывшийся в Нём больше не перерождается).
- **Namaste vs namaskára**: к jiiva — namaskára; к Parama Puruśa — что угодно (Он — член семьи).

## Key Concepts

- **Náma / námii** — имя / именуемый.
- **Kendrita / stambhita shakti** — централизованная/латентная сила.
- **Iśt́a mantra** — личное имя Господа.
- **Pápa / pratyaváya** — грех совершения / грех упущения.
- **Bhiiśańa / bhadra / mrtyurmrtyu** — грозный / добрый / смерть смерти.
- **Nrsiḿha** — «лучший человек» (Puruśottama), не «получеловек-полулев».
- **Liilá** — игра с невидимой причиной.

## Mental Models

- «Имя — это активация латентной силы: называй, и оно оживёт».
- «Для тебя одно имя — твоё Iśt́a mantra; другие — не твои».
- «Страх правит мирозданием, любовь — семью; Он — и то, и другое».
- «Отношения с Ним — личные: вне pápa/puńya, как ребёнок на коленях отца».

## Anti-patterns

- **Считать «имя» простым словом** — имя несёт bháva и активирует.
- **Путать имя с именуемым** — имя сильнее, потому что активирует.
- **Выбирать «тысячи имён» вместо своего Iśt́a mantra** — Hanumán выбрал одно.
- **Бояться Его грозности вне семейных отношений** — Он bhadra для детей.

## Worked Example

*Реконструкция.* Hanumán спрашивает Ráma, кто сильнее — Он или Его имя. Ráma: «Я не могу перепрыгнуть океан, ты можешь — с Моей силой». Hanumán: «Возьму Твоё имя и прыгну». Объяснение: латентная энергия имени (точка в Ом) активируется наречением (полумесяц). Как поэт, не написавший стихов, не признан — так и имя без наречения бессильно. Для человека единственное имя — его Iśt́a mantra; прочие — не его имена.

## Key Takeaways

1. Имя активирует латентную силу — нарекай и используй имя сознательно.
2. Твоё единственное имя — Iśt́a mantra; не распыляйся на другие.
3. Отношения с Господом — личные, вне греха/добродетели.
4. Страх — закон мироздания (Bhiiśańa), любовь — семья (bhadra); соединяй.
5. Наибольшее блаженство — за пределами языка: где максимум — молчание.
