# Глава 18: To Know Him Is to Be Free from All Fetters

*«Subháśita Saḿgraha Part 9»; DMC 17 октября 1971, New Delhi.*

## Core Idea

Только познание Parama Puruśa освобождает от всех уз. Он — súkśmátisúkśma (тоньше тонкого) внутри всех объектов, единый и всепроникающий; Его знание = слияние ума с Космическим Умом. Связь — творец-творение, семейная, не судья-подсудимый. Бхакты мудрее пандитов: не тратят время на бесплодные дебаты о liilá.

## Frameworks Introduced

- **Súkśmátisúkśmaḿ kalilasya madhye**: объект вне органов — súkśma; вне концептуального диапазона ума — súkśmátisúkśma. В мельчайшем (белый муравей) Его игра так же действует, как в крупном.
- **Vishvasya srast́á**: вселенная создана статическим принципом Prakrti; как свидетель Он — Vishva; создал Себя Сам (Svayambhú).
- **Liilá vs Kriid́á**: kriid́á — причина видна; liilá — виден только эффект. Для единицы творение — liilá; для Него — kriid́á. Кана́да: «Kárańábhávat káryábháva»; за пределами TSP причина непостижима умом.
- **Связь Творец-творение**: Он — создатель, мы — творение; отношения близкие и семейные. **Bábá**: от vapra («дорогой») → bappa → bábá; и для Него единицы — Bábá. «Bábá Nám Kevalam» — взаимно: Он существует, потому что преданные существуют.
- **Великий конфликт преданных и Господа**: «Ты велик — ты моя жизнь» ↔ «Ты велик — ты Моя жизнь»; без решения, длится вечно. Бхакты советуют пандитам не тратить время (жизнь 70–80 лет; «art is long, life is short»).
- **Одиночество до творения**: до вселенной Он был один — говорить не с кем, смеяться не с кем; проявил Себя множеством, чтобы продолжить божественную игру.
- **Равенство всех творений**: белый муравей = комар = мамонт = три мира (sama plushiná sama mashakena sama nágena); никто не мелок для Него.
- **Огонь один, форм много** (Агни-риши): Единый проявляется многим.
- **Числа — психические творения**: «один»/«два» — конструкции ума; для описания Parama Puruśa годится только «один» (до слияния ум не достигнет Его).
- **Deva = Mahádeva**: каждая волна от Него — «deva», источник — Mahádeva; cidaekarasah (непрерывный поток сознания); к знанию Его — свобода от всех пут.
- **Восемь пут (páshas)**: ghrńá (ненависть), shauṋká (опасение), bhaya (страх), lajjá (стыд), jugupsá (подавление), kula (происхождение), shiila (тщеславие культуры), mána (тщеславие). Также шесть врагов и 50 пропенситив.
- **Jńatvá Shiva → shánti**: shánti = погружённость в себя; Shiva = Cognitive Faculty (Citishakti); Prakrti — Его имманентная сила; без разрешения Citishakti Пракрти бессильна.

## Key Concepts

- **Súkśmátisúkśma / kalila** — тоньше тонкого / тонкая часть объекта.
- **Liilá / kriid́á** — игра с невидимой/видимой причиной.
- **Svayambhú** — самосозданный.
- **Bábá** — «дорогой»; взаимные отношения.
- **Sama plushiná...** — равенство всех творений.
- **Deva / Mahádeva / cidaekarasah** — волна / источник / непрерывный поток сознания.
- **Паши (8 пут)** — перечень уз.
- **Shánti** — самопогружение; Shiva = Citishakti.

## Mental Models

- «Творение для тебя — liilá; для Него — kriid́á; не трать время на "почему"».
- «Отношение — семья, не суд: Он не судья, ты не подсудимый».
- «В Его глазах муравей = мамонт: никто не важен и не мелок».
- «До слияния ум не описывает Его; единственное число — "один"».

## Anti-patterns

- **Пандитские дебаты о причинах** liilá — упражнение впустую.
- **Чувство собственной незначительности** («Он не заботится обо мне») — ошибочно.
- **Ненависть к любому творению** — ненавидеть Его проявление.
- **Думать о физическом освобождении**: постоянное освобождение — через познание, слияние ума с Космическим.

## Worked Example

*Реконструкция.* Белый муравей в калиле: даже у крошечного существа есть мозг, и в нём действует Его игра. Он — свидетель (svayambhú), создатель (vishvasya srast́á). Причина творения вне TSP — для ума непостижима → liilá. Бхакта не спорит о причинах; знает, что Он — создатель, а он — творение; отношения семейные («Bábá»). Познать Его = слить ум с Ним = свобода от всех пут.

## Key Takeaways

1. Свобода от уз — через познание Его, единственный путь (nánya panthá).
2. Принимай творение как liilá: не трать энергию на поиск причины.
3. Культивируй семейные отношения с Ним, без страха суда.
4. Никого не презирай: в Его глазах всё равно важно.
5. Освобождение — через слияние ума с Космическим Умом.
