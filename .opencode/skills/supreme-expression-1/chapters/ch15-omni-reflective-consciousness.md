# Глава 15: The Omni-Reflective Cognitive Consciousness

*«Subháśita Saḿgraha Part 10»; DMC 1 октября 1971, Calcutta.*

## Core Idea

Pratisaḿvedii Puruśa — Верховное Отражающее Сознание: последняя «отражающая пластина», на которой покоится всякое отражение. Путь анализа не ведёт к Нему (упирается в бесконечность причин); путь синтеза (от чувств → citta → aham → mahat → jiivátma → Parama Puruśa) — ведёт. Ни один относительный фактор и даже единичное сознание не являются Верховной Пластиной; только невоплощённое Верховное Познание (nirakśara).

## Frameworks Introduced

- **Pratisaḿvedana / pratisaḿvedii**: saḿvedana — действие, pratisaḿvedana — реакция (отражение); объект, на котором отражается волна, — pratisaḿvedii (отражающая пластина).
- **Критика путей к первопричине**: анализ (поиск причины причины) упирается в непознаваемое; путь dharma — синтез многих в одно, в Верховное Единство в разнообразии.
- **Четыре шага синтеза**: (1) чувственные выражения → citta; (2) citta → ahaḿtattva (doer-I); (3) aham → mahat (existential I); (4) mahat → jiivátmá; отражающая пластина jiivátma = Parama Puruśa.
- **Разбор «кандидатов»** (повторяет ch10): время (не причина), природа/Prakrti (иманентная сила Puruśa, ограниченная свобода), судьба/niyati (накопленные реакции; не сдавайся судьбе без инициативы), случай/yadrcchá (нет случайностей; «ha» — акустический корень солнца/vishuddha, «t́ha» — ájiṋá; hat́ha yoga = контроль тонкой энергии физической), материя (ум управляет материей), jiivátma (заражён умом; зеркало краснеет от красной розы; до освобождения не Iishvara — «Klesha-karma-vipákáshayaeraparámrśt́a puruśavisheśa Iishvara»).
- **Пракрти без интеллекта опасна**: энергия — слепая сила; электроотбойник раздавит руку ребёнка; са́дхана Prakrti без касания Shiva опасна.
- **Познавательный принцип — и материальная, и действующая причина**: Cognitive Principle — и материал, и причина творения.
- **Три уровня Сознания**: kśara (мутируемый) + akśara (неизменяемый) emanate из **nirakśara** (непроявленное Верховное Познание) — только оно Верховная Отражающая Пластина. Путь: материя → ум → сознание → Верховное Познание.

## Key Concepts

- **Pratisaḿvedii Puruśa** — Верховная Отражающая Пластина.
- **Путь синтеза** — соединение многих в одно.
- **Kśara / akśara / nirakśara** — изменяемое / неизменяемое / невоплощённое.
- **Citta / ahaḿtattva / mahat / jiivátma** — ступени синтеза.
- **Klesha-karma-vipákáshaya** — четыре фактора, от которых свободен Iishvara.
- **Hat́ha yoga** — контроль тонкой энергии через физическую.

## Mental Models

- «Анализ упирается в стену; синтез — единственный путь к Верховной Пластине».
- «Любое отражение требует пластины: ищи последнюю, на которой всё покоится».
- «Слепая энергия без интеллекта разрушительна — не отрывай са́дхану от Сознания».
- «Поднимайся: материя → ум → сознание → Верховное Познание».

## Anti-patterns

- **Анализ вместо синтеза** в поисках первоначала.
- **Фатализм**: полная сдача судьбе без инициативы.
- **Культ энергии/Prakrti без Сознания** — опасно.
- **Считать единичное сознание Верховной Пластиной**: оно заражено умом (закрашено цветом розы).

## Worked Example

*Реконструкция.* Увидев объект: волны отражаются в citta (иначе не видишь). citta укоренена в ahaḿtattva (doer-I); aham — в mahat; mahat — в jiivátma. Отражающая пластина jiivátma — Parama Puruśa. Значит по пути синтеза ты приходишь к Верховной Отражающей Пластине. Анализ же (причина причины) упирается в непознаваемое за пределами ума — тупик.

## Key Takeaways

1. Для поиска Верховного используй синтез, а не анализ.
2. Восприятие — цепочка отражений; найди последнюю пластину.
3. Ни относительный фактор, ни единица не могут быть первопричиной.
4. Энергия без Сознания слепа и опасна.
5. Верховная Пластина — невоплощённое Верховное Познание (nirakśara).
