# Глава 23: Mantra Caetanya

*«Subháśita Saḿgraha Part 10»; DMC 28 мая 1967, Allahabad.*

## Core Idea

Всё вибрационно; первый и тончайший вибрационный поток — shabda (звук). Мантра — набор shabdas, медитация на который ведёт к освобождению. **Mantra caetanya** — «оживление» мантры: параллельность индивидуальной эктоплазматической вибрации с Космической; без неё даже миллионы повторений бесполезны. Путь возвращения домой: shravana → manana → nididhyásana.

## Frameworks Introduced

- **Shabda Brahma**: первый вибрационный поток Brahma; Kárańa Brahma — чисто субъективный (svagata, svarasátmaka), без объективного (paragata); Kárya Brahma — выражен. Vowels (svaravarńa) — Kárańa Brahma; consonants (vyaiṋjana) — «действия», разнообразие творения.
- **Pará / paráshakti**: стартовая точка shabda в мире идеаций; есть и в единице, и в Космосе; потенциальна, но без медиума не выражается; выражается как shabda при сшибании волн.
- **Определение мантры**: «Mananát tárayet yastu sah mantrah» — набор shabdas, медитация на который ведёт к освобождению; не каждый звук/набор. Пример: «поговорим» не поможет подняться, «помогите поднять» — поможет (разные результаты при одном семени идеи).
- **Mantra siddhi vs mantra caetanya**: siddhi — параллельность единичной эктоплазматической вибрации с Космической достигнута (финальная цель); caetanya — пробуждение: физическая вибрация + эктоплазматическая + подъём к духовному уровню. Мёртвый shabda без пробуждения бессмыслен.
- **Индивидуальный ритм**: у каждого своя вибрация (стиль речи, еда); «Vaecitryaḿ prákrtadharmah» — разнообразие — закон природы (А́nanda Sútram); свобода личности = беспрепятственное выражение индивидуальных ритмических вибраций.
- **Условия mantra caetanya**: (1) мантра должна соответствовать самскаре индивида; (2) братская эмоция и привязанность к внешнему миру (не «са́дхана для личного спасения» — это самообман/эгоизм); служение человечеству с отношением к Parama Puruśa.
- **Kula / kaola / Mahákaola / purashcarańa**: kula — точка блокировки jiivabháva; kaola — достигшие совершенства; Mahákaola — движущие коллективную эктоплазму, пробуждают новую силу в shabda = purashcarańa; только они — статус гуру; их шабды — siddha mantras (индивидуальные усилия не достаточны).
- **Животный vs человеческий уровень**: животное — личный дух + безличный медиум (рост от грубого к тонкому, без духовного падения); человек — личный медиум влияет; когда личное превосходит безличное — это человек.
- **Пять уровней shabda**: pará → pashyantii → madhyamá → dyotamána → shrutigocará → vaekharii (от тонкого к грубому).
- **Три шага возвращения (шравана-манана-нидидхьясана)**:
  1. **Shravana** (слушание Его имени): Hari kathá даёт тончайшие вибрации (звук тоньше образа); kiirtana (пение, слышишь сам и другие) и bhajana (слушание самому); идёт против потока vibrational faculty → к стартовой точке.
  2. **Manana** (размышление только о Нём): всему иному приписывай Brahma-hood; от конца primordial к его началу.
  3. **Nididhyásana** (непрерывное медитирование/отдача): собрать все пропенситивы в точку и отдать Parama Puruśa; сдать «Я» (арх-враг); «у тебя нет ума — вот мой ум, прими» (шлока Ratnákara).
- **Bhava / bhava ságara**: вибрационная фаза — океан мирского; её Когнитивный принцип — Bhava, Оперативный — Bhávánii Shakti; пересечь можно только через Hari kathá.

## Key Concepts

- **Shabda / Shabda Brahma / pará** — звук/первый поток/стартовая точка.
- **Mantra / mantra siddhi / mantra caetanya** — звук, медитация на который ведёт к свободе; финал/пробуждение.
- **Purashcarańa / Mahákaola / siddha mantra** — оживление мантры/мастера/пробуждённая мантра.
- **Shravana / manana / nididhyásana** — три шага возвращения домой.
- **Bhava / Bhávánii Shakti** — вибрационная фаза и её сила.
- **Vaecitryaḿ prákrtadharmah** — разнообразие — закон природы.

## Mental Models

- «Звук тоньше образа: слушание Его имени — тончайший вход».
- «Мантра без оживления — как миллионы мёртвых букв: сила не в повторении, а в резонансе».
- «Са́дхана — возвращение домой: снаружи (шравана), внутри (манана), вручение (нидидхьясана)».
- «Отдай "Я" — арх-врага; пока сдаёшь "моё", а не "Я", сдача неполна».

## Anti-patterns

- **Считать себя «са́дхакой ради личного спасения»** и отрицать мир — самообман.
- **Повторять мантру без параллельности/резонанса** — бесполезно (см. ch16: «Mara»).
- **Нарушать чужой ритм дисциплиной/гневом** — против свободы личности.
- **Учить мантре без статуса гуру** — только Mahákaola может оживлять.
- **Искать прогресс в физическом/интеллектуальном** без перевода в духовное — самообман.

## Worked Example

*Реконструкция.* Человек не может встать. Сказать «давайте поговорим» не поможет; сказать «помогите поднять» — поможет: разные выражения одной идеи дают разные результаты. Мантра — набор звуков, резонирующий с твоей самскарой и, при параллельности с Космической вибрацией, ведущий к освобождению. Чтобы оживить её, нужен шравана (слушать Его имя — Hari kathá тоньше образа), манана (всему приписать Brahma-hood) и нидидхьясана (сдать «Я»). Мантра caetanya ведёт к mantra siddhi — возвращению в дом (Puruśottama).

## Key Takeaways

1. Начинай с шраваны: слушай и говори Его имя — звук тоньше образа.
2. Мантра должна соответствовать твоей самскаре и быть оживлена (резонанс).
3. Не отрывай са́дхану от мира — служение человечеству обязательное условие.
4. Три шага: шравана → манана → нидидхьясана (сдача «Я»).
5. Без оживления мантры (purashcarańa через Mahákaola) повторения бесполезны.
