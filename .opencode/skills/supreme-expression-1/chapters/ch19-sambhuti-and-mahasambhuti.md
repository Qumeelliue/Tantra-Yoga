# Глава 19: Sambhúti and Mahásambhúti

*«Subháśita Saḿgraha Part 9»; DMC июль 1967, Delhi.*

## Core Idea

Sambhúti — «правильное происхождение/развитие»: особое творение Parama Puruśa (вселенная, живые виды, формы avatára). Vinásha — полное разрушение без возврата; prańásha — возврат к источнику. Jiivakot́i (развивающиеся существа) и Iishvarakot́i (высшие проявления божественности). Mahásambhúti — особое проявление для исправления хаоса среди sambhútis (Shiva и Krśńa), Táraka Brahma.

## Frameworks Introduced

- **Sambhúti / vinásha / prańásha**: sambhúti — оригинальное творение (элементы, виды); vinásha — разрушение без возврата к оригиналу (мальчик 5→25 лет: тело 5-летнего исчезло); prańásha — возврат к исходному источнику (пшеничная мука → puri → мука).
- **Всё — sambhúti**: от солнца до муравья; вся вселенная — коллекция sambhútis. Avatára: когда Parama Puruśa проявлен в физическом объекте, объект — Его avatára.
- **Jiivakot́i vs Iishvarakot́i**: jiivakot́i — развивающиеся существа (от протозоев до людей); сила ограничена (физическая сила не растёт бесконечно, память — до возраста); эволюционируют через psychic и social clash. Iishvarakot́i — большее проявление божественности; jiivakot́i может возвыситься до него са́дханой.
- **Эволюция форм avatára** (последовательность sambhútis): рыба (matsya) → черепаха (kúrma) → вепрь (baráha) → получеловек-полулев (narahari) → карлик (vámana) → bhrgupati (Parashurama) → Ráma → Balaráma (инженер, земледелие, город Дварака) → Buddha (критика жертвоприношений) → Kalki (уничтожение греха; «Vinu bhaya hoi na piriiti» — где нет страха, нет любви).
- **Kalávatára / aḿshávatára / khańd́ávatára**: разные степени avatára, ни одна не полная. Shiva и Krśńa НЕ в последовательности — они Mahásambhútis (Táraka Brahma).
- **Mahásambhúti**: специальное проявление, когда коллективный хаос неразрешим отдельным sambhúti (5 млрд человек потеряли жизненность → требуется особое проявление). Роль: править всеми sambhútis, дисциплина, гармония. «Бесконечный поток интеллекта, мудрости и знания»; через новые системы/идеи/идеалы, скор и наказание создаёт новый мир.
- **Пять лиц Shiva (Paiṋcánana)**: Dakśińeshvara (сладкие наставления), Vámadeva (громкое наказание), Iishána (совет о последствиях), Kálágni (запугивание без исполнения), Kalyáńasundaram (доброта «сядь рядом»). Господь смотрит пятью лицами и действует по ситуации.
- **Молитва**: asato má sadgamaya (из нереального в реальное, из тьмы в свет, из смерти в бессмертие); «Rudra yatte dakśińaḿ mukham...» — защити меня через Dakśińeshvara-лицо.
- **Геология-урок**: смена эпох (Archean, Mesozoic, Oligocene, Eocene); австралопитеки ~1,7 млн лет назад (Miocene/Oligocene) — предки людей (не «Káshyapa»/«Bharadvája»); саргассовые моря → минеральное масло из жира животных (Ассам, Гарo-Хаси, Гималаи, Раджастан).
- **Все направления — sambhúti**: pradisha и anudisha — все Его творения; не важно, куда сидеть лицом.

## Key Concepts

- **Sambhúti / vinásha / prańásha** — творение / разрушение / возврат к источнику.
- **Jiivakot́i / Iishvarakot́i** — уровни проявления.
- **Mahásambhúti / Táraka Brahma** — особое проявление для исправления хаоса.
- **Kalávatára / aḿshávatára / khańd́ávatára** — неполные avatára.
- **Paiṋcánana** — пять лиц Shiva (руководство по ситуации).
- **Keshava** — имя Krśńa; «Keshava dhrta...» — последовательность форм.

## Mental Models

- «Творение — школа sambhúti: каждая форма — ступень; ничто не лишнее».
- «Муравей важен: даже он может нарушить баланс вселенной».
- «В коллективном кризисе нужен не очередной лидер, а Mahásambhúti — особая структура».
- «Пять лиц — это управление по ситуации: сладко, строго, советом, страхом или добротой».

## Anti-patterns

- **Ненависть к любому sambhúti** (алкоголикам и пр.): ненависть — не моральное мужество.
- **Считать только Krśńa/Shiva «аватарами»**: весь эволюционный ряд — Его sambhútis.
- **Геологический/эволюционный невежество о предках человека** (не «Káshyapa», а австралопитеки).
- **Считать юг неблагоприятным направлением** — все направления — Его творение.

## Worked Example

*Реконструкция.* Эволюция форм avatára как ряд sambhúti, соответствующих ступеням эволюции: рыба (вода) → черепаха (вода+суша) → вепрь (суша, примитив) → narahari (получеловек) → карлик (ранний человек) → Parashurama → Ráma (развитый человек) → Balaráma (агрокультура, инженерия) → Buddha (духовно развитый) → Kalki (грядущее уничтожение греха). Shiva (~7000 лет назад) и Krśńa (~3500 лет назад) — не звенья ряда, а Mahásambhúti/Táraka Brahma, приходящие исправить коллективный хаос.

## Key Takeaways

1. Различай sambhúti (творение), vinásha (уничтожение без возврата), prańásha (возврат к источнику).
2. При коллективном кризисе ищи структурное решение (Mahásambhúti), а не частное.
3. Вся эволюция — Его творение: уважай каждый уровень.
4. Управляй по ситуации — как пять лиц Shiva.
5. Никакое творение не лишнее: баланс вселенной зависит от каждого.
