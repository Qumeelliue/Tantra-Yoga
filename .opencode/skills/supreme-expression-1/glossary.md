# Глоссарий — Supreme Expression Volume 1

**А́нанда (ánanda)** — бесконечное счастье, тождественное Brahma; «Sukham Ánantam Ánandam» (Ch 2, 17).

**А́тман (átman / jiivátmá)** — единичное сознание; отражение Puruśa на уме; «Я знаю, что существую» (Ch 2, 13).

**А́шайа (áshaya)** — приют/опора; цепочка приютов ведёт к Нему; Он — приют всех, Сам без приюта (Ch 30).

**А́сакти (ásakti)** — привязанность к ограниченному объекту; противоположность бхакти (Ch 40, 34).

**Ави́дья́ (Avidyámáyá)** — злая сила, затемняющая отражение Сознания; создатель шести врагов и восьми пут (Ch 11).

**Бха́гавата дхарма** — «относящаяся к божественности» человеческая dharma; врождённая склонность к Верховному; факторы vistára/rasa/sevá (Ch 25).

**Бхакти (bhakti)** — преданность как служение Богу («Bhaktir Bhagavato Sevá»); мост между jiiva и Shiva; не молитва и не лесть (Ch 11, 17, 20).

**Биджа-мантра** — семенной звук действия или божества; биджа статичности — «ta» (Ch 41, 42).

**Вае́ра́гья (vaerágya)** — правильное использование вещей и ментальное равновесие среди объектов; НЕ отречение/бегство (Ch 11, 26).

**Ви́дья́ма́йя (Vidyámáyá)** — добрая сила, расширяющая отражение Сознания; связана с ваера́гьей и вивекой (Ch 11).

**Випа́ка (vipáka)** — реакция действия; из-за изменения TSP обычно больше действия («проценты») (Ch 30).

**Гу́ха́ (guhá)** — «Я существую» (тончайший ум); суть духовности скрыта в нём (Ch 13, 24).

**Дагдхаби́джа (dagdhabiija)** — «сожжённое семя»; садхака без своих боли/радости, несущий бремя других (Ch 29).

**Дхарма (dharma)** — «то, что держит»; совокупность поведения (ácárańát dharmah); уровни vastu/jaeva/bhágavata (Ch 24, 26).

**Дхрувасму́рти (dhruvasmrti)** — постоянное памятование «Paramátmá свидетельствует меня»; духовное знание (Ch 7, 8).

**Дхи́ра (dhiira)** — обращающий органы внутрь, стремящийся к Pratyagátmá (Ch 33).

**И́швара (Iishvara)** — контролёр; свободен от kleśa/karma/vipáka/áshaya; владелец восьми оккультных сил (Ch 30, 35).

**И́ш́т́а (Iśt́a)** — личная любовь к Верховной Личности; «истанист» в паре с идеологом (Ch 28).

**Ка́рья Брахма / Ка́рана Брахма** — проявленный (эффект) / причинный Brahma; вместе = Saguńa Brahma (Ch 5).

**Ка́лпана́ (kalpaná)** — воображение; citta принимает форму без танматр; мир — калпана́ Saguńa Brahma (Ch 1).

**Кле́ша (kleśa)** — то, что тревожит ум; четыре типа vrtti (kliśt́a и др.); пять сил Avidyá (Ch 27, 30).

**Космический Ум / macropsychic conation** — вселенная как мысль Космического Ума (Ch 1, 5).

**Кша́ра / Акша́ра / Ниракша́ра** — превращённое / неизменяемое / невоплощённое Сознание (Ch 15, 16).

**Кулакун́д́алини́ (kulakuńd́alinii)** — спящая божественность (coiled serpentine) в основании; пробуждается са́дханой (Ch 22, 41, 42).

**Ли́ла́ (liilá) vs Кри́да́ (kriid́á)** — игра с невидимой/видимой причиной (Ch 14, 18, 36).

**Майя (Máyá)** — оперативный принцип Бога; сила иллюзии физической реальности; непреодолима без укрытия в Нём (Ch 16, 35).

**Ма́нава / махаджана** — человек / практик, прошедший путь (Ch 13).

**Мантра / мантра-чаэтанья / мантра-сиддхи** — звук, медитация на который ведёт к освобождению; пробуждение (параллельность вибраций) / финальная реализация (Ch 23).

**Ма́трика́ ва́рна́с** — 50 причинных матриц (звуков), выводимых из Ом (Ch 41, 42).

**Микрокосм / Макрокосм (Jiiva / Shiva)** — единица / Космос; разница объективная (upádhi), не субъективная (Ch 5, 6).

**Ни́йяти / адр́шт́а** — судьба = накопленные реакции прежних действий; не управляющий фактор (Ch 10).

**Ни́ити (niiti)** — «ведущее к kśema»; мораль-ворота к дхарме; смесь относительного и абсолютного (Ch 24).

**Нитья́нитья вивека** — различение вечного и преходящего (Ch 33).

**Ота / прота йога** — индивидуальная / коллективная связь Puruśottama с единицами (Ch 2).

**Па́па / пу́нья** — действия, вредящие/развивающие других (не «грех» по Библии) (Ch 24).

**Пара́бхакти** — высшая любовь к Para Brahma, дающая блаженство Ему (Ch 21, 35).

**Парама Ра́са / Виша́я Ра́са** — блаженный поток Бога / «вкус» мирских объектов (Ch 14).

**Пра́крти / Пуруша** — квалифицирующий принцип / субъект-сознание; guńas Sa-Ra-Va (Ch 1, 5).

**Пра́кртили́на / Ви́дехали́на** — слияние с феноменальным (джада самадхи) / бестелесное состояние без направления (Ch 34).

**Пра́нидха́на / ану́дхья́на** — сведение 1000 пропенситив в точку / «погоня» за Ним, если Он «уходит» (Ch 16).

**Пратйага́тма́** — всезнающий А́тман, свидетель jiivátma (Ch 33).

**Пратисам́ве́дии Пуруша** — Верховная Отражающая Пластина (Ch 15).

**Пурашчара́на** — оживление мантры через Mahákaola (Ch 23).

**Ра́га́тмика́ бхакти** — высшая преданность: любить, чтобы дать Ему блаженство (Ch 35).

**Са́дху / дурджана** — чей контакт делает других хорошими / духовно разлагающий (Ch 24).

**Садвипра** — духовный революционер, лидер в yama/niyama (Ch 27).

**Сага́на Брахма / Ниргу́на Брахма** — квалифицированное / неатрибутированное Сознание (Ch 1, 2).

**Сама́дхи** — остановка ума при несимволизируемом; шесть стадий от sálokya до nirvikalpa (Ch 4, 22).

**Самска́ра** — реактивный моментум; невыраженный психический символ (Ch 4, 29).

**Са́м́бху́ти / вина́ша / прана́ша** — творение / разрушение без возврата / возврат к источнику (Ch 19).

**Сара́ва / Пара́ра́са** — собственный поток микрокосма / поток Космоса (Ch 25, 27).

**Сету (bhakti-rúpa setu)** — мост преданности через реку bhava (Ch 20).

**Та́нтра** — освобождение от статичности + расширение; духовная наука (Ch 41, 42).

**Танма́тра** — тонкая форма получения объекта (звук/касание/образ/вкус/запах) (Ch 1, 2).

**Та́ттвы (бхуты)** — пять рудиментальных факторов (эфир/воздух/огонь/вода/земля) (Ch 1, 2).

**ТТТ (TSP: время-пространство-личность)** — относительные факторы, ограничивающие знание и действия (Ch 7, 8).

**Упа́дхи** — различительный атрибут/объективный аналог единицы (Ch 6).

**Хара** — «похититель грехов»; Akśara (Ch 16).

**Шабда** — звук; первый вибрационный поток Brahma (Ch 23).

**Шравана / манана / нидидхья́сана** — слушание / размышление / отдача «Я» (Ch 23).

**Яма-нияма** — кодекс духовной дисциплины (обязателен без исключений) (Ch 26).
