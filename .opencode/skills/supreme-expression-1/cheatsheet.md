# Читшит — правила решений по Саркару (Supreme Expression 1)

## Космология и творение

| Ситуация | Правило |
|---|---|
| Найти причину системы/мира | Ни один относительный фактор (время/природа/судьба/случай/материя) — не первопричина; причина — Верховное Познание |
| Мир «грубый» | Это мысль-волна Saguńa Brahma; относительная истина (не Satya, не ложь) |
| «Мёртвая» материя | Сознание спит в ней под влиянием Prakrti; не считай её безжизненной |
| Восприятие объекта | citta принимает форму объекта (с танматрами или без) — не «картинка на сетчатке» |
| Творение закончится? | Нет: число единичных сознаний бесконечно |

## Знание и прогресс

| Ситуация | Правило |
|---|---|
| Оценить источник знания | Проверь на TSP-зависимость: устареет → не настоящее знание; неизменно (от А́тмана) → настоящее |
| Гордец знанием | «Путаница знания», а не знание — жди провала |
| Хочешь настоящего прогресса | Поднимайся по лестнице: физическое → psychic → spirituo-psychic → духовное (dhruvasmrti) |
| Медитация | Прими позицию объекта: «Paramátmá видит меня», не «я вижу Его» |

## Dharma и поведение

| Ситуация | Правило |
|---|---|
| Оценить «правила» | Три уровня: vastu (автомат), jaeva (автомат), bhágavata (сознательный выбор) |
| Niiti vs dharma | Niiti — ворота (dos+don'ts); dharma — дом (только «делай»); мораль без практики — паспорт |
| Оценить pápa/puńya | Развиваешь других = puńya; вредишь = pápa (не «грех по Библии») |
| Выбрать «доброго/злого» | Результативная праведность: баланс, а не сырой процент |
| Направление желаний | Одна цель, одна база, одно имя; несколько — искажают пара́ |

## Бхакти и спасение

| Ситуация | Правило |
|---|---|
| Молитва о вещах/спасении | Не бхакти (просьба/лесть бесполезны); бхакти = «звать с преданностью», служение |
| Объект идеации | Только Nirakśara (третья сущность); kśara/akśara — нет |
| Мотивация преданности | Различай ásakti (получить) и bhakti (слиться); высшая — rágátmiká (дать Ему блаженство) |
| Карма-реакции | Не устранимы (золото/железо — цепи); меняется только срок; не «компенсируются» добром |
| Страх грехов | Не медитируй на грех — идеируй на Отца; Он Отец и грешников |

## Са́дхана и Tantra

| Ситуация | Правило |
|---|---|
| Подавлять желания? | Нет — канализируй/сублимируй (Vaerágya = правильное использование) |
| Мантра без резонанса | Бесполезна (миллионы повторений ≠ mantra caetanya); нужна параллельность вибраций |
| Стадии samádhi | Sálokya → sámiipya → sáyujya → sárúpya → sárśt́hi → nirvikalpa (kaevalya) |
| Пробудить божественность | Kulakuńd́alinii из múládhára к sahasrára (пинеальная); нужна помощь гуру/Бога |
| Оккультные силы как цель | Не проси их: «хочу Тебя, не Твои силы» |

## Общество и мир

| Ситуация | Правило |
|---|---|
| Лидерство/власть | Лидеры — установленные в yama/niyama (sadvipras); энергия слепа без интеллекта |
| Расширение на конечном | Бьётся о границы (конфликты, насилие) — направь на Бесконечное |
| Равенство | Не по количеству, а по качеству (са́дхане); касты — против единства |
| Кризис эпохи | Ожидай поляризации; восстановление = возврат на место (saḿsthápana), не просто наказание |
| Оценка личной силы | Bala = использование имеющейся силы, не запас; белка = Гару́да при полной отдаче |

## Быстрые сигналы («tells»)

- Видишь просьбу о «плодах» в молитве — это не бхакти, а сделка.
- Говорит «это нельзя оспаривать» — блокирует прогресс; вероятно, защита, не истина.
- Знание «Lahore — столица» из книги 30-летней давности — образец дефектного (TSP) знания.
- «Я грешник, спаси» — медитация на грех; дефектный подход.
- Спор «что первично» (время/природа/случай) — тупик: причина вне относительности.
- Действие без преданности — золотая/железная цепь; с преданностью — мост.
- Расхождение внутреннего и внешнего «Я» растёт — дефект цивилизации, лечи единением.
