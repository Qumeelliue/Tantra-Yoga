# Читшит — Táttvika Praveshiká

| Ситуация | Правило |
|---|---|
| Почему ум ищет счастье | Ум счастлив в среде, совместимой с его самскарами; иная среда невозможна для существования |
| Что такое dharma | Свойство, «удерживающее в существовании» (dhr); не религия; огонь должен жечь |
| Что такое svabháva | Свой склад ума; меняется, индивидуален; dharma — неизменна и обща |
| Чем занят а́тман | Не действует; только вдохновляет (притяжение магнита); очищение — работа самого ума |
| Как создан универсум | Мысль-волны citta Брахмы (Saguńa Brahma); saiṋcara → pratisaiṋcara; конец — истощение самскар |
| Какой гуны преобладает в Брахме | Sattvaguńa (благо всех); rajoguńa вторым; tamoguńa незначителен |
| Dhárańá vs Dhyána | Dhárańá: внешний объект, прерывиста, статична; Dhyána: внутренний, непрерывна (поток масла) → samádhi |
| Что нужно для samádhi | Растворение ума; ávesha (самогипноз) — только помощник |
| Сколько кош и лок | 5 кош в единичном (annamaya…hirańmaya), 7 лок космического ума (Bhúr…Satya) |
| Рай/ад существуют? | Нет: после смерти ума нет; самскары — объект а́тмана |
| Что такое Satya | Неизменна, безгранична, вне времени/места/личности; относительное (размер луны, история) — asatya |
| Карма: немедленная реакция | Не конечный результат; корень (múlakárańa) — самскары; карма и кармафала — волна |
| Гипноз / «духи» / планшетка | Чисто ментальные феномены участников; ненадёжны |
| Единство общества | Общий идеал (Brahma с 5 лет) + бескастовость + коллективные функции + запрет смертной казни |
| Наказание в Марге | Отстранение от функций на срок или «привести 10 человек на правый путь»; без метки и без остракизма |
| Дисциплина | Законы рациональны и изменяемы; «разум после послушания» |
| Соц. безопасность | Нет несправедливости (экономической/половой/расовой); работа уборщика почётнее зависимости |
| Мир | Психическое равновесие; садхана даёт, суеверие разрушает |
| Artha vs Paramártha | Artha — временное облегчение; Paramártha (через садхану) — постоянное (atyantikii nivrtti) |
| Власть по классам | Сила → интеллект → деньги → рабочие; AM не отдаёт власть классу |
| Безклассовое общество | Результат практики всех четырёх классовых навыков каждым (универсальная пригодность) |
| Мир реален? | Да: мир — проявление Верховного; не беги от мира |
| Кому доступны практики | Всем: без ограничений по классу, касте, полу, семейному статусу |
| Проверка учения | Три вопроса: а́тман? мир? Бог? + тест на логическую замкнутость |
