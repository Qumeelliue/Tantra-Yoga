# Читшит — правила решений по неогуманизму Саркара

## Привязанности (сантименты)

| Ситуация | Правило |
|---|---|
| Определить природу привязанности | Спроси про радиус: территория (geo) / группа (socio) / человечество (human) / все существа (Neohumanism) |
| Больше круг = лучше? | Нет: гуманизм = socio-sentiment maximitis, «увеличенный национализм», та же болезнь |
| Интернационализм | Не решение: признаёт нации, живущие за счёт друг друга |

## Психика

| Ситуация | Правило |
|---|---|
| Как движется человек/группа? | Инстинкт (врождённое) / сентимент (слепой бег) / рациональность (взвешивание) |
| Сентимент вместо логики | «Стопроцентная вероятность большой опасности»; дальше логику заменит суеверие |
| Слушать книги и людей | Не автоматически: сначала рациональная проверка (siddhánta), потом совесть (viveka) |

## Противоядия

| Ситуация | Правило |
|---|---|
| Борешься с geo-сантиментом | Изучение + рационалистическая ментальность |
| Борешься с socio-сантиментом | Sama-samája tattva + прото-психо-духовность |
| Псевдогуманизм | Пробуждённая совесть; только стадия «миссия» обезоруживает стратегию |
| «Буду добрым, но молчать о несправедливости» | Телега впереди лошади; голос против зла обязателен |

## Эксплуатация

| Ситуация | Правило |
|---|---|
| Найти корень эксплуатации | Психологическая (комплексы страха/неполноценности) — фундамент всех видов |
| Метод эксплуатации | Хитроумная стратегия = psycho-economic; грубая сила = politico-economic |
| Культурная | Pseudo-culture ломает «хребет»; контроль культуры = рабство |
| «Пророк говорит голосом неба» | Догма; проверяй на спутниковые группы и выгоду |
| Лидер сменил сентимент после разоблачения | Метаморфозная стратегия, а не эволюция |

## Ценности

| Ситуация | Правило |
|---|---|
| Существо без пользы человеку | Экзистенциальная ценность остаётся: право жить не зависит от пользы |
| Строишь/вырубаешь среду обитания | Предусмотри альтернативы обитателям, иначе баланс миров рушится |
| Оценить стадию зрелости | Культ → суть → миссия; только в миссии псевдогуманизм бессилен |
| Оценить идею/теорию | Фундамент = благополучие всех на базе sama-samája tattva; иначе — метеор |

## Быстрые сигналы («tells»)

- «У нас обязательно должна быть X-промышленность» без сырья → гео-экономический сантимент.
- «Наша вода/земля — самая святая» → гео-религия; проверь фактами.
- Проповедь мира с «порохом в кармане» → первоклассное лицемерие.
- «Давайте постепенно» против явного зла → реформизм, сохраняющий дефекты.
- Помощь с оттенком «мы вас жалеем» → комплекс превосходства, спутниковые группы.
- Не признаёт ошибку из-за престижа → эго убивает интеллект.
- «Могу ли я?» → «Почему бы нет, конечно, можем!».
