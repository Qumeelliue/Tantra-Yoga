# Глоссарий — Prout in a Nutshell Volume 2 Part 7

**Анушасана (anushásana)** — «shásana ради блага»: дисциплина для социального благосостояния, адаптирующаяся к времени, месту, личности (Ch 2).

**Бха́рья (bháryá)** — жена, лишённая социальных и религиозных прав; «Puttrárthe kriyate bháryá» — «жена взята, чтобы родить сыновей» (Ch 2).

**Ваешья (vaeshya)** — класс накопителей; цвет — жёлтый; деньги = жизненная сила; «crooked intellect» без духовного сознания (Ch 3).

**Варна (varńa)** — «цвет», социальный класс по преобладающему психическому цвету: шудра — чёрный, кшатрий — красный, випра — белый, ваешья — жёлтый; не наследственный (Ch 1).

**Викра́нти (vikránti)** — контр-эволюция; **prativiplava** — контр-революция (Ch 2, 3).

**Випра (vipra)** — интеллектуал; цвет — белый; «satanic vipras» — эксплуататоры, благородные — sadvipras (Ch 2).

**Гати/агати (gati/agati)** — движение / неподвижность как относительные состояния (Ch 1).

**Готра (gotra)** — клан; **pravar** — линия предков; **gotratyága** — выход из клана (Ch 2).

**Джайя (jáyá)** — жена с социальными правами, но без религиозных; **kalatra** — жена без обоих прав (Ch 2).

**Дхарма (dharma)** — «система для достижения Высшего», одна для всех, рациональна, объединяет; ≠ религия (Ch 5, 6).

**Ка́ранья-па́уза / systaltic (systolic) движение** — пульсирующее движение: пауза (сжатие) → импульс → манифестативная пауза (проявление) (Ch 1, 10).

**Катра (kháńd́a pralaya)** — «частичное уничтожение»: микросмерть единицы после каждого выдоха (Ch 1).

**Ка́тра́н (kránti)** — эволюция; **viplava** — революция; ускорение коллективной волны (Ch 1).

**Кшатрий (kśatriya)** — класс борцов; «борьба — их дхарма»; цвет — красный; «might is right» (Ch 1).

**Лингам (linga)** — фаллический символ увеличения численности (изобретён кшатриями; философская интерпретация випра — вымысел) (Ch 1).

**Меланин** — пигмент кожи; больше — защита от жара; объясняет «расовые» различия (Ch 4).

**Парама Пуруша (Parama Puruśa)** — Высшее Сознание; все языки — Его языки; все — Его дети (Ch 5, 6, 9).

**Пиннаклед интеллект (agryábuddhi)** — «вершинный интеллект», движение по прямой, вмещает все варны; пробуждение — у благородных випра (Ch 2).

**Практическая ценность вещей (Vaeshya Age)** — ниже, чем в других эпохах: блага инертны; стагнация — проклятие (Ch 3).

**Псевдо-ваешьи (pseudo-vaeshyas)** — випры с экономическим интеллектом под покровительством ваешьи; без качеств обоих классов (Ch 3).

**Религия (religion, majhab)** — множественна, делит; основана на страхе, психо-сентименте, ритуале, традиции (Ch 5, 6).

**Са́дхана (sádhaná)** — устойчивая духовная практика; в ней тоже есть пауза и скорость (Ch 10).

**Са́ма́джа чакра (sámája cakra)** — социальный цикл: шудра → кшатрий → випра → ваешья → революция (Ch 1).

**Са́тван-випра (sadvipra)** — духовный революционер; для него ценность человеческой жизни выше всех (Ch 8).

**Скриптура (shástra)** — то, что «дисциплинирует, ведёт к духовности и высшему благу»; скриптуры, душащие общество, не принимать (Ch 6, 8).

**Социальные ценности (social values)** — ценность по социальной ответственности (короли, мудрецы) (Ch 8).

**Сурплус-труд (surplus labour)** — относительная безработица в недоразвитых регионах; местный приоритет занятости (Ch 7).

**Трифарнос существование** — физический + ментальный + духовный потоки человека (Ch 8).

**Трудовое равенство** — труд всех групп (фермеров, врачей, ремесленников) равноценен в экономике (Ch 7).

**Хьюман кардинал стратум** — точка встречи психо-духовного и духовного слоёв; база кардинальных принципов (Ch 8).

**Хьюман кардинал принциплз** — человеческие ценности по существу (а не по заслугам); предшествуют социальным (Ch 8).

**Ча́турварника (cáturvarńika)** — четырёхклассовая система; «социальное колесо» мира (Ch 1).

**Шре́штхи (shreśt́hii)** — «человек богатства» — титул, купленный ваешьей у випра (Ch 3).

**Шудра (shúdra)** — работник; психология страха и физического удовольствия; настоящее; «survival of the fittest» (Ch 1).

**Экономическое землевладение (economic landholding)** — владение, где output > input; размер зависит от плодородия, климата, управления (Ch 7).

**Эксплуатация** — «фундаментальная болезнь» общества; убрав её, уберём делителей (Ch 6).

**Язык, 6 стадий выражения** — Pará (семя), Pashyantii (росток), Madhyámá (картина), Dyotamáná (вибрация), Vaekharii (голосовые связки), Shrutigocará (вокализация); различие — только в последних двух (Ch 6).

**Agryábuddhi / катра — см. Пиннаклед интеллект / Ка́тра́н.**
