# Читшит — правила решений по Саркару (Prout 7)

## Социальный цикл и власть

| Ситуация | Правило |
|---|---|
| Кто сейчас у власти | Спроси: какой ресурс незаменим? сила (kśatriya) → интеллект (vipra) → деньги (vaeshya) → число работников (shúdra) |
| Класс доминирует | Он эксплуатирует остальных; смена доминанта проблему не решает |
| Ваешьи у власти | Ожидай: измы (каста, коммунализм, национализм) финансируются их деньгами; «разделяй и властвуй» |
| Конец эпохи | Доминант «по имени только» теряет власть; невыносимая эксплуатация → шудра-революция (после тщательной подготовки) |
| Определить «возраст» эпохи | В начале — ещё social spirit; в конце — только эксплуатация (ваешьи перестают принимать совет) |

## Движение, пауза, динамика

| Ситуация | Правило |
|---|---|
| Спад в работе/медитации/учёбе | Пауза = стадия ассимиляции, сбор импульса; не паникуй |
| Прогноз после «застоя» | Оцени качество предыдущей паузы — она определяет скорость следующей фазы |
| Пессимизм о периоде | Пессимист не изучал историю; пауза готовит подъём |
| Страх перед технологией | Творец сильнее творения; реальная угроза — «демоны в человеческом обличье», не вещь |

## Единство и разделители

| Ситуация | Правило |
|---|---|
| Объединять людей | Поощряй аспекты единства, обескураживай аспекты разъединения; не силой |
| Различия (еда, язык, религия, одежда) | Не устраняй силой — растворяй естественным сближением и психологией |
| Вредная для человечества идеология | Не терпима; сопротивляться «железной рукой» |
| Спор «dharma или религия» | Dharma объединяет и рациональна (только единичный ум); религия делит (страх, ритуал, традиция) |
| Подавление языка | Никогда; «все языки — языки Parama Puruśa»; подавление = катастрофа |
| Национальные границы/паспорта | Петти-национализм вреден; национальность меняется за ночь — это фикция |

## Аграрная экономика

| Ситуация | Правило |
|---|---|
| Доля населения в сельском хозяйстве | 30–45% — здорово; 75% — опасно |
| Реформа земли | Экономическое владение (output > input), размер по региону; раздача «по куску» — petit bourgeoisie |
| Кооператив | Три фактора: мораль, сильный надзор, добровольное принятие; вводить фазами |
| Посредники в сельском хозяйстве | Устранить («agricultural capitalists» — паразиты) |
| Раздел продукции кооператива | 50% — зарплата труду, 50% — дивиденды владельцам; доля труда не падает |
| Занятость | Сначала местным; новые программы — только после спроса на труд |
| Налог | Процент урожая (не деньгами); государство хранит запас на случай бедствий |

## Ценности и правосудие

| Ситуация | Правило |
|---|---|
| Оценить решение против человека | Human value предшествует social value; институт служит человеку, не наоборот |
| Определить вину/добродетель | Что блокирует движение к высшему — вина; что облегчает — добродетель; они относительны (время, место, личность) |
| Наказание | Для исправления: сладкие слова → жёсткие → предупреждение → гуманные меры; только нарушитель; без вечного клейма |
| Оценить достоинство | По существу, не по посту/деньгам («Yasyástivittam...» — критика ваешьи-оценки) |
| Кого ставить к власти | Моралистов + универсалистов + практикующих садхану; судить по результату, не по речам |

## Быстрые сигналы («tells»)

- Видишь «благотворительность» ваешьи — скорее всего инвестиция в сохранение эксплуатации, не альтруизм.
- Конфликт «религии» с логикой («в религии нет места разуму») — маркер доктрины, а не dharma.
- Кто-то объявляет «чистоту крови»/превосходство расы — научно несостоятельно: «кровь всегда чиста».
- Оружие/машина внушают страх сильнее, чем люди-злонамеренники, — страх перепутан: угроза в человеке, не в вещи.
- «Земля тем, кто пашет» как лозунг — ведёт к petit bourgeoisie; решает производство, не владение.
- Эпоха кажется «мёртвой» — проверь паузу: возможно, идёт сбор импульса для следующей скорости.
