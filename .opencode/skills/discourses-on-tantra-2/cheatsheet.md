# Читшит — правила решений по Саркару (Discourses on Tantra Vol. 2)

## Суть Тантры

| Ситуация | Правило |
|---|---|
| Что такое Тантра | Расширение (tan) + освобождение от косности (ta+trae) |
| Признак настоящей практики | Есть борьба: «где нет борьбы, нет садханы» |
| Практика vs теория | 99% практики, теория вторична |
| Цель садханы | Пробудить и поднять кулакундалини к сахасраре |
| Проверить идею | Расширяет ли ум? Направлена ли к desideratum? |

## Йога и стадии

| Ситуация | Правило |
|---|---|
| Определение йоги | Слияние jiivátmá с Parámátmá (не подавление) |
| «Подавление пропенсити» (Патанджали) | Отвергнуто: подавленное действует внутри |
| Уровень человека | pashu (мысли≠слова≠действия) → viira → deva (всё совпадает) |
| Три стадии садханы | Shákta → Vaeshnava → Shaeva; не пропускать |
| Высшая мотивация | Ragátmiká bhakti |

## Силы и цели

| Ситуация | Правило |
|---|---|
| Сила/техника служит благу всех | Vidyá Tantra — правильный путь |
| Сила/техника эксплуатирует людей | Avidyá Tantra — деградация |
| «Сверхъестественное» явление | Сверхъестественного нет — ищи механизм и виновника |
| Шесть действий Vidyá | Интеллект, пропенсити, смирение, дхарма, самоотдача, shántikarma |

## Равенство и общество

| Ситуация | Правило |
|---|---|
| Кто достоин вершины | «Минимальная квалификация — человеческое тело» |
| Касты и gotra | Отменены; все в Shivagotra |
| Цель в борьбе с неравенством | vijaya (уничтожить корень), не jaya |
| Компания | Satsang ведёт к освобождению; плохая — к узам |

## Передача и мотивация

| Ситуация | Правило |
|---|---|
| Передать знание | diipanii (свет) → mantragháta (пробуждение) → mantra caetanya (смысл) |
| Настоящий гуру | Физический+психический+духовный уровни; и наказать, и миловать |
| Мантра без смысла | Бесполезна; нужна идеация |
| Успех проекта | 6 секретов: решимость, шраддха, наставник, равновесие, самообладание, ресурсы |

## Быстрые сигналы («tells»)

- Деятельность «дай-дай» без борьбы — не садхана.
- Хвастают кастой/статусом — рабство у Веды.
- Система судит «phat» (сгоряча) — нужна глубина.
- «Призрак» = живой манипулятор + страх аудитории.
- Механизм «чуда» не объясним — вероятно Avidyá.
- Практика без направления оттянутого внимания — бури.
- Радость вместе (lalita) + решительные действия (tándava) — здоровый путь.
- Ущемление женщин/меньшинств — противоречит Тантре.
