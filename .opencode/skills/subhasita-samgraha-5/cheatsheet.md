# Читшит — правила решений (Subháśita Saḿgraha Part 5)

## Садхана и свобода

| Ситуация | Правило |
|---|---|
| Понять смысл садханы | Вернуть исходную чистоту (золото), переплавив искажения; не уничтожать их |
| Оценить «скованность» | Проверь 8 оков (родословная, тщеславие культуры, ложный престиж, ненависть, сомнение, стыд, страх, злословие) + 6 врагов |
| Менять поведение | Меняй среду/образование коллективно — иначе даже честный не устоит |
| «Я честен, зачем садхана?» | Мораль — старт, не финиш; без идеации мораль рухнет |
| Оценить знание/действие | Без преданности («соли») они пресны; преданность — главное |

## Микрокосм и Макрокосм

| Ситуация | Правило |
|---|---|
| Цель микрокосма | Превращай прея (конечное удовольствие) в шрея (космическое благо) — пузырёк станет океаном |
| Сделать «что-то втайне» | Невозможно: всё отражается в Космическом уме мгновенно |
| Громко повторять мантры | Низшая форма; высшая — умственная (ма́насик) |
| Обвинять Брахму в частичности | Чисть зеркало ума; Он притягивает всех, кроме «ржавых» |
| Два дерева-птицы | Одна ест плоды (переживает карму), другая — свидетель; дживатман не «грешен» сам |

## Эволюция и творение

| Ситуация | Правило |
|---|---|
| Тонкость и расширение | Чем тоньше — тем шире и труднее воспринять; от грубого к тонкому |
| Пять факторов | Эфир(1 танматра)→воздух(2)→свет(3)→жидкость(4)→твёрдое(5); тонкость убывает |
| Читать священные тексты | Бери суть по рациональной проверке; отбрось мифы (кожура манго) |
| Поклоняться деватам | Допустимо ради artha, не ради парамартхи |
| Конец вселенной | Тепловой смерти не будет: джадаспхота перераспределяет энергию |
| Космический звук | По слоям ума: сверчок→колокольчики→флейта→гонг→пчёлы/океан→Ом |

## Форма, пол, дхарма

| Ситуация | Правило |
|---|---|
| Формы vs сущность | Ювелир видит золото, не серьги; за формами — одна сущность |
| Сделать копию Брахмы | Невозможно: нужен «конечный и бесконечный» объект сравнения |
| Религия vs дхарма | Дхарма рациональна и едина; религия — слепая вера и множественность |
| Уважение ко всем религиям | Не платформа; единая дхарма без дискриминации |
| Пол и садхана | Нет различия; пол = следствие притягивающих/притягиваемых сил самскар |
| Кто реинкарнирует | Самскары, а не Атман (Атман — свидетель) |

## Быстрые сигналы («tells»)

- «Не спорь, просто верь» → религия, а не дхарма (Ch 4).
- «Я не ворую — зачем мне это» → морализм как маска без идеации (Ch 1, 2).
- Показное громкое повторение мантр → низшая форма джапы (Ch 2).
- «Молокас сакрален, сахар нет» → статичность против науки (Ch 3).
- Спор «Хари или Аллах» → плен статики, один Брахма (Ch 4).
- Глиняные «богини» и дорогие ритуалы → коммерция веры, не садхана (Ch 2).
