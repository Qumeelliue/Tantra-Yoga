# Глоссарий — Subháśita Saḿgraha Part 5

**Авидьямайя** — Майя с доминированием статического принципа; причина огрубления и мира (Ch 3).

**Акустический корень** — звуковая суть вибрации девата; совокупность корней = Омкара (Ch 3).

**Анулома / пратилома** — нисходящий (сознание→махаттаттва→...) / восходящий (садхана) порядок метаморфозы (Ch 1).

**Артха / парамартха** — психо-физическое (мгновенное облегчение, напр. еда) / духовное (полное прекращение тройных страданий) (Ch 1).

**А́с́т́апаша** — восемь оков: родословная, тщеславие культуры, ложный престиж, ненависть, сомнение, стыд, страх, злословие (Ch 1).

**Бхава** — resolve/воля к рождению; усиливает цикл перерождений (Ch 4).

**Бхакти** — преданность; «соль» знания и действия; самая важная из трёх (Ch 1, 4).

**Бхута-шуддхи** — отвод ума от грубого к тонкому; часть пратьяхара-садханы (Ch 3).

**Вибхаджани шакти** — притягиваемая сила; доминирование → мужское тело (Ch 4).

**Видьямайя** — Майя с доминированием сентивного; ведёт к бессмертию/сознанию (Ch 3, 4).

**Девата** — вибрационная эманация Брахмы со своим акустическим корнем; конечная, не равна Брахме (Ch 3).

**Джадаспхота** — взрыв предельно сгущённой структуры → обратно в эфир; исключает «тепловую смерть» (Ch 3).

**Джапа** — повторение: ваканик (громко), упам́шу (шёпотом), ма́насик (умом — высшая) (Ch 2).

**Дхарма vs религия** — дхарма сокрушает препятствия, рациональна, едина; религия требует слепой веры, множественна, эксплуатируется (Ch 4).

**Кама / према** — любовь к относительным объектам (ограниченная према) / сильное влечение к Высшему (даёт мукти) (Ch 4).

**Кевала-бхакти (парабхакти)** — исключительная преданность; устраняет I-чувство навсегда → мокша (Ch 1, 4).

**Кшара / акшара** — изменяемые эманации / неизменяемый Брахма (Ch 3).

**Майя / Пракрити** — почти синонимы; Пракрити = равновесие трёх гун; Майя = рабочее состояние (Ch 3).

**Ма́насик-джапа** — умственное повторение; никем не заметно (Ch 2).

**Мукти / мокша** — освобождение (слияние в Сагуна) / спасение (слияние в Ниргуна) (Ch 3, 4).

**Омкара (пранава)** — совокупность акустических корней; «семя космоса» (Ch 3).

**Пратима** — копия/образ; для Брахмы невозможна (нет «конечного и бесконечного» объекта сравнения) (Ch 4).

**Пратисан̃чара** — интроверсия/возврат к сознанию; инициация после возникновения пра́н̃ы (Ch 3).

**Пурушасу́кта** — гимн: Сахасраширша Пуруша (бесчисленные головы/глаза/ноги) (Ch 2).

**Рипу** — шесть врагов: гнев, жадность, похоть, гордость, зависть, очарование (Ch 1).

**Самскара** — реактивный момент поступка; реинкарнируются самскары, не Атман (Ch 4).

**Самуйоджани шакти** — притягивающая сила; доминирование → женское тело (Ch 4).

**Сан̃чара** — экстраверсия/огрубление, доминирование тамаса (Ch 3).

**Сарватомукха** — «лики во все стороны»; Брахма во всех направлениях (Ch 1).

**Сатсанга** — хорошая компания (Ch 3, 4).

**Свадхйайа** — изучение хороших книг (Ch 3).

**Танматра** — инференциальная волна; количество растёт с огрублением фактора (1–5) (Ch 3).

**Шрея / прея** — космическое благо / конечный объект удовольствия (Ch 2).
