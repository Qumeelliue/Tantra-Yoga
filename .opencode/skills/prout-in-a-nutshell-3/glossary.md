# Глоссарий — Prout in a Nutshell Volume 1 Part 3

**Born criminal (преступник по природе)** — человек с дефектом тела/желёз, «пациент», требующий лечения, а не наказания (Ch 2).

**Время-место-личность (time, space, person)** — относительные факторы, определяющие добродетель/порок и мораль (Ch 1, 2).

**Вседозволенность (license)** — злоупотребление свободой; противопоставляется liberty и разрушает социальную структуру (Ch 1).

**Ваешья (vaeshya)** — бизнесмен/торговец с капиталистическим менталитетом; «утончённый преступник», pishácavat (Ch 3). Также класс эпохи производства (Prout 1).

**Вичара (vicára)** — правосудие: «особый ментальный процесс установления истины» (Ch 2).

**Викшубдха (vikśubdha)** — «недовольный, раздражённый»; богатый класс при частном бизнесе под госконтролем (Ch 3).

**Вритти (vrtti)** — занятие; то, что поддерживает существование: физическое (профессия), ментальное (психическая pabula), духовное (блаженство) (Ch 3).

**Групповизм (groupism)** — склонность людей группироваться по роду занятий; преодолевается высокими идеалами (Ch 3).

**Джна́на виста́ра / виджня́на са́дхана́ (jñána vistára / vijiñána sádhaná)** — осознание прав во всех сферах / полное осуществление этих прав (Ch 1).

**Давление обстоятельств (circumstantial pressure)** — принуждение, вибрирующее грубый ум; единственный инструмент, действующий на корыстных (Ch 1, 2).

**Добродетель (puńya)** — то, что расширяет ум и приближает вселенную к себе; относительно (время/место/личность) (Ch 2).

**Кармава́да (karmaváda)** — доктрина действия/реакции Гиты; Саркар отвергает её использование для оправдания бедности (Ch 1).

**Корректирующие меры (corrective measures)** — восстановительные меры вместо карательных; единственный допустимый тип реакции на преступление (Ch 2).

**Лакшми / Сарасвати (Lakśmii / Sarasvatii)** — богиня богатства / искусства; «Sarasvatii должна быть освобождена из рабства Lakśmii» — искусство не должно зависеть от капитала (Ch 3).

**Па́па (pápa)** — порок; относительно (время/место/личность, религия) (Ch 2).

**Панчаят (panchayat)** — сельский совет; система арбитража, критикуемая Саркаром за слабую компетенцию; члены должны назначаться, только юристы (Ch 3).

**Пи́ша́кават (pishácavat)** — «гнилые»: ваешьи-«вампиры», высасывающие кровь общества (Ch 3).

**Преступники: по природе / привычке / среде / бедности / слабости** — пять категорий преступников Саркара для выбора меры (Ch 2).

**Рипу (ripu; śad́aripu)** — шесть врагов ума: káma (желание), krodha (гнев), lobha (алчность), mada (тщеславие), moha (ослепление), mátsarya (ревность) (Ch 2, 3).

**Сатьяграха (satyágraha)** — «человеческий призыв»; «интеллектуальный метод использования силы» через давление обстоятельств (Ch 1).

**Са́дхана́ (sádhaná)** — духовная практика; источник силы для реализации идеалов; «sadhana of the Supreme» (Ch 1).

**Садху (Sádhu)** — «честный»; имя, присоединявшееся к именам ваешьев в древности для напоминания об идеале честности (Ch 3).

**Свобода — право рождения (birthright)** — свобода не дар; достигается борьбой; права признаются, а не даруются (Ch 1).

**Тюрьма как больница (prison as hospital)** — «тюрьмы не для наказания, а для лечения болезни»; corrective centre; начальник — учитель-психолог (Ch 2).

**Универсальный уголовный кодекс (universal penal code)** — единый кодекс для всего человечества, принятый глобальной организацией (Ch 2).

**Частные интересы (vested interests)** — корыстные группы, эксплуатирующие невежество во всех сферах (Ch 1).

**Шатама́ри / сахасрама́ри (śat́amárii / sahasramárii)** — «убивший сотню / тысячу»: сарказм о врачах, «квалифицирующихся» ценой жизней (Ch 3).

**Шудра / кшатрия / випра / брахман** — классы (Prout 1); в Ch 1-3 фон для анализа эксплуатации и ваешьев.
