# Читшит — правила решений по Саркару (Prout 3)

## Социальная справедливость

| Ситуация | Правило |
|---|---|
| Оценить права группы (женщины, меньшинства) | Раздели «отняты» и «не признаны»; права признаются, не даруются; свобода ≠ вседозволенность |
| Достижение свободы | Свобода — право по рождению, достигается борьбой, не дарится |
| Равенство прав | По умолчанию равны все; исключения: стимулирование полезной обществу деятельности и временная награда за выдающийся вклад; базовые нужды — всем без исключений |
| Найти эксплуататора | Проверь vested interests: кто зарабатывает на невежестве/голоде/суеверии; монополия на ресурсы недопустима |
| Зарплата | Потребности семьи + запас на случайности, «не пенни больше»; неиспользуемые деньги теряют ценность |
| Оценить «образованность» | Узнал много + запомнил много + применил в жизни; спесь и диплом без применения = банкротство |

## Изменение общества

| Ситуация | Правило |
|---|---|
| Грабёж богатых («Робин Гуды») | Не работает: общество попрошаек, семя капитализма живо, насилие рождает насилие |
| Только ненасилие/сатьяграха | Гандизм — утопия; сатьяграха = давление обстоятельств, «интеллектуальный метод силы» |
| Коммунизм силой | Хуже грабежа: подавляет самовыражение, ум взорвётся |
| Менять общество | Человеческий призыв + давление обстоятельств + моральное воспитание + духовная сила |
| Национализация собственности | Не грабить и не платить всем: пенсии/единовременные слабым, работа по способностям сильным; даже эксплуататор — человек |
| Социальный прогресс | Коллективен: мозги + руки + ноги; усилие Ханумана и белки равноценны |

## Правосудие

| Ситуация | Правило |
|---|---|
| Реакция на преступление | Корректирующие меры, не карательные; термин «penal system» удалить |
| Сомнение в приговоре | Наказания нет — лучше простить виновного, чем наказать невиновного |
| Смертная казнь | Отвергнута: «срубить голову от головной боли» |
| Причина преступления | Классифицируй: природа→лечи, привычка→кодекс+воспитание, среда→убери из среды, бедность→экономика/революция, слабость→осторожность |
| Дурная компания | Влияет на всех 7–70 лет; 99% ошибочно считают себя невосприимчивыми |
| Мораль/юридический кодекс | Конфликт кодексов → моральный кодекс главенствует; кодекс должен быть динамичен |
| Определение имморального | Эксплуатация другого ради личной/групповой выгоды или лишение права на самосохранение |
| Кодекс для всех | Универсальный уголовный кодекс; конституция мира — от глобальной организации |

## Экономика и профессии

| Ситуация | Правило |
|---|---|
| Владеть землёй | Вся земля — общая собственность; использование — местная власть через кооперативы производителей |
| Распределять еду/одежду/топливо | Кооперативы потребителей; бизнесменам — только несущественное |
| Производить лекарства/стройматериалы | Автономные органы / государство; не бизнесмены |
| Банки | Не в руках бизнесменов |
| Национализация / частный бизнес под госконтролем / высокие налоги | Всё обречено; средний путь — баланс общества |
| Кооператив реален, если | Общая экономическая структура + одинаковые потребности + близкие рынки |
| Спекулятивные рынки | Немедленно закрыть; свободная мировая торговля |
| Врач/юрист/артист | Служение, не бизнес; коррупция служителя опаснее преступления |
| Искусство/кино/театр | Собственность — местные автономные органы, выбор репертуара — художники; нравственность артистов под контролем общества |

## Быстрые сигналы («tells»)

- Фатализм «так предопределено судьбой/кармой» о чужих страданиях → вероятно, аргумент эксплуататора.
- Группа решает всё через свой профессиональный интерес → групповизм без идеалов.
- Врач «продаёт» своё лекарство/микстуру настойчиво → бизнес-менталитет, не служение.
- Кино/медиа у власти коммерции → «Sarasvatii в рабстве у Lakśmii».
- «Господин и слуга» вместо взаимной сердечности → субкоординация, не кооперация.
- Система «пенальная» по умолчанию → Саркар потребовал бы корректирующую.
