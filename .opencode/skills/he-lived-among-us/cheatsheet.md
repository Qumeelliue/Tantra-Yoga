# Cheatsheet — He Lived Among Us

Быстрые правила решений и справка по оценкам Саркара внешними экспертами.

## Правила решений

| Ситуация | Правило |
|----------|---------|
| Две крайние позиции (материя/дух, индивид/общество) | Ищи синтез (холизм Саркара), не «или/или» |
| Оцениваю «прогресс»/развитие | Проверяй направление к благу (shubha), не скорость |
| Критикую догму/религию/систему | Имей готовую альтернативу; не «брей голову против вшей» |
| Оцениваю экономику | Меряй покупательной способностью и минимумом жизни, не GNP |
| Проектирую будущее/общество | Циклическая модель без «финала истории»; бесклассовость — утопия |
| Распределяю ресурсы | Сначала минимум всем, потом избыток достойным (санкционированная концентрация) |
| Система затрагивает природу | Включай в заботу все существа; псевдо-гуманизм — не гуманизм |
| Использую числа Саркара (93%, 247, 5018) | Помечай «⚠ к калибровке»; сверяй с первоисточником |
| Изучаю слово/понятие | Раскапывай корень — этимология открывает культуру |
| Планирую хозяйство/природу | Смешанные культуры + интеграция + сбор дождя + двухфазный лес |
| Анализирую национализм/кастовость | За ними — гео/социо-сантименты; лекарство — разум + преданность |
