# ch06: Шестнадцать пунктов (глава 7)

*Глава: Sixteen Points.*

## Core Idea

Шестнадцать пунктов — компактный «чек-лист» практикующего: гигиена, еда, пост, медитация, святость цели и правил, память о клятвах, обязательное участие в dharmacakra и выполнение C.S.D.K. Это и статусная база: «sadvipra» — устоявший в Шестнадцати пунктах (по Part 1).

## Frameworks Introduced

- **16 пунктов**:
  1. После мочеиспускания — мыть водой.
  2. Мужчинам — обрезание или постоянно оттянутая крайняя плоть.
  3. Никогда не стричь волосы суставов тела.
  4. Мужчинам всегда — kaopiina (laungotá).
  5. Vyápaka shaoca — по указаниям.
  6. Купание — по предписанной системе.
  7. **Только sáttvika (уравновешенная) еда**.
  8. Пост — по предписанию.
  9. Регулярная sádhaná.
  10–13. **Бескомпромиссная строгость и вера в святость**: Ishta (цель), Ádarsha (идеология), Supreme Command (верховное указание), Conduct Rules (правила поведения).
  14. Помнить содержание своих клятв.
  15. Обязательное еженедельное dharmacakra в местной jágrti.
  16. Соблюдать **C.S.D.K.** (Conduct Rules, Seminar, Duty, Kiirtana).

## Key Concepts

- **kaopiina (laungotá)** — набедренная повязка.
- **sáttvika** — уравновешенная (см. caryacarya-3, глава 2 об Áhárya).
- **sadvipra** — «духовный революционер», устоявший в 16 пунктах (электорат в Part 1).
- **C.S.D.K.** — правило, семинар, долг, киртан.

## Mental Models

- «16 пунктов — это чек-лист, а не пожелания: каждый пункт проверяем (мытьё, одежда, еда, пост, медитация, участие)».
- «Четыре "святых столпа" (10–13) — фильтр лояльности: без них остальные пункты теряют смысл».
- «C.S.D.K. — акроним для памяти: правила, семинар, долг, киртан».

## Anti-patterns

- **Негигиеничная гигиена** (пропуск мытья/очищения) — против пунктов 1, 5, 6.
- **Не-sáttvika еда** — против пункта 7.
- **Пропуск поста / dharmacakra** — против пунктов 8, 15.
- **Гибкость в святости Ishta/Ádarsha/SC/Conduct** — против пунктов 10–13.

## Worked Example

*Практик по 16 пунктам.* Утром: мытьё после мочеиспускания, vyápaka shaoca, купание по системе. Одевается: мужчина — с kaopiina, крайняя плоть оттянута. Ест только sáttvika еду, постится по предписанию. Медитирует регулярно. В воскресенье — обязательный dharmacakra. Помнит клятвы; выполняет C.S.D.K. (правила, семинар, долг, киртан). Именно такие люди — sadvipras — избирают окружных глав в Part 1.

## Key Takeaways

1. 16 пунктов — измеримый статус практикующего.
2. Четыре столпа святости (Ishta/Ádarsha/SC/Conduct) — сердце списка.
3. Гигиена, еда, пост, медитация, dharmacakra — обязательная рутина.
4. C.S.D.K. — мнемоника для повседневного обязательства.
5. Sadvipra — статусная база для участия в управлении (Part 1).
