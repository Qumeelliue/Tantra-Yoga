# Читшит — правила решений по Caryácarya Part 2

## Духовная практика

| Ситуация | Правило |
|---|---|
| Медитация | Дважды в день (до завтрака / до ужина), Iishvara prańidhána |
| Japa | Ishta-мантра 80 раз, затем без счёта |
| Yama-Niyama | Соблюдать при всех обстоятельствах |
| Пропустил dharmacakra (служба/больные) | Индивидуальная медитация в jágrti в тот же день |
| Пропустил без уважительной причины | Пропустить главную трапезу недели |
| Нет средств для sháshi за свой проступок | Поститься (еду отдать нуждающемуся, водой — растения) |

## Тело и пост

| Ситуация | Правило |
|---|---|
| Перед медитацией / едой / сном | Vyápaka shaoca (гениталии, руки до локтей, ноги до колен, 12× вода в глаза, уши, шея) |
| Ekádashii (11-й день лунного месяца) | Пост без воды — обязателен |
| Púrńimá / Amávasya | Пост по желанию (санньяси — обязательно) |
| После мочеиспускания | Мыть водой (пункт 1; и 1-й пункт 16) |

## Социальное поведение

| Ситуация | Правило |
|---|---|
| Начинаешь есть | Проверь, все ли поели; распределяй еду поровну |
| Давать ответственность | Только устоявшим в Yama-Niyama |
| Лицемер (ложь/неблагодарность/клятвопреступление/предательство/клевета) | Временное перемирие, не прощение до реформации |
| Фальсифицированный товар/лекарство | Не продавать/не применять; фальсификатора не прощать до реформации |
| Подарок «по должности» | Это взятка — не принимать |
| Пациент умер | Врачу не брать плату за визит |
| Выборы | Судить по делам; голосовать за устоявших в YN; лучше не голосовать, чем за недостойного |
| Наказание | 4 шага: слова → жёсткость → предупреждение → наказание; мера ≤ любви |
| Преследование женщин / вред Marga / воровство / лицемерие | Величайшие преступления (mahápátaki) |
| Угощение | prityanna — есть; ápadanna — есть любую; shráddhánna — не есть |
| Приданое-угощение | Помогать делом, но не есть за этим столом |
| Азартные игры / лотереи | Избегать |

## Служение и долги

| Ситуация | Правило |
|---|---|
| Какой вид севы | Тот, что нужнее сейчас (4 равных: физический / еда-вода / спасение / ум-дух) |
| Кем быть марги | Всеми четырьмя сразу (vipra, kshatriya, vaeshya, shúdra) |
| Долги | Отец, мать, ácárya, guru — неискупимы без Moksá |

## Личная дисциплина (шилы/пункты)

| Ситуация | Правило |
|---|---|
| Бессознательная ошибка | Признать немедленно, просить наказания |
| Требовать что-то от других | Сначала сам подай пример |
| Критика / групповщина / многословие | Избегать |
| Еда | Только sáttvika |
| Святость Ishta/Ádarsha/SC/Conduct | Бескомпромиссная строгость |
| Воскресенье | Обязательное dharmacakra |

## Этикет

| Ситуация | Правило |
|---|---|
| Чихание/кашель | Прикрыть рот; мыть руки; не за столом |
| Разговор | Дай высказаться, слушай (лёгкий звук), смотри на собеседника |
| Чужие письма/писанина | Не читать |
| Гости/звонки | Не после 21:00 |
| Подача еды | Правой рукой; стакан — за нижнюю часть |
| Пить воду / мочиться / испражняться | Не стоя |
| Еда по ноздрям | Твёрдая — правая (pingalá), жидкая — левая (idá); при idá — sádhaná |
