# Читшит — правила решений по Саркару (Supreme Expression Volume 2)

## Социальный цикл и власть

| Ситуация | Правило |
|---|---|
| Кто у власти? | Ресурс эпохи: сила (kśatriya) / интеллект (vipra) / капитал (vaeshya) / большинство (shúdra) |
| Класс доминирует | Будет эксплуатировать; смена доминанта не решает |
| Класс начал эксплуатировать | Садвипра: сила против kśatriya, интеллект против vipra, выборы против vaeshya |
| После vaeshya | Шудра-революция → новый kśatriya-век |

## Грех и преступность

| Ситуация | Правило |
|---|---|
| Причина деградации | Нехватка → минимум; переизбыток → утилизировать; застой → «молот» |
| Тип преступника | Природа → лечить; привычка → образование+дисциплина; среда → убрать из среды; бедность → экономика; слабость → осторожность |
| Сомнение в вине | Никакого наказания |
| Карать или исправлять | Всегда corrective: слово → твёрже → предупреждение → гуманная мера; «жизнь за жизнь» отвергнуто |

## Экономика

| Ситуация | Правило |
|---|---|
| Владение землёй/фабриками | Социализация (не национализация); кооперативы работников; без компенсации капиталистам |
| Распределение необходимого | Кооперативы и автономные органы; НЕ бизнес, НЕ центральное правительство |
| Бизнесу | Только предметы роскоши |
| Механизация | Под капитализмом = безработица; в коллективной экономике = меньше труда |

## Мир и политика

| Ситуация | Правило |
|---|---|
| Зло на глазах | Вмешайся (разумный мир); невмешательство = пособничество (статичный мир) |
| Агрессор напал на слабого | Сопротивляйся силой; «козлы не установят мир в обществе тигров» |
| «Мир любой ценой» | Отвергнуто: мир — результат борьбы |
| Кандидат набрал <50% | Повторный тест популярности |
| Образование | Платят гос-во, решают педагоги; бесплатно, вне партий |

## Идеи и прогресс

| Ситуация | Правило |
|---|---|
| Оценить теорию | Идёт ли за практикой? Есть ли намерение/реальность/применение/среда? |
| Оценить «прогресс» | Плюсы-минусы в физике/интеллекте = ноль; прогресс = движение к Shubha |
| Куда целиться | Dharma и Mokśa (Caturvarga) |
| Группа выживает? | Шесть факторов Bhati: идеология, культ, соц-экономика, мировоззрение, шастра, прецептор |

## Общество и ценности

| Ситуация | Правило |
|---|---|
| Строить сообщество | Как паломников: останавливаться ради слабого; без «свои/чужие» |
| Человек vs институт | Человек выше: институты служат человеку, не наоборот |
| Лидер | Только в Yama-Niyama + садхана |
| Прощение | Индивидуально — можно; за группу — нельзя |
| «Конец борьбы» | Vidya-avidya и классовая борьба вечны |

## Быстрые сигналы («tells»)

- Красивая теория без намерения реализовать — лицемерие.
- «Наука обогнала цивилизацию» (комфорт без утончённости) — путь гибели.
- «Не вмешивайтесь в чужие дела» — вероятное пособничество угнетателю.
- «Кровь чистая», «высшая раса» — антинаучно: все из одного корня.
- Знание без применения в жизни — не имеет ценности (Ch 20).
