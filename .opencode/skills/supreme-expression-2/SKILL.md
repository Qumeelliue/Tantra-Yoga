## Core Frameworks & Mental Models

### Социальный цикл (samája cakra)
Четыре эпохи по кругу: **Shúdra** (работники) → **Kśatriya** (сила) → **Vipra** (интеллектуалы-паразиты) → **Vaeshya** (капитал) → шудра-революция. Термины: **kránti** (смена эпох), **yuga saḿkránti** (переход), **parikránti** (полный оборот), **viplava** (революция-скачок), **vikránti**/ **prativiplava** (контр-эволюция/революция, недолговечны). Шудра не правит и не эксплуатирует. **Применение:** кто доминирует, на каком ресурсе, кто восстанет.### Sadvipra — лидер общества
Духовный революционер в **Yama** (ahiḿsá, satya, asteya, aparigraha, Brahmacarya) и **Niyama** (shaoca, santośa, tapah, svádhyáya, Iishvara prańidhána), пропитанный Космической идеацией. Не даёт доминирующему классу эксплуатировать: против kśatriya — сила, против vipra — интеллектуальная революция, против vaeshya — выборы.

### PROUT и пять принципов
Максимальная утилизация и рациональное распределение физических, психических и духовных потенциалов. Принципы: (1) никакого накопления без одобрения коллектива; (2) максимальная утилизация и рациональное распределение всех потенциалов; (3) максимальная утилизация потенциалов единичных и коллективных тел; (4) балансировка утилизаций; (5) метод меняется со временем-местом-личностью, всегда прогрессивен. Ядро: **минимум каждому** + **вознаграждение таланту**, разрыв постоянно сжимается.

### Три причины греха
(1) **Нехватка** пищи (pabula) → зверство; (2) **неутилизация переизбытка** → эксплуатация; (3) **застой** — «величайшая болезнь». Решения: минимум / интеллект / садвипры «бьют молотом».

### Corrective justice
**Vicára** = поиск истины; карательную систему удалить (наказание порождает мстительность). Пять категорий преступников: (1) по природе — лечить как пациентов; (2) по привычке — моральное образование+дисциплина; (3) из-за среды — убрать из среды; (4) из-за бедности — экономика, не суд; (5) по слабости — осторожность. Сомнение → никакого наказания. Имморальность = эксплуатация или лишение права на жизнь.

### Нация = чувство
Нацию создаёт **sentiment**, не язык/раса/религия. Анти-эксплуатационное чувство объединяет, но умирает с эксплуатацией; вечно объединяет духовное наследие и Космическая идеология → универсальная нация. Раздел Индии — следствие политической борьбы вместо экономической.
### Теория после практики
Успешная теория рождается из практики (яблоко упало → теория). Четыре причины провала: лицемер, оторванный теоретик, неэффективность применения, трудности среды. Проверяй: что идёт первым?### Asti-Bhati-Ananda и шесть факторов
Asti (существование) без Bhati (развития) — не жизнь; цель Bhati — Ananda (блаженство). Шесть факторов группы: (1) духовная идеология; (2) культ/садхана; (3) социально-экономическая теория; (4) социальное мировоззрение; (5) шастра; (6) прецептор. Слабость одного губит; без факторов группа вымирает. Термической смерти не будет (Jadasphota) — переселение на другие планеты.
### Прогресс только духовный
Прогресс = движение к Shubha. Пять чувств: Anukulavedaniiyam (приятное), Pratikulavedaniiyam (неприятное), Avedaniiyam (нигилизм), Nirapekśavedaniiyam (подавление), Aplutavedaniiyam (не-латеральное, без негативной скорости). В физике/интеллекте плюсы-минусы уравновешены — прогресса нет; чистый прогресс даёт только духовное (Aplutavedaniiyam). Caturvarga: Káma / Artha / Dharma / Mokśa; цель — Dharma и Mokśa.

### Человеческие ценности выше социальных
История уважала только социальные ценности, никогда — кардинальные человеческие принципы. Садвипра: человеческая ценность — фундамент, социальная — следствие; ответственность — только достойным (Yama-Niyama+садхана), человеческая ценность — никому не отнимается. Наказание в 4 ступени, только виновный, снимается при исправлении.

### Мир и демократия
**Sáttvikii shánti** (разумный мир: вмешивайся, защищай) vs **támasikii shánti** (статичный: невмешательство = пособничество). Мир — результат борьбы. Демократия — «лучшее из плохого»: тест популярности при <50%, образование бесплатно и вне партий.

### Социализация, децентрализация, кооперативы
**Социализация** (не национализация): всё принадлежит всем; без компенсации капиталистам. Децентрализация в самодостаточные единицы; механизация в коллективной экономике = меньше труда. Кооперативы — для необходимого; бизнесу — только роскошь.


### Мировое правительство и универсализм
Национализм/коммунализм/кастовость — «измы» одного типа; свободен только универсализм. Мировое правительство: две палаты, начинает как законопроизводящий орган. Vishva bháśá — самый распространённый язык века; одна культура с локальными особенностями, социальный синтез.

### Пять принципов социальной психологии (ch08)
**Единство** (общий идеал, бескастность, коллективные функции, нет смертной казни), **безопасность** (никакой несправедливости; дисциплина: повиновение → потом аргумент), **мир** (садхана + анти-суеверие). Nivrtti: sámayikii (временное) vs atyantikii (постоянное).
