# Читшит — Ánanda Vacanámrtam Part 3

## Права и квалификация

| Ситуация | Правило |
|---|---|
| Право женщины на спасение | Равно мужскому: минимум — человеческое тело |
| Разница полов | Только в двух нижних кошах (annamaya, kámamaya) |
| Возраст/учёность для садханы | Нерелевантны (пример Дхрувы) |
| Человек | Разумное существо, НЕ «разумное животное» |
| Отличие от животных | Бхагавата-дхарма: vistára + rasa + sevá |

## Йога и практика

| Ситуация | Правило |
|---|---|
| Что такое йога по Тантре | Слияние (yuiṋj) дживатмы с Параматмой |
| Приостановка без направления | Опасна: пропенситы бунтуют внутри |
| Цель медитации | Направить отозванное к Высшему — слияние |
| Самадхи | Утверждение «Я — Брахма» |
| Чистое зеркало ума | Садхана + jana sevá; цель — слияние, не Савикальпа |

## Секреты успеха

| Ситуация | Правило |
|---|---|
| Начать дело | Решимость «должен преуспеть» |
| Шраддха | Приписать всё цели и направить всё к ней |
| Наставник | Гуру-пуджа: делать по его желанию |
| Равновесие | Все — братья; без комплексов |
| Органы и пища | Контроль; пища контролируемая И питательная |

## Гуру и молитва

| Ситуация | Правило |
|---|---|
| Кто гуру | Брахма Сам; форма — рамка |
| Три функции | Генератор (a) / Оператор (u) / Дестроер (ma) = G-O-D |
| Что дарить Ему | «Твою вещь» (Tava dravyam); единственное «моё» — эго/ум |
| Ответ на «кто я?» | Tattvamasi — «Ты еси То» |
| Есть ли Сатана | Нет; только misdeeds авидья-майи |

## Смерть и посмертие

| Ситуация | Правило |
|---|---|
| Судный день | Не существует: суждение по действиям |
| Ум после смерти | Ищет новое тело по самскарам (не ждёт) |
| Ад/рай | Нет вечных мест; цель — Satyaloka |
| Поминовение (шраддха) | Без еды/вещей — вера и молитва; долг кончается кремацией |
| «Призраки» | Тантрик или собственная эктоплазма; не самостоятельны |
| Семь дев-йони | Скрытые желания при садхане (якша=деньги; сиддха=силы) |

## Миропорядок

| Ситуация | Правило |
|---|---|
| Кто всё контролирует | Он; даже смерть слушается (страх перед Ним) |
| Индрии хотят «увидеть Его» | Не догонят: Он быстрее ума |
| Природные бедствия | Авидья-майя с благим намерением |
| Основа общества | Один «изм» — универсализм (PROUT) |
| Всепроникновение | Sarva = sa (sattva)+ra (энергия)+va (дхарма) |

## Быстрые сигналы («tells»)

- «Спасение только мужчинам» — корысть жрецов, не духовность.
- «Я отключаю мысли» без направления — жди внутреннего взрыва.
- «Дал вещи покойнику» — их съел/продал жрец; предок не нуждается.
- Боишься «призраков» — ты «сам призрак» (анандамарги).
- «Это естественно» — природа лишь стиль Пракрти; всё по Его разрешению.
- Скрытое желание в садхане («если бы мне...») — путь в дев-йони.
