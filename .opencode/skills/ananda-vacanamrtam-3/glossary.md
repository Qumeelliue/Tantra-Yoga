# Глоссарий — Ánanda Vacanámrtam Part 3

**Ава́тара (avatára)** — «нисхождение»; каждая частица творения — аватара Всевышнего (при отказе от «аватаризма» как доктрины) (Ch 1).

**Авидья-майя / Видья-майя (Avidyá/ Vidyá máyá)** — центробежная / центростремительная силы Майи (Ch 14).

**Акша-мала (aksá málá)** — пятьдесят акустических корней (буквы-звуки-цвета), основа азбуки (Ch 20).

**Аха́ра (áhára)** — «собираемое»: физическая и ментальная пища (Ch 3).

**Бха́гавата-дхарма** — vistára (расширение) + rasa (поток) + sevá (служение); отличает человека (Ch 12).

**Бха́ва / бха́ва́тита (bháva / bhávátiita)** — поток духовности/сентимента; Он вне бхавы (Ch 10).

**Бха́ва́ру́дха́ртха / йога́ру́дха́ртха** — корневой / употребительный смысл слова (Ch 2).

**Дева-йони (devayoni)** — семитипичные трёхэлементные существа по скрытым желаниям (якша, ракша, киннара, видьядхара, гандхарва, сиддха, пракртили́на) (Ch 17).

**Джи́ватма (jiivátmá)** — отражение Параматмы на ментальном «зеркале» (Ch 18).

**Дхрува** — ребёнок, начавший садхану в 5 лет (пример) (Ch 12).

**Йога** — по Тантре: слияние (yuiṋj) дживатмы с Параматмой; не только приостановка Патанджали (Ch 2).

**Ка́рья / Ка́рана Брахма** — эффект / причина; акустические корни ka и aum/a (Ch 20).

**Кевала (kevala)** — недвойственная Сущность; нет Сатаны (Ch 9).

**Кошы** — annamaya и kámamaya — нижние, «телесные»; там половая разница (Ch 1).

**Крипия** — см. Part 2.

**Ма́нава (mánava)** — «существо, где ум доминирует» (Ch 10).

**Мритьюрмритью (Mrtyurmrtyu)** — «смерть смерти»; достигший Его умирает окончательно (Ch 7).

**Нарада** — «распространяющий преданность» (Ch 12).

**Ниргуна-стхити / Савикальпа** — слияние зеркала с оригиналом / стадия чистого отражения (Ch 18).

**Пра́на́ма-мантра** — «Tava dravyaḿ Jagatguro Tubhyameva samarpaye» (Ch 5).

**Пракртили́на** — ставший объектом поклонения (камень/дерево/металл) (Ch 17).

**Пратьяга́тма (Pratyagátmá)** — оригинал-свидетель отражений (Ch 18).

**Прета (preta)** — отделённый ум после смерти (Ch 17).

**Пу́рна** — полнота; бесконечность минус бесконечность = бесконечность (Ch 19).

**Рудра́кша** — пространство, где танцуют буквы (Ch 20).

**Садгуру** — рамка, через которую Táraka Brahma ведёт к sat (Ch 10).

**Самадхи** — утверждение «Я — Брахма» (Ch 8).

**Сама́тта-бха́ва (samatábháva)** — полное ментальное равновесие (Ch 3).

**Самсара-круг (Brahma Cakra)** — движение вокруг Нуклеуса (Ch 6).

**Сатва-лока (Satyaloka)** — цель установления (вместо ада/рая) (Ch 15).

**Семь секретов успеха** — решимость, шраддха, гуру-пуджа, равновесие, контроль органов, питательный контроль (Ch 3).

**Сиддха** — лучший из дев-йони (желание оккультных сил) (Ch 17).

**Tattvamasi** — «Ты еси То» (Ch 9).

**Угра (ugra)** — «заострённый», вершинный (не «свирепый») (Ch 7).

**Универсализм** — единственный «изм», основа общества (Ch 11).

**Шраддха́** — направленность ума к цели, признанной supreme (Ch 3, 16).

**Шра́ддха (Shráddha)** — поминовение умерших без материальных даров (Ch 16).

**Экста́пья** — см. Part 2.

**Экста́пья-материя (ectoplasmic)** — материал ума, из которого творится и «призраки» (Ch 5, 17).
