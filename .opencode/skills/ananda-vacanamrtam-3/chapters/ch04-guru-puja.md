# Chapter 4: Guru Pújá

*Дискурс 4 октября 1978, Patna. Discourse 63 серии.*

## Core Idea

«Brahmaeva Gurureka náparah» — Брахма Сам есть Гуру; форма — рамка Его выражения. Гуру — связующее звено jiiva и Shiva, открывающее глаза палочкой духовного знания. Gurur Brahmá, Gurur Viśńu, Gurur Devo Maheshvara — три функции одной Сущности (G-O-D).

## Frameworks Introduced

- **Гуру**: gu (тьма) + ru (рассеиватель); «Brahmaeva Gurureka náparah» — единственный гуру — Брахма; секреты Брахмы знает только Он; выражается через рамку. «Форма не есть гуру — гуру выражает Себя через форму».
- **Акханда мандалакарам**: вселенная — овальное (ańd́a) выражение («Brahmáńd́a»); Parama Purusa всепроникающ (vis) → **Viśńu**. Микрокосм не может коснуться Его без гуру — «звена между jiiva и Shiva»; это звено noumenally — Táraka Brahma.
- **Аджняна-мазь**: микрокосмы ослеплены неведением; гуру «палочкой» (shaláká) наносит мазь духовного знания, открывает глаза.
- **Namah / namo mudrá**: сдача всех «десяти пальцев» — всех выражений и умений, собранных в точку.
- **Три функции** (Gurur Brahmá, Viśńu, Maheshvara): Генератор (a), Оператор (u), Дестроер (ma) = **G-O-D**, «Aum»; «Prańavátmakaḿ Brahma». Brahmá+«a»=Brahmá (творчество); Viśńu — всепроникновение через Viśńu Máyá; Maheshvara — контроль devas/devatás, отзыв действий (смерть = простой отзыв).
- **Gurureva Parama Brahma**: para/parápara/Parama; гуру — выражение Parama Brahma, рассеивающее духовный мрак.

## Key Concepts

- **Akhańd́a mańd́alákáram** — «нераздельное круговое» (всепроникающее).
- **Brahmáńd́a** — овальное выражение Космоса.
- **namáh / namo mudrá** — самоотдача всех действий.
- **G-O-D** — Generator-Operator-Destroyer.
- **shaláká** — палочка для мази знания.

## Mental Models

- «Думай о гуру как об окне, а не о стекле: свет — Брахма; окно лишь пропускает».
- «Думай о смерти как об отзыве ролей: Дестроер возвращает актёров за кулисы».

## Anti-patterns

- **Поклоняться форме как гуру** — форма — рамка, не гуру.
- **Пытаться коснуться Всевышнего без гуру** — нужен мост.
- **Путать три функции с тремя богами** — одна Сущность (G-O-D).

## Worked Example

*Как гуру открывает глаза? Все микрокосмы — части Нуменальной Сущности, но ослеплены неведением. Гуру наносит мазь духовного знания (палочкой) — глаза открываются. Гуру — звено jiiva→Shiva; noumenally это Táraka Brahma. Тот же Господь — Генератор (a), Оператор (u), Дестроер (ma): «Gurur Brahmá, Gurur Viśńu, Gurur Devo Maheshvara». «Tasmae Shrii Gurave namah» — сдаю все свои десять пальцев.*

## Key Takeaways

1. Единственный гуру — Брахма; форма — рамка.
2. Гуру — мост jiiva→Shiva (Táraka Brahma).
3. Открывает глаза мазью духовного знания.
4. Три функции — одна Сущность: G-O-D (aum).
5. Namah = сдача всех действий («десяти пальцев»).
