# Chapter 13: Nityaḿ Shuddhaḿ

*Дискурс 15 октября 1978, Patna. Discourse 72 серии.*

## Core Idea

Шлока Тантры: «Nityaḿ shuddhaḿ nirábhásaḿ nirákáraḿ niraiṋjanam; Nityabodhaḿ cidánandaḿ Gurubrahma namámyaham». Господь — неизменный (только Он может быть «чистым»), без отражений/сходства, без формы, без пятен, всезнающий (bodha), блаженное Познание. Творение — Его лила; никогда не бойся — Он о тебе заботится.

## Frameworks Introduced

- **Nityam**: неизменное; также «deva» — вибрирующее всё (sarva-dyotana, akhańd́a cidaekarasa: неразделимое, олицетворённое Познание с единым потоком от анади к ананте).
- **Shuddham**: «как должно быть, в должной форме» — относительное слово. Чистое гхи через 10 лет не останется чистым (время меняет) → ни один объект физического мира не шуддха; **только Параматман** — чист всегда.
- **Nirábhásam**: без отражения/искажения; и без сходства (никто не может быть «вторым Парама Пурушей»).
- **Nirákáram**: без формы — форма появляется под узлами трёх гун; неограниченное (время/личность/пространство) не имеет формы.
- **Niraiṋjanam**: без чёрных пятен (aiṋjana).
- **Nityabodham**: bodha = опыт, подкреплённый интеллектом (радуга — перцепция без концепта, не bodha; техник понимает машину, обыватель — нет). Он знает всё и каждого — ничего тайного.
- **Cidánandam**: cit (Познание) + ананда; Он — Познавательное блаженство; не ищет счастья вовне — Его существование и есть блаженство.
- **Лила**: творение — драма; Он — Режиссёр, вовлекает каждого в роль; вводит в узы и освобождает — Его лила. Никому не желает зла. «Не бойся: Сущность, ведущая звёзды, ведёт и тебя».

## Key Concepts

- **nityam / shuddham** — неизменное / чистое (только Он).
- **nirábhásam / nirákáram / niraiṋjanam** — без отражения / формы / пятен.
- **bodha** — знание с пониманием (vs перцепция).
- **cid ánanda** — блаженное Познание.
- **liilá** — божественная драма.

## Mental Models

- «Думай о "чистоте" как о неизменности: гхи чист сегодня, но не через 10 лет; только неизменное — чисто всегда».
- «Думай о мире как о постановке: у каждого своя роль; режиссёр заботится о всех».

## Anti-patterns

- **Считать физические вещи чистыми** — время всё меняет; чист только Он.
- **Считать опыт «знанием» без понимания** — bodha требует концепта.
- **Бояться роли в драме** — Он режиссёр и заботится о тебе.

## Worked Example

*Что значит «чистый»? Чистое гхи не останется чистым через 10 лет — время изменит его. Значит, в физическом мире чистоты нет; чист только неизменный Параматман. Он без формы (вне уз гун), без пятен, знает всё (bodha — понимание, не просто опыт). Творение — драма; Он режиссёр. Никого не бойся: ведущий звёзды ведёт и тебя.*

## Key Takeaways

1. Только неизменное может быть чисто (шуддха).
2. Он без отражений, формы, пятен.
3. Bodha = опыт с пониманием; Он знает всё.
4. Cid ánanda — Его существование и есть блаженство.
5. Мир — лила; Он заботится о каждом; не бойся.
