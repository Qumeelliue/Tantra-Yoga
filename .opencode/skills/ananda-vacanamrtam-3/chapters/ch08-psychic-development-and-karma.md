# Chapter 8: Psychic Development and Karma

*Дискурс 8 октября 1978 (утро), Patna. Discourse 67 серии.*

## Core Idea

Человек проходит ступени: shúdra (Брахма как пища) → dvija (второе рождение через вайдики-дикшу) → vipra (интеллектуальный голод) → bráhmana (тантрики-дикша, реализация Брахмы). Карма = смена места, требует правильной цели; кульминация дхьяны — самадхи («Я — Брахма»).

## Frameworks Introduced

- **Четыре ступени** («Janmaná jáyate shúdrah...»): 
  - **Shúdra**: рождённый; Брахма воспринимается как пища («Annaḿ Brahmeti»).
  - **Dvija**: «второе рождение» — вайдики-дикша будит сверх-мирской и духовный голод.
  - **Vipra**: интеллектуальный голод; изучение дхарма-шастр.
  - **Bráhmana**: тантрики-дикша и реализация Брахмы («Brahma jánáti bráhmana»).
- **Вторая фаза — Karma**: «Karma brahmeti karma bahu kurviita». Карма = смена места; место — один из трёх относительных факторов (время-место-личность). Где движение — там карма и три узы.
- **Опасность кармы**: действие без правильной цели может вести к разрушению (воровство — тоже карма). «Культ кармы не без опасностей» — нужна цель и путь.
- **Третья фаза — Satya jiñánam**: знание неметаморфозного Брахмы.
- **Четвёртая — «Ahaḿ Brahmásmi so’ham»**: мало приблизиться — нужно слить единичное «я» в Него; через дхьяну (асаны, пратьяхара, пранаяма, дхарана).
- **Самадхи**: утверждение в позиции «Я — Брахма» — кульминация дхьяны.

## Key Concepts

- **shúdra → dvija → vipra → bráhmana** — духовные ступени (не каста).
- **Vaedikii diikśá / Tántrikii diikśá** — два вида инициации.
- **karma = смена места** — с тремя относительными факторами.
- **samádhi** — «Я — Брахма».

## Mental Models

- «Думай о голоде как о лестнице: пищевой → духовный → интеллектуальный → реализация».
- «Думай о карме как о двигателе без руля: энергия есть, но без цели — к разрушению».

## Anti-patterns

- **Действие без цели** — карма может вести назад/к разрушению.
- **Останавливаться на приближении** — нужно слияние, не близость.
- **Считать самадхи «знанием о Брахме»** — это утверждение «Я — Брахма».

## Worked Example

*Человек начинал с мысли «еда — Брахма» (шудра). Вайдики-дикша открыла духовный голод — он dvija. Изучение шастр — vipra. Тантрики-дикша и реализация — brahmana. В пути он действует (карма) — но с целью: действие без цели разрушает. Наконец: мало знать Брахму — надо слить «я» через дхьяну; итог — самадхи «Я — Брахма».*

## Key Takeaways

1. Ступени: шудра→двиджа→випра→брахман (по голоду и дикше).
2. Карма = смена места; требует правильной цели.
3. Действие без цели опасно.
4. Мало приблизиться к Брахме — нужно слияние через дхьяну.
5. Самадхи = утверждение «Я — Брахма».
