# Chapter 7: Pramá – 1 / Dynamic Equilibrium and Equipoise

*Февраль 1987, Калькутта.*

## Core Idea

**Pramá** = равновесие (equilibrium — баланс силы) + равно-взвешенность (equipoise — баланс веса) во всех трёх сферах: физической, психической, духовной. Человечество не установило pramá и потому деградирует. Восстановление баланса — поэтапно, начиная с физической сферы.

## Frameworks Introduced

- **Guńatrikońa (треугольник сил)**: три гуны (sattva/rajas/tamas = sentient/mutative/static) поддерживают баланс взаимным превращением; при давлении static Prakrti баланс теряется и начинается творение через вершину — **lokatrikońa / pramátrikońa** (треугольник человеческого существования: физическое-психическое-духовное).
- **Три стадии упадка**: **derangement** (расстройство) → **disruption** (разрушение) → **degeneration** (деградация). Общество сегодня — в стадии деградации. Подъём обратный: degeneration → disruption → derangement → pramá.
- **Три уровня pramá**: **pramá saḿvrddhi** (физический прогресс в согласии с психическим/духовным), **pramá rddhi** (психический пик, agryábuddhi), **pramá siddhi** (духовный абсолют в равновесии с физическим/психическим).
- **Метод восстановления**: делить каждую сферу на под-сферы (физическая: сельское хозяйство, промышленность, торговля, медицина, ирригация, физкультура; психическая: physico-psychic/psychic/psycho-spiritual), строить под-треугольники, поднимать ступенями. Для физической сферы учитывать: спрос/предложение сейчас и в будущем, максимальное использование земли, Five Fundamental Principles.
- **Практика физического равновесия**: сельское хозяйство по принципу потребления (не прибыли), кооперативы, фермерские бригады, правильные культуры для правильных почв, ирригация.

## Key Concepts

- **Pramá** — баланс + равно-взвешенность (этимология: má = «мерить»).
- **Lokatrikońa / pramátrikońa** — треугольник трёх сфер индивидуального и коллективного существования.
- **Ráŕh** — «стартовая точка цивилизации»; пример: богатая ресурсами, но бедная из-за отсутствия pramá.
- **Дефект философии без pramá** — «labyrinth of metaphysics», dogmatic extravaganza.

## Mental Models

- «Думай о pramá как о равновесии весов: если у тебя перевес в одной сфере — страдают другие две».
- «Подъём идёт снизу: сначала физический пол — иначе "антисоциальные элементы получат верх"».

## Anti-patterns

- **Паломничества и продажа имущества ради «духовности»** — пример отсутствия pramá в духовной сфере.
- **Материальный прогресс без духовного** (Запад) и «духовность без материи» — оба ущербны.
- **Художественный дисбаланс** (лотос больше пруда, поэзия без ритма) — следствие психического дисбаланса.

## Worked Example

Ráŕh: природа дала золото/серебро/медь/уголь/плодородные почвы, но люди недоедают и полураздеты. Причина — нехватка pramá: планирование не учитывало баланса сфер. Правильное планирование: под-треугольник сельского хозяйства (ирригация, высокоурожайные семена, 3-4 урожая в год, кооперативы) → баланс физической сферы → подъём психической и духовной.

## Key Takeaways

1. Pramá = баланс физического/психического/духовного в индивиде и коллективе.
2. Упадок идёт по стадиям derangement→disruption→degeneration; подъём — обратно, по ступеням.
3. Начинать восстановление с физической сферы.
4. Ресурсы природы достаточны — не хватает равновесного планирования.
5. Идеал — pramá saḿvrddhi/rddhi/siddhi во всех сферах.
