# Chapter 20: Developmental Planning

*1979 (тур автора по Индии, ноябрь–декабрь).*

## Core Idea

Общество — венок из разных цветов на одной нити: все сферы связаны. Для прочного социального порядка нужны три фактора: **идеологическое вдохновение**, **дисциплина**, **экономическая стабильность**. Планирование — строго снизу вверх, по socio-economic units, никогда не навязывается сверху.

## Frameworks Introduced

- **Три фактора социального порядка**: (1) идеологическое вдохновение на всеобщих принципах, ставших частью структуры; (2) дисциплина в индивидуальной/коллективной жизни; (3) экономическая стабильность.
- **Региональное планирование**: потенциалы различаются (Bihar: surplus в северо-востоке, deficit в юго-востоке) → отдельные планы; централизованное планирование «провалилось везде».
- **Принцип снизу вверх**: план для Pundibari составляется в Pundibari, а не в Jalpaiguri; привлекаются местные специалисты, но **ответственность за реализацию — у местных моралистов**.
- **Капиталистическое планирование** — на индивидуальные/групповые интересы; контроль над сырьём ради прибыли; PROUT-планирование — на благо всех, партиям места нет.
- **Socio-economic units**: те же 5 критериев (общие проблемы, потенциалы, этнос, сентименты, география); 44 единицы для Индии; единица ≠ только география — это «самодостаточная социально-экономическая группировка», основа социальная/культурная/экономическая, не религиозная/лингвистическая.
- **Данные для плана**: география (реки, озёра, каналы, горы), минеральные/лесные/водные ресурсы, агро/индустриальные потенциалы (агро- и агрико-индустрии), демография (навыки, здоровье, психология), аграрный потенциал (распределение земли), коммуникации.
- **Флоатинг-популяция**: сраститься с регионом или вернуться; научная реорганизация населения.
- **Эры Индии**: Nehru/Gandhi/Janata — всё «Vaeshya Era» с мягкой политикой к капиталу; Janata — «контр-движение внутри Vaeshya Era», не революция; поэтому экономика не развивалась.

## Key Concepts

- **Welfare of all** — идеал планирования.
- **Grass roots** — корни; направление развития «bottom to top».
- **Moralists as implementers** — моралисты несут ответственность за реализацию.
- **Socio-economic unit** — «самодостаточная группировка», не просто территория.

## Mental Models

- «Думай о плане как о растении: оно растёт из корня вверх; навязанный сверху план — пластиковый цветок».
- «Политические эпохи приходят и уходят, но пока у власти капитал — экономика народа не растёт».

## Anti-patterns

- **Централизованное планирование** — «утопический миф».
- **План из кабинета в тысячах миль** — бесполезен для деревень.
- **Пятилетние планы по прихоти лидеров** — не учитывают местное.
- **Мягкая политика к капиталистам** — не даёт развития.

## Worked Example

Индия после независимости: три эры (Nehru, Gandhi, Janata) — все «soft state» к капиталистам; экономическое развитие отсутствует. Следовательно, единственный путь — socio-economic units с децентрализованным планированием снизу вверх и моралистами во главе реализации.

## Key Takeaways

1. Идеология + дисциплина + экономическая стабильность — фундамент общества.
2. Планирование снизу вверх, на месте, местными силами.
3. Ответственность за реализацию — у местных моралистов.
4. Socio-economic units — самодостаточные группировки (не лингво/религиозные).
5. Капиталистическое планирование обслуживает интересы капитала.
6. Флоатинг-популяция — сращивается или возвращается.
