# Chapter 21: Block-Level Planning

*1981, Калькутта.*

## Core Idea

В децентрализованной экономике планирование идёт по блокам — низший уровень планирования. **Четыре фактора планирования**: cost of production, productivity, purchasing capacity, collective necessity. Пренебрежение покупательной способностью (в пользу per capita) — обман капиталистов.

## Frameworks Introduced

- **Четыре фактора планирования**:
  1. **Cost of production**: фермеры не считают труд семьи/инструменты → убытки; агрикультуру реорганизовать «как индустрию» (системный учёт затрат, экономическая жизнеспособность каждого производства).
  2. **Productivity**: экономика обязана иметь внутреннюю силу производить больше; деньги инвестируются (rolling), не копятся; максимум производства по коллективным нуждам; без недоиспользования мощностей.
  3. **Purchasing capacity**: **per capita income — обманчивый/дефектный показатель**, скрывает дисперсию и игнорирует инфляцию; настоящий индекс — покупательная способность; рост через лёгкую доступность минимума, стабильные цены, рост зарплат. Покупательная способность — без предела, всегда растёт.
  4. **Collective necessity**: настоящие и будущие потребности единицы; минимум — в приоритете, но заслуженные/особые нужды не забыты.
- **Уровни планирования**: block (базовый) → district → state → national → global. В конституции — положение о block-level planning. **Block-level planning board** в каждом блоке.
- **Научное деление блоков**: не по политике, а по физическим чертам (речные долины, климат, рельеф, почвы, флора/фауна), социально-экономическим потребностям и психо-физическим устремлениям.
- **Intra-block vs inter-block**: intra — план одного блока; inter — сотрудничество соседних блоков для проблем через границы (защита от наводнений, речные проекты, коммуникации, высшее образование, аффорестация, экология, key industries, эрозия, вода, энергия, рынок).
- **Сроки**: short-term ≤ 6 месяцев; long-term ≤ 3 года (⚠ к калибровке); дополняют друг друга.
- **Выгоды**: малая площадь — планировщик понимает все проблемы; местные лидеры по местным приоритетам; быстрые результаты; местные организации мобилизуют ресурсы; занятость; покупательная способность; база сбалансированной экономики. Полная занятость — только через блоковые индустрии.
- **Пример различий**: Punjab (гималайские ледниковые реки, вечная вода, гидро Bhakhra Nangal) vs Cauvery Valley (реки Гхатов, сезонные, без гидро, экстремальный климат, laterite Deccan). Планы не могут совпадать.

## Key Concepts

- **Block-level planning board** — совет блока.
- **Ascending order of planning** — планирование по возрастающей (снизу вверх).
- **Per capita income vs purchasing capacity** — центральная пара показателей.
- **Intra-/inter-block planning**.

## Mental Models

- «Думай о блоке как о клетке планирования: клетка здорова → организм (страна) здоров».
- «Per capita — это средняя температура по больнице; покупательная способность — пульс каждого пациента».

## Anti-patterns

- **Политическое деление блоков** — не совпадает с экономическими реальностями.
- **Опора на per capita income** — «дефективный и обманчивый индекс, популяризованный капиталистическими экономистами».
- **Планы, не учитывающие будущие потребности** (энергетика не поспела за промышленностью в Bengal/Bihar).
- **Единый план для разных регионов** (Punjab = Cauvery) — нелепость.

## Worked Example

Индия: электропроизводство отстало от промышленного роста (Bengal, Bihar) — отсутствие учёта collective necessity. Правильно: блоковые планы с короткими (≤6 мес.) и долгими (≤3 года) горизонтами, дополняющими друг друга; блок решает свои проблемы (включая флоатинг-популяцию на месте), район над блоком, и т.д.

## Key Takeaways

1. Block — базовый уровень планирования, закреплённый конституционно.
2. Четыре фактора: затраты, продуктивность, покупательная способность, коллективная необходимость.
3. Покупательная способность — мера прогресса; per capita — обман.
4. Научное деление блоков (география+экономика+психика), не политика.
5. Inter-block сотрудничество — для трансграничных проблем.
6. Сроки: ≤6 мес. и ≤3 года (⚠ к калибровке).
