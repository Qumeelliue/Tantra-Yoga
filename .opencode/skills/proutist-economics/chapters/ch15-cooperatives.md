# Chapter 15: Cooperatives

*18 февраля 1988, Калькутта.*

## Core Idea

Общество — коллективное движение к общей цели (sámánam ejati iti samájah). Лучшая форма организации — **координированная кооперация** (равные права) вместо субординированной (мастер-слуга). Кооперативная система — «самое сладкое выражение человечности»; коммуна — её антипод.

## Frameworks Introduced

- **Coordinated vs subordinated cooperation**: координация = действие с равными правами, престижем и locus standi, на благо друг друга; субординация = под чьим-то надзором. Везде — только координация. Коммуна и капитализм основаны на субординации → деградация морали.
- **Типы кооперативов**: farmers (по земле и продуктивности), producers (агро/агрико/не-агро), consumers (распределение essential), service (врачи — интеллектуальные сервисные), banking, housing, family annuity.
- **Доля и управление**: дивиденд по земле + по труду; акции по продуктивности земли; записи о продуктивности; «no profit shares» — только dividend (иначе кооператив станет коммерческим); transfer акций — с разрешения кооператива, наследование по местной системе (Dayabhága/Hindu Code); голосование по человеку, не по акциям; дирекция из членов, оплачиваемая, только моралисты.
- **Производство по категориям**: essential (рис, соль, одежда), demi-essential (масло, мыло), non-essential (люкс). Essential производят producers кооперативы и распределяют через consumers; люкс — частный сектор; крупные капитальные инфраструктуры (железные дороги) — правительство. Список essential постоянно пересматривается правительством.
- **Фазовая социализация земли**: 4 фазы (uneconomic → все → рациональное распределение → без конфликта).
- **Защита фермеров**: кооператив продаёт урожай в лучшее время (против distress sales); платит налоги коллективно; фермеры-неработники остаются членами по земле (без зарплаты); постоянные рабочие получают бонусы.
- **Сателлитные кооперативы**: малые поставляют детали большим (автомобиль), снижая трудозатраты.
- **Против «floating population»**: члены — только местные («мигрирующие птицы не место в кооперативах»); иначе экономика региона расшатывается.
- **Единство**: поощрять общие факторы (бог-центричность Индии, санскрит, единый календарь), подавлять разъединяющие (календарная неразбериха: Saḿvat vs Shakábda).

## Key Concepts

- **Samájah** — общество как коллективное движение.
- **Distress sale** — вынужденная продажа под давлением (по бедности).
- **Demi-essential / non-essential commodities**.
- **Satellite cooperatives**.
- **Trademark для борьбы с black market** (клеймо производителя на одежде).

## Mental Models

- «Думай о кооперативе как о семье с равными правами: решения совместные, распределение по вкладу, а не по силе».
- «Всякое звено посредника — будущая эксплуатация; кооператив забирает долю middlemen себе».

## Anti-patterns

- **Субординированная кооперация** — мастер-слуга, угнетает потенциал.
- **Коммуна**: нет личной собственности → нет заботы; равные зарплаты умным и обычным → нет стимулов; «сокращает производство».
- **Profit-акции в кооперативе** — путь к коммерциализации и спекуляции.
- **Флоатинг-популяция** — «Howrah кормит 17 месяцев, а мигранты съедают за 6.5» (⚠ цифры к калибровке).
- **Hoarding/black-marketeering** — неизлечимы в «демократии», где они финансируют выборы.

## Worked Example

Четыре фермера (A=2, B=5, C=10, D=15 акров) объединяют землю; прибыль делится по земле и труду; продуктивность учтена в акциях. Плодородие варьирует — акции отражают и его. Убирают межи → больше пахотной земли. Кооператив хранит урожай и продаёт в лучший момент — конец «distress sales».

## Key Takeaways

1. Координированная кооперация — норма всякой коллективной жизни.
2. Кооператив — лучшая система производства/распределения; коммуна — худшая.
3. Акции только dividend; голосование по человеку.
4. Фазовость (4 фазы) социализации земли.
5. Члены — только местные; флоатинг-популяция исключается.
6. Моралисты в дирекции обязательны.
