# Chapter 25: Elevating Backward Classes

*Июнь 1979, Калькутта.*

## Core Idea

PROUT — «sarva jana hitáya» (благо всех): никто не подавляется. Марксизм («правление пролетариата») нереалистичен, капиталистическая демократия — «правление меньшинства ваешьев». До установления PROUT — временная система приоритетов по **экономическому положению**, а не по рождению/касте.

## Frameworks Introduced

- **Правило садвипров**: PROUT поддерживает правление sadvipras — только они представляют интересы всех классов; «правил шудр» не бывает (критика пролетарской диктатуры как «утопии»).
- **Приоритетная система (временная мера)**: (1) первая очередь — бедные из отсталых семей (по услугам/образованию, независимо от рождения); (2) вторая — бедные из неотсталых; (3) третья — небедные из отсталых; (4) последняя — небедные из неотсталых. «Отсталые» = семьи, не получавшие услуг/образования в прошлом; сохраняется, пока не гарантирован минимум.
- **Против job reservation**: при PROUT надобность отпадёт («jobs will seek people»); критерий — экономическое состояние, не каста (богатый «низкокастовый» сапожник не нуждается; бедный Maethil Brahmin — нуждается).
- **Отсталые группы в опасности вымирания**: Zulus/Pygmies (Африка), Lodhas (Bengal), Birhars (Chotanagpur), Málas (Malda), Angars (Bihar), Ladakhis, Scheduled Castes Kinnaur, Romanish (Европа), Maoris — срочные шаги: снятие образовательных неравенств, кустарные промыслы, ирригация, энергия, связь, транспорт.
- **Трибулы**: шаги для Tripura и мира — образование, cottage industries, агрикультура (вода), электроэнергия, телефоны, железные дороги.

## Key Concepts

- **Sarva jana hitáya** — благо всех.
- **Sadvipras** — представители интересов всех классов.
- **Backward classes** — отсталые (по доступу к услугам/образованию).
- **Preferential system** — временная система приоритетов.

## Mental Models

- «Думай о приоритетах как о триаже: помогают по степени нужды, а не по ярлыку группы».
- «Каста — это бирка; нужда — это состояние; система должна читать состояние, а не бирку».

## Anti-patterns

- **Пролетарская диктатура** («rule of the shúdras») — нереалистична, «дом из карт».
- **Демократия большинства** — на практике власть меньшинства ваешьев.
- **Job reservation по рождению** — не по духу PROUT (только временная мера по нужде).
- **Подавление языков/культур отсталых групп**.

## Worked Example

Пример «сапожник и брамин»: богатый сапожник «низкой» касты не нуждается в резервировании — оно для него избыточно; бедный Maethil Brahmin из «высокой» семьи — нуждается; резервирование поднимет стандарт всего общества. Бихар воюет за резервирование; эта система завершает конфликт отсталых/передовых.

## Key Takeaways

1. PROUT — за благо всех, против подавления.
2. Пролетарская диктатура нереалистична; правит садвипра.
3. Приоритеты — по нужде (экономика), не по рождению.
4. Job reservation — временная мера до гарантии минимума.
5. Группы в опасности — срочная защита (образование, промыслы, инфраструктура).
