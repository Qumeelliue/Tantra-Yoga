# Chapter 22: Decentralized Economy – 1

*16 марта 1982, Калькутта.*

## Core Idea

Централизованная экономика (капиталистическая и коммунистическая) неспособна искоренить эксплуатацию. Единственный путь — **децентрализованная экономика** с пятью принципами: местные ресурсы местным, производство для потребления, кооперативы, полная занятость местных, удаление чужих товаров с местных рынков.

## Frameworks Introduced

- **Пять принципов децентрализации**:
  1. **Ресурсы единицы — местным**: ресурсы минимума в местных руках; местное сырьё полностью используется; «местные» = срастившие интересы с единицей (не по цвету/касте/языку); аутсайдеры не вмешиваются (иначе флоатинг-популяция и отток богатства).
  2. **Производство для потребления, не прибыли**: местный рынок поглощает местные товары; деньги циркулируют локально; риск экономической катастрофы уходит; покупательная способность растёт.
  3. **Производство/распределение через кооперативы**: кооперативы терпели из-за централизации (конкуренция с монополистами); децентрализация — условие успеха кооперативов; частная собственность упраздняется поэтапно; люкс — малый частный сектор; распределение — через потребительские кооперативы.
  4. **Местные заняты в местных предприятиях**: иначе безработица не решается; кооперативы дают работу и навыки; агро/агрико-индустрии по потребностям.
  5. **Удаление неродных товаров с рынков**: местные пользуются местным (даже если хуже/дороже — сначала), иначе местные индустрии закрываются; затем качество/цена/объём поднимаются, чтобы не было нелегального импорта.
- **Структура промышленности**: key industries (местное правительство, «no profit, no loss»), medium (кооперативы, без монопольной прибыли), малые/кустарные (частные, люкс, в согласии с кооперативами). Кустарные — не единственная опора деревни; женщины получают доход.
- **Энергия**: каждый регион самодостаточен по энергии; local power (солнце, термо, биогаз, гидро, ядерная, пневматика, электромагнетизм, приливы) на «no profit, no loss» — ключевая индустрия.
- **Торговля**: распределение через потребительские кооперативы; **без income tax**, налог на производство каждой единицы; экспорт — только готовых товаров, только в единицы без возможности производства, через кооперативы, без мотива прибыли; сырьё не экспортировать; free trade — после достижения самодостаточности.
- **Скорость денег**: чем чаще меняют руки, тем выше их экономическая ценность.
- **Психо-культурный слой**: уверенность местных против эксплуатации; **местный язык** во всех делах (администрация, образование, экономика, культура) — защита от психической эксплуатации.

## Key Concepts

- **Local people / outsiders** — критерий сращивания интересов.
- **Production for consumption** — максим.
- **Floating population** — источник оттока капитала.
- **Local language** — экономический и культурный инструмент.

## Mental Models

- «Децентрализация — не про уменьшение экономики, а про передачу руля местным: руль у одного — корабль тонет, у команды — плывёт».
- «Чужой товар на местном рынке — сдача позиций: сначала местный (даже хуже), потом улучшай его».

## Anti-patterns

- **Экономическая централизация** — «стратегия накопления капитала у немногих»; обещания лидеров — «жестокие розыгрыши».
- **Экспорт сырья** — отток богатства.
- **Отток местного капитала** и флоатинг-популяция.
- **Мотив прибыли в производстве** — конкуренция за самый прибыльный товар, игнор потребностей.

## Worked Example

Разрыв богатых/бедных: обычному — велосипед, заслуженному (врач) — машина; цель — поднять обычных до скутеров, сокращая разрыв, но никогда не дать ему вырасти (иначе «эксплуатация в обличье удобств»). Децентрализация не оставляет лазейки: растёт и минимум, и оценка удобств с точки зрения коллективного блага.

## Key Takeaways

1. Децентрализация — единственный способ остановить эксплуатацию.
2. Пять принципов: местные ресурсы, производство для потребления, кооперативы, занятость местных, местные рынки.
3. Key industries — «no profit, no loss», у местного правительства.
4. Экспорт — только готового, через кооперативы, без прибыли.
5. Местный язык — инструмент экономической и психической защиты.
6. Скорость обращения денег — мера их ценности.
