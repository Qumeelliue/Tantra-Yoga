# Chapter 17: Cooperative Production (Excerpt A + B)

*15 и 16 мая 1988, Калькутта.*

## Core Idea

Ранжирование систем производства: **кооперативная — лучшая**, затем частная (private enterprise), затем sharecropping (испольщина), и худшая — **коммуна**. Коммуна лишает стимулов и «чувства единства с работой»; sharecropping создаёт новый феодализм и petit bourgeoisie; кооператив соединяет стимулы, технологии и коллективную силу.

## Frameworks Introduced

- **Рейтинг систем**: cooperative > private enterprise > sharecropping > commune.
- **Дефекты коммуны**: отрицание индивидуальной собственности → нет стимула; рабочие — «волы с завязанными глазами»; интеллектуалы приравнены к простым работникам; производство падает; страны-коммуны закупают еду у капиталистических.
- **Дефекты sharecropping (испольщины)**: (1) арендатор может не обработать всё (7 акров у 3 хозяев = 21 акр — обрабатывает часть); (2) арендаторы бывают богаче землевладельцев → капитализм в сельском хозяйстве; (3) нанимают батраков сами; (4) мелкие владельцы не могут обработать сами → «новый феодализм»; (5) уход от land ceiling (арендатор не владелец — закон его не касается).
- **Дефекты частного земледелия**: до 100% неплодородной земли не используется; нет капитала на технику/семена/ирригацию; без земельных потолков — переаккумуляция.
- **Кооператив**: коллективная сила для давления на правительство (ирригация, семена), объединение участков (убрать межи), разделение сохраняется на неровной земле (иначе не оросить), максимум «больше производства, больше дивидендов, больше бонусов».
- **Экономическое планирование по блокам**: перекроить границы блоков по плодородию (все неплодородные — в один блок для планирования).
- **Практика кормов**: Napier grass, millet, jawar, khesári (безопасная обработка: замачивание и снятие шкурки убирает парализующие алкалоиды).

## Key Concepts

- **Bargadar / bhagcáśi** — бенгальские термины для арендатора-испольщика.
- **Distress/исходные стимулы**: «если произведу больше — заработаю больше».
- **Block-level planning по плодородию**.
- **Khesári** — pulse с токсичной шкуркой (см. также ch33).

## Mental Models

- «Думай о системах производства как о лестнице мотивации: чем выше личная связь с результатом, тем выше урожай».
- «Коммуна = конвейер без хозяина; кооператив = конвейер, где каждый совладелец».

## Anti-patterns

- **Коммуна** — «против человеческого», закупки продовольствия у капиталистов.
- **Sharecropping** — уход от законов о земельных потолках, новый феодализм, праздный арендатор.
- **Частное без потолка** — переаккумуляция, неиспользуемая земля.
- **Планирование по старым политическим границам блоков** — не учитывает плодородие.

## Worked Example

Арендатор собирает 21 акр у трёх владельцев и обрабатывает лишь часть — остальное пустует; его стандарт жизни выше, чем у хозяев; сам нанимает батраков. Всё это — зарождение нового феодализма и агрокапитализма. Кооператив решает: объединение, стимулы, технологии, коллективный голос.

## Key Takeaways

1. Кооператив — лучшая система; коммуна — худшая.
2. Sharecropping рождает феодализм и petit bourgeoisie.
3. Кооператив даёт стимулы и чувство единства с работой.
4. Планирование блоков — по плодородию, а не по политике.
5. Модернизация возможна в кооперативе, не в одиночку.
