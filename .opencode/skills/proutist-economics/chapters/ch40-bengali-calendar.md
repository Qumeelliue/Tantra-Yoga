# Chapter 40: The Bengali Calendar

*Дата N/A.*

## Core Idea

Бенгальский календарь — **солнечный**, учитывающий сезоны; используется для сельского хозяйства по всей Индии и Бангладеш. Точный календарь — научная основа земледелия.

## Frameworks Introduced

- **Солнечный календарь**: месяцы привязаны к сезонам (в отличие от лунного Hindi календаря, по которому «нельзя вести земледелие»). Грегорианский — тоже солнечный, но «не откалиброван» (начало арка — 14 апреля, середина месяца).
- **Соотношение**: солнечный год ~365 дней, лунный ~355; каждые ~3 года лунный уходит на месяц вперёд (⚠ к калибровке).
- **12 месяцев** (мид-апрель → мид-апрель): Vaeshákha, Jyaeśt́ha, Áśáŕha, Shrávańa, Bhádra, Áshvina, Kárttika, Agraháyańa, Paośa, Mágha, Phálguna, Caetra.
- **Применение**: сельское хозяйство по солнечным месяцам (посевы/урожаи aman/áus/boro, пшеница в Kárttika…); hathiya — сочетание Солнца и Луны в Рыбах при дожде — «отлично для урожая» (Bihar).
- **Исследования**: календари уточнять — «это сделает земледелие научным и увеличит продуктивность».

## Key Concepts

- **Solar calendar** — солнечный календарь.
- **Seasons alignment** — привязка к сезонам.
- **Hathiya** — благоприятная агро-комбинация.

## Mental Models

- «Солнечный календарь — это часы природы: посеешь по ним — попадёшь в сезон; по лунному — опоздаешь на сезон».
- «Точность календаря = точность урожая».

## Anti-patterns

- **Лунный календарь для земледелия** — рассогласован с сезонами.
- **Неточный солнечный календарь** — недоиспользование агро-возможностей.

## Worked Example

Bengal: áus сеют в Vaeshákha, собирают в Bhádra; aman — в сезон дождей; boro — конец зимы → лето; пшеница ранняя — 1–мид Agraháyańa, поздняя — до 7 Paośa. Так по солнечным месяцам планируется полный годовой цикл (см. ch33).

## Key Takeaways

1. Солнечный календарь — основа научного земледелия.
2. Лунный календарь для агро не годится.
3. 12 месяцев привязаны к сезонам (середина апреля — начало).
4. Уточнение календарей повышает продуктивность.
