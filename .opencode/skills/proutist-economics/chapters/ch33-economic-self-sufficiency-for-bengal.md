# Chapter 33: Economic Self-Sufficiency for Bengal

*6 июня 1986, Калькутта.*

## Core Idea

Бангалистан (Greater Bengal) может и должен стать экономически самодостаточным: самодостаточность в производстве **минимума** (еда, одежда, жильё, образование, медицина) + крупное производство **cash crops и не-аграрных продуктов**. Детальный региональный разбор ресурсов и культур.

## Frameworks Introduced

- **Два столпа самодостаточности**: (1) минимум требований (staple еда, ткань, стройматериалы, учебное оборудование, лекарства); (2) прибыльные cash crops и не-аграрные продукты.
- **Еда**: решить ирригацию (Ráŕh: shift/lift/tank/малые речные проекты; 4 урожая в год; aman/boro/áus ротация; рис за 90 дней); почвы (sticky Ráŕh для aman, sticky-sandy для áus/jute, sandy Bangladesh); регионы (Tripura: áus, чили, картофель; Nadia/Murshidabad: пшеница; берега: кокос). Самодостаточность достижима (пример Японии при большем давлении населения).
- **Paddy (детально)**: виды (áus — сухие поля, sticky-sandy, риск низкий; aman — 4 вспашки, трансплантация треугольником, вода до цветения; boro — требует 3× воды пшеницы, глубокие скважины, зимний/летний); побочные продукты (bran oil, цемент из husks + известняк + морская почва, бумага из straw, грибы из разложения). «Pigeon crops» — вторичные культуры между основными. Пшеница: три орошения, sticky-sandy, юго-западный ветер хорош; 90% пшеницы + 10% pulses (азот) = 100% пшеницы + 10% бобовых. Кукуруза: 60–80 дней, всесезонная, сухой климат.
- **Pulses**: замена животного белка (пастбищ не хватает); чёрный грам (энергия+сила), зелёный грам (быстрая энергия), cow pea (резервная); khesári — токсична в шкурке (замачивать/снимать).
- **Одежда**: cotton (tree/bush — Ráŕh/Tripura), mulberry silk (Ráŕh; garad/matka), non-mulberry (tasar/endy/muuṋgá), синтетика (nylon из кокоса/рисовой шелухи/джута; rayon из джута/ананаса/банана), шерсть (Ráŕh), jute-wool; linseed/okra/sesame — волокна на экспорт (Ahmedabad).
- **Стройматериалы**: кирпич/черепица, известь (известняк, ghuting — ~90% извести, раковины, устрицы), цемент (известь+известняк+доломит; из рисовой шелухи aman + ghuting — «в каждой деревне»), песок (Mogra), судостроение (garán/sundari wood Sundarbans; железо/марганец/медь/серебро Ráŕh; 4000 кв. миль Sundarbans, 1600 — WB, 2400 — BD — ⚠ к калибровке); каучук (Duars/Tarai/Tripura).
- **Образование**: родной бенгальский + английский (второй) + санскрит (обязательный); бумага из джута/mesta/bamboo/vicali grass/corn cobs; чернила из hematite/blue vitriol/indigo.
- **Медицина**: травы (Duars, Goalpara, Darjeeling plains, Jhańpa; Assam/Meghalaya/Sundarbans — второй пояс; Ráŕh/Tripura — третий) + минералы (ртуть, медь — Tamakhun, Manbhum); антимоний/мочевина (Jhargram/Birbhum/Dhanbad/Purulia/Singbhum).
- **Индустрии**: cash crops (чёрный перец Tripura, чили, зелёный грам 3 раза в год, rubber, cocoa/coffee, джут → грубая одежда, cashew — «hijli bádám», silk/lac, beeswax) и не-аграрные (mica — abhra, естественный газ/нефть, сера (Bakreswar-Nanur 80 миль), йод из морских водорослей (Digha), алюминий (Jhalda-Angara bauxite), соль (Digha/Contai/Ramnagar/Junput), сахар из сладкого картофеля, индустрии из linseed/okra.

## Key Concepts

- **Bangalistan** — Greater Bengal (самодостаточный блок).
- **Minimum requirements** — еда/одежда/жильё/образование/медицина.
- **Cash crops / non-agricultural industries** — две опоры.
- **Pigeon crop** — подсевная культура.

## Mental Models

- «Самодостаточность — это карта ресурсов против карты потребностей: каждую клетку карты заполни местным производством».
- «Отходы — это сырьё: шелуха → цемент, солома → бумага, жмых → топливо».

## Anti-patterns

- **Зависимость от чужих регионов** в минимуме (рис/ткань/лекарства) — уязвимость.
- **Экспорт сырья вместо переработки** — Бангладеш шлёт сырую кожу (нет технологии дубления).
- **Неправильные культуры для почв** (пшеница в сыром климате — грибок).
- **Глубокая скважина** — опускание зеркала (пример Malda/Nadia).

## Worked Example

Бенгалия может накормить ~70 млн (⚠ к калибровке) своими ресурсами: Ráŕh даёт aman/boro, Tripura — áus/картофель/чили, дельта — рыбу; четыре урожая в год при решённой ирригации. Пуралия/Банкура — беднейшие (еда из травы), но при правильном планировании — самодостаточны.

## Key Takeaways

1. Самодостаточность = минимум + cash crops + не-аграрные индустрии.
2. Почвы/климат определяют культуры; планирование по блокам.
3. Отходы агрикультуры — сырьё для индустрий.
4. Медицина и образование — из местных ресурсов.
5. Япония — доказательство: даже с давлением населения можно кормить себя.
