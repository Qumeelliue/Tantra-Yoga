# Chapter 34: Some Developmental Programmes for Bengal

*10 февраля 1989, Калькутта.*

## Core Idea

Метод развития: знать местность до деталей (города >100 тыс., источник питьевой воды, гигиена, доходы, экономическая база) и применять знания практически. Разборы кейсов: **Birbhum, Digha, Bankura** + принципы для любого блока.

## Frameworks Introduced

- **Вопросы планировщика**: главные производственные города; города >100 тыс.; источник питьевой воды (артезианская/дождь); гигиена; главный доход граждан; база (агро/индустрия/коммерция).
- **Birbhum**: два типа земли (высокая/низкая — Tarapith), люди высокой земли выше ростом; запад развитее востока; болезни кожи на высокой земле; образование района в 1856 из Suri/Rampurhat/Dumka/Deoghar/части Murshidabad.
- **Историко-культурный слой**: Pancha Gaur (пять сладких земель Бенгалии: Ráŕh, Samatat, Banga, Barendra, Mithila); Upabanga/Shriibhum; Caetanya и трибулы Tripura (Devaburman).
- **Tripura-заметки**: почвы granite (Kamalpur — cashew/ананас); садковидная топография; картофель 2 раза в год (красный/белый); источник воды Salema (река Dhalai из Longthorai Hill — сезонна).
- **Digha**: «Diirghaka» → Diirghá → Digha; самый широкий пляж в мире; **масштабная аффорестация** samudric jhau вдоль берега против штормов; каменные подпорные стены против эрозии (штормы ~каждые 7 лет); дорога+железная дорога до Bhograi; **порт Bhograi** (устье Suvarnareka) вместо только Calcutta Port для кокоса/рыбы/бетеля/cashew; marine drive для туризма.
- **Bankura**: три зоны — Visnupur subdivision (aman хорош, áus/boro нет, ирригация/дренаж); Indus block (плоская, схожа с Burdwan — планировать вместе); Khatra + остальное (волнистое, минералы: уголь/слюда/серебро/медь южнее дороги Purulia–Bankura). Почва для гори-культуры (grapes/сладкие лимоны/папайя/guava; Taldanga — gourd). Разделить по потенциалу (агро/гори/минералы).
- **Принцип развития региона**: учесть power/water reserves, community problems, землю/почвы, mixed farming, сырьё, местные индустрии.

## Key Concepts

- **Know your area** — главный принцип планировщика.
- **Pancha Gaur** — пять сладких земель.
- **Marine drive / Bhograi port** — инфраструктура Digha.
- **Zonation by potential** — деление района по потенциалу.

## Mental Models

- «План без знания местности — рецепт без кухни: ингредиенты есть, а блюда нет».
- «Каждый регион — пазл: собери карту потенциалов, и самодостаточность сложится сама».

## Anti-patterns

- **Планирование из кабинета вдали** — бесполезно (см. ch20).
- **Игнорирование штормов/эрозии** на побережье.
- **Смешивание зон с разным потенциалом** в один план.

## Worked Example

Digha: при аффорестации + стенах + железной дороге до Bhograi + порте — курорт мирового уровня, туризм, экспорт кокоса/рыбы/cashew через новый порт, конец оттока людей в Calcutta/Durgapur/Bombay.

## Key Takeaways

1. Знать местность до деталей — условие плана.
2. Digha: аффорестация + стены + порт Bhograi + железная дорога.
3. Bankura: делить на зоны по потенциалу (агро/гори/минералы).
4. Инфраструктура создаёт экономику, а не наоборот.
5. Каждый блок — свой детальный разбор.
