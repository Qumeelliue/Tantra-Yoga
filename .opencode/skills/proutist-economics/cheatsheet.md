# Читшит — правила решений по экономике PROUT (Proutist Economics)

## Показатели и цели

| Ситуация | Правило |
|---|---|
| Оценить благосостояние | Покупательная способность, не per capita income (Ch 2, 21, 30) |
| Распределить богатство | Минимум всем → излишек по merit → максимум удобств всем (Ch 1, 8) |
| Увеличить покупательную способность | Максимум essential-производства; стабильные цены; рост без инфляции (Ch 2) |
| Выбрать производство | Для потребления, не для прибыли (Ch 22, 23) |

## Деньги и торговля

| Ситуация | Правило |
|---|---|
| Куда вкладывать займы | Только в продуктивное; никаких «вокзалов вместо линий» (Ch 4) |
| Депрессия | Концентрация богатства + блокировка оборота денег; лечить оборотом и производством (Ch 11, 12) |
| Торговля между единицами | Бартер; сырьё не экспортировать — перерабатывать на месте (Ch 2, 22) |
| Налоги | Без income tax; налог у источника производства; essential — tax-free (Ch 2) |
| Экспорт | Только готовое, через кооперативы, без прибыли, в единицы без возможности производства (Ch 22) |

## Кооперативы и земля

| Ситуация | Правило |
|---|---|
| Организовать производство | Кооператив (координация), не коммуна (субординация) (Ch 15, 17) |
| Акции кооператива | Только dividend; голосование по человеку (Ch 15, 30) |
| Земля | Фазовая социализация (4 фазы); НЕ «земля пахарю» (Ch 13, 14) |
| Размер кооператива | Определяют сами фермеры; против гигантских колхозов (Ch 14) |
| Состав членов | Только местные; флоатинг-популяция исключается (Ch 15, 22) |

## Планирование

| Ситуация | Правило |
|---|---|
| Уровень планирования | Block (низший) → district → state → national → global (Ch 21) |
| Факторы плана | Cost of production, productivity, purchasing capacity, collective necessity (Ch 21) |
| Откуда план | Снизу вверх, на месте, местными; ответственность — моралистам (Ch 20) |
| Сроки | Short ≤6 мес., long ≤3 года (⚠ к калибровке) (Ch 21) |
| Занятость | ≤30–45% в сельском хозяйстве (⚠ к калибровке) (Ch 13, 24) |
| Отсталые классы | Приоритет по нужде (бедные/отсталые → …), не по касте (Ch 25) |

## Вода и экология

| Ситуация | Правило |
|---|---|
| Источник воды | Поверхностные воды; дождь где падает; НЕ глубокие скважины (Ch 16, 19) |
| Берега рек | Аффорестация; деревья держат воду (Ch 19, 35) |
| Удобрения | Органические предпочтительны; химия — с исследованиями (Ch 16) |
| Циклоны/эрозия | Прибрежная лесополоса ~1 миля (Ch 35) |

## Диагнозы («tells»)

- Per capita растёт, а простые люди беднеют — «обманчивый индекс»; смотри покупательную способность (Ch 30).
- Отрасль на импортном сырье — «больная» (Ch 38, 39).
- Деньги замерли у немногих — готовится депрессия (Ch 11).
- Обещают «равное всем» — утопия/обман; обещают минимум+рост — PROUT (Ch 1, 8).
- Доминирует класс/группа — она эксплуатирует; смена доминанта не лечит (Ch 1).
- План из кабинета вдали — миф; план на месте — практика (Ch 20).
