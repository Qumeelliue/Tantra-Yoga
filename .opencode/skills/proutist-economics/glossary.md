# Глоссарий — Proutist Economics

**Agrico-industries** — пред-уборочные отрасли: способствуют росту агропродукции (Ch 30).
**Agro-industries** — после-уборочные отрасли, зависящие от агропроизводства (Ch 30).

**Бартер (barter trade)** — обмен товарами без денег; основа торговли между самодостаточными единицами; защита от депрессии (Ch 2, 11, 12, 32).

**Блок (block)** — низший уровень планирования; Block-level planning board в каждом блоке (Ch 21).

**Булльон** — золото/серебро как мера обмена; «bullion value» денег (Ch 11).

**Ваешья-эра (Vaeshya Era)** — эпоха капиталистов/производителей; «последняя стадия» сейчас (Ch 1, 11).

**Время-место-личность (desha-kála-pátra)** — факторы, по которым меняется метод использования; прогрессивное использование (Ch 1).

**Dividend shares** — дивидендные акции кооператива (по чистой прибыли); против profit/preference акций, ведущих к коммерциализации (Ch 15, 30).

**Distress sale** — вынужденная продажа урожая под давлением нужды (Ch 15, 30).

**Джут (jute)** — «больная отрасль» из-за синтетики; примеры Dundee/Bengal (Ch 2, 39).

**Economic holding** — земельное держание, где выпуск > затрат; минимум/максимум по региону (Ch 13, 14).

**Экономическая демократия** — политическая централизация (у моралистов) + экономическая децентрализация (у местных); против «политической демократии» (Ch 24).

**Экономическая единица (socio-economic unit)** — самодостаточная группировка по 5 критериям (проблемы, потенциалы, этнос, сентименты, география); 44 в Индии (Ch 3, 20).

**East Wet Theory** — влажный восток = ниже активность, сухой запад = выше; гео-психология в планировании (Ch 26).

**Фазовая социализация земли** — 4 фазы кооперирования земли (неэкономичные → все → рациональное распределение → без конфликта) (Ch 13, 14, 15).

**Флоатинг-популяция** — «плавающее население», не срастившее интересы с регионом; селить или возвращать (Ch 13, 20, 22, 26).

**Gandhahárin** — ремесленник, вынужденный странствовать за заработком (Ch 23).

**Guńatrikońa / lokatrikońa** — треугольник сил (три гуны) / треугольник трёх сфер существования (Ch 7).

**Keep money rolling** — деньги в обращении; застой денег → депрессия (Ch 4, 11, 12).

**Координационная кооперация** — действие с равными правами и на благо друг друга; против субординированной (мастер-слуга) (Ch 15).

**Кооператив** — лучшая система производства/распределения; типы: farmers/producers/consumers/service/banking/housing/annuity (Ch 15).

**Минимум требований (minimum requirements)** — food/clothing/housing/education/medical (+ транспорт/энергия/вода), гарантируются всем; растут с эпохой (Ch 1, 2, 8).

**Максимум удобств (maximum amenities)** — гарантируется всем «по условиям среды»; special amenities — заслуженным по merit (Ch 8).

**Покупательная способность** — реальный показатель благосостояния (против per capita income); максим «выше всего — покупательная способность простых людей» (Ch 2, 11, 21, 30).

**Production for consumption** — производство для потребления, не прибыли (Ch 22, 23).

**Psycho-economy** — часть экономики о психических пабулах и борьбе с психо-эксплуатацией (Ch 5, 6).

**Psycho-economic exploitation** — психическая + экономическая эксплуатация (язык, культура, СМИ, «секуляризм») (Ch 9, 31).

**Pramá** — равновесие + равно-взвешенность всех сфер (физической/психической/духовной) (Ch 7).

**Pseudo-revisionism** — «похоже на оригинал, но не суть»; ярлык коммунизма (Ch 10).

**Sadvipra** — моралист/духовный искатель в ядре социального цикла; контролирует смену эпох силой (Ch 1, 25).

**Sarva jana hitáya** — «благо всех»; идеал Proutistic social order (Ch 25).

**Shúdra-революция** — подъём большинства работников против доминирования; финал витка цикла (Ch 1).

**Систальтика** — ритмичное (сжатие/расширение) движение всего; статичность — болезнь (Ch 11).

**Сюзеренитет vs супремация** — авторитет без налогов / с налогами (Ch 18).

**Value of wealth** — ценность богатства = его покупательная способность (Ch 30).

**Zamindar** — налоговый посредник-помещик (Ch 18).
