# Глава 5: Санскрит — язык Тарака Брахмы

*Лингвистико-духовная часть.*

## Core Idea

Санскрит — «гирвани» (язык божественных существ), духовный язык науки, изобретённый в Индии (не принесённый ариями). Автор объясняет его происхождение, психо-акустические основы, историю изучения и будущую роль как мирового языка.

## Frameworks Introduced

- **Санскрит = indigenous language Индии**, не «импортированный из Центральной Азии» (по Бабе, Discourses on Tantra Part 1): в древности один язык шёл от Центральной Азии до Юго-Восточной Азии; юго-восточная ветвь = санскрит, северо-западная = ведический.
- **Психо-акустические заметки** (по Varna Vijinana): при виде объекта в нервах возникает ментальный звук (напр., белый — «dhapdhap», красный — «taktak»), затем слово; так создаются корни языков; семь основных звуков → семь нот → все языки и музыка.
- **Инференциальные акустические заметки**: звук, возникающий от контакта слуховых нервов с внешним звуком (голоса животных): Sa — павлин, Re — бык, Ga — коза, Ma — лошадь, Pa — кукушка koel, Dha — осёл, Ni — слон.
- **Пятьдесят букв**: 16 гласных (svara) + 34 согласных (vyanjana); «один звук — один символ».
- **Vyarana (грамматика) Панини** — «Аштадхьяйи» (~400 до н.э.): 4000 правил, непревзойдённая научность.
- **Шесть стадий выражения идеи**: para (центр идеи) → pashyanti (видение способа выражения) → madhyama (идея получает медиум) → vaikhari (облечение в конкретный язык) → dyotamana (звук внутри) → shrutigocara (слышимый).
- **Санскрит в будущем**: по Бабе — возрождение как мирового языка (~500 лет), роль в сохранении культурного единства Индии.

## Key Concepts

- **Shabda (звук)** → **Shabda Brahma**: идея творения сначала выражается как звук; звук-Брахма — первое выражение Ka'rana Brahma.
- **Bija mantra / акустический корень** — звук действия (напр., «ha ha ha» — смех).
- **Akshara mala** — «гирлянда букв» (индийские алфавиты).
- **Рg Veda** — древнейший письменный санскрит, ~15 000 лет (по книге); 1 028 гимнов.
- **Практические факты**: бенгали — 94% санскритская лексика; латынь — «дочь ведического»; Monier-Williams словарь (1872).

## Worked Example

*Слово dhavala (белый).* Видя белый цвет, нерв создаёт звук «dhapdhap»; «dhava» + суффикс «la» → «dhavala» = «белый». Автор показывает, как психо-акустическая теория объясняет возникновение слов без случайности.

## Key Takeaways

1. Санскрит — indigenous духовный язык, а не импорт ариев.
2. Звуки языка имеют психо-акустическое происхождение; музыка и речь — из одной системы.
3. Санскрит — язык мантр и тангрической практики (50 биджа-звуков соответствуют кундалини).
4. Грамматика Панини — научный эталон; важность фонетики.
5. По Бабе, санскрит — будущий мировой язык; его исчезновение = культурная смерть Индии.
