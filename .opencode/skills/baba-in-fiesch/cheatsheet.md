# Читшит — Baba in Fiesch

## Идеация и ум

| Ситуация | Правило |
|---|---|
| Выбрать объект медитации | Только бесконечный (Парама Пуруша); все конечные суррогаты — отсев (Ch 7) |
| Думаешь «я грешник / я неудачник» | Замени на положительную идеацию «я дитя Отца»; Kiirtan очищает (Ch 6, 13) |
| Боишься призрака/провала | Призрак — твой эктоплазм; держи факел против тьмы, не тьму в кармане (Ch 9, 12) |
| Хочешь измениться | «Как думаешь, так и станешь»; начинай «я сделаю», не «я попробую» (Ch 12) |

## Практика и самадхи

| Ситуация | Правило |
|---|---|
| Объяснить самадхи | Лестница: Dashá → Bhává → Bhává Samádhi → Mahábhává → Nirvikalpa (Ch 10) |
| Выбор мантры | Bábá Nám Kevalam — главная мантра Ананда Марги (Ch 3) |
| Танцы | Тандава (муж., сила) / Kaoshikii (расширение ума) / Kiirtan (мост к медитации) (Ch 9) |
| Медитация | Секрет: «Он — субъект, я — объект; помни, что Он видит тебя» (Ch 6) |

## Успех и дисциплина

| Ситуация | Правило |
|---|---|
| Цель в жизни | Твёрдая решимость + shraddhá + Гуру + без комплексов + самоконтроль + умеренность (Ch 10) |
| Отношение к еде | Pramitáhára: мало, но субстанциально; мясо — уму и духу вред (Ch 10) |
| Дисциплина | Из любви, не из страха; скриптуры-запугивание — враги единства (Ch 3) |
| Препятствия | Борьба (sangram) — норма; война (yuddha) — зло; человек сильнее препятствий (Ch 10) |

## Лидерство и обучение

| Ситуация | Правило |
|---|---|
| Обучать сопротивляющихся | Парадокс/юмор/притча → разворачивание смысла («наказание» как любовь) (Ch 8, 10) |
| Наладить личный контакт | Прогулка, малая группа, вопросы о деталях мира (Ch 1, 2) |
| Понимать «грешника» | Samyak Darshan: видеть причину, не судить; перестраивать общество (Ch 11) |
| Доводить дело | Samyak Karmánta: не бросать начатое до завершения (Ch 11) |
