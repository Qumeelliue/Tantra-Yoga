# Читшит — правила решений по Саркару (Subhasita 19)

## Цели и преданность

| Ситуация | Правило |
|---|---|
| Определить тип цели | Káma (материя) / Artha (психика) / Dharma (психо-дух) / Mokśa (дух) |
| Есть ли «переваривающий плод» | Без преданности плоды «не перевариваются»; преданность — философский камень |
| Просящий благ у Господа | Это не преданность; преданный просит занятости в служении |
| Держит что-то своё | Полная сдача обязательна («одна пайса» своей силы блокирует помощь) |

## Пропенсивности и поведение

| Ситуация | Правило |
|---|---|
| Классифицировать поведение | Кривая боли: боль-боль (клишта), радость-радость (аклишта — бхакти), боль-радость (студент), радость-боль (взяточник) |
| «Гоняюсь за славой» | Это Sambit-сигнал: пора развернуться к главным пропенсивностям |

## Проступки (патаки)

| Ситуация | Правило |
|---|---|
| Оценить тяжесть | Рекуррентность: обычный < atipátaka (непоправим) < mahápátaka (рекуррентное зло) |
| Искупление mahápátaka | Отречение + служение + изобрести рекуррентное добро («пенициллин») |
| Pápa vs «грех» | Папа = препятствие развитию (не библейский грех); puńya = развитие других |
| Неделание должного | pratyaváya так же важен, как запретный акт |

## Импульсы и майя

| Ситуация | Правило |
|---|---|
| «Плохой» импульс | Не подавляй — канализируй к высшему; подавленное прорывается |
| Саттва-гуна довела почти | Дальше — Bháva-ságara; его переходит только преданность |
| Борьба с майей | Бесполезна: майя сильнее; побеждай через её помощь |

## Фокус и рост

| Ситуация | Правило |
|---|---|
| Много устремлений | Эшана двойная = провал; один объект эшаны обязателен (бхакти, не а̄сакти) |
| Долгий рост к цели | Восемь Samyak-факторов: цель/решимость/речь/занятие/упражнение/завершённость/память/приостановка |
| Милость не «доходит» | Проверь зонт эго: сними — и промокнешь |
| Спор учёных о направлении | Иди за практиками (mahájanas), не за спорами |

## Быстрые сигналы («tells»)

- «Мне приятно творить» → рагануга; «Ему приятно, мне неважно» → рагатмика (Gopa).
- Подавление бхавы → прорыв с силой; канализация → тонкая волна.
- «Хочу и Господа, и сдачу экзамена» → двойная эшана, работа не сделается.
- После киртана тянет на другую музыку → нарушение «закона» Mohana Vijiṋána.
- Зло кажется огромным → вспомни метафору светлячка против солнца.
- «Я не верю в Бога» в полдень, «спаси меня» в полночь → все боятся Его (боязливая любовь — начало садханы).
- Хвалишься знанием из старой книги → «первоклассный дурак» (Ch 7).
