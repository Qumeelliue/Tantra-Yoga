# Глава 10: The Path of Salvation

*Дискурс от 26 сентября 1979 DMC, Caracas.*

## Core Idea

Всё движется по пульсации (systaltic): скорость-пауза. Спасение = слияние с ядром (nucleus): движение вокруг Парама Пуруши с уменьшением радиуса до нуля. Восемь факторов Будды уменьшают радиус (усиливают Vidyá); зонт эго мешает «дождь милости».

## Frameworks Introduced

- **Пульсация движения**: скорость-пауза (systaltic) — сущность всякого движения; в паузе набирается сила, в скорости — эманация; нет абсолютной скорости или абсолютной паузы.
- **Ядро и движение по эллипсу**: во всех порядках (атом, луна-земля, солнце-планеты, космос) — ядро + движение вокруг; космологический порядок уникален: ядро духовное (Парама Пуруша) с потенцией психического/физического, движущиеся — физические.
- **Vidyá vs Avidyá**: центростремительная (уменьшает радиус) vs центробежная (увеличивает); усиление Видьи = спасение (радиус → 0 → слияние с ядром).
- **Восемь факторов Будды (Samyak...)**: Darshan (правильная философия/знание цели), Saḿkalpa (твёрдая решимость), Vák (правильная речь/ориентация нервов), Ájiiva (чистая профессия, не против коллектива; «человек — социальное существо»), Vyáyám (правильное упражнение тела-ума-духа), Karmánta (завершай начатое), Smrti (правильная память — постоянная память о мантре во всех делах), Samádhi (правильная приостановка ума в Парама Пуруше).
- **«Человек — не рациональное животное»**: человеческая жизнь — «идеологический поток»; старые логики («рациональное животное») и «животное = движущееся растение» — отвергнуты.
- **Сфера освобождения**: прогресс физики/психики конечен (проблемы создают проблемы); настоящий прогресс — в духовной сфере (вне времени/места/личности).
- **Умbrella of ego (зонт эго)**: милость — дождь, зонт эго не даёт промокнуть; сними зонт → будешь омыт милостью. Милость — для всех (все дети Его); разница — в осознании её.
- **Принятие милости**: «не бойся отца»; Он всегда зовёт — отвечай.

## Key Concepts

- **Systaltic movement** — движение через скорость и паузу (пульсация).
- **Vidyá Shakti** — центростремительная сила к ядру.
- **Samyak Darshan и др.** — восемь «правильных» факторов.
- **Social creature** — человек социальное существо; профессия не должна вредить коллективу.
- **Radius → 0** — слияние с ядром = спасение.
- **Samyak Smrti** — постоянная память о мантре (даже при работе), а не только в медитации.

## Mental Models

- «Думай о спасении как о сжатии радиуса: каждый "правильный фактор" уменьшает расстояние до ядра».
- «Используй два вида сил: центробежная (зло/хаос) увеличивает радиус; центростремительная (Видья) сжимает».
- «Помни о пульсации: в паузе — сила, в скорости — движение; не ищи абсолютной остановки».
- «Думай о зонте эго как о барьере для дождя милости: сними его — и промокнешь благодатью».

## Anti-patterns

- **Думать, что физика/психика дают постоянный прогресс**: проблемы создают проблемы — только духовное вне ограничений.
- **Профессия против коллектива**: воровство/азарт — не «правильное занятие».
- **Незавершённое дело**: начал — закончи (Samyak Karmánta).
- **Зонт эго**: гордость мешает принять милость.
- **Страх «не хватит силы»**: «ты всегда в Его поле зрения, ты не один».

## Worked Example

*Уменьшение радиуса.* Аспирант движется вокруг ядра (Парама Пуруша) по эллипсу. Усиливая Vidyá (центростремительную), он уменьшает радиус. Восемь факторов: знает цель (Samyak Darshan), твёрдо решает (Samyak Saḿkalpa), правильно говорит (Samyak Vák), честно зарабатывает (Samyak Ájiiva), упражняет тело-ум-дух (Samyak Vyáyám), завершает дела (Samyak Karmánta), помнит мантру в делах (Samyak Smrti), приостанавливает ум в Нём (Samyak Samádhi). Радиус → 0 → слияние с ядром = спасение. Снимает зонт эго — милость (дождь) его омывает.

## Key Takeaways

1. Всё движение пульсирует: скорость-пауза; абсолютной остановки нет.
2. Спасение — сжатие радиуса до нуля вокруг духовного ядра.
3. Vidyá (центростремительная) vs Avidyá (центробежная); усиливайте Видью.
4. Восемь правильных факторов (Samyak) — практический путь сжатия радиуса.
5. Милость для всех; зонт эго мешает её принять — сними его.
6. Человек — социальное существо; профессия не должна вредить коллективу.
