# Глоссарий — Ánanda Vacanámrtam Part 1

**Абхога (abhoga / viśaya)** — объект, «питающий» ум; ограниченная пища = ограниченный ум, бесконечная = освобождение (Ch 13).

**Авирбхава (ávirbháva)** — внезапное явление духовного блага; антоним пра́дурбхавы (Ch 23, 28).

**Агос/аэшварья (áeshvarya)** — оккультная сила (vibhúti), восемь сиддх (Ch 30).

**Ананда (ánanda)** — блаженство; в отличие от sukham (счастья) — бесконечное (Ch 14).

**Атıпа́таки (atipátakii)** — грешник, причинивший постоянный ущерб; искупает жертвой личных удовольствий (Ch 12).

**Аум (aum / oṋm)** — a (творение) + u (сохранение) + ma (отзыв) = Generator-Operator-Destroyer, «G-O-D» (Ch 31, 35).

**Бха́гавата дхарма** — свадхарма человека: vistára (расширение), rasa (преданность), sevá (служение) (Ch 20).

**Бхагава́н (Bhagaván)** — обладатель шести качеств: áeshvarya, prátapa, yasha, shrii, jiṋána, vaerágya (Ch 30).

**Бхава (bhava)** — реакции/реактивные моментумы, океан которых пересекают кораблём-Господом (Ch 10).

**Бхакти** — корень «bhaj»+«ktin»: движение к Единому без второй мысли (Ch 16, 30).

**Ваекунтха (Vaekuńt́ha)** — «без сокращения»; состояние ума, свободного от сжимающего греха (Ch 17).

**Вайрагья (vaerágya)** — непривязанность; не давать уму окрашиваться цветом объектов (Ch 30).

**Вибхути (vibhúti)** — оккультные силы (Ch 30).

**Виира (viira) / виирабхава** — герой / героическое состояние: готовность сражаться с невзгодами (Ch 36).

**Випра / випрапатти (viprapatti)** — установка «всё делаю я»; основа материализма (Ch 7).

**Глáни (gláni)** — деградация дхармы ниже принятого стандарта (Ch 23).

**Гопа (gopa)** — «доставляющий удовольствие» Господу (корень gup), не «пастух» (Ch 16, 29).

**Дхира (dhiira)** — стойкий в идеале при похвале/брани, богатстве/бедности, жизни/смерти (Ch 19).

**Дхьяна** — корень «dhae»: оттянуть наклонности и устремить к Высшему; без любви бессмысленна (Ch 29).

**Джапа (japa)** — повторение Iśt́a mantra; mánasika (мысленный) — лучший, vacanika (голосовой) — худший (Ch 10).

**Джива (jiiva) / дживатва** — единичное сознание / единичность (Ch 13).

**Иишвара (iishvara)** — контролёр; Maheshvara — Господь всех контролёров (Ch 34).

**Ист́а-мантра (Iśt́a mantra)** — личная мантра после инициации (Ch 10, 19).

**Клсита (kliśt́a)** — см. паттерны/читшит (термин пробного тома).

**Космологическое Ядро / Puruśottama** — центр космоса, источник энергии (Ch 11, 14, 18).

**Кришна** — три объяснения: философское, биологическое, историческое (Ch 14).

**Мадхьяма / нича / уттама** — категории по готовности к работе (Ch 21).

**Майя (Daevii Máyá)** — тройственная творческая сила Господа; подчинена Ему (Ch 8).

**Маха́па́таки (mahápátakii)** — грешник с повторяющимися грехами; искупление — жизнь + постоянная польза (Ch 12).

**На́рада** — «дающий преданность» (nara+da) (Ch 17).

**Нара́яна (Náráyańa)** — всепроникающий Господь; ставит Своё ядро там, где поют Его имя (Ch 17).

**Па́па / пратьява́йя / па́така** — грех совершения / грех упущения (хуже) / совокупность (Ch 12, 26).

**Парама Пуруша** — Всевышний; «большой корабль» через океан реакций (Ch 8, 10).

**Пашу (pashu)** — животная стадия человека; Господь для них — Pashupati (Ch 36).

**Пранава (Prańava)** — «движение»; aum — контролирующее слово (Ch 35).

**Прана́ипата (prańipáta)** — полная самоотдача Всевышнему (Ch 6).

**Прапатти (prapatti)** — «я — инструмент в руках Господа»; основа вайшнавизма и суфизма (Ch 7).

**Парапатти-итог** — «Ты еси» (Tvamasi) (Ch 7).

**Пратьяга́тма (Pratyagátmá)** — Господь, свидетельствующий Свои отражения (Ch 34).

**Пра́дурбхава (prádurbháva)** — предчувствие akalyáńa (зла); антоним авирбхавы (Ch 28).

**Пратисаинчара (pratisaiṋcara)** — центростремительное движение к Ядру (Ch 12).

**Руадра (Rudra)** — «заставляющий лить слёзы» (и горя, и блаженства); единый контролёр (Ch 28, 33).

**Ра́га́нуга́ бхакти** — «люблю, потому что мне приятно» — не финальная стадия (Ch 16).

**Ра́га́тмика́ бхакти** — «люблю, чтобы доставить удовольствие Тебе» — вершина (Ch 16).

**Ра́ма** — три значения: блаженство йогинов, самое блистательное, смерть Раваны (Ch 14).

**Равана (Rávańa)** — десятиликий внешне направленный ум; Rao+Ana — «толкающий в падение» (Ch 14, 15).

**Садхана** — духовная практика; усилие поиска скрытого за творением Господа (Ch 33).

**Садвипра сама́джа** — духовное общество, цель при yuga parivarttana (Ch 24).

**Сайва (sevá)** — бескорыстное служение без желания получить (Ch 6).

**Сам́кальпа (saḿyak samkalpa)** — правильная идеология + твёрдая решимость достичь цели (Ch 27).

**Самскара (saḿskára)** — ментальные реактивные моментумы (Ch 5).

**Сарва (sarva)** — «всё»: sa (sentient) + ra (энергия) + va (характеристика) (Ch 11, 35).

**Сахитарака Брахма (Táraka Brahma)** — Освобождающий Брахма, приходящий при деградации дхармы (Ch 23, 24).

**Свадхарма / парадхарма** — своя дхарма / чужая (Ch 20).

**Сина́чара (saiṋcara)** — центробежное движение творения.

**Синтативный/мутативный/статический** — три гуны: sentient/mutative/static (Ch 1, 32).

**Упа́дхи** — см. пробный том (различающие атрибуты).

**Шастра (shástra)** — дисциплина, ведущая к освобождению (Ch 30).

**Шива-таттва (shivatva)** — космичность, цель человека (Ch 13).

**Шлока о дхира** — стойкость при всём (Ch 19).

**Шрия (shrii)** — притяжение, атрибут Бхагавана (Ch 30).

**Шудра (shúdra)** — рождённый с «привычками животности»; первая ступень до посвящений (Ch 36).
