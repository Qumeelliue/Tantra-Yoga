# Chapter 36: From Animality to Divinity

*Дискурс 7 сентября 1978 (утро), Patna. Discourse 36 серии.*

## Core Idea

Каждый по рождению — pashu (животное); процесс возвышения pashu → man → devatá и есть садхана. Имена Господа соответствуют стадии искателя: Pashupati (спящее человечество) → Viireshvara (герои) → Mahádeva (божественные). Высшая стадия — когда мысли, слова и дела едины.

## Frameworks Introduced

- **Три стадии человека** (из Rudrayámala Tantra): pashu (животное) → viira (герой) → devatá (божественный).
- **Четыре ступени по рождению/посвящению**: рождённый — shúdra (все «привычки животности»); получивший вайдики-дикшу — dvija (второе рождение, «уже не животное»); прошедший писания, духовное знание — vipra; получивший та́нтрики-дикшу (психо-духовную) — Bráhmańa.
- **Имена Господа по стадии**: Pashupati («Господь животных») — для спящего человечества; Viireshvara — для viiras, готовых сражаться с невзгодами; Mahádeva — для достигших divyabháva.
- **Viirabháva**: когда человек знает «что делать, чего не делать» и готов биться со всеми невзгодами; «никогда не боится, не принимает поражения». Viira → его Господь Viireshvara. (Примечание автора: «он» включает «она».)
- **Divyabháva**: полное утверждение в viirabháva → deva/devatá «в человеческой структуре».
- **Три выражения и их согласованность**:
  - pashu: мысли, слова, дела разрознены («психические волны идут так, губы говорят иначе, действия — третье»); в обществе таких большинство.
  - viira: слова = дела, но мысли ≠ слова; в обществе их уважают как mahapurusas/лидеров — но дефект остаётся.
  - devatá: мысли = слова = дела; «лучшая стадия человеческого существования».
- **Миссия работников**: увеличивать число devatás в человеческом обществе.

## Key Concepts

- **pashu → viira → devatá** — стадии возвышения.
- **shúdra → dvija → vipra → Bráhmańa** — ступени по посвящениям.
- **Pashupati / Viireshvara / Mahádeva** — имена Господа по стадии.
- **viirabháva / divyabháva** — героическое / божественное состояние.
- **мысли-слова-дела** — критерий стадии (ср. ch03).

## Mental Models

- «Думай о духовном прогрессе как о выравнивании трёх регистров: мысли-слова-дела постепенно сходятся в одно».
- «Думай об имени, которым ты обращаешься к Господу, как о зеркале твоей стадии».

## Anti-patterns

- **Считать «могущество» итогом** — viirabháva не финал; дефект (мысль ≠ слово) остаётся.
- **Оставаться в pashu-состоянии** — разрозненность трёх регистров; «уменьшайте число таких людей».
- **Относить «он» только к мужчинам** — «он» означает и «она» (ремарка автора).

## Worked Example

*Кто-то говорит: «я обычный, куда мне до божественного». Автор: по рождению все — pashu; но стандарт — возвышение к godliness. Сначала узнаёшь, что можно и что нельзя, становишься готов сражаться — viira; твой Господь уже Viireshvara. Доведя героизм до совершенства (никогда не принимать поражение) — приходишь к divyabháva, становишься devatá; Господь — Mahádeva. Критерий: у pashu мысль-слово-дело разрознены (большинство), у viira слова=дела, у devatá всё едино.*

## Key Takeaways

1. Все рождаются pashu; садхана — путь к godliness.
2. Стадии: pashu → viira → devatá; Господь: Pashupati → Viireshvara → Mahádeva.
3. Ступени посвящений: shúdra → dvija → vipra → Bráhmańa.
4. Viirabháva — бой с невзгодами; divyabháva — никогда не принимать поражение.
5. Devatá = мысли=слова=дела; цель работников — умножать таких людей.
