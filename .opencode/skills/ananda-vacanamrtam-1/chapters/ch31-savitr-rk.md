# Chapter 31: Savitr Rk

*Дискурс 2 сентября 1978, Patna. Discourse 31 серии.*

## Core Idea

«Гаятри-мантра» на самом деле называется **Savitr Rk** — рик (шлока) третьей мандалы, 62-го сукты, 10-го рика Рк Веды, обращённая к Savitá (Творцу-Отцу). Суть молитвы — направление ума к блаженству; разбор «aum»: a=создание, u=сохранение, ma=отзыв → G-O-D.

## Frameworks Introduced

- **Структура Рк Веды**: мандалы → сукты → рики; «Рк Веда» названа по «рик» (шлока/знание); в ведическое время не было письменности — отсюда «Shruti» (услышанное); санскрит не имеет собственного алфавита.
- **Savitr Rk**: третья мандала, 62-й сукта, 10-й рик; назван по слову обращения «Savitá».
- **Семь ритмов**: gáyatrii, uśńika, triśt́upa, anuśt́apa, brhati, jagatii, paunkti; гаятри = 3 строки по 8 слогов.
- **Ритм против грамматики**: при конфликте грамматики и ритма поддерживается ритм (поэтому «vareńi-yam» разбито на две части).
- **«Oṋm» (aum)**: у любого действия — акустическое проявление. Творение = действие → звук «a» (первая буква/альфа); сохранение и питание → «u»; отзыв/разрушение → «ma». Generator-Operator-Destroyer = «G-O-D».
- **Семь слоёв**: выражения септилинейны; три мира (физический, психический, астральный); их творец — Savitá; «для планеты Земля солнце — savitá»; для всех систем — Космическое Ядро = Отец.
- **Применение**: до инициации проси Космического Отца вести интеллект к блаженству; после получения Iśt́a mantra — следуй правилам, просить больше нечего.

## Key Concepts

- **Savitr Rk** — «рик для Савиты» (не «гаятри-мантра»).
- **mańd́ala / súkta / rk** — структура Рк Веды.
- **Shruti** — услышанное (Вед а).
- **aum = a+u+ma** — создание/сохранение/отзыв.
- **Savitá** — Творец/Отец (ср. ch22).

## Mental Models

- «Думай о "гаятри" как о жанре, а о тексте — как о конкретном рике: правильное название — Savitr Rk».
- «Думай о звуке как о следе любого действия: у каждого выражения есть акустический корень».

## Anti-patterns

- **Называть Savitr Rk «гаятри-мантрой»** — неточность: гаятри — ритм, рик назван по адресату.
- **Править ведический текст по грамматике** — при конфликте ритм сильнее.
- **Использовать гаятри после инициации** — после Iśt́a mantra она не нужна.

## Worked Example

*Что за «гаятри»? Автор: это рик, обращённый к Savitá — 3-я мандала, 62-й сукта, 10-й рик. Ведийские тексты передавались устно (Shruti), санскрит без собственного письма. Ритм — гаятри (3×8 слогов); при конфликте грамматика уступает ритму. «Oṋm»: творение звучит «а», питание — «u», отзыв — «ma»; вместе Generator-Operator-Destroyer = GOD. Смысл: «Господи, веди мой ум к блаженству».*

## Key Takeaways

1. «Гаятри-мантра» — на самом деле Savitr Rk (по адресату Savitá).
2. Рк Веда = мандалы → сукты → рики; «Shruti» от устной передачи.
3. Гаятри — ритм: 3 строки по 8 слогов; при споре ритм важнее грамматики.
4. aum = a (создание) + u (сохранение) + ma (отзыв) = G-O-D.
5. Молитва одна: веди мой интеллект к блаженству; после инициации — только Iśt́a mantra.
