# Cheatsheet — Glimpses of a Mystery

Быстрые правила решений и справка по ключевым фактам книги.

## Правила решений

| Ситуация | Правило |
|----------|---------|
| Хочу проверить Гуру/наставника | Не испытывай — очисти мотив; только раздутое эго испытывает |
| Эго мешает росту | «Заставь себя унизиться» — опыт публичной уязвимости → cetanasphot'a |
| Сложная лекция/информация | Слушай целостно, запоминай суть, не конспектируй каждое слово |
| Есть сила, сомневаешься в применении | Служит ли общему благу? Не выставляй публично; сиддхи — знание для служения |
| Оцениваешь духовный рост | Меряй любовью, рациональностью, памятью, служением — не деньгами/статусом |
| Учитель резок/игрив | Различай nitya и lila; не «пробивай» драму |
| Шесть врагов (гнев/вожделение и др.) | Не подавляй, не потакай — сублимируй через любовь к идеалу |
| Дар кажется ничтожным | Ценна интенсивность чувства, не цена; «19 к 20 не станет» |
| Описываешь глубокий опыт | Слова бедны; не суди чужие переживания по словам |
| Разлука/выгорание | Ищи Гуру в работе; «работай, умирая»; начинай с песни |
| Явный сон о наставнике | Это не сон — продолжение связи; проверяй «следы» |
| Внутренний блок | Сначала прими реальность, потом обещай действие |

## Персоналии и места

- **Бхаскарананда Авадхута** — автор, региональный секретарь, ученик Бабы.
- **Пранавананда Авадхута** — ачарья, давший инициацию автору.
- **Ачарья Дасарат** — ачарья, через которого Баба «читал» прошлое.
- **Бишамбхар** — студент-математик, опыт нирвикальпа-самадхи (1966).
- **Тейдж Каран** — директор школы, опыт кундалини (1965).
- **Джайдхари** — садовник, получил слышание omnkara (1968).
- **Jamalpur** — центр ранней Ананда Марги, «ягрти» (центр).
- **Ranchi** — место демонстраций (смерть, сиддхи, Дхарма Самикша).
- **Ананандагар** (Purulia, W.B.) — духовный центр, место видений автора.
- **Деогхар** — место начала Prabhät Samgiita (1982).
- **RU (Renaissance Universal)** — дискуссионная платформа Бабы (с конца 1950-х).
