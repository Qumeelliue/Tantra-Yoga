# Паттерны — Ba'ba' 101 Stories (жизненные уроки и приёмы)

Биографический сборник — паттерны извлечены как наблюдаемые приёмы Ba'ba' в работе с людьми.

## Шок-разоблачение + исцеляющее прощение
**Когда использовать**: закоренелые скрытые привычки, самообман.
**Как**: публично/лично назови проступок (кража, жадность, курение, пропуск практики) → дай конкретный путь исправления → сразу прости и ободри («ты всё равно мой сын»). (Ch 3, 8)
**Компромиссы**: требует доверия аудитории; при отсутствии любви может сломать человека.

## Урок через притчу, а не нотацию
**Когда использовать**: передача сложных принципов, коллективные собрания.
**Как**: расскажи короткую историю с моралью (паровоз, дерево wood-apple, птица, три кандидата в водители), затем обозначь вывод. (Ch 5)
**Компромиссы**: притча допускает разные толкования — нужно уточнить «что ты понял».

## Невозможный срок как тренировка ума
**Когда использовать**: демотивированная команда, ментальная лень.
**Как**: ставь цель выше достижимой, дави/подгоняй, затем объясни: цель — «сделать ум готовым», а не срок. (Ch 6)
**Компромиссы**: у людей без контекста вызывает цинизм — объясняй механизм после.

## Индивидуальная «доза» наказания
**Когда использовать**: наставничество, дисциплина, управление.
**Как**: смотри на психологию человека (твёрдый/мягкий, гордый/робкий) и применяй разную подачу одного урока; одному — строго, другому — мягко, третьему — с юмором. (Ch 4, 8)
**Компромиссы**: требует знания людей; «унифицированная» дисциплина проще, но слабее.

## Перенаправление желаний к высшей цели
**Когда использовать**: мелкие/временные устремления.
**Как**: исполни маленькое желание (мягкие ладони, ароматы), затем покажи: «почему такое крошечное желание? Желай Parama Purusa». (Ch 4, 8)
**Компромиссы**: не работает с материалистами без веры — для них дай притчу о сандале.

## «Твёрдый снаружи, мягкий внутри»
**Когда использовать**: границы, переговоры, устойчивость к эксплуатации.
**Как**: будь твёрдым внешне (чтобы тебя не использовали/обманывали), но сохраняй мягкость и доброту внутри. (Ch 5)
**Компромиссы**: легко скатиться в жёсткость — нужна регулярная проверка «внутренней мягкости».

## «Знание без демонстрации»
**Когда использовать**: лидерство, влияние.
**Как**: знай больше (мысли, состояние, детали), но используй знание только для урока в нужный момент; иногда намеренно «не знаю ничего». (Ch 4)
**Компромиссы**: знание, показанное преждевременно, пугает/вызывает отчуждение.

## Забота как завершение работы
**Когда использовать**: доведение задач до конца, сервис.
**Как**: после дела проверь «хвосты»: кровать, одеяло, еда, гигиена, вода — детали, которые человек забыл. (Ch 2)
**Компромиссы**: требует внимания к мелочам и времени.

## Скорость + система (безопасность для других)
**Когда использовать**: процессы, вождение, проекты.
**Как**: скорость без системы = авария; система без скорости = мало результата. Разгоняйся, не создавая опасности для других. (Ch 5, 6)
**Компромиссы**: требует дисциплины на старте.

## «Кто делает через меня» (анти-эго)
**Когда использовать**: мотивация, оценка своих успехов.
**Как**: помни, что «Парама Пуруша делает всё через тебя»; успех — Его, ошибки — твои; излишняя гордость разрушает. (Ch 8)
**Компромиссы**: может подорвать инициативу у людей без духовной веры — адаптируй как «командный успех».
