# Читшит — краткая справка (Ba'ba' 101 Stories)

## Правила решения (как действовал Ba'ba')
| Ситуация | Правило |
|---|---|
| Скрытый проступок | Разоблачи факт → путь исправления → прощение и любовь (Ch 3, 8) |
| Передать принцип | Притча вместо нотации; уточни «что понял» (Ch 5) |
| Демотивированная команда | Невозможный срок + давление → объяснение «это тренировка ума» (Ch 6) |
| Мелкое желание | Исполни → перенаправь на Parama Purusa (Ch 4, 8) |
| «Я» заносится | «Кто делает через меня?» — эго не терпимо (Ch 8) |
| Здоровье | Причина в поведении/привычках; касание + предписание; «через 4 дня» (Ch 3) |
| Гигиена | Языкочистка ежедневно; мыть рот после еды (Ch 3) |
| Пост | Строго 4 раза в месяц (даже при «врачебном запрете» — «я знаю твою проблему») (Ch 3) |
| Работа vs садхана | «Только садхана — бесполезна»; кто много работает — с ним Ba'ba' (Ch 6) |
| Скорость | Скорость + система; не создавать опасности для других (Ch 5) |

## Методы обучения (быстро)
- Шок-разоблачение + прощение (Ch 3, 8).
- Притча (Ch 5).
- Публичная похвала скромному, игнорирование выскочки (Ch 1, 4).
- Индивидуальная доза строгости (Ch 8).
- Песня/киртан как урок (Ch 7).
- Прямой вопрос о прошлом («где ты был позавчера в полдень?») (Ch 4).

## Ключевые термины
- **Ba'ba'** — П.Р. Саркар; **cane** — трость для исцеления/передачи.
- **Dharma Samiiks'a** — личная аудиенция-«ревизия»; **DMC** — большое собрание.
- **Sadavrata** — кормление бедных; **Field Walk** — прогулка с наставлениями.
- **Prabha'ta Sam'giita** — песни Нового Рассвета; **kiirtan** — хвала только Parama Purusa.
- **Vidya/Avidya Tantra** — знание/тьма; **tandava/kaoshikii** — практики Ba'ba'.
- **Sastaunga Pranam** — полное поклонение.

## Что НЕ является целью (по книге)
- Демонстрация психических способностей («знание без демонстрации») (Ch 4, 9).
- Мелкие желания (золото, слава, ароматы) — временно, «желай Parama Purusa» (Ch 8).
- «Книжный интеллект» без практики и служения (Ch 5, 6).
- Эго и гордость своими заслугами (Ch 8).

## Структура книги
101 история без нумерации глав; в скилле сгруппированы в 9 тем (инициация, грация, целительство, всеведение, притчи, работа, музыка, преданность/эго, тантра). Все имена участников в книге заменены буквами (S, R, M...) — редактор убрал реальные имена.
