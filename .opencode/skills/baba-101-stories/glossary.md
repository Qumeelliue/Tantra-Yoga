# Глоссарий — Ba'ba' 101 Stories

**A'ca'rya (ачарья)** — духовный учитель/священник миссии; ачарья-тренинг — обучение на этот пост (Ch 1).

**Ananda Nagar** — «Город Блаженства», штаб-квартира Ананда Марги в Западной Бенгалии; место больших DMC (Ch 6).

**Avarta Kiirtan** — форма коллективного пения имени Бога (Ch 7).

**Avidya Tantra** — «тантра тьмы»: садхана, дающая психическую силу, но ведущая к тьме; злоупотребление силой (Ch 9).

**Avidya Tantrik** — практик Avidya; по книге двигает предметы силой ума, «занимает места», разрушает (Ch 9).

**Ba'ba'** — «самый любимый» (отец); обращение учеников к П.Р. Саркару (все главы).

**Cane (трость)** — посох Ba'ba'; касание им пупка/сердца/горла — метод исцеления/передачи (Ch 3).

**Dada / Didi** — «старший брат / старшая сестра»; обращение к монахам и монахиням миссии.

**DMC (Dharma Maha'cakra)** — большое духовное собрание/конференция; Ba'ba' давал дискурсы (Ch 6).

**Dharma Samiiks'a (DS)** — «ревизия дхармы»; личная аудиенция, на которой Ba'ba' читал состояние тела/ума/духа и давал предписания (Ch 3).

**Field Walk** — ежедневная прогулка Ba'ba' с учениками; время наставлений (Ch 1, 2).

**General Darshan** — публичная встреча/благословение Ba'ba' (Ch 1, 8).

**Guru Puja** — поклонение гуру (Ch 1).

**Kaoshikii** — танец/физическая практика, введённая Ba'ba' для женщин (и всех) в Патне (Ch 9).

**Karma (санскара)** — реактивный след прошлых действий; авария как «завершение санскары» (Ch 2).

**Kiirtan (киртан)** — пение имени Бога; «kit + anat» = хвала только Parama Purusa (Ch 7).

**LFT** — целостный/постоянный работник миссии (Ch 6, 8).

**PA (Personal Assistant)** — личный помощник Ba'ba' (Ch 2, 6).

**Prabha'ta Sam'giita** — «Песни Нового Рассвета»; ~5000 песен Ba'ba' (Ch 7).

**Prakrti** — Природная сила/энергия; «Пракрти вынуждена действовать» (Ch 6).

**Sadavrata** — программа бесплатного кормления бедных (октябрь 1981) (Ch 6).

**Sastaunga Pranam** — поклонение, при котором касаются пола восемью частями тела (Ch 1).

**Tandava** — танец Шивы; возрождён Ba'ba' в 1971 после ~7000 лет; для мужчин (Ch 9).

**Vidya Tantra** — «тантра знания»: садхана, ведущая к совершенству; сильнее Avidya (Ch 9).

**Vishuddha cakra** — горловая чакра; управляется Parama Purusa (Ch 7).

**Yama/Niyama** — моральные принципы; «соблюдать с несгибаемой строгостью» (Ch 5).
