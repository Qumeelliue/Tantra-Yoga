## Правила решений

| Ситуация | Правило |
|---|---|
| Угроза/опасность | Пратик + лунгота + шаоча-майнджуса + мантра; строгая нравственность |
| Болезнь/кризис | Сдай проблему + коллективный киртан/аварта |
| «Случайность» | Ищи наставление, а не совпадение |
| Сомнение в Гуру | Учись («educate»), а не «испытай» |
| Проект в другом регионе | «Знай местность → планируй → служи»; люби как родную |
| Помощь/грант | Вкладывай в «умножающееся»; избегай долгов |
| Соблазн компромисса | Дхарма защищает дхармику; строгость побеждает |
| Уход лидера | Клятва + «Can I count upon you?» + продолжай служение |

## 8 «оккультных проявлений» (Guide to Human Conduct)

Stambha (оцепенение) · Kampa (дрожь) · Sveda (пот) · Svarabheda (охриплость) · Ashru (слёзы) · Vaevarna (изменение цвета) · Romanca (мурашки) · Pralaya (падение в самадхи). Субсидиарные (13): танец, пение, смех, катание, рыдание, зевание, икота, кружение, расслабление, слюнотечение, «Хум»-рычание, безразличие, глубокое дыхание.

## Экономические принципы Бабы для Африки (ch15)

- Помощь «умножать» (ж/д → пути, не станция)
- Избегать займов; возвращать помощь быстро; беспроцентный кредит
- Бороться с малярией/диареей, а не строить онкоклиники
- Давать советы только тем, кто просит/открыт
- «Пустыня приближается — аффорестация»
- «Люби эти страны, как любишь свою»
