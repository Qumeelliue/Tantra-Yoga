# Читшит — правила решений по Саркару (Subháśita Saḿgraha 12)

## Объект идеации и цель

| Ситуация | Правило |
|---|---|
| Выбрать объект идеации/медитации | Чек-лист: за пределами времени-пространства-личности; не измерение, не стиль, не фикция, не слепая сила |
| «Это судьба» / «просто случайность» | Судьбы и случайностей нет — есть действия и их реакции; «fight against fate» |
| Кандидат: природа / элементы / энергия | Отвергни: стиль, сгустки энергии; энергии нужен разумный источник |
| Кандидат: единичный дух (а́тман) | Отвергни: ограничен, не Supreme |
| Оценить, на что реально направлена система | Что является её «идеацией» — тем её участники и становятся (закон трансмутации) |

## Dharma и человек

| Ситуация | Правило |
|---|---|
| Проверить, «это ещё X?» | Свойство-маркер исчезло → имя ложно (огонь не жжёт — не огонь) |
| Что отличает человека от животных | Bhágavata Dharma: vistára, rasa, sevá, tadsthiti |
| Человек без своей дхармы | «Осёл из человеческой матери»; деградация к животности |
| «Лучше чужой dharma совершенный…» | Нет: свой dharma (даже несовершенный) > paradharma (дхарма растений/животных) |
| Где искать суть dharma | Внутри собственного экзистенциального Я-чувства, не в Kashi/Kaaba |

## Йога и практика

| Ситуация | Правило |
|---|---|
| «Йога = подавление мыслей/пропенсити» | Отвергни: нет объекта объединения, ум-пустыня; йога = saḿyoga (объединение) |
| «Йога = безмыслие» | Отвергни: сон/болезнь; движение — природа ума |
| Куда девать пропенсити | Направь (диверсия) на Iśt́a; не подавляй (суспензия) |
| Йогин и атеизм | Йогин не может быть на́стика; без двух сущностей (преданный + Господь) йоги нет |
| Цель движения | Одна сингулярная: Iśt́a един в имени/форме/идее (пример Ханумана) |

## Жизнь и цель

| Ситуация | Правило |
|---|---|
| С чего начинается любой анализ цели | ádarsha = состояние, которым хочешь стать; движение без него — корабль без руля |
| Личный или философский Бог | Нужен личный (Iśt́a): абстракция не насыщает сердце |
| Успех творческий/профессиональный | Параллельность индивидуального потока космическому = genius; без неё — technician |
| Как согласовать жизнь | Три волны: этика-тело + инкантация-ум + любовь-дух |
| Служение или сделка | Служение односторонне (отдаёшь всё); сделка взаимна; ищи, что ты ждёшь взамен |
| Препятствия (Ма́yá) | Убери «зонт тщеславия» — милость прольётся; она для всех без исключения |

## Быстрые сигналы («tells»)

- Слышишь «это судьба» — ищи автора действия; причина всегда есть.
- «Очисти ум от мыслей» как цель практики — вероятно, дефектное определение (сон ≠ йога).
- Практика, требующая «24 часа в сутки» и не оставляющая времени людям, — самоцельная, не идеальная.
- Ожидание награды/похвалы от действий — коммерция, а не служение.
- «Я грешник» в языке практики — саморазрушительная идеация, меняй на «я ребёнок, помоги».
- Обещание «победы» без упоминания Iśt́a/dharma — победа приписана не тому субъекту.
