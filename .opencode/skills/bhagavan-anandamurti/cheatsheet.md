# Краткая справка

## Шесть качеств Бхагавана (Bhag)

| Качество | Значение | Ключевое правило |
|----------|----------|------------------|
| **Aeshvarya** | 8 оккультных сил | всеведение = любовь; шуддхи/киртан для концентрации |
| **Pratap** | любовь + наказание | «лучше от Гуру, чем от Пракрти»; клаш сжигает санскары |
| **Yasha** | репутация | поляризация — признак Бхагавана; садвипра |
| **Shrii** | красота/энергия | любовь внутренняя; без культа личности |
| **Jinana** | знание | атма-джинана вечна; свадхьяя + садхана |
| **Vaeragya** | отрешённость | без подавления и бегства; «быть в мире, не под его влиянием» |

## Правила решений

| Ситуация | Правило |
|----------|---------|
| Кажется, Гуру жесток | «Лучше наказание от Гуру, чем от слепой Пракрти» |
| Плохая репутация у фигуры | Проверь поляризацию — признак, не аномалия |
| Садхана не идёт | 45 мин шуддхи + 15 мантра; нет блаженства → 45 киртана/10 шуддхи/5 мантра |
| Хочу любви/близости | «Если бы близость была нужна, ботинки были бы освобождены»; идеация |
| Сомнение в пути | Три опасности: прошлое, сравнение, сомнение в Гуру |
| Хочу благодати | Действие + Сдача = Благодать |
| Мантра правильная? | «Растёт обстоятельство посвящения» (счастье/боль растут) |
| Внешний мир vs духовность | Субъективный подход через объективное приспособление |
| Служу, но выгораю | Три вида служения + «Он видит меня»; сдай плоды |
| После ухода Гуру | Сущность остаётся; «ищи внутри»; миссия — Его тело |

## Формула: мысль → действие → привычка → характер → судьба

## Ключевые термины-числа (⚠ к калибровке)
- Тарака Брахма приходит ~каждые **3500 лет**.
- Демократия успешна при моральности/грамотности/сознательности у **≥51%** избирателей.
- Секс — идеально **≤4 раз/мес**; садхана ≥**1 час**/сессия (некоторые 4 часа/день).
- Садхаки **>29 лет** избегают сахара.
- Баба знал **>200 языков**; композиции **5018 песен** (Prabhat Samgiita).
- Кремация 21.10.1990: **79 авадхутов** посвящены за 5 дней до ухода.
