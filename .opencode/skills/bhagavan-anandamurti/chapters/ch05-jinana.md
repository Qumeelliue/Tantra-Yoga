# Глава 5: Jinana — Знание

## Core Idea
Джинана бывает мирская (относительная, забывается) и духовная (атма-джинана, вечная). Реальное знание — субъективизация объективности: знающий и познанное становятся одним. Садхана и свадхьяя дают мудрость.

## Frameworks Introduced
- **Атма-джинана — единственное реальное знание**: мирское забывается (MA по химии → клерк 25 лет → не помнит формулу; MA по санскриту → юрист 25 лет → ничего). Духовное знание не теряется, потому что бесконечно и неизменно; Сатья (истина) = Брахма.
- **Субъективизация объективности**: «в случае знания есть связь — называется знанием; субъективизация объективности означает поглощение объекта». Дефект знающего/познанного/среды (желтуха — видеть всё жёлтым) искажает.
- **Свадхьяя**: чтение священных текстов с пониманием; в Ананда Марге — **Ananda Sutram** и **Subhasita Samgraha** (все части), также Ánanda Vacanámrtam, Namami Krsnasundaram. Свадхьяя + садхана = атма-джинана.
- **Омнисценция Бабы**: >200 языков («Я знаю все языки милостью Бога»), любая тема «как специалист» (география, языки, происхождение); «Я пишу статьи… на всех языках… обо всех темах».
- **Интеллект и апекс**: «для интеллектуалов духовный прогресс задержан, потому что их интеллектуальное тело растёт, но без апекс-ментальности цель далека; когда интеллектуальное тело сильно расширится, оно станет одним с Макрокосмом». Для общества интеллектуальный прогресс не discouraged.
- **Психология слушателя**: «птица пела птичье — каждый услышал своё» (Рам-Сита / Аллах / чеснок-лук / push-ups) — ум видит в объекте своё.
- **Толстая кожа**: «люди с очень толстой кожей часто имеют криминальную ментальность»; «если будешь больше садханить, кожа станет тонкой».

## Key Concepts
- **Будущее по Бабе** (⚠): тело человека станет меньше/тоньше, голова больше; очки/зубы в интеллектуальных регионах — от расширяющегося черепа; перенаселение → полёт на другие планеты; «банки тел» и отправка мозга; уменьшение репродуктивной способности, тест-трубки; смена пола из-за изменения вритти (гормональные изменения).
- **Джинана как служение умом**: карма = служение телом, джинана = служение умом, бхакти = служение сердцем; «Бхагаван найден в сердце любящего преданного».
- **«Знание без действия бесплодно; действие без знания разрушительно»** — оба нужны, с идеацией на Верховного.
- **Баба-в-тюрьме**: «Ты не сможешь держать меня за решёткой долго; пусть Марга кончится — я восстановлю шестнадцать подобных организаций». При 4 годах поста — строгий режим втайне от тюремщиков.

## Mental Models
- «Знание истинно, когда знающий и познанное едины».
- «Интеллект без апекса задерживает духовный прогресс, но нужен обществу».
- «Ум видит своё в объекте — толкование зависит от психологии слушателя».

## Anti-patterns
- Считать книжную эрудицию знанием (она забывается).
- Противопоставлять знание и действие — оба нужны с идеацией.
- Негативно оценивать интеллектуалов — их прогресс полезен обществу.

## Worked Example
Дада-садхак в тюрьме: сомнение в себе («заслужил ли я?») → Баба иронично «почему Нарада не говорит со мной?» (жест «всё ли хорошо?» дважды пропущен) → на полевой прогулке «Я приглашаю вас на фестиваль света — внутри и снаружи, приходите навсегда» → «и я благодарю тебя» (за перенесённое в тюрьме) → слёзы любви. Урок: Баба знает внутреннюю борьбу и отвечает на неё.

## Key Takeaways
1. Атма-джинана — единственное не теряющееся знание.
2. Свадхьяя (Ananda Sutram, Subhasita Samgraha) + садхана = мудрость.
3. Омнисценция Бабы — знак Бхагавана.
4. Интеллект нужен обществу, но апекс-ментальность — для духовного прогресса.
5. «Субъективный подход с объективной адаптацией» — рамка действий.
