# Cheatsheet — Glories of Baba

Быстрые правила решений и справка по ключевым фактам книги.

## Правила решений

| Ситуация | Правило |
|----------|---------|
| Хочу духовного прогресса | Сначала ищи милость/присутствие; рвение — следствие, не причина |
| Инициация/решение откладывается | Воспринимай как тест рвения; проси настойчиво, будь готов оставить всё |
| Есть сила, хочется «поправить» природу | Не вмешивайся эгоистично; применяй для общего блага |
| Мне навредили | Не мсти; Пракрити уравновесит; оставайся честным |
| Просил помощи — не вижу результата | Помощь может быть невидимой (сон/другой человек/предмет); проверяй после |
| Вдохновенная работа | Будь инструментом; ошибки приходят с эго |
| Ухаживаю за растениями | Растения — чувствующие; равное внимание; слушай интуицией |
| Постигло несчастье | Ищи урок; «не было великого без страданий»; принимай заботу и служи |
| Кажется, что «дали мало» | «19 не станет 20»; милость пропорциональна служению |
| Размышляю «уйти от мира» | Отречение = служение, не бегство; честность в миру — тоже садхана |
| Выгорание/усталость | «Работай, умирая»; узнавай идеал в работе |

## Персоналии и места

- **Автор** — ачарья/авадхута Ананда Марги, госслужащий (кооперативы), позже авадхута.
- **Ачарья Амулья Ратанджи** — ачарья, давший инициацию автору (бывший начальник).
- **Пранавананда** — ачарья, коллега в проповеди в Kerala.
- **Нитьянанда → Сатьянанда Авадхута** — первый авадхута (июль 1962).
- **Рам Танук** — адвокат Бабы, исцелён от пролома черепа.
- **Дасарат** — марги/ачарья, связан с историей чёрной собаки.
- **Ачарья Дивьянанда** — первый марги, совершивший само-иммоляцию (протест).
- **Ачарья Асима Кумар** — ачарья, посланный инициировать д-ра Анакула (по указанию Бабы).
- **Анакул** — д-р, «чудесная инициация» через ачарью (посланец Бабы).
- **Haps Peter / Капил** — ученик из Швейцарии, получил самадхи через трость.
- **Jamalpur** (Bihar) — центр Ананда Марги, квартира Бабы, тигриная гробница.
- **Ranchi** (Bihar) — джагрити, место демонстраций и работы автора.
- **Bankipur / Patna** — тюрьма, где сидел Баба (1971–1978).
- **Ramnagar (Champaran)** — первое DMC автора (1957).
- **Madras / Kerala** — проповедь автора (голодовка Бабы).
