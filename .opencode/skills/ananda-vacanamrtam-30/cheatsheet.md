# Читшит: правила решений

## Пропенсити (50)

| Ситуация | Правило |
|----------|---------|
| Ум качается вверх/вниз | Он та́т̣астха́: вверх → дух, вниз → материя |
| 49 мирских пропенсити | Отводи поток (не подавляй) к единой пара̄ |
| Pápa vs puńya | Pápa = против коллектива; puńya = за коллектив |
| Хочешь узнать 50-ю | Пара̄ (духовное знание) в а̄джин̭а̄ |

## Стадии са̄дханы

| Стадия | Признак |
|--------|---------|
| Yatamána | Борьба с узлами (внутр. ripus / внеш. páshas) |
| Vyatireka | Контроль одной пропенсити, поражение от других |
| Ekendriya | Контроль одного органа, поражение через другой |
| Vashiikára | Контроль всех 50 + органов; у Ступицы |
| Ключевой принцип | Не движешься вверх = движешься вниз |

## Служение

| Ситуация | Вид sevá |
|----------|-----------|
| Медицинское/физическое | Shúdrocita |
| Охрана слабых | Kśatriyocita |
| Кормление голодных | Vaeshyocita |
| Обучение/мораль/проповедь | Viprocita (постоянный результат) |
| Голодному умирающему | Дай еду, не медитацию |

## Догма и движение

| Ситуация | Правило |
|----------|---------|
| Идея с жёсткой границей | Догма: противоречит духу ума |
| Гибкая граница идеи | Норма (стиль меняется по времени/месту/лицу) |
| Vidyá / Avidyá | Центростремительная (к Ядру) / центробежная (от Ядра) |
| Неподвижность | Смерть; движение = жизнь |

## Карма и санскары

| Ситуация | Правило |
|----------|---------|
| Реакция чисто психическая | Равна действию |
| Реакция физико-психическая | Больше действия |
| Плоды благих дел | Отдай Paramátmá (золотая цепь тоже цепь) |
| Dagdhabiija | Сожжённое семя: нет своих боли/радости |
| Не исчерпанные санскары | Исчерпываются переживанием (karmabhogena) |

## Разное

| Тема | Правило |
|------|---------|
| Оккультные силы на 3-й стадии | Хочешь Parama Puruśa, не игрушку; внутрь, не наружу |
| Смерть | Утрата связи форм; время = мера движения |
| Человек | Идеологический поток, не «разумное животное» |
| Природа | Стиль Prakrti; творит Тот, чей это стиль |
| Намаскар | Почтение Parama Puruśa в другом (трикути + грудь) |
| 1 + нули | Parama Puruśa впереди: действия умножают; без Него — ноль |
