# Chapter 28: Bio-Psycho-Spiritual System of Kiirtana

*Дата не указана. (Приложение.)*

## Core Idea
Действие считается завершённым («finality»), если (1) полностью выполнено и (2) результат получен. Kiirtana (siddha mantra «Bábá náma kevalama») строится по ритму дыхания: 4 стадии на вдохе + 4 на выдохе = 8 фасетов; мантра должна быть ашт̣а̄кшарии (8-сложной), произноситься целиком на каждый такт.

## Frameworks Introduced
- **Finality (завершённость)**: два условия — полностью соблюдено + результат на руках. «Переступил порог → вошёл в комнату» — акт завершён; произнесение первого слога мантры = переступление порога в новый мир; завершение работы в новом мире даёт блаженство.
- **Ритм дыхания**: мантра повторяется по силлабическому ритму вдоха и выдоха; дыхание — действие, живое существо всегда «в действии» (это постоянное усилие — yatamána, 1-я стадия).
- **Четыре стадии (по ch19) на вдохе и на выдохе**:
  1. **Yatamána** — постоянное усилие, контроль одной-другой пропенсити на время;
  2. **Vyatireka** — концентрация то достигается, то теряется;
  3. **Ekendriya** — контроль над одной пропенсити более длительный; мантра звучит в ухе, видно Iśt́a, запах сандала/розы;
  4. **Vashiikára** — установление в идеации Parama Puruśa, полная сдача, полный контроль.
- **Восемь фасетов**: 4 стадии × (вдох + выдох) = 8; siddha mantra должна быть ашт̣а̄кшарии — «Bábá náma kevalama» (с добавленным «a» для мелодии) — 8 слогов. Первый слог «bá»: «переступаю порог в новый мир»; последний «ma»: «я выполнил свой долг».
- **Целостность**: мантра должна произноситься полностью на каждый такт мелодии — иначе kiirtana не совершенен; метод приносит «completion» за 2–3 минуты.

## Key Concepts
- **finality** — завершённость действия (2 условия).
- **siddha mantra** — «совершенная мантра» (Bábá náma kevalam).
- **aśt́ákśarii** — восьмисложная.
- **Iśt́a** — идеал/Господь.

## Mental Models
- «Любое действие проверяй на "finality": полностью выполнено + результат получен».
- «Kiirtana — био-психо-духовная система: дыхание × 4 стадии × 2 фазы».

## Anti-patterns
- **Произносить часть мантры на такт** — kiirtana несовершенен.
- **Действия без завершённости** — не «final».

## Worked Example
Первое произнесение «bá» — переступил порог нового мира; последнее «ma» — «долг выполнен». С каждым полным тактом мантра проходит цикл 4+4 стадий. При правильном методе эффект — за 2–3 минуты. Вывод: система даёт блаженство завершённости.

## Key Takeaways
1. Finality = выполнено полностью + результат в руках.
2. Kiirtana связана с ритмом дыхания (вдох/выдох).
3. Четыре стадии × 2 фазы = 8 фасетов.
4. Siddha mantra должна быть восьмисложной.
5. Произноси мантру целиком на каждый такт.
