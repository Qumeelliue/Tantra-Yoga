# Chapter 5: Macropsychic Conation

*1971 или раньше, Ernakulam или Trivandrum.*

## Core Idea
Фундаментальная субстанция — Верховное Познание, в котором действуют три оперативных принципа (sattva/raja/tama — по длине волны). Творение — результат их вечной борьбы в треугольнике сил; из вершины исходит конация Верховного.

## Frameworks Introduced
- **Треугольник сил**: три принципа (по длине волны — sentient/mutative/static) борются в сфере проявления; из вершины — точка фундаментальной позитивности, начало творения и конации.
- **Три фазы творения (экстроверсия)**:
  1. **Bindu** — первая точка (базовый принцип), теоретически существует, практически не утверждается;
  2. **Náda** — движение по прямой; дух метаморфозируется в абстрактное (átmá → mánasa); «примордиальный принцип»;
  3. **Kalá** — из-за внутреннего столкновения/сплочения на́да образует кривизны; всё видимое/ощущаемое — в пределах кала́.
- **Вселенная = сеть волн разной длины**; вибрации — конативное выражение Верховного «я». Из макрокосмической конации получаем квинквелементальный мир и микрокосмы.

## Key Concepts
- **bindu / náda / kalá** — три этапа проявления.
- **макрокосмическая конация** — волевое выражение Верховного.
- **треугольник сил** — вечная борьба принципов.

## Mental Models
- «Творение — результат борьбы, не гармонии: конация рождается из конфликта».
- «Думай о проявлении как о спектре: точка (bindu) → линия (náda) → кривизна (kalá)».

## Anti-patterns
- **Считать три принципа разными сущностями**: это один принцип на разных длинах волн.

## Worked Example
Из вершины треугольника выходит конация: bindu (теоретическая точка) → нада (прямая, дух→абстракция) → кала (кривизны = проявленный мир). Всё, что мы видим и чувствуем, — в кала́. Вывод: видимый мир — сеть вибраций конации Верховного.

## Key Takeaways
1. Три гуны — один принцип на разных длинах волн.
2. Конация рождается из борьбы сил в треугольнике.
3. Bindu → náda → kalá: точка → линия → кривизны.
4. Вселенная — сеть волн разной длины (кала́).
5. Микрокосмы и квинквелементальный мир — из макрокосмической конации.
