# Chapter 6: Ascribe Brahma-hood to All

*14 декабря 1971 утро, Patna.*

## Core Idea
Человек — не «разумное животное»; его жизнь — идеологический поток. Но для тела нужны еда, одежда, лечение, образование — мирские обязанности, отвлекающие от духовного долга. Решение — **madhuvidyá**: приписывай брахма-природу (на̄ра̄йан̣а-природу) мирскому делу — и тогда мирское становится са̄дханой.

## Frameworks Introduced
- **Madhuvidyá (аскрипция брахма-худа)**: пока делаешь мирское дело — «припиши ему брахма-природу»; время не тратится впустую, духовное наложено на мирское.
- **Мантра Brahmárpańam** (поэтапно):
  - **Brahmárpańam** — сам акт подношения есть Брахма (брахма-худ приписан глаголу);
  - **Brahmahavih** — подношаемый объект есть Брахма;
  - **Brahmágnao** — получатель есть Брахма;
  - **Brahmańáhutam** — подносящая личность есть Брахма;
  - **Brahmaeva tena gantavyam** — цель подносящего есть Брахма;
  - **Brahmakarma samádhiná** — слившись по завершении порученного Брахмой дела.
- **Pitrpuruśebhyo namah**: благодарность предкам (непрерывность человеческой расы, ~10 лакхов лет назад — австралопитек).
- **Rśidevebhyo namah**: рши = великие изобретатели всех времён (пенициллин, самолёт, телевизор, телега) — «коллекция их изобретений — современная цивилизация».

## Key Concepts
- **madhuvidyá** — «медовая видья»: помнить, что всё есть Брахма.
- **rśi** — «изобретатель», «великий человек», а не только ведический мудрец.
- **аскрипция** — приписывание брахма-природы мирскому.

## Mental Models
- «Превращай мирской долг в духовную практику аскрипцией, а не избеганием».
- «Думай о великих изобретателях как о рши: уважай вклад каждого в цивилизацию».

## Anti-patterns
- **Разделение «мирское vs духовное»** как непроходимая граница: аскрипция снимает его.
- **Пренебрежение предками/изобретателями**: непрерывность расы и цивилизации — часть dharma.

## Worked Example
Са̄дхака должен медитировать, но обязан кормить семью. Вместо вины он делает мирскую работу с мантрой: «акт — Брахма, объект — Брахма, получатель — Брахма, я — Брахма, моя цель — Брахма». Работа перестаёт быть отвлечением — она становится практикой. Вывод: идеация меняет природу действия.

## Key Takeaways
1. Человек — идеологический поток, а не животное.
2. Мирские обязанности нельзя игнорировать — их надо одухотворять.
3. Аскрипция брахма-худа превращает работу в са̄дхану.
4. Рши — изобретатели всех эпох; цивилизация — их коллекция.
5. Уважение предков — часть непрерывности человеческого рода.
