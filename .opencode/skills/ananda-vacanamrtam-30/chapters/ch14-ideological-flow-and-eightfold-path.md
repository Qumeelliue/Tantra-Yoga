# Chapter 14: Ideological Flow and the Eight-fold Path

*10 августа 1979 вечер, Bangkok.*

## Core Idea
Человеческая жизнь — идеологический поток к Верховному Ядру (Кришна, Parama Puruśa). Пока движешься — помни восемь пунктов Будды (samyak …), переинтерпретированных для духовного пути.

## Frameworks Introduced
- **Идеологический поток**: растения/животные — «бесцельное движение» (еда); человек может умереть за идеологию. Кто не движется к идеологической цели — хуже животного («vrkśádhama»).
- **Ядро (nucleus)**: как земля — ядро луны, солнце — ядро планет, так Parama Puruśa — ядро космоса; все движутся вокруг Него осознанно/неосознанно.
- **Восемь пунктов (samyak = «правильный»)**:
  1. **samyak darshana** — правильная философия (должен ведать «что делать/чего не делать»);
  2. **samyak saḿkalpa** — правильная решимость («я должен быть достоянием общества», не «величайшим вором»); без неё философия не двигает (спящая потенциальность);
  3. **samyak vák** — правильное выражение (через кarmendriya — внешнее: говорить, делать, трогать);
  4. **samyak ájiiva** — чистая профессия (не антисоциальная) + **психическое занятие (ábhoga)**: объект идеации; «думая о воре, станешь вором» (пример peshaskrt-насекомого, превращающего таракана в свою форму); лучший объект — Parama Puruśa;
  5. **samyak vyáyám** — упражнение: физическое (сильным как слон) + психическое (mánasik vyáyám — у а̄ча̄рьи);
  6. **samyak karmánta** — завершай начатое в должном порядке (не бросай на полпути);
  7. **samyak smrti** — правильная память (anubhúta viśayá sampramośah smrtih — воспроизведение воспринятого); лучшая smrti — Parama Puruśa; «никогда не забывай Господа»; состояние — dharmamegha samádhi;
  8. **samyak samádhi** — поглощение ума объектом (фигура исчезает → цвет → слияние видящего); с Saguńa — savikalpa, с Nirguńa — nirvikalpa (высшая); достигается dhyána (пали jhán, япон. zen).

## Key Concepts
- **ábhoga** — «психическая пища», объект идеации.
- **dharmamegha samádhi** — состояние, когда не забываешь Господа.
- **savikalpa / nirvikalpa samádhi** — с-видоизменением / без-видоизменения поглощение.
- **karmendriya / jiṋánendriya** — двигательные / чувствительные органы.

## Mental Models
- «Выбирай объект идеации как диету ума: о чём думаешь, тем станешь».
- «Проверяй жизнь восьмью samyak-пунктами: философия → решимость → речь → профессия → упражнение → завершение → память → поглощение».

## Anti-patterns
- **Негативные мысли («сможу ли я?»)**: верный признак неуспеха; думай «должен преуспеть».
- **Незавершённые дела** — дефект, блокирующий поток.
- **Психическая пища-вор/дурной объект** — превращает в дурного.

## Worked Example
Человек, идействуя о воре, начинает «психически есть» вора: объективная половина ума принимает его форму, затем и субъективная — человек становится вором. Поменяй объект на Parama Puruśa — существование превратится в Parama Puruśa. Вывод: ájiiva (психическое занятие) определяет судьбу.

## Key Takeaways
1. Человек = идеологический поток к Ядру.
2. Восемь samyak-пунктов — компас пути.
3. Психическое занятие (ábhoga) важнее физической профессии.
4. Объект идеации превращает в свою форму.
5. Завершай начатое; не забывай Господа (dharmamegha samádhi).
6. Nirvikalpa samádhi — высшая цель, достигается dhyána/zen.
