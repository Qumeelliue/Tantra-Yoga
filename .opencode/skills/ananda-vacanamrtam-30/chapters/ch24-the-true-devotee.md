# Chapter 24: The True Devotee

*10 октября 1971 вечер, Patna. (Приложение.)*

## Core Idea
Разграничение добра/зла существует только для не-совершенных преданных. Истинный преданный может думать только о Parama Puruśa; поскольку желает только угодить Ему, может только делать добро. Развивай такую преданность, но пока её нет — различай «что делать/чего не делать».

## Frameworks Introduced
- **Преданность выше добро/зло**: для истинного преданного нет «дос и донтс» — только идеация Parama Puruśa; желая угодить Ему, он автоматически благотворителен. Развив такую любовь, не нужно беспокоиться о правилах.
- **Tapah — часть са̄дханы**: самоотверженное служение (tapah) — тоже служение Господу, помогающее са̄дхане.
- **Порядок**: пока преданность не развита — различай добро/зло (правила нужны как ступени).

## Key Concepts
- **tapah** — самоотверженное служение.
- **истинный преданный** — не может мыслить «добро/зло», ибо мыслит только о Господе.

## Mental Models
- «Правила — для тех, кто ещё не любит: развивай любовь, правила уйдут сами».
- «Проверка преданности: что ты делаешь, когда никто не смотрит и правила не видны?»

## Anti-patterns
- **Преждевременно отбросить правила** («я предан, мне не нужны дос/донтс») — пока любовь не развита, это самообман.

## Worked Example
Кришна болен; лекарство — «пыль с ног истинного преданного». Уличный мальчишка: «не знаю, преданный ли я, но люблю Его и рад помочь». Вывод: искренняя любовь превыше формальной идентичности преданного.

## Key Takeaways
1. Дос/донтс — для тех, кто ещё не истинный преданный.
2. Истинный преданный мыслит только о Господе → делает только добро.
3. Tapah — часть са̄дханы.
4. Развивай преданность через са̄дхану и служение; правила — ступени.
