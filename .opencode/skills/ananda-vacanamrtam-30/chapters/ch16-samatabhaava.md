# Chapter 16: Samatábháva

*2 декабря 1979, Calcutta.*

## Core Idea
Samatábháva — ментальное равновесие, четвёртый секрет успеха (по Шиве): ни комплекс неполноценности, ни превосходства. Без комплексов ум может двигаться к Parama Puruśa. Уважение надо отдавать всем, особенно «āmánii» — лишённым общественного престижа.

## Frameworks Introduced
- **Samatábháva**: веди себя с каждым так, чтобы ни у тебя, ни у другого не развивались комплексы превосходства/неполноценности. Комплекс любого рода — психическая болезнь.
- **Trńádapi suniicena**: «будь смиреннее травы» (комплекс превосходства встречается чаще, чем неполноценности — даже знающий азбуку чувствует превосходство над неграмотным).
- **Taroriva sahiśńuna**: «будь терпелив, как деревья». Терпимость — не ради самой терпимости: ассимилируй удар противника, чтобы контратаковать с большей силой; терпимость ради измерения силы и её ослабления. Не терпи бесконечно — иначе пригласишь смерть.
- **Amániináḿ mánadena**: «воздай уважение тем, кому никто не уважает». 99% людей не имеют социального престижа по трём причинам: (1) общество не признало, (2) экономическая зависимость, (3) невежество. Уважение даётся только через все три: **образование + социальное признание + экономическая самодостаточность** — одновременно.
- **Равенство от единого Отца**: нет высших/низших по касте или религии; все — дети Бога; равный социальный престиж для всех.

## Key Concepts
- **samatábháva** — ментальное равновесие.
- **āmánii** — не имеющий социального престижа.
- **trńádapi suniicena…** — стих Чайтаньи (смирение, терпимость, уважение, киртан).

## Mental Models
- «Отсутствие комплексов = условие движения ума к Богу».
- «Терпимость — стратегия: ассимилируй силу противника, не отдавай её обратно».
- «Уважение — продукт трёх факторов: знание, признание, экономика».

## Anti-patterns
- **Терпимость ради терпимости** — не идеал; она должна вести к ассимиляции и росту силы.
- **Комплексы превосходства/неполноценности** — психические заболевания, блокирующие путь.

## Worked Example
Нанесли удар — не возвращай его сразу (не ассимилировал), а прими, оцени силу противника, ассимилируй и контратакуй с большей силой. Терпимость «пока полезна». Вывод: равновесие ума — активная стратегия, не пассивность.

## Key Takeaways
1. Samatábháva — равновесие без комплексов (4-й секрет успеха).
2. Комплекс любого рода — психическая болезнь.
3. Будь смиреннее травы; комплексы превосходства повсеместны.
4. Терпимость — для ассимиляции силы, не ради неё самой.
5. Уважение — через образование + признание + экономику, всем трём.
6. Все — дети одного Отца; равный престиж.
