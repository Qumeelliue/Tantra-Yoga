# Chapter 25: One and Zero

*5 ноября 1971 вечер, Patna. (Приложение.)*

## Core Idea
Каждое действие — с Parama Puruśa или «ноль». Он — единица; действия — нули. С Ним нули умножают (×10 за каждое), без Него складываются в ноль. «Умножай, не дай всему стать нулём».

## Frameworks Introduced
- **Арифметика идеации**: Он = 1, твои действия = 0. Если 1 стоит впереди и действия прилагаются к Нему, каждое действие умножает (прибавляет ноль к 1 = ×10). Если 1 нет — нули складываются друг с другом, сумма = 0.
- **Практика**: начинай каждое действие с идеацией Parama Puruśa; даже малое «с Ним» = много; большое «без Него» = ничто.
- **Цель**: человеческая форма дана для реализации Его; не трать жизнь впустую.

## Key Concepts
- **Единица (1)** — Parama Puruśa.
- **нули** — действия без идеации.

## Mental Models
- «Превращай действия в множители, а не слагаемые нулей: ставь единицу впереди».
- «Проверяй любое действие вопросом: с Ним или без Него?»

## Anti-patterns
- **Действия без идеации**: даже великие на вид, они складываются в ноль.
- **Трата человеческой жизни** — пришёл реализовать Его, а ушёл с «нулями».

## Worked Example
1 (Parama Puruśa) + действие = 10; + действие = 100; + действие = 1000. Без 1: 0+0+0+0 = 0. Вывод: идеация умножает ценность действий.

## Key Takeaways
1. Parama Puruśa — единица; действия — нули.
2. С Ним каждое действие умножает (×10).
3. Без Него сумма действий — ноль.
4. Человеческая форма — для реализации Его; не дай жизни стать нулём.
