# Глоссарий

**Abhoga (ábhoga)** — «психическая пища»; объект идеации (психическое занятие).

**Ájiiva** — профессия (физическая) + психическое занятие (abhoga).

**Aśt́ákśarii** — восьмисложная (мантра).

**Átmamokśárthaḿ jagaddhitáya ca** — «для собственного освобождения и блага мира»; девиз миссии са̄дхаки.

**Átmajiṋána** — самопознание; единственное условие mokśa.

**Bindu / náda / kalá** — три фазы макрокосмического проявления: точка / линия / кривизны.

**Brahmáńd́a** — овальная (яйцеобразная) вселенная.

**Brahmavid Brahmaeva bhavati** — «знающий Брахму становится Брахмой».

**Dagdhabiija** — «сожжённое семя»; са̄дхака, чьи санскары не прорастут.

**Dharma pracára** — духовная пропаганда.

**Dharmamegha samádhi** — состояние «не забывающего Господа».

**Dvija** — «дважды рождённый»; после инициации.

**Ekendriya** — 3-я стадия са̄дханы: контроль пропенсити одного органа.

**Finality** — завершённость действия (2 условия: выполнено + результат на руках).

**Gurupújanam** — почитание гуру; оттягивание пропенсити к объекту поклонения.

**Hita** — благо/благодеяние (все четыре вида служения).

**Jad́a** — косная материя.

**Jinvana-vrtti** — основная жизненная устремлённость.

**Kriid́á / liilá** — постижимая / непостижимая игра Господа.

**Mád́huvidyá** — «медовая видья»: помнить, что всё есть Брахма; аскрипция брахма-худа мирскому.

**Mahásambhúti** — Великое Нисхождение (Шива, Кришна).

**Noumenal / phenomenal** — контролирующая сущность / выраженные проявления.

**Oṋḿkára / prańava / Shabda Brahma** — звук, помогающий войти в контакт с Parama Puruśa.

**Parashakti (paráshakti)** — единственная (50-я) пропенсити, связывающая ум с духом.

**Parama Puruśa (Puruśottama)** — Верховное Сознание/Ядро.

**Pramitáhára** — умеренная, саттвичная, сбалансированная пища.

**Prapaiṋcadeha** — квинквелементальная структура.

**Ripus / páshas** — внутренние враги (пропенсити) / внешние путы.

**Rśi** — изобретатель, великий человек (не только ведический мудрец).

**Sadguru** — истинный гуру; только Brahma.

**Samatábháva** — ментальное равновесие (без комплексов).

**Saḿskára** — (1) реактивный момент; (2) переориентация/инициация.

**Saḿvrtti / pravrtti / nivrtti** — баланс / движение вовне / движение внутрь.

**Samyak** — «правильный» (восемь пунктов Будды).

**Sarvajiṋá** — всезнающий.

**Siddha mantra** — совершенная мантра (Bábá náma kevalama).

**Shraddhá** — принятие Дезидератума как единственной истины (нет англ. эквивалента).

**Shudrocita / kśatriyocita / vaeshyocita / viprocita sevá** — четыре вида служения (физическое / охрана / экономическое / интеллектуальное).

**Táṭasthá shakti** — «сила на линии прибоя» (ум между духом и материей).

**Tapah** — самоотверженное служение.

**Trikut́i** — точка между бровями (концентрация).

**Trńádapi suniicena…** — «смиреннее травы, терпеливее дерева» (Чайтанья).

**Vashiikára** — 4-я стадия са̄дханы: полный контроль пропенсити и органов.

**Vidyá / Avidyá** — центростремительная / центробежная силы (к Ядру / от Ядра).

**Vrtti** — пропенсити (50: 49 мирских + 1 духовная).

**Vyatireka** — 2-я стадия са̄дханы: контроль одной пропенсити, поражение от других.

**Yatamána** — 1-я стадия са̄дханы: борьба с узлами.
