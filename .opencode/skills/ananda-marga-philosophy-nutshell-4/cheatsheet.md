# Читшит — правила решений (Ananda Marga Philosophy Part 4)

## Метафизика и космология

| Ситуация | Правило |
|---|---|
| Понять устройство мира | Всё из макрокосмического ума; Saiṋcara (ум→материя→жизнь), Pratisaiṋcara (обратно к уму) |
| Первая причина | Треугольник сил (guńayantraka): sattva/rajas/tamas |
| Монизм или дуализм? | Монизм: Brahma = Shiva (Cognitive) + Shakti (Operative, подчинена) |
| Мир — иллюзия? | Нет: относительная истина, питающая путь к абсолютному |

## Майя и пути садханы

| Ситуация | Правило |
|---|---|
| Сила в покое / в творении | Равновесие гун = Prakrti; творение = Máyá |
| Почему «не вижу истину» | Avaranii (покрытие) или vikśepii (отвлечение) Avidyámáyá |
| Как освободиться | Мадхьямачара: бой с майей с фиксированной целью (не лесть, не слепой бой) |
| «Выпросить» свободу | Не выйдет: лесть даёт только «доминион-статус» |

## Действие

| Ситуация | Правило |
|---|---|
| Действие без цели | kriyá → bondage |
| Действие с космической идеацией | karma → освобождение |
| Что обязательно (nitya) | Еда, купание, отдых, духовная практика |
| Что случайно (naemittik) | Работа, учёба, благотворительность, фестивали |

## Пища и ум

| Ситуация | Правило |
|---|---|
| Хочешь саттвичные клетки | Саттвичная пища: рис, зерно, бобовые, фрукты, молочное |
| Что вредит уму | Тамасичное: лук, чеснок, алкоголь, несвежее, мясо/рыба/яйца (⚠ список) |
| «Буду практиковать и есть что угодно» | Ошибка: пища влияет на ум независимо |
| Сколько отдыхать после болезни | ~21 день для новых клеток (⚠ к калибровке) |

## Знание

| Ситуация | Правило |
|---|---|
| Оценить источник | Относительное (восприятие/инференция/авторитет) — ненадёжно |
| Признак истины | Универсально + рационально + психологично (ápta vákya) |
| Мозг vs сердце | Слушай сердце |
| Когда отвергнуть знание | Когда оно против универсального гуманизма |
| Логика (yukti) | váda (разведка) → jalpa (контраргументы) → vitanda (поражение) |

## Социальное устройство

| Ситуация | Правило |
|---|---|
| Единство общества | Общая идеология + бескастовость + коллективные функции + нет смертной казни |
| Безопасность | Справедливость (достоинство труда, равенство полов/каст) + дисциплина |
| Наказание | Исправляет: «приведи 10 человек к духовности»; не карает и не клеймит |
| Законы | Рациональные, допускают поправки; послушание сначала, обсуждение потом |
| Критика кодекса Ману | Жёсткие законы + страх + религиозные наказания = распад |

## Память

| Ситуация | Правило |
|---|---|
| Где хранится память | В citta; мозг — инструмент припоминания |
| Память прошлых жизней | Extra-cerebral; активна у детей ~до 5 лет, játismara ~до 12 (⚠) |
| Хочешь узнать своё прошлое | Осторожно: может подорвать вдохновение; чужие самскары видеть легче |
| Забывчивость прошлого | Благо («милостивый декрет»), не недостаток |

## Ритм и бхакти

| Ситуация | Правило |
|---|---|
| Разница существ | Разница ритмов; разнообразие — закон природы |
| Слияние с миром | Self-surrender: индивидуальный ритм (svarasa) → универсальный (Paramrása) |
| Бхакти — это | Идеация на Верховном, не eulogy и не ритуал |
| Любовь к конечному | ásakti → сделка/потеря; к Бесконечному — вечность |
| Какая бхакти в марге | Rágátmiká → kevalá; не vaedhii, не jiṋánamishrá |
| Как получить милость | Делать своё: идеировать; права и обязанности неразделимы |
| Грешник и спасение | Право рождения каждого (пример Ratnákar → Valmiki) |

## Быстрые сигналы («tells»)

- Видишь «выпросить у системы уступку» лестью → доминион-статус, не свобода.
- Действие «на автопилоте» без цели → kriyá, рабство.
- Жалоба «не знаю истины» при близости к объекту → ávarańii: покрытие.
- «Нищета — карма из прошлой жизни» → инструмент эксплуатации (пассивный фатализм).
- Комплекс неполноценности/страх → «слабость — грех»: отбрось.
- «Сладкая» остановка у дверей Господа (gopiibháva) → не останавливайся, сливайся.
