# Читшит — Discourses on Tantra Volume One

## 3+1+3 шакти
- **Kaośikii** = равновесие, невыраженная, источник kośa
- **Bhaeravii** = потеря равновесия, náda (прямая линия)
- **Bhavánii** = kalá (кривизны), мир восприятия
- Сáдхана: Bhavánii → Bhaeravii → Kaośikii → Puruśottama

## Цепочка творения
Kámabiija (семя желания) → náda → kalá → sadrsha parińáma → мир
Положительность: Shambhúliuṋga (старт). Отрицательность: Svayambhúliuṋga (спит куна́лини).

## Ступени самадхи (по чакрам)
sálokya (свадхиштхана) → sámiipya (манипура) → sáyujya (анахата) → sárúpya (горло) → sárśt́hi (аджна) → nirvikalpa/kaevalya (сахасрара)

## Мантра — 2 правила
1. Смысл (mundane significance) + акустический корень (acoustic root)
2. Siddha mantru даёт только Mahákaola
- aum = a(творение)+u(сохранение)+ma(разрушение) + точка + полумесяц

## Корни 4 vargas
va=dharma, sha=artha, śa=káma, sa=mokśa

## История Шивы (бииджи по эпохам)
Vedic: m → Jain/Buddhist/Post-Shiva: aeḿ → Puranic: haoḿ
- 64 ветви Тантры, Dashamahávidyá, Nátha Cult (nátha vs iishvara)

## Шива — факты
- ~7000 лет назад; систематизатор Тантры; отец цивилизации
- Санскрит — индийский, ведический — язык ариев; шрифт — от тантриков
- 5 лиц: Dakśińeshvara, Iishána, Kalýańasundaram, Vámadeva, Kálágni
- 3 жены: Гаори (арийка), Кали (неарийка), Ганга (монголка). Дурга/Кали-богиня — НЕ жёны

## Тантра vs Веды
- Тантра старше Вед; золото/эмаль цивилизации
- Пуранические ритуалы ≤1300 лет; Дурга — период Патанов

## 4 ácára + 5 cults
Shaeva/Shа́kta/Saora/Gáńapatya/Vaeśńava; Siddhántácára/Vámácára/Kulácára

## Три вида страданий
ádhibhaotika (общество) → ádhidaevika (ум) → ádhyátmika (духовная разлука)

## Быстрые ответы
- «Кто такой Mahásambhúti?» → проявление Parama Puruśa для коррекции общества (Шива, Кршна); это Тарака Брахма, не аватара
- «Что такое Тантра?» → tan (расширять) + tra (освободитель); наука расширения ума и освобождения
- «Кто такие джагирти?» → вне данной книги; см. другие тома Саркара
- «Когда впервые записаны Веды?» → поздно (суеверие shruti), в Kashmir (Sáradá); часть утрачена
