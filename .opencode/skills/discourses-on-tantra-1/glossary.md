# Глоссарий — Discourses on Tantra Volume One

Транслитерация по тексту книги; термины упрощены до читаемого уровня.

- **Akshámálá** — «гарлянда букв»; 50 букв индоарийского алфавита (a…kśa), каждая — акустический корень (causal matrix).
- **Ánanda Sútram** — афоризмы Саркара (1962), сжатая «формула» космологии (гл. 4).
- **Aparashiva** — тот же Guńámaya в фазе проявления объективного (антитезиса).
- **Avidyámáyá** — экстроверсивная сила Пракрити, направляющая от тонкого к грубому; оппозит Vidyámáyá.
- **Bhaeravii** — 2-я стадия Пракрити: потеря равновесия, náda (прямая линия); «настоящее Я». В парной паре — Puruśa Bhaerava.
- **Bhava** — Puruśa в мире творения (bhava = «становиться»).
- **Bhavánii** — 3-я стадия Пракрити: kalá (кривизны), мир восприятия; «энергия эволюции».
- **Biija mantra** — акустический корень; звук-вибрация, из которого проистекает действие.
- **Brahma Cakra** — цикл saincara (вовне) и pratisaincara (обратно).
- **Devatá** — вибрационное выражение, исходящее из Supreme Nucleus (философски); бог/богиня (мифологически).
- **Guńámaya** — непроявленное Сознание в равновесии треугольника сил; синоним Parashiva.
- **Jiivakot́i / Iishvarakot́i** — обычные живые существа / более высокие проявления божественности.
- **Kámabiija (icchábiija)** — «семя желания» творения; точка фундаментальной положительности у Shambhúliuṋga.
- **Kaośikii (Shivánii)** — 1-я стадия Пракрити: равновесие, источник kośa; невыраженная.
- **Kalá** — поток с кривизной (вторая фаза эволюции после náda).
- **Káliká Shakti** — оперативная сила (через kálacakra); ≠ богиня Кали.
- **Kula** — последний позвонок, место спящей куна́лини.
- **Kulakuńd́alinii** — «свёрнутая змея»; спящая божественность, сила фундаментальной отрицательности; путь обратно к Брахме.
- **Liuṋga** — точка/предел всех выражений; Shambhúliuṋga = старт (положительность), Svayambhúliuṋga = конец (отрицательность).
- **Lokáyata / lokottara** — мирское / запредельное (суть Shaeva Dharma — подъём из lokáyata в lokottara).
- **Mahákaola** — пробуждённый гуру, способный двигать коллективную эктоплазму и давать siddha mantru.
- **Mahásambhúti** — великое проявление Parama Puruśa для коррекции общества (Шива, Кршна); Тарака Брахма в теле из пяти элементов.
- **Mantra** — «mananát tárayet»: набор звуков, медитация на которые ведёт к освобождению; = смысл + акустический корень.
- **Mantra caetanya / siddhi** — оживление мантры / её кульминация в достижении цели.
- **Náda** — поток без кривизны; стадия между kámabiija и kalá.
- **Nirvikalpa samádhi / kaevalya** — высшая ступень самадхи: «только одно существует».
- **Paṋcánana** — «пятиликий» Шива; пять лиц = пять режимов благополучия.
- **Pará / pashyanti / madhyamá / dyotamáná / vaekharii / shrutigocará** — шесть стадий речи от тонкого к грубому.
- **Parashiva** — Сознание в непроявленном равновесии (Guńámaya).
- **Práńáyáma** — систематическое регулирование вайю для контроля ума.
- **Prańásha / vinásha / násha** — возврат к источнику / трансформация без возврата / обычное разрушение.
- **Pratisaincara** — возвратный цикл эволюции сознания.
- **Saincara** — цикл творения (от сознания к материи).
- **Sambhúti** — первородное творение Parama Puruśa; всё творение.
- **Samádhi, ступени** — sálokya (Отец со мной) → sámiipya (близость) → sáyujya (контакт) → sárúpya (я одно с Ним) → sárśt́hi (я — Он) → nirvikalpa.
- **Shambhú / Svayambhú** — «сам-сотворённый контролёр» (старт, положительность) / «сам-сотворённый» (конец, отрицательность).
- **Shravana / manana / nididhyásana** — слушание, идеация, сосредоточение и отдача ума; путь «домой».
- **Shruti** — Веды как устное знание (shruti = «ухо»).
- **Svarúpa parińáma** — взаимопревращение гун в равновесии (без результата).
- **Sadrsha parińáma** — последовательность похожих кривизн (гомогенез), создающая мир.
- **Táraka Brahma** — средняя точка между Saguńa и Nirguńa, разрушитель оков; тантрическая концепция.
- **Váyus (10)** — 5 внутренних (práńa, apáńa, samána, udána, vyána) + 5 внешних (nága, kúrma, krkara, devadatta, dhanaiṋjaya).
- **Vrtti (50)** — пропенситы ума; 50×2×10 = 1000 vrttis, контролируемых сахасра́рой.
- **Oṋḿkára (práńava)** — a (творение) + u (сохранение) + ma (разрушение) + точка (непроявленное) + полумесяц (проявление).
