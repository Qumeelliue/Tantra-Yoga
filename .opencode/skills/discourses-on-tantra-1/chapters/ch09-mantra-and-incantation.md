# Chapter 9: Mantra and Incantation

*Дискурс от 29 ноября 1978, Madras. Discourse 118 из Ánanda Vacanámrtam Part 5.*

## Core Idea

Мантра — слово, повторение/самовнушение которого освобождает микрокосм от всех оков физической и психической жизни. Для мантры обязательны два качества: обычный смысл и акустический корень. «Incantation» — неполный перевод.

## Frameworks Introduced

- **Определение мантры**: «Mananát tárayet yastu sah mantrah» (man + trae + d́a). Два обязательных свойства: (1) осмысленность (mundane significance), (2) акустическая уместность (acoustic root). Отсутствие любого — не мантра.
- **Двойной смысл**: каждое духовное слово имеет обычное значение + акустическое (вибрационное) значение.
- **Пример «Krśńa»**: корень krś — «притягивать» (всё притягивающая сила, nucleus вселенной); krś — «быть» («я существую, потому что Он существует»); «тёмный» (тёмный цвет — самый притягательный). Акустический корень — **klrḿ** (ka + lr).
- **Звуки творения**: **aum** = a (творение) + u (сохранение) + ma (разрушение-возврат). При творении — волнение в Макрокосме, звук a; сохранение — u; возврат к источнику — ma (последняя буква последней варги pa-pha-ba-bha-ma). «Generator, Operator, Destructor» = G-O-D.
  - **aum = Kárańa Brahma** (Causal); **ka = Kárya Brahma** (Effect/объективированный мир). Ka (первый согласный) = звук перевода Noumenal→phenomenal.
  - Значения ka: (1) первый согласный алфавита; (2) Effect Brahma — объективный мир; (3) «вода» (kaccha = земля, окружённая водой). Kápálika — служащий объективному миру (pálana kriyá of ka).
- **Klrḿ**: ka (объективный мир, сохраняющий) + la (твёрдые сущности) → «божественная сила, вибрирующая весь объективный мир, поддерживая близость к материальному миру».
- **Hara (Shiva)**: ha (эфирный слой) + ra (энергия/kriyáshakti) → «властелин эфирного плана и всех энергий». Hara — акустический корень Шивы.

## Key Concepts

- **Акустический корень — универсален для всего Космоса**, не только санскрит.
- **Siddha mantra**: признана Ма́ха́каолой / Ма́ха́самбхути; только тогда это мантра. Человек сам не может «пробудить» мантру.
- **«Нельзя переводить»**: mantra не имеет синонима в других языках; incantation — вынужденная замена.

## Mental Models

- «Мантра — двуликий: один лик — смысл, второй — вибрация; без обоих — не мантра».
- «Акустический корень — как подпись звука: по нему опознаёшь, что именно вибрирует».
- «GOD = Generator–Operator–Destructor: три функции Брахмы в звуках a-u-m».

## Anti-patterns

- **Использовать слово без акустического корня как мантру** — не будет работать.
- **Приравнивать «мантра» к «incantation»** — потеря двухкомпонентной сути.
- **Забывать, что только Ма́ха́каола/Ма́ха́самбхути могут дать siddha mantru**.

## Worked Example

Слово «Krśńa»: обычный смысл — «притягивающий», nucleus вселенной, «Тот, кто есть, потому что Он есть». Акустический корень — klrḿ. Проверка: есть ли и смысл, и корень? Да. Значит, при признании Ма́ха́каолой оно может стать мантрой. Слово «Shiva» через «Hara»: ha (эфир) + ra (энергия) — тоже полноценный корень. Любое слово без этой пары (например, случайное «abc») — не мантра.

## Key Takeaways

1. Мантра = смысл + акустический корень; иначе не мантра.
2. aum = a+u+ma = творение/сохранение/разрушение-возврат; Kárańa Brahma; ka = Kárya Brahma.
3. Krśńa: корень klrḿ; Hara (Shiva): корень ha+ra.
4. Только Ма́ха́каола/Ма́ха́самбхути дают siddha mantru.
5. «Мантра» не имеет синонима; incantation — приблизительный перевод.
