## Правила решений (уровень «когда X → делай Y»)

| Ситуация | Правило |
|---|---|
| Начать новую миссию/движение | Сначала внутренний фундамент (фаза бхакти), потом публичность (фаза карма-йоги) |
| Развивать людей | Контакт (PC) + наказание с превышением любви + обещание идеала |
| Подготовить кадры | Экзамены на понимание (MIKE), а не на память; «я с ними» для не сдавших |
| Кодекс поведения для команды | Panchadasha Shila (15 правил) + Sixteen Points (ежедневная дисциплина) |
| Блокировка/визовый барьер | Меняй маршрут (Route B), не цель; ценности негибки, планы гибки |
| Экономическая справедливость | PROUT: 5 принципов; покупательная способность — ключевой показатель |
| Охватить весь мир любовью | Неогуманизм: включая растения/животных/«неживое» |
| Новая наука о вирусах/эпидемии | Парадигма Microvita: негативные нейтрализуются позитивными ⚠ |
| Передать наследие лидера | Институт (Gurukula) + преемники + «идеология бессмертна» |
| Права будущего общества | Universal Bill of Rights: безопасность флоры/фауны, покупательная способность, 4 права, кардинальные ценности главенствуют |

## Ключевые фреймворки одним взглядом

- **5 принципов PROUT** — от «нет накопления без одобрения коллектива» до «метод меняется по времени-месту-личности».
- **Авадхута** = «второй Шива»: равнодушие, чистота, жизнь в настоящем, 32 правила.
- **Prama** = равновесие физическое (спрос ↔ предложение ↔ покупательная способность), психическое (осознанность), духовное (садхана/сева/преданность).
- **Kiirtan-мантра** Baba Nam Kevalam — коллективный инструмент очищения и преодоления препятствий.
