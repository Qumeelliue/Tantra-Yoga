# Читшит — Sarkar's Short Stories Part 1 (Сюжет → Мораль)

| Сюжет (рассказ) | Правило | Почему |
|---|---|---|
| Ссора свекрови/невестки (Ch 1) | Думай о последствиях до оскорбления | «Тит-фор-тат» бьёт по мстителю |
| Жена съела рыбу и «отчиталась» (Ch 2) | Проверяй отчёт, а не «клятвы чистотой» | Нелепые оправдания работают на доверчивых |
| Все бреют головы по слуху (Ch 3) | Ищи источник первого звена | Цепочка из 5+ звеньев искажает факт |
| Спор о слове (Ch 4) | Ищи формулировку, устраивающую всех | Достоинство обеих сторон = мир |
| Хитрый директор (Ch 5) | Не давай оппоненту задавать правила | Толпа судит по форме, а не по смыслу |
| 19 двойников Раваны (Ch 6) | Ударь по эмоциям — маска падёт | Эмоция ломает концентрацию |
| Царь ошибается в санскрите (Ch 7) | Авторитет ≠ безошибочность; критикуй мягко | Юмор запоминается лучше выговора |
| Две глухие женщины (Ch 8) | Проверяй понимание, не поддакивай | Вежливое «да» не означает понимание |
| Птицы «поют своё» (Ch 10) | Осознавай проекцию восприятия | Слышишь себя, а не источник |
| Злой до смерти (Ch 11) | Не жди, что смерть/обстоятельства изменят натуру | «Чёрное не примет другой оттенок» |
| Слуга с похоронами (Ch 12) | Проговаривай цель и границы инструкций | Буквальность без смысла = абсурд |
| Обезьяны про Ситу (Ch 13) | Критика других = зеркало себя | Судим по своим меркам |
| Лакшмана против сна (Ch 14) | Потребности можно отсрочить, но не отменить | Записывай договорённости (дневник) |
| Обезьяны не хотят быть людьми (Ch 15) | Комплекс неполноценности мешает принять благо | За рационализацией — страх потери себя |
| Четыре вора (Ch 16) | Не играй по чужим правилам — перепиши их | Историю можно обратить в козырь |
| Шакалы на поминках (Ch 17) | «Спектакль слабости» — приманка для хищника | План сильнее численности |
| Кот-«царь леса» (Ch 18) | Сходство ≠ тождество; притворство ломается | Не согнёшься — сломаешься |
| Лота-«мошенник» (Ch 19) | Форма без смысла — источник конфуза | Рифма/омоним выдаёт подражателя |
| Тришанку у ворот (Ch 20) | Застой = подвешенность без результата | Механические уловки не заменяют заслуги |
| Парвати-старуха (Ch 21) | Гневные слова становятся «законом» через слух | Репутация сильнее фактов до проверки |
| Хяттандас и «рай» (Ch 22) | Не покупай «гарантии» — это мошенничество с доплатами | Каждая гарантия → апгрейд-плата |
| Гопал-тактик (Ch 23) | Дозируй плохие новости, строй цепочку причин | Такт = порядок подачи, не ложь |
| Страх «ребиреби» (Ch 24) | Табу слова не защищает; проверяй симптомы | Суеверие превращает совпадения в доказательства |
| Три королевы (Ch 25) | Запрет без плана исключений будет нарушен заботой | Гостеприимство важнее буквы |
| Панчу и брак дочери (Ch 26) | Не приноси детей в жертву «стигме» | Сравнительная «мораль» обнажает абсурд |

**Запомнить:** Саркар-сатирик = **доведи порок до абсурда + дай явную мораль**. Рассказы независимы; ищи по сюжету или морали.
