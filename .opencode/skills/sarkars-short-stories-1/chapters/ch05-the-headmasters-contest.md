# Chapter 5: The Headmasters' Contest

## Core Idea
Два директора школ из соседних деревень состязаются в учёности. Хитрый директор (мастер обмана) задаёт честному вопрос «Ами джани на?» («Я не знаю») — тот честно отвечает «не знаю». Затем спрашивает, что нужно для брака (вива́ха) — учёный отвечает грамматическим правилом («гхайн»), хитрый трактует буквально («никогда не слышали о таком в свадебной церемонии»). Толпа провозглашает хитрого победителем.

## Frameworks Introduced
- **Ловушка невежества через честность**: честный отвечает буквально на вопрос «я не знаю» — и выглядит неучем.
- **Манипуляция толпой**: хитрый обращается к «экспертам по житейским делам», апеллирует к бытовому опыту, а не к науке.
- **Двусмысленность и её эксплуатация**: научный ответ (морфология: «vi + vaha + ghaiṋ = viváha») превращается в абсурд в устах демагога перед невежественной аудиторией.
- **Сдвиг контекста**: учёный отвечает на лингвистический вопрос, публика слышит «свадебный обряд» — контексты разведены.

## Key Concepts
- **Ами джани на (ámi jáńi ná)** — «я не знаю» (бенгальский) — вопрос-ловушка.
- **Вива́ха (viváha)** — брак (санскрит); в морфологии: «vi + vaha + ghaiṋ».
- **Гхайн̭ (ghaiṋ)** — грамматический аффикс; «гхайн» для толпы = абсурд.
- **Деревенский полицейский** — «элита», ликует и угощает сладостями.

## Mental Models
- «Думай о честности как о слабости перед тем, кто выбирает правила игры».
- «Думай о толпе как о судье по жизненному опыту, а не по истине: она верит тому, кто говорит на её языке».
- «Думай о демагоге как о том, кто меняет критерии оценки (наука → быт) в свою пользу».

## Anti-patterns
- Отвечать на вопрос противника без проверки правил.
- Верить толпе, судящей о науке по бытовому опыту.
- Считать «победителем» того, кто громче аплодируется.

## Worked Example
Хитрый: «Что нужно для вивахи?» Учёный: «Гхайн. Приставка vi + vaha + гхайн = виваха». Хитрый толпе: «Слыхали ли вы, чтобы в свадебной церемонии требовался гхайн?» Толпа: «Нет». «Мои 14×2=52 поколения предков не слыхали». Толпа аплодирует. Победа достаётся обману, наука проиграла перед невежеством.

## Key Takeaways
1. Демагог задаёт вопросы, в которых честность выглядит глупостью.
2. Аудитория без критериев истины судит по форме и опыту.
3. Научная точность уязвима перед переводом в бытовой контекст.
4. Не позволяй оппоненту устанавливать правила оценки.
