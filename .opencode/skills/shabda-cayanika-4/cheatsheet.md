# Читшит — правила решений по Саркару (Shabda Cayaniká 4)

## Этимология и правописание

| Ситуация | Правило |
|---|---|
| Вывести смысл слова | Корень + суффикс → «то, что …»; все значения растут из этого |
| Tatsama или tadbhava | Санскрит как есть (káca) — tatsama; народное изменение (káṋc) — tadbhava; оба законны |
| Кончается слово на энд-lra | Пиши/говори как lra (gulo/guli); в англ. переводе — la |
| Слово с падежной m | Пиши `uṋga`, не `ḿga`: `gauṋgá`, `kaliuṋga`, `kuiṋja` |
| Составное слово с káli | Только i: `Cańd́iidása` верно, `Káliidása` нет |
| Сажа / дёготь / пек | Сажа и дёготь — всегда i (`káli`); пек — всегда ii (`kálii`) |
| Чернила vs облако | Чернила `kajjvala` (с va), облако `kajjala` (без va) |
| Писать vikása или vikásha | vikásha (развитие, корень kásh=светить); vikása = «сильно кашляющий» |
| Сочетание sha/śa + tha | Невозможно; только `káśt́ha` (ретрофлексное t́h) |
| Префикс mahá- | `mahánidrá`=смерть, `mahámáḿsa`=человеческая плоть, `maháshúdra`=молочник |
| Слово «кашляющий» vs «развитие» | Пиши sh в ákásha/prakásha/vikásha |

## Этика и поведение

| Ситуация | Правило |
|---|---|
| Сделал запретное | `pápa` (искупимо возвратом+прощением) |
| Не сделал должное | `pratyaváya` — «более отвратителен», чем pápa |
| Грех с крайними аскезами | `atipátaka` (убийства Аджаташатру и т.п.) |
| Грех, умноженный в истории | `mahápátaka` (обман доверия — Равана) |
| Врождённый порок (ripu) | Сдерживай сублимацией, не подавляй |
| Навязанный узел (pásha) | Преодолевай активно: иди к источнику страха |
| Ненависть (ghrńá) | Это pásha; разбирай рассудком |
| Хорошая компания | Satsanga = освобождение; плохая = оковы |
| Показная добродетель | Лицемерие = разница видимости и реальности (`kukkut́ii`, сатира Акалманда) |
| Алкоголь | Рушит интеллект; «ритуальное» оправдание — слабость и извращённость |

## Идея и ремесло

| Ситуация | Правило |
|---|---|
| Материализовать идею | Три условия: план + сила + инфраструктура |
| Один человек тянет идею | Редко; нужен посредник/среда (káriká) |
| Ручной труд vs голос | `shilpa` — только руками; певец не `kant́hashilpii` |
| Искусство с инструментом | `káru-vidyá` (ремесло); превосходное пение — káru |
| Заёмные деньги | Должны оборачиваться; не в витрины/пристройки |

## Язык и общество

| Ситуация | Правило |
|---|---|
| Имя дочери Saramá | Не называй: sárameya = собака; Saramá Рамайаны — демон |
| Обычай «выдавать» невесту | Против гуманизма; отменять рационально (критика Manu) |
| Кастовая система | Средство угнетения; melbandhan защищал от изгнания |
| Проверить слово на «иностранность» | Проверь этимологию: pat́ii — санскритское, kágaj — арабское |
| Птица/цвет/вещь чёрные | Возможные имена: kálii/káli/káliká/kála — выбирай по корню и роду |
| Рог носорога как лекарство | Миф; рог — масса волос; истребление не оправдано |
| Лак/шёлк/агуру | «Рождённые насекомым» = `kiit́aja`; имена по виду шёлка (tasar/muga/eńd́i/garad) |

## Меры времени (по káśt́há/kala)

| Ситуация | Правило |
|---|---|
| 1/13 доли луны | `káśt́há` (kalá — 1/16 луны; 16-я — amákalá) |
| Моргание глаза | 18 palakas = 1 káśt́há |
| Зенит/надир | `parákáśt́há` / `apakáśt́há` |
| Волна | Подъём + предшествующий спуск = káśt́há |
