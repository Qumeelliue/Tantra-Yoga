# Читшит — правила решений по Саркару (Light Comes)

## Духовный путь

| Ситуация | Правило |
|---|---|
| Определить стадию человека | «Я-только» → «Я и Ты» → «Ты и Я» → «Только Ты» |
| Сильное материальное влечение | Не подавлять — перенаправить на Parama Puruśa (праvrtti→nivrtti) |
| Знание/действие кажутся пустыми | Они разжигают преданность, а не цель: проверяй по bhakti |
| Выбрать компанию | satsaṋga: уменьшает расстояние до Господа; иначе asatsaṋga |
| Путь кажется «лезвием бритвы» | Выход — преданность; где преданность, там Параматма |

## Дхарма и садхана

| Ситуация | Правило |
|---|---|
| Что такое dharma X? | Dharma = природа: огонь жжёт, человек ищет Брахму |
| Цель жизни человека | viśt́ára + rasa + sevá → tadsthiti (Bhágavat Dharma) |
| Нет сил начать/продолжить | parishrama — первое и последнее условие успеха |
| Препятствия в садхане | Добрый знак: Avidyámáyá защищается — продолжай |
| Мечта вместо действия | «Манго само не упадёт в рот»: практика обязательна |

## Гуру и поведение

| Ситуация | Правило |
|---|---|
| Кого считать гуру | Тьма-рассеиватель («gu» тьма, «ru» рассеивающий), освобождённый |
| Гуру демонстрирует чудеса | Самозванец под властью Avidyámáyá — «отвергни как змею» |
| Ждать милости пассивно | Ложь: «пастух не пасёт стадо»; усилие + милость обязательны |
| Исправить нарушение | 4 ступени шасти; мера ≤ мере любви; цель — реформа |
| Критиковать другого | Сначала проверь себя на тот же дефект; критикуй без «прилипания» |

## Практики тела и ума

| Ситуация | Правило |
|---|---|
| Еда | Саттвичное всегда, мутативное изредка, статичное никогда |
| Еда по мотивам | priityanna — принять; ápadanna (выживание) — любые ограничения сняты; shráddhánna — не принимать |
| Пост | Upavása — дни по альманаху ⚠; не голодовка, а «жизнь рядом с Богом» |
| Нечем занять ум | Киртана: 10 индрий + ум заняты; мриданга возвращает внимание |

## Нео-гуманизм и общество

| Ситуация | Правило |
|---|---|
| Чувство привязано к земле/общине | Это geo/socio-sentiment; расширяй до Neohumanism |
| Оценить существо | Экзистенциальная ценность > утилитарной; никто не уполномочен убивать |
| Эксплуатация в обществе | Ищи психический фундамент: внушённый комплекс неполноценности |
| Голод и переедание в разных странах | Дисбаланс — творение эгоистов, не Бога; минимум благ — каждому |
| Управление кооперативом | Только честные директора; иначе «настоящий социализм не увидит света» |
| Равноправие | Женщины равны: пол лишь в двух низших кошах; 50% в притеснении = нет прогресса |

## Материализм и будущее

| Ситуация | Правило |
|---|---|
| Страх перед оружием/бомбой | Создатель ума сильнее создания: бомбу ум и остановит |
| Жадность управляет решениями | Lobha — корень всех грехов; грех идёт кривым путём-бумерангом |
| Материализм обещает блага | Не даст даже материального: у власти нет моралистов |
| Догма «непогрешима» | Бумерангом сломается о прогресс; вставай на сторону будущего |
| Настроение пессимизма | Оптимизм — суть жизни; «Caraeveti» — единственный мантра |

## Быстрые сигналы («tells»)

- «Я сам всё делаю, я — агент» — не понят скрытый контролёр; эго деятеля.
- Сверхспособности как аргумент — признак ложного гуру.
- Критика чужих идеалов вместо конструктивной работы — «критика прилипает».
- Мгновенное прощение неисправленных — слабость ума, вред обществу.
- «Развитые» страны, не стоящие на своих ресурсах, — форма принуждения к покупке.
- «Я люблю Его, чтобы получить» — коммерция; «хочу, чтобы моя любовь радовала Его» — преданность.
