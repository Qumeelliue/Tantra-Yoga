# Читшит — правила решений по Саркару (Pramá)

## Диагностика и восстановление

| Ситуация | Правило |
|---|---|
| Оценить здоровье системы | Три сферы: физическая + психическая + духовная; равновесие = прама |
| Заметил потерю баланса | Восстанавливай немедленно (derangement) — ждать = распад = дегенерация |
| Система в дегенерации | Восстановление ступенчато: дегенерация → распад → расстройство → баланс |
| С чего начать восстановление | Физический пласт первым (антисоциальные элементы возьмут верх) |
| Сложная система | Раздели на подпласты-подтреугольники и балансируй по частям |

## Физический пласт

| Ситуация | Правило |
|---|---|
| Планировать экономику региона | Четыре фактора: спрос (сейчас/будущее), предложение (сейчас/будущее), максимум земли, 5 принципов PROUT |
| Сельское хозяйство | Ирригация + сорта + 3–4 урожая + правильные культуры + кооперативы; принцип потребления, не прибыли |
| Нужда в соседней стране | Физическая прама глобальна: «рядом свет и тьма не остаются» — равновесие неполно |
| Бедная страна с нехватками | Увеличить производство; не нападать; при перенаселении — бартер излишками |

## Психический и духовный пласт

| Ситуация | Правило |
|---|---|
| Оценить искусство/философию | Проверь пропорцию и баланс (пример лотоса и пруда); догматическая философия — «психическая болезнь» |
| Духовная практика | Паломничества и омовения — не путь; путь — внутрь, через пранипа́та → парипрашна → сева́ |
| Создать духовный позыв | Образование: начальные школы с духовно-психическим стилем, а не колледжи |
| Психическое заболевание | Различай brain disease (физика) и mental disease (объективированный ум); лечи через баланс и садхану |

## Самодисциплина

| Ситуация | Правило |
|---|---|
| Запуск сложного дела | Семь факторов: решимость → шраддха → наставник → самата-бхава → контроль чувств → питание |
| Контроль других | Сначала контроль себя: «кто не владеет собой — не владеет другими» |
| Еда | Сбалансированная (pramitáhára); тама́сик еда портит ум и клетки |
| Служение vs коммерция | Служение односторонне; взаимное = сделка. Коммерция — для хлеба, сева — для прогресса |

## Догма и микростатья

| Ситуация | Правило |
|---|---|
| Жёсткая вера/изм | Догма блокирует даже физическую праму — «где догма, прамы нет» |
| Оценить «тёмную» технологию/эффект | Микростатья ни друг, ни враг по природе; всё зависит от использования |
| Мир войн «толерантных» стран | Догмы внутренне противоречивы (банки при запрете процентов) — не верь лозунгам |
| Образование мира | Переориентируй: йога-асаны, диета, спорт + неогуманизм, аштанга-йога; «эта вселенная — наша» |

## Быстрые сигналы («tells»)

- «Запад богат, Индия духовна» — оба без прамы: ни один пласт не совершенен без настройки с другими.
- Слышишь «путь Будды» как единственный — чистый Nivrtti без Saḿvrtti не даёт «повода жить».
- Догма + банки, «толерантность» + войны — внутренние противоречия = догма.
- Сосед голодает, ты богат — физическая прама твоя неполна; готовься к беспокойству.
- Человек на пике одной сферы без других — «башня без фундамента»: нет совершенной прамы.
