# Паттерны — Pramá

## Диагностика баланса (три сферы)
**Когда использовать**: оценка индивида, команды, общества, продукта.
**Как**: проверь физический пласт (ресурсы, потребление, безопасность), психический (образование, культура, мышление), духовный (смысл, устремление, единство). Равновесие всех трёх = прама; перекос = дефекты (искусство без пропорции, экономика без культуры, духовность без физики).
**Компромиссы**: «три сферы» — метафора; операционализируй через конкретные метрики каждого пласта.

## Анализ стадий упадка
**Когда использовать**: анализ деградирующей системы (компания, сообщество, продукт, экономика).
**Как**: определи стадию: derangement (потеря баланса) → disruption (распад) → degeneration (полная дегенерация). Восстановление — ступенчато снизу вверх, нельзя прыгнуть из дегенерации в равновесие.
**Компромиссы**: стадии описательны; не все системы проходят их линейно — ищи и прыжки, и циклы.

## Восстановление физического пласта первым
**Когда использовать**: кризисное управление, антикризисные программы.
**Как**: если физический пласт (еда, жильё, безопасность) разбалансирован — «антисоциальные элементы возьмут верх» и потянут вниз психику и духовность. Начинай восстановление с физического, затем психический, затем духовный.
**Компромиссы**: «физический первым» не означает игнорировать верхние — они связаны и взаимно влияют.

## Подпласты-подтреугольники
**Когда использовать**: сложные системы балансировки (экономика региона, продуктовая экосистема).
**Как**: раздели пласт на подпласты (физический: агро, промышленность, торговля, медицина, ирригация, физкультура; психический: языки, литература, история, философия, наука — как часть физического). Для каждого — свой подтреугольник; восстанавливай по одному, ступенчато.
**Компромиссы**: деление на подпласты субъективно; важно не «правильное» деление, а разумные границы, позволяющие балансировать по частям.

## Чек-лист семи факторов побуждения
**Когда использовать**: личная и командная самодисциплина, запуск сложных проектов.
**Как**: решимость («я преуспею») → шраддха (движение к истине) → следование наставникам → самата-бхава (баланс ума, немедленное восстановление прамы) → контроль чувств → сбалансированное питание/среда. Выпадение фактора ослабляет весь прогресс.
**Компромиссы**: факторы духовные; для светских проектов переводи в светские аналоги (цель, наставничество, баланс, самодисциплина, ресурсы).

## Служение vs коммерция
**Когда использовать**: проектирование сервисов, волонтёрства, продуктов с социальной миссией.
**Как**: служение одностороннее (не ожидает возврата); взаимный обмен — коммерция. Коммерция — для пропитания, сева — для прогресса. Не маскируй коммерцию под служение и наоборот.
**Компромиссы**: грань тонка; гибрид (подписка = коммерция + благотворительность = сева) работает, если честно разделён.

## Тест догмы
**Когда использовать**: оценка жёстких верований в команде, продукте, обществе, политике.
**Как**: спроси «есть ли противоречие между заявленной догмой и практикой?» (банки в странах без процентов; «толерантные» в войнах). Догма блокирует физическую, психическую и духовную праму — «даже физическая pramátrikońa невозможна, где догма».
**Компромиссы**: «догма» ≠ убеждение; различай твёрдые принципы и негибкую веру, игнорирующую факты.

## Глобальность прамы
**Когда использовать**: проектирование региональных/глобальных решений.
**Как**: помни, что физическая прама глобальна: «рядом свет и тьма не могут оставаться». Если где-то рядом нужда — равновесие всей системы неполно, конфликт вероятен.
**Компромиссы**: глобальный идеал не парализует локальные улучшения — двигайся шагами, но учитывай соседей.

## Бартер вместо агрессии
**Когда использовать**: межрегиональные нехватки ресурсов.
**Как**: нехватки решаются обменом излишками (бартер), а не захватом ресурсов. Атака ведёт к политической нестабильности и экономическому ущербу для всех.
**Компромиссы**: бартер не решает структурные дисбалансы; это тактический инструмент, не стратегия.

## Микростатья: друг/враг по использованию
**Когда использовать**: оценка «тёмных» и «светлых» технологий, эффектов, явлений.
**Как**: «по природе никто никому не враг» — отношение определяет использование. Яд — лекарство, змеиный яд — медицина. Оценивай по применению, не по сущности.
**Компромиссы**: не превращай в моральный релятивизм — важно намерение и последствия для коллективного развития.
