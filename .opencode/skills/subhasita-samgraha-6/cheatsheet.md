# Читшит — правила решений (Subháśita Saḿgraha Part 6)

## Поклонение и устройство мира

| Ситуация | Правило |
|---|---|
| Что является первопричиной | Не природа и не время; Брахма-Чакра вокруг Пурушоттамы |
| Время как причина | Нет: время — измерение мотивности действия, не творец |
| Работа, которая связывает | Работа ради работы; с Брахма-идеацией — освобождает |
| Оценить силу/власть | Шкала: baddha (в оковах) vs Гуна-дхиша (гуны дремлют) |
| Оккультные силы/Бхагаван | Шесть бхаг и семь сил — не цель; Бхагеша — выше оков |

## Преданность и пути

| Ситуация | Правило |
|---|---|
| Выбрать путь | Преданность > знание > действие; «мокша-карана-самагрaм бха́тирева гарийаси» |
| Мукти vs мокша | Према расширяет I-чувство (мукти); парабхакти/кевала-бхакти устраняет (мокша) |
| Цель садханы | Пуруша (Сознание), не Пракрити; конверсия материя→энергия→идея→сознание |
| Тапах | Добро другим через собственные трудности; дхарма = благо всех существ |
| Мир «иллюзорен»? | Майявада отвергнута: садхана — расширение, путь храбрых |

## Пять совестей (вивека-пан̃чака)

| Ситуация | Правило |
|---|---|
| Постоянное/непостоянное | Религии относительны; дхарма вечна; адаптируйся к эпохе |
| Одно/много | Вечное не может быть многим; боги-соперники — иллюзия |
| Сознание/не-сознание | Деньги/формы — не-сознание; не дают бесконечного счастья |
| Пять слоёв | Еда/одежда — необходимость, не цель; сознание выше кош |
| Знания мало | Нужны действие и преданность; пран̃ипа́тена/парипрашнена/севaйа |

## Знание и вопрос

| Ситуация | Правило |
|---|---|
| Разделить науку/духовность | Апара-вопрос (внутри мира) vs парама-вопрос (о источнике) |
| Субъект/объект | В пара-видье ты — объект Другого Субъекта; путь — сдача |
| Реальное знание | Духовно-интуитивное (aparokśanubhúti); перцептивное — «тень знания» |
| Речь о Брахме | Словами не описать (шесть шакти речи ограничены) |
| «Познать Брахму» | Brahmavid Brahmaeva bhavati — познать = стать |

## Быстрые сигналы («tells»)

- «Работа ради работы» в команде → накопление «долгов», выгорание (Ch 1).
- «Я честен, но внутренне пуст» → морализм без идеации (Ch 1, 2).
- «Уважаю все религии» как платформа → не решает; дхарма одна (Ch 4).
- Изм, клевещущий на конкурентов и гребущий власть → «религия XX века» (Ch 4).
- Дорогие ритуалы/паломничества → коммерция веры, не садхана (Ch 1, 2).
- Спор через слова о «невыразимом» → дебаты ради удовольствия (Ch 5).
