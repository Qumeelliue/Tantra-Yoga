# Chapter 3: The Intuitional Science of the Vedas – 5

*Дискурс Agraháyańa Púrńimá 1956, DMC.*

## Core Idea

Bharga (белый свет) неотделим от Saguńa Brahma — Он самосветящийся. В теле три региона гун (тамо/раджо/саттво). Puruśottama имеет пять/восемь свойств (Nrsiḿha-мантра). Он̭м́kára покрывает всю Cosmic System и больше, чем Ануштубха (только ядро). Он̭м́kára — для слушания, не произнесения.

## Frameworks Introduced

- **Bharga**: в Гаятри-мантре «bharga» = белая радиация, неотделимая от Брахмы; «Bharga» трёхбуквенный: «Bha» (освещает миры), «Ra» (даёт счастье), «Ga» (то, во что творение сливается). Брахма самосветящийся (autophanous) — «Daevii hyeśá...».
- **Три региона гун в теле**: ниже пупка — tamoguna; пупок-горло — rajoguna; горло-трикути (между бровями) — sattvaguna. В vrtti-активности регионы активируются по доминанте гуны.
- **Nrsiḿha = Puruśottama** (не полу-человек-полу-лев из Пуран): Nr = nara/puruśa, Siḿha = shreśt́ha. Пять свойств (из мантры «Ugraḿ viiram maháviśńum...»): **Ugram** (милостивый через творение/сохранение/разрушение), **Viiram** (смелый, встречает все проблемы), **Maháviśńu** (всепроникающий, «Visnu»=vast), **Jvalantam** (блажущий, источник всех сил), **Sarvatomukham** (всевидящий, в 10 направлениях). Плюс **Bhiiśańam** (грозный для тех, кто не осознал единство; из страха Его ветер дует), **Bhadram** (благостный), **Mrturmrtyum** (Смерть смерти — для достигших смерти больше нет).
- **Он̭м́kára vs Ануштубха**: Ануштубха-мантры (8 слогов) — для Puruśottama (ядра); он̭м́kára — для всей Cosmic System (всех пяти факторов). Поэтому он̭м́kára больше; Ануштубха внутри его. Он̭м́kára — четырёхслоговой (a-u-ma + sonic dot), из которых три — Сагуна, точка — Ниргуна.
- **Он̭м́kára для слушания**: «не звук для произнесения, а для слушания»; человеческий голос не может дать верную форму. Постигший он̭м́kára идёт к sonic dot — Turiiya — Nirguńa — Iishvaragrása.

## Key Concepts

- **Bharga** — белый свет, неотделимый от Брахмы.
- **Трикути** — место ума, где начинается «Avarna» (бесцветность).
- **Nrsiḿha / Puruśottama** — высшее Ядро, защитник садхаков.
- **Ануштубха** — мантра для Puruśottama.
- **Iishvaragrása** — поглощение Ишвары в Ниргуне.

## Mental Models

- «Думай о Bharga как о свете лампы: лампа и свет — не два отдельных».
- «Смотри на Nrsiḿha как на символ Ядра, а не мифологическое чудовище».
- «Думай об он̭м́kára как о резонансе всей системы, а Ануштубха — о её ядре».

## Anti-patterns

- **Придавать Брахме форму** (полу-человек-полу-лев) — ридикюль, «отвергать супрамунданное».
- **Пытаться произнести он̭м́kára голосом** — «это не звук для произнесения».
- **Считать Ануштубху и он̭м́kára равными** — он̭м́kára покрывает всю Cosmic System.

## Worked Example

Автор разбирает мантру «Ugraḿ viiram maháviśńum...»: Ugra — «Ur»=anu+graha (милостивый); солнце для земли — Ugra (создаёт/сохраняет/разрушает). Viira — смелый, противостоит всем проблемам. Mahavisnu — расширил ум до бесконечности. Jvalanta — источник всех сияний («Na tatra súryo bháti...»). Sarvatomukha — свидетель всех направлений. Bhiiśańa — из страха Его ветер дует, солнце сияет (история: Огонь не смог сжечь соломинку, Воздух не смог сдуть). Bhadra — благословенный. Mrtur mrtyum — Смерть смерти: для достигших Пуршоттаму их смерть последняя.

## Key Takeaways

1. Bharga (белый свет) — неотделимая радиация Брахмы.
2. Тело отражает гуны в трёх регионах.
3. Nrsiḿha — не миф, а Puruśottama с пятью/восемью свойствами.
4. Он̭м́kára покрывает всю Cosmic System; Ануштубха — только ядро.
5. Он̭м́kára — для слушания, не произнесения; ведёт к Turiiya.
