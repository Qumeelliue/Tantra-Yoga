# Читшит: правила решений

| Ситуация | Правило |
|----------|---------|
| Хочешь реализовать Брахму | Не через слова/интеллект — садхана + милость; «знающий становится Брахмой» |
| Строишь практику | Три аспекта: знание+преданность+действие; два — средняя; «только знание» — обломки |
| Читаешь много, не практикуя | «Книжный Брахма» не считается; добавь садхану |
| Хочешь «прыгнуть выше» без усилий | Нужна вера «я достигну» (первая ступень) + shraddhá + контроль чувств + умеренная пища |
| Думаешь «уйти в Гималаи» | Это психическая болезнь; sannyása = преданность истине, не отшельничество |
| Стремишься к Турье | Пойми он̭м́kára (a-u-ma + sonic dot); три состояния — относительны; нужна полная самоотдача |
| Веришь в «вещие сны» | Сенсорный сон — самскары; супраментальное видение — редкий прогноз (~8–10 раз/жизнь) |
| Доверяешь гипнозу/планшеткам/зеркалу | Почти всегда твои самскары; не духи |
| Путаешь сон и самадхи | Сон — отдых, samádhi — слияние; сон не освобождает |
| Слышишь о «33 крорах богов» | Невежество; 33 девы = органы+нервы и их космические аналоги |
| Спрашиваешь «почему ум тяжёлый» | Ниже пупка — tamoguna; пупок-горло — rajoguna; горло-трикути — sattvaguna |
| Видишь миф «Nrsiḿha» | Не полу-человек-полу-лев: Puruśottama, защитник садхаков |
| Думаешь «он̭м́kára vs Ануштубха» | Он̭м́kára покрывает всю Cosmic System; Ануштубха — только ядро |
| Хочешь произнести он̭м́kára голосом | Это звук для слушания, не произнесения |
| Хочешь познать через роли («я — Хануман») | В Ананда Марге — спонтанное «я есмь», без imposition ролей |
| Слышишь «сон — конец сознания» | Сон — отдых умов; смерть — прекращение всех трёх умов |
| Спрашиваешь «кто такой Ишвара» | Ишвара = спящий макрокосм (Prájiṋa — микро); в Турье — Iishvaragrása |
| Оцениваешь вайю в теле | 5 внутренних (práńa, apána, samána, udána, vyána) + 5 внешних (зевание, икота, голод/жажда, сон, потягивание) |
