# Читшит — правила решений по Саркару (Ananda Marga 5)

## Управление и знание

| Ситуация | Правило |
|---|---|
| Кто управляет жизнью | Buddhi-возничий держит вожжи-ум; Атман — свидетель-пассажир |
| Органы «разбежались» | Не убивай (restraint≠умерщвление): учи и держи вожжи |
| Есть теория, нет практики | Это jñāna; нужен vijñāna — практическое умение, иначе «катастрофа» |
| Знание о Брахмане | Познаётся agryábuddhi (острый сфокусированный ум), не спорами |

## Материя и сознание

| Ситуация | Правило |
|---|---|
| «Мир из атомов, духа нет» | Материя = сжатая энергия; энергия = сознание под покровом Пракрти |
| Сознание из комбинации элементов? | Нет: потенциал в каждом атоме (бамбук в семени, соль из хлора+натрия) |
| Физика vs духовная философия | Физика аналитична (опровергает прошлое); духовная — синтетична (накапливает) |
| Память «живёт в мозге»? | Нет: живёт в читте (самскары); мозг — машина, ум — механик |

## Состояния и практика

| Ситуация | Правило |
|---|---|
| Оценить состояние ума | kṣipta (ярость) / múdha (дурман) / vikṣipta (отвлечение) / ekagra (концентрация) |
| Киртан/восторг без морали | Подозревай vikṣipta: срыв после сеанса; контроль без yama/niyama опасен |
| Подъём по кошам | Кámamaya → manomaya → atimánasa → vijiṋánamaya → hirańmaya; финал — satyaloka |
| Пратйахара | yatamána → vyatireka → ekendriya → vashiikára (полный контроль чакр и лок) |
| Медитация | Только в sthirásana (неподвижная поза); пра́н́а́яма — с Brahmabháva, иначе разрушение |

## Быстрые сигналы («tells»)

- «Возничий» не обучен практикой — жди катастрофы при первых трудностях.
- Моралист без садханы — «певец-бхаджана»: благость на публике, срыв наедине.
- Тот, кто спорит о Боге «белый или чёрный» — не знает, что Брахман вне атрибутов.
- Шунья «как пустота» — ошибка: шунья = неатрибутивная полнота.
- Ли́н̭га-поклонение вульгарно: неатрибутивный Puruṣa — единственный абсолют.
