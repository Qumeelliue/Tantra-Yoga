# Читшит: правила решений

| Ситуация | Правило |
|----------|---------|
| Хочешь понять мотивацию преданности | Определи объект: плод/слава → támasika/rājasika; «уничтожь карму» → sāttvika; только Брахма → Kevalá; «люблю любя» → Rāgátmiká |
| Думаешь, что конечный объект — база жизни | Конечное уйдёт; база жизни — только Brahma; применяй madhuvidyá |
| Любишь ребёнка/отца/дело | Люби Брахму в их форме — тогда потеря не страшна |
| Хочешь «уйти в Гималаи» | Это эскапизм (страх долга); vaerágya = бесстрашие, а не бегство |
| Решаешь, как помочь нуждающемуся | Голод → еда; болезнь → уход; агрессия → защита; невежество → наставление |
| Пьянице предлагают деньги | Не давай: усилит порок; нужна твёрдость + проповедь |
| Заметил гордость за доброе дело | Идеация Náráyańa: объект — Брахма, я — инструмент; предай действие и реакцию |
| Служишь без любви | Это показуха; служение без премы бессмысленно |
| Думаешь «только духовное» / «только мирское» | Нужен баланс vidyá/avidyá: интроверсия к Брахме + нормальные мирские дела |
| Оцениваешь сон-«пророчество» | Сенсорный сон — самскары; супраментальное видение — редкий прогноз (~8–10 раз/жизнь) |
| Доверяешь гипнозу/спиритизму | Отражают твои же самскары; не духи |
| «Почти достиг истины» | Преграда — Hirańmaya Kośa; сними покров садханой |
| Чувствуешь «мы/они» по касте/религии | Дифференциация — главное препятствие; все равны перед Брахмой |
| Сомневаешься в праве женщины/шудры на знание | Право есть: женщины — авторки ведических стихов, Вьяса — сын рыбака |
| Ум «застрял» на объекте | Ум принимает форму объекта; направь его на Брахму |
| Боишься «конца вселенной» | Космический mind-stuff бесконечен; полного растворения не будет |
| Думаешь, что Брахма «выигрывает» от твоего освобождения | Он не нуждается; будь благодарен за милость |
| Видишь преданного-«суперстициозного» | Всё равно считай его высоким: любая бхакти лучше отсутствия |
| Утверждаешь «факт» как «истину» | Факт (tathya) меняется; satya неизменна и вне времени/пространства/личности |
| Хочешь познать Брахму | Стреляй из лука-упанишады: он̭м́kára — образ лука, ум — стрела |
