# Читшит — правила решений (Ánanda Vacanámrtam 14)

## Дисциплина и успех

| Ситуация | Правило |
|---|---|
| Построить дисциплину | 8 принципов Будды: darshana/saḿkalpa/vák/ájiiva/vyáyáma/karmánta/smrti/samádhi |
| Довести дело | Кarmánta: закончи качественно; Uttama доводит, Adhama боится начать |
| Оценить успех | Три вида: Pratiśt́há (физич.), Sarvajiṋatá (психич.), Siddhi (духовн.) |
| Достичь успеха | 7 секретов: решимость→вера→гуру→равновесие→контроль→диета (седьмого нет) |
| Диета | Саттвичная, сбалансированная; ни переедания, ни голода |

## Виды человека и йога

| Ситуация | Правило |
|---|---|
| Классифицировать мотивацию | Pashu (еда/сон) → viira (борьба с узами) → deva (божественность) |
| Выбрать стиль практики | Pashvácára → viirácára/ciinácára → divyácára |
| Что есть йога | Объединение unit с Supreme (sugar-water); не суспензия, не упражнение |
| Йога в трёх сферах | Karma (физич.) / Jiñána (психич.) / Bhakti (духовн.); иначе дисбаланс |
| Оценить практику как «йога» | Проверь: объединяет (yuiṋj) или складывает (yuj)? |

## Действие и причинность

| Ситуация | Правило |
|---|---|
| Прогноз последствий | Реакция ≠ равна действию: меняются время/пространство/личность (Tridańd́a) |
| Плохое кажется хорошим | Пока реакция не созрела — иллюзия; маятник качнётся |
| Объяснить событие | Ищи причину: всё каузально, «accidental» = миф, «incidental» = факт |
| Знать за пределом теории | Невозможно: зенит ума — предел; дальше только слияние |

## Ум и внушение

| Ситуация | Правило |
|---|---|
| Управлять умом | Iśt́a Mantra — лучший auto-suggestion |
| Выбрать окружение | Satsauṋga (добро) vs дурная компания (вред); компания = внушение |
| Оценить добро | Ближе к Сущему = добро; дальше = зло |
| Восприятие | Extro-internal (извне) vs intro-external (проекция наружу); галлюцинации — проекции |

## Сущее, свидетель, догма

| Ситуация | Правило |
|---|---|
| Контакт с Сущим | «Он видит меня» — ты объект, Он субъект; освобождает от эго |
| Чувство одиночества | Ложь: ты никогда не один; Он — свидетель, энергию даёт Он |
| Аудит идеи | Границы = догма; догма запечатывает будущее интеллекта |
| Сдаваться догме | Никогда: «Dogma — No More!» |
| Познать Макрокосм | Расширяй периметр ума борьбой с ограниченностью |

## Быстрые сигналы

- Видишь «йогу» из упражнений/суспензии — это не йога по Саркару.
- Практика без преданности («садхана без преданности») — «трата времени».
- Идея с запретом выходить за черту — догма; проверяй во всех науках.
- «Меня никто не видит» — «будешь пойман с поличным»: Он всё свидетельствует.
- Слышишь «всё случайно» — неверно: всё инцидентально, причина есть.
