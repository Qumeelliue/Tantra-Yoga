# Chapter 14: What Is Yoga?

*Дискурс от 12 сентября 1979, Haifa.*

## Core Idea

Человеческое существование трёхчастно; йога нужна во всех трёх сферах — физической, психической, духовной — иначе равновесие утрачено. Йога = объединение (yuiṋj), не сложение (yuj) и не упражнение. Три йоги: Karma, Jiñána, Bhakti.

## Frameworks Introduced

- **Йога во всех трёх сферах**: только духовной йоги недостаточно — существование станет несбалансированным; нужен йога-ориентированный подход в каждой сфере.
- **Йога в физической сфере**: помни, что всё, что видишь/делаешь, — в эктоплазмической сфере Творца. Капля, чувствующая единство с океаном, — становится океаном; человек, чувствующий себя ребёнком Supreme Father и ставший одним с Ним, обретает безмерную силу (через Guru Mantra). Разделённый — обычен; единый — Supreme.
- **Йога в интеллектуальной сфере (Jiñána Yoga)**: 50 пропенсити × 20 направлений = 1000 выражений, управляемых pineal gland (в бессознательном); есть в cerebral и extra-cerebral памяти. Йога = отвод (withdraw) пропенсити и направление их к Parama Puruśa. `Yogashcittavrttinirodhah` в интеллектуальной сфере.
- **Karma Yoga**: karma = действие = изменение места; `kr` → karma.
- **Йога в духовной сфере (Bhakti Yoga)**: `Saḿyoga yoga ityukto jiivátmáparamátmanah` — объединение unit с Supreme. Этимология: `yuj` = добавить (2+2=4, идентичность сохранена), `yuiṋj` = унифицировать (сахар+вода, идентичность теряется). В духовной йоге — `yuiṋj`.
- **Два «я»**: маленькое «я» (имя: Solomon, Joseph) различно; большое «я» (Parama Puruśa) — одно для всех. Йога духовная: теряешь имя маленького «я», получаешь большое «я»; получаешь всё, теряя ничего.
- **Йога ≠ упражнение**: «йога не означает упражнение; йога означает объединение».
- **Дхарма человека (4 квалификации)**: (1) расширяться, (2) стать одним с Cosmic Body, (3) делать благородное, (4) искать высший покой. Это отличает человека от животных/растений.
- **Йога — панацея**: физических, психических, духовных недугов; в индивидуальной жизни практикуй, в коллективной — побуждай других.

## Key Concepts

- **Karma Yoga / Jiñána Yoga / Bhakti Yoga** — три йоги по сферам.
- **1000 пропенсити** — 50×20 (здесь ×20, в других дискурсах ×2×10).
- **Guru Mantra** — мантра гуру (для единства).
- **`kr` → karma** — действие = изменение места.
- **`jiñá` → jiñána** — «знание» = субъективизация объективности.
- **yuj vs yuiṋj** — добавлять vs объединять.
- **Маленькое/большое «я»** — unit vs Cosmic.

## Mental Models

- «Оценивай равновесие по трём сферам: физическая, психическая, духовная — йога нужна во всех».
- «Различай add (yuj) и unify (yuiṋj): духовная йога — объединение, не сложение».
- «Помни два "я": имя меняется, большое "я" едино».

## Anti-patterns

- **Йога только духовная**: «существование станет несбалансированным».
- **Йога как упражнение**: «нет, йога — объединение».
- **Путать karma (изменение места) со случайным действием**: karma = смена позиции.

## Worked Example

*Сахар и вода.* Два плюс два манго = четыре (add: четыре отдельных манго). Сахар в воде — унификация: отдельного сахара больше нет. В духовной йоге (`yuiṋj`) единичное сознание становится одним с Supreme — «маленький A или девочка B станет Parama Puruśa».

## Key Takeaways

1. Йога нужна во всех трёх сферах, иначе дисбаланс.
2. Физическая: единство капли с океаном; психическая: отвод пропенсити к Сущему.
3. Karma = изменение места; Jiñána = субъективизация объективности.
4. Духовная йога — `yuiṋj` (объединение), не `yuj` (сложение).
5. Два «я»: теряешь имя маленького, получаешь большое.
6. Йога — панацея всех недугов; дхарма человека — расширение, единство, благородство, покой.
