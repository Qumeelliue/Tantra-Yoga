# Chapter 19: The Causal Matrix

*Дискурс от 21 сентября 1979, Kingston.*

## Core Idea

У творения три фактора: творец, творческая сила, материал. Causal Matrix — не Operative Principle, а Supreme Consciousness, желающий создать. Творение — ответ на «мучения одиночества»; все — члены Universal Family; никто не может быть «вне Его ума».

## Frameworks Introduced

- **Три фактора творения**: (1) творец; (2) творческая сила; (3) материал. Для вселенной: Supreme Creator (Parama Puruśa) + Operative Principle (Parama Prakrti) + материал. **Causal Matrix — Supreme Consciousness, желающий создать**, не Operative Principle.
- **Зачем творение**: учёные и люди действия не ответили за 4000 лет; преданные отвечают: «Мой Отец был один; спасаясь от страданий монотонности, Он создал». Материал — из Его ума (всё внутри Него; ничего вовне).
- **Никто не незначителен**: все — психические создания, любящие дети Loving Progenitor; никто не должен быть подавлен/угнетён/репрессирован.
- **Universal Family / Fraternity**: все создания — члены одной семьи; никто не может выйти за периметр Его ума; Он не может сказать «уходи» (куда? вне Его — ничего; «либо смени имя, либо отмени приказ»). Грешники — «непослушные дети», которых Он хочет исправить, не изгнать.
- **Творение = игра**: после освобождения от монотонности Он играет вечную игру с детьми — это мир. Нет меланхолии, одиночества, беспомощности, комплексов.
- **Мышление и ectoplasm**: мысль — часть эктоплазмы, принимающая форму; квинквелементальная вселенная — проекция Cosmic ectoplasm; в результате внутреннего/внешнего столкновения и сцепления создаются энергия, свет, психическая структура; всё в итоге сливается в нуклеус, из которого вышло.
- **Финальный desideratum**: все живые и неживые из одного источника, живут в одном эктоплазмическом поле; конечная цель — Supreme Home.

## Key Concepts

- **Causal Matrix** — Supreme Consciousness, желающий создать.
- **Operative Principle (Parama Prakrti)** — творческая сила/механика.
- **Monotony** — монотонность как причина творения.
- **Universal Fraternity / Family** — универсальное братство.
- **Ectoplasmic stuff** — эктоплазмическая сущность мышления.
- **Supreme Home** — финальная цель.

## Mental Models

- «Различай Causal Matrix (сознание-желание) и Operative Principle (механику исполнения)».
- «Думай о творении как о противодействии монотонности — игра, не наказание».
- «Невозможность изгнания: если Он бесконечен — вне Его нет места; грешник тоже Его ребёнок».

## Anti-patterns

- **Меланхолия/одиночество**: «не страдай психологией меланхолии — ты в Его уме».
- **Комплексы (inferiority/superiority)**: исключены, когда знаешь общее происхождение.
- **Мысль «вне Его»**: невозможно — всё внутри Его ума.

## Worked Example

*Дерзкий ребёнок.* Если Сущий скажет грешнику «уходи, наглец», тот ответит: «Отец, Ты бесконечен, всё внутри Тебя; если есть что-то вне — Ты не бесконечен. Либо отмени приказ, либо смени имя». Сущий не может изгнать никого — грешники Его «непослушные дети», которых Он хочет исправить через их поведение.

## Key Takeaways

1. Три фактора творения: творец, творческая сила, материал.
2. Causal Matrix — Supreme Consciousness, желающий создать.
3. Причина творения — спасение от монотонности.
4. Все — Universal Family; никто не вне Его ума.
5. Нельзя изгнать: вне бесконечного нет места.
6. Финальная цель всех — Supreme Home; никаких комплексов.
