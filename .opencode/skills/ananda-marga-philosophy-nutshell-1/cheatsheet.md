# Читшит — правила решений по Саркару (Nutshell 1)

## Счастье и цель

| Ситуация | Правило |
|---|---|
| Понять, утолит ли цель | Если цель конечна — разожжёт аппетит; бесконечное насыщает только Бесконечное |
| Найти dharma человека/системы | Dharma = природа. Огонь жжёт; человек ищет Космическое Сущее |
| Человек ведёт себя «хуже животного» | Не использует ясно-отражённое сознание — теряет право называться человеком |
| Выбрать ориентир счастья | Реализация Бесконечного, а не накопление конечного |

## Сознание и восприятие

| Ситуация | Правило |
|---|---|
| Почему «очевидное» не видят | Видит ум (citta принимает форму объекта), не орган; занятый ум = нет восприятия |
| Разобрать, кто действует | Свидетель (átman) наблюдает; деятель («Я»/ahaḿtattva) действует и пожинает результат |
| Оценить, реален ли объект | Реальность = отражение на ментальной плите через tanmátras; грубость = число tanmátras |

## Космология (быстрая справка)

| Ситуация | Правило |
|---|---|
| Puruśa + Prakrti | Неразделимы, как две стороны листа; оба беспричинны |
| Nirguńa vs Saguńa | Nirguńa — Prakrti не связывает (высшее); Saguńa — связывает, творит (= Bhagaván) |
| Почему ум не познает Brahma | Измеритель должен быть тоньше измеряемого; ум тоньше материи, но без «измерительных» качеств |
| Статус мира | Мыслеволна Saguńa Brahma: не Satya, не ложь — относительная истина |

## Карма и жизнь

| Ситуация | Правило |
|---|---|
| Действие совершено | Будет karmaphala равной интенсивности (психическое или физическое) |
| Смерть | Отделение ума от тела; мозг — база ума, без него ум не работает |
| Нерастраченные реакции | Становятся saḿskára → перерождение в подходящем теле (поле подбирает Prakrti) |
| Рай/ад после смерти | Нет: без мозга ум не переживает удовольствие/боль; «рай/ад» — опыт здесь |
| Призраки | Противоречат перерождению; логично только одно — перерождение |
| Замещение ответственности | Невозможно: «кто посеет, тот пожнёт» |

## Космогония (saincara/pratisaincara)

| Ситуация | Правило |
|---|---|
| Творение | Центробежно: Puruśottama → Mahattattva → Ahaḿtattva → citta → 5 факторов (тонкое→грубое) |
| Точка выхода сил | Вершина «треугольника сил» Prakrti (Shambhú); центр — Puruśottama |
| Энергия/жизнь | clash даёт práńa; ядро + благоприятная среда → práńáh (жизнь) |
| Распад структуры | Jad́asphot́a (взрыв) → распад только до пяти факторов; «negative saincara» |
| Возврат к тонкому | Pratisaincara: грубое→тонкое, psychic dilation; человек может выбрать путь вверх или вниз |
| Конечная цель | Yoga/mukti: слияние unit-ума с Puruśottama («единство в объективности → единство в субъективности») |

## Быстрые сигналы («tells»)

- Погоня за «ещё одной ступенью» статуса/денег → бесконечная жажда, не насыщение.
- «У нас открыты глаза, но они не видят» → ум занят/гипнотизирован, восприятия нет.
- Обещание награды «после смерти/в другом месте» → проверь, есть ли там работающая среда (ум/мозг).
- Система без ядра и без среды → распад (jad́asphot́a), а не устойчивость.
- Человек «выбирает грубое» → negative pratisaincara; среда должна склонять к тонкому.
