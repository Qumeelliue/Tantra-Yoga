# Глоссарий — Ananda Marga Philosophy in a Nutshell Part 1

**Átman / единичное сознание (unit consciousness)** — свидетель существования ума; не действует, только наблюдает (Ch 1, 4, 5, 7).

**Ádhára** — опора/носитель: тело (мозг) для отражения сознания и работы ума (Ch 3, 4, 5).

**Bhagaván** — Saguńa Brahma («обладающий bhaga»: могуществом, благожелательностью, светом); не высшее состояние (Ch 2, 5).

**Buddhitattva / mahattattva** — «Я существую», чувство знания существования; порождается sattvaguńa (Ch 1, 4, 5).

**Bhúmácaetanya / Paramátman / Brahma** — совокупность всех единичных сознаний; Космическое Сознание (Ch 1, 2, 3).

**Dhyāna** — см. медитативную практику в Part 3 (Ch 3 Q&A); здесь — контекст «Я существую».

**Guńa** — «связывающий принцип» Prakrti: sattva (sentient), raja (mutative), tamah (static) (Ch 1, 2, 3, 6).

**Jad́a** — инертное/грубое; Puruśa при максимальном влиянии Prakrti (Ch 3, 6).

**Jad́asphot́a** — взрыв мёртвых/умирающих тел; распад на пять факторов; «negative saincara» (Ch 6).

**Kalpaná** — воображение/мыслеволна; citta принимает форму объектов мысли (Ch 3).

**Káyii** — ранние водоросли/мхи; самое примитивное отражение сознания (Ch 3).

**Karmaphala** — результат/реакция действия (восстановление формы ума), переживаемая как удовольствие/боль (Ch 5).

**Kśititattva (kśiti)** — твёрдый фактор; предел огрубления (Ch 3, 6).

**Muktapuruśa** — достигший Nirguńa; добровольно принявший срок влияния Prakrti ради освобождения других (Ch 3).

**Mahattattva** — «Я существую» (первая ступень квалификации сознания) (Ch 1, 6).

**Mánuśa** — человек как стадия развитого эго и свободы выбора направления (Ch 7).

**Nirguńa Brahma / Brahmasvarúpa** — высшее состояние: Prakrti не квалифицирует Puruśa (Ch 2, 3).

**Negative pratisaincara** — движение ума вниз, к грубому (дерево, протозоа, камень) (Ch 7).

**Paramátman** — сумма всех единичных сознаний (Ch 1).

**Prakrti** — оперативный принцип Puruśa; «уникальная сила», квалифицирует Сознание; неотделима от Puruśa (Ch 1, 2, 6).

**Práńa** — энергия (clash внутренних/внешних сил в структуре) (Ch 6).

**Práńáh** — витальная энергия; коллектив 10 вайю; «слепая» сила (Ch 6, 7).

**Pratisaincara** — синтетическое, центростремительное движение (грубое→тонкое) к Puruśottama (Ch 6, 7).

**Prajápati / Hirańyagarbha** — связанная / освобождённая (muktapuruśa) стадии Saguńa Brahma (Ch 3).

**Pretatman** — «душа-призрак»; отрицается логикой перерождения (Ch 5).

**Psychic dilation** — расширение ума тремя силами (физическая/психическая/духовная) (Ch 7).

**Puruśa / Citishakti** — чистое Сознание; материал творения (Ch 1, 2, 3, 6).

**Puruśottama / Shambhú** — Нуклеус-сознание / Puruśa в вершине треугольника сил (Ch 6, 7).

**Saguńa Brahma** — квалифицированное Сознание; источник творения; = Bhagaván (Ch 2, 3).

**Saincara** — центробежное движение тонкое→грубое от Нуклеуса (Ch 6, 7).

**Saḿskára** — реакция в потенциальности, уходящая с átman после смерти (Ch 5).

**Sádhaná** — настойчивое усилие освободиться от Prakrti; требует осознания уз (Ch 3, 7).

**Sattvaguńa / rajoguńa / tamoguńa** — sentient/mutative/static принципы Prakrti (Ch 1, 2, 3, 6).

**Satyadraśt́a rshi** — провидец, видящий истину за «шоу» мира (Ch 3).

**Tanmátra** — микроскопическая фракция волны объекта, получаемая индриями (Ch 1, 3).

**Unit consciousness** — см. átman (Ch 1).

**Vidyámáyá / Avidyámáyá** — сила знания (интроверсия, к Puruśottama) / неведения (экстроверсия, огрубление) (Ch 7).

**Yoga** — слияние unit-ума с Puruśottama (Ch 7).
