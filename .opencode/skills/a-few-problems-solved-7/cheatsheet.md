# Читшит — A Few Problems Solved Part 7

## Общество и власть

| Ситуация | Правило |
|---|---|
| Кто сейчас у власти | Какой ресурс незаменим: сила → интеллект → деньги → число работников |
| Сменить власть «по-старому» | Смена класса не решает — меняется эксплуататор, не система |
| Построить жизнеспособное общество | Единство + безопасность + мир (все три) |
| Дать людям общий идеал | Только вечный (Brahma/общее благо); временный — распадётся |
| Наказать провинившегося | Корректирующе: временное исключение + привести 10 человек; без вычёркивания |
| Женщины/расы/касты | Нет несправедливости по полу/расе/касте; равные обязанности |

## Познание и ум

| Ситуация | Правило |
|---|---|
| Как человек узнаёт | Субъективизация объективности: внешнее → внутреннее «я» |
| Три камеры ума | Объективная (форма объекта) + субъективная (свидетель) + Верховный Субъект (присутствие) |
| Человек видит «призраков» | Объективация без свидетеля; нужна встряска/равновесие |
| Психический сбой | Болезнь ума ≠ болезнь мозга; фобия (страх)/мания (слабость)/меланхолия/комплексы |
| Комплекс неполноценности | Взращивай уверенность, но не скатывайся в превосходство |
| Запомнить материал | Читай вслух + ритм + дробление («ass-ass-i-nation») + пустой ум |

## Духовное и познание

| Ситуация | Правило |
|---|---|
| Два культа знания | Jinána márga (вопросы «что/откуда») — путь развития; prapatti (пассивная сдача) — дефект |
| Как приблизиться к Верховному Субъекту | Идеация «Он наблюдает»; не разглядывание и не лесть |
| Знание о прошлом/настоящем | Сравнение двух вибраций = узнавание; память = воспроизведение |

## Ренессанс и экономика

| Ситуация | Правило |
|---|---|
| Аудит пробуждения системы | Физический (наука/равенство/минимумы) → психический (догмы/угнетение) → духовный (конверсия) |
| Право живых существ | Нео-гуманизм: Вселенная — не патримоний людей; оружие против «животные нам на еду» |
| Строить экономику | Четыре части: people (минимумы) → psycho → commercial → general |
| Гарантировать минимумы | Покупательная способность как конституционное право; иначе люди без юридической силы |
| Частные предприятия | Ограничивай до монополии; дальше — кооператив |

## Быстрые сигналы

- Доминирует класс «незаменимого ресурса» → ищи, кого эксплуатируют.
- «Война объединила страну» — временный идеал, не решение.
- Наказание, вычёркивающее человека навсегда, — антипаттерн (распад общества).
- Ум «становится» объектом — норма; без свидетеля — иллюзия.
- Повторный страх-образ — фобия; повтор из слабости — мания; «никто не любит» — меланхолия.
- Экономика без гарантии минимумов — неполна: пропущена people's economy.
- Проповедь пассивной сдачи («всё в руках Бога») — тормоз развития (prapatti márga).
