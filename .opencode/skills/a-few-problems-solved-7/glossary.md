# Глоссарий — A Few Problems Solved Part 7

**Анубхава (anubhava / anubhúti)** — «становление после»; восприятие, воспроизведённое в уме позже (Ch 4, 6).

**Арта (artha)** — то, что даёт временное освобождение от мирских желаний; физическое средство (Ch 2).

**Атьянтика нивритти (atyantikii nivrtti)** — постоянное прекращение страдания; только через Paramártha (Ch 2).

**Бескастовое общество (casteless society)** — идентичность jiiva mátra, отсутствие группировок по привилегиям (Ch 2).

**Брахман / випра (bráhmańa / vipra)** — класс интеллекта/знания (Ch 1).

**Ваэшья (vaeshya)** — класс торговли/денег (Ch 1).

**Верховный Субъект (Supreme Subjectivity)** — присутствие-катализатор за всем познанием; не субъект и не объект (Ch 7).

**Гарана́ (gharáńá)** — школа/стиль музыки (Ch 6).

**Гуру бха́й / джа́та бха́й (guru bhái / játa bhái)** — единоверцы-ученики / родичи по касте (Ch 2).

**Джняна ма́рга (jinána márga)** — культ знания (шайва): «что это? откуда?» до Supreme Point (Ch 3).

**Джняна (jiṋána)** — знание; от корня jiṋá — знать (Ch 3).

**Дхру́ва смрити (dhruvásmrti)** — постоянная, непоколебимая память; предпосылка сама́дхи (Ch 4).

**Дхья́на / Иишвара прани́дха́на (dhyána / Iishvara prańidhána)** — медитация; практика с мыслью о Верховном (Ch 5, 7).

**Джиива ма́тра (jiiva mátra)** — «все живые существа»; отождествление человека с любым живым существом (Ch 1, 2).

**Достоинство труда** — работа уборщика почётнее зависимости от других (Ch 1, 2).

**Идеация (ideation)** — мысль о Верховном Субъекте, способная объективироваться (Ch 7).

**Индии (indriya)** — орган чувств (Ch 4).

**Капитальная казнь (capital punishment)** — вычёркивание из общества (остракизм) или смерть; запрещена (Ch 2).

**Классы (varna)** — брахманы/випры, кшатрии, ваэшьи, шудры (Ch 1).

**Коллективная психология (collective psychology)** — движущая сила истории (Ch 8).

**Кшатрий (kśatriya)** — класс силы (Ch 1).

**Мания (mania)** — повторный образ из слабости, не страха (touch-mania) (Ch 5).

**Меланхолия (melancholia)** — «меня никто не любит»; вплоть до суицида (Ch 5).

**Милита́ сн́а́на / дхармачакра (milita snána / dharmacakra)** — коллективное омовение; коллективная медитация (Ch 2).

**Нео-гуманизм (Neohumanism)** — право на жизнь всех живых существ (Ch 9).

**Нивритти (nivrtti)** — прекращение страдания (Ch 2).

**Объективный ум (objectivated mind)** — почти весь эктоплазм; принимает форму объекта (Ch 5).

**Парама́ртха (Paramártha)** — постоянное освобождение от страдания через садхану (Ch 2).

**Прапатти ма́рга (prapatti márga)** — культ пассивной сдачи воле Космоса; дефект (Ch 3).

**Пратисаинчара (pratisaiṋcara)** — интроверсия, движение от материи к сознанию; отрицательная — деволюция (Ch 9, 10).

**Психо-экономика (psycho-economy)** — экономика, развивающая психические pabula (Ch 11).

**Ра́кша́си видья́ (rákśasii vidyá)** — применение эктоплазмической силы объективным умом к внешним событиям (Ch 5).

**Ренессанс (renaissance)** — пробуждение из «кимерской дремоты» во всех слоях (Ch 9).

**Садхана́ (sádhaná)** — систематическая духовная практика (Ch 2).

**Са́ма́йики нивритти (sámayikii nivrtti)** — временное прекращение страдания (Ch 2).

**Свабха́ва (svabháva)** — естественная склонность ума становиться как его объект (Ch 2).

**Смрити (smrti)** — память: точное воспроизведение ранее воспринятого (Ch 4, 6).

**Субъективизация (subjectivization)** — взятие внешнего объекта внутрь психического «я» (Ch 3).

**Субъективный ум (subjectivated mind)** — свидетель, знающее «я» (Ch 5, 7).

**Суеверия (superstition)** — социальные/психические/духовные заблуждения, нарушающие мир (Ch 2).

**Свара ша́стра (svara shástra)** — наука о музыкальных нотах (Sadáshiva) (Ch 7).

**Три фундамента общества** — единство, социальная безопасность, мир (Ch 2).

**Фобия (phobia)** — повторный образ из страха (hydrophobia) (Ch 5).

**Шудра (shúdra)** — класс работников (Ch 1).

**Эктоплазм (ectoplasm)** — психический субстрат, из которого формируются ментальные объекты (Ch 5).

**Четырёхмерная экономика (quadri-dimensional economy)** — people's / psycho- / commercial / general economy (Ch 11).
