# Читшит — решения по Саркару (Discourses on Prout)

## Владение и распределение

| Ситуация | Правило |
|---|---|
| Кто владеет ресурсом | Рудиментарный фактор никто не создал → владелец Космическая Сущность |
| Лимит накопления | По совокупным ресурсам общества, не по аппетиту индивида |
| Социализация земли | Компенсация землевладельцам — нет (принцип); пособия уязвимым; работа безработным |
| Порядок реализации | Духовно → психически → силой (в интересах общества) |

## Идеология и власть

| Ситуация | Правило |
|---|---|
| Оценить идеологию | Мерь объём «проецируемой массы», а не ярлык; меньше 360° — изм |
| Борьба с капитализмом | С измом, не с людьми; «лечи» уводом жажды |
| Коррупция | Идеал первый, идеал второй, идеал всегда — критика без идеала помогает противнику |
| Демократия | Мобократия → фулократия; коррупция неустранима |
| Лучшая форма | Благодетельная коллегиальная диктатура садвипр; единоличная — отвергнута |
| Строение власти | Селектро-элекционное: политика выборная, исполнители назначенные |
| Приход к власти | 3 фазы пропаганды → интеллектуальная или физическая революция |
| Нация устойчива | Восьмой фактор — общие идеалы на Абсолюте (космическое владение) |

## Экономика и общество

| Ситуация | Правило |
|---|---|
| Распределить отрасли | Малые — частнику; средние — кооперативу (броня, снимать постепенно); крупные — ближайшему правительству |
| Автоматизация | В экономике потребления — сокращение часов, не рабочих мест |
| Мотивировать работников | Сдельная + премия + право участия в управлении |
| Децентрализация | Самодостаточные единицы; ареал растёт с транспортом |
| Контроль рождаемости | В коллективной экономике не нужен; рост населения — благо |
| Проституция/приданое | Лечи независимостью женщин + межкастовые/международные браки |
| Гарантированный минимум | Пища/одежда/жильё/медицина/образование + покупательная способность |
| Разрыв минимум↔удобства | Минимизировать постоянно; нуля не будет (разнообразие — закон природы) |
| Свобода | Физическую — «резко и безжалостно» ради коллектива; мысль и дух — свободны |
| Добро/зло | Pápa = против коллектива, puńya = помощь коллективу; мерило — шлока Вьясы |

## Быстрые сигналы («tells»)

- Заводы растут там, где рынок и дешёвый труд — капиталистическая логика.
- Внедряешь машины и увольняешь людей — ты в прибыльной рамке, не в коллективной.
