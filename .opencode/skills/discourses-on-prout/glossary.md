# Глоссарий — Discourses on Prout

**Авидья (Avidyá)** — экстроверсиальная сила; борьба Vidyá и Avidyá — основа творения (Ch 4).

**Ахимса ≠ неприменение силы** — ahiḿsá = «не вредить»; non-violence = «не применять силу» (Ch 1).

**Брахма (Brahma)** — Верховная Сущность, владелец вселенной; «ничто моё — всё общее достояние» (Ch 5).

**Брахмавидья (Brahmavidyá)** — интуиционал-наука, единственная философия на Абсолюте (Ch 6).

**Благодетельная диктатура садвипр** — лучшая форма правления: коллегиальный совет, сменяемый председатель; единоличная отвергнута (Ch 5).

**Вишва-бхаша (vishva bháśá)** — вселенский язык; сегодня кандидат — английский (Ch 2).

**Гарантированный минимум** — минимальные потребности (пища, одежда, жильё, медицина, образование), обеспеченные покупательной способностью (Ch 6).

**Да́ябха́га (Dáyabhága)** — наследственное право, где наследие зависит от главы семьи (Ch 1).

**Заминдар (zamindar)** — землевладелец; при социализации компенсация не полагается, лишь пособия (Ch 1).

**Измы** — идеологии с «углом группового интереса»; фактор войн; панацея — универсализм (Ch 1, Ch 2).

**Key industries** — ключевые отрасли; владеет «ближайшее правительство», не центр (Ch 3).

**Космическое наследие** — рудиментарные факторы принадлежат Космической Сущности; люди — пользователи общего достояния (Ch 1).

**Мобократия / фулократия** — правление толпы / глупцов; суть демократии по Саркару (Ch 5).

**Pápa / puńya** — против коллективного интереса / помощь коллективному прогрессу; критерий — шлока Вьясы (Ch 6).

**Парама Пуруша (Parama Puruśa)** — Космическое Сознание, «Высший Отец» вселенской семьи (Ch 1).

**Покупательная способность** — решающий фактор физического благополучия (Ch 6).

**Политически образованная группа** — стражи коррупции выборов; ядро — студенты (Ch 4).

**Рационализация** — замена старых машин на новые; в коллективной экономике сокращает часы, а не рабочие места (Ch 3).

**Садвипра (sadvipra)** — духовный революционер по Yama и Niyama; носитель будущей власти (Ch 4, Ch 5).

**Садхана (sádhaná)** — устойчивое духовное усилие; dharma sádhaná — духовный образ жизни (Ch 1, Ch 6).

**Самскрити / кршти (saḿskrti / krśt́i)** — «культура» в добром / общем смысле (Ch 2).

**Савикалпа-самадхи (savikalpa samádhi)** — квалифицированное космическое поглощение (Ch 1).

**Селектро-элекционная структура** — синтетика (политика) выборная, аналитика (исполнение) — селекционная (Ch 5).

**Специальные удобства** — блага для интеллектуалов; разрыв с минимумом минимизируют, не обнуляют (Ch 6).

**Трёхъярусная экономика** — малые — частнику; средние — кооперативам; крупные — ближайшему правительству (Ch 3).

**Тройственная жажда** — физическая (ненасытна), психическая и духовная (бесконечны) (Ch 1).

**Универсализм** — 360-градусная проекция без угла группового интереса (Ch 1, Ch 2).

**Фиссипарные тенденции** — раскалывающие тенденции; продукт корыстных лиц (Ch 2, Ch 6).

**Яма и Нияма (Yama и Niyama)** — кардинальные принципы морали; основа садвипра-пути (Ch 1, Ch 4).
