# Читшит — правила решений (Subháśita Saḿgraha Part 7)

## Высший вопрос и знание

| Ситуация | Правило |
|---|---|
| «Я знаю Брахму» | Претензия на владение субъектом — неполно; держи «знаю» и «не знаю» вместе |
| Сделать вывод о Брахме | siddhánta неприменим: Брахма вне положительного/отрицательного |
| Достичь бессмертия | Установление в пратибодха-видита (Omni-telepathic Entity) |
| Оценка «пандита» | Книжное знание ≠ знание о Нём; искренность важнее эрудиции |

## Человеческая жизнь и клеши

| Ситуация | Правило |
|---|---|
| Желание расширения | Переключи на бесконечное; конечные ресурсы — собственность человечества |
| Лидерство в борьбе | Садвипра = установлен в yama/niyama + реальная работа |
| Диагностика несвободы | 5 клеш: авидья/асмита/рага/двеша/абхинивеша |
| Гнев/жадность/гордость | Не уничтожай — направь против Авидьи (гнев на статику, жадность к Нему...) |
| Думать об препятствиях | Ошибка: препятствия становятся целью; думай о цели |

## Садхана

| Ситуация | Правило |
|---|---|
| Выбрать «путь» | Путь один (ананда-марга); мнения (мата) о Высшем ценности не имеют |
| Стадии практики | Шакта (борьба) → Вайшнава (поток блаженства) → Шаева (нон-атрибутивность) |
| Контроль чувств | Пратьяхара: йатамана → вйатирека → экендрия → вашикара (только преданным) |
| Работа и авторство | Сдавай оригинальные действия Брахме — реакции ускорятся, но станут короче |
| Справиться с реквизициями | Долг-аналогия: быстрое страдание сейчас лучше 1000 месяцев риска |

## Прогресс и клаш

| Ситуация | Правило |
|---|---|
| Развитие ума | Три фактора: физический клаш + психический клаш + аттракция Великого |
| Только мораль | Не далеко ведёт: «моралист» деградирует в плохой компании |
| Эволюция | Контакт с развитым умом «перескакивает» этапы; выбирай окружение |
| Конец вселенной | Тепловой смерти нет: джадаспхота перераспределяет энергию |
| Ад/рай | Нарака = дегенерация к материи; сварга = движение к Сознанию |

## Энергия и применение

| Ситуация | Правило |
|---|---|
| Природа шакти | Многозначна; энергия = форма в абстрактном; требует дуальности |
| Стадии действия | Вдох/задержка/выдох/пауза; пауза = смерть или новый импульс |
| Реинкарнация | Реактивные потенциалы дрейфуют и переформируются; маха-мритью — выход |
| Воздействие на «сопротивляющихся» | Духовные вибрации → психическая сила → физическое (редко) |
| Гордость знанием | Компенсируй мадху-видьей (космической идеацией поверх дел) |

## Быстрые сигналы («tells»)

- «Все пути ведут к Богу» → смешение мата и патха; путь один (Ch 3).
- Лидер-взяткодатель борется со взятками → не садвипра, риторика (Ch 2).
- «Я прошёл мимо бара на 10 шагов — награжу себя» → абхинивеша (Ch 2).
- «Цивилизованный» лицемер убивает миллионы «чисто» → опаснее «грубого» (Ch 4).
- Преданность «я тебе — ты мне» без мысли о Высшем → коммерция, не преданность (Ch 5).
- «Мой язык/моя страна/моя вера» как конечная цель → микро-эксклюзивность, источник конфликта (Ch 6).
