# Глоссарий — Ananda Marga Karma Sannyása in a Nutshell

**Абхила́ша (abhilása)** — желание; первый вид действия, возникающий в уме под властью Avidyámáyá (Ch 3).

**Авадхана (avadhána)** — внимание/адвертенция: действие ума через сенсорные органы и пра́н́ендрию (Ch 3).

**Анубхава (anubhava)** — первая стадия садханы: очищение тела и ума через а́саны и пра́н́ая́му (Ch 3).

**Аштаунга йога (astáuṋga yoga)** — восьмичленная йога; в трёх стадиях: anubhava → prájiṋa → puruśakhyáti (Ch 3).

**Бхагават-дхарма** — одна для всех людей; четыре ноги: Vistára, Rasa, Sevá, Tadsthiti (Ch 11).

**Бхакти** — преданность; на пути бхакти цель сама по себе; = служение Бхагавану, prema, ánanda, jiivanam (Ch 7).

**Ва́сана́ (vásaná)** — сумма реактивных моментумов всех чувств боли/удовольствия; определяет течение жизни (Ch 3).

**Ва́сана́-бха́нда (vásanábhánda)** — «сосуд желаний»; его заполняют идеацией Сознания и предлагают Парама Пуруше (Ch 3).

**Видехи мана (videhii mana)** — бестелесный ум; не функционирует; лишь несёт bundle of samskaras (Ch 3).

**Вола (прямая/косвенная)** — первичное действие; сердцебиение/сон — косвенная воля; её остановка = mahámrtyu (Ch 3).

**Гуха́ (guhá)** — «пещера»; скрытое чувство «я есмь» в глубине «Я»; причина единства дхармы (Ch 11).

**Два супарна** — ведическая аллюзия: две птицы на дереве — вкушающий джива́тман и свидетель Параматман (Ch 1).

**Дрш́т́а/адр́ш́т́а ведани́йа карма** — реакции той же жизни / из прошлых жизней (судьба) (Ch 3).

**Дхармакшетра** — тело как поле исполнения дхармы (Ch 5, 8).

**Карма-санньяса (karma-sannyása)** — состояние отождествления с неизменным; время/пространство/личность в тактильном отношении с Субъективной Сущностью (Ch 4).

**Карма́шая (karmáshaya)** — «сосуд» самскар; определяет ход жизни (Ch 3).

**Картрттва (kartrttva)** — «я-центрированное» чувство власти над действием; от Avidyámáyá (Ch 9).

**Курукшетра** — мир как поле «делай» (kur + hi); сцена действия (Ch 5, 8).

**Мадхувидья (madhuvidyá)** — «медовое знание»: брать объект удовольствия с космическим чувством, чтобы действие не связывало (Ch 2).

**Мах-а́мртью (mahámrtyu)** — «величественная смерть»: остановка косвенной воли при исчерпании самскар (Ch 3).

**Пара Брахма / Апара Брахма** — невозмутимое исходное состояние / трансформированный в объекты; парабхакти — любовь к Пара (Ch 4).

**Парабхакти (parábhakti)** — интенсивная любовь к Пара Брахме; опора карма-санньясы (Ch 4).

**Праджня (prájiṋa)** — вторая стадия садханы: осознание «я не есть тело»; sentient = prasaḿkhyána (Ch 3).

**Пранипа́та (prańipáta)** — полное подчинение Параматману; осуществляется через парабхакти (Ch 4).

**Пратьяяму́лака карма** — оригинальное действие (свободная воля) (Ch 3).

**Пу́нья / па́па** — добродетель/грех; битва между ними идёт внутри каждого (Ch 5).

**Пуруша-кхья́ти (puruśakhyáti)** — идеация на Парама Пурушу; слияние ва́сана́-бха́нды (Ch 3).

**Рохит** — учёный-бездельник из Веды; антипример (Ch 6, 8).

**Самскараму́лака карма** — реакция на оригинальное действие; механическое исполнение (Ch 3).

**Санджая (saiṋjaya)** — совесть/viveka; «спрашивающий» ум (Ch 5).

**Санньяса (sannyása)** — sat + nyása: отождествление с неизменным; «преданность истине» (Ch 1, 4).

**Сат/Сатья** — неизменное; вне времени/места/личности (Ch 1).

**Свабха́ва (svabháva)** — «природа» = стиль операции Пракрати (Ch 9).

**Сваджа́ти́я/виджа́ти́я/свагата** — однородные/разнородные/внутренние различия относительных объектов (Ch 1).

**Сямьяк карма́нта (samyak karmánta)** — «совершенное завершение»: безупречное доведение дела до конца (Ch 10).

**Са́мкальпа (saḿkalpa)** — решимость; сильнее желания; из са́мкальпы Космического Ума возникла вселенная (Ch 3).

**Са́дхана** — усилие к Парамартхе (полному устранению мирских страданий) (Ch 1).

**Свабха́ва → операционная система** — Пракрати действует через созданную Парама Пурушей систему; Он бдит над ней (Ch 9).

**Шамбху́лин̭га (Shambhúliuṋga)** — философский термин для Макрокосмической Воли (Ch 3).

**Шукла/крш́н́а/шуклакрш́н́а/ашуклакрш́н́а карма** — приятная/болезненная/смешанная/«ни-та-ни-другая» карма (только самадхи) (Ch 3).

**Юга (Kali/Dvápara/Tretá/Satya)** — состояния активности человека, не исторические эпохи (Ch 6, 8).

**Krti** — физическое действие через моторные органы (Ch 3).
