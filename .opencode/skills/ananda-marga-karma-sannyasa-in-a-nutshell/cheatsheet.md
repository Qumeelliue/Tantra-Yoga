# Читшит — правила решений по Саркару (Karma Sannyása in a Nutshell)

## Практика и цель

| Ситуация | Правило |
|---|---|
| Что такое садхана | Усилие к Парамартхе (устранению страданий); садхана дома/в миру |
| Атман и Параматман | Различаются только самскарами; устрани их — станешь Им |
| Хочешь не создавать оков | Мадхувидья: бери объект с космическим чувством («проявление Брахмы») |
| Поклоняться | Идолы отвергнуты: всепроникающий не может быть конечным объектом |
| Ум | Одноканален: не думает о двух объектах одновременно; выбери объект |
| Достижение цели | Shreya ведёт; preya используй так, чтобы не связывал |

## Действие и карма

| Ситуация | Правило |
|---|---|
| Что такое действие | Относительное изменение положения объекта |
| Первопричина действия | Воля (прямая/косвенная); ум — двигатель, энергия — слепая сила |
| Виды кармы | Pratyayamúlaka (оригинальная) / sámskáramúlaka (реакция) |
| Желание | Ва́сана́ определяет течение жизни; извлечение из неё = садхана |
| Реакции в этой жизни | Drśt́a vedaníya karma; из прошлых жизней — adŕśt́a (судьба) |
| Не-связывающая карма | Ashuklakŕśna — только садхана/самадхи |
| Мысли | Создают самскары так же, как действия |

## Освобождение и отношение

| Ситуация | Правило |
|---|---|
| Освободиться от оков | Три процесса вместе: отказ от плодов, отказ от тщеславия деятеля, предание действий Высшему |
| Чувство «я делаю» (kartrttva) | От Avidyámáyá; Парама Пуруша его не допускает |
| Кто реально действует | Операционная система Пракрати; «я — машина, Он — машинист» |
| Плоды действий | Предложи Ему; результаты плохих — прими |
| Завершить дело | Samyak karmanta: безупречный финиш, без дефекта |
| Не могу всё один | Кооперация: «или сам, или с помощью, но добыть воду» |

## Конфликт и дхарма

| Ситуация | Правило |
|---|---|
| Где идёт битва добра/зла | Внутри каждого: тело (дхармакшетра) + мир (курукшетра) |
| Ум слеп | Нужна совесть/Санджая, чтобы видеть битву |
| Дхарма | Одна для всех; различий быть не может |
| Четыре ноги дхармы | Vistára (цель) → Rasa (поток) → Sevá (служение) → Tadsthiti (установление) |
| Служение | Односторонне: «дать и не взять»; служение созданиям = служение Парама Пуруше |
| Юги | Состояния активности: спит (Kali) → проснулся (Dvápara) → встал (Tretá) → движется (Satya) |

## Быстрые сигналы («tells»)

- «Начну практику в уединении» — Avidyámáyá пойдёт с тобой; дело в направлении ума, не в месте (Ch 1).
- Безделье «по логике» — Рохит-синдром; «удача спящего спит» (Ch 6, 8).
- Демонстрация «величия»/демонстрация власти — разворот к Апара Брахме, развращение (Ch 4).
- «Я всё делаю сам» — игнорирование кооперации; колодец не выкопать одному (Ch 10).
- Гордость от пожертвования — kartrttva/тщеславие деятеля; «Брахма служит только Брахме» (Ch 9).
- «Нет времени на духовное» — ум одноканален и заполнен объектами; освободи канал (Ch 1).
