# Читшит — правила решений по Саркару (Subháśita Saḿgraha 13)

## Цель и путь

| Ситуация | Правило |
|---|---|
| Определить стадию деятельности | 4 стадии: Káma (физика) → Artha (психика) → Dharma (психо-дух) → Mokśa (дух) |
| Цель конечна (объект, деньги, психический пабулум) | Не цель: конечное не насыщает; цель обязана быть субъективной (духовной) |
| Распределять таланты/ресурсы | Объективная корректировка: каждый по природе (руки→молоток, ноги→велосипед, математик→математика) |
| Выбрать путь достижения | Карма и джнана ненадёжны (ветка деградации); бхакти (преданность/сдача) надёжен |
| «Йога = подавление мыслей» | Отвергни: нет объединения; йога = saḿyoga (объединение единичного и Космического Я) |
| «Йога = безмыслие» | Отвергни: сон/бессознательность; движение — природа ума |

## «Я» и desideratum

| Ситуация | Правило |
|---|---|
| Проследить «Я» | Глаз → мозг → doer «Я» → «я существую» → «я знаю» → Верховное «Я» |
| Цель жизни | Desideratum в единственном числе: единая Верховная Сущность (G-O-D) |
| Мотив преданности | Фаза 1: «люблю, потому что получаю удовольствие»; фаза 2: «люблю, чтобы Ты получал благо» |
| Удержание от деградации | Сознание: «Он видит всё, что я думаю» |

## Parama Puruśa

| Ситуация | Правило |
|---|---|
| «Бог велик» | brhat = неизмеримо велик + делает великими; измеримое «великое» (Гималаи) — не brhat |
| Природа Бога | Supreme Subjectivity + Supreme Positivity; Krśńa = притяжение; Shiva = баланс |
| «Почему не ненавидит?» | Ненависть = отталкивание; Он — All-Attractive, не может ненавидеть |
| Найти убежище | Вложенные системы (атом→ядро→город→…→солнечная система→Он); верхняя точка — Supreme Nucleus |

## Тантра и практика

| Ситуация | Правило |
|---|---|
| Что такое тантра | tan (расширять) + tra (освободитель): наука освобождения через расширение |
| Молитва как главная практика | Отвергни: `prárthanárcaná mátraeva bhramamúlam` — вводит в заблуждение; нужна садхана |
| На что направлена идеация | «Как думаешь — таким станешь»: ум станет формой своего объекта (деньги → сейф ростовщика) |
| Джнани/карми/бхакта | Все — тантрики (расширяют ум); бхакта эффективнее — правильно тратит время |
| Роль киртаны | Для преданного незаменима («рыба без воды»); даёт блаженство, недоступное другим путям |
| Звуки и цвета пропенсити | 50 главных, 1000 вторичных; у каждой — вибрация и цвет; цвета гун: белый/жёлтый/чёрный |

## Быстрые сигналы («tells»)

- Видишь цель «объект» (деньги/статус) — это не terminus, а станция; ищи субъективную цель.
- «Сделай ум пустым» как метод — вероятно, неправильное определение (сон ≠ йога).
- Практика без расширения (замкнутая, ритуальная) — не тантра.
- Человек знает много сортов «манго», но не ест плод — джнани-ловушка (трата времени).
- Система обещает «укрытие», но цепочка заканчивается раньше Верховного — безопасность неполна.
