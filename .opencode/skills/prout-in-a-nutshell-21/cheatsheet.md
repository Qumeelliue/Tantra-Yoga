# Читшит — правила решений по Саркару (Prout 21)

## Единство и религия

| Ситуация | Правило |
|---|---|
| Объединить людей | Поощряй только общие точки; различия не разжигать и не навязывать единообразия |
| Раздор на почве языка/религии | Не спорь о различиях — запусти кампанию против эксплуатации |
| Религия vs dharma | Религия разделяет; dharma (природа) едина — объединяй вокруг dharma |
| Фанатик | Усиливай логическую волну; сила усилит реакцию |

## Революция и социальный цикл

| Ситуация | Правило |
|---|---|
| Это революция? | Меняет ли коллективную психологию? Нет — дворцовая смена |
| Кто революционеры | vikśubdha shudra; shudra сами не могут |
| Готовность к изменениям | 6 требований: эксплуатация, организация, философия, кадры, руководство, стратегия |
| Какой сентимент | Только положительные; отрицательные — самоуничтожительны (Гитлер) |
| Власть сконцентрирована | Раздели: политическая — моралистам, экономическая — местным |

## Экономика (децентрализация)

| Ситуация | Правило |
|---|---|
| Планировать экономику | Начинай снизу (где живут люди) |
| Кто контролирует ресурсы | Местные жители; посторонним запрещено |
| Мотив производства | Потребление, а не прибыль |
| Организация | Кооперативы; частное — только где кооператив невозможен |
| Неместные товары | Убирай с рынка; покупай местное, поднимай качество |
| Экспорт | Только готовое, только избыток, через кооперативы; сырьё — нет |
| Рациональная цена | Себестоимость + не более 15% прибыли (⚠ значение Саркара) |
| Ключевые отрасли (энергия) | Местное правительство, «no profit, no loss» |

## Экономическая демократия

| Ситуация | Правило |
|---|---|
| Какая демократия нужна | Экономическая, а не политическая (лозунг PROUT) |
| Минимум потребностей | Гарантирован всем (пища, одежда, жильё, образование, медпомощь) |
| Покупательная способность | Непрерывно растёт — индикатор искоренения эксплуатации |
| Кто решает экономику | Местные жители |
| Посторонние | Строго запрещены (иначе отток капитала) |
| Оценка развитости | >30–45% в с/х → недоразвитость (⚠ порог Саркара) |

## Здоровье

| Ситуация | Правило |
|---|---|
| Алкоголь | Только как лекарство, по предписанию врача + одобрение второго |
| Ритуал с вином | Заменить кокосовой водой |

## Быстрые сигналы («tells»)

- План «сверху» без местных — централизация, жди провала на местах.
- Экономика меряется только прибылью — эксплуатация неизбежна.
- «Систему сломали, психология не изменилась» — это была не революция.
