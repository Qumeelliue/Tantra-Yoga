# Chapter 4: Decentralized Economy – 1

*Дискурс от 16 марта 1982, Калькутта (Proutist Economics).*

## Core Idea

Централизованная экономика — капиталистическая и коммунистическая — не может искоренить эксплуатацию и навсегда решить проблемы народа. Единственный путь — **децентрализованная экономика**: планирование с самого низкого уровня, где живут люди, на базе социо-экономической единицы. Это гарантирует процветание и путь к психо-духовному прогрессу.

## Frameworks Introduced

- **1-й принцип — местный контроль ресурсов**: ресурсы единицы контролируют местные жители (слившие свои интересы с интересами единицы); отрасли на местном сырье — целиком местные; посторонним вмешиваться запрещено (иначе «плавающее население» и отток богатства).
- **Распределение избытка по заслугам**: сверх минимума — по заслугам (врач — машина, обычный — велосипед); разрыв постоянно сокращается и не растёт — иначе эксплуатация вернётся в обличии привилегий.
- **2-й принцип — производство для потребления, не для прибыли**: прибыль как мотив создаёт конкуренцию за самые прибыльные товары; производство для потребления устраняет неопределённость местной экономики.
- **3-й принцип — кооперативы**: производство и распределение через кооперативы; частная собственность отменяется поэтапно; частное — только где кооператив невозможен. «Кооператив и децентрализация неразделимы».
- **4-й принцип — местная занятость**: местные заняты в местных предприятиях; сами определяют минимум потребностей и политику.
- **5-й принцип — удаление неместных товаров**: неместные товары убираются с местных рынков; покупать местное, даже хуже/дороже, и поднимать его качество.
- **Отрасли**: ключевые (энергия) — у местного правительства «no profit, no loss»; средние — кооперативы; малые/кустарные — владельцы (роскошь). Рациональная цена: ≤15% прибыли.
- **Торговля**: через потребительские кооперативы; нет подоходного налога — налог на производство; экспорт только готовых товаров (не сырья!), только избытка, не ради прибыли; свободная торговля — после самодостаточности.
- **Деньги в обращении**: ценность денег зависит от скорости обращения; местный контур → растущая покупательная способность.

## Key Concepts

- **Socio-economic unit** — социо-экономическая единица (не политическая).
- **Minimum requirements** — минимальные потребности.
- **Floating population** — «плавающее население»: приток извне, отток капитала.
- **Consumers cooperatives** — потребительские кооперативы распределения.

## Mental Models

- «Экономика — замкнутый контур: местные ресурсы → местное производство → местное потребление → деньги остаются внутри».
- «Тест "кто принимает решение?": решение из офиса за тысячи км — централизация и провал».

## Anti-patterns

- **Экономическая централизация** (капиталистическая или коммунистическая) — стратегия накопления капитала.
- **Экспорт сырья** — истощение местного богатства (пример Ориссы).
- **Рост разрыва «минимум vs привилегии»** — возврат эксплуатации.
- **Производство ради прибыли** — игнорирует потребности, усиливает неравенство.

## Worked Example

*Децентрализованная экономика Ориссы.* Вместо экспорта сырья: местные зоны производят готовые товары, строят сталелитейные заводы и ирригацию (+300% производства). Решения — местные жители; ключевые отрасли — no profit/no loss; средние — кооперативы; малые — владельцы; цена — до 15% прибыли.

## Key Takeaways

1. Планирование снизу — единственный способ решить экономические проблемы.
2. Пять принципов: местный контроль, производство для потребления, кооперативы, местная занятость, удаление неместных товаров.
3. Кооперативы успешны только при децентрализации; они неразделимы.
4. Разрыв «минимум vs привилегии» сокращается, но не исчезает; его рост = возврат эксплуатации.
5. Экспорт только готового, только избытка, через кооперативы; сырьё — нет.
