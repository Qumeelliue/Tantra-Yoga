# Читшит — правила решений по Саркару (Subhasita Samgraha 26)

## Работа с фрагментом

| Ситуация | Правило |
|---|---|
| Нужна тема «Mantra» из Part 26 | Файл даёт только шлоку-определение; полнота — в Part 24 Ch10 |
| Часть записи неразборчива | Пометить «неразборчиво»; не выдумывать содержание |
| Ссылка на «текст Part 26» | Не ссылайся: том не издан, текста нет |
| Шлока «Mananát tárayet…» | Мантра = собрание звуков, ведущее к освобождению |

## Быстрые сигналы («tells»)

- «Much of the tape is unintelligible» — редакторская пометка о неразборчивости.
- «as yet unpublished in any language» — статус тома.
- «Efforts to transcribe it are going on» — расшифровка продолжается.
