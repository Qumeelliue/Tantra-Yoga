# Глоссарий — Subháśita Saḿgraha Part 26

**Mantra (мантра)** — собрание звуков, которое при медитации/повторении ведёт к освобождению («Mananát tárayet yastu sah mantrah parikiirttitah»). Определение из фрагментарного дискурса «Mantra».

**Part 26 (том 26)** — «as yet unpublished in any language»: не издан ни на одном языке; содержит один дискурс «Mantra».

**DMC (Dharma Mahácakra)** — крупное духовное собрание; контекст дискурса (10 ноября 1979, Hyderabad).
