# Читшит — правила решений по Саркару (Ánanda Vacanámrtam Part 33)

## Космология и устройство мира

| Ситуация | Правило |
|---|---|
| Понять структуру системы | Ищи ядро (nucleus) и вращающихся; система = cakra |
| Две силы в системе | Притяжение к ядру = vidyá (развитие/единство); отталкивание = avidyá (завеса/распад) |
| Что такое смерть | Изменение; физическая смерть — изменение с разрывом видимой связи |
| Благодать недоступна | Сними «зонтик» тщеславия/ненависти/стыда — благодать лилась всё время |
| Оценить знание | Предмет изменчив → apará (временно); предмет вечен → pará (постоянно) |
| Знание без контроля | Ведёт к «грамотным зверям»; pará должна управлять apará |

## Практика и стадии

| Ситуация | Правило |
|---|---|
| Определить стадию практики | По самоощущению: животное (Pashupati) → герой (Viireshvara) → божество (Mahádeva) |
| Стадии садханы | yatamána (труднейшая) → vyatireka → ekendriya (сила!) → vashiikára (контроль) |
| Получил силу/власть | Нужна способность её контролировать; злоупотребление = откат |
| Сон ≠ пустота | В сне бессознательное работает; vacuity — только nirvikalpa |
| Самадхи vs смерть | Самадхи: три камеры слиты, полон знания; смерть: разрыв параллелизма, без знания |
| Доказать реальность самадхи | «Хвост» блаженства после возвращения из пустоты — доказательство |

## Отношение и поведение

| Ситуация | Правило |
|---|---|
| Хорошая/плохая компания | Satsaunga освобождает; asatsaunga связывает; внутренняя идеация важнее внешней |
| Наказание | Только в социальной сфере, никогда в духовной |
| Экономическое давление | Запрещено (приданое, долги, подарки = превращение в зверя) |
| Занятие по времени | Цвет при чтении: жёлтый/белый — физ.; красный — физ.+мент.; синий/зелёный — мент.+дух.; снежный — дух. |
| Тайное прегрешение | Иллюзия ávarańii («никто не видит») — взгляд ядра пронизывает завесу |
| Прошлое «чёрное» | Реализация доступна любому (Ratnakar, Angulimala); решает Бог |

## Жизнь и энергия

| Ситуация | Правило |
|---|---|
| Жить долго | Славно и в действии (Caraeveti), а не «червём»; баланс труда + духовная практика |
| Физическая перегрузка | Сокращает жизнь; медитация/гигиена продлевают |
| Конверсия энергии | В электрическую = смерть; в магнитную — влияет на тело; в духовную — безопасна |
| Что прочно | Только неизменный Parama Puruśa; всё изменчивое — плохой фундамент |
| Ум не может быть пустым | Занят или хорошим, или плохим; в свободное время — идеация |

## Быстрые сигналы («tells»)

- Видишь «радиус» человека растущим (отдаление от ядра/цели) — доминирует avidyá.
- Кто-то «хвалит в лицо» (stuti) или кланяется с подношениями (árcaná) — возможно, это не bhakti, а тоудизм/ритуал.
- Плохая компания «входит» через подсознание — смотри на содержание smarańa/manana.
- Сила без сдержек (власть, деньги, оккульт) — предвестник падения.
- «Никто не видит» — сигнал активной завесы ávarańii.
- Перегрузка трудом при хороших намерениях — риск сокращения жизни (примеры Vivekananda, Chaitanya).
