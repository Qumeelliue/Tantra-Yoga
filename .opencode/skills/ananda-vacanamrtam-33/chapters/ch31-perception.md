# Chapter 31: Perception

*Дискурс 1969, Ranchi.*

## Core Idea

Ничто в проявленной вселенной не заслуживает абсолютного доверия — абсолютна только одна Entity, nave этой вселенной. Органы — не сами органы: это «ворота», через которые волны входят и активируют ум; ум видит, слышит, нюхает.

## Frameworks Introduced

- **Органы = ворота, не инструменты**: глаза, нос, уши — лишь gateways; волны входят и активируют ум, и ум начинает видеть/слышать и т.д. Если ум активирован иначе — воспринимает без органов. Это возможно «если Он того пожелает» — всё может случиться по Его воле.
- **Восприятие другими органами**: вещи можно видеть кожей, ушами, носом, языком и даже без органа — если Он пожелает.
- **Превращения**: человек → камень, камень → человек, человек → женщина/животное и обратно. Но желательно, чтобы камень стал человеком, а не наоборот. При превращении человека в женщину — постепенное изменение желез; при превращении в животное — человек умрёт (огромная разница между телом человека и животного).
- **Безтелесные умы**: каждый безтелесный ум имеет свет по своим реактивным моментумам; если человек одолжит кусочек эктоплазма — ум получит форму (ментальное тело) по saḿskáras, и можно увидеть, каким этот ум будет после перерождения.
- **Вывод**: «Нет пользы видеть все эти вещи. Старайся видеть только Одного».

## Key Concepts

- **Ворота восприятия** — органы как каналы волн.
- **Эктоплазм** — ментальная субстанция, которую можно одолжить.
- **Безтелесный ум** — ум до/после воплощения со своим светом.

## Mental Models

- «Восприятие — функция ума; органы лишь каналы; главное — активация ума».
- «Любая форма (тело) — позиция, заданная волей; но есть физические ограничения (человек→животное = смерть)».
- «Фокус: видеть только Одного».

## Anti-patterns

- **Абсолютно доверять проявленному** — ничто в нём не абсолютно.
- **Довольствоваться зрелищами** — «нет пользы видеть все эти вещи».

## Worked Example

Человек видит кожей/без органа — по Его воле возможно всё. Он узнаёт: человек → камень возможен, камень → человек желателен, но человек → животное = смерть (разница тел). Безтелесный ум с одолженным эктоплазмом виден в форме по своим saḿskáras. Вывод: «старайся видеть только Одного».

## Key Takeaways

1. Органы — ворота для волн; ум — действующее лицо.
2. Восприятие без органов возможно по Его воле.
3. Превращения форм ограничены физически (человек → животное = смерть).
4. Безтелесные умы видимы через одолженный эктоплазм по saḿskáras.
5. Итог: видеть только Одного.
