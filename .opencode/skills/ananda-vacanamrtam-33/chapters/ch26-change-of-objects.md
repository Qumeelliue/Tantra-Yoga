# Chapter 26: Change of Objects

*Дискурс 1969, Ranchi.*

## Core Idea

Вместе с изменениями длин волн объектов меняются внешние поверхности физических структур: вибрации, звук, форма и цвет. Демонстрация показывает серии превращений объектов по смене длин волн.

## Frameworks Introduced

- **Связь волн и форм**: изменение длины волны объекта → изменение внешней поверхности, вибраций, звука, формы, цвета.
- **Демонстрация**: наблюдающий садхака видит двух живых людей на коленях Ба́ба́; затем по указанию — два каменных осколка, затем последовательно: (1) два огромных гиганта, (2) два свирепых тигра, (3) два человеческих черепа, (4) две обезьяны, (5) два манго (leḿŕá), (6) два батата, (7) два зерна риса, (8) два зерна cúŕá (воздушного риса), (9) две козы, (10) две собаки, (11) два лотоса. Когда наблюдатель присоединился — все три превратились в: (1) трёх годовалых детей, (2) трёхногий стол, (3) стул, (4) экземпляр Subháśita Saḿgraha Part 1.
- **Вывод**: серии изменений происходят из-за изменений длин волн разных сущностей.

## Key Concepts

- **Длина волны** — определяющий фактор формы/восприятия.
- **Leḿŕá** — сорт манго (повторяющийся в демонстрациях).

## Mental Models

- «Восприятие формы управляется длиной волны; смена волны = смена видимого объекта».
- «Объект ≠ его видимая форма: форма — функция волны».

## Anti-patterns

- **Считать форму неотъемлемой** — форма меняется с длиной волны.

## Worked Example

Наблюдатель смотрит: два человека → по смене волн — два камня, затем гиганты, тигры, черепа, обезьяны, манго, батат, зерно, рис, козы, собаки, лотосы. Присоединившись — все трое превращаются в детей, стол, стул, книгу. Всё — игра длин волн.

## Key Takeaways

1. Смена длины волны → смена формы, цвета, звука.
2. Внешний вид объектов полностью волнозависим.
3. Демонстрации показывают силу контроля длин волн.
