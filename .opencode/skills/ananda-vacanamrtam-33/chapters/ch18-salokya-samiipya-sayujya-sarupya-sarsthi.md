# Chapter 18: Sálokya, Sámiipya, Sáyujya, Sárúpya, Sárśt́hi

*Дискурс 1969, Ranchi.*

## Core Idea

Jiiva берёт начало в Shiva и имеет потенциал слиться обратно. Разделяют их bandhanas (путы), представленные в теле чакрами. Пробитие чакр = становление jiiva = Shiva. Каждая чакра даёт особое чувство, цвет, звук и форму.

## Frameworks Introduced

- **Путь чакр с чувствами** (от низа вверх):
  - **Múládhára** (mańipadma у буддистов; «Oṋḿ mańipadme hummm» = точка старта, hummm = борьба садханы): пересечение → **sálokya** («Господь со мной», не один); золотисто-жёлтый; звук сверчка (tick-tick); квадрат.
  - **Svádhiśt́hána**: → **sámiipya** (близость); водянисто-белый; звук páyala (колокольчики танцора); полумесяц.
  - **Mańipura**: → **sáyujya** (близкое прикосновение); красный; сладкая флейта; треугольник.
  - **Anáhata**: → **sárúpya** (одинаковость); синий → зеленоватый; гонг/море; шестиугольник/круг.
  - **Vishuddha**: → **sárśt́hi** («Я есть Он»); смесь цветов; звуки колокола/флейты/моря переходят в oṋm, всё чётче.
  - **Ájiṋá (trikut́i)**: → **kaevalya** — только «Ты», ощущение единства; без звука и цвета (нет экспрессии). Внутренние стадии; последняя — **nirbiija nirvikalpa**.
- **Механика**: с подъёмом ума меняются форма, цвет, звук, и сам эктоплазм; дойдя до Верховного (вне времени/пространства/личности), меняться нечему.
- **PROUT vs финализм**: философии «последнего пророка»/«последнего слова» — ложны. PROUT: цель — ultimate subjectivity (Brahma), курс — объективная подстройка по времени/пространству/личности (5-й принцип).
- **Практические правила**: успех легко достигнутый не ценится — обычно идти «трудным путём» садханы; садхана сидя, на одеяле/защите (при падении тела меньше травм); не уходить в отшельничество — помогать другим духовно; avadhúta, служивший медиумом, был великим святым прошлой жизни, его грех — отказ от духовной помощи людям (self-centred).

## Key Concepts

- **Bandhanas / páshas** — путы, представленные чакрами.
- **Kaevalya** — стадия «Ты», без «Я» и «Он».
- **Nirbiija nirvikalpa** — крайняя внутренняя стадия kaevalya.
- **Guru krpá** — ускорение эволюции через благодать гуру.

## Mental Models

- «Путь духовности — прохождение контрольных точек; у каждой свои маркеры (чувство, цвет, звук, форма)».
- «"Слишком быстрый" успех обесценивается — нормальный путь — трудная садхана».

## Anti-patterns

- **Отшельничество вместо помощи людям** — грех самодостаточности (пример avadhúta).
- **Садхана без физической защиты (асана/одеяло)** — риск травмы при падении тела.
- **Догма «последнего пророка»** — ложная философия.

## Worked Example

Садхака медитирует с му́ла́дха́ры: чувство sálokya, жёлтый, сверчок, квадрат. Поднимается: сва́дхиштха́на (близость, белый, колокольчики), мани́пура (прикосновение, красный, флейта), ана́хата (одинаковость, синий/зелёный, гонг), вишуддха («Я есть Он», oṋm нарастает). На а́жин́а — kaevalya: только «Ты», тишина; последняя стадия — nirbiija nirvikalpa. Дальше менять нечего.

## Key Takeaways

1. Чакры — контрольные точки пути; пробитие = слияние jiiva с Shiva.
2. Sálokya → sámiipya → sáyujya → sárúpya → sárśt́hi → kaevalya — последовательность чувств.
3. У каждой чакры свой цвет, звук, форма.
4. Kaevalya — только «Ты», без звука и цвета; край — nirbiija nirvikalpa.
5. PROUT: субъективная цель + объективная подстройка; нет «последнего слова».
6. Помощь другим духовно — обязанность садхаки, не отшельничество.
