# Chapter 9: Guńayantraka and Svarúpa Parińáma

*Дискурс c. 1969.*

## Core Idea

До творения силы трёх гун (sentient, mutative, static) текут параллельно; когда теряют параллельность — образуют многоугольники, затем треугольник сил (Guńayantraka). Творение начинается, когда равновесие треугольника ломается и сила вырывается через вершину.

## Frameworks Introduced

- **Исходное состояние**: Puruśa — одно бесконечное трансцендентное существо; имманентные принципы — sentient/mutative/static. Пока волны идут параллельно — фигура не образуется; Prakrti = anucchúnyá (unmanifested), Brahma = niśkala (objectless), nirguńa (сбалансированная Prakrti не влияет).
- **Guńayantraka (треугольник сил / Srśt́imátrká / Causal Matrix)**: когда в точке действуют больше двух сил — они стремятся к треугольнику. Сбалансированный треугольник не создаёт результата, но метаморфоз неизбежен.
- **Svarúpa parińáma (гомоморфная эволюция)**: взаимный обмен идентичностями между тремя принципами — sentient проникает в mutative, mutative в static и обратно. Пока равновесие — Prakrti = Múlá Prakrti. В углах треугольников (biija bindu) гуны постоянно превращаются друг в друга.
- **Срыв равновесия**: из-за неоднородности потока результирующая вырывается через вершину; точка выхода = **kámabiija**; дисбаланс = **guńakśobha**. С этой точки Prakrti начинает влиять на Puruśa — «ноуменальная причина феноменального».
- **Svarúpa parińáma по Са́мкхья**: при растворении мира гуны меняются «внутри себя» (sentient→sentient и т.д.), не трогая другие — в отличие от творящей взаимной трансформации.

## Key Concepts

- **Biija bindu** — конические точки треугольников, где гуны трансформируются.
- **Kámabiija** — точка прорыва; **guńakśobha** — дисбаланс (в тантре).
- **Múlá Prakrti** — Prakrti в равновесии; **anucchúnyá** — нерождённая Prakrti.
- **Niśkala Brahma** — объект-без-объекта, без субъективации/объективации.

## Mental Models

- «Творение — не линейный процесс, а срыв равновесия множества сил; ищи момент потери параллельности».
- «Эволюция гомоморфна: элементы обмениваются идентичностями, а не только смешиваются».

## Anti-patterns

- **Считать равновесие стабильным**: равновесие сил не может длиться вечно — творение неизбежно.
- **Смешивать две версии svarúpa parińáma**: при творении гуны переходят друг в друга; при растворении (по Са́мкхья) — внутри себя.

## Worked Example

Бесконечный поток трёх гун теряет параллельность → многоугольники → треугольник. Сначала равновесие (Múlá Prakrti, Brahma nirguńa). Силы начинают проникать друг в друга (sentient→mutative→static), в biija bindu гуны меняются непрерывно. Поток неоднороден, результирующая вырывается через kámabiija (guńakśobha) — с этого момента Prakrti влияет на Puruśa, начинается saiṋcara.

## Key Takeaways

1. Творению предшествует сбалансированный треугольник сил — Guńayantraka / Causal Matrix.
2. Svarúpa parińáma — взаимная трансформация гун; при растворении (Са́мкхья) — трансформация «внутри себя».
3. Точка прорыва (kámabiija) — ноуменальная причина феноменального мира.
4. Равновесие Prakrti = Múlá Prakrti; срыв = guńakśobha.
