## Правила решений

| Ситуация | Правило |
|---|---|
| Похоронить лидера | Кремация против догмы; пепел — по миру (не самадхи-догма) |
| Пережить утрату лидера | Общий ритуал + истории + запись опыта (ритрит) |
| Ошибка подчинённого | Разоблачить мягко, сохранив достоинство; требовать честности |
| Организационный конфликт | Координация «выигрыш-выигрыш» (крокодил+птица) |
| Страх | Сдача высшей силе + регулярная садхана, а не борьба |
| Оценить «вклад Саркара» | Сверь числа (5018, 180 стран, 22 часа ⚠) с первоисточниками |
| Авидья-тантрик рядом | Имени Бабы и садханы достаточно; при инициации — клятва не применять силы |
| В изоляции | Преврати в интенсивную практику, не в горечь |

## Ключевые цитаты-якоря

- «Can I count upon you? / Can I rely on you?» — клятва работников 20.10.1990.
- «Гармония между мышлением, говорением и деланием» — критерий работника.
- «Я Дхарма Гуру, не могу отступить» — про голодовку 1973–1977.
- «Вы можете держать меня за решёткой, но не арестуете мою мысль и идеологию».
- «Когда преданный делает шаг ко Мне, Я иду на десять шагов» (пересказ, ch01).
- «Это не случайность, это игра Гуру» — рефрен анализа автора.
