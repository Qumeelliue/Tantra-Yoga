# Chapter 20: Emanation

*Дискурс от 30 октября 1983, Калькутта.*

## Core Idea

Utsárańa (эманация) — «то, что из чего-то произведено и движется к большей манифестации»: из семени скрытый потенциал разворачивается в систальной волне (crest-and-trough). Этот закон работает в языке, письме, произношении, одежде, теле и даже в обычаях — остановить его нельзя.

## Frameworks Introduced

- **Эманация = vyaktiikarańa**: от непроявленного к проявленному. Волна первого импульса затухает от «ударов и контрударов» — как река быстра в горах и медленна в дельте. Закон применим к языку: изменение неудержимо.
- **Эманация в словах**: Glowing Chester → Glow-Chester → Glouchester → Gloucester; ed́inbárg → ed́invará; six pennies worth → six pen-worth; Bengali: keleuṋkárii из kalauṋkakárii, gámchá из gátramokśańa → gá-mochá, yácchetái из yá-icche-tái, eblá/oblá из e-belá/o-belá, rovvár из ravivár.
- **Цепочки Sanskrit → Bengali**: avidhavá → avihavá → aihaá → áiha → eyo (женщина с живым мужем); dadhi → dahi → dai (curd; dae — неверно); vadhú → vahu → vau; madhu → mahu → mau; sádhu → sáhu → sáu (merchant); alagnasparsha → álgoch. Правило: если первый компонент кончается на a, а второй — на anat́/kta, вставляется ii (bhasma+bhúta = bhasmiibhúta, nava+karańa = naviikarańa).
- **Эманация в теле**: длинные руки (ájánulambita) были эталоном красоты; люди умели шевелить ушами; был хвост (nyáj из nyuvjaka, не lej/lyáj; láungula → neuṋgun); был appendix для жвачки (romanthana, «chewing the cud») — ныне рудименты. «Рудиментальный ≠ фундаментальный» — рудимент = «из семени».
- **Эманация в одежде и обычаях**: климат/география диктуют одежду (dhoti в грязных странах); lungi — бирманское слово и одежда (из Chittagong через Burma); слово tattva («новости» + дары: ткани, сладости) → новое понятие: sandesh (название сладости из «всевозможных новостей»).
- **Эманация письма**: письмо живёт ~2000 лет; первое письмо Индии — Bráhmii/Kharośt́hii (изобретено ~5000 лет назад); из него три ветви: **Náradá** (юго-запад Аллахабада) → Nágarii/Devanágarii (Gujarat Nágar pandits; Deshii Nágarii/Moŕi — местные), **Sáradá** (северо-запад) → T́ekŕi, Laddaki, Kashmiri Sáradá, Duggardeshii; **Kut́ilá** (Восток, иначе Shriiharśa) → Bengali, Maethilii, Manipuri, Assamese, Oriya. Письма из той же семьи: Guŕmukhii (Panjabi, введён Arjanadeva, не природная дисторсия Sáradá), Devanágarii — не единственное письмо санскрита (есть Sáradá, Shriiharśa, южноиндийские).

## Key Concepts

- **Происхождение ka**: вертикаль (puruśa) + горизонталь (prakrti) = крест (+) = káryabrahma; bija-мантра ka → буква ka в Bráhmii.
- **Зрелость писем**: Sáradá ~1300 лет назад, Kut́ilá ~1100, Nágarii ~800. Веды записали кашмирские пандиты в Sáradá (когда 52 из 108 частей исчезли).
- **Произношение-эманация**: конъюнкты ya/ma/va в modern Bengali не произносятся, первая буква удваивается: padmá → paddá (1000 лет назад padumá); lakśmii → lakkhii (раньше lachmii); svámii → sámii (раньше soámii); dvádashii → doádashii (Бурдван).
- **Кухня-эманация**: mashalá (Farsi), чили не было, páncphoŕan ~650 лет, sántláno; jháler jhol, jholer baŕi.

## Mental Models

- «Эманация — поток реки: затухает на равнине, но не остановится (Дамодар не сдержать песком)».
- «Каждый слой жизни — язык, письмо, одежда, тело — меняется по одной волне».
- «Меньше потребность — меньше орган/слово (хвост, жвачка, lungi входят и выходят)».

## Anti-patterns

- **Писать dae, vao, mao** — неверно: dai, vau, mau.
- **lej/lyáj вместо nyáj** — из nyuvjaka возможно только nyáj.
- **Devanágarii как «письмо санскрита»** — у санскрита нет своего письма; локальные письма старше.
- **Отрицать изменение письма/произношения** — эманация неустранима.

## Worked Example

*Путь слова «полотенце»*. Sanskrit gátramokśańa → gátramocchana → ga-mochá → gámchá. И «eyo»: avidhavá → avihavá → aihaá → áiha → eyo. Вывод: каждое современное слово — конечная точка длинной цепочки эманации; зная ступени, можно предсказывать будущее языка.

## Key Takeaways

1. Эманация — от непроявленного к проявленному, систальная волна.
2. Язык/письмо/одежда/тело меняются по одному закону, без остановки.
3. Письма: Bráhmii → Náradá/Sáradá/Kut́ilá (Shriiharśa).
4. Слова превращаются ступенями (dadhi → dai; avidhavá → eyo).
5. У санскрита нет «своего» письма.
