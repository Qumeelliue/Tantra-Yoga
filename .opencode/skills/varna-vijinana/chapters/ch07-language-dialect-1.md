# Chapter 7: Language and Dialect – 1

*Дискурс от 31 июля 1983, Калькутта.*

## Core Idea

Язык от диалекта отличают **восемь условий** («восьминогой кровати»); в этом дискурсе разобраны первые четыре: собственная лексика, местоимения, глагольные окончания, падежные окончания.

## Frameworks Introduced

- **Восемь условий языка** (объявлены здесь, четыре разбираются в ch07, четыре — в ch08):
  1. Собственный **словарь** 2. Собственные **местоимения** 3. Собственные **глагольные окончания** 4. Собственные **падежные окончания** 5. Собственная **литература** 6. Собственная **интонация** 7. **Психоакустические и инференциальные акустические ноты** 8. **Синтаксис**.
- **Лексика = зеркало прогресса**: словарь сообщества отражает уровень культуры. У наименее развитых племён ~850 слов, у высокоразвитых обезьян ~750 — разница минимальна. Бенгали ≈125 000 слов; нуждается в обогащении (воскрешённый ведизм právrt́ «сильный дождь»).
- **Номинальные глаголы** (átmanepadii): se kablácche ná из kabul karche (Бурдван); sah rámáyate («твердит "Ram, Ram"»); номинальные глаголы обогащают лексику.
- **Местоимения = обязательное условие языка**: без своих местоимений «языковость» исчезает. Бенгали имеет свои ~1200 лет: aham → ahammi → áhmi → áhme → ámi; bhaván → appan → ápana → ápni; tvam → tuhme → tumi.
- **Глагольные окончания — отпечаток родословной**: по ним определяют, из какого Prákrta вышел язык (пример одного предложения на English/Bengali/Hindi/Maithili/Bhojpuri/Angika/Magahi/Marwari/Punjabi — у всех «языков Деми-Магадхи» почти одинаковое выражение; Urdu — другая лексика, другое выражение). Диалект = плавающие окончания (ámi dimure… Barisal; mui karbu ni — Midnapore).
- **Семь Prákrta и их потомки** (генеалогия):
  1. **Mágadhii** (Páli; два произношения sha, без sa/śa) → восточная Деми-Магадхи (Maithili, Angika, Bengali, Assamese, Oriya, Koshalii) + западная (Magahii, Bhojpuri, Nagpuri, Chattisgari).
  2. **Shaorasenii** (Vrśńipura → Vit́hur; Камса, Матхура) → Avadhii, Bághelii, Bundelii, Vrajabhákhá, Hariyánavii.
  3. **Paeshácii** → D́ogrii, Panjabi, Páháŕii.
  4. **Páshcáttya** → Kashmiri, Pashto, Tazaki, Uzbeki.
  5. **Pahlavii/Saendhavii** → Sindhii, Múltánii.
  6. **Málavii** → Gujarati, Kacchii, Marwari, Mevárii, Haŕaotii.
  7. **Maháráśt́rii** → Marathi, Konkańii.
- **Падежные окончания**: от Assamese до Pashto — все потомки Sanskrit, общие правила; Bhojpuri различает svabhávártha (состояние) и karańártha (действие) — признак полноценного языка.

## Key Concepts

- **Prákrta — язык народа**: учёные презирали его, «Sanskrit» = «очищенный»; в санскритских драмах необразованные персонажи говорят на Пра́крите.
- **Páli из pallii** (заимствовано из Tamil), не из Pát́aliputra; Rájagira из rájagiri, не из rájagrha.
- **93% бенгальских слов из Sanskrit**; Oriya ~90%, Malayalam ~75%; Sumatra/Java/Bali/Thailand — изобилие санскритских слов.
- **Трансформации глагола**: karoti → karai → kare; átmanepadii→parasmaepadii: vidyate → vijjati; с префиксом vi: jayati → vijayate.
- **Одно язык → разные языки**: Bengali+Assamese+Maithili+Oriya были одним языком ~850 лет назад; Telegu и Kannad, Tamil и Malayalam — тоже.

## Mental Models

- «Восемь условий — чек-лист: прогони его, прежде чем решать "язык или диалект"».
- «По глагольным окончаниям видна родословная языка, как по отпечаткам».
- «Словарь — зеркало культуры: бедный словарь = бедная стадия развития».

## Anti-patterns

- **Считать Bhojpuri/Маgahii/Chhattisgarhi «диалектами»** — по восьми условиям это полные языки, им нужны признание и литература.
- **Неправильная этимология по памяти**: páli ← Pát́aliputra (неверно); Rájagira ← rájagrha (неверно).
- **«Sanskrit — искусственный язык»** — ложь: 93% слов в речи народа.

## Worked Example

*Одно предложение — восемь языков.* «Экономический прогресс страны зависит от её политической независимости»: English → Bengali → Hindi → Maithili → Bhojpuri → Angika → Magahi → Marwari → Panjabi. У всех — почти одинаковый строй и глагольные окончания (независимого происхождения от Деми-Магадхи). Urdu: «Mulkii ektasádii tarakkii uskii siiásii ázádii par makub hae» — совсем другой словарь и грамматика. Вывод: общность окончаний = общность происхождения.

## Key Takeaways

1. Восемь условий отделяют язык от диалекта; не признавать «малые» языки — ошибка.
2. Словарь — зеркало прогресса сообщества.
3. Свои местоимения — обязательный признак языка (бенгали ~1200 лет).
4. Глагольные окончания выдают родословную языка.
5. Семь Пра́криты — древо всех современных индоарийских языков.
