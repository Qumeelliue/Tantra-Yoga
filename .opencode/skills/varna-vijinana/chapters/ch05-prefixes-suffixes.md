# Chapter 5: Phonetics, Prefixes and Suffixes

*Дискурс от 17 июля 1983, Калькутта.*

## Core Idea

Четыре стиля произношения санскрита (Káshiká, Maháráśt́rii, Dravidian, Bengali), двадцать upasarga (префиксов) и pratyaya (суффиксы) — универсальный механизм образования слов во всех языках мира.

## Frameworks Introduced

- **Четыре стиля произношения Sanskrit**: Káshiká (vivrta), Maháráśt́rii, Dravidian, Bengali (Gaoŕiiya, saḿvrta). «Па́т́на́» пишется по-разному в каждом стиле — все написания верны для своего стиля. Bengali: á простое (Jamalpur), остальные — долгое á (французское).
- **Активирующая идея vs активируемое качество**: префикс (upasarga) отделяет часть от большей идеи; суффикс (pratyaya) — «активируемое качество», которое привязывает корень к нужному смыслу. Пример: sam-ci-ghaiṋ → saiṋcaya (sam — активирующая идея, ghaiṋ — активируемое).
- **Двадцать upasarga Sanskrit**: pra, pará, apa, sam, anu, ava, nir, dur, abhi, vi, adhi, su, ut, ati, ni, prati, pari, api, upa, á.
- **Соответствие суффиксов**: английский «er» = Sanskrit d́a: go+er=goer, trae+d́a=tra, gam+d́a=ga; gáyattrii (gae+shatr+trae+d́a+iip).
- **Три ветви латинской семьи**: Continental (немецкий, чешский, венгерский…), Occido-Demi-Latin (испанский, португальский, «пол-язык» баскский), Oriento-Demi-Latin (французский, итальянский). Две пары похожих языков: испанский↔португальский, бенгали↔ория.
- **Два стиля английского произношения**: Anglo-Saxon (d→j: immejiate, ejucation) и Norman (d→d́: immediate, education).

## Key Concepts

- **Префиксы Bengali**: há, á, ni (há-bháte из há-bhátiyá; á-dekhle из á-dekhilá).
- **Farsi префиксы в Bengali**: be- («без»): beimán, bewárish, be-ákkile, be-kár, kárkháná, kárigar. Arabic аналог be = lá: lá-wárish.
- **Словообразование Bengali**: ámra → ámba → ámbá → ánbaa → ánb (манго, ~5 ступеней через 4 поколения: Sanskrit → Prákrta → Demi-Prákrta → old Bengali → modern Bengali). Пра́крита puśpa → Mágadhii puśpala → … → phul (цветок).
- **93% бенгальской лексики из Sanskrit** — но произносить её надо по-бенгальски, не по-санскритски.
- **Ведические корни слов**: godhúma (go «язык» + dhúma «праздник» → пшеница = праздник для языка), vriihi (рис; «в котором скрыт большой потенциал» — отсюда bahuvriihi), dhánya = «зелёная растительность», не рис.
- **Русский — потомок Vedic**: nah, vah живут в русском; Páshcáttya Prákrta → кашмири, пушту, таджикский, узбекский.

## Mental Models

- «Слово = префикс + корень + суффикс; префикс отделяет часть от целой идеи, суффикс придаёт точный смысл».
- «Стиль произношения региона — закон для этого региона: не мерить чужой стиль своей меркой».
- «Филология сближает народы и служит неогуманизму — расстояния между людьми сокращаются через понимание языка».

## Anti-patterns

- **Произносить санскритские заимствования по-санскритски в бенгали** — «разница в 4 поколения» языков.
- **Навязывать чужое произношение** (ey-ágára, ey-ákádash из бенгальского e — влияние индо-бирманское, не арийское).
- **Считать слово nábálak санскритским** — это искажённое Farsi ná-válig.

## Worked Example

*Путь слова «цветок» по Пра́критам.* Sanskrit puśpa → Mágadhii puśpala → Demi-Mágadhii puphphala → old Bengali pupphul → modern Bengali phul. В Páshcáttya Prákrta: padmapuśpa → padampośp → pampos (кашмири). Вывод: одна пра́крита, разные ветви — разные цепочки звуков, но все выводятся системно.

## Key Takeaways

1. Четыре стиля произношения — разные системы, а не ошибки.
2. 20 префиксов Sanskrit + свои префиксы каждого языка (Farsi be, Bengali há/á/ni).
3. Слово разбирается на префикс + корень + суффикс — это и есть этимология.
4. Слова мигрируют ступенями Sanskrit→…→современный язык (~4 поколения).
5. Sanskrit — фундамент бенгали; его изучение обязательно на университетском уровне.
