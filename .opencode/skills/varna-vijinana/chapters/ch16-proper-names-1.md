# Chapter 16: Proper Names – 1

*Дискурс от 9 октября 1983, Калькутта.*

## Core Idea

Люди ищут ритм в языке (отсюда «ритмические слова» вида cá-t́á), имена собственные нельзя искажать, а топонимы хранят историю заселения — в них читаются древние Austric-слои и география затопления.

## Frameworks Introduced

- **Ритмические слова (не сама́са)**: жизнь ритмична (systaltic order), поэтому к односложным/двусложным словам добавляют рифмующийся «хвост»: cá-t́á, cál-culo, jal-t́al, cáśá-bhúśá, nadii-t́adi. Это не сложные слова, а ритм. Анекдот: Махараджа Manindra Chandra Nandi — «Esab cáśa-bhúsorái bale-t́ale tháke».
- **Имена собственные неприкосновенны**: искажение Paris → «Paris», Chicago → «Chicago», Londres → London, Moscow, Rome, Cairo — ошибки. Правильно: párii, shikágo, Moscova, Roma, Kahira. Kalikátá → «Calcutta» — без логики; нужно Kalikata. Ассамский: ca всегда sha (tincukiyá → tinsukiyá).
- **Топонимический слой diiyá (остров)**: Sanskrit dviipa → Mágadhii diia → Bengali diiyá. Маггадхский закон: ka/ta/pa/da в Sanskrit → a в Пра́крите. Nadiiyá из Navadviipa, Háthiiyá из Hastiidviipa, Májhdiiyá из Madhyadviipa. Западный Rarh никогда не был под водой → там нет -diiyá.
- **Слой d́áuṋgá (возвышенность из моря)**: Austric слово; settlement, поднявшийся из моря, — d́áuṋgá (Beldáuṋgá, Nárkold́áuṋgá, Pat́old́áuṋgá — будущий College Square). Rarh: d́áuṋgál (высоко), námál (низко).
- **Слои рельефа**: parvata → páháŕ → páháŕii → d́uḿri/d́áḿrá → t́ilá → d́hibi. Bokaro Steel City = Mará Páhárii («мёртвый камень»).

## Key Concepts

- **Austric слова в Bengali**: d́áuṋgá, joŕ (река, кроме больших), sánko (мост), haŕká (внезапный паводок), sol/suli, d́ihi/d́ihá, ráŕh (из ráŕhá/ráŕho «красная земля»), biira (лес) → Birbhum. В Dravidian (Kuruk) их мало.
- **pallii — Dravidian**, не санскрит; в Sanskrit pallii = «ящерица»; páŕá (район) ≠ из pallii (это восточноиндийское слово; muhallá из Farsi).
- **История через топонимы**: 24 Paraganas заселены людьми западного Rarh после катастрофы (~750 лет назад шторм затопил 150 миль побережья); кровные линии и говоры выдают происхождение (влияние Contai/Tamaluk).
- **Диминутивы**: Sanskrit aka/raka/ruka = English let/kin/ock: vatsaruka → báchru (телёнок), go+ruka = goru (корова), dviiparaka → diyárá (островок).
- **Этимология света**: diipa → diia → diiyá; diipávalii («много ламп») → diiyáóyálii → deoyálii. ka = «пересаженная психическая идея» — cálm = «сегодня».

## Mental Models

- «Имя — капсула географии: -diiyá = было море, d́áuṋgá = встало из моря».
- «Слой за слоем: Sanskrit, Austric, Dravidian, Farsi — топонимы многослойны, как археология».
- «Ритм — потребность жизни; язык добавляет эхо к коротким словам».

## Anti-patterns

- **Искажать имена собственные** — «ни при каких условиях нельзя менять имена собственные».
- **Принимать общепринятое искажение за норму** (Calcutta вместо Kalikátá, Burdwan вместо Varddhamán, Moscow вместо Moscova).
- **Путать происхождение** (páŕá из pallii — ложь; Májdiyá вместо Májhdiiyá).

## Worked Example

*Что говорит имя «Májhdiiyá»*. Madhyadviipa («средний остров») → Majjhdiiia → Májhdiiyá (через Magadhii: dviipa → diia). Пишется с jha+dii. Западный Rarh таких имён не даёт — значит, этот район был под водой и заселён позже. Вывод: топоним читается как геологическая карта.

## Key Takeaways

1. Ритмические слова — это ритм, а не сама́са.
2. Имена собственные не подлежат «исправлению» по произношению других.
3. -diiyá = остров (был под водой); d́áuṋgá = поднялся из моря.
4. Austric, Dravidian, Sanskrit, Farsi — слои топонимики.
5. Имя города — история заселения и катастроф.
