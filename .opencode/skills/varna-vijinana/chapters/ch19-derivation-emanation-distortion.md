# Chapter 19: Derivation, Emanation and Distortion

*Дискурс от 23 октября 1983, Калькутта.*

## Core Idea

Звук — тончайшее из пяти умозаключений («shabdabrahma»); первичные корни всех языков созданы акустической деривацией (подражанием звукам), а из них через префиксы и суффиксы выведены слова. Язык меняется по законам времени, места и человека.

## Frameworks Introduced

- **Акустическая деривация**: люди подражали звукам природы и через параллельные звуки выражали идеи. Сначала — корни, потом аффиксы. Примеры: t́hak t́hak (дровосек) → t́hakkara; jhanjhan (посуда); maŕmaŕ; paŕpaŕ (накрахмаленная дхоти) → paŕpaŕiye pálálo; gaŕgaŕ (катящееся) → gaŕiye jáoyá; turtur (конь) → turaga/turauṋga; kurkur (олень) → kuraga; cyán cyán (рыбы) → cyáḿ; hávháv (жадная еда) → hávŕe hávŕe; phat́ (тантра) → phat́phat́; phut́áni → «хвастовство». Звук → психическая вибрация → слово.
- **Четыре корневых языка**: Vedic, Latin, Hebrew, old Chinese. Метод деривации у всех идентичен (префикс+корень+суффикс). Только Vedic не имел грамматики — был живым языком до изобретения письма.
- **Vedic — старший корень**: начался ~15 000 лет назад, зрел ~10 000; язык живёт ~1000 лет, так что за 5000 лет ведического развития могли возникнуть 5 новых языков; внутри Вед язык младших мандал отличается от старших.
- **Latin — западная ветвь Vedic**: frater/mater/pater = Vedic bhrátar/mátar/pitar; суффикс śńik в Latin (dynamic, static, economic).
- **Дисторсия по времени**: изменение идёт через неграмотных/полуграмотных; пока отклонение небольшое — нового имени не дают; когда далеко — называют новой ступенью: ahaḿ grhaḿ gacchámi → ahammi garaham jacchámi (Prákrta) → ahammi garahe jacchái (Demi-Prákrta) → áhmi gharae jácchai (old Bengali) → ámi ghare jácchi (Bengali).

## Key Concepts

- **Sáhitya и изустность**: люди хранили Veda из-за богатства идеи (dharma); неграмотные интеллектуалы тех лет — rśi («культурный человек» из корня r). árśa доктрина.
- **Hindu = географический термин** (долина Инда), Farsi слово; религиозно-правильное имя — «последователь árśa».
- **Papyrus**: pápire/pápires → paper; Egypt = Mishradesha (смешанный); gypsy ← «Egyptian» (beduin). Ка́gaj из Farsi kágad.
- **Звукоподражательная лексика**: кра́йне много; часть неразложима на prefix+root+suffix — принимать такие слова надо, а не изгонять.
- **Грамматика следует языку**: Panini подстроил грамматику под Vedic+Sanskrit; Vopadeva — под Laokika Sanskrit (Vedic уже мёртв «как дронт»).
- **Развитие новых литератур**: Hebrew возрождён в Израиле (новая литература — «очень рад»); Egypt — влияние French+English; Iraq движется.

## Mental Models

- «Каждое слово — эхо звука: слушай природу, когда ищешь происхождение корня».
- «Язык переименовывается ступенями: пока изменение мало — та же ступень, далеко — новое имя».
- «Vedic — река без плотин, Sanskrit — колодец, Latin — ветвь реки на западе».

## Anti-patterns

- **Забывать изустную литературу прошлого** — люди бросали песни, когда язык менялся; но народные песни/песенки живут ~700–800 лет.
- **Считать «Hindu» религиозным именем** — это география.
- **Пытаться удержать язык насильно** — языки растут обменом (перекличка с ch06).

## Worked Example

*Цепочка одного слова через эпохи.* ahaḿ grhaḿ gacchámi (Sanskrit) → ahammi garaham jacchámi (Prákrta) → ahammi garahe jacchái (Demi-Prákrta) → áhmi gharae jácchai (old Bengali) → ámi ghare jácchi (современный Bengali). Каждая ступень — новый «титул» языка, хотя механически это цепочка дисторсии.

## Key Takeaways

1. Первичные корни — звукоподражательные (акустическая деривация).
2. Четыре корневых языка: Vedic, Latin, Hebrew, old Chinese.
3. Деривация = префикс + корень + суффикс, одинакова во всех четырёх.
4. Язык переименовывается ступенями по мере отдаления от оригинала.
5. Живой язык не знал грамматики; грамматика — после.
