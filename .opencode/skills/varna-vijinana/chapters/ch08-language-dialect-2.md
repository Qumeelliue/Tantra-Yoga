# Chapter 8: Language and Dialect – 2

*Дискурс от 7 августа 1983, Калькутта.*

## Core Idea

Остальные четыре условия языка: собственная литература, интонация, психоакустические/инференциальные ноты и синтаксис. Ключевое разграничение: **литература ≠ sáhitya** — sáhitya требует мотива блага.

## Frameworks Introduced

- **Литература (5-е условие)**: «literature» из латинского liter «кирпич» (буквы обжигали как кирпичи; отсюда laterite — красная земля Рарха). Язык должен иметь свою литературу, письменную или **устную** (sáhitya не обязана быть записанной — Веды = Shruti «услышанное»).
- **sáhitya ≠ literature**: sáhitya = `hitena saha` («с благом»). Вся sáhitya — литература, но не вся литература — sáhitya. Без мотива блага — только литература (apasáhitya). Шекспир — «беспрецедентный сплав»; Киплинг — больше литература; Милтон, Шоу — sáhityik.
- **akṣara «непреходящее»**: akśara = то, что не kśara (не разрушается). Звук, раз произнесённый, вечно отдаётся в космическом центре → **первое условие гуманизма — свобода речи** (анти-неогуманистические догмы её отнимают).
- **Интонация (6-е условие)**: своя у каждого языка и каждого диалекта («миля за милей»). Неверное произношение — социальный проступок: оно распространяется и искажает язык.
- **Эталонный стандарт языка**: для каждого языка нужен лёгкий, хорошо понятный стандарт с высокой интонацией: Bengali = Калькутта, Panjabi = Moghulpurá, Angika = Campánagar, Nágpurii = Gumlá, Oriya = Cuttack, Assamese = Shivasagar, Magahii = Rajgir, Maithili = Madhuvanii, Bhojpuri = Dumraon, Bághelii = Rewa, Urdu = Delhi (Chandnichowk), Chhattisgarhi = Raipur. Английский = треугольник London–Cambridge–Oxford.
- **Психоакустические/инференциальные ноты и синтаксис (7-е и 8-е условия)** — заявлены здесь, детально в ch09 и ch11.

## Key Concepts

- **Стандартное произношение каждого языка по-своему**: Sanskrit — sma/dma как «сма»/«дма» (padma = pad-ma), Bengali — sma→sya, dma→dda; Maithilii — i перед согласным (пишем pánii, читаем páin).
- **Грамматическая память Веды**: па́ндия одного Veda = Páńd́eya (Pánŕe), двух = Dvivedii, трёх = Trivedii, четырёх = Caturvedii; Yajurveda разделилась на Krśńa/Shukla.
- **Устная литература**: Tusu (западный Рарх), Bhádu (восточный), Bhawaia (север), Bhát́iyáli (юго-восток), Ául, Baul, Múrshidá, Sári, Járigán, Vratakathá, Páncálii, колыбельные — полноправная литература.
- **Родоначальники литератур**: Jyotiriishvara Thakur (Maithili, до Vidyapati), Naval Sharma (Chhattisgarhi), Alfred (английская), Hussain Shah (бенгальская), Caryápada >1000 лет (Kalacakrayána Buddhism).
- **Французское влияние на английскую интонацию**: Henry VIII история; французы не произносят t́a varga; английский — t́a varga + почти нет ta varga.
- **Английский разговорный стандарт** — внутри треугольника London–Cambridge–Oxford; Cockney — искажённый говор, не диалект.

## Mental Models

- «Проверяй произведение по мерке времени, а не эпохи/среды: "я бы мерил меркой, выдерживающей испытание временем"».
- «Литература — кирпичное дело; sáhitya — служение благу».
- «Произношение — социальная ответственность: учитель с плохим произношением вредит миллионам».

## Anti-patterns

- **Считать литературу и sáhitya синонимами** — «ночь и день»: литература без блага — не sáhitya.
- **Учить детей, что литература = sáhitya** — «лучше признать незнание, чем учить ошибке».
- **Принимать «локальный акцент» за отдельный диалект** (Cockney — испорченный английский).
- **Игнорировать родной стандарт** — учитель, копирующий чужой акцент, распространяет ошибку.

## Worked Example

*Разбор авторов по осям «литература / sáhitya».* Сатьендранатх Датта — «маг метра»: больше литература. Рабиндранат Тагор — беспрецедентный сплав. Valmiki Rámáyańa — sáhityik, но не развитый язык; Vyása Mahábhárata — почти 100% sáhitya. Wordsworth — мало литературной ценности, большая sáhityik. Romain Rolland — глубокая sáhityik. Вывод: оценивай по вечной мерке, не по моде эпохи.

## Key Takeaways

1. Языку нужны своя литература (устная или письменная), интонация и стандарт.
2. sáhitya = литература с мотивом блага; не смешивать понятия.
3. Свобода речи — первое условие гуманизма (akṣara вечно).
4. Каждый язык имеет эталон произношения (Калькутта для бенгали).
5. Малые языки (Bhojpuri, Magahii и др.) имеют свою литературу — значит, они языки.
