# Chapter 17: Proper Names – 2

*Дискурс от 9 октября 1983, Калькутта (продолжение).*

## Core Idea

Санскритские имена распространились от южной России до Юго-Восточной Азии; топонимические суффиксы (talá, vanii, Vasán, d́ihi, báŕi, sol/suli) — систематический ключ к истории народа и земли.

## Frameworks Introduced

- **Санскрит — язык обширного региона**: от южной России (Shákadviipa) через India+Afghanistan (Jambudviipa) до Burma+SE Asia (Suvarńadviipa). Таиланд: ja → d́a, ńa → d́ha (Krśńadás → Krśd́had́ás); Jakarta из Yogyakarttá; Java из Yavadviipa (столица Vátávipura → Batavia); Singapore из Rarh’s Siḿhapur (через Sahasrarabáhu).
- **Топонимические суффиксы (система)**:
  - **talá/talii**: место под деревом/для дела — Nimtalá, Ágartalá, Cańd́iitalá; talii — без «для дела» (Ámtalii).
  - **vanii**: изобилие дерева — Ásánvanii, Madhuvanii.
  - **Vasán**: новое поселение — Rájávasán, Nuyávasán (не Nayávasán).
  - **d́ihi/d́ihá** (Austric): сухие места западного Rarh — Bámund́i, Hánsd́ihá; в затопленных районах нет.
  - **báŕi/beŕe**: vát́i/vát́iká → Khaŕibáŕi, Ulubeŕe, Golábáŕi.
  - **sol/suli** (Austric): село на возвышенности — Khayrasol (рыба khayrá), Asansol (от Ásán Miina), Lodhásuli.
  - **sáhii/sái, kerá/kelá**: западный Rarh — Bábusáhii, Seráikelá.
  - **chaŕá/kándi** (нативные Bengali): «пучок» деревень — Lakśmiichaŕá, Chátinákándi.
  - **ghurńii/daha**: водоворот у реки — Ghurńii, Máldah (Malla + Mahánand daha), Sardaha, Cakradaha → Cákadá, Shiyáldaha.
  - **-gunge (gaiṋja)**: рынок — Tolleygunj, Ballygunge (из Baligaiṋja).
- **Историческая топонимика как метод**: если у народа нет письменной истории, история восстанавливается из имён городов; «большая часть преподаваемой истории будет безжалостно отброшена».

## Key Concepts

- **Имена цветов/фруктов**: rajaniigandhá (тубероза) из Мексики через португальцев (450 лет назад), имя «ночной аромат»; Batavia lemon (pomelo), mahálauṋga, jambiira, sharvatii nebu (не lebu) vs kamalá (orange); cini из Batavia → bát́á cini.
- **Семьи цитрусовых**: nebu (рind не снимается: jambiira, mahálauṋga, Batavi) vs kamalá (кожура снимается: Sylheti, Assam, Darjeeling, Nagpuri kamalá); keno nebu — гибрид.
- **Shákadviipii Brahmans**: бежали от ислама, селились в Индии; астрология/Ayurveda; не-ведические ритуалы; солнечные храмы (Końárk). В Bengali — Vaedyaka система с вскрытием трупов (Madhusudhan Gupta — остракизм).
- **Крокодилы**: «crocodile gangelitis» (речные) vs alligator (amazonika); взаимовыгодный союз с птицами.
- **Калькутта**: три деревни (Kalighat, Sutanuti — ткачи sutá+nut́i, Govindapur) + 27+35 деревень; Baŕabájár из Buŕá Bájár (Buŕo Shiva); Entally из Hentálii (лес hintal).

## Mental Models

- «Суффикс топонима — системный ключ: узнав -daha/-vanii/-Vasán, ты читаешь географию и историю».
- «Культурное смешение читается в именах (Jamalpur = Jámál + pura)».
- «Народ без письменной истории — народ, чью историю ещё надо вычитать из карты».

## Anti-patterns

- **Nayávasán вместо Nuyávasán** — «Nayá — хинди, не бенгальское».
- **«Nepali» как имя языка** — зонтик, а не язык (повтор ch09).
- **Ошибочные названия** (Nayágrám, lebu вместо nebu) — «открывай глаза на ошибку, а не следуй слепо».

## Worked Example

*Чтение названия Asansol.* Asansol — Austric sol («село на возвышенности») + имя основателя Ásán Miina. Рядом Khayrasol (рыба khadirá) и Siháŕasol (деревья sheoŕá) — все в одном районе Бурдвана. Вывод: суффикс sol маркирует тип местности и частную историю основания.

## Key Takeaways

1. Санскритская топонимика покрывает пол-Евразии (Jambudviipa → Suvarńadviipa).
2. Каждый суффикс (-daha, -vanii, -Vasán, -d́ihi, -sol) читается систематически.
3. Имена — метод реконструкции истории без письменных источников.
4. Местные названия вытесняются чужими произношениями (Calcutta, gunge).
5. Культурное смешение видно в самих именах.
