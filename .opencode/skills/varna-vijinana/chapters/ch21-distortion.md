# Chapter 21: Distortion

*Дискурс от 6 ноября 1983, Калькутта.*

## Core Idea

Vivarttana (дисторсия) — «испорченная форма изменения»: в отличие от эманации, движение слова останавливается. Три причины: неверное произношение, аббревиация, импорт слов без понимания смысла.

## Frameworks Introduced

- **Эманация vs дисторсия**: всякое движение в космосе есть закон vidhátá (система, а не сущность); естественное изменение = utsárańa; испорченное = vivarttana. Дисторсия НЕ продолжает путь эманации.
- **Три причины дисторсии**:
  1. **Неверное произношение масс**: cikitsá → cikicchá, mahotsav → mocchav, bhisá → bhicá, mesh → mec, «selection» → cheleccion; dápana из darpańa (не развивается дальше 1300 лет). Дисторсия остановлена.
  2. **Аббревиация**: yá-icche-tái → yácchetái; banávat́ii → banáot́i; laŕkápan → laŕakpan; tálib-e-ilm → tálbelim; á-dekhilá-paná → ádekhlepaná. Английские: «general purpose car» → G.P. car → G.P. → giip → jeep; «all correct» → «ol korect» → «O.K.» → okay; Greenwich → griinic; sandwich → sándic; northwest wind → noŕwester.
  3. **Импорт/«полировка» слов без смысла**: soccára («тот, кто не убрался после дефекации» вместо «голос»), bhijiṋa вместо abhijiṋa, ádhikyatá (двойная абстракция), anushiilana (нативный бенгальский, не санскрит), rúpakathá (нет такого слова; правильно kathá/kathániká), stimita (от astamita).
- **Критерий остановки**: если дисторсия «неестественна» — движение обрывается (dápan); если «естественна» — продолжается (prastara → patthara → páthar, но не páthár).
- **Правило минимального прироста**: при контрасте двух сущностей первый компонент кончается на á/o, второй — на i: lát́hálát́hi, márámári, káŕákáŕi, dekhádekhi, sarásari, hásáhási, táŕátáŕi, culoculi, t́hesát́hesi. Живой источник «бесконечной жизненности» бенгали.

## Key Concepts

- **Афоризм дисторсии**: á, i, u — теряются в произношении; ao → o (aośadh → ośudh, okhadh в Maithili).
- **Аббревиация как наука**: из первых букв: ágama (ágataḿ + gataḿ + mataḿ); Bhu-su-ku (bhojana+shayana+karma — буддийский поэт, 1200 лет).
- **Akronym в русле афоризмов**: образуются у всех народов.
- **Bauṋgál ≠ Vauṋga + Farsi ál**: слово в поэзии 1200-летней давности; Banjala (Chinese), Banjalitis (Latin), Bangala (Turkish), Bangal (Farsi/Urdu), Bengal (English).
- **Правописание-ловушки**: shvajana vs svajana; puttra (два ta); gavii → gái, но НЕ gábhii; itahpúrve (не itipúrve); visarga в spaśt́atah, но не spaśt́atai (гласный рядом с visarga).
- **Plural латинских**: memorandum→memoranda, cactus→cacti; «memorandums»/«cash-memos» — «беспорядок».
- **Ложные санскритизмы**: prasráva (из Farsi pesh-áb; правильно mútratyága); gaveśańá («поиск коровы») — хороший, но для «research» лучше vishad sandhán.
- **География ветра**: kálvaeshákhii = noŕwester; háoyá — турецкое слово.

## Mental Models

- «Эманация — река, дисторсия — лужа: естественное течёт дальше, испорченное застаивается».
- «Каждое новое слово проверяй на смысл, длину и возможность сама́са».
- «Ветер называется по направлению движения, а не откуда дует — но с исключениями».

## Anti-patterns

- **«Выдумывать» слова без этимологии** (anushiilana, rúpakathá, káhinii, ádikyatá) — «готовить счета» не помогает языку.
- **ádhikyatá вместо ádhikya/adhikatá** — двойное «-ness», но автор признаёт живость ádikhyetá в разговоре.
- **bhijiṋa** — карантин для ошибки: в Hindi «знающий» и «незнающий» перепутаны.
- **shahiid для павших за родину** — правильно dadhiici (жертва вне джихада).

## Worked Example

*Рождение «O.K.»*. Война в Америке: испаноязычные солдаты писали «ol korect» (вместо «all correct»); затем сократили до «O.K.»; в мире принято «okay/okey»; «He has already okayed it». Полная цепочка дисторсии через аббревиацию, принятая обществом.

## Key Takeaways

1. Дисторсия = испорченное изменение; движение останавливается.
2. Три причины: произношение масс, аббревиация, импорт без смысла.
3. Естественная дисторсия может стать новым правилом (páthar), неестественная — нет (dápan).
4. Правило минимального прироста (á...i) порождает живые слова.
5. Проверяй каждое новое слово на смысл и этимологию — «лучше признать незнание».
