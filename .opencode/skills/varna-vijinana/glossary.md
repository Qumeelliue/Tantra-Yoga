# Глоссарий — Varńa Vijiṋána

**Abhijiṋa** — «знающий хорошо» (abhi + jiṋá); не путать с bhijiṋa (нет такого слова). Ch21.

**Akśara** — «непреходящее» (не kśara); буква; garland букв = akśamálá. Ch05, Ch08.

**Antahsthavarńa** — ya/ra/la/va: не согласные, а дифтонги гласных (ya=i+a, ra=r+a, la=lr+a, va=o+a). Ch02–03.

**Apavarga** — действие завершено и результат получен (3-й падеж в Sanskrit). Ch12–13.

**Atmanepadii/parasmaepadii/ubhayapadii** — глагольные залоги: «для себя» / «для другого» / оба. Ch04, Ch14.

**Ayogaváha / demi-vowels** — aḿ и ah: гласные, не произносимые без помощи. Ch02.

**Bahuvriihi** — сама́са с многими vyásavákya, управляется jáhár/játe. Ch18.

**Bhaván** — «ваша светлость» (Sanskrit), прародитель ápani. Ch12.

**Bhávádhikarańa** — локатив идеи (sáhitye nipuńa). Ch11, Ch15.

**Bija mantra** — «семенной» звук; ka — биджа káryabrahma. Ch20.

**Carańapúrti** — «заполнение стопы»: вставка для ритма без изменения глагола. Ch11.

**Demi-Prákrta** — промежуточная ступень Sanskrit → современные языки. Ch01, Ch19.

**Dhrupadii язык** — «скованный грамматикой» (Sanskrit, Arabic, Hebrew, Latin, Greek, Pali). Ch13.

**Dvandva** — сама́са разных слов без союза (girisindhu). Ch18.

**Dvigu** — сама́са с числительным (triloka, Caturveda). Ch18.

**Emanation (utsárańa)** — естественное разворачивание из непроявленного; изменение языка. Ch19–20.

**Gaveśańá** — «поиск коровы» (go+eśańá): исследование; но для «research» лучше vishad sandhán. Ch06, Ch21.

**Hasanta** — знак отсечения конечной гласной. Ch01, Ch14.

**Inference acoustic notes** — сравнение по эталону (mishkálo «чёрный как mishi»). Ch09.

**Káládhikarańa** — локатив времени (sandhyábeláy). Ch11, Ch15.

**Karmmańi dvitiiyá** — «винительный — 2-й падеж» (правило Sanskrit, не всегда для Bengali). Ch12.

**Káraka / vibhakti** — падеж / падежное окончание. Ch11–15.

**Kheyál** — свобода вокала в музыке (противопоставлено dhrupadii). Ch13.

**Krt / taddhita** — суффикс к корню / к основе. Ch04.

**Laokika Sanskrit** — «очищенный» язык народа. Ch01, Ch19.

**Madhyapadalopii** — сама́са с пропущенным средним словом. Ch18.

**Nitya samása** — сама́са синонимов (ashrujal, nácaduyár). Ch18.

**Nominal verb** — глагол, созданный от имени (rámáyate). Ch07.

**Prákrta** — «язык народа»; семь Пра́крит после Vedic. Ch01, Ch07, Ch19.

**Pratyaya / upasarga** — суффикс / префикс. Ch05.

**Psycho-acoustic notes** — вибрация ума при виде объекта → первичный корень слова. Ch09.

**Rgveda/Yajurveda/Atharvaveda** — три Veda с разными стилями произношения (r — ri — ru). Ch01–04.

**Sáhitya** — литература с мотивом блага (hitena saha); ≠ literature. Ch08.

**Samása** — сложное слово; определяется через vyásavákya. Ch18.

**Saḿvrta/Vivrta/Tiryyak** — три системы произношения Sanskrit. Ch01.

**Sandesh** — сладость; из tattva «всевозможные новости» (эманация обычая). Ch20.

**Saḿskára** — накопленный след/склонность (влияет на психоакустические ноты). Ch09.

**Shruti** — «услышанное»; Veda как устная литература. Ch08.

**Svabhávártha / karańártha** — состояние / действие (глагол Bhojpuri). Ch07.

**Tatpuruśa** — сама́са с падением падежного окончания первого слова. Ch18.

**Trrń-семья** — pitr/mátr/bhrátr = father/mother/brother (Latin/French/English/Farsi). Ch15.

**Uśmavarńa** — свистящие придыхательные (sha/sa/śa/ha/kśa). Ch02–03.

**Utsárańa / vivarttana** — эманация / дисторсия (естественное / испорченное изменение). Ch19–21.

**Varga** — группа из 5 согласных по месту артикуляции. Ch02–03.

**Vyásavákya** — развёрнутая фраза для определения сама́са. Ch18.

**Vyaktiikarańa** — проявление/эманация (от непроявленного к проявленному). Ch20.

**Восемь условий языка** — лексика, местоимения, глагольные окончания, падежные окончания, литература, интонация, акустические ноты, синтаксис. Ch07–08.

**Локатив (7-й)** — adhikarańa; три: время/идея/база. Ch11, Ch15.

**Правило ya** — «padánte padamadhyasthe "ya"-kára "ia" ucyate» (ya в начале — ja, в середине — ia). Ch01.
