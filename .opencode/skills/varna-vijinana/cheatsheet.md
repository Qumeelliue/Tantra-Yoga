# Читшит — правила решений и быстрые справки

## Язык или диалект? (решай по 8 условиям)
| Условие | Язык | Диалект |
|---|---|---|
| Словарь | свой, большой | малый/общий |
| Местоимения | свои | нет своих |
| Глагольные окончания | свои, стабильные | плавающие |
| Падежные окончания | свои | вариации |
| Литература | своя (устная/письм.) | нет |
| Интонация | своя + стандарт | локальная |
| Акустические ноты | свои | чужие |
| Синтаксис | свой | чужой |

Пример: Bhojpuri/Angika/Maithili = языки, несмотря на отсутствие конституционного признания.

## Сама́са: дерево решений
1. Восстанови vyásavákya (развёрнутую фразу). Неоднозначно → не классифицируй.
2. Ушло падежное окончание 1-го слова → **tatpuruśa** (6-й/7-й и т.д.).
3. Второе слово поясняет/«есть» первое → **karmadháraya**: форма (rúpaka), сравнение (upamita/upamána), пропуск (madhyapadalopii).
4. В фразе есть jini/je → **upapada**.
5. Много фраз, управляется jáhár/játe → **bahuvriihi**.
6. Числительное → **dvigu**.
7. Разные слова, союз o/ár → **dvandva** (не evaḿ!).
8. Синонимы → **nitya**.
9. От indeclinable (theke…paryanta) → **avyayiibháva**.
10. Действия по порядку → **supsupeti** (karmadháraya).

## Эманация vs дисторсия
| Признак | Эманация (utsárańa) | Дисторсия (vivarttana) |
|---|---|---|
| Характер | естественный | испорченный |
| Продолжение | течёт дальше | останавливается |
| Пример | prastara→páthar | cikitsá→cikicchá; dápan |
| Триггеры | время/место/человек | произношение масс, аббревиация, импорт без смысла |

## Правила-ловушки
- **Падежи**: номинатив не обязан быть 1-м (в Bengali — 7-й: págale ki ná bale). Дательный — только в Sanskrit; Bengali/Hindi его не имеют. by = прямая связь, with = косвенная. «of» читается ov, не off.
- **Санскрит произносится как пишется**; в Bengali/English письмо ≠ звук (housewife=huzif/haus-waif; question=questiyan).
- **Правописание**: puttra/gáyattrii — два ta; kárttika из krttiká; разбирай prefix+root+suffix.
- **Род заимствований**: kalam — жен. (Hindi) / муж. (Urdu, «саженец»); dukán (u) жен. / dúkán (ú) муж.
- **Конъюнкты**: группы palatal/cerebral/dental не смешиваются (kaśt́a, nishcala); va/ya/ma в конъюнкте не произносятся, первая буква удваивается (padmá→paddá).

## Запомни эталоны
- **Нить языков**: `sútre mańigańá iva` — все языки на одной нити.
- **Сроки**: язык ~1000 лет, письмо ~2000; Sanskrit→…→Bengali = 4 поколения.
- **Четыре корневых языка**: Vedic, Latin, Hebrew, old Chinese.
- **7 Пра́крит**: Mágadhii, Shaorasenii, Paeshácii, Páshcáttya, Pahlavii/Saendhavii, Málavii, Maháráśt́rii.
- **Эманация письма**: Bráhmii → Náradá (→Devanagari), Sáradá, Kut́ilá/Shriiharśa (→Bengali).
- **átmanepadii/parasmaepadii**: субъект «я»/«другой»; с префиксом vi — átmanepadii (vijayate).

## Теллы-сигналы
- Увидел «-diiyá» в топониме → регион был под водой.
- Увидел «-ábád» → город не старше ~700 лет (Pathan-Mughal).
- Услышал «Ámi dimure» (Barisal) → диалектное окончание, язык один.
- Слово «заканчивается на -atá» от существительного → вероятно ложная двойная абстракция (ádhikyatá).
- Встретил «неправильное» слово, принятое обществом (O.K., házrá) → принятое употребление = норма, но пометь происхождение.
