# Паттерны и приёмы анализа — Varńa Vijiṋána

## Анализ языка по восьми условиям
**Когда использовать**: спор «язык или диалект», оценка языкового статуса.
**Как**: проверь по чек-листу — (1) словарь, (2) местоимения, (3) глагольные окончания, (4) падежные окончания, (5) литература (устная/письменная), (6) интонация, (7) психоакустические/инференциальные ноты, (8) синтаксис.
**Trade-offs**: признаки «плавают» в диалектах; конституционный статус не решает вопроса.

## Этимологическая цепочка (4 поколения)
**Когда использовать**: проверка происхождения слова.
**Как**: прогони слово через Sanskrit → Prákrta → Demi-Prákrta → old Bengali → modern Bengali (пример: ámra → ámba → ámbá → ánbaa → ánb). Если цепочка не сходится — этимология ложна (kacuri «из» karcariká → kacre не существует).
**Trade-offs**: звуковые законы (ka/ta/pa/da → a в Mágadhii) обязательны; «народная этимология» чаще всего ложь.

## Определение сама́са через vyásavákya
**Когда использовать**: классификация сложного слова.
**Как**: восстанови развёрнутую фразу (какой предлог/окончание ушло) → определи тип: tatpuruśa (ушло падежное окончание), karmadháraya (rúpaka/upamita/upamána), bahuvriihi (много фраз, jáhár/játe), dvigu (число), dvandva (разные слова, o/ár), nitya (синонимы), avyayiibháva (indecclinable), supsupeti (последовательность).
**Trade-offs**: одни слова дают разные типы (gajagaman); без однозначной фразы тип не определяется.

## Отличие эманации от дисторсии
**Когда использовать**: оценка языкового изменения / новых слов.
**Как**: (1) изменение естественное (сохраняет звуковой закон) → utsárańa, продолжает путь (prastara → páthar); (2) испорченное (нарушает законы) → vivarttana, движение стоп (cikicchá из cikitsá, dápan). Три триггера дисторсии: произношение масс, аббревиация, импорт без смысла.
**Trade-offs**: принятое обществом может стать нормой (O.K., ádikhyetá), даже если «ошибочно».

## Звукоподражательная деривация корней
**Когда использовать**: поиск происхождения первичного корня.
**Как**: ищи подражание звуку (t́hak t́hak → t́hakkara; turtur → turaga) или психическую вибрацию (красное → t́akt́ak → t́akt́ake lál; белое → dhapdhap → dhavala) или сравнение-эталон (jet black, mishkálo).
**Trade-offs**: часть слов неразложима на prefix+root+suffix — принимать как данность, не изгонять.

## Проверка правописания через разбор
**Когда использовать**: длинные/трудные слова.
**Как**: разбей на prefix + root + suffix (preposition = pre+posit+ion; samabhivyáhára = sam-abhi-vi-á-hr-ghaiṋ). Удвоение после светлой гласной (acquire), суффикс меняет произношение, префикс — почти нет.
**Trade-offs**: Sanskrit — «как пишется, так и читается»; в Bengali/Hindi/English письмо расходится со звуком.

## Определение родословной по окончаниям
**Когда использовать**: генеалогия языков.
**Как**: сравни глагольные окончания (karoti → karai → kare; набоr форм «…nirbhar…» по языкам) и притяжательные маркеры (ká/kii/ke; da/dii/de; ra/ri/re). Вывод о Пра́крите-предке.
**Trade-offs**: Urdu — иная лексика, но индийская грамматика; Farsi — отдельная ветвь.

## Чтение топонимов
**Когда использовать**: история/география по именам мест.
**Как**: ищи системные суффиксы — -diiyá (остров, был под водой), d́áuṋgá (поднялся из моря), -daha (водоворот у реки), -vanii (изобилие), -Vasán (новое поселение), -d́ihi (сухое место Rarh), -sol (село на возвышенности, Austric), -ábád (Pathan-Mughal эпоха, ≤700 лет), -ganj (рынок).
**Trade-offs**: имена многослойны (Sanskrit/Austric/Dravidian/Farsi); ложная этимология по созвучию — ошибка.

## Ритмическая пара (не сама́са)
**Когда использовать**: анализ «cá-t́á», «jal-t́al».
**Как**: добавь рифмующийся «хвост» к короткому слову для ритма — это ритмическое слово, не сложное.
**Trade-offs**: усиливает живость языка, но не образует новое значение.

## Проверка заимствования
**Когда использовать**: оценка иностранных слов в языке.
**Как**: проверь семейство корня (dast/khor/ábád/stán), род по правилам принимающего языка (kalam жен. в Hindi, муж. в Urdu), чередование u/o (dukán/dokán).
**Trade-offs**: запрет заимствований вредит языку; гибриды (bhágii+dár) нормальны; ложные санскритизмы (prasráva, anushiilana) — ошибка.
