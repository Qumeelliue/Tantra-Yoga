# Глоссарий — To the Patriots

**Анти-сентимент** — чувство против угнетателя (анти-арийский, анти-буддийский, анти-мусульманский, анти-британский); объединяет, но недолговечен (Ch 1, 2).

**Ана́рья (Anárya)** — «не-арий», уничижительное имя аборигенов Индии от ариев (Ch 1).

**«Без-нация» (nationless India)** — состояние Индии без сильного сентимента (случалось неоднократно) (Ch 1, 2).

**Бенгалистан (United Socialist Bengal)** — формула Сухарварди–Сарата Боса против раздела Бенгалии; отвергнута народами (Ch 1).

**Бхи́кшу (bhikśu)** — буддийский монах; упадок бхикшу — причина гибели буддийской нации (Ch 1).

**Бху́дан (Bhúdán)** — движение Vinoba Bhave («дар земли»); по Саркару — не борьба с эксплуатацией (Ch 2).

**Группа наций (compact multinational unit)** — «совместная семья» наций на базе одной идеологии (Ch 2).

**Две нации** — модель Саркара: угнетатели и угнетённые рождают два противо-сентимента (Ch 1).

**Индийская нация** — продукт анти-британского сентимента; умерла с уходом британцев (Ch 2).

**Космическая идеология** — учение, что Единое Верховное Сущее — цель всех существ; скрепа универсальной нации (Ch 2).

**Лингвистическая провинция** — штат по языковому принципу; провал лидеров (Ch 2).

**Муслим хомланд (Muslim homeland)** — требование отдельной родины на Hindu phobia (Ch 2).

**Национальный язык** — спорный вопрос, добавивший разъединение; решение — за сильной нацией будущего (Ch 2).

**Романская письменность** — самая научная, но навязывать её живым языкам с литературой нельзя (Ch 2).

**Сарводайя (Sarvodaya)** — движение Jayprakash Narayan («подъём всех»); по Саркару — избегает анти-эксплуатации (Ch 2).

**Сентимент (sentiment)** — чувство единства; единственный создатель нации (Ch 1).

**Социальный/экономический/психологический капитализм** — эксплуатация во всех сферах, которую лидеры хотели сохранить (Ch 2).

**Универсальная нация** — финальный масштаб: вся планета/вселенная как одна нация на духовном наследии (Ch 2).

**Хинду-фобия (Hindu phobia)** — страх индусского большинства, посеянный британцами; создал требование отдельной родины → раздел (Ch 2).

**Шанкарачарья** — великий учёный-логик, способствовал гибели буддийской нации (Ch 1).

**Эксплуатация** — не только экономическая: социальная, экономическая, психологическая (Ch 2).
