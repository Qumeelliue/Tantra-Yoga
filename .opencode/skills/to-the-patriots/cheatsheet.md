# Читшит — правила решений по Саркару (To the Patriots)

## Диагностика нации / единства

| Ситуация | Правило |
|---|---|
| Заявляют «нас объединяет язык/религия/раса» | Проверь СЕНТИМЕНТ: факторы незначительны, нацию создаёт только чувство |
| Один язык у двух сообществ | Могут быть разными нациями (бенгальцы: индийцы/пакистанцы) |
| 4 языка в одном государстве | Может быть одна нация (Швейцария) |
| Объединение «против врага» | Работает временно: контр-сентимент умирает со своим источником |
| Строишь долгосрочное единство | Нужен позитивный сентимент (идеология/наследие), не только «против» |

## Стратегия изменений

| Ситуация | Правило |
|---|---|
| Освободительное движение | Веди экономическую борьбу (анти-эксплуатация), политическая придёт следом |
| Политическая борьба без экономической | Бландер: противник посеет фобии → раскол (раздел Индии) |
| Провинции/адм. деление | По экономике, НЕ по языку |
| Язык образования | Английский + максимум утверждённых языков для ответов; не закрывай студентов в провинции |
| Национальная письменность | Не навязывай «научную» письменность живым литературным языкам; решение — воля носителей |
| Мультиэтническое государство | «Совместная семья» на одной идеологии; голосование большинством дробит семью |
| Форсировать единство силой | Путь к «балканизации»; сила порождает недовольство и раскол |

## Устойчивость институтов

| Ситуация | Правило |
|---|---|
| Организация без учёных/лидеров | Умрёт независимо от массы (буддийская нация) |
| Благотворительная инициатива при угнетении | Проверь: борется с причинами эксплуатации? Если нет (Bhúdán/Sarvodaya) — подавляет боевой дух народа |

## Долгосрочный мир

| Ситуация | Правило |
|---|---|
| Хочешь устойчивого мира | Слой 1: анти-эксплуатация (нации) + Слой 2: духовное наследие + одна Космическая идеология (универсальная нация) |
| «Разоружение» против национальных чувств | Слова: пока есть нац. чувства — военные приготовления идут подпольно |

## Быстрые сигналы («tells»)

- «У нас общий язык/культура, значит мы одна нация» — вероятная ошибка; ищи сентимент.
- Движение обещает «дары» вместо борьбы за причины — вероятная подачка капиталистам.
- Реформа админ. деления по языку при слабом нац. сентименте — предвестник раскола.
- Лидер «за свободу» без экономической программы — вероятный буржуа, сохраняющий капитализм.
- Единство только «против X» — временный ресурс, планируй переход к позитивному.
