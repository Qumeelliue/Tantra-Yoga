# Глоссарий — Discourses on Neohumanist Education

**Абсолютное знание (ápta vákya)** — знание, полученное напрямую от Космического Ума через психо-духовную практику; универсально, рационально, психологично (Ch 39).

**Агарма (Ágama)** — ответы Шивы Парвати в духовной науке; нигама — её вопросы (Ch 41).

**А́чарья (ácárya)** — учитель, обучающий примерным поведением; `ácarańát páthayati yah sah ácaryah` (Ch 20).

**Ахамтаттва (ahaḿtattva)** — субъективированное «я действую»; расширенное — buddhi (интеллект) (Ch 16, 33).

**Алексированная психология (apexed psychology)** — ум, сведённый в одну точку к Высшему (Ch 29, 31).

**Апáра-джина́на (apará-jiñána)** — мирское знание (внутренняя проекция внешней физичности) (Ch 40).

**Апариграха (aparigraha)** — не принимать сверх необходимости (Yama) (Ch 26).

**Абхога (ábhoga)** — «объект наслаждения» (санскр.), точнее чем pabulum (Ch 29).

**Бодхи (bodhi)** — интуиция (расширенное mahattattva) (Ch 33).

**Брахмачарья (Brahmacarya)** — опыт присутствия Высшего во всём (Yama) (Ch 26).

**Вайшья (vaeshya)** — класс капиталистов/торговцев в социальном цикле (Ch 26).

**Вада / джалпа / витанда (váda/jalpa/vitańda)** — три ступени логики: обнаружение слабостей / аргумент победы / полное поражение противника (Ch 39).

**Верховный Субъект (Supreme Subjectivity)** — катализатор за всем знанием; присутствие, не действие (Ch 44).

**Вивека (viveka)** — совесть: финальная дискриминация «благо всех существ» (Ch 7).

**Видья (Vidyá)** — интровертивная сила; против Авидьи (экстровертивной) (Ch 3).

**Видъядхипака (Vidyádhiipaka)** — правильный термин для современного канцлера университета (не кулапати) (Ch 20).

**Видьяртхи (vidyarthi)** — начальный ученик (вне зонта гуру) (Ch 19).

**Викранти (vikránti)** — контр-эволюция (против цикла) (Ch 26).

**Випра (vipra)** — интеллектуальный класс в социальном цикле (Ch 26).

**Вишва-бхаша (vishva bháśá)** — мировой язык (Ch 1).

**Вишвавидьялая (vishvavidyalaya)** — буквальный перевод «университет», мисном (Ch 18).

**Гео-сентимент (geo-sentiment)** — любовь к родной земле; начало лестницы сентиментов (Ch 24).

**Гениальность (genius)** — врождённый дар; техник — навык, выработанный практикой (Ch 12).

**Гхарана (gharáná)** — школа музыки (Ch 43).

**Гуру-чакра (Guru cakra)** — внутренняя сторона sahasrára; точка концентрации в садхане (Ch 29).

**Джива (jiv́a)** — единичное существо (Ch 37).

**Джинана (jiñána)** — знание: субъективизация объективности (Ch 16).

**Джнана-марга (jiñána márga)** — культ знания (шаива): «что это? откуда?» (Ch 16).

**Догма (dogma)** — идея с линией, за которую нельзя выходить (Ch 17, 32).

**Дхарма (dharma)** — природа/характеристика существа (растение/животное/человек) (Ch 22).

**Ишвара-пранидхана (Iishvara prańidhána)** — вера: единица — инструмент Всевышнего (Niyama) (Ch 26).

**Итихаса (itihása)** — история как «сияющее отражение коллективной жизни» (Ch 15).

**Камамая коша (kámamaya kośa)** — грубейший слой ума, работа с индриями (Ch 36).

**Кармавада (karmaváda)** — доктрина действия/реакции; используется для оправдания бедности (Ch 21).

**Катуспатхии (catuspáthii)** — малая школа при гуру (100–1000 учеников) (Ch 9, 18).

**Катализатор (catalyst)** — метафора Верховного Субъекта (Ch 44).

**Классы A/B/C** — по совпадению мысли/слова/дела (Ch 28).

**Кош (kośa)** — слой ума: annamaya, kamamaya, manomaya, atimanása, vijinánamaya, hiranyamaya (Ch 36).

**Кранти (kránti)** — эволюция (смена возраста) (Ch 26).

**Кулапати (kulapati)** — глава гуркула (10 000 бесплатных студентов) (Ch 20).

**Кшатрий (kśatriya)** — воинский класс социального цикла (Ch 26).

**Лимфа (lymph)** — сырьё для гормонов; её количество связывают с интеллектом и духовностью (Ch 29) ⚠.

**Лока (loka)** — мир/уровень (bhuh...satya) (Ch 36).

**Ма́нава-дхарма (manava dharma)** — человеческий дхарма: vistara (расширение), rasa (поток), sevá (служение), mokśa (освобождение) (Ch 14).

**Махаттаттва (mahattattva)** — экзистенциальное «я есть»; расширенное — bodhi (интуиция) (Ch 33).

**Метаморфозированная сентиментальная стратегия** — быстрая смена сентимента оппортунистом при раскрытии прежнего (Ch 23).

**Микровита (microvita)** — витальные микроорганизмы сознания; друзья/враги по поведению (Ch 17) ⚠.

**Микрокосм** — индивидуальный ум (Ch 13).

**Микро-психические стремления** — четыре категории влечения к пáбулуму (Ch 31).

**Нандана-виджиняна (nandana vijinána)** — эстетическая наука (Ch 13).

**Неогуманизм (Neohumanism)** — любовь ко всем существам и всей вселенной (Ch 24).

**Нигама (Nigama)** — вопросы Парвати Шиве (Ch 41).

**Нияма (Niyama)** — shaoca, santośa, tapah, svádhyáya, Iishvara prańidhána (Ch 26).

**Омнисценция (omniscience)** — всезнание; только в чистом духовном слое (Ch 35).

**Пáбулум (pabulum)** — объект наслаждения (см. ábhoga) (Ch 29).

**Па́ра-джина́на (pará-jiñána)** — духовное знание (Ch 40).

**Парама Пуруша** — Верховное Сознание (Ch 39 и др.).

**Парикранти (parikránti)** — полный цикл социальной эволюции (Ch 26).

**Прана-дхарма (práńa dharma)** — кардинальная характеристика народа/расы (Ch 11).

**Прапта-вакья (prápta vákya)** — относительное знание (извне) (Ch 39).

**Прати-виплава (prativiplava)** — контр-революция (Ch 26).

**Прото-психо-духовность (proto-psycho-spirituality)** — динамичный (мерцающий) психо-духовный подход (Ch 23).

**Раса-лила (rása liila)** — космический танец Парама Пуруши (Ch 22).

**Рационалистический менталитет** — взвешивание плюсов/минусов (Ch 7).

**Садвипра (sadvipra)** — духовный революционер, следующий Yama-Niyama (Ch 26).

**Самаджа чакра (sámája cakra)** — социальный цикл (Ch 26).

**Сама-самаджа таттва (sama-samája tattva)** — право всех на еду, одежду, жильё, образование, лечение (Ch 23).

**Самскары (saḿskáras)** — ментальные реактивные моментумы (Ch 2, 37).

**Санчара/пратисанчара (saiṋcara/pratisaiṋcara)** — экстро-/интроверсивное движение Макрокосма (Ch 26, 31).

**Сатьяграха (satyágraha)** — «интеллектуальный метод насилия» (принуждение обстоятельствами) (Ch 21).

**Сахитья (sáhitya)** — литература как «шествие с мыслью о благе всех» (Ch 2).

**Сахитьяика (sáhityika)** — писатель-провидец истины (kavi) (Ch 2).

**Сиддханта (siddhánta)** — логическое решение (не просто решение) (Ch 7).

**Смрити (smrti)** — память (ре-создание воспринятого) (Ch 30, 40).

**Социо-сентимент (socio-sentiment)** — любовь к группе в ущерб другим (Ch 24).

**Синтез / анализ** — объединение / дробление (Ch 13).

**Та́либ-уль-илм (tálib-ul-ilm)** — «ищущий знания» (ученик) (Ch 34).

**Танматра (tanmátra)** — тонкая сущность ощущения (Ch 36).

**Тандава / лалита** — танец Шивы (ритм) / Парвати (мудра) (Ch 4).

**Тати́та-сахитья (tat́astha sáhitya)** — «прибрежная» литература, между временным и вечным (Ch 2).

**Тиртха (tiirtha)** — место паломничества; высший — внутри («я существую») (Ch 41).

**Трилатеральное развитие** — физическое + ментальное + духовное (Ch 5).

**Уголовный кодекс садвипр** — 4 стадии: сладкие слова → жёстче → предупреждение → меры; для исправления (Ch 27).

**Факультет знания** — механизм знания (отражение/преломление + субъективизация) (Ch 16, 42–44).

**Хирани-майя коша (hirańmaya kośa)** — тончайший причинный слой ума (Ch 36).

**Церебральная память** — воспоминание через мозг; **экстра-церебральная** — через причинный ум (прошлые жизни) (Ch 30).

**Чатуспатхии** — см. катуспатхии.

**Чатpa (chatra)** — ученик под «зонтом» одного гуру/школы мысли (Ch 9, 19).

**Шильпи (shilpi)** — художник-ремесленник (Ch 37).

**Шудра (shúdra)** — класс работников в социальном цикле (Ch 26).

**Шрути (shruti)** — «слышимое» (Веды, запоминание на слух) (Ch 9).

**Юга-самкранти (yuga saḿkránti)** — переходный возраст между эпохами (Ch 26).

**Юга-сахитья (yuga sáhitya)** — эпохальная литература (на языке народа) (Ch 2).

**Юкти (yukti)** — разум (vada+jalpa+vitanda) (Ch 39).

**Яма (Yama)** — ahiḿsá, satya, asteya, aparigraha, Brahmacarya (Ch 26).
