# Читшит — правила решений по неогуманистическому образованию (DNE)

## Образование и учитель

| Ситуация | Правило |
|---|---|
| Как учить детей | Через игру и сказки; жажда знания, а не страх |
| Как учить подростков | Идеализм («мечта будущего») |
| Как учить молодых взрослых | Идеализм + реализм |
| Выбрать учителя | По характеру/служению (самаджа-гуру), не по дипломам |
| Кто задаёт образовательную политику | Совет компетентных учителей, без политики |
| Куда вкладываться в первую очередь | Начальные школы/детсады, не колледжи |
| Образование и мораль | Знание + мораль = мирное общество |
| Экзамены | Оценивать жажду и диапазон знания, не мелочи |
| Обученность человека | Прочитал + понял + запомнил + применил |

## Знание и ум

| Ситуация | Правило |
|---|---|
| Доверять источнику | Проверь: prápta (относительное) vs ápta (абсолютное) |
| Восприятие/вывод/авторитет | Все ненадёжны (дефект знающего/времени) |
| Конфликт мозга и сердца | Слушай сердце |
| Знание vs память | Запомнить ≠ понять (память — ре-создание) |
| Запоминать | Читай вслух (глаза+язык+уши), ритм, ассоциации, дробление («ass-ass-i-nation») |
| Самопознание | Átma-jñána — единственное истинное знание; остальное — «тень» |
| Медитация | Био-психологическая: знай железы/гормоны; идеация «Субъект наблюдает» |

## Сентименты и общество

| Ситуация | Правило |
|---|---|
| Оценить мотивацию лидера | Study → плюсы/минусы → сиддханта → «благо всех» (viveka) |
| Лидер меняет сентимент | Метаморфозированная стратегия — хамелеон, разоблачай |
| Расширение любви | geo → socio → human → Neohumanism (все существа) |
| Борьба с догмой | Бескомпромиссная война, не избегание |
| Распределение ресурсов | Общая собственность; минимальный достаток всем |
| Исправление нарушителя | 4 стадии: слова → жёстче → предупреждение → мера; только виновный |
| Оценка истории | Истинная история — народа (прогресс, трудности, женщины, слабые), не царей |

## Социальный цикл и наука

| Ситуация | Правило |
|---|---|
| Кто у власти | Класс на ресурсе эпохи: shudra→kshatriya→vipra→vaeshya |
| Класс доминирует | Эксплуатирует; задача садвипры — мешать |
| Стагнация | Смерть; движение — закон жизни |
| Наука | Развивать под контролем садвипр; не «поворачивать Гангу вспять» |
| Региональное неравенство | Бартер/коммерция; не войны за ресурсы |

## Быстрые сигналы («tells»)

- «Буду учить через страх» — знания исчезнут со страхом → меняй метод.
- Студент не задаёт вопросов — жажда знания не пробуждена.
- Учитель-партиец тянет учеников в политику — недисциплина неизбежна.
- «Наша земля/раса лучшая» — гео-/социо-сентимент, сужающий любовь.
- «Всё есть в священных писаниях» — догма, блокирующая интеллект.
- Медиа в руках государства/бизнеса — жди пропаганды/эксплуатации низменного.
- Лидер говорит одно, делает другое — C-класс (или «демон в человеческом облике»).
- История только о королях — предвзятая история правящего класса.
- Учишь взрослого вора «добру» — поздно: лепили надо в детстве («зелёный бамбук»).
- Абсолютное знание (по Саркару) всегда на благо всем; относительное — проверяй.
