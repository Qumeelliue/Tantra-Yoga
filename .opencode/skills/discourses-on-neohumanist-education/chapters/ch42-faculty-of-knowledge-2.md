# Chapter 42: The Faculty of Knowledge – 2

*Дискурс от 4 мая 1980, Calcutta.*

## Core Idea

Обычное знание — частично материальное (вибрации органов → мозг → впечатление) и частично абстрактное (психические вибрации). Процесс знания: орган → нерв → мозг → ум; память — ре-создание вибраций; Dhruvásmrti — постоянная память, условие самадхи.

## Frameworks Introduced

- **Вопросы**: (1) обычное знание материально или абстрактно? — и то и другое, частично; (2) есть ли сверхсознательное знание, не связанное с телом? — см. продолжение (ch44).
- **Механика вкуса**: кислое (тамаринд, слива, тыква) → вибрация в языке → нерв → мозг (впечатление) → психические вибрации (разные для разных) → сравнение → «помню»; двойное наслаждение: вкус сейчас + воспоминание (гурман вспоминает расагуллы).
- **Две тенденции ума**: приобретение и жертвование; с эволюцией жертвование усиливается (поделиться радостью с гостем — представить, что гость наслаждается).
- **Знание через органы**: звук, прикосновение, вкус, запах, форма; рага Асояри: звук → ухо → мозг → ум; ритм заставляет ноги двигаться (высокое возбуждение — потеря контроля нервов, крики «Goal!» во сне).
- **Вывод**: большая часть процесса знания материальна, малая — абстрактна.
- **Две функции ума**: думать и запоминать. Память: вибрация → впечатление → ре-создание (реплика). `Anubhútaviśayásampramośah smrtih`; пример слона (образ → ретина → ум; заключение «это слон» по сходству).
- **Dhruvásmrti** — постоянная, неустанная память; необходимый прекурсор духовного самадхи.

## Key Concepts

- **Indriya** — орган чувств (ворота).
- **tanmátra** (контекст) — тонкая сущность ощущения.
- **smrti / Dhruvásmrti** — память / постоянная память.
- **rasagollás** — сладости (пример психической вибрации).

## Mental Models

- «Знание — мост: орган → нерв → мозг → ум; большую часть — материальная».
- «Память — ре-создание вибрации: услышал рагу — ум танцует, и ноги тоже».
- «Жертвование — высшая тенденция эволюции: поделиться радостью с гостем».

## Anti-patterns

- **Путать впечатление мозга с психическим пониманием**.
- **Считать память пассивной** — это активное ре-создание вибраций.

## Worked Example

*Кислые сливы.* Ешь тамаринд → вибрация в языке → нерв → мозг → впечатление. Ешь сливу — похожая, но иная вибрация; сравниваешь — «слива кислее/кислее». Двойное наслаждение: вкус сейчас + приятные воспоминания (гурман). Сладкое: сладких много, сладкоестель чувствует разницу. Так строится знание: материальное + абстрактное.

## Key Takeaways

1. Обычное знание частично материально, частично абстрактно.
2. Механика: орган → нерв → мозг → психическая вибрация.
3. Память — ре-создание вибраций, не пассивное хранилище.
4. Жертвование (делиться радостью) — высшая тенденция.
5. Dhruvásmrti — условие самадхи.
