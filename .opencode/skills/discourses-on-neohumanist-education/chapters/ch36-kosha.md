# Chapter 36: Kośa

*Дискурс от 31 мая 1959, Jamalpur.*

## Core Idea

Ум — не абсолютная сущность, а преобразованное состояние сознания. Пять кошей ума (от грубого к тонкому) и соответствующие локы, свидетельствующие сущности, тела макрокосма и микрокосма.

## Frameworks Introduced

- **Сознание — высшая субъективность**; ум — преобразованное состояние сознания; действует через моторные/сенсорные органы (прямые агенты) и афферентные/эфферентные нервы (непрямые). Tanmátras (тонкие сущности ощущений) отражаются/преломляются → ощущение/восприятие/концепция.
- **Качество восприятия** зависит от: здоровых объектов, здоровых ворот органов, бездефектных tanmátras, сильных нервов и citta, готового эго (ahaḿtattva). Дефект любого → неверное восприятие (глаукома → радужный спектр).
- **Kámamaya kośa** — часть ума, работающая с индриями; контролирует физические стремления микрокосма.
- **Пять кошей (в порядке грубости при саннчаре)**: hirańmaya → vijinánamaya → atimánasa → manomaya → kámamaya (от тонкого к грубому; kámamaya — самая грубая, где citta — грубое вещество).
- **Три части ума**: crude (sthúla manah — kámamaya), subtle (súkśma manah — manomaya), causal/astral (atimánasa, vijinánamaya, hirańmaya). Психологическая терминология conscious/sub-conscious/unconscious неточна.
- **Макрокосм**: ка́мамая коша Макрокосма выражена через пять рудиментарных физических факторов; макрокосм не нуждается в нервах/структурах. Единство микрокосма и макрокосма в причинном слое: «есть один причинный ум во вселенной»; через садхану — тонкое соединение.
- **Тела**: annamaya kośa (единицы) = грубое тело (sthúla deha); kámamaya + manomaya + atimánasa + vijinánamaya + hirańmaya = тонкое тело; выше hirańmaya до Puruśottama — sámánya deha. Макрокосм: ка́мамая = «грубое тело Параматмана»; остальные коши = тонкое тело; ahaḿtattva/mahattattva = астральное тело.
- **Свидетельствующие сущности**: Puruśottama свидетельствует космический причинный/тонкий/грубый ум как Virát́a (Vaeshvánara), Hirańyagarbha, Iishvara; микрокосм — как Vishva, Taejasa, Prájiṋa.
- **Локы**: bhuh (физический мир), bhuvah (грубый ментальный), svah (тонкий ментальный), mahah (сверхментальный), janah (сублиминальный), tapah, satya (причинный). Термин loka — только макрокосм.
- **Полная таблица** (макрокосм и микрокосм) сопоставляет коши, ум, свидетельствующую сущность, тело, локу.

## Key Concepts

- **Kośa** — коша (оболочка/слой ума).
- **kámamaya / manomaya / atimánasa / vijinánamaya / hirańmaya / annamaya** — коши.
- **tanmátra** — тонкая сущность ощущения.
- **ahaḿtattva / mahattattva / citta** — «я действую» / «я есть» / объективированное «я».
- **Loka** — мир/уровень (bhuh...satya).
- **Virát́a / Hirańyagarbha / Iishvara** — свидетельствующие сущности макрокосма.
- **Vishva / Taejasa / Prájiṋa** — свидетельствующие сущности микрокосма.
- **Sámánya deha** — финальная фаза тела.

## Mental Models

- «Ум — как луковица: слои (коши) от грубого ощущения до тонкого "я есть"».
- «Восприятие — цепь: объект → орган → нерв → citta → эго; рвёшь любое звено — картинка искажена».
- «В причинном слое микрокосм и макрокосм — одно; садхана это открывает».

## Anti-patterns

- **Терминологическая путаница** (conscious/subconscious/unconscious ≠ crude/subtle/causal).
- **Игнорирование роли эго (ahaḿtattva)** в восприятии.
- **Утверждение о раздельном существовании единичного причинного ума**.

## Worked Example

*Слон.* Объект (слон) передаёт tanmátras через глаз → оптический нерв → мозг (печать) → citta → свидетельствующее эго ahaḿtattva. Если глаз здоров, нерв силён, эго готово — точное восприятие. Глаукома → искажение (спектр). Так строится понимание: ум — преобразованное сознание, действующее через коши.

## Key Takeaways

1. Ум — преобразованное состояние сознания, не абсолют.
2. Пять кошей: hirańmaya...kámamaya (тонкий→грубый).
3. Три части ума: грубый, тонкий, причинный.
4. Восприятие зависит от цепочки факторов; дефект → искажение.
5. Причинные умы микрокосма и макрокосма едины; локи и свидетельствующие сущности сопоставимы.
6. Садхана соединяет тонкое с тонким — путь к единству.
