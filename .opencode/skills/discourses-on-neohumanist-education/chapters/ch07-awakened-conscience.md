# Chapter 7: Awakened Conscience (Discourse 9)

*Дискурс от 22 марта 1982, Calcutta.*

## Core Idea

Против «демонов в человеческом облике» (оппортунистов на гео-/социо-сентиментах) нужна трёхступенчатая защита: изучение → рационалистический менталитет → пробуждённая совесть (viveka).

## Frameworks Introduced

- **Корень рабства — в уме**: физическое угнетение имеет психический источник; «религиозные делецы» вредят и физически, и духовно.
- **Два вида знания**: parájinána / áptajinána (трансцендентальное, от Космического Центра, вне выгоды) vs aparájinána / práptajinána (нетрансцендентальное, о материальном мире). Здесь речь о втором.
- **Изучение (study)**: интенсивный интеллектуальный анализ — «субъективная ассимиляция объективных событий»; существует и literal (книги), и non-literal (слушание) — никто не отрезан.
- **Два дефекта знания**: (1) дефект невежества (ошибка передаётся от учителя к ученику); (2) дефект изменения времени (столица штата переехала — учебник устарел). Знание из книг не абсолютно.
- **Лестница к совести**:
  1. **Study** — изучить (с осознанием дефектов).
  2. **Рационалистический менталитет** — взвесить плюсы и минусы; логическое решение = **siddhánta** («не просто решение — логическое решение»).
  3. **Viveka (совесть)** — финальный критерий: «благо всех существ, духовное благополучие всех» — тогда «да» или окончательное «нет»; если идея может быть полезна в будущем — «нет» неокончателен.
- **Аналогия «лягушки в колодце»**: geo-сентимент — колодец; только расширяя горизонт (пруд → океан) увидишь истину; пропаганда «наша земля благодатна» при реальном импорте зерна — пример bondages geo-сентимента.
- **Псевдо-революционеры**: «голос революционеры» говорят одно, делают другое — опаснее открытых реакционеров; распознаются только трезвым анализом.
- **Siddhánta vs viveka**: siddhánta — решение по плюсам/минусам; viveka — финальное решение по критерию блага всех.

## Key Concepts

- **áptajinána / práptajinána** — трансцендентальное / нетрансцендентальное знание.
- **siddhánta** — логическое решение.
- **viveka** — совесть (финальная дискриминация по благополучию всех).
- **"vocal revolutionaries"** — голосовые революционеры (псевдо-реформисты).
- **geo-sentiment** — любовь к своей земле, ограничивающая видение.

## Mental Models

- «Изучение — первый шаг, рациональность — второй; совесть — третий: "прочитал → взвесил → решил по благу всех"».
- «Думай как лягушка, которую тащат из колодца: каждая ступень расширения горизонта — шаг к истине».
- «Знание имеет два дефекта — глупость учителя и старость учебника; проверяй всегда».

## Anti-patterns

- **Слепая вера книгам и речам**: «я прочитал — значит так» без проверки.
- **Гео-сентимент как «наша земля прекрасна» при реальной нищете** — ложь, которую надо разбить изучением.
- **Принятие чужих слов без «да/нет по благу всех»** — путь к подчинению оппортунистам.
- **Халатность к коллективу**: «важнее защитить коллектив, чем себя».

## Worked Example

*Анализ пропаганды.* Лидер раздувает «наша нация героев» и «наша вода чиста, каждый протоплазматический клекток освободится». Учёный проверяет: вода не пригодна даже для купания, страна импортирует зерно. Ступени: изучил факты → взвесил (ложь vs правда) → сиддха́нта: «не так» → критерий блага всех: распространять правду → совесть пробуждена → борется с geo-сентиментом, просвещает других.

## Key Takeaways

1. Корень угнетения — в уме; борись на уровне идей, не только фактов.
2. Изучение необходимо, но знание не абсолютно (дефекты невежества и времени).
3. Рационалистический менталитет ведёт к сиддха́нте — логическому решению.
4. Совесть (viveka) = финальный критерий «благополучие всех» — основа выбора.
5. Псевдо-революционеры опаснее открытых врагов; их распознаёт только трезвый анализ.
