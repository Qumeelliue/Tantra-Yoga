# Chapter 35: The Mind Grows in Magnitude

*Дискурс от 2 июня 1990, RU, Anandanagar.*

## Core Idea

Четыре главных психических факультета: (1) мышление (включая медитацию), (2) запоминание, (3) трансмутация/диверсия психических пáбулумов, (4) рациональность/рационализация. Мышление требует методичности; медитация — знания желёз.

## Frameworks Introduced

- **Факультет 1 — мышление**: методическое мышление даёт положительный результат; неметодическое — в основном отрицательный; учить думать методично (не растрачивать психические потенции). Медитация — «мышление с концентрацией»: требует знания расположения желёз/поджелёз, клеток мозга и их гормональной секреции; без этого медитация «не даёт плода» — нужна биология.
- **Факультет 2 — запоминание**: ассоциировать запоминаемое с психическими пáбулумами сходства/близости; физический + психический (+отчасти духовный) подход; избегать поджелёз с враждебными гормонами; связывать с качествами и корнями плекси.
- **Факультет 3 — трансмутация/диверсия психических пáбулумов**: научно менять направление стремлений; различается по человеку/группе/виду; нужны специальные тренировочные центры в разных местах мира (по типам: развитые/развивающиеся/недоразвитые; животные — для метазойных структур с чётким «я» чувством, не только инстинкт).
- **Факультет 4 — рациональность**: избегать мысли-волн физического уровня для физической рациональности; на психическом — избегать телепатии/ясновидения психического уровня; на смешанных уровнях — тоньше (телепатия на психо-духовной смеси, ясновидение на тонкой психической/грубой духовной); омнисценция — только в чистом духовном. Не гонись за оккультными силами — это плохо; только желание единства с Высшим.
- **Рационализация против догмы**: только мысль-волна с духовного плана спасёт человечество от догмы (разделения, войны); развить через ремоделирование ума; «вы — славные выражения Верховного Господа», действуйте коллективно.

## Key Concepts

- **Four mental faculties** — мышление, память, трансмутация, рациональность.
- **Transmutation / diversion of psychic pabula** — трансмутация/отвлечение психических стремлений.
- **Telepathy / clairvoyance / omniscience** — уровни оккультных сил.
- **Systalsis** (контекст, ch23) — ритмическое чередование.

## Mental Models

- «Ум — мультиинструмент: учись думать методично, помнить ассоциативно, перенаправлять стремления и рационализировать».
- «Медитация без биологии — как вождение без карты желез».
- «Оккультные силы — мишура; единственная цель — единство с Высшим».

## Anti-patterns

- **Неметодическое мышление** — растрата потенций.
- **Медитация без знания желёз** — без плода.
- **Погоня за телепатией/ясновидением/омнисценцией ради себя** — «это плохо».
- **Догма, разделяющая людей** — враг рационализации.

## Worked Example

*Студент готовится к экзамену.* Методично думает (структурирует), запоминает через ассоциации (подобные пáбулумы), использует глаз+язык (чтение вслух) для двойной фиксации, ассоциирует с плекси; когда устаёт — трансмутирует стремление; не поддаётся оккультным соблазнам, стремится к духовной цели.

## Key Takeaways

1. Четыре психических факультета: мышление, память, трансмутация, рациональность.
2. Мышление должно быть методичным; медитация требует биологии (желёз/гормонов).
3. Память — через ассоциации и физико-психический подход.
4. Трансмутация стремлений — обучаемая наука (тренировочные центры).
5. Оккультные силы не цель; рационализация с духовного плана побеждает догму.
