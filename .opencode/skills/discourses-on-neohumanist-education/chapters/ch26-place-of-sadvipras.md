# Chapter 26: The Place of Sadvipras in the Samája Cakra

*Дискурс от 4 июня 1959.*

## Core Idea

Социальный цикл: shudra → kshatriya → vipra → vaeshya → shudra (samája cakra). Садвипры (следующие Yama-Niyama) — активные стражи цикла, не дающие доминирующему классу эксплуатировать.

## Frameworks Introduced

- **Цикл классов**:
  - **Shúdra Age**: все работники физического труда; сила правит; «жизнь груба, но не жестока» (нет интеллектуальной эксплуатации).
  - **Kshatriya Age**: военная мощь; герои-гиганты без интеллекта; наследственность силы.
  - **Vipra Age**: интеллектуальная эксплуатация; паразиты-интеллектуалы; сохраняют власть через суеверия и кастовую систему (Hindu caste system — пример).
  - **Vaeshya Age**: капитализм, деньги; laissez-faire → монополия немногих; масса — «рабы капиталистов» (shudra-рабы).
  - **Shúdra revolution**: недовольство масс → организованное восстание; лидеры — «тоже kshatriya» → цикл повторяется.
- **Термины цикла**: эволюция = kránti; переход между эпохами = yuga saḿkránti; полный цикл = parikránti; контр-эволюция (сила против цикла) = vikránti; быстрый контр-переворот = prativiplava (counter-revolution; аналог отрицательного пратисаинчары).
- **Sadvipra**: духовный революционер, следующий Yama-Niyama, работающий планово для возвышения людей.
- **Yama (5)**: ahiḿsá (не причинять страданий мыслью/словом/делом), satya (действие/слово для реальной пользы), asteya (не-кража, включая ум: «отказаться от желания чужого»), aparigraha (не принимать сверх необходимости), Brahmacarya (опыт присутствия/власти Высшего во всём).
- **Niyama (5)**: shaoca (чистота тела и ума), santośa (довольство результатом своего труда), tapah (усилия к цели вопреки дискомфорту), svádhyáya (изучение и усвоение духа книг), Iishvara prańidhána (вера: каждая единица — инструмент в руках Всевышнего, искра верховного огня).
- **Задача садвипры**: не дать доминирующему классу эксплуатировать (эксплуататоры деградируют сами, эксплуатируемые не могут расти); может применять силу: против kshatriya — физическую; против vipra — интеллектуальную революцию; против vaeshya — выигрывать выборы (демократия — их оружие).
- **Демократия не решает** (см. ch3): классовое доминирование, относительные истины, подкуп голосов.

## Key Concepts

- **Samája cakra** — социальное колесо/цикл.
- **Yama / Niyama** — десять моральных принципов.
- **Sadvipra** — духовный революционер-страж.
- **kránti / vikránti / prativiplava / yuga saḿkránti / parikránti** — термины изменения цикла.

## Mental Models

- «Цикл не остановить (стагнация = смерть); задача — не дать доминанту эксплуатировать».
- «Каждый класс поднимается на незаменимом ресурсе эпохи — и эксплуатирует на нём».
- «Садвипра — не наблюдатель: активный страж, применяющий силу при необходимости».

## Anti-patterns

- **Классовое доминирование в любой форме** — эксплуатация и деградация всех.
- **Кастовая система как инструмент vipra-власти**.
- **Капиталистическая монополия** (демократия как оружие ваешьев).
- **Слепая вера в «эволюцию»** без активного вмешательства садвипры.

## Worked Example

*Смена эпох.* Первобытные shudra-работники; сила даёт вождей-kshatriya; интеллект (наука, управление) даёт власть vipra-паразитам; торговля и деньги — vaeshya; большинство снова shudra-рабы капитала; их восстание (лидеры — снова kshatriya) замыкает цикл. Садвипра не даёт никому из них узурпировать.

## Key Takeaways

1. Социальный цикл: shudra → kshatriya → vipra → vaeshya → shudra.
2. Каждый класс в свою эпоху эксплуатирует; задача садвипры — мешать этому.
3. Yama-Niyama — моральная база садвипры.
4. Эволюция (kránti) неостановима; стагнация = смерть.
5. Садвипры применяют разные силы против разных доминантов (физич/интеллект/выборы).
