# Chapter 3: Social Psychology

*Дискурс 1957, Jamalpur (из Táttvika Praveshiká).*

## Core Idea

Для существования общества необходимы три фундамента: **единство**, **социальная безопасность** и **мир** (= психическое равновесие). Под каждым — конкретные механизмы Ananda Marga: общий идеал (Brahma), бескастовость, коллективные функции, отсутствие капитального наказания; отсутствие несправедливости (экономической/половой/расовой) и дисциплина; духовные практики против суеверий.

## Frameworks Introduced

- **Единство**: исчезновение обществ — из-за эгоизма, групп по интересам, непонимания. Обеспечивается:
  - **общим идеалом**: «общий идеал войны» — временный; Ananda Marga сеет идеал Brahma с 5 лет ⚠ (возраст к калибровке); экономический общий идеал — земля = общая собственность (мантра Saḿgacchadhvaḿ).
  - **бескастовым обществом**: без групп с привилегиями; guru bhái (единоверцы) вместо játa bhái (каста); с рождения (Námakarańa) до смерти (Shráddha Kriyá); семьи с «провинившимся» не изгоняются.
  - **коллективными социальными функциями**: milita snána (совместное купание), dharmacakra (коллективная медитация); общее действие — единство и терпимость.
  - **без капитального наказания**: остракизм = гибель общества; в Marga — только временное отстранение от функций + привести 10 человек на путь ⚠; исправительный, не оставляющий клейма.
- **Социальная безопасность**:
  - **без несправедливости**: экономической (достоинство труда: «работа мусорщика уважаемее зависимости»; против hoarding-инстинкта — общая собственность), по полу (равенство ответственности, брак на равных, духовные практики для женщин), по расе (пример Гитлера и Harijans; первый шаг — забыть расу/касту).
  - **дисциплина**: законы рациональны и изменяемы; «сначала послушание, потом спор» — аргумент после соблюдения, иначе indiscipline.
- **Мир = психическое равновесие**:
  - **духовные практики** дают равновесие; **суеверия** разрушают. nivrtti (прекращение страданий): sámayikii (временное; artha — физическое) vs atyantikii (вечное; Paramártha через са́дхану).
  - борьба с суевериями трёх сфер: социальной (ведьмы, вдовы — равны незамужним), психической (призраки — игра ума; shráddha/да́на «через Ваетарни» — мистификация), духовной (рай/ад, страх Бога).

## Key Concepts

- **unity / social security / peace** — три фундамента.
- **общий идеал** — Brahma (сеется с 5 лет ⚠); мантра Saḿgacchadhvaḿ.
- **guru bhái / játa bhái** — единоверцы / кастовые родственники.
- **Námakarańa / Shráddha Kriyá** — церемония имянаречения / похоронный обряд.
- **milita snána / dharmacakra** — совместное купание / коллективная медитация.
- **nivrtti (sámayikii / atyantikii)** — прекращение страданий (временное / вечное).
- **artha / Paramártha** — временное облегчение / вечное освобождение.
- **без капитального наказания** — только временное отстранение + 10 человек ⚠.

## Mental Models

- «Единство строится общим идеалом и общими действиями, а не подавлением различий».
- «Наказание должно исправлять, не клеймить: остракизм убивает общество».
- «Безопасность = отсутствие несправедливости + дисциплина с рациональными изменяемыми законами».
- «Мир — равновесие ума: духовные практики успокаивают, суеверия раскачивают».

## Anti-patterns

- **Кастовые/классовые привилегии и деления** — разрушают единство.
- **Капитальное наказание (смерть/остракизм)** — деградация общества и индивида.
- **Дискриминация по полу/расе/труду** — угроза безопасности.
- **Неспор после послушания / спор до него** — дисциплина требует порядка «сначала исполни, потом предлагай».
- **Суеверия любой сферы (призраки, рай/ад, вдовство-ограничения)** — разрушают психическое равновесие.
- **Гарантия минимума без условий труда** — психология лени (ср. Ch 9 Part 2).

## Worked Example

*Наказание без клейма (разобран автором).* Вместо изгнания/смерти провинившемуся — временное отстранение от социальных функций; чтобы вернуться, привести десятерых на верный путь ⚠. Период — исправление и служение, без клейма для семьи; общество не раскалывается.

## Key Takeaways

1. Общество держится на единстве, безопасности и мире (равновесии ума).
2. Единство: общий идеал (Brahma) + бескастовость + коллективные функции + без кап. наказаний.
3. Безопасность: без несправедливости (труд/пол/раса) + дисциплина («сначала послушание, потом спор»).
4. Мир: духовные практики (atyantikii nivrtti через Paramártha) против суеверий трёх сфер.
5. Наказания — исправительные, без клейма; остракизм губителен.
6. Сравни: минимальный идеал — общий для всех, экономика — общая собственность.
