# Читшит — правила решений по Саркару (Nutshell 3)

## Революция и общество

| Ситуация | Правило |
|---|---|
| Масштабное изменение | Меняй 4 сферы связанно: экономика, социум, мышление, дух |
| Классы/статусы | Развивай все роли в каждом (ум/тело/труд/экономика) — универсальная пригодность |
| Бесклассовое общество | Достигается практикой, не провозглашением |
| Аудит законов | Спроси: кто писал и в чью пользу? Нужен общий вечный идеал |
| Мир | Реален и является манифестацией Высшего; работа в нём — садхана |

## Социальная психология (триада)

| Ситуация | Правило |
|---|---|
| Единство | Общий идеал + бескастовость + коллективные функции + без кап. наказаний |
| Безопасность | Без несправедливости (труд/пол/раса) + дисциплина («сначала послушание, потом спор») |
| Мир | Равновесие ума: практики дают, суеверия разрушают |
| Наказание | Исправительное, без клейма (временное отстранение + реституция), не остракизм |
| Суеверия | Три сферы: социальные (вдовы), психические (призраки), духовные (рай/ад) — борись |

## Критика чужих философий

| Ситуация | Правило |
|---|---|
| Теория «мир — иллюзия» (Shankara) | Требует свидетеля и основы («без верёвки не ошибиться змеёй»); Máyá ≠ Prakrti |
| Дуализм (Sáḿkhya) | Prakrti — сила Puruśa, не сторонняя сущность |
| «Всё анади» (Árya Samája) | Снимает нужду в прогрессе и садхане |
| Марксизм | Теоретическое равенство, питание бедностью, насилие |
| Буддизм | Принимает карму/перерождение → должен принять átman |
| Валидация | Три прама́н́а: pratyakśa (восприятие), anumána (вывод), ágama (авторитет) |

## Q&A — практические правила

| Ситуация | Правило |
|---|---|
| dharma | «То, что держит» (свойство); универсально; ≠ религия |
| Svabháva | Индивидуальная природа, меняется |
| Медитация | Dhárańa — внешнее, прерывистое (кадры); dhyána — внутреннее, непрерывное (поток масла) → samádhi |
| Satya | Неизменное, вне времени/места/личности; история/время — относительны |
| Память | В citta (семя), не в мозге; болезнь мозга ≠ болезнь ума |
| Призраки/боги | Галлюцинации слабого ума; экзорцизм лечит нервы, не мантры |
| Идолы | Конечная форма не освобождает; идеация на грубом деградирует |
| Ритуалы vs са́дхана | Ритуал = preya (выгода); са́дхана = nivrtti (освобождение) |
| Популяризация | Конструктивная работа, не критика |
| Саньяси-эскапизм | Бегство от мира не освобождает |
| Экономика | По time/place/person, не универсальная теория |
| Против зла | Только ненасилие недостаточно — нужна и сила/давление |

## Кос́-видьи (иерархия влияния ума)

| Влияющий слой | Влияемый слой | Название |
|---|---|---|
| маномайя | камамайя → аннамайя | bhútavidyá (гипноз) |
| атиманас | маномайя | paeshácii vidyá |
| виджнянамайя | атиманас | gándharva vidyá (музыка/танец/живопись) |
| хира́нмайя | виджнянамайя | daevii vidyá (киртан/бхаджан) |
| satya/átman | хира́нмайя | bráhmii vidyá |
| átman → átman | — | brahmii ákarśańa (krpá) — Sadguru |

## Быстрые сигналы («tells»)

- Законы/правила пишет доминант — вероятно, себе в пользу.
- «Мир неважен» в теории — вероятен эскапизм/эксплуатация.
- Перманентный бан/изгнание в сообществе — разрушает общество, нужна исправительная санкция.
- Практика сулит деньги/славу/материю — путь preya, не са́дхана.
- «Сделаем всех равными» — против закона природы (разнообразие).
- Критика как метод продвижения — связывает с осуждённым; делай пример.
- Теория обещает «вечную» экономику — применима к t/p/p, не универсальна.
