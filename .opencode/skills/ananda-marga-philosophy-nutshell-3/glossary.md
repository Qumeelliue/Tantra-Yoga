# Глоссарий — Ananda Marga Philosophy in a Nutshell Part 3

**Ananda Marga** — революция в экономике, социуме, мышлении и духе одновременно (Ch 1).

**Árya Samája** — школа: всё anádi → нет прогресса/садханы; yajiṋa-ритуалы; pralaya — противоречие (Ch 2).

**Ádhára** — основа ограниченного; без неё átman сливается с Brahma (вода из чаши в пруд) (Ch 4).

**Brahma sádhaná** — главная цель; конструктивная работа — её часть (Ch 5).

**Bráhmii vidyá / brahmii ákarśańa (krpá)** — влияние satya/átman на кос́ы; путь Sadguru (Ch 4).

**Bhútavidyá** — гипноз: маномайя влияет на камамайю → аннамайя (Ch 4).

**Caturárya satya** — четыре благородные истины буддизма (duhkha/причина/прекращение/путь) (Ch 2).

**Citishakti / preraná** — сила сознания / вдохновение (магнит-железо) (Ch 4).

**Daevii vidyá** — влияние хира́нмайи на виджнянамайю (киртан/бхаджан) (Ch 4).

**Dharma** — «то, что держит» (dhr), свойство; НЕ религия/mazhab; универсально и неизменно (Ch 4, 5).

**Dharmacakra / milita snána** — коллективная медитация / совместное купание (Ch 3).

**Dhárańa** — citta принимает формы ВНЕШНИХ объектов (прерывисто, статично, tamoguńi) (Ch 4).

**Dhyána** — только ВНУТРЕННИЙ объект; непрерывно (taela dhárá), динамично, rajoguńi; ведёт к samádhi (Ch 4).

**Gándharva vidyá** — влияние виджнянамайи на атиманас (музыка/танец/живопись) (Ch 4).

**Guru bhái / játa bhái** — единоверцы / кастовые родственники (Ch 3).

**Jiiva mátra** — «все живые существа» (Ch 1).

**Karma / karmaphala** — действие (samvedana+kriya) / результат-реакция (Ch 4).

**Kośa-видьи** — иерархия влияний слоёв ума (от bhútavidyá до bráhmii) (Ch 4).

**Mahattattva / 25 tattvas** — «Я существую»; 8 форм Prakrti + 16 vikrti + 1 = 25 ⚠ (Ch 4).

**Máyá (Shankara)** — иллюзия; критикуется: требует свидетеля и основы; ≠ Prakrti Ananda Marga (Ch 2, 5).

**Marxiиkayá** — теоретическое равенство, питание бедностью, нетерпимость, насилие (Ch 2).

**Milita snána** — см. Dharmacakra (Ch 3).

**Nivrtti (sámayikii / atyantikii)** — прекращение страданий (временное через artha / вечное через Paramártha) (Ch 3, 5).

**Paeshácii vidyá** — влияние атиманаса на маномайю (ментальная сила → физическое действие) (Ch 4).

**Pratyakśa / anumána / ágama** — три прама́н́а (восприятие/вывод/авторитет) (Ch 2).

**Puruśottama (guńaadaniish)** — контролёр guńa, за их периметром; не Nirguńa (есть witness) (Ch 5).

**Samvedana / prati-samvedana** — психическая волна / психическая реакция (Ch 4).

**Samája cakra** — социальный цикл (контекст Ch 1; подробно — Part 2).

**Saḿgacchadhvaḿ…** — мантра единства/общей собственности (Ch 1, 3).

**Satya / asatya** — неизменное вне t/p/p / относительная истина (Ch 4).

**Svabháva** — индивидуальная психическая природа (sva+bháva), меняется (Ch 4).

**Sañnyásii-эскапизм** — бегство от мира/долгов/страха; Гималаи — тоже мир (Ch 5).

**Trikálajiṋa** — знающий прошлое/настоящее/будущее (через са́дхану к Satya) (Ch 4).

**«Тень тени»** — ум ест tanmátras (тень), объект — мыслеволна Cosmic Mind (тень) (Ch 5).

**Универсальная пригодность** — каждый практикует качества всех четырёх классов (Ch 1).
