# Читшит — правила решений по Саркару (Subháśita Saḿgraha 14)

## Йога и тантра

| Ситуация | Правило |
|---|---|
| «Йога = сложение (2+2=4)» | Нет: это сложение; йога = объединение (сахар+вода, идентичность растворяется) |
| «Йога = подавление пропенсити» (Patanjali) | Отвергни: ум-пустыня, не с чем объединяться |
| «Йога = безмыслие» | Отвергни: сон/бессознательность тоже «безмыслие»; йога = saḿyoga (объединение) |
| Что такое тантра | ta (тупость) + tra (освободитель); также tan = «расширять» → освобождение через расширение |
| Йога vs тантра | Практически одно; различие только в языке |
| Ритуальная/замкнутая практика | Не тантра: нет расширения ума |
| Признак «связанный/свободный» | `Páshabaddha jiivah, páshamuktah Shivah` — путы → jiiva, свобода → Shiva |

## Градации бхакти

| Ситуация | Правило |
|---|---|
| «Навреди моим врагам» | Támasikii (статичная) — избегай, ведёт к деградации |
| «Дай мне прогресс/финансы/повышение» | Rájasikii (мутативная) — цель не Он |
| «Соблюдаю из приличия» / «прекрати мои страдания» | Sáttvikii (сентиентная) — всё ещё не «хочу Тебя» |
| «Хочу Тебя одного, ничего больше» | Kevalá bhakti — единственная плодоносящая |
| «Поклоняюсь ради блаженства» | Ráganugá — лёгкий эгоизм |
| «Служу, чтобы Ты блаженствовал» | Rágátmiká — высшая; преданный = gopa |
| Как достичь Parama Puruśa | Только rágátmiká bhakti; не тщеславием джнаны, не беспокойством кармы |

## Быстрые сигналы («tells»)

- Молитва с императивом «дай/сделай/убери» — градация ниже kevalá.
- Практика, после которой ум не расширяется, — не тантра (нет освобождения от тупости).
- Слышишь «gopa = пастух» — ошибка; gopa = «дающий удовольствие Господу».
- Обещание достичь цели «знанием» или «действием» без преданности — не приведёт.
- Метод, требующий «опустошить ум» как terminus — пустыня/сон, а не йога.
