# Cheatsheet — Yoga Sádhaná

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Что такое йога? | `Samyogo yoga ityukto jiivätma-Paramätmanoh` — объединение, не подавление (ch01). |
| Хочешь классифицировать определение йоги | Отвергай cittavrttinirodhah и «безмыслие»; принимай объединение (ch01, ch08). |
| Йог и атеизм | Йог обязан быть теистом (jiivātmā + Paramātmā + veda) (ch02). |
| Как отличить дхарму от сектантства? | Дхарма объясняет 5 коз и ведёт к совершенству; сектантство застревает на manomaya (ch04, ch05). |
| Какая пища для садхаки? | Sāttvika: рис, пшеница, бобовые, фрукты, молоко; избегай тамасичной (лук, чеснок, грибы, мясо, рыба, яйца) (ch06). |
| Асаны: с чего начать? | Никогда без разрешения ачарьи; индивидуальный подбор (ch12). |
| Пранаяма: правило | С космической идеацией (иначе хатха-пранаяма); 3→7 кругов, ≤4 раза/день; шуддхи (ch13). |
| Концентрация или медитация? | Внешний/прерывистый объект = дхарана; внутренний/непрерывный = дхьяна (ch15, ch16). |
| Объект медитации «убегает» | Анудхьяна: преследуй Его, не сдавайся (ch16). |
| Молиться или практиковать? | `Prärthanärcanä mätraeiva bhramamülam` — молитва ошибка; практика — усилие к цели (ch16). |
| Хочешь управлять поведением | Работай через железы (асаны/диета); страх = manipura (ch09, ch06). |
| Пратьяхара без направления | Нельзя — буря в подсознании; направляй к читте→ахам→махат→Когнитивному (ch14). |
| Жить в миру и практиковать | Madhuvidyä: каждое действие с космическим чувством (ch14). |
| Классификация бхакти | Гāonī (тамас/раджас/саттва/ваидхи/джнянамишра) — низшая; kevalā/rāgātmikā — высшая; принимай rāgātmikā (ch19). |
| Бхакти — путь или цель? | Цель; karma − jñāna = bhakti (ch20). |
| Кто может быть гуру? | Mahākaola: знает теорию+практику, языки+шастры, умеет наказывать и благословлять (любовь≥наказания) (ch21). |
| Мантра не работает? | Без идеации (mantra-caetanya) и purashcarana — бесполезна; нужна siddha-мантра (ch22). |
| Как возвращаться «домой»? | shravana (слушание) → manana (размышление) → nididhyäsana (слияние); отдай «Я» (ch23). |
| Что делать с «Я сдал всё»? | Сдай и само «Я» — иначе эго остаётся (ch23). |
| Самадхи — заслуга? | Только милость Параматмы; усилие подготавливает (ch17, ch18). |
| Четыре стадии samprajñāta | savitarka → savicāra → sānanda → sāsmitā → исчезновение асмиты = asamprajñāta (ch17). |
| Стадии слияния | sālokya → sāmiipya → sāyujya → sārupya → sārsthi → kaevalya/nirvikalpa (ch18). |
| Обоняние и микро-вита | Тонкие выводы (звук) → positive микро-вита; грубые (запах) → negative; но запах+тонкая идея = positive (ch25). |
| Женщины и духовность | Равные права; аргументы против — эксплуататорские (ch09, ch25). |
| Ежедневная практика садхака | Дважды в день (утро/вечер) + еженедельный дхармачакра (ch11, SUPREME COMMAND). |
| Тайный мантра-фокус жизни | bhavisca: bha (Бхагаван), vi (vinay), sa (samyam), ca (caritra) (ch28). |

## Ключевые формулы

- Йога: `Samyogo yoga ityukto jiivätma-Paramätmanoh`.
- Бхакти: `karma − jñāna = bhakti`.
- Пропенсивности: 50 × 2 × 10 = 1000.
- Коза→практика: annamaya→asana, kāmamaya→yama-niyama, manomaya→prānāyāma, atimānasa→pratyāhāra, vijñānamaya→dhāranā, hiranmaya→dhyāna.
- Ишвара-пранидхана: «Oneness in objectivity → oneness in subjectivity».
- Молитва: `Prärthanärcanä mätraeiva bhramamülam`.
- Исключения: без них нет эволюции (ch29).
