# Glossary — Yoga Sádhaná

**Ācārya / Ācāryā** — квалифицированный духовный учитель, обучающий всем урокам медитации.
**Ābhoja** — «психическое пропитание»: ум принимает форму объекта.
**Abhidhyāna** — pranidhāna + anudhyāna: ум непрерывно поглощён идеацией Высшего.
**Aham / aham-tattva** — «делатель Я», эго, вторая ментальная субъективность.
**Ahimsā** — ненасилие (не наносить вреда мыслью или делом).
**Anāhata cakra** — четвёртый психо-духовный центр (середина груди); 12 пропенсивностей.
**Anandam** — божественное блаженство; Брахма.
**Anudhyāna** — преследование объекта медитации («не отпущу Его»).
**Aparigraha** — удовлетворение минимумом жизненных необходимостей.
**Asana** — третья ступень аштанга-йоги: позы для физического и психо-физического здоровья.
**Asat** — ложь/небытие (противоположность Sat).
**Astaunga / astāungika yoga** — восьмиступенчатая йога.
**Asteya** — не присваивать чужого.
**Ātmā / ātman** — душа, сознание, чистая когниция.
**Avidyāmāyā** — центробежная/экстроверсивная сила Пракрити.
**Bāpā** — «дорогой»; ласковое имя Парама Пуруши/Анандамурти.
**Bhagavān** — обладатель bhaga (6 атрибутов); Господь.
**Bhāgavata dharma** — дхарма человека: vistāra (расширение), rasa (поток), sevā (служение), tadsthiti (реализация Высшего).
**Bhajana** — индивидуальное повторение имени Бога (слышишь сам).
**Bhakta** — преданный; **Bhakti** — преданность.
**Bhāva** — выраженная вселенная; также ступень экстаза (см. dashā/bhāva/mahābhāva).
**Bīja mantra** — акустический корень; звук, из которого проистекает действие.
**Brahma** — Высшая Сущность (Пуруша + Пракрити).
**Brahma cakra** — Космический Цикл (saincara → pratisaincara).
**Brahmacarya** — «пребывать привязанным к Брахме» (видеть Брахму во всём), НЕ воздержание.
**Cakra (plexus)** — психо-духовный центр вдоль сушумна-канала (см. ch09).
**Caraeveti** — «продолжай, продолжай» (двигайся вперёд).
**Caritra** — характер = сумма всех действий индивида.
**Citta** — «сделанное Я», объективированное «Я», ум-субстанция.
**Cittabhūmi** — ум-вещество, принимающее форму объекта (эктоплазм).
**Dagdhābīja** — «сожжённое семя»: санскары/прарабдха полностью истощены.
**Dashā / bhāva / mahābhāva** — ступени божественного экстаза (см. ch18).
**Dhāranā** — шестая ступень: удержание ума на точках тела; статична.
**Dharma** — присущее свойство; путь праведности.
**Dhyāna** — седьмая ступень: медитация, непрерывный поток к Сознанию.
**Dīpanī** — «факел света» (первая фаза дикши).
**Dīksā** — инициация; Tāntrikī (полная) vs Vaidikī (очищение).
**Gāonī bhakti** — низшая преданность (с тремя гунами, ваидхи, джнянамишра).
**Gopāla** — «контролёр чувств» (go = органы чувств), не «пастух».
**Guru** — «рассеиватель тьмы» (gu + ru).
**Guru cakra** — внутренняя сторона сахасрары; точка дхьяны.
**Gurukrpa** — милость гуру (начало, середина, конец).
**Iishvara prahidhāna** — «движение к Высшему Убежищу»; ментальная практика.
**Ista** — любимый объект; личный Бог.
**Jada** — грубое.
**Jīva / jīvātmā** — единичная сущность/душа.
**Jñāna** — знание; духовное самопознание.
**Kāmamaya kosa** — «грубый ум».
**Kaola / Mahākaola** — гуру, поднимающий кундалини свою / свою и других.
**Kāpālika sādhanā** — практика, заставляющая столкнуться со всеми внутренними узами.
**Karma** — действие; иногда действие, порождающее санскары.
**Kosa** — оболочка ума (5 штук; см. ch04).
**Krsna** — Парама Пуруша; великий тантрический гуру (~1500 до н.э.⚠), второй Tāraka Brahma.
**Kundalinī / kulakundalinī** — «спящая божественность» у основания позвоночника.
**Lalanā cakra** — чакра между vishuddha и ājinā.
**Mantra** — звук, который ведёт к освобождению; «инкантативный, пульсирующий, идеативный».
**Mantrāghāta** — удар акустического корня по кундалини (пробуждение).
**Mantra-caetanya** — пробуждение мантры (концептуальное понимание + психическая ассоциация).
**Mahātma / Mahattattva** — «Я существую», экзистенциальное «Я».
**Mahāpuruṣa** — высокоэволюционировавший психо-духовно человек.
**Māyā** — Пракрити в фазе творения; иллюзия конечного.
**Microvitum** — тонкая сущность между физическим и психическим.
**Moksa** — духовное освобождение, неквалифицированное.
**Mudrā** — упражнение как асана, но с большей идеацией.
**Mūlādhāra cakra** — нижний центр (основание позвоночника); 4 пропенсивности.
**Nadī** — канал психической энергии; нерв.
**Nididhyāsana** — непрерывная медитация с неразрывным потоком.
**Nirvikalpa samädhi** — полная остановка ума; мокша.
**Ota yoga / Prota yoga** — индивидуальная / коллективная связь Пурушоттамы.
**Pāpa / pātaka / pratyavāya** — грех / грех (нарушение «нельзя» + неисполнение «должен»).
**Parābhakti** — высшая преданность.
**Parama Purusa** — Высшее Сознание; **Paramātmā** — свидетель.
**Prāna** — витальная энергия (10 потоков: prāna, apāna, samāna, udāna, vyāna, nāga, kūrma, krkara, devadatta, dhanainjaya).
**Prānāyāma** — четвёртая ступень: контроль витальной энергии через дыхание.
**Pratyāhāra** — пятая ступень: отведение ума от чувств.
**Prakrti** — Космический Оперативный Принцип (sattva/rajah/tamah).
**Purusottama** — Ядро-сознание (Nucleus Consciousness).
**Rājādhirāja yoga** — высшая йога: физическое → ментальное → квалифицированное → неквалифицированное духовное.
**Rasa** — космический поток; вкус; «Rasah vae sah» — Он — воплощение потока.
**Sadhana** — «устойчивое усилие»; духовная практика.
**Sadguru** — великий гуру; канал Tāraka-Brahmas.
**Saguna / Nirguna Brahma** — атрибутивный / не-атрибутивный Брахма.
**Saincara / pratisaincara** — экстроверсия к грубости / интроверсия к Сознанию.
**Samädhi** — «поглощение» ума в Космическом или ātman.
**Samprajñāta / asamprajñāta** — термины Патанджали (см. ch18).
**Samskāra** — реактивная ментальная инерция; результат кармы.
**Samyama** — регулируемое поведение.
**Sat / satya** — «неизменное»; истина.
**Satsaunga** — хорошее общество (полезное для духовного роста).
**Sāttvika / rājasika / tāmasika** — саттвичное / мутативное / статичное (гуны, пища, практики).
**Savikalpa samädhi** — самадхи с ощущением второй сущности.
**Sevā** — одностороннее служение без выгоды.
**Shraddhā** — почитание, veneration.
**Shravana / manana / nididhyäsana** — слушание / размышление / непрерывная медитация.
**Sūtra** — афоризм («семя многих слов»).
**Tantra** — tan+tra+da: «расширение + освобождение»; практический культ.
**Tāraka Brahma** — касательная точка между Saguna и Nirguna; Гуру-принцип.
**Vairāgya** — непривязанность (не отвращение).
**Vaidhī bhakti** — преданность по правилам писаний без любви.
**Vāyu** — витальный воздух/поток энергии.
**Vrtti** — пропенсивность, выражение ума (50 основных / 1000 всего).
**Yama / niyama** — первые две ступени аштанга-йоги (5+5 принципов).
