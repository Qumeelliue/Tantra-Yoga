# Chapter 12: Asanas, Mudräs and Bandhas

*Из Ananda Marga Caryacarya Part 3 и Shabda Cayanika.*

## Core Idea

Асаны — практика управления пропенсивностями через железы; практические примеры асан, мудр и бандх. Ключевое правило: **никогда не практиковать без разрешения ачарьи** (индивидуальный подбор по телу, санскарам, времени).

## Frameworks Introduced

- **Почему асаны нужны**: пропенсивности возбуждаются дефектами желёз; даже искренние люди не могут сосредоточиться, пока ум экстровертирован железами. Асаны исправляют железы → контроль пропенсивностей.
- **Mudrā vs Asana**: мудры — почти то же, но с большей идеацией; правил по ноздрям нет.
- **Примеры асан** (продолжительность — половина минуты, 4 раза; ⚠ дозировки к калибровке):
  - Utkatā-kūrmakāsana (сложная черепаха) — артрит/тяжёлые грузы.
  - Jatila-utkatāsana (сложный стул) — бери-бери, слоновая болезнь, военные/полиция.
  - Utkata-pashcimottānāsana — сифилис, дуоденальная язва, диабет, подагра, туберкулёз, астма, ожирение и др. (⚠).
  - Kukkutāsana (петух) — туберкулёз, слабость рук/ног.
  - Tulādandāsana (баланс) — слабость ног, спортсмены, подростки.
- **Мудры**: Utksepa (утром в постели + стакан воды), Uḍḍayana (подтягивание живота, 8 сек), Vāyavī (надавливание на груди, 7 раз, концентрация на anāhata). Полезны для кишечника, поджелудочной, астмы/давления.
- **Бандхи**: Jālandhara-bandha (зажим подбородка, контроль голоса, «водяной барьер» Jallundhar); Bandhatraya yoga: Mahāmudrā, Mahābandha, Mahāvedha — комбинация с задержкой дыхания и фиксацией на чакрах (полминуты).
- **Sītkārī mudrā** — древние упражнения с водой для кровотока.

## Key Concepts

- **kūrma nādī** — канал голосовых связок; vāyus — десять витальных воздухов.
- **pressurizing/depressurizing** — механизм влияния асан на железы (см. ch09).
- **Ācārya/Ācāryā** — квалифицированный духовный учитель; без его разрешения — риск.
- **Shavāsana, массаж** и др. — из Caryacarya Part 3 (37 асан описаны там).

## Mental Models

- **Тело → железы → ум**: асанная практика как рычаг над пропенсивностями.
- **Индивидуализация**: нет универсальной программы для всех.

## Anti-patterns

- **Практика без ачарьи** — «не рискуй, практикуя асаны и мудры без разрешения ачарьи».
- **Асаны как самоцель** — «несколько асан не делают йогом» (ch01).

## Worked Example

Практика Mahāmudrā: сядь, прижми левую пятку к mūlādhāra, вытяни правую ногу; вдохни, сократи сфинктер, захвати стопу руками, удерживай jālandhara-bandha полминуты; выдохни, расслабься. Полезно при дизентерии, диарее, диспепсии, семенной слабости (⚠).

## Key Takeaways

1. Асаны управляют пропенсивностями через железы.
2. Без разрешения ачарьи практиковать опасно.
3. Мудры = асаны с большей идеацией; бандхи = контроль нервов/вайю.
4. Конкретные асаны — под конкретные болезни (⚠ дозировки к калибровке).
5. Bandhatraya (mahāmudrā/mahābandha/mahāvedha) — специальная группа.
6. Индивидуальный подбор по телу, санскарам и времени — обязателен.
