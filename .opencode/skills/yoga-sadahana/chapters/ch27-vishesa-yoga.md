# Chapter 27: Vishesa Yoga Sädhanä

*Из дискурса о Vishesa-йоге.*

## Core Idea

Вишеша-йога — высшая садхана Ананда Марги: концентрация на точке «варанаси» (между адужна и сахасрара-чакрой), где прекращается цикл рождений. Служение — обязательная часть.

## Frameworks Introduced

- **Этимология «варанаси»**: vār = «остановить», anas = «рождение»; varana = «запрет». Vārāṇasi — «точка, где больше нет рождения», НЕ город в Уттар-Прадеше; бинду между ājinā и sahasrāra чакрами (гипофиз и пинеальная железа).
- **Kāshī** = «светящаяся» (kāsh + al); «если умереть в Каши — не переродишься» — не город, а духовная точка. Правильная производная Vārāṇasī = vār + anas (не Varunā+Ashi → тогда было бы «Varunāsī»).
- **Самопознание**: `Traelokye yäni bhütäni täni sarväni dehatah` — «всё, что в трёх мирах, есть в твоём теле»; самопознание (ātmajñāna) через погружение внутрь (центр плекса → mūlādhāra как идеационная сущность).
- **Кāpālika-садхана**: техника быстрого подъёма ума к этой точке.
- **Служение**: два типа — внешнее (служение живым существам = служение Парама Пуруше; Он приходит как больной/нищий) и внутреннее (japakriyā/дхьяна с идеацией служения). Без ожидания награды. «Служение-мыслящий садхак может достичь освобождения простым повторением нама-мантры; высшие йоги без служения не получат ничего».
- **Вишеша-йога** — высшая садхана; уроки включают концентрацию на этой точке ежедневно; доступна только определённым ачарьям после тестов (прим. редактора).

## Key Concepts

- **vārāṇasī / kāshī** — бинду прекращения рождений.
- **ātmajñāna** — самопознание.
- **kāpālika sādhanā** — техника подъёма ума.
- **внутреннее/внешнее служение** — две формы sevā.

## Mental Models

- **Тело = микрокосм**: всё во вселенной есть в теле.
- **Служение = путь к концентрации**: идеация служения усиливает концентрацию.

## Anti-patterns

- **Тщеславие при служении** — «служу Богу, а не людям» (искажение).
- **Высшая практика без служения** — бесполезна («служение = сущность духовной жизни»).

## Worked Example

Садхак ежедневно в садхане концентрирует ум на точке варанаси (между аджна и сахасрара) → ум поднимается так высоко, что нет нужды в новом теле → не перерождается. При этом служит (внешне и внутренне) без тщеславия.

## Key Takeaways

1. Варанаси/Каши — духовная точка (между аджна и сахасрара), не город.
2. Установление в этой точке = конец перерождений.
3. Самопознание: всё есть в теле (микрокосм).
4. Вишеша-йога — высшая садхана Ананда Марги.
5. Служение (внешнее + внутреннее) обязательно.
6. Без служения высшие практики бесполезны.
