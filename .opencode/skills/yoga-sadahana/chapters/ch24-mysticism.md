# Chapter 24: Mysticism and Yoga

*Дискурс от 14 сентября 1979, Стамбул.*

## Core Idea

Мистицизм — бесконечное усилие найти связь конечного с Бесконечным, себя с Высшим Я (khud → Khudā). На вершине мистицизм становится духовностью; йога — движение конечного к Бесконечному в мистическом стиле.

## Frameworks Introduced

- **Определения**: мистицизм = связь конечного с Бесконечным; при достижении пика человеческой славы — духовность. `Nalpe sukhamasti bhutaeva sukham` — «человек не удовлетворён конечным».
- **Эстетическая наука → духовность**: человеческий путь к Бесконечному: сначала эстетическая наука (не обязательно «приятное» — может быть «трудное/неловкое»), выражение от тонкого к тончайшему → пик = вершина славы. Художник выражает красиво; наслаждаться эстетикой может каждый.
- **Йога как мистическое объединение**: для мистика йога = «объединение» (сахар и вода), не «добавление» (яблоки сохраняют идентичность).
- **Марш к Высшей цели — для всех**: физическая/психическая структура человека подходит; животные и растения действуют по инстинктам, их мозг неразвит; человеческое психо-духовное движение нельзя подавить.
- **Йога — вершина человеческих «хотений»**: в йоге человек выражает себя через искусства и науки; финальная точка всех искусств и наук — Парама Пуруша.
- **Духовность — обязательна**: без духа движения к Высшему человек деградирует ниже человеческого статуса.

## Key Concepts

- **mysticism** — связь конечного с Бесконечным.
- **Aesthetic science** — тончайшее выражение; пик = духовность.
- **Purusottama / Parama Purusa** — Отец всех, Causal Matrix.

## Mental Models

- **Лестница: эстетика → мистицизм → духовность**.
- **Конечное не насыщает**: жажда Бесконечного врождённа.

## Anti-patterns

- **Деградация без движения** — отсутствие духа движения к Высшему.
- **Путать «приятное» с эстетическим** — эстетика может быть и трудной.

## Worked Example

Художник выражает тонкое (эстетика) → зритель, испытывая эстетический вкус, начинает движение к Бесконечному (мистицизм) → на пике — духовность: объединение с Высшим (йога).

## Key Takeaways

1. Мистицизм = поиск связи конечного с Бесконечным.
2. Эстетика — первый шаг к духовности; пик — духовность.
3. Йога = объединение (сахар-вода), не добавление (яблоки).
4. Движение к Высшему — для всех людей.
5. Без этого движения человек деградирует.
