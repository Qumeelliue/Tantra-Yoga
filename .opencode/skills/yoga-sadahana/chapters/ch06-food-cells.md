# Chapter 6: Food and Cells, Physical and Mental Development

*Из Ananda Marga Philosophy in a Nutshell Parts 1–4.*

## Core Idea

Пища и клетки напрямую определяют состояние ума. Саттвичная пища создаёт саттвичные клетки → аура, ясность ума, духовное развитие. Грубая пища → тамасичные клетки → ментальная деградация.

## Frameworks Introduced

- **Три категории пищи по гунам**:
  - **Sāttvika (саттвичная)**: рис, пшеница, ячмень, бобовые, фрукты, молоко и молочные продукты — «производит саттвичные клетки», способствует физическому и ментальному благополучию.
  - **Rājasika (мутативная)**: хороша для тела, не вредит уму (может и помогать).
  - **Tāmasika (статичная)**: вредна для ума: лук, чеснок, грибы, вино, испорченная пища, мясо крупных животных (коровы, буйвола), рыба, яйца.
- **Клетки как живые существа**: клетки прошли эволюцию; через совместные жизни нашли существование в теле; каждая клетка-ум разовьётся в человеческий ум.
- **Аура = коллективная эффульгенция клеток**: злость → смерть клеток, красное лицо, аура теряется; саттвичное питание + садхана → сияние (махапуруши с аурами на картинах).
- **Пища и ум связаны**: `Ahärashuddhao sattvashudhih` — «саттвичное питание производит саттвичное тело». Нельзя есть без разбора.
- **Скрыто-грубые продукты**: молоко только что родившей коровы, белый баклажан, khesāri pulse, красная пуни, листья горчицы — часто растут из гнилого вещества (статичны).
- **Отдых для клеток**: при длительной болезни — полный отдых минимум 21 день для роста новых здоровых клеток.

## Key Concepts

- **citta-клетки и развитие**: клетки — преобразование через жизни → развитие к человеческому уму.
- **Эффульгенция / aura** — сияние тела от саттвичных клеток.
- **sattvaguṇa** — принцип, делающий клетки (и тело, и ум) «посвящёнными».
- **«Нельзя» идея**: «я буду делать садхану и есть любую пищу» — не работает.

## Mental Models

- **Пища → клетки → ум**: причинная цепочка от диеты к поведению и духовному прогрессу.
- **Внешнее отражает внутреннее**: лицо злого человека выдает гнев; аура садхака выдает чистоту.

## Anti-patterns

- **Еда без разбора**: даже «нормальные» продукты могут быть тамасичными по происхождению.
- **Пренебрежение диетой при садхане** — «просто делаю садхану» недостаточно.

## Worked Example

Садхак, питающийся саттвично и практикующий садхану, получает: саттвичные клетки → эффульгенцию/ауру → умиротворённый ум → лучшую концентрацию.

## Key Takeaways

1. Пища делится на sāttvika / rājasika / tāmasika — выбирай для ума.
2. Клетки — живые существа, влияют на ауру и характер.
3. Аура — следствие саттвичного питания и садханы.
4. Есть продукты, скрыто статичные (по происхождению).
5. При длительной болезни — отдых ≥21 дня для регенерации клеток.
6. «Есть всё подряд + садхана» — не работает.
