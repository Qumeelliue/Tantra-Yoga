# Chapter 21: Sadguru and Yoga Sädhanä

*Из «Gurukaraha» (перевод Mohit K. Roy) и др.*

## Core Idea

Садгуру — «рассеиватель тьмы» во всех трёх сферах; Tāraka-Brahma, действующий через него. Критерии гуру строги; благость идёт через микро-вита.

## Frameworks Introduced

- **Этимология**: gu = тьма, ru = рассеиватель. «Гуру» в древности — любой учитель (алфавит, готовка, Vaidikī-dīkṣā). **Sadguru**: sat = «неизменное» (в ведическом санскрите, не «хороший»); тот, через кого приходят в контакт с неизменным — через которого действует Tāraka Brahma. `Sadgurum tvam namāmi`.
- **Побуждение к поиску**: желание покоя (eṣanā) → заставляет искать проводника; awakening = **sambhāra** (откровение); шуддха-майя/пара-пракрити приводит к гуру.
- **Критерии гуру**:
  - Разгоняет тьму в **трёх сферах**: физической, психической, духовной. Только академический/психический/духовный учитель по отдельности — недостаточно.
  - Духовно: должен быть **Mahākaola** (каола = поднявший своё микрокосмическое положение; махакаола = умеющий поднять и других). Шива и Кришна — махакаолы.
  - Владеет деталями садханы (теория + практика), умеет обучать, знает языки и шастры.
  - **Shāstra** = «то, что дисциплинирует и освобождает» (`Shāsanāt tārayet yastu sah shāstrah`); не обязательно Веды; «ясные инструкции». Anushāsana = «исправление, полезное для благополучия» (не пытка).
  - **Nigrahānugrahe shakto gururityabhidhiyate** — гуру умеет и наказывать, и благословлять; любовь ≥ наказания.
  - Знает, как Парама Пуруша связывается с дживами (как Ганг сливается с Бенгальским заливом).
  - `Brahmaeva Gururekah näparah` (Ananda Sütram) — только Брахма — Гуру; через Его физическую структуру.
  - Для духовного учителя: God-realization недостаточно — нужны ещё знания; академические степени для гуру — необязательны, но знание обязательно.
- **Три сферы гуру**: духовная (теория+практика), психическая (психология, «знать в тысячу раз больше книг»), физическая (решение мирских проблем — еда, одежда, образование, лечение).
- **Микро-вита и благодать**: negative микро-вита может действовать до vishuddha (физико-психическая чакра), с силой — до ājinā (lunar plexus) = **rusti/risti** (избегай); positive микро-вита — до ājinā; поднятие positive выше ājinā до guru-чакры = **krpā**, до пика человеческой славы = **karunā**. Микро-вита не даёт духовной силы сама по себе — нужен специальный источник (вара-бхайя-мудра Садгуру).
- **Пранама**: sāstaunga-pranäma (все тело, гуру-чакра на объект) / dandavat; namaskara — не пранама; благословение — «kalyānam bhūyāt» (пусть душа идёт вверх).
- **Ошибка садхаки**: возраст 13–15 и направление потенциала через садхану — «обязательно успешен» (см. ch09).

## Key Concepts

- **Mahākaola / kaola** — маха-гуру / каола.
- **Tāraka Brahma** — касательная точка между Сагуна и Ниргуна; Гуру-принцип.
- **sambhāra** — внезапное пробуждение желания Бога.
- **krpā / karunā / rusti** — уровни движения микро-вита.
- **Vaidikī vs Tāntrikī dīkṣā** — см. ch22.

## Mental Models

- **«Рассеивать тьму всех сфер»** — гуру = универсальный наставник, не узкий специалист.
- **«Брахма — единственный Гуру»** — через человека-махакаолу.

## Anti-patterns

- **Гуру без знаний шастр/языков** — «не сможет объяснить почему».
- **Наказание без любви** — недопустимо; любовь ≥ наказания.
- **«Для Бога-реализации не нужны знания» → гуру без знаний** — для гуру знание обязательно.
- **Считать приостановку жизни «величием»** (см. ch07).

## Worked Example

Ищущий, измученный мирской суетой (eṣanā), внезапно просыпается к поиску покоя (sambhāra) → шуддха-майя приводит к гуру → гуру даёт дикшу, учит техникам (purashcarana), освещает путь (dīpajñāna) → дīkṣā = «вступление на путь».

## Key Takeaways

1. Sadguru = проводник к неизменному (sat), не просто «хороший учитель».
2. Гуру разгоняет тьму во всех трёх сферах.
3. Гуру должен быть Mahākaola.
4. Nigrahānugrahe shakto — и наказывать, и благословлять; любовь ≥ наказания.
5. Только Брахма — Гуру (`Brahmaeva Gururekah näparah`).
6. Избегай rusti, стремись к krpā/karunā.
7. Направление потенциала в 13–15 лет через садхану ведёт к успеху.
