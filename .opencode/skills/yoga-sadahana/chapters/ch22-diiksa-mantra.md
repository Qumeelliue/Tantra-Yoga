# Chapter 22: Diiksä, Mantra and Yoga Sädhanä

*Из Ananda Vacanämrtam Part 16 и др.*

## Core Idea

Дикша — научный процесс инициации в тантрическом культе: свет (dīpanī), пробуждение мантры (mantra-caetanya), сжигание кармы (pāpakṣaya). Мантра без siddha-статуса и идеации бесполезна.

## Frameworks Introduced

- **Зачем мантра**: для знания Брахмы нужна непрерывная идеация на «so'ham»; попугайное повторение недостаточно. Нужна ритмическая параллельность инкантативного и ментального потоков.
- **Согласование**: индрии контролируются умом, ум — вайю; все должны консолидироваться и быть направлены к Парама Пуруше.
- **Дикша = Tāntrikī**: `Dīpa jñānam yato dadyāt kuryāt pāpakṣayam tatah; Tasmāddīksetisä proktä sarvatantrasya sammatä`. Vaidikī-дикша — не культ, лишь «попросить Бога показать путь» (см. ch03).
- **Три фазы Tāntrikī-дикши**: dīpanī (факел света — «показать путь во тьме Майи»), mantrāghāta (удар акустического корня по кулакундалини — пробуждение спящей), mantra-caetanya (движение пробуждённой вверх).
- **Diiksa = di + ksa**: первая буква kulakundalinii (dī) + последняя буква pāpakṣaya (kṣa).
- **Purashcarana-kriyā** — система подъёма кулакундалини; без него повторение мантры бессмысленно.
- **Pāpa и pāpakṣaya**: pāpa = негативные реактивные моменты; дикша учит, как удовлетворять их на психическом плане.
- **Мантра**: в духовной сфере = «то, что помогает достичь постоянного освобождения». Всякий звук-экспрессия = bījaman тра (khat-khat = ходьба). `Caetanrahita mantra prokta varnctstu kevalam` — мантра без идеации — «просто буква/звук», бесполезна даже после миллионов повторений.
- **Siddha-мантра**: создаётся только Mahākaola через purashcarana; обычная мантра без этого — «просто набор слов». Kaola может поднять СВОЮ кундалини с помощью siddha-мантры; махакаола — создатель.
- **Shambhūliṅga**: точка начала творения, «фундаментальная сила позитивности»; svayambhu-liṅga (в основании позвоночника) — местоположение спящей силы (кулакундалини).
- **Mantrāghāta + mantra-caetanya = dīpanī**; подъём кундалини → санскары (prārabdha) сгорают → **dagdhabija** («сожжённое семя») = pāpakṣaya.
- **Два аспекта мантры**: mantrāghāta и mantra-caetanya; для освобождения от prārabdha.

## Key Concepts

- **dīpanī / mantrāghāta / mantra-caetanya** — три фазы.
- **purashcarana** — ритуальное пробуждение кундалини.
- **siddha mantra / caetanyayukta mantra** — «энергизированная идеей мантра».
- **dagdhabija** — сожжённые семена санскар.
- **kūrmā-nādī / vāyus / indriyas** — каналы и органы.
- **Abhiseka** — «ауспишное начало» (пробуждение кундалини при дикше).

## Mental Models

- **Свет в темноте**: дикша как фонарь на тёмной дороге жизни.
- **Спящий пробуждается**: мантра-агхата — как сильное встряхивание спящего.

## Anti-patterns

- **Попугайное повторение мантры** — без параллельности и идеации.
- **Мантра без purashcarana** — «миллиарды повторений не дадут результата».
- **Джапа с вредными мыслями** — бесполезна.
- **Обычный гуру как создатель siddha-мантры** — только Mahākaola.

## Worked Example

При дикше: Махакаола произносит siddha-мантру → mantrāghāta будит кулакундалини (джалтан: спящий просыпается) → mantra-caetanya ведёт её вверх → prārabdha сгорает (dagdhabija) → путь к самадхи открыт.

## Key Takeaways

1. Дикша = dīpanī + mantrāghāta + mantra-caetanya (Tāntrikī).
2. Без параллельности инкантации и ментального потока мантра мертва.
3. Мантра без идеации — «просто буква» (Caetanrahita…).
4. Siddha-мантру создаёт только Mahākaola.
5. Purashcarana обязателен для подъёма кундалини.
6. Сгорание prārabdha = dagdhabija = pāpakṣaya.
7. Vaidikī-дикша — лишь очищение, не настоящая дикша.
