# Chapter 17: Savikalpa Samädhi, Nirvikalpa Samädhi and the Supreme Attainment of Salvation

*Из «Psychic Assimilation in Psycho-Spiritual Practice» (Subhäsita Samgraha Part 8).*

## Core Idea

Самадхи — состояние равновесия ума, а не позитивное/негативное состояние. Долгая и тщательная садхана ведёт к установлению в самадхи; окончательное — нирвикальпа (нирбиджа) самадхи = мокша.

## Frameworks Introduced

- **Самадхи = состояние равновесия**: как гладкая поверхность воды — верхние (samkalpātmaka) и нижние (vikalpātmaka) течения ума параллельны. Самадхи не экстровертно и не интровертно (не pravrtti/nivrtti).
- **Пракрити-лина и видеха-лина**: два из семи devayoni; санскары в семенной форме ждут среды; риск перерождения. Состояния nirbiija, но не полной омнисценции. Видеха-лина из-за bhavapratyaya; шунья-дхьяна (идеация на ничто) ведёт к videhaliina — дефектный путь.
- **Путь upäyapratyaya** (позитивная идеация и истощение санскар) — правильный; не bhavapratyaya.
- **Шраддха (veneration)**: принимая что-то после логического размышления, развиваешь шраддху; `Shrat satyam tasmin dhiiyate iti shraddhä`. Расширение читты = шраддха; самадхи — максимум расширения читты. Шраддха обязательна для самадхи (не для pravrtti/nivrtti).
- **Вирья (spiritual vigour)**: сила разгонять негативные мысли; рождается из шраддхи. Память (smriti) усиливается вирьей; dhruvasmriti («фиксированная память») — только объект идеации Высшее → самадхи.
- **Абхога (psychic pabulum)**: ум принимает форму объекта; без освобождения от pabulum нет покоя. Отталкивание = тоже pabulum (привязан к несуществующей форме объекта).
- **Вашикара-сиддхи** (контроль над объектами через отталкивание) — не высшее; это nirbiija-prakrtiliina-самадхи, возможность будущего рождения.
- **Ступени samprajñāta самадхи** (4): savitarka (на грубых объектах = jada самадхи, +/−), savicāra (на тонких pabula, имя/слава), sānanda (pabulum — блаженство), sāsmitā (pabulum — «Я»-чувство, asmitā). Когда исчезает asmitā → asamprajñāta (остаётся только Когнитивный принцип, Purusākhyāti).
- **Омнисценция**: знание прошлого/настоящего/будущего; семя в каждом, «созревает» через sadhana; `Tatra nirätishayam sarvajñätva bījam`.
- **Jada самадхи**: ум в восторге от грубого объекта (деньги, собственность) — НЕ samprajñāta.
- **Установление в дхьяне = гарантия самадхи**: только после установления в дхьяне можно достичь нирвикальпа-самадхи; тогда спасение — «в порядке вещей».
- **Дхиана vs джапа**: в дхьяне не нужны dīpanī/mantra-caetanya; джапа — композит процессов; дхьяна-крийя полна в себе; новичкам труднее в дхьяне.
- **Вайрагья vs отталкивание**: вайрагья = отсутствие привязанности, не repulsion; повторная практика космической идеации (Brahma-bhävanä). Абхиаса = `Tatra sthitao yatno'bhyäsah` — создание непрерывной психической вибрации.
- **Ни в коем случае не откладывать**: прекращение практики → ум заполняется волнами мыслей; «я практикую, потому что ачарья сказал» — неверная психология.

## Key Concepts

- **savikalpa / nirvikalpa / samprajñāta / asamprajñāta** — категории самадхи (термины Патанджали vs автора см. ch18).
- **jada, savitarka, savicāra, sānanda, sāsmitā** — 4 ступени samprajñāta.
- **prakrtiliina / videhaliina** — состояния с латентными санскарами.
- **bhavapratyaya / upäyapratyaya** — путь санскар vs путь позитивной идеации.
- **abhidhyāna** — постоянная погружённость в идеацию (см. ch16).
- **Purusākhyāti** — когда остаётся только Когнитивный принцип.

## Mental Models

- **Равновесие**: самадхи = параллелизм верхнего и нижнего течения ума.
- **Семя и созревание**: омнисценция — созревшее семя через садхану.

## Anti-patterns

- **Поклонение Ниргуна** — без милости.
- **Отталкивание как метод** — создаёт новый pabulum.
- **Videhaliina через шунья-дхьяну** — «дефектный культ».
- **«Практикую, потому что ачарья сказал»** — не бери на себя ответственность.
- **Jada-самадхи называть samprajñāta** — ошибка.

## Worked Example

Садхак: постепенно samkalpātmaka/vikalpātmaka потоки становятся параллельны (равновесие) → шраддха → вирья разгоняет негативные мысли → dhruvasmriti → читта отождествляется с целью → samprajñāta (4 стадии) → исчезновение asmitā → asamprajñāta.

## Key Takeaways

1. Самадхи — равновесие, не позитив/негатив.
2. Установление в дхьяне гарантирует самадхи.
3. Prakrtiliina/videhaliina — риск перерождения; правильный путь — upāyapratyaya.
4. Шраддха → вирья → смарити → дхрувасмарити → самадхи.
5. 4 стадии samprajñāta; исчезновение асмиты = asamprajñāta.
6. Нирвикальпа (нирбиджа) самадхи = мокша.
7. Не откладывай практику; бери ответственность за свою садхану.
