# Читшит — правила решений (Manasadhyatmik)

## Стадии и прогресс

| Ситуация | Правило |
|---|---|
| Определить стадию садханы | yatamána (усилие+санкция ума/Атмана) → vyatireka (колебание) → ekendriya (одна цель) → vashiikára (полный контроль) |
| Действие — «делать или нет» | Санкция ума + Атмана; философия объединяет человечество? Если нет — не yatamána |
| Действие по страху/приказу | Рабское; без санкции ума/Атмана; не ведёт к благу |
| Работа над привычкой | Divert (отвлечь ум), не «не делай» — запрет усиливает |
| Устойчивая мысль | Материализуется — выбирай объект осознанно |
| Выбор объекта ума | Самый большой/лучший/долговечный/любящий — Parama Puruśa |

## Знание

| Ситуация | Правило |
|---|---|
| Оценить знание | Три стадии: ava (поверхностное) → upa (психический пласт) → samyak (вечное через Supreme) |
| Доверять восприятию/выводу/авторитету | Ненадёжны; проверяй (пар≠дым, печатное слово≠истина) |
| Книжная эрудиция | Видьядхара: «альманах, предсказывающий дождь без капли» — не знание |

## Ум и контроль

| Ситуация | Правило |
|---|---|
| Ум расщеплён (осмотр+тревога) | Извлечь из лишнего, сконцентрировать на одном |
| Контроль одной вритти, остальные бушуют | Negative ekendriya; цель — консолидация всех на Supreme |
| Эмоциональный всплеск | Пра́н́а́й́а́ма: успокоить дыхание → ум → вритти |
| Гордость «я контролирую» | Проверь остальные вритти (сон выдаст) |

## Судьба и цель

| Ситуация | Правило |
|---|---|
| Жизненный приоритет | Объект идеации определяет судьбу: идеируй Supreme, не деньги/музыку/книги |
| Оккультные силы (aeshvarya) | Станции, не цель; удовлетворение = остановка роста |
| Vidya vs avidya Tantra | Только madhyammárga (средний путь) ведёт к Supreme |
| Исчерпание усилий | Полная сдача (Shiva/Shánta); сдача мирскому = грубость |

## Социальное (из yatamána-дискурсов)

| Ситуация | Правило |
|---|---|
| Физические/соц. проблемы | Artha (временное решение) обязателен, пока нет paramártha |
| «Всё в мире ложно» | Эксплуатирующая ложь; мирские усилия нужны |
| Свобода общества | Социо-экономическая ≠ психо-экономической; истинная — освобождение интеллекта |
| Догма/страх в культуре | Инструмент эксплуатации («без страха нет любви», кастовые запреты); разоблачай |
| Общество для прогресса | Структурировано так, чтобы удовлетворять физические и психические потребности |

## Быстрые сигналы («tells»)

- «Брошу завтра» / «в следующий благоприятный день» — классическая отсрочка, не решение.
- Обет молчания на 2 дня → срыв — negative ekendriya, не прогресс.
- Эрудит, цитирующий книги без практики, — vidyadhara-траектория.
- Лидер, использующий страх («иначе ад») — эксплуатирует через догму.
- Человек, чьи мысли о деньгах/славе, — готовит себе devayoni-судьбу.
- «Санкция ума есть, Атмана нет» — философия расщепляет человечество → не yatamána.
- Спор с догматиком, где он зовёт поражение «добровольным отступлением», — догма живёт.
- Сытая, но без свободы мысли — социо-экономическая свобода без психо-экономической.
