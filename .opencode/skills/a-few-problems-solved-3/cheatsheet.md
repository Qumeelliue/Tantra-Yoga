# Читшит — правила решений по Саркару (A Few Problems Solved Part 3)

## Сила и страх

| Ситуация | Правило |
|---|---|
| Техноугроза (бомбы, ИИ) | Творец психически сильнее творения; найди контр-средство; реальный враг — «демоны в человеческом обличье» |
| Страх в одиночку | Ты дитя Parama Puruśa — «Na vibheti kutashcana»; борись коллективно |

## Общество и аффликции

| Ситуация | Правило |
|---|---|
| Что такое общество | Коллективное движение к общей цели (samája); отставших несут |
| Физические страдания | Рост покупательной способности каждого, а не доход сам по себе |
| Психические/духовные | Подготовка ума + преданность (bhakti) |
| Временное vs вечное | Артха — временно; парамартха — навсегда (тройные аффликции) |
| Прогресс половины | Женщины заперты = скорость страны вдвое меньше |

## Музыка и искусство

| Ситуация | Правило |
|---|---|
| Настроить ум | Триада песня/инструмент/танец — вибрировать эктоплазм к одной точке |
| Песня | Ритм + мелодия + чувство (bháva); без bháva — нет сладости |
| Инструмент | Вибрирует параллельно bháva; потеря параллельности = бесполезен |
| Танец | Восточный (жест + ритм) выразительнее западного (только ритм) |
| Выбрать форму | Kirtana — прямое отражение Высшего; bhajana — возврат к идее |

## Движение и прогресс

| Ситуация | Правило |
|---|---|
| Застой | Пауза = сбор инерции для следующего шага; не пессимизм |
| Услышал/узнал | Ассимиляция в паузе, выражение в скорости |
| Древние цивилизации | Гибли из-за потери координации (майя — без колеса); держи баланс сфер |
| Настоящий прогресс | Духовный; физический/психический относителен |

## Словесность

| Ситуация | Правило |
|---|---|
| Оценить текст | Кавья (красота) / пурана (вымысел-воспитание) / итикатха (хроника) / итихаса (мораль) |
| Воспитывать | Итихаса: учит káma, artha, dharma, mokśa и niiti |

## Единство

| Ситуация | Правило |
|---|---|
| Деление по богатству/расе/нации/религии | Несостоятельно: признаки внешние и меняются |
| Конфликт «мы/они» | Диагноз — эксплуатация; убери её — исчезнут и классы |
| Языки | Различия лишь в последних 2 из 6 стадий выражения; не подавлять |
| Границы/паспорта | Барьеры вредны; нации меняются за ночь — не дели людей |

## Таланты

| Ситуация | Правило |
|---|---|
| Гений или техник | Гений рождается; техник создаётся практикой — не путай |
| Нет веры в себя | Твёрдая решимость — первый фактор успеха (Phaliśyatiiti vishvásah) |
| Гений увядает | Среда решает: освободи от быта, не завидуй; люди используют 1–2% ⚠ |

## Быстрые сигналы («tells»)

- Паника перед «непобедимой» техникой — забыто: создатель сильнее творения.
- «Все умирают, прогресса нет» — пессимизм без изучения истории (пауза = рывок).
- Один класс безнаказан, другой наказывается за мелочь — дискриминация, не общество.
- Религия объявляет себя выше логики — «majhabme akkalká dakhl nehi» — деление людей.
- Народ «проснулся» гражданином другой страны без спроса — фикция нации.
- Текст красив, но ничему не учит — кавья, не итихаса.
- Человек рвётся бежать, не останавливаясь — теряет вкус и ассимиляцию.
