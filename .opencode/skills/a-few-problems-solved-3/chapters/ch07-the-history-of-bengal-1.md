# Chapter 7: The History of Bengal – 1

*Дискурс от 15 апреля 1979 года, Calcutta.*

## Core Idea

Бенгалия — «восточная граница между Jambudviipa и Suvarńadviipa», зона слияния трёх речных цивилизаций: гондванской (Ráŕh), гангской (северная Индия) и брахмапутрской (монгольской). Смешанная (Gaoŕiiya) цивилизация породила особую социальную систему (Dayabhága, роль женщин, шесть коренных общин) и свой солнечный календарь.

## Frameworks Introduced

- **Термины**: `varśa` — «то, что изливается» / «большой остров» / «год»; Jambudviipa — древняя Индия (от Средней Азии до Бирмы); Bhárata Varśa — пригодная для жизни часть; `bhárata` = bhr («кормить») + ta («расширять») — «земля, помогающая всестороннему развитию». Tibet — Kiḿpuruśa Varśa (шутка: безбородые тибетцы).
- **Речные цивилизации**: цивилизация идёт вдоль речных долин: 500 миль вдоль Ганги — одна культура (Варанаси ≈ Патна); 40 миль вглубь — уже другая.
- **Гондвана и Ráŕh**: ~300 млн лет назад ⚠ северная Индия и часть Бенгалии были под водой; горы Виндхья/Са̄тпура/Са̄hyādri/Раджмахал/Ра̄мгарх снежные, реки с талой водой (Субарнарекха, Камса̄ватii, Дамодар, Аджай, Mayurákśii). Ráŕh — древнейшая почва (запад: Manbhum, Bankura, Midnapur, запад Burdwan, Birbhum). Старейшие манускрипты бенгали — на западе (скала Shushunia, Beletor, Shrii Krśńa Kiirtana Báru Cańd́iidása).
- **Три потока → Gaoŕiiya цивилизация**: Ráŕh (гондванская) + Гангская + Брахмапутрская (монгольская, Sang Po из Тибета). Монгольская цивилизация критиковалась ариями (Karma Puráńa: «пожиратели рыбы»). В Аллахабаде ~1200–1300 лет назад ⚠ признали лишь 10 категорий брахманов (Pañcagaoŕiiya + Pañcadrávid́ii); бенгальские (Ráŕhii, Bárendra и др.) объявлены «небрахманами с брахманскими фамилиями».
- **Тантра в смешении**: родилась в таких смешанных цивилизациях; гангско-брахмапутрский стык (Goyalanda). Бенгальская раса = смешение кровей (Australoid + Dravidoid → тёмные; монгольская кровь → Rajvaḿshiis, Chakmas).
- **Сентиментальность бенгальцев**: долго терпят, потом внезапно бунтуют; принятие ислама массами — реакция на эксплуатацию; джайны Банкуры → вайшнавизм Чайтаньи.
- **Социальная система Бенгалии**: (1) женщины с предоконной ролью (древность: идентификация по матери; Khásiyás в Meghalaya и сейчас); (2) наследование по сестре матери (в отличие от северной Индии); (3) девушка после брака сохраняет связь с родом отца (ashaoca 3 ночи); (4) **Dayabhága** (отец вправе лишить сына наследства) vs **Mitákśará** (равные доли, сын — даже в утробе — совладелец); (5) всего два класса — Vipra и Shudra (нет Kshatriya/Vaeshya); (6) **шесть коренных общин**: Kaevartta, Máháto, Gop, Namashudra, Rájvaḿshii, Cákmá — «лампа-держатели», верхние касты — «лампы»; Vaedya — непризнанные аюрведические брахманы.
- **Ненаследственная монархия**: бенгальские короли просили, а не приказывали; шесть общин бунтовали против плохих королей (Kaevarttas против Devapála II); в битве Курукшетры бенгальцы не участвовали («война бесполезна»); вечный конфликт с Дели.
- **Календарь**: северная Индия — лунный (месяцы по фазам, ekadashii пропадает при tryáhasparsha); Бенгалия — **солнечный** (месяц по вхождению солнца в знак зодиака; А̄ш̄áŕh/Shrávan — 32 дня ⚠); солнечный держит связь с сезоном посева/жатвы; бенгальская астрология — viḿshottariiya (120 лет) vs áśt́ottariiya (108 лет) ⚠. Ввёл King Sháliváhan (southern Bengal/Samatat́); reckoner (Sárańii) → táká/anna/pái. Современные альманахи неточны (затмение на 100 минут позже) — нужна точная калибровка.

## Key Concepts

- **varśa / Jambudviipa / Bhárata Varśa / Suvarńadviipa** — земли/острова древнего мира.
- **Gondwanaland / Ráŕh / Samatat́ / Borin (Bárendra) / Vauṋga / Cattal (Shriibhúmi)** — регионы древней Бенгалии.
- **Dayabhága / Mitákśará** — системы наследования (отцовская воля / равные доли).
- **Pañcagaoŕiiya / Pañcadrávid́ii** — десять признанных категорий брахманов.
- **Kaevartta / Máháto / Gop / Namashudra / Rájvaḿshii / Cákmá** — шесть коренных общин.
- **viḿshottariiya / aśt́ottariiya** — системы астрологического расчёта.
- **sárańii** — расчётный альманах; **Sháliváhan** — вводитель солнечного календаря.

## Mental Models

- «Цивилизация течёт по рекам: речная долина — культурная магистраль».
- «Смешанная цивилизация — норма: Бенгалия = три речных потока в одном сплаве».
- «Социальные институты — ответ на среду (вода/реки), а не на указ сверху».
- «Календарь — это точность жизни: солнечный для посева, лунный для обрядов».

## Anti-patterns

- **«Чистая» культура/раса** — Бенгалия — смесь трёх потоков и кровей; «верхние касты» — «лампы» на «лампа-держателях» из шести общин.
- **Подавление местной специфики** — бенгальских брахманов объявили «ненастоящими»; местные общины бунтовали.
- **Универсальный календарь для всех** — лунный северный не годится для посева в Бенгалии; солнечный — точнее для сезонов.
- **Наследственная монархия** — в Бенгалии королям нужна была поддержка общин; «король» без народа не король.

## Worked Example

*Два наследственных права.* В северной Индии — Mitákśará: сыновья (даже в утробе) совладельцы наследства отца; отец не вправе лишить. В Бенгалии — Dayabhága (по Jiimútaváhana): отец — единственный владелец при жизни, может лишить сына и передать наследство вне семьи. Это следствие смешанной (не чисто гангской) культуры Бенгалии, где женщины и материнская линия сохраняли значение (наследство материнского дяди идёт сёстрам-племянникам).

## Key Takeaways

1. Бенгалия — зона слияния гондванской, гангской и брахмапутрской цивилизаций.
2. Речные долины определяют культуру; смешение — норма.
3. Социальная система Бенгалии уникальна: Dayabhága, наследование по материнской линии, ненаследственная монархия.
4. Шесть коренных общин — «лампа-держатели» бенгальского общества.
5. Солнечный бенгальский календарь точнее лунного для сельского хозяйства.
6. Бенгальский характер — «долго терпят, потом внезапно бунтуют».
