# Глоссарий — Human Society Part 2

**Ануша́сана (anushásana)** — «shásana для блага»: дисциплина ради благополучия, адаптированная к времени/месту/личности (Ch 2).

**Брахмава́да (Brahmaváda)** — духовная философия на основе Брахмана; по Саркару — исторический синтез кшатриев, а не жрецов (Ch 1).

**Вае́шья (vaeshya)** — психотип накопителя: владеть, а не наслаждаться; мера всех вещей — деньги; жёлтый цвет (мутативность + статичность) (Ch 1, 3).

**Ви́крама́нти (vikránti)** — контр-эволюция: попытка уходящего класса вернуть власть (Ch 1, 4).

**Ви́плава (viplava)** — революция, коренное изменение (Ch 1, 4).

**Випры (vipra)** — психотип интеллектуала: управляет другими умом; белый цвет; эксплуатация через знание, религию, сверхъестественное (Ch 2).

**Ви́пра-сатаны (intellectual satans)** — випры, эксплуатирующие «надуманными философиями» (мир иллюзорен) и религией как великой мистификацией (Ch 2, 3).

**Ви́кшубдха шудра (vikśubdha shúdra)** — «недовольный шудра»: экономически shúdra, ментально kśatriya/vipra; двигатель революции (Ch 4).

**Гота́пра́ва́ра (gotra-pravar)** — клан-линия, введённая при переходе власти к vipra (Ch 2).

**Готаратья́га (gotratyága)** — добровольный уход из одного клана под защиту другого лидера (Ch 2).

**Госкапитализм (state capitalism)** — рост нацбогатства без борьбы с эксплуатацией; обогащение только верхушки (Ch 3).

**Джа́я / бха́рья / калатра (jáyá/bháryá/kalatra)** — категории жён с последовательно урезаемыми социальными и религиозными правами в Vipra Age (Ch 2).

**«Имя только»** — деградация класса, когда власть наследуют неспособные, «называющиеся» kśatriya/vipra (Ch 1, 2).

**Кинх́а́нда́ пралая (khańd́a pralaya)** — «частичное уничтожение»: микрокосмическая смерть после каждого выдоха (Ch 1).

**Кра́нти (kránti)** — эволюция, постепенное изменение (Ch 1, 4).

**Кша́тра-пита / сарда́р (kśátra-pitá / sarddár)** — кшатрий-вождь; до монархии (Ch 1).

**Кшатрий (kśatriya)** — психотип борца: подчиняет материю своей волей; красный цвет; «Might makes right» (Ch 1).

**Линга / культ фаллоса (linga)** — символ увеличения численности воинской группы; позже «философски» переосмыслен (Ch 1, 2).

**Мадхьявитта сама́джа (madhyavitta samája)** — «средний класс»: ментально kśatriya/vipra, а не по доходу (Ch 4).

**Ма́йява́да (máyáváda)** — доктрина иллюзии/отрицания мира; по Саркару — опасное бегство от реальности (Ch 2).

**Матриархат → патриархат** — смена при переходе от shúdra-общества к kśatriya (Ch 1).

**Паору́ша (paoruśa)** — «мощная личность»: воля, отвага, сила (Ch 1).

**Паразиты-випры** — випры, живущие чужим трудом и интеллектом (Ch 2).

**Пра́ти-виплава (prativiplava)** — контр-революция (Ch 1, 4).

**PROUT (Progressive Utilization Theory)** — теория прогрессивного использования; пять принципов — см. Ch 4 (Ch 4).

**Псевдо-вае́шьи (pseudo-vaeshya)** — випры с пробудившимся экономическим интеллектом; завершают Vaeshya Age (Ch 3).

**Садви́пра (sadvipra)** — моралист + духовный человек + борец против безнравственности; «белый vipra» (Ch 2, 4).

**Сама́джа чакра (sámája cakra)** — социальное колесо: shúdra → kśatriya → vipra → vaeshya → революция → второй оборот (Ch 1, 4).

**Санча́ра / пратисанча́ра** — цикл творения/инволюции сознания (контекст Ch 1).

**Сарасвати → Лакшми** — метафора: знание становится рабой богатства (Ch 2).

**Систолическая пауза (saḿkocátmaka bháva)** — состояние покоя, из которого рождается действие; systaltic = пульсативный (Ch 1).

**Социальная волна** — коллективный поток движения; укорачивание длины волны ускоряет эволюцию/революцию (Ch 1).

**Средний класс (ментальный)** — см. madhyavitta samája (Ch 4).

**Те́зис–антите́зис–си́нтез** — схема вращения цикла и вмешательства sadvipra (Ch 4).

**Ча́турварника (cáturvarńika)** — четырёхклассовая социальная система (не каста) (Ch 1).

**Шрес́тхи (shreśt́hii)** — «человек богатства»; титул, купленный у vipra (Ch 3).

**Шудра (shúdra)** — психотип: физическое наслаждение, страх перед природой, только настоящее; чёрный цвет; единственный класс, способный быть большинством (Ch 1, 4).

**Эволюция / революция** — см. kránti / viplava (Ch 1, 4).

**Я́йя-бха́рья** — см. jáyá/bháryá (Ch 2).
