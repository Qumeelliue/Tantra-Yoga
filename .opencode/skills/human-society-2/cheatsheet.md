# Читшит — правила анализа общества по Саркару (Human Society Part 2)

## Кто у власти и что дальше

| Ситуация | Правило |
|---|---|
| Определить текущий возраст | Незаменимый ресурс: сила → интеллект → деньги → число работников |
| Класс доминирует | Неизбежно эксплуатирует остальных; смена доминанта проблему не решает |
| Признак Vaeshya Age | Финансы только у ортодоксальных ваешьев, не у умных випров; деньги = мера достоинства |
| Власть перешла «по имени» | Наследственность заменила способность → скорый переход к следующему классу |
| Определить следующего | «Имя только» деградирует → власть берёт следующий психотип по ресурсу |

## Психотипы и мотивация

| Ситуация | Правило |
|---|---|
| Кто-то спит/боится природы, живёт сегодняшним днём | shúdra-ментальность (покупается, революцию не делает) |
| Борется с материей, ценит традиции и престиж | kśatriya-ментальность (прошлое + настоящее) |
| Управляет умом, эксплуатация через знание/религию | vipra-ментальность (все времена, но с креном) |
| Владеет, а не наслаждается; всё меряет деньгами | vaeshya-ментальность |
| Экономически шудра, по уму кшатрий/випра | vikśubdha shúdra — лидер перемен |

## Как меняется общество

| Ситуация | Правило |
|---|---|
| Постепенное изменение | kránti (эволюция) — медленно, «черепаший» путь |
| Резкое изменение | viplava (революция) — обычно с кровью; без крови, если много випра-ментальных |
| Уходящий класс возвращает власть | vikránti / prativiplava (контр-эволюция / контр-революция) |
| Судьба/фатализм оправдывает страдания | Орудие эксплуатации, отвлекает от борьбы |
| Демократия | Покупаются голоса; путь медленный, не революция |
| Кооперативы/социализм | Выживают только при честной администрации и высокой морали |

## Эксплуатация и власть

| Ситуация | Правило |
|---|---|
| Монополия на знание/«посредничество к истине» | Интеллектуальная эксплуатация (випры): религия, экзорцизм, «ключ к небесам» |
| «Мир иллюзорен, отрекись» | Надуманная философия (интеллектуальные сатаны) |
| Благотворительность от капитала | Инвестиция: возвращается прибылью и успокоением критиков |
| Финансируемые «измы» (национализм и пр.) | Разделение эксплуатируемых деньгами ваешьев |
| Долг: деньги отнять | Недостаточно — жадную ментальность надо обезвредить силой + пробуждением интеллекта |

## Лидеры перемен

| Ситуация | Правило |
|---|---|
| Оценить реформатора | Тест садвипры: мораль + духовность + борьба; критерий — честность, не симпатия |
| Богатый моралист-революционер | Должен «спуститься к среднему классу» — отказаться от грешной роскоши |
| Беречь лидеров | Не давать числу vikśubdha шудр уменьшаться (безработица, планирование семьи) |
| После победы | Победители становятся kśatriya второго оборота; колесо не остановить |

## Быстрые сигналы («tells»)

- Финансы замыкаются на узкой группе «ортодоксов», умных отстраняют → Vaeshya Age.
- «Всё предрешено», «страдаешь за прошлые грехи» → успокоительная доктрина против перемен.
- Пожертвование с пиаром → вероятно, «инвестиция в успокоение».
- Законы пишутся красиво, но не исполняются → ширма эксплуатации.
- Голоса покупаются → демократия ваешьев, а не власть народа.
- Ужесточение «ради дисциплины» без учёта людей → kśatriya-жёсткость (или хуже).
