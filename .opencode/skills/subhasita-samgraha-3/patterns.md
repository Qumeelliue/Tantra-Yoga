# Паттерны — Subháśita Saḿgraha Part 3

## Карта четырёх сил Майи
**Когда использовать:** диагностируя «почему не видно истину» у себя/других.
**Как:** раздели Avidyá на vikśepa (удаляет: «далеко от истины — ничего не видно») и ávarańii (прячет: «рядом, но закрыто крышкой»); Vidyá — на samvit (пробуждение «надо встать») и hládinii (движение к Брахме с радостью). Найди, какая сила сейчас доминирует.
**Компромиссы:** силы не наблюдаемы напрямую — только по симптомам поведения.

## Выбор пути борьбы с Майей
**Когда использовать:** выбирая стратегию духовной/жизненной практики.
**Как:** средний путь (Madhyamácára) — с ясной целью (Брахма/смысл); это выбор Ананда Марги. Vámácára (без цели) — рискован; Dakśińácára (мольбы) — не даёт свободы. Оцени, есть ли у тебя цель, прежде чем бороться.
**Компромиссы:** «без цели» соблазнительно; цель требует пересмотра.

## Подача сильных вибраций
**Когда использовать:** при сообщении больших новостей (смерть, выигрыш).
**Как:** готовь ум ступенями: намёк → усиление → суть (пример дедушки: «нет писем…» → «может, болен…» → «его больше нет»). Резкий шок превышает ёмкость ума → обморок/кома.
**Компромиссы:** не для всех ситуаций уместно; экстренность ограничивает.

## Чтение варны по гуне
**Когда использовать:** оценивая «тип» человека/культуры (не для дискриминации!).
**Как:** смотри на доминирующий «цвет» ума: белый (sattva/знание), красный (rajah/энергия), жёлтый (rajah+tamah/дело), чёрный (tamah/инертность). Помни: варна по деятельности и практике меняется (Вишвамитра-кшатрия стал брахманом).
**Компромиссы:** категоризация упрощает; «цвет» — текучее состояние, не ярлык рождения.

## Пратьяха́ра — «предложение цветов»
**Когда использовать:** когда замечаешь, что объект «красит» ум (привязанность).
**Как:** заметь объект, привлёкший внимание; мысленно «подари» его цвет Брахме — ум выцветает, привязанность не прирастает. Суть Васантотсавы — внутреннее, не внешние краски.
**Компромиссы:** требует осознанности; не подавляет желание — перенаправляет.

## Различение shreya/preya
**Когда использовать:** при моральном/жизненном выборе («польза сейчас vs польза потом»).
**Как:** проверь: устраняет ли вариант боль навсегда (shreya/Paramártha) или только временно (preya/artha). Учитывай страх трудностей как главный источник выбора preya. Káma — к фрагменту, prema — к целому.
**Компромиссы:** преходящие удовольствия не «зло» сами по себе; важно не путать их с целью.

## Проверка «истинного учителя»
**Когда использовать:** выбирая наставника/источник знания.
**Как:** проверь редкое сочетание: компетентность (знает науку) + реальная практика (не только речь) + преданность. «Двести приглашённых → десять слушали → один практикует» — узкая воронка.
**Компромиссы:** критерии субъективны; «практика» трудно проверяема.

## Полная самоотдача вместо «профита»
**Когда использовать:** когда частичное усилие не даёт результата.
**Как:** отпусти «что я получу» (сюжет Драупади: отпустила сари — спасена; Рама-лодочник: прими прибежище, а не таскай дерево к золоту). Самоотдача = расширение души, не потеря.
**Компромиссы:** звучит радикально; в повседневности — постепенный процесс.
