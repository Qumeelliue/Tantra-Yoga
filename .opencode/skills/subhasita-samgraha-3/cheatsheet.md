# Чит-лист — Subháśita Saḿgraha Part 3

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| «Почему истина не видна?» | Раздели: vikśepa (далеко) или ávarańii (закрыто) — Avidyá |
| Выбор стратегии практики | Средний путь с целью (Madhyamácára); Vámá/Dakśińa — рискованные |
| Сообщаешь сильную новость | Подавай ступенями; резкий шок разрушает ум |
| Оценка «типа» человека | По цвету ума: белый/красный/жёлтый/чёрный (sattva/rajah/tamah); варна меняется |
| Привязанность к объекту растёт | Пратьяха́ра: подари его цвет Брахме |
| Моральный выбор | Shreya (вечное устранение боли) vs preya (временное); страх — корень выбора preya |
| Влечение к кому-то «непонятно» | Это не обязательно секс: влечение коренится в желании счастья/самосохранения |
| Выбор наставника | Проверь: знание + практика + преданность (редкая воронка) |
| Частичное усилие не работает | Полная самоотдача (Драупади): «все 16 анна», а не «профит» |
| Хочешь понять сон | Последняя фаза сна (подсознание активно) — сны-предвестия сбываются |
| Верить в призраков | Нет: это телепатическое видение/ясновидение бессознательного |
| Идол/ритуал как путь | Нет: внешняя шелуха; «идол из рук гончара не спасёт» |
| «Ом» — что делать | Слушать, не произносить; опора (alambana) между Сагуна и Ниргуна |

## Быстрая справка

- **Силы**: Avidyá = vikśepa (удаляет) + ávarańii (прячет); Vidyá = samvit (пробуждение) + hládinii (движение); tatastha = равновесие.
- **Три пути**: Madhyamácára (с целью — выбор AM) / Vámácára (без цели) / Dakśińácára (мольбы).
- **Цвета**: sattva=белый (vipra), rajah=красный (kśatriya), rajah+tamah=жёлтый (vaeshya), tamah=чёрный (shúdra).
- **Та́нматры**: звук, касание, форма, вкус, запах. Звук — тончайший; Oṋḿkára — семя всех звуков.
- **Káma vs Prema**: káma — к фрагменту (extroversio); prema — к целому (introversio).
- **Artha vs Paramártha**: artha — временное снятие боли; Paramártha — навсегда.
- **Шесть врагов**: похоть, гнев, жадность, иллюзия, гордость, зависть.
- **Ключевые мантры-якоря**: «Yato váco nivartante» (слова отступают от Брахмы); «Náyam hanti na hanyate» (никто не убивает и не умирает); «Где Я — там нет Его, где Он — нет меня».
