# Читшит — Tattva Kaomudii Part 1

## Онтология и сознание

| Ситуация | Правило |
|---|---|
| Спор «живое/неживое», «дух/материя» | Единое Сознание; разница — степень оков Пракрти (пар/вода/лёд) |
| Кто свидетельствует ум | Дживатман (отражение Космического Сознания); вдохновение — Citta Shakti/Cosmic Ideation |
| Чем наслаждается ум | Танматрами («тенью»); вселенная из пяти факторов — «тень» Космического Ума → «тень тени» |
| Пуруша | Свидетель без участия («pure shete yah sah Puruśa») |
| Пракрти | Не Единая Сущность, а принцип многообразия через огрубление |
| Ниргун̇а vs Сагун̇а Брахма | Ниргун̇а — без свидетельствования; Сагун̇а — контролёр времени-места-личности |
| Пурушоттама | Ядро Сагун̇а Брахмы; гун̇адхи́шва, но не гун̇адхина/гун̇асришт̣а |
| Новое тело после смерти | Раджогун̇а по сан̇ска́рам; не слепая сила, а Пурушоттама/Макрокосм |

## Освобождение и цель

| Ситуация | Правило |
|---|---|
| Мукти | Свобода от оков |
| Мокша | Свобода даже от свидетельствования объекта |
| Атеист (не верит в Атман/Параматман/Веды) | Мукти/мокша/нирвана бессмысленны |
| Свобода человека | «Доминион-статус», не абсолют |
| Утолит ли цель | Конечное не насыщает ум, чья дхарма — бесконечное |

## Системы и общество

| Ситуация | Правило |
|---|---|
| Материализм | Дефектен психологически: давление → революция; мораль без духовных идеалов ложна |
| «Только ненасилие» | Не работает: на невосприимчивых нужно давление |
| Ритуализм vs садхана | Ритуалы = прея (эксплуатация, кровь); садхана = нивртти, без разделений |
| Распространять идею | Конструктивной работой, не критикой |
| Одна экономическая теория для всех | Нет: оптимальна только для своего времени-места-личности |
| Профессиональные касты | Устарели; деления по касте никогда не были нужны |
| Брахма садхана vs работа | Садхана важнее; работа — её часть |

## Ум, память, психика

| Ситуация | Правило |
|---|---|
| База памяти | Читта, не мозг; отпечатки в нервных волокнах гаснут |
| Болезнь мозга vs ума | Дефект носителя ≠ дефект ума; диагностируй слой |
| «Призрак», «бог», видение | Игра ума (ка́мамая/маномая подавлены, внушение); положительная/отрицательная галлюцинация |
| Одержимость | Самогипноз; экзорцизм «лечит» нормализацией нервов |
| Дхарана | Ответы приходят из причинного ума при концентрации; «божество» — психический феномен |

## Быстрые сигналы («tells»)

- Видишь «вечное учение» на все времена — это иллюзия контекста (Q52).
- Кто-то в рясе бежит от мира в Гималаи — «Гималаи тоже в этом мире» (Q48).
- Идеология продвигается критикой врагов — вероятно, мало пользы (Q47).
- Один и тот же ритуал у разных народов — не духовность (Q46).
- «Я видел призрака» — вероятно, галлюцинация слабого ума, а не факт (Q56).
