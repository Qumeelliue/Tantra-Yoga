# Читшит — Stories of Baba (краткая справка)

## Хронология жизни (по сборнику)

| Период | События |
|---|---|
| 1921–1950-е | Детство в Баммунагре, юность и работа в Джемалпуре; «дело с огнём», школы, деревни вокруг Натнагара |
| 1955 | Основание Ананда Марги (после 1955 — рост, школы) |
| 1962–1970 | D.M.C. по всей Индии, полевая работа, whole-timers |
| 1971 | Первый арест в Патне, больница, освобождение по решению Верховного суда |
| 1975–77 | Чрезвычайное положение (Emergency): запрет, аресты работников |
| 1977 | Выход из тюрьмы (после Патнского High Court), «праздник красок», девять арок |
| 1980-е | Зарубежные поездки (самолёт вместо корабля), Prabhat Samgiit, Копенгаген |
| 1990 | Уход Бабы (вне книги) |

⚠ Хронология реконструирована по воспоминаниям и требует сверки с источниками.

## Устройство практик

| Практика | Суть |
|---|---|
| P.C. | Личная аудиенция; по списку; переживается как откровение |
| General Darshan | Общий дискурс; отвечает на непроизнесённые вопросы |
| D.M.C. | Многодневное собрание с дискурсом; «ничего не планируй после» |
| Reporting | Личный отчёт работника; опоздание = потеря ачарьяства |
| Field walk | Прогулка с Бабой; место разговоров и проверок |
| W.T. / S.P.T. | Штатное служение; в S.P.T. просили еду молча |

## Методы обучения Бабы (быстрая справка)

| Ситуация | Приём | Пример |
|---|---|---|
| Исправить поступок | Учительная притча → вопрос о значении | Бхайрав, «длинные рукава», Рамаджани |
| Скрытое поведение | Точная деталь-доказательство | Мыло, кофе и поза сна, блоки |
| Сомнение в знании | Мысленный тест-условие | «Повернётся дважды» |
| Проверка честности | Ситуация-тест | Гурпиту, билет, шестнадцать пунктов |
| Отказ от переживаний | Притча о собаках у листьев | «Цель одна — познать Парамапурушу» |
| Расфокус | «Цель одна, не многие» | Наставление после D.M.C. |

## Быстрые ориентиры по людям

- **Baba** — гуру, организатор, «два глаза всегда следят».
- **P.A.** — посредник P.C. и быта.
- **G.S.** — генсек; фигурирует в сценах дисциплины.
- **Ачарьи / L.F.T. / W.T.** — иерархия работников.
- **M.N. Roy / Subhas Bose** — известные посетители молодости (Ch 9).

## Быстрые сигналы («tells»)

- Видишь прямую нотацию у «Бабы» — скорее всего, авторское переложение; в оригинале — притча или вопрос.
- Деталь-доказательство (кофе, мыло, номер блока) — маркер темы всеведения.
- Голодовка/отказ от еды — инструмент принципа, а не слабость.
- «Свапнил паривеш» (обстановка сновидения) — язык описания духовной атмосферы.
- Числа (3000 лет, 99%, 1 рупия) — воспоминания, ⚠ к калибровке.
