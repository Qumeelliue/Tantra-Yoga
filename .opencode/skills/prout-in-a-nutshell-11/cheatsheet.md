# Читшит — правила решений по Саркару (Prout 3 Part 11)

## Мораль и поведение

| Ситуация | Правило |
|---|---|
| Применять ли силу против нападающего | Если нападающий — átatáyii (грабит/похищает/угрожает оружием/поджигает/травит) и иного выхода нет — сила = доблесть, не хи́мса |
| Сказать «правду», которая ранит | Служи благополучию (satya), а не факту (rta): защити преследуемого, щади больных |
| Сколько накапливать | Aparigraha: только необходимый для жизни минимум; минимум относителен времени-месту-личности |
| Брак vs целибат | Брак — естественная функция, не грех; брахмачарья = видеть Brahma во всём, а не «хранить семя» |
| Кому помогать в тапасе | Только реально нуждающимся и слабейшим; «накорми голодного, а не банкетируй богача» |
| Помощь без проверки нуждаемости | Искажает тапас: богатый скряга станет скупее, а ты — подавлен |
| Громкая молитва/пение вслух | Бесполезна; лучший джапа — ментальный (mánasika) |

## Страдания и цели

| Ситуация | Правило |
|---|---|
| Средство «снимает проблему» | Вернётся ли она? Да → artha (временно), закрывай и корень → paramártha |
| Голодному проповедуют духовность | Сначала еда/кров (káma), потом медитация; PROUT — обязательный первый этаж |
| Мысль «я грешник» | Опасна: «как думаешь — таким станешь»; прими убежище в Parama Puruśa |
| Комплекс превосходства/неполноценности | Лечи социальный порядок, а не мотивацию; в духовном комплексов нет — это право рождения |
| «Как я, низкий, пойду к Отцу?» | Это mahimnabodha (ложная скромность): ребёнок не стесняется великого отца |

## Общество и экономика

| Ситуация | Правило |
|---|---|
| Часть общества отстаёт (нет еды/денег) | Ты не в духе Saḿgacchadhvaḿ — «двигайтесь вместе»; PROUT стоит на этом шлоке |
| Разделение на «своих/чужих» (каста, нация) | Враждебно человечеству; единственный «изм» — универсализм |
| Распределение богатства | Богатство вселенной — общее достояние; коллективное распределение — обязанность |
| Накопление без согласия коллектива | Запрещено первым принципом PROUT |
| Диагноз бедствия | Локализуй стратум: физическая нужда → распределение; психическая → поддержка/благодать; духовная → садхана |
| Усилий человека «мало» или «много» | Усилие обязательно, но «чуть-чуть» космической милости незаменимо (Mahat krpayaeva…) |

## Контент и коммуникация

| Ситуация | Правило |
|---|---|
| Оценить произведение | Определи тип: kávya (ясность), puráńa (поучение через вымысел), itikathá (хроника), itihása (благотворная история с моралью) |
| «История» в школе — это? | Скорее itikathá (хроника); itihása учит четырём varga и моральному кодексу |
| Коммуникация «не доходит» | Проверь символизацию: не Абсолют ли выражаешь, насколько символ полон, отвечает ли он времени-месту-личности |
| Требовать «традиционных форм» в искусстве | Ошибка («рай дурака»): выражение обязано отражать век |
| Гений vs мастер | Гений — от рождения; техник — навык через усилие и садхану; сокращать зазор — долг обоих |

## Быстрые сигналы («tells»)

- Видишь комплекс у человека — ищи строевую причину (рабство/наследство), а не «характер».
- Решение «всегда работает» без проверки нуждаемости — вероятно, искажённый тапас.
- Проповедь без еды голодному — обман и жесткость.
- Двусмысленная речь при решении судьбы людей — нарушение saḿvadadhvaḿ.
- Один накопил больше всех — он отнял у другого; деньги конечны.
- Хроника без морали на почетном месте — itikathá, а не itihása.
- Пять принципов PROUT (памятка): (1) накопление лишь с согласия коллектива; (2) максимум использования и рациональное распределение всех потенциалов; (3) максимум использования физических/метафизических/духовных потенциалов единиц и коллектива; (4) корректировка между этими использованиями; (5) прогрессивный метод, меняющийся по времени-месту-личности.
