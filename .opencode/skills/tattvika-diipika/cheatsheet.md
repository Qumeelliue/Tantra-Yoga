# Читшит — Táttvika Diipiká

| Ситуация | Правило |
|---|---|
| Главный долг таттвики | Пропаганда коллективного блага (Satya → Shiva); только Satya, с объяснением причин |
| Оппонент грубит / заблуждается | Не отвечай грубостью; мягко объясни; поведение друга, не инструктора; «ты глуп, я мудр» — запрещено |
| Публикуешь материалы | Tattva Sabha: факты об идеале Марги; не ради партии, для блага массы |
| Говоришь с платформы | Press: не славословь партию; не создавай делений; чувство единства всех живых |
| Объясняешь Satya конкретному человеку | Proper approach: его форма (Shúdrocita/Vaeshyocita/Kśatriyocita/Viprocita), его родной язык, взвешенные слова |
| Цена книги | С учётом экономического положения народа |
| Праздник/собрание | Utsava: дети первыми, 2–3 пункта старикам, полная дисциплина, совместная еда, всем художникам — сцена |
| Во время shúdrocita-sevá | Не веди пропаганду; служение самоценно |
| Оцениваешь «общество» | Двигаются ли вместе как паломники? Есть ли место слабым? Или деления эксплуатируют других? |
| Права и ответственность | Принадлежат всем; разрыв → судьба всех в руках доминирующей группы |
| Культура | Утончение инстинктов; лицемерие («сухой пост» после тайного стакана) — антипод |
| Játakarma (новорождённый) | Социальное признание; участвовать может любой; мантры на родном языке; ребёнок — проявление Brahma |
| Ответственность за ребёнка | Коллективная (не только родители); минимум — дети в окружении |
| Эксплуатация | Против; лечи не «мазью», а ускорением; скорость = настройка время–место–личность |
| Инициация | В 5 лет (до — физиология не готова; после — пороки 5–15); высшие уроки с 15–16 |
| Брак | Не раньше созревания тела: 18 (жен.) / 22–26 (муж.) ⚠ |
| Возможный корыстный интерес | Дикша — социальный долг, не бизнес; обряд без ачарьи ведёт старший мужчина |
| Имя и титул | Единый титул Deva; санскрит-имя (единый стандарт); согласие обязательно |
| Вход в новый дом | Grha Pravesha: первой входит женщина (Grhińii grhaḿ ucyate) |
| Вермильон (sindúr) | Украшение, часть одежды; не куса́мска́ра; свинцовый — риск отравления ⚠ |
| Местный язык | Не пренебрегай: Будда распространил буддизм проповедью на местном языке |
