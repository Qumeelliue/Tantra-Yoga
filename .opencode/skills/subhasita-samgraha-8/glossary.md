# Глоссарий — Subháśita Saḿgraha Part 8

**Ábhoga** — психический «пиабал»: форма, которую ум принимает при контакте с объектом/идеей; освобождение от пиабала — условие мира (ch05).

**Abhyása** — непрерывная практика, постоянная психическая вибрация; в паре с vaerágya (ch05).

**Ahaḿtattva** — «doer-I», средняя камера ума (ch01).

**Ánanda vrtti** — единственная пропенса блаженства после свертывания всех vrttis (ch01).

**Ávarańii shakti** — сила avidyámáyá: завеса «меня никто не видит» (ch07).

**Avidyámáyá** — центробежная сила от nucleus к материи (ch07).

**Bhavánii / Bhaeravii / Kaośikii Shakti** — три стадии Prakrti: кривизна (мир), прямая линия (náda), равновесие; восхождение преданного — обратное (ch02).

**Bhágavata dharma** — врождённое влечение к Supreme; три фактора: vistára, rasa, sevá (ch08).

**Bodhi** — интуиция (mahat больше aham) (ch01).

**Citta** — грубейшая камера ума, «done-I» (ch01).

**Citi Shakti** — Когнитивная Сила; пять качеств: shuddhá/anantá/aparińámii/apratisaḿkramá/darshita viśayá (ch02, ch04).

**Diipanii** — «факел»: понимание внутреннего смысла мантры перед повторением (ch03).

**Dŕśt́a / adŕśt́a vedaniiya karma** — реакции в этой жизни / в следующих («судьба») (ch06).

**Ekágra** — состояние сосредоточенности; база настоящего samádhi (ch04).

**Jaŕa samádhi** — «samádhi» на грубом объекте; ум превращается в объект (ch04).

**Japakriyá** — повторение мантры с параллелизмом ментального потока (ch03).

**Karmáshaya** — связка неотработанных самскар (ch06).

**Klesha** — болезненные пропенсы; классы: pramáńa/viparyaya/vikalpa/nidrá/smrti (ch04).

**Kśipta / múrha / vikśipta / ekágra / nirodha** — пять состояний ума (ch04).

**Kuńd́alinii** — «спящая божественность»; пробуждение = интуиция (ch01, ch03).

**Mahápátaka** — грех без искупления с повторяющимся эффектом (ch07).

**Mánasá / maniiśá** — грубый ум / интеллект (шкала ума) (ch01).

**Mahattattva** — «existential-I», тончайшая камера ума (ch01).

**Mantra caetanya** — «пробуждение мантры»: психическая ассоциация и понимание духа (ch03).

**Mokśa / pranásha** — полное слияние с Supreme Cause (ch04).

**Paiṋcamakára (5 М)** — грубая форма: контролируемое утоление желаний; тонкая (yoga márga): духовные смыслы (ch03).

**Pratisaiṋcara / Saiṋcara** — фаза возврата (грубое→тонкое) / творения (тонкое→грубое) (ch01).

**Pratyávaya** — грех несовершения должного; вреднее paapa (ch07).

**Pratyayamúlaka / samskáramúlaka karma** — оригинальное действие / реакция (ch06).

**Puruśakhyáti** — установление в Supreme Cognitive Faculty; полная самоотдача (ch06).

**Rágánugá / rágátmiká bhakti** — ступени чистой бхакти: «люблю ради моей радости» / «ради Его радости» (ch07).

**Rasa / svarasa** — поток; Космический vs индивидуальные потоки (ch08).

**Samprajiṋáta (= savikalpa) samádhi** — citta одной волной; ступени: savitarka/savicára/sánanda/sásmita (ch04–ch05).

**Samskára** — реакция в потенции; разрушается равной противоположной вибрацией (ch06).

**Sevá** — служение без ожидания возврата; внешнее/внутреннее (ch08).

**Shraddhá** — венация после логики; «расширение citta»; первая ступень к samádhi (ch02, ch05).

**Shuddhá bhakti** — чистая преданность (pará bhakti); ступени rágánugá/rágátmiká (ch07).

**Vaedhii bhakti** — формальная преданность; типы: támasikii/rájasikii/sáttvikii (ch07).

**Vaerágya** — отсутствие привязанности (НЕ отвращение) (ch05).

**Vásanábháńd́a** — «горшок желаний»; хранилище реактивных моментов (ch06).

**Vidyámáyá** — центростремительная сила к nucleus; инструменты: samvit/hládinii (ch07).

**Viparyaya / vikalpa / nidrá / smrti** — ложное знание / слова в переносном смысле / сон-вакуум / память (ch04).

**Viirya** — духовная выносливость (ch02, ch05).

**Vistara** — расширение ума к Космической Сущности (ch08).

**Vrttis** — пропенсы/склонности ума; число убывает с развитием интуиции (ch01).

**Vikśepii shakti** — сила avidyámáyá: отталкивание от nucleus (одержимость) (ch07).
