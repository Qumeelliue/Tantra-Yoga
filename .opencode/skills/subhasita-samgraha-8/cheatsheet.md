# Читшит — Subháśita Saḿgraha Part 8

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Ум застрял на обиде/конфликте | Меняй объект идеации: думай о Supreme, а не о дефектах оппонента (ch07) |
| Хочешь понять, «настоящий ли samádhi» | Проверь состояние: из ekágra? Объект тонкий? Есть vaerágya (без отвращения)? (ch04–ch05) |
| Не можешь отказаться от сильной привычки | Не подавляй: введи контролируемое ограничение как мост к тонкому пути (ch03) |
| Учёный «застрял» в знании | Дай задачу действия: action − knowledge = devotion (ch07) |
| Выбираешь форму практики | Идеация на Brahma > dhyána > japa/stuti > идолы (ch03) |
| Оцениваешь «служение» организации | Вопрос «что возвращается?» Возврат = сделка, не sevá (ch08) |
| Человек жалуется на «судьбу» | Судьба = реакция на неизвестное прошлое; действие + идеация меняют горшок желаний (ch06) |
| Видишь показную религиозность | Ритуал без внутреннего смысла = низшая ступень (Vaedikácára) (ch03) |
| Просят «спасти от наказания» грешника-манипулятора | Проверь тип: pátaka/atipátaka/mahápátaka; последний неискупим (ch07) |
| Чувствуешь «меня никто не видит» | Ávarańii shakti: всё видно третьей сущности (ch07) |
| Хочешь измерить прогресс ума | Смотри шкалу: citta-доминанта → intellect → intuition; число пропенс уменьшается (ch01) |

## Мини-справочник «типы бхакти»

| Тип | Формула/признак | Результат |
|---|---|---|
| támasikii | просит навредить врагу | ни liberation, ни salvation |
| rájasikii | просит мирские блага | ни liberation, ни salvation |
| sáttvikii | «покажу религиозность» | ни liberation, ни salvation |
| rágánugá | «люблю — мне радостно» | ступень к слиянию |
| rágátmiká | «люблю — Ему радостно» | слияние с Supreme |

## Мини-справочник «категории греха»

| Термин | Смысл | Искупимость |
|---|---|---|
| paapa | вредящее действие | — |
| pratyávaya | несовершение должного | вреднее paapa |
| pátaka | компенсируемый ущерб (возврат украденного) | искупимо |
| atipátaka | неискупимое (напр. отрубить руку невинному) | нет |
| mahápátaka | неискупимое + повторяющийся эффект | нет |

## Мини-справочник «состояния ума → база samádhi»

| Состояние | Характер | Samádhi? |
|---|---|---|
| kśipta | бешеное (гнев) | jaŕa |
| múrha | слепая привязанность | jaŕa |
| vikśipta | рассеянное | jaŕa |
| ekágra | сосредоточенное | да: savikalpa → nirvikalpa |
| nirodha | приостановленное | вершина практики |
