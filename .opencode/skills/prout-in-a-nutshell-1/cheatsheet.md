# Читшит — правила решений по Саркару (Prout 1)

## Социально-экономический анализ

| Ситуация | Правило |
|---|---|
| Определить, кто сейчас у власти | Спроси: какой класс/ресурс незаменим в эту эпоху? (сила → интеллект → производство/деньги → число работников) |
| Класс доминирует | Он эксплуатирует остальных → смена доминанта проблему не решает |
| Доминант-большинство | Аффлюенты не бывают большинством — только работники; их подъём предсказуем |
| Построить справедливую систему | Общество без делений и дискриминации; равные возможности; иначе «гнездо ткача» |
| Оценить благополучие человека | Бедность = много желаний; довольство ума — признак достаточности |

## Цель и счастье

| Ситуация | Правило |
|---|---|
| Понять, утолит ли цель | Если цель конечна — разожжёт аппетит; бесконечное насыщает только Бесконечное |
| Найти dharma человека/системы | Dharma = природа. Огонь жжёт; человек ищет Космическое Сущее |
| Человек ведёт себя «хуже животного» | Не использует ясно-отражённое сознание — теряет право называться человеком |

## Искусство и литература

| Ситуация | Правило |
|---|---|
| Оценить произведение | Тест благости: всестороннее развитие + движение с народом + радость + связь причин/следствий |
| Выбрать режим творчества | Эпохе служат на языке народа (yuga); вечности — тонкие теории (tat́astha) |
| «Искусство для искусства» | Отвергнуто: искусство оправдано служением обществу |
| Решать о пристойности | Середина: ни ханжество, ни спекуляция на низком; ведущее — благость и радость |
| Оценить художника | По силе характера и духовному голоду (genius), а не по технике |
| Награды/рейтинги | Только от неполитического совета; гос. награды = пропаганда |

## Экономика творцов

| Ситуация | Правило |
|---|---|
| Как издаваться | Авторские кооперативы; не монополисты-издатели, не государство |
| Кто обязан поддерживать художников | Общество; государство как представитель народа (театры, гонорары за показы, галереи-библиотеки) |
| Как поддержать живопись/скульптуру | Галереи-библиотеки (выдача оригиналов), выставки, обучение эстетике |
| Критика | Компетентна + сочувствующая; за авторитет — ответственность; неуспешные авторы — худшие критики |

## Быстрые сигналы («tells»)

- Видишь награду от государства партийно-ангажированной — вероятна пропаганда, а не искусство.
- Текст «взахлёб» эксплуатирует сексуальное/низкое — коммерческая спекуляция, не сахитья.
- Критик, не создавший ничего сам, разносит всех — вероятно, выдаёт собственные провалы.
- Произведение идёт «на шаг-два впереди» народа — здорово; на сто шагов — прибрежное/оторванное.
- «Чистюля» от искусства избегает болезненных тем — ханжество (правый тупик).
