# Читшит — правила решений по Саркару (Subhasita 20)

## Идеология и мотивация

| Ситуация | Правило |
|---|---|
| Есть принцип, нет вдохновения | Добавь Ишту (личный объект любви/миссии) — иначе сердце «бесплодно» |
| Есть личная любовь, нет принципа | Добавь идеологию — иначе «буддийские матери»: общая Ишта при разной идеологии = конфликт |
| «Нет сил» | Используй всю имеющуюся силу до предела, потом проси больше; мужество придёт по силе |
| Просить сверх усилия | Не проси, пока не исчерпал своё: «сначала сделал лучшее, потом право просить» |

## Эшана и фокус

| Ситуация | Правило |
|---|---|
| Много целей/устремлений | Двойная эшана = работа не сделается; сведи к одному верховному объекту |
| Желание возникло | Спроси «с чем была ассоциация?» (закон Abhoga) — управляй окружением, не только желанием |
| Эшана к конечному | Это а̄сакти (привязанность) — плохой смысл; к бесконечному — бхакти |
| Нет эшаны | Существование в опасности аннигиляции: найди верховное устремление |

## Аститва и исходы

| Ситуация | Правило |
|---|---|
| Внешнее ≠ внутреннее («хочу Господа» + глубокая жажда славы) | Глубинная цель исполнится → Пракртилина (Jada-самадхи), почти необратимо |
| Практика без наставника/цели | Видехалина: «лодка без руля»; сначала направление, потом действие |
| Оценить стадию практики | Bhava (двойственность) → Gunatmaka (качества) → Shiva (без эго); цель — высшая |
| «Революция» как разрушение | Поджог автобусов вредит людям; разрушение — не направление |

## Преданность и служение

| Ситуация | Правило |
|---|---|
| «Духовность» без действия | Себялюбие (khudaparasti); настоящая преданность не слепа к социальному/экономическому страданию |
| Связать личную цель и пользу | Формула: самосовершенствование ↔ благо мира (Atma moksartham jagat hitaya ca) |
| Просьба к Господу | Проси только parábhakti (абсолютную преданность); «дай мне X» — не преданность |

## Быстрые сигналы («tells»)

- Слышишь «у меня нет сил/мужества» → не использовал имеющуюся силу (мужество по силе).
- «Хочу и Господа, и сдачи экзамена» → двойная эшана, жди провала.
- Человек декларирует одно, а в глубине желает славы → риск Пракртилины.
- «Я делаю садхану по книгам» → риск Видехалины без прецептора.
- «Наш путь — слияние», но эго на месте → ещё не Shiva Samadhi (стадии Bhava/Gunatmaka).
- Преданность без заботы о людях → себялюбие; «не понял Господа».
- За «единицу любви» ожидай «двойную любовь» в ответ — механика взаимности.
