# Чит-шит — Ánanda Vacanámrtam Part 9

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Оценить человека | Три «я»: думать/говорить/делать совпадают = superior |
| Хвалить Бога | Kiirtana громко (слышно другим), не japa (мысленно) |
| Где пребывает Hari | В Hariparimańd́ala, где поют kiirtana (не в покое) |
| Выбрать имя Бога | Одно (Ekbuddhi): внутри/снаружи, в беде/благополучии |
| «Я не смогу» | Vishvása: «должен преуспеть»; критика не важна |
| Комплексы | Все 4 (inferiority/superiority/defeatist/escapist) — болезни; все — дети Отца |
| Гуру | 1-й класс: объясняет + следит + наказывает (Nigrahánugraha) |
| Еда | Pramitáhára: мало, но питательное (≠ parimita) |
| Сделал зло | Pátaka: компенсируй (вернуть + интерес) |
| Необратимый вред | Atipátaka: только духовное посвящение Paramátmá |
| Пример-зло (фальсификация) | Mahápátaka: recurring; посвящение жизни служению |
| Не сделал добро | Pratyaváya — грех (хуже pátaka) |
| «Я грешник» | Даже sudurácárii спасается неделённым вниманием (Гита) |
| Начать са́дхану | Кииртана → медитация сразу после |
| Скорбь | Помни: мир из блаженства; в конце — колени Отца |
| Усталость/груз | Вычерпай воду из лодки (са́мска́ры); Hari крадёт их |
| Служение | «Долг перед другими, но никто не должен мне» |
| Уважение | Уважай непризнанных (ápani, не tumi/tui по богатству) |
| Действие | Юги — состояния: лежишь (Kali), движешься (Satya) |
| Право на спасение | Нужна только человеческая структура; каста/пол/учёность не важны |
| Дискриминация | Психо-экономическая эксплуатация; один Отец — одна «каста» |
| Скрыться от Него | Нельзя: Он manomaya, слышит мысли; признай «сегодня боюсь» |
| «Я вижу Его» | В медитации наоборот: «Он видит меня» |
| «Настоящее» | Не существует: прошлое+будущее |
| Ад/рай | Состояния тьмы/света в Его уме; Он master обоих |

## Шесть причин успеха (шлока Shiva)

1. Vishvása — «должен преуспеть»
2. Shraddhá — движение к высшей истине (shrat)
3. Gurupújana — почитание гуру (1-й класс наказывает)
4. Samatábháva — равный взгляд без комплексов
5. Indriyanigraha — контроль органов
6. Pramitáhára — умеренная питательная еда
7. «Saptamaḿ naeva vidyate» — седьмого нет (+ kiirtana)

## Три класса гуру

3-й: объясняет и всё · 2-й: объясняет + проверяет · 1-й: объясняет + следит + наказывает

## Четыре ноги dharma

Vistára (расширение) · Rasa (поток) · Sevá (служение) · Mokśa (turiiya)

## Виды pápa/puńya

- Pátaka (компенсируемо) → Atipátaka (духовное посвящение) → Mahápátaka (recurring; жизнь ради идеала)
- Pratyaváya: не сделал добро (хуже pátaka)
- Puńya: pratyakśa (прямое) + apratyakśa (косвенное, веками)

## Кииртана-градация звука

mánasokti (на губах) → upáḿshu (не выходит) → vácanika (в ухо) → kiirtana (на расстоянии) — только последнее kiirtana
