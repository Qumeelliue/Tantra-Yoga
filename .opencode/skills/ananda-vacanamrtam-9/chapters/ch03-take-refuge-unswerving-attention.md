# Chapter 3: "Take Refuge in Parama Puruśa with Unswerving Attention"

*Дискурс 3, 27 февраля 1979, Джамму.*

## Core Idea

Karma = изменение положения объектов; nitya (нейтральное) и naemittika (по стандартам → puńya/pápa). Виды puńya (прямое/косвенное) и pápa (pátaka/atipátaka/mahápátaka) с атонениями; Гита: даже sudurácárii спасается неделённым вниманием.

## Frameworks Introduced

- **Karma**: изменение положения объектов; нет изменения — нет karma. Nitya karma (нейтрально) + naemittika karma (occasional; по стандартам → puńya, нет → pápa).
- **Puńya**: прямое (накормить голодного/напоить; добро другим + собственное возвышение — ближе к Paramátma) + косвенное (посадка дерева, канал; задержка, но длится тысячи лет). Косвенное — 2 типа (немедленное благо vs отложенное).
- **Pápa**: harm другим + собственное падение. **Pátaka** (сделал, что нельзя; компенсируемо: вернул + интерес + просьба прощения → смыто). **Atipátaka** (некомпенсируемо: отрезал пальцы; соц. атонения нет; духовное — посвятить себя Paramátmá). **Mahápátaka** (recurring: фальсификация перца папайей; Равана). Атонение: pátaka — мгновенно компенсацией; atipátaka/mahápátaka — духовно, пока не придёт mercy Paramátmá; соц. атонение через соц. службу, но прощение греха даёт только Paramátma.
- **Равана-эпизод**: похитил Sita в облике садху → женщины больше не доверят садху (recurring) → mahápátaka; Shiva не спас. Термины: pátaka = duśt́a, atipátaka = dúrácárii, mahápátaka = sudúrácárii. Избегать всех трёх.
- **Гита**: `Api cet sudúrácáro bhajate Mámananyabhák; So'pi pápavinirmuktah mucyate bhavabandhanát.` Даже sudurácárii с неделённым вниманием («Mámananyabhák») освобождается.

## Key Concepts

- **Nitya/naemittika karma** — регулярное/окказиональное действие.
- **Pátaka/atipátaka/mahápátaka** — по компенсируемости.
- **Duśt́a/dúrácárii/sudurácárii** — синонимы грешников.
- **Ananyabhák** — неделённое внимание.

## Mental Models

- «Добро — прямое и косвенное; косвенное длится веками».
- «Некомпенсируемое зло атоняется только духовным посвящением».
- «Recurring-зло (пример-зло) — mahápátaka».
- «Даже худший спасается неделённым вниманием».

## Anti-patterns

- **Считать кражу смытой без компенсации** — нужен возврат + интерес.
- **Равнять mahápátaka с pátaka** — разные атонения.
- **Отчаиваться за sudurácárii** — Гита даёт надежду.

## Worked Example

Пример-Rávańa: похитил Sita в облике садху. Если бы как вор — atipátaka; но как садху — mahápátaka (рекуррентное недоверие к садху; будущие злодеи притворятся садху). Парвати просила спасти; Shiva отказал. Соц. атонения нет; только посвящение жизни духовному идеалу и служению.

## Key Takeaways

1. Naemittika karma по стандартам = puńya/pápa.
2. Puńya: прямое + косвенное (долговечное).
3. Pátaka компенсируемо; atipátaka — только духовно; mahápátaka — recurring, атонение через посвящение.
4. Равана — mahápátaka из-за облика садху.
5. Гита: даже sudurácárii освобождается неделённым вниманием.
6. Социальное прощение греха даёт только Paramátma.
