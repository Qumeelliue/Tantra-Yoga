# Chapter 14: Parama Puruśa Is Everywhere

*Дискурс 14, 5 апреля 1979, Патна.*

## Core Idea

Шлока Yajurveda `Apáńipádo javano grahiitá...`: Parama Puruśa без рук/ног/глаз/ушей, но всё принимает, движется, видит, слышит — у Него только внутренний мир. В медитации: «Он видит меня». Mahat vs brhat.

## Frameworks Introduced

- **История письма/Vedas**: Vedas ~15000 лет назад ⚠; письмо изобретено ~5500 лет назад (Saendhavii, Mahenjodaro); Bráhmii (справа налево) и Kharośt́ii (слева направо); при Ashok Bráhmii преобладала. До письма знание — через слух (shru + ktin = shruti). 60% Vedas осталось, 40% потеряно ⚠. Разделение: Rgveda (rk, древнейшая), Yajurveda (yajuh = ритуалы; ardhvayyu), Atharvaveda (atharva = старый; brahmań); Sámveda = сборник песен (sáma; Udgátá; Hotá — связной).
- **Шлока Apáńipádo**: apáńipáda = без рук/ног; javano grahiitá = блуждающий, но принимающий (внутренне); acakśu = без глаз, но видит; akarńa = без ушей, но слышит. Для человека два мира (внутренний/внешний); для Него один — внутренний; всё из Его психического воображения.
- **Знание**: vedya = познаваемое; у Него нет внешнего мира; знает всё (страницы книг); `na ca tasyásti vettá` — никто Его не знает (Он — субъект всех). Медитация: не «я вижу Parama Puruśa», а «я сижу перед Ним, Он знает всё моё». Конечный человек не может познать бесконечного.
- **Mahat vs brhat**: vishála = измеримое (Гималаи — на карте); brhat = неизмеримое (Brahma; brhattvád brahma brḿhańattvád brahma); mahat = великое в психическом смысле (маленький ростом, великий знанием). `Tamahuragryaḿ puruśaḿ mahántam` — agrya = передовой/представительный; mahána = величайший.

## Key Concepts

- **Shruti** — знание через слух; Vedas.
- **Apáńipádo javano grahiitá** — без рук, но принимающий.
- **Внутренний мир** — единственный для Него.
- **Mahat vs brhat vs vishála** — психическое/неизмеримое/измеримое.

## Mental Models

- «Медитация: не ты видишь Его, а Он тебя».
- «Знание — субъективизация; Его знание без органов».
- «Не измеряй неизмеримое (brhat); цени психическое величие (mahat)».

## Anti-patterns

- **Медитировать «я вижу Его»** — обратная психология.
- **Считать знание только через органы** — для Него всё внутреннее.
- **Смешивать mahat и brhat** — разные сферы.

## Worked Example

Пример-подношение: человек в Патне мысленно подносит что-то Parama Puruśa (tava dravyaḿ jagatguro...); Он принимает без «мирских» рук — всё в Его уме.

## Key Takeaways

1. Parama Puruśa без органов, но всё принимает/видит/слышит.
2. У Него один мир — внутренний.
3. Медитация: «Он видит меня», не наоборот.
4. Никто Его не знает — Он субъект всех.
5. Mahat (психическое) ≠ brhat (неизмеримое) ≠ vishála (измеримое).
6. Shruti — знание через слух; Vedas устные до письма.
