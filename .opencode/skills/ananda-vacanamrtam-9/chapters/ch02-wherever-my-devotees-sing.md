# Chapter 2: "Wherever My Devotees Sing"

*Дискурс 2, 25 февраля 1979 (вечер), Джамму.*

## Core Idea

Hari пребывает не в vaekuńt́ha и не в сердце йога, а там, где преданные поют kiirtana (Hariparimańd́ala). Kiirtana создаёт волну блаженства, идеальную для последующей медитации.

## Frameworks Introduced

- **Táńd́ava уровни**: tańd́u = прыгать; tańd́ula = рис (прыгающие зёрна). Brahmatáńd́ava (колено к пупку/выше), viśńutáńd́ava (колено выше anáhata), rudratáńd́ava (колено выше vishuddha). ⚠ детали из дискурса.
- **Hariparimańd́ala**: кииртана создаёт среду; волна исходит из ядра среды; siddha mantra (aśt́ákśarii — 8 слогов) создаёт специальную волну.
- **Шлока**: `Náhaḿ tiśt́hámi vaekuńt́he yogináḿ hrdaye na ca; Madbhaktáh yatra gáyanti tatra tiśt́hámi nárada.`
- **Vaekuńt́ha** = kuńt́há (контракция) ушла; ум без контракции; не «далёкая страна». Но там нет волны kiirtana — блажен лишь один.
- **Yogi**: cittavrtti приостановлены; сердце — сухая пустыня (нет сладости rasa); никто не получает блаженство, кроме йога.
- **Hari — в Hariparimańd́ala**: madbhaktáh yatra gáyanti tatra tiśt́hámi. Блаженство kiirtana → медитация сразу после даёт великое блаженство. Kiirtana — обязательный долг каждого аспиранта.
- **Этимология**: nára (вода / Paramá Prakrti / преданность) + ayańa (shelter) = Náráyańa (shelter Prakrti); Nárada = «дающий преданность» (nára + da).

## Key Concepts

- **Vaekuńt́ha** — состояние без контракции ума.
- **Hariparimańd́ala** — среда кииртаны с волной блаженства.
- **Raso vae sah** — He полон rasa (сладости).
- **Nárada/Náráyańa** — этимология (shelter Prakrti).

## Mental Models

- «Hari не в покое, а в движении бхактов: там, где поют».
- «Сердце йога — сухая пустыня без кииртаны».
- «Kiirtana → волна → медитация с блаженством».
- «Сладость (rasa) распространяется в круге, не в одиночестве».

## Anti-patterns

- **Считать vaekuńt́ha местом** — это состояние без контракции.
- **Ограничиваться личным блаженством** — kiirtana распространяет его.
- **Тихая кииртана** — волна не эманирует.

## Worked Example

Пример-вопрос Нарады: «Ты везде, но где Твой nucleus?» Ответ: там, где преданные поют kiirtana. Если бы Он был в сердце йога (пропенситы приостановлены), блаженство не вышло бы наружу; в кииртане rasa разливается.

## Key Takeaways

1. Hari пребывает в Hariparimańd́ala, где преданные поют.
2. Vaekuńt́ha = отсутствие контракции, не место.
3. Yogi в приостановке — «сухая пустыня» без сладости.
4. Kiirtana создаёт волну блаженства и готовит к медитации.
5. Náráyańa = shelter Paramá Prakrti; Nárada = дающий преданность.
6. Kiirtana — долг каждого духовного искателя.
