# Читшит — правила решений по Саркару (AMPN 8)

## Разрушение и спасение

| Ситуация | Правило |
|---|---|
| Наказание/удаление зла | Цель — vinaasha (метаморфоза к лучшему), не pranaasha (аннигиляция) |
| Временная помощь | Это traana — повторяется; строй paritraana (вечное благо) |
| Внешняя святость (пепел, одежда) | Не критерий: sádhu — по честной жизни, благу других, постоянной Бог-сознательности |
| Мораль без якоря | Падает при больших искушениях — нужна дхармическая основа |
| Переходная эпоха | Yuga sandhi — время, когда необходим приход великой личности |

## Дуализм и слияние

| Ситуация | Правило |
|---|---|
| «Я и мой Господь» | Начальная стадия; в конце дуализм не выживает (1+1=2→1+1=1→1+1=?) |
| Движение к центру | Через преданность; знание/действие лишь разжигают её |
| Тип слияния | Jiiva–Брахма: unified (sugar-water), не united (sugar-sand) |
| Учение без начала | «Что без начала — без конца»: требует ответа о происхождении |
| Плен ума | Число ментальных объектов; один всеобъемлющий объект = свобода |

## Дхармы и грех

| Ситуация | Правило |
|---|---|
| Приоритизация целей | Первичная дхарма = «1»; upadharmas = «нули»; без единицы нули ничего не стоят |
| Делать злое | Paapa — «делать, что не следует» |
| Не делать доброе | Pratyavaaya — «не делать, что следует»; оба = pataka |
| Чувство вины/безнадёжности | Грех — временное отражение (зеркало и роза); вблизи Господа впечатления стираются |
| Спасение | «Vrindavana в твоём уме» — путь внутрь, имя Господа очищает |

## Стратегия и лидерство

| Ситуация | Правило |
|---|---|
| Сильный противник | Стратегическое отступление из силы = «два шага назад, сто вперёд» (Мадхура→Дварака) |
| Судить великого | Три канала: слова / дела / умолчания |
| Борьба в практике | Sádhana — непрерывный бой с препятствиями; снятие их ведёт к слиянию |
| Праведность | Не отступать морально; отступать тактически; объединять праведных |

## Акустика и язык

| Ситуация | Правило |
|---|---|
| Буква/звук слова | Неси идеацию: am — яд, ah — нектар; контролируй ментальность речи |
| Речь «не идёт» | Сбой на одной из 6 стадий (paraa→pashyanti→madhyamaa→dyotamaanaa→vaekharii→shrutigocará) |
| Onm | a(творение)+u(сохранение)+m(разрушение)+точка(непроявл.)+полумесяц(проявление); rr — сверх-корень |
| Пропенсити человека | ka-надежда, kha-беспокойство, ja-эго, na-moha, pa-отвращение, dha-жажда… |
| Удаление буквы | Нельзя: все 50 — каузальные матрицы |
| 6 врагов | ripus: kama, krodha, lobha, mada, moha, mattsarya |
| 8 пут | ghrna, shanka, bhaya, lajja, jugupsa, kula, shiila, maana |

## Быстрые сигналы («tells»)

- Философия объясняет конец, но молчит о начале — вероятен скрытый дефект.
- «Святость» по пеплу и имени без дел — не sádhu, а «осёл из человеческой утробы» (Шива).
- Наказание «навсегда» — признак pranaasha-мышления, чуждого Господу.
- «Не хочу стать сахаром, хочу есть его» — дуализм, обречённый на слияние.
- Разговорчивость без содержания — vaekharii-экстраваганца, слава без спасения.
