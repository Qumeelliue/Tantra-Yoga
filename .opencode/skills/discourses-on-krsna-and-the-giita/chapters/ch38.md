# Chapter 38: Struggle Must Go On

*Дискурс 22 июня 1980, Мокама.*

## Core Idea

Борьба обязательна в четырёх сферах: экономической (эксплуатация), языковой, ментальной и духовной. Жизнь — сумма бесконечных борьб. Объединяйся: что трудно одному — легко тысячам. При благой цели победа неизбежна.

## Frameworks Introduced

- **Борьба в сферах**:
  - экономическая — против эксплуатации бедных;
  - языковая — против угнетающего языка;
  - ментальная — против тех, кто унижает или лишает моральных прав;
  - духовная — против сил, препятствующих духовному продвижению.
- **Жизнь = война из битв**: «число битв образует войну». Слова Кришны: на поле боя не беспокойся; помни благородство цели — при благой цели победа неизбежна; «выбрось в мусорное ведро силы-препятствия, как колючки с дороги».
- **Сила единства**: задача, трудная для одного, — лёгкая для 8–10; ещё легче для тысяч. «Samánii va ákútih, samáná hrdayánivah» — «пусть устремления будут едины, сердца неразделимы». Делайте все работы сообща; решайте проблемы мира легко и с улыбкой.
- **Парама Пуруша с делающим добро**: не нужно даже молиться «дай силы» — Он с тобой и даёт силы всегда. «Двигайтесь вперёд» — Yuddhasva vigatajvarah («борись без лихорадки страха»).

## Key Concepts

- **Yuddhasva vigatajvarah** — «сражайся, без тревоги».
- **Samánii va ákútih** — единство устремлений.
- Четыре сферы борьбы — экономика, язык, ум, дух.

## Mental Models

- «Любая эксплуатация (деньги, язык, достоинство, дух) требует контрборьбы».
- «Множитель победы — коллектив: 1 против N, N против 1».

## Anti-patterns

- **Одиночная борьба без единства** — трата сил.
- **Тревога на поле боя** — противоречит заповеди «вигата-джварах».

## Worked Example

Задача, невозможная для одного, становится лёгкой для 8–10 и «очень лёгкой» для тысяч: объединённые устремления решают проблемы мира.

## Key Takeaways

1. Борьба обязательна: экономика, язык, ум, дух.
2. Жизнь — война из битв; цель благородна → победа неизбежна.
3. Единство умножает силы: тысячи делают невозможное лёгким.
4. Парама Пуруша с делающим добро — силы уже даны.
5. «Йуддхасва вигата-джварах» — борись без лихорадки.
