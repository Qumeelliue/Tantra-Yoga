# Chapter 19: Dharmakśetra — the Human Body

*Дискурс 18 января 1980, Калькутта.*

## Core Idea

Дхарма — «нуменальное» свойство, контролирующее все прочие. Основная дхарма человека — манава/бхагавата-дхарма на четырёх опорах. Тело — единственное поле (кшетра) её практики; без него ум — беспомощный носитель санскар.

## Frameworks Introduced

- **Нуменальное vs феноменальное**: дхарма = нуменальное качество («одна ложь — нуменальная причина феноменальных преступлений»); идентифицирующие признаки: вода мочит, воздух сушит, огонь жжёт. Вторичные дхармы (поэзия, бизнес, политика, ораторство) — зависят от основной.
- **Основная дхарма человека**: манава/бхагавата-дхарма, четыре опоры — **vistára (расширение), rasa (поток/капитуляция), sevá (служение), tadsthiti (пребывание в Парама Пуруше)**. «Sah dharma catuspádah» — дхарма четырёхногое; потеряй ногу — охромела, не держит вторичные дхармы.
- **Полив срубленного дерева**: без основной дхармы вторичные бесполезны; человек без манава-дхармы — «уже не человек», от него ничего не жди.
- **Источник дхармы — жажда счастья**: конечные объекты не дают счастья («Nálpe sukhamasti, bhúmaeva sukham») — только бесконечное; источник бесконечного счастья = Парама Пуруша/Пурушоттама. «Sukhaḿ váinchati sarvo hi» — каждый хочет счастья, поэтому дхарма обязательна всем (vipra, kshatriya, бизнесмен, фермер, интеллектуал, рабочий).
- **Условия практики**: нужна квинквелементальная структура с нервными клетками/волокнами; без тела ум — лишь семя-санскары, не может ни грешить, ни обретать добродетель, «совершенно бесполезен»; только в теле возможно культивировать дхарму.
- **Дхармакшетра**: kśa (произношение: ригведийское k+śa, яджурведийское k+kha; бенгали — k+kha) — поле дхармы = тело. Внутри — грех и добродетель схлестнулись, точат оружие; слепой ум спрашивает совесть об исходе.

## Key Concepts

- **Ácarańat dharmah** — дхарма отражается в поведении.
- **Практика дхармы посмертно невозможна** — «даже боги для дхармы должны принять человеческую форму».
- **Kulakuńd́alinii** (контекст четырёх опор) — путь к Парама Пуруше.

## Mental Models

- «Тело = единственный полигон дхармы: нет тела → нет практики, только санскары».
- «Основная дхарма — фундамент; вторичные — постройка; строй на фундаменте».

## Anti-patterns

- **Развивать только вторичные дхармы** (бизнес/политика) при отсутствии основной — полив срубленного дерева.
- **Ждать добродетели/прогресса без тела** — бесполезное существование.

## Worked Example

Вор, ставший правдивым, перестаёт быть вором (ложь — нуменальная причина преступлений). Аналогично: человек, практикующий бхагавата-дхарму, перестаёт быть «человеком по форме лишь».

## Key Takeaways

1. Дхарма = нуменальное свойство, контролирующее прочие.
2. Основная дхарма человека = бхагавата-дхарма на 4 опорах.
3. Без основной дхармы вторичные бесполезны.
4. Источник дхармы — жажда вечного счастья.
5. Дхарма-садхана возможна только в теле (дхармакшетра).
6. В теле бьются грех и добродетель; ум вопрошает совесть.
