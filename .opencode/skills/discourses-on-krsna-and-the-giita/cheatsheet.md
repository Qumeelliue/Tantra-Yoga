# Читшит — правила решений по Саркару (Discourses on Krśńa and the Giitá)

## Кришна и имена

| Ситуация | Правило |
|---|---|
| Значение «Кришна» | Три смысла: притягивать всё к себе; «чёрный» (притягательный цвет); «Я есть, потому что Он есть» (krśibhúh) |
| Все «Кришны» | Философский, биологический (сахасрара), исторический — одна сущность |
| Значение «Рама» | Источник радости йогинов; источник всех энергий; «смерть Раваны» (убежище убивает грубую экстраверсию) |
| Бхагаван | Владелец 6 атрибутов: аишварья, вирья/пратапа, яша, шри, джняна, вайрагья |

## Махабхарата-аллегория

| Символ | Расшифровка |
|---|---|
| Дхритараштра | Слепой ум (держатель структуры тела) |
| Санджая | Совесть / вивека (сила различения) |
| 100 Кауравов | 10 индрий × 10 направлений — агенты слепого ума |
| 5 Пандавов | 5 элементов/чакр восхождения кундалини |
| Дхармакшетра | Человеческое тело (поле практики дхармы) |
| Курукшетра | Мир, вечно говорящий «делай» (kuru) |

## Дхарма

| Ситуация | Правило |
|---|---|
| Определить дхарму вещи | Дхарма = свойство/природа; опознавательный признак (огонь жжёт, вода мочит) |
| Свадхарма человека | Манава/бхагавата-дхарма, а не религия |
| Опоры бхагавата-дхармы | Вистара (расширение), раса (поток/преданность), сева (служение), тадстхити (пребывание в Нём) |
| Выбор между своей и чужой дхармой | Лучше умереть в свадхарме, чем жить по парадхарме (животному) |
| Развитие человека | Не «рациональное животное»: человек = идеологический поток к Парама Пуруше |

## Бхакти

| Ситуация | Правило |
|---|---|
| Человек просит у Бога вещи | Получит вещи, но не Его — просящий «что-то» не получает ядро |
| Низшие бхакты | Тамасика (вредить врагам) → раджасика (своя выгода) → саттвики (своё освобождение) |
| Высшие бхакты | Рагануга: «сделай как лучше для меня»; рагатмика: «только давать Тебе радость, безразлично к своим плодам» |
| Отношение к майе | Джняни боится; бхакт — нет (майя — «служанка» Парама Пуруши) |
| Майя непреодолима | Прибегнувшие к Нему пересекают её («Máyámetáḿ taranti te») |

## Карма и грех

| Ситуация | Правило |
|---|---|
| Право на действие | Право на действие есть, на плод — нет; плодом распоряжается Пракрити |
| После действия | Не терзайся результатом — он вне контроля |
| Патака | Совершённый грех; смывается возвратом/извинением |
| Атьяпатака | Не смывается; искупление — полное духовное посвящение |
| Махапатака | Рекуррентный вред обществу (пример заражает); спасение — полная отдача садхане и служению |
| Пратyaвая | Упущенное добро — хуже совершённого зла |
| Доброе дело | Прямое (быстрое) и косвенное (медленное, но на тысячелетия — сажай дерево) |
| Делать добро / зло | Добро — немедленно; зло — откладывай (Shubhasya shiighram, ashubhasya kálaharańam) |

## Нисхождение и общество

| Ситуация | Правило |
|---|---|
| Дхарма ниже стандарта + адхарма правит | Глани → приход Тараки Брахмы / Махасамбхути |
| Застой общества («грязь» паузы) | Садвипры чистят; если перегрузка — нисходит Парама Пуруша |
| Признак великой идеи | Полная поляризация; «середина/экватор» = пустяк |
| Мера греха в обществе | Рекуррентность: заражает ли пример других |
| Кто отвечает за вора | Общество, породившее условия, — в сотню раз больше, чем сам вор |

## Практика

| Ситуация | Правило |
|---|---|
| Три фактора прогресса | Пранипата (капитуляция) + парипрашна (вопрос для действия) + сева (одностороннее служение) |
| Против тщеславия | Видеть Бога в получателе помощи; медитация: «Он видит меня» |
| Комплекс (превосходства/неполноценности/страха) | Изгонять; гордись только: «я дитя Владельца всего» |
| Стыд перед Богом | Стыд = паша (узы); бороться; перед Отцом грешник и праведник равны |
| Тело | Машина A-класса; без работы «ржавеет»; дано для работы, не для досуга |
| Неподвижность | Движение = жизнь; лежишь → Кали-юга, движешься → Сатья-юга |
| Ум | Господин 10 индрий; управляется пранаямой (вайю) |
| Память | Равная важность всему; иначе баланс ума рушится |

## Садхана-механика

| Ситуация | Правило |
|---|---|
| Кундалини | 8 шагов + гуру-чакра (прыжок) + сахасрара (9-я); слияние = мокша |
| Публичная сиддха-мантра | 8 слогов (как и киртан) |
| Звук пранавы | Меняется по уровням (гром→колокольчики→флейта); в слиянии — беззвучие |
| 1000 вритти | 50 главных × 2 (внутр./внешн.) × 10 направлений |
| Порядок контроля чакр | Сначала нижние чакры, потом сахасрара |
| 3 вида страданий | Мирские (общество), ментальные (садхана), духовные (разлука) |
