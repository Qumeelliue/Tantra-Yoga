# Читшит — правила решений по Саркару (Prout 15)

## Экономика

| Ситуация | Правило |
|---|---|
| Оценить политику/бизнес | Тест 5 принципов PROUT: накопление, использование потенций, регулировка, гибкость |
| Зачем работает производство | Мотив потребления (PROUT) — не прибыли (капитализм) |
| Деньги не используются/стоят | Застой ломает экономику → держать в обращении |
| Куда вкладывать доходы | В developmental programmes (прямо растят богатство), не в зарплаты — иначе инфляция |
| Внешние риски торговли | Бартер устойчивее экспорта и буллона к депрессиям |
| Подоходный налог | Отменить; компенсация акцизом +10% — доход не теряется, чёрные деньги исчезают |

## Планирование и развитие

| Ситуация | Правило |
|---|---|
| С чего начать план | Block-wise (низший уровень) → самодостаточная единица → федерация; снизу вверх |
| Как делить регионы | Socio-economic единицы по 5 факторам; не по религии/языку |
| Доходы региона утекают | 100% местных доходов остаются на месте, пока душевой доход не сравняется с развитым районом |
| Зарплаты «вместо развития» | Нельзя — покупательная способность не растёт, рынок уходит вверх |

## Социальная политика

| Ситуация | Правило |
|---|---|
| Помочь отсталым классам | 4-уровневая преференция по экономическому положению (бедный+отсталый → бедный → небедный+отсталый → небедный); не по рождению |
| Гарантия минимума | Покупательная способность за работу по способности, не раздача товаров |
| Когда кончаются преференции | Когда нет бедности / гарантирован минимум — тогда «работы ищут людей» |
| Job reservation | Постоянно — не в духе PROUT; только временно как трамплин |

## Лидерство и политика

| Ситуация | Правило |
|---|---|
| Выбрать лидера | По качествам: интеллект, мудрость, цельность, пионерский запал, самопожертвование |
| Демократия vs диктатура | Демократия — лучшее из существующих, но слаба в лидерстве; диктатура сильна, но недолговечна |
| Любая партийная диктатура | Отвергнута; решение — sadvipra-лидерство |

## Право и правосудие

| Ситуация | Правило |
|---|---|
| Смертная казнь | Отвергнута (правосудие несовершенно); исключение — особая опасность без шанса исправления |
| Массовые казни (gańahanana) | Не поддерживаются, даже для преступников |
| Penal code | На кардинальных принципах человека (Yama/Niyama), без различия греха и преступления |
| Наказание | Пропорционально проступку; у каждого — шанс на исправление |

## Идеология и экология

| Ситуация | Правило |
|---|---|
| Оценить цель/идеологию | Ádarsha = духовный смысл + параллель с Высшим Сущим; материализм материализует ум |
| Материалистическая цель | Ум станет материей → вакуум; заменяй на SSSP-направление |
| Единобразие/одинаковость | Природа не поддерживает идентичность — будет jad́asphota; разнообразие — закон |
| Лес/эрозия | Вырубка → меньше дождя, больше наводнений, пустыня; цель — крупномасштабное лесоразведение |

## Быстрые сигналы («tells»)

- Видишь «правило большинства» на словах — проверь, кто на деле правит (меньшинство ваешья, партийные кадры).
- «Земля тем, кто пашет» — проверь логику: «голова — тем, кто бреет?».
- Повторение без доказательств («постоянное вещание») — вероятна промывка сознания.
- Памятники и дороги в честь лидеров сомнительных систем — «грех тратить публичные деньги».
- «Голуби мира» + точащееся оружие — лицемерие: «проповедуй мир, но держи порох сухим».
