# Читшит — правила решений по Саркару (Prout 1 Part 2)

## Общество

| Ситуация | Правило |
|---|---|
| Оценить жизнеспособность сообщества | Проверь три столпа: единство (общий идеал), безопасность (нет несправедливости + дисциплина), покой (равновесие без суеверий) |
| Разрушилось единство | Причины: эгоизм, группы ради выгоды, непонимание других → строй общий идеал и общие функции |
| Справедливая система наказаний | Без казни и остракизма; временное неучастие + «приведи десять на верный путь»; без клейма на семье |
| Дисциплина в коллективе | Законы рациональны и изменяемы; порядок = «сначала послушание, потом аргументация» |
| Обеспечить покой | Sadhana + прямое опровержение суеверий (социальных/психических/духовных) |
| Страдание не проходит | Artha даёт только временное облегчение; вечное — только Paramártha через sadhana |

## Идеологии и теории

| Ситуация | Правило |
|---|---|
| Оценить философию/доктрину | Найди самопротиворечие: кто судит? есть ли «верёвка» (основа)? что с причиной/следствием? |
| «Вечная» теория/практика | Проверь время-место-личность: условия изменились → она анахронизм (касты) |
| Материализм как идеология | Психологически дефектен: конечное не насыщает бесконечное; подавление → страх и шпионы |
| «Непротивление злу» | Без внешнего давления + образования не работает; добрые слова жадность не остановят |
| Религия vs мораль | Религия: статика, исключительность, страх, коммунализм. Мораль: ведёт к Космическому, вне TSP |
| Контрреволюция/поражение | Не конец: сжатие ускоряет следующее расширение — суди по потенциалу, а не позиции |

## Классы и революция

| Ситуация | Правило |
|---|---|
| Анализ власти | Кто правит: сила → интеллект → деньги → единство работников? Смена класса = тот же цикл |
| «Революция» | Только разрыв цикла (уничтожение деления), а не передача власти следующему классу |
| Устранить классовое деление | Практика всех четырёх качеств каждым: ум + тело + заработок + служение (не проповедь) |
| «Мир — иллюзия» | Отвергнуто: мир реален, он проявление Верховного Сущего; действуй в мире, а не беги |
| Духовные практики | Без ограничений: любой касты, пола, семейного статуса; семейный = санньяси |

## Образование

| Ситуация | Правило |
|---|---|
| Учить ребёнка | Пробуди жажду знания; страх даёт знания, исчезающие с источником страха |
| Дети | Через игру и истории |
| Подростки | Через идеализм |
| Молодые взрослые | Сплав идеализма и реализма |
| Выбор учителя | По характеру (цельность, лидерство, служение), не по диплому; оплата не ниже судей |
| Политика образования | Учителя формулируют, государство предлагает; учителя вправе отклонить |
| Родители | Главные за морально-духовное; нужны самоконтроль и здравый смысл; не лгать, не пугать |
| Языки | Родной + мировой (английский); без политической перегрузки |
| Медиа (радио/кино) | Под непартийными культурными советами; не бизнес, не государство |

## Быстрые сигналы («tells»)

- Норма «священна и неизменна» и закрепляет исключительность группы → религия, а не мораль.
- «Братство всех» только внутри своей общины → коммунализм.
- «Всё безначально, усилия не нужны» → доктрина без прогресса.
- Обучение через запугивание и «хининовые пилюли» → знания не закрепятся.
- Учитель/лидер проповедует одно, делает другое → пример сильнее слов.
- Кино/медиа эксплуатируют низменные инстинкты или ведут партийную линию → рупор, а не образование.
