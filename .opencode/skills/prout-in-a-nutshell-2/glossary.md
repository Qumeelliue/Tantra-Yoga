# Глоссарий — Prout in a Nutshell Volume 1 Part 2

**Адвайта (advaetaváda / monism)** — недуализм Шанкарачарьи: Brahma един, мир иллюзорен; Саркар критикует (Ch 1).

**Анумана (anumána)** — вывод; второй источник знания после pratyakśa (Ch 1).

**А́ртха (artha)** — мирской достаток, дающий лишь временное (sámayikii) облегчение страданий (Ch 2).

**Атьянтики нивритти (atyantikii nivrtti)** — вечное прекращение страданий; даётся только Paramártha через sadhana (Ch 2).

**А́ча́рья (ácárya)** — духовный учитель (Ch 1).

**Бха́ктха́ (bhákhá)** — «простонародный язык»; презрительное название пандтами языка Будды (Ch 1).

**Бескастовое общество (casteless society)** — общество, где нет групп экономических/социальных привилегий; идентичность — jiiva mátra (Ch 2).

**Ва́ешья (vaeshya)** — класс торговцев/производителей в цикле правящих классов (Ch 3).

**Виплава / пративиплава (viplava / prativiplava)** — революция / контрреволюция (Ch 4, 5).

**Вишва бха́са́ (vishva bháśá)** — мировой язык; по Саркару, сегодня — английский (Ch 6).

**Время-место-личность (time, space, person, TSP)** — относительные факторы; любая теория привязана к ним и становится анахронизмом (Ch 4).

**Гуру бха́и / джа́та бха́и (guru bhái / játa bhái)** — «братья по гуру» / «братья по касте» (Ch 2).

**Дхарма (dharma)** — обретение блаженства через регулярную sadhana; не «религия» (Ch 5).

**Джи́ва ма́тра (jiiva mátra)** — «живое существо как любое другое»; идентичность без касты/расы/веры (Ch 2).

**Дукха (duhkha)** — страдание; свойство mánas, поэтому не абсолютная истина (Ch 1, 4).

**Каста (caste)** — наследственная профессиональная классификация; была оправдана при кустарной экономике, сегодня бессмысленна (Ch 4).

**Коммунализм (communalism)** — групповая психология, основанная на религии; источник угнетения (Ch 5).

**Кулаку́н́да́ли́ни таттва (kulakuńd́alinii tattva)** — концепция пробуждения латентных духовных потенциалов человека (Ch 1).

**Ма́йя (Máyá)** — иллюзорная сила у Шанкарачарьи (анирвачаниия); не равна Prakrti Ананда Марги (Ch 1).

**Маха́я́на / Хинаяна (Maháyána / Hiinayána)** — северная / южная школы буддизма (Ch 1).

**Мировая философия (Sad́adarshana)** — шесть теистических школ индийской философии (Ch 1).

**Мораль (niiti)** — «содержащее принцип ведения»; сила, поющая песнь Бесконечного и ведущая к Космическому состоянию; вне TSP (Ch 5).

**На́стика / а́стика (nástika / ástika)** — не верящий / верящий в átman, Paramátman и Веды (Ch 1).

**Нивритти (nivrtti)** — прекращение страданий; см. sámayikii / atyantikii (Ch 2).

**Ниргуна / сагуна Брахма (Nirguńa / Saguńa Brahma)** — Брахма без качеств / с качествами (Ch 1).

**Па́ра́ма́ртха (Paramártha)** — то, что даёт вечное освобождение; достигается только sadhana (Ch 2).

**Пра́ман́а (pramáńa)** — валидация знания: pratyakśa, anumána, ágama (Ch 1).

**Пра́тйакша (pratyakśa)** — прямое восприятие; единственная pramáńa Charvaka (Ch 1).

**Религия (religion)** — застывшая доктрина с претензией на исключительность; статична, эксплуатирует страх, порождает коммунализм (Ch 5).

**Са́ма́джа (samája)** — «общество» = «двигаться вместе» (Ch 5).

**Са́ма́джа гуру (samája guru)** — ведущий общество силой интеллекта, мудрости, личности и лидерства; в образовании — учитель (Ch 6).

**Са́ма́йики нивритти (sámayikii nivrtti)** — временное прекращение страданий через artha (Ch 2).

**Са́м́скара (saḿskára)** — ментальный реактивный моментум; толкает делить общество или формирует талант (Ch 1, 6).

**Сад́ха́на (sádhaná)** — духовная практика; источник atyantikii nivrtti и покоя (Ch 2).

**Са́хи́тьяка (sáhityika)** — писатель с мыслью о благе всего человечества; «учитель общества» (Ch 6).

**Саннья́си (sannyásii)** — отшельник; в Ананда Марге равен семейному человеку (Ch 3).

**Са́м́ха́рка-саинчара (saiṋcara / pratisaiṋcara)** — центробежная / центростремительная сила Brahma (Ch 1).

**Сва́бха́ва (svabháva)** — естественная склонность; свойство ума становиться подобным объекту (Ch 2).

**Систолическое движение (systaltic)** — ритмичное, волновое движение, свойственное обществу (Ch 5).

**Универсальная пригодность (universal fitness)** — владение качествами всех четырёх классов в одном индивиде (Ch 3).

**Чарвака (Charvaka)** — материалистическая школа; сознание из четырёх элементов; признаёт только pratyakśa (Ch 1).

**Чату́ра́рья сатьям (catuŕárya satyam)** — четыре благородные истины буддизма (Ch 1).

**Шу́дра (shúdra)** — класс работников в цикле правящих классов (Ch 3).

**Шуньява́да (shúnyaváda)** — нигилизм; «мир — иллюзия»; школа Nagarjuna (Ch 1).
