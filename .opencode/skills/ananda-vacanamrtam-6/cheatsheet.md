# Чит-шит — Ánanda Vacanámrtam Part 6

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Выбрать путь к цели | Bhakti — ближайший и безопасный (jñána «C», karma «B», bhakti «A») |
| Оценить слово как мантру | Акустический корень + совпадение смыслов + признание Mahákaola |
| Какое знание искать | Ápta vákya (прямое от Parama Puruśa), не prápta (через среду) |
| Простить врага коллектива | Лично — можно; коллективно — только с согласия коллектива |
| Простить неисправившегося | Не прощать — иначе поощряешь вредную привычку |
| Контроль себя vs окружения | Damanam (внутреннее) выше shamanam (внешнего); стремись к dánta |
| «Поститься» | Upavása = жить у Господа; голодание = anashana; держи субъективную близость |
| Медитация на Supreme | Он — субъект, ты — объект: «Он видит меня» |
| Служение Parama Puruśa | Прямо не служить — через Его детей (bhagavatosevá) |
| Что подарить Ему | Свой ум (всё остальное уже Его) |
| Сравнить временную/полную победу | Jaya — временная; vijaya — полная |
| Противоречащие писания/мнения | Следовать mahájana (преданным), не jñánii |
| Истинное паломничество | Внутри «я» (átmatiirtham), не географические места |
| Чувствуешь безнадёжность (melancholia) | Признак jñánii; бхакт помнит ota/prota связь — он не один |
| Страх перед прошлыми грехами | Ближе к Нему — грехи сгорают; Отец чистит, не презирает |
| Греховная мысль в уме | Не грех до действия; сразу пой kiirtana |
| Задача с физическими нуждами | Решать социально (PROUT), а не духовно; настоящее нельзя игнорировать |
| Богатство и право собственности | Без одобрения коллектива не накапливать (принцип PROUT) |
| Как преуспеть в sádhaná | Человеческая структура + 6 кодов + práńipáta/pariprashna/sevá |
| Задавать вопросы | Pariprashna: тот, чей ответ исполнишь в жизни |
| Служить угнетённым | Sevá с благодарностью за возможность (видеть Náráyańa в них) |
| Оценить дружбу | Bandhu (только Он) / suhrd (недостижим) / mitram (временно) / sakhá (одна душа) |
| «Знаю!» с уверенностью | Проверь источник и год; книга 1912 — уже неверна; знание-тень |
| Вспомнил прошлую жизнь | Extra-cerebral память; не стремись быть játismara |
| Обещаешь встречу | «Если Бог позволит» — человек смертен в любой час |
| Всё «знать» | Знать одного (Бога) — знать всех (Brahmavid sarvavid) |
| Жизнь как драма | Ты актёр; осознание роли защищает от боли/радости |
| Стремление «не сливаться» ради вкуса | Заблуждение: слияние даёт Nityánanda; liilánanda ты уже имеешь |

## Семь кодов успеха (шлока Shiva)

1. Vishvása — «это исполнится»
2. Shraddha — вера
3. Gurupújana — почитание гуру
4. Samatábháva — уравновешенность
5. Indriya nigrahah — контроль чувств
6. Pramitáhára — умеренная пища
7. «Saptamam naeva vidyate» — седьмого нет

## Пять принципов PROUT (сноска ch10)

1. Никакого накопления без одобрения коллектива
2. Максимальное использование и рациональное распределение потенций
3. Максимальное использование потенциалов единиц и коллективов
4. Правильная настройка между использованиями
5. Метод меняется по времени/месту/лицу; прогрессивное использование

## Десять wonts dharma

Dhrti (терпение) · Kśamá (прощение) · Dama (контроль) · Asteya (не-воровство) · Shaoca (чистота) · Indriyanigraha (контроль чувств) · Dhii (интеллект без низости) · Vidyá (движение ума к Parama Puruśa) · Satyam (движение к Sat) · Akrodha (безгневие как искусство боя)

## Три подфазы Tántrikii diikśá

Diipanii (свет факела) → Mantrágháta (удар корня мантры) → Mantra caetanya (движение к positivity)

## Три случая ясной памяти прошлой жизни (ch16)

1. Хорошо развитая личность
2. Командовавшие собственной смертью / умершие в полном сознании
3. Погибшие в несчастных случаях
