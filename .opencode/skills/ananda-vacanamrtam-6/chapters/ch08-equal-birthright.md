# Chapter 8: An Equal Birthright

*Дискурс 126, 5 декабря 1978, Мадрас.*

## Core Idea

Женщины имеют равное право на спасение. Shiva (через ответ Párvatii) поставил минимумом квалификации человеческую структуру, а не мужскую. Те, кто утверждает обратное, — антисоциальные элементы, представители vested interests.

## Frameworks Introduced

- **Минимальная квалификация са́дхака**: стих Shiva Párvatii — `Átmajiṋánamidaḿ Devi paraḿ mokśaeka sádhanam; Sukrtaermánavo bhútvá jiṋániicenmokśamápnuyát.` Спасение = знание себя; достичь можно только в человеческой структуре (накопленной хорошими saḿskáras). Никакого «мужского тела» не требуется.
- **Átmajiṋánam vs aparajiṋánam**: внутренне-направленное (inwardly-projected) действие = átmajiṋánam; внешне-направленное = aparajiṋánam. Путь спасения — внутренняя проекция.
- **Sádhu**: `Pránáh yathátmano'bhiiśt́ah bhútánám api te tathá; Átmaopamyena bhutánáḿ dayáḿ kurvanti sádhavah.` — кто любит других, как себя; вегетарианец (не хищник, как кошки/собаки/тигры). «Man» — общий род, включает мужчин и женщин.
- **Tráńa vs paritráńa**: tráńa = временное спасение (наводнения, голод); paritráńa = постоянное освобождение. Krśńa — «paritráńáya sádhúnám».
- **Duśkrtám** = антисоциальные элементы (их уничтожение — цель).
- **Sthápana vs saḿsthápana**: sthápana = поставить dharma в правильное положение (после gláni-деградации); saḿsthápana = поставить и сделать устройство, удерживающее её в правильном положении. `Dharmasaḿsthápanártháya sambhavámi yuge yuge`.

## Key Concepts

- **Pápakśaya/структура тела**: тело человека — результат хороших действий прошлых жизней; это ворота к átmajiṋánam.
- **Право на спасение** — равное для обоих полов; девочка и мальчик — две руки одного Отца.
- **Vested interests / антисоциальные элементы** — те, кто утверждает неравенство.

## Mental Models

- «Критерий человека — человеческая структура, а не пол».
- «Ты — руки Отца; Отец не хотел бы для дочери ада, а для сына блаженства».
- «Любовь к другим как к себе — маркер sádhu».

## Anti-patterns

- **Утверждать, что женщины не могут спастись** — антисоциальная позиция, vested interests.
- **Хищническое отношение к жизни (плотоядность)** — не sádhu.
- **Путать tráńa и paritráńa** — временное спасение не равно освобождению.
- **Переводить «man» только как мужчину** — общий род в санскрите.

## Worked Example

Пример-диалог: Párvatii спрашивает Shiva о минимальной квалификации аспиранта (как в объявлениях о работе). Ответ: человеческая структура — единственное требование; пол не упоминается. Параллель с Krśńa: «paritráńáya sádhúnám» — sádhu общего рода; Krśńa никогда не лишает женщин права.

## Key Takeaways

1. Минимальная квалификация — человеческая структура, не мужская.
2. Átmajiṋánam — внутренняя проекция; путь к спасению.
3. Sádhu любит других, как себя, и не плотояден.
4. Paritráńa = постоянное освобождение; tráńa = временное.
5. Saḿsthápana — установка + механизм удержания dharma.
6. Неравенство полов в спасении — признак антисоциальной идеологии.
