# Читшит — правила решений по Саркару (Subhasita 17)

## Поток и направление

| Ситуация | Правило |
|---|---|
| Определить судьбу системы/человека | Спроси: поток движется к грубому или тонкому? Направление решает всё |
| Влечение «мешает» (жадность, слава) | Не подавляй — перенаправь объект на высшее (правртти → нивртти) |
| Движение к грубому стимулируется | Предупреждение: деградация к материи, «пыль земли» |
| Два возможных исхода восхождения | Сагуна-стхити (слияние с Космическим Умом) или ниргуна-стхити (сдача «Я» полностью) |

## Оковы и баланс

| Ситуация | Правило |
|---|---|
| Найти препятствия пути | Пройди 8 внешних паш (ненависть, сомнение, страх, застенчивость, притворство, гордость родом, культурный комплекс, эго) + 6 внутренних рипу |
| Строить устойчивую трансформацию | Две руки: бороться с оковыми + служить всей вселенной; одно без другого не работает |
| Проверить, «вне ли ты человечества» | Любой правртти-поток перенаправляем — никто не исключён |

## Инстинкт, догма, бхакти

| Ситуация | Правило |
|---|---|
| Разобрать причину поведения | Различай: инстинкт (поток), самскара (потенциальная реакция), вртти (направление) — не смешивай |
| Развить врождённые способности | Учёба, культура, общение, садхана; садхана обязательна для всех существ |
| Авторитетный императив противоречит совести | Проверь: здравый смысл → логика → человечность; нелогичное отвергай даже от высшего авторитета |
| «Писание» оправдывает вред существам | Контртест: «освободи себя тем же ножом» — абсурд вскрывает догму |
| Оценить развитие существа | Смотри на объект ума: тело → чувства → действия → их источник → Единое |
| Низший инстинкт | Сублимируй в преданность — это доступно всем, включая развитых животных |

## Быстрые сигналы («tells»)

- Поток остановился → стагнация и деградация неизбежны («ум обязан двигаться»).
- Ум оправдывает «так принято» без фактов → вероятна догма.
- Слышишь «ты благословен, а они — рабы» / «животные — еда» → классическая догма из дискурса.
- Влечение гасят запретом, а не перенаправлением → правртти вернётся сильнее.
- Воюют с пороками, но не служат миру → односторонний рост, разбалансировка.
