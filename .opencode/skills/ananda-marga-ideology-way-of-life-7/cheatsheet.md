# Читшит — правила решений по Саркару (Ideology and Way of Life Part 7)

## Мир и материя

| Ситуация | Правило |
|---|---|
| Что такое материя | Статически связанная форма энергии; разбирай до первоосновы, как ювелир до золота |
| Объект познаётся | По проявленным характеристикам = акциональным выражениям через гуны |
| Вечное или преходящее | Тест трёх факторов: измени время/место/лицо — изменилось? → преходящее |
| Пол человека | Не абсолютен: в jiivátman пола нет → дискриминация по полу недопустима |

## Духовная практика

| Ситуация | Правило |
|---|---|
| Начать духовную жизнь | yama и niyama — фундамент; свет против статической тьмы |
| Три пути (знание/действие/преданность) | Все нужны, но преданность — «соль»; без неё — безвкусно |
| Действие обязано выполнять | Делай с идеацией «деятель — Brahma», отдай результат — самскары не копятся |
| Дхарма индивидуальна? | Нет: iishvara pranidhána работает только с внешней практикой; «закрытая комната» = напрасно |
| Цель садханы | Puruśa, где Prakrti дремлет; не Prakrti и не составной объект |

## Учение и цели

| Ситуация | Правило |
|---|---|
| Разобрать причину явления | Ни природа (svabháva), ни время не причина; субъект — Puruśottama |
| Определить источник веры | Религия/ism — множественны, относительны; dharma — едина, вечна, центрирована на Brahma |
| «Синтез религий» | Невозможен = их аннигиляция; dharma всегда в единственном числе |
| Кому учить Brahmavidyá | Только обладающим parábhakti; Гуру один — Paramátmá |
| Встретил иллюзионизм («мир — иллюзия») | Отвергни: это орудие эксплуатации; садхана — путь храбрых, не бегство |

## Совесть и решения

| Ситуация | Правило |
|---|---|
| Выбрать между вариантами | Это vicára; viveka = намеренно выбрать shreya против preya |
| Проверить решение | Прогони через 5 видов совести (вечное→единое→сознание→коши→действие+преданность) |
| Служение | Видеть Brahma в нуждающихся; «ради голосов/обращений» = торговец |
| Знание приводит к тщеславию | Знание неполно без действия и преданности (mahávákya viveka) |
| Любовь к своим детям | Не сокращай — расширь на всех детей; расширение = садхана |

## Быстрые сигналы («tells»)

- Кто-то требует «не спорь, прими писания» — вероятно, религиозная эксплуатация.
- «Бог живёт в храме/в таком-то месте» — ограничение Бесконечного, поклонение конечному.
- Вор размышляет, с какой комнаты начать — vicára без совести.
- «Молasses свят, фабричный сахар нечестив» — статический консерватизм против науки.
- Купание в Ганге после грабежей, храмы на чёрный рынок — показное, не dharma.
- Проповедник благословляет богатых и не видит бедняков — «нечестивый союз» религии и капитала.
