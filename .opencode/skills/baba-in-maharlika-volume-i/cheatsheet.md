## Дискурсы Бабы (глава II)
| Тема | Ключевая идея |
|---|---|
| G-O-D | Бог = генератор, оператор, разрушитель; «маг», всё внутри Его ума |
| Бхакти | 5 уровней; высшая — рагатмика (любовь ради удовольствия Ему) |
| Стадии самадхи | sālokya → sāmīpya → sāyujya → sārupya → sārs't'hi → nirvikalpa |
| Kaola / Mahākaola | kaola поднимает свою кундалини; mahākaola — других; Tāraka Brahma |
| Surrender | «делай, что считаешь лучшим для меня»; просьба ≠ surrender |
| Принципы философии | 4 условия теории; критика mixed economy / peaceful coexistence |
| Longing for the Great | следуй практику (mahājana), а не теоретику |
| Life is Short | используй тело, пока служит; марш вперёд = жизнь |

## Правила решений
| Ситуация | Правило |
|---|---|
| Чувствуешь себя грешником | «Я сын/дочь Великого Отца» — не медитируй на грех |
| Ждёшь ответа слишком долго | Сдайся («Ты решай») — сдача ускоряет |
| «Совпадение» повторилось 3+ раз | Это паттерн заботы, не удача |
| Нужна помощь, но далеко от Гуру | Идеация, сны, киртана, svādhyāya (притягивают положительные микровиты) |
| Гордость/эго | Жди «измельчения эго» — прими scolding как тренировку |
| Гонения на организацию | Снизь профиль, учи медитации, «мастер придёт, когда готов» |
| Выбор «малая семья» vs миссия | Универсальная семья — высший ориентир миссионера |

## Ключевые люди
- **Vimalānanda** — первый миссионер-монах (с 1967).
- **Adveshānanda** — Para Bhakta, создатель whol-timers.
- **Satyajita / Muraliidhāra / Suvedānanda** — авторы многих историй (от инициации до P.C.).
- **Vishokānanda / Keshavānanda** — PA Бабы.
- **Gagana / Asitiimä / Divyananda** — мученики.
- **Sister Diipänvitä** — составитель книги; автор глав-хроник.
