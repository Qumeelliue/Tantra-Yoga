# Краткая справка (The Flame That Burns Upward)

## Ситуация → Правило

| Ситуация | Правило |
|----------|---------|
| Сопротивление движению | 4 фазы: непризнание → подавление → репрессия → признание |
| Идентификация врагов | 6 категорий: религия, партии, чиновники, региональные лидеры, пресса, дефекторы |
| Ложные обвинения | Документируй, судись, опровергай в суде/парламенте |
| Новость без проверки | «Эхо-обычай» — проверяй источник, не повторяй |
| Внутренний раскол | Смотри сговор дефекторов с внешними силами (таблица совпадений) |
| Экономика vs духовность | Без минимума нужд мораль невозможна; экономика служит духовной цели |
| Демократия | Требуй 4 условий; иначе — «фолакратия» |
| Революция | Возможна кровная/бескровная (по ментальности восставших) |
| Клевета прессы | «Повторяй ложь — станет правдой» (Геббельс); отвечай фактами |
| Загадочность организации | Открытость: книги, пресс-конференции, центры |
| Оценка системы | Капитализм/марксизм/смешанная экономика — все против человека; PROUT — ответ |

## Пять принципов PROUT

1. Никакого накопления богатства без одобрения коллектива.
2. Максимальное использование и рациональное распределение всех потенциалов.
3. Максимальное использование физических/метафизических/духовных потенциалов.
4. Правильное согласование этих использований.
5. Метод меняется с временем/местом/личностью — всегда прогрессивен.

## Ключевые формулы

- **Капитализм**: «делает человека нищим»; **Коммунизм**: «делает нищего зверем».
- **Смешанная экономика**: «псевдоним капитализма».
- **Демократия без условий**: «фолакратия».
- **Тантра**: «Там ядаят тарайета ясту са тантра» — освобождающее от неведения.
- **Геббельс**: «повторяй ложь — станет правдой» — приём, обличаемый книгой.
