## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Эго-теория без практики | Гуру «диагностирует» ударом; «я, чувствующее боль, требует медитации». |
| Негативный приказ гуру | Не нарушать: последствия на тебе (пример с Ма). |
| Сильное влечение | 3 стадии: благочестивый образ → мать → дхьяна на гуру. |
| Сомнение «гуру забыл меня» | Забота гуру скрыта, но реальна (история с питанием). |
| Провалил экзамен/испытание | Грейс гуру превращает провал в успех (пересдача с внутренней готовностью). |
| Гонения/запрет | Подполье + практика; после кризиса рост (16→85 стран ⚠). |
| Спрашивать гуру обо всём | Ответ изнутри важнее; гуру экономит годы, но не заменяет практику. |
| Успех приписывать себе | «Только грейс Бабы делает вас способными» (урок двух ачарьев). |
| Слова гуру | Мантры: носи, созерцай, помни; «твои слова важнее твоего существования». |
| Несправедливость | Сопротивляйся (при необходимости физически); терпимость — трусость. |
| Видишь женщину | Называй «Ma» (мать); снимает влечение. |

## 16 критериев Таараки (кратко)

Рождённый на стыке эпох · без гуру · приносит писания · даёт метод · прецептор с рождения · не идёт на компромисс с несправедливостью · самкальпа · революционер · организатор · искореняет безнравственность · многогранен · не нуждается в дисциплине (но практикует как пример) · щедр · тонок в форме · пробуждает вибрацию · всегда спорен.
