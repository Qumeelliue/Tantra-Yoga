# Читшит — краткая справка (Bábá in Taiwan)

## Кодексы и успех
| Ситуация | Правило |
|---|---|
| Хочешь «60% успеха» | Восемь самьяк-принципов (Ch 1): цель → решимость → контроль → профессия → упражнения трёх тел → доводи до конца → память-мантра → самадхи |
| Секреты Siddhi | Шесть факторов (Ch 3): вера, шраддха, гуру, равновесие, самоконтроль, прамитахара — «седьмого нет» |
| Оценка теории | Наука = рациональность + причинность; искусство = тонкие чувства; знание = самопознание |

## Природа человека
| Ситуация | Правило |
|---|---|
| «Кто я?» | Человек — идеологический поток, не «рациональное животное» (Ch 4) |
| Догма/подавление | Подавление любознательности (Vistára) — вредно |
| Служение | Сева — односторонний дар; в каждом — Его выражение |
| Уровни людей | pashu → viira → deva (Ch 5); пути: пашавачара → вира/чина → дивья |
| Йога = | Объединение дживатмы с Параматмой (не «пустой ум») |

## Движение и прогресс
| Ситуация | Правило |
|---|---|
| Прогресс | Только духовный: радиус к Нуклеусу (Ch 6, 7) |
| «Хорошо одетый примат» | Изобретения без духовного роста — не развитие |
| Слои существования | Кама → Артха → Дхарма → Мокша (Ch 11) |
| Социальный долг | Строй общество с едой/одеждой/жильём/медициной/образованием для всех |

## Ум и внушение
| Ситуация | Правило |
|---|---|
| Самопрограммирование | Авто-внушение (лучшее — Ишта-мантра); внешнее — из сатсанга (Ch 8) |
| Выбор компании | Сатсанг приближает к Господу; амитавьяя (умные разговоры без цели) — нет |
| Галлюцинации | Эктоплазм: intro-external → положительная; extro-internal → мир в ум (Ch 9) |
| Преданный | «Самый хитрый»: отдаёт Ему ум; умнее интеллектуала и акционалиста |

## Звук и мантра
| Ситуация | Правило |
|---|---|
| Звук/языки | Все священны (из Источника); 50 звуков ↔ 50 желёз (Ch 10) |
| Aum | a-создание, u-поддержание, ma-разрушение — коллективный звук |
| Кундалини | Спящая божественность (kula) → diipanii → Brahmarandhra |
| Мантра | «Онм манипадме хум»: вспоминай Господа; седалище божественности; hum — корень борьбы |

## Карма и причина
| Ситуация | Правило |
|---|---|
| «Почему мне плохо» | Маятник реакций: добрым станешь — старые злые реакции пошли (Ch 12) |
| Реакции | Не равны действию: Tridańd́a (время/пространство/личность) меняются |
| Путь к мокше | Добрые реакции предлагай Ему; злые бери на себя |
| Всё каузально | «Нет причины — нет следствия» (Канада); за зенитом — Его воля (Ch 13) |
| Садхана | Без преданности — пустая трата; с преданностью — максимальное использование |
