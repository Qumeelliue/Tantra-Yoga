# Паттерны — Bábá in Taiwan (жизненные уроки и приёмы)

## Проверка «наука или искусство?»
**Когда использовать**: оценка знания, теории, практики.
**Как**: наука = рациональность + причинно-следственная связь на каждом шаге (и духовная практика — наука); искусство = движение к тонким чувствам. Знание = субъективизация объективного; настоящее знание — самопознание. (Ch 2)
**Компромиссы**: не отвергает искусство — лишь разводит цели.

## Восьмеричный чек-лист дисциплины
**Когда использовать**: самопроверка «почему у меня не получается».
**Как**: цель/философия → твёрдая решимость → контроль органов → чистая профессия → упражнения трёх тел → доводи до конца → правильная память (мантра) → сворачивание ума. (Ch 1)
**Компромиссы**: «60% успеха» — не вся формула, но фундамент.

## Тест «мой объект идеации»
**Когда использовать**: выбор цели/объекта устремлений.
**Как**: объект конечен → аддикция/ограничение; бесконечен (вне времени/пространства/личности) → путь к единению. Ум принимает форму объекта. (Ch 3, 9, 11)
**Компромиссы**: мирские цели не «запрещены», но не должны становиться финальными.

## Различение «добро/зло» по дистанции
**Когда использовать**: этическая оценка действий и компании.
**Как**: уменьшает дистанцию до Господа = добро (пунья); увеличивает = зло (патака = папа + пратьявайя). Компания — внешнее внушение: выбирай сатсанг. (Ch 8)
**Компромиссы**: метрика духовная; для практических решений добавляй конкретику.

## Механика успеха
**Когда использовать**: «как добиться успеха (в т.ч. духовного)».
**Как**: успех = реакция на доброе действие; для Siddhi — шесть факторов: твёрдая вера, шраддха, гуру, равновесие, самоконтроль, прамитахара (седьмого нет). (Ch 3)
**Компромиссы**: духовная рамка; для материальных целей адаптируй «веру + контроль + диету».

## Карма-анализ «почему мне плохо»
**Когда использовать**: страдания «без видимой причины».
**Как**: маятник реакций: стал добрым → начались реакции старых злых дел; реакция не равна действию (Tridańd́a меняется). Не «юглеруй»: злые реакции бери на себя, добрые предлагай Ему. (Ch 12)
**Компромиссы**: не отменяет реальных причин; добавляет духовный слой.

## Тест «прогресс или суета»
**Когда использовать**: оценка «развития» — своего, продукта, общества.
**Как**: прогресс = приближение к Нуклеусу (радиус к нулю) / пирамидирование существования; изобретения и гардероб при прежнем уме — «хорошо одетый примат»; не трать время на «психический плюс-минус». (Ch 6, 7)
**Компромиссы**: не отрицает материальный слой (Кама — социальный долг), лишь смещает цель.

## Пирамида существования (цели жизни)
**Когда использовать**: определение приоритетов.
**Как**: Кама (нужды) → Артха (смысл/психика) → Дхарма (сворачивание пропенсите) → Мокша (предложение чувства существования). Уважай нижние слои, не делай их целью. (Ch 11)
**Компромиссы**: требует баланса «субъективного подхода и объективной адаптации».

## Причинный поиск
**Когда использовать**: «почему это случилось?»
**Как**: всё каузально (Канада); ищи причину (возможно, далёкую); за зенитом логики — свободная воля Господа; там познание только единением (преданная садхана). (Ch 13)
**Компромиссы**: не фатализм — причинность не отменяет выбора.

## Три уровня людей
**Когда использовать**: самооценка и оценка среды.
**Как**: pashu (еда/сон/похоть) → viira (борьба с оковами) → deva (божественный); пути: пашавачара → вира/чина-ачара → дивья-ачара. Поднимайся с уровня на уровень. (Ch 5)
**Компромиссы**: не «классовое» деление — уровни состояния ума, не статуса.
