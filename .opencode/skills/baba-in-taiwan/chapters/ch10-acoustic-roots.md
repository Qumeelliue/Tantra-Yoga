# Глава 10: Acoustic Roots (Акустические корни)

*25 августа 1979, Тайбэй.*

## Core Idea
Каждый звук — волна из Источника; **все звуки священны** (все языки равно достойны). ~50 главных звуков ↔ 50 желёз; коллективный звук — **aum** (a-создание, u-поддержание, ma-разрушение). У каждого действия есть **акустический корень** (звук-поддержка). Спящая божественность (kulakuńd́alinii) поднимается к Brahmarandhra через тантру; мантра «Oṋḿ mańipadme hum».

## Frameworks Introduced
- **Звук и волны**: предложение → слова → слоги → буквы → акустические волны; все волны из Нуклеуса; «звук не может быть плохим — всё из Той Сущности».
- **50 звуков и железы**: ~50 главных звуков ↔ 50 главных желёз/суб-желёз; десять звуков (d́a, d́ha, ńa, ta, tha, da, dha, na, pa, pha) — поджелудочная, управляют десятью пропенсите (застенчивость, страх...).
- **Aum**: рынок вдали — «hawawawawa» (коллективный звук); все звуки → 50 → aum; a=создание, u=поддержание, ma=разрушение; aum — коллективный звук всех действий; «мирское выражение Парама Пуруши».
- **Акустический корень**: действие ↔ поддерживающий звук: движение — «khat-khat», смех — «ha-ha», желание («хочу манго»/«хочу ананас» — разные волны), борьба — «hum».
- **Тантра**: tan = расширение, tra = освободитель; «наука, расширяющая ум и дух и освобождающая»; dhyána → c'han (кит.) → chen (кор.) → zen (яп.); tantra → taota → tao.
- **Kulakuńd́alinii**: спящая божественность в низу позвоночника (kula, mańipadma); пробуждается садханой; **diipanii** — специальная сила, поднимающая её; доходит до **Brahmarandhra** (макушка) → единение с Парама Пурушей; шишковидная железа контролирует 1000 пропенсите (50×2×10).
- **Мантра**: «Oṋḿ mańipadme hum» — «aum'ом помню Парама Пурушу; манипадма — седалище спящей божественности; hum — акустический корень борьбы» (борьба с ограничениями при подъёме).

## Key Concepts
- **Акустический корень** — rudimental-звук действия (корень = рудимент).
- **Kula / kuńd́alinii / diipanii / Brahmarandhra** — элементы тантра-физиологии.
- **Все языки священны** — уважение ко всем.

## Mental Models
- «Звук — семя действия: за каждым делом стоит его звук-корень».
- «Aum — шум вселенной: весь звук сжат в три буквы создания-поддержания-разрушения».

## Anti-patterns
- Пренебрежение «чужими» языками (все равно достойны).
- Считать мантру «пустой скороговоркой» — у неё есть внутренний смысл (пример: монахи не знали смысла «Онм манипадме хум»).
- Думать, что звука нет, если он не слышен (волны есть всегда).

## Worked Example
Английская «a» имеет 22 произношения; «ant»/«elephant» — одно A-N-T звучит по-разному; китайская картинка произносится по-разному в Мандарине/Кантоне. Все эти выражения священны. Их коллективный звук на расстоянии — «hawawawawa» = aum. Мантра «Онм манипадме хум»: aum (вспомни Господа), манипадма (седалище спящей божественности), hum (акустический корень борьбы при подъёме кундалини).

## Key Takeaways
1. Все звуки и языки священны (из Источника).
2. 50 звуков ↔ 50 желёз; 10 — поджелудочная.
3. Aum = коллективный звук: a-создание, u-поддержание, ma-разрушение.
4. У каждого действия — акустический корень (khat-khat, ha-ha, hum).
5. Тантра — расширение+освобождение; dhyána→c'han→chen→zen; tantra→taota→tao.
6. Кулакундалини → Brahmarandhra; «Онм манипадме хум» — мантра этого пути.
