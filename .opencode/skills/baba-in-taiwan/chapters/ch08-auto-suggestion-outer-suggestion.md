# Глава 8: Auto-Suggestion and Outer Suggestion (Само- и внешнее внушение)

*23 августа 1979, Тайбэй.*

## Core Idea
Мышление = «говорить внутри». Авто-внушение — сам себе (лучшее — Ишта-мантра); внешнее внушение — из компании (**Satsauṋga** — хорошая, Asatsauṋga — вредная). Добро = уменьшение дистанции до Господа; зло = увеличение. **Puńya** (добро) / **Pátaka** (зло = Pápa + Pratyaváya). «Kuru Puńyam Ahorátram» — пунья все 24 часа; привычка → натура → джапа во сне.

## Frameworks Introduced
- **Три вида выражения**: внешний голос; **Upáḿshu** (внешний, слышишь только ты — шёпот мантры); внутренний (мысль).
- **Авто-внушение**: «Sudarshan, будь идеальным человеком» — совесть ведёт ум к идеалу; «я обязан стать хорошим»; лучшее — Ишта-мантра (auto = сам; cent percent успех).
- **Внешнее внушение**: из хорошей компании — укрепляет авто-внушение; из плохой — «воруй» — вредит (может погубить и человечество). «Выбор компании обязателен».
- **Satsauṋga** = Sat (добро) + sauṋga (компания). **Буддхика-амитавьяя (intellectual extravaganza)** — интеллектуальные разговоры без приближения к Господу — не сатсанг.
- **Добро/зло (Sat/Asat)**: действие, уменьшающее дистанцию до Господа, — добро; увеличивающее — зло. Результат борьбы добра и зла в пользу добра = **conscience (Viveka)** — сила различения.
- **Puńya/Pátaka**: пунья = добрые действия (уменьшающие дистанцию); патака = увеличивающие. **Pátaka = Pápa** (делаешь «нельзя»: не укради) **+ Pratyaváya** (не делаешь «надо»: помоги страждущему).
- **Ahorátram** = 24 часа (ахо — день от восхода; ратри — ночь). «Как делать пунью во сне?» — через привычку→натуру: джапа на дыхании идёт в подсознании/бессознательном во сне (как алкоголик: привычка → натура). «Я не пью воды без пу́джи — это стало моей натурой».

## Key Concepts
- **Viveka** — совесть/различение (результат борьбы добра со злом).
- **Upáḿshu** — шёпотная мантра.
- **Puńyavána / Pátakii** — человек пуньи/патаки (источник внешнего внушения).

## Mental Models
- «Компания — трансляция: кого слушаешь, того и повторяешь».
- «Привычка — семя натуры: повторяй мантру, пока она не станет твоей натурой — тогда она будет "работать" даже во сне».

## Anti-patterns
- «Интеллектуальная экстраваганца» — умные разговоры без цели приближения к Нему.
- Компания патакии (негативное внешнее внушение).
- Считать «внешнее внушение» неважным (оно indispensable для прогресса).

## Worked Example
Ты внушаешь себе: «Sudarshan, будь идеальным человеком» — авто-внушение (совесть гонит к идеалу). Другой говорит тебе то же — внешнее внушение. Лучшая авто-внушение — Ишта-мантра; лучшая внешняя — сатсанг. Плохая компания («воруй») — внешнее внушение, вредящее и тебе, и человечеству.

## Key Takeaways
1. Мысль = внутренняя речь; авто-внушение программирует ум.
2. Лучшее авто-внушение — Ишта-мантра; лучшее внешнее — сатсанг.
3. Добро = уменьшение дистанции до Господа; зло = увеличение.
4. Патака = папа (делать нельзя) + пратйавая (не делать надо).
5. Привычка → натура: пунья возможна и во сне (джапа автоматична).
6. Буддхика-амитавьяя — не сатсанг.
