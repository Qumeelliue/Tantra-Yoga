# Читшит — правила решений (Ánanda Vacanámrtam Part 21)

## Оценка гуру/наставника

| Ситуация | Правило |
|---|---|
| Проверить, гуру ли человек | Снимает ли тьму во всех трёх пластах: физическом + психическом + духовном |
| Кто вообще может быть гуру | Только Mahákaola (поднял себя и может поднять других) |
| Человек реализовался, но не учён | Реализация без учёности и умения учить ≠ гуру |
| Проверить практику и теорию | Гуру обязан знать детали садханы И подтверждать их шастрами |
| Проверить психическую квалификацию | Знание психологии и «в тысячу раз больше книг»; умение снять want |
| Проверить физическую заботу | Решает проблемы еды, одежды, образования, лечения |
| Как сочетать наказание и любовь | Наказание без любви плохо; степень наказания ≤ степени любви |
| Что такое хорошее правило | Шастра: дисциплинирует + освобождает + не даёт своеволия под видом свободы |

## Быстрые сигналы («tells»)

- Учитель «только духовный» и игнорирует быт ученика — неполный гуру.
- Наказание перевешивает любовь — наставник теряет право зваться гуру.
- Толстый том называют шастрой — вероятно заблуждение; шастра = дисциплина-освобождение.
- «Я реализовался, этого достаточно» — смешение реализации и квалификации гуру.
