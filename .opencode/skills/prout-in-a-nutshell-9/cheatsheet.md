# Читшит — правила решений по Саркару (Prout 9)

## Баланс и prama

| Ситуация | Правило |
|---|---|
| Оценить здоровье общества/региона | Разложи на три страта: физический, психический, духовный; найди стадию (derangement → disruption → degeneration) |
| Восстанавливать баланс | Сначала физический страт, затем психический, затем духовный; через субтреугольники подстратов |
| Физическая сфера под угрозой | Антисоциальные элементы возьмут верх — чини физику первой |
| Агрикультура | Веди на принципе потребления, а не прибыли |
| Оценить превосходство цивилизации | По степени prama (equilibrium + equipoise), а не по богатству |

## Догма и гибкость

| Ситуация | Правило |
|---|---|
| Идея с жёсткой границей | Это догма: не позволяет думать за периферией — противна духу ума |
| Проверить идею на догматизм | Применяется ли гибкость по времени-пространству-личности (5-й фактор PROUT)? Нет → догма |
| Догма при физическом изобилии | Всё равно опасна: угрожает психическому существованию |
| Догма и prama | При догме невозможен даже физический pramátrikońa |

## Общество

| Ситуация | Правило |
|---|---|
| Является ли группа обществом | Тест пилигрима: никто не остаётся позади (больного несут, еду делят) |
| Разделение на «свои» группы | Не истинное общество; ведёт к эксплуатации других групп |
| Оценить культуру | Культура = облагораживание (refinement), а не лицемерие (hypocrisy) |
| Права и ресурсы | Богатство природы и права-ответственности принадлежат всем существам |

## Цивилизация

| Ситуация | Правило |
|---|---|
| Понять региональные различия | Модель реки: hill (зарождение) → plain (развитие) → delta (зрелость); слияния = суб-цивилизации |
| Простая vs смешанная | Простая — физически сильна; бленд — психически сильна, сложна |
| Кто главенствует в дельте | Рукава (branches), а не притоки |

## История и психология

| Ситуация | Правило |
|---|---|
| Кто делает историю | Коллективная психология, не монархи; фокус: монархи → министры → простые люди |
| Смена социального порядка | Физическая сила (патриархат) → интеллект (эпоха интеллекта) |
| Равенство полов | Превосходство — по остроте интеллекта, а не по полу |
| «Бесполезный» человек | Никто не ничтожен: за всем — историческая необходимость |

## Ренессанс и экономика

| Ситуация | Правило |
|---|---|
| Оценить «проснулось» ли общество | Ренессанс-чеклист: все страты (наука, социальная, политика, экономика, культура, психика, духовность) |
| Минимум для людей | Гарантия минимума покупательной способности — без корректировок |
| Наука и оружие | Наука для служения и блаженства; оружие — для защиты хороших идей |
| Нехватка в регионе | Бартер/коммерческие транзакции, не военная атака (атака = нестабильность) |
| Догмы и деление людей | Догмы впрыснуты с детства; оружие — неогуманизм («вселенная для всех») |

## Империализм и нео-этика

| Ситуация | Правило |
|---|---|
| Любой «изм» (национализм, кастовость, лингвизм…) | Форма империализма — психического недуга «пожирания чужой пабулы» |
| Корень империализма | Психология, не институты; погружённость в углеродную пабулу |
| Лечение империализма | Нео-этика: (1) Макрокосмическая Сущность как desideratum; (2) баланс углеродной/не-углеродной пабулы |
| Оценить пищевую культуру ума | Углеродное → к грубому; не-углеродное → к тонкому и духовному |

## Образование

| Ситуация | Правило |
|---|---|
| Создать духовный порыв | Начинай с начальных школ и детских садов, а не с колледжей |
| Учебный план | Неогуманистическая философия + Astauṋga Yoga; физическая культура, диета, спорт |
| Руководящая философия образования | «Эта вселенная наша» — люди + животные + растения |

## Быстрые сигналы («tells»)

- Видишь жёсткий «изм» без права выйти за периферию — догма, угрожающая психике.
- Группа «своих», оставляющая чужих — не общество (нет теста пилигрима).
- Один регион богат, соседний в нищете — отсутствие физического pramátrikońa («свет и тьма не могут стоять рядом»).
- Ум «пожирает» чужое (империи, монополии, лингвизм) — недогма, а империалистическая психология.
- Люди голодают при богатых ресурсах региона — нет планирования по prama.
- «Животные созданы для нашей еды» — physico-psychic догма; контраргумент неогуманизма: «вселенная для всех».
