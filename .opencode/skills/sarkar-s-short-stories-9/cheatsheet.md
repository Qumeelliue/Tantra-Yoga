# Читшит — The Man and the Ideology

| Ситуация | Правило | Почему |
|---|---|---|
| Оцениваешь лидера/противника | Действуй как беспристрастный судья | Ярлыки скрывают стиль и результаты |
| Лидер «пробудил массы» | Проверь, направил ли он их в борьбу | Пробуждение без направления = пассив |
| Нет стратегии и программы, есть агитация | Критикуй как половинчатость | «Не убить змею, сломать палку» |
| Выбор союзника с другой идеологией | Смотри на цель, не на доктрину | Державы садились с СССР за стол |
| Слышишь «субхашизм»/«изм» в адрес стиля | Проверь, есть ли доктрина | Страсть + прагматизм ≠ идеология |
| Конфликт стилей раздражает | Ищи разделительный ум (гео-сентимент) | Различие затуманивает рациональность |
| Критика «без риска» | Проверь, пострадал ли критик | «Без царапины» — подозрительно |
| «Квислинг» из-за союза с Осью | Оцени легитимность по цели | WWII — война двух империализмов |
| Оценка Бозе vs Ганди | Стиль: наступательный vs пассивный | «Бей, пока железо горячо» vs негативное движение |

**Запомнить:** суди о человеке по **стилю + стратегии + результатам**, а не по лагерю и ярлыкам.
