# Глоссарий — Caryácarya Part 3

**Áhára / Áhárya** — еда, пища; классификация по гунам (Ch02).

**Ámbhasii mudrá** — дыхательная мудра с умом на svádhisthána (Ch08).

**Ánáhata cakra** — энергетический центр середины груди (Ch08).

**Ápána** — одна из десяти жизненных сил (нисходящая) (Ch09).

**Ásana** — «положение, в котором удобно» (Sthirasukhám ásanam); поза, снимающая помехи медитации через железы (Ch07).

**Ashokáshashthii / Ashokáshtamii** — женские обряды (6/8 день половины месяца Caetra): семена маша + цветы ашоки (Ch05).

**Átapa snána** — солнечная ванна (дозированный цикл нагрев→тень→массаж) (Ch06).

**Bandha** — «замок»: твёрдое сжатие нервов на время (Ch08).

**Bandhatraya** — три замка: mahámudrá, mahábandha, mahávedha (Ch08).

**Bhuutashuddhi / Ásanashuddhi / Cittashuddhi** — ступени отвода ума перед концентрацией (Ch09).

**Brahmacarya** — ум, привязанный к Brahma (НЕ «сохранение shukra»); формы: naeshthika (холостым), prajápatya (женатым) (Ch04).

**Cakra** — энергетический центр: muládhára, svádhisthána, manipura, anáhata, vishuddha, ájñá (trikuti), sahasrára (Ch08).

**Dhaotii** — очищение горла пальцем (на пустой желудок, после nášápána) (Ch06).

**Ekádashii** — 11-й день лунного месяца; обязательный пост (Ch03).

**Idá nádií / Pingalá nádií** — левый/правый энергетический канал (ноздря) (Ch02).

**Iishvara prańidhána** — медитация-сдача (пост — «рядом с Iishvara») (Ch03).

**Jalandhara bandha** — подбородочный замок (Ch08).

**Kaopiina (laungotá)** — набедренная повязка (Ch05, Ch07).

**Kumbhaka** — задержка дыхания (vasti, shiitalii, siitkárii и др.) (Ch09).

**Káshamgásana** — поза зайца (Ch07).

**Mudrá** — жест/поза с идеацией (Ch08).

**Múlshodhana** — очищение прямой кишки пальцем после дефекации (Ch06).

**Nášápána** — промывание ноздрей водой (Ch06).

**Pitr Yajiṋa** — ежедневное приношение предкам (мантра с мудрой после купания) (Ch01).

**Práńá** — энергия; десять жизненных сил: práńa, apána, samána, udána, vyána, nága, kuurma, krkara, devadatta, dhanañjaya (Ch09).

**Práńáyáma** — контроль жизненных сил через дыхание; ступени Sádhárańa / Sahaja / Vishesha / Ántár (Ch09).

**Rájasika** — мутативная гуна еды: полезна телу, нейтральна уму (или наоборот) (Ch02).

**Rshi** — «изобретатели нового», предки-мудрецы (Ch01).

**Sandhyá** — временные отрезки дня: рассвет ±45 мин, 9–12, закат ±45 мин, полночь ±45 мин (Ch01).

**Sattva / Rajah / Tamah** — три гуны: уравновешенность / движение / инерция (Ch02).

**Sáttvika** — уравновешенная еда (полезна телу и уму); обязательна практикующим ásanas (Ch02).

**Shavásana** — поза трупа (расслабление после ásanas, ≥2 мин) (Ch07).

**Shiitoshná snána** — контрастная ванна (тёплая вода до шеи + холодная на голову) (Ch06).

**Shukra** — конечная эссенция пищи, «пища мозга»; три стадии (лимфа, половые клетки, жидкости) (Ch03, Ch04).

**Sikta mardana** — массаж влажным полотенцем (Ch06).

**Snańa mantra** — мантра купания (Ch01).

**Támasika** — статичная гуна: вредна телу или уму; гнилое, мясо крупных, опьяняющие (Ch02).

**Trikuti** — ájñá cakra, точка межбровья (Ch08).

**Upavása** — пост; «пребывание рядом с Iishvara» (Ch03).

**Utkshépa mudrá** — утренняя практика (сгибания в постели + стакан воды) (Ch06).

**Vishiuddha cakra** — горловой центр (Ch08).

**Vrtti** — умственная склонность (выражается через железы) (Ch03, Ch07).

**Vyákápa shaoca** — обширная чистота, «полу-ванна» (Ch01, Ch02, Ch05).

**Vyákápa snána (vistrta)** — холодная лечебная ванна по зонам (Ch06).

**Vajrolii mudrá** — сжатие vajrolii nádií при мочеиспускании (Ch08).

**Vasti mudrá** — поддержка гениталий при дефекации (Ch06).
