# Читшит — правила решений по Caryácarya Part 3

## Купание

| Ситуация | Правило |
|---|---|
| Порядок купания | Пупок → ниже пупка спереди → сзади → макушка (по позвоночнику) → омовение |
| После купания | Мантра Pitr Yajiṋa с мудрой 3 раза (до вытирания) |
| Когда купаться | В одной из трёх sandhyá (рассвет / 9–12 / закат); не в полночную |
| Холод/болезнь | Тёплая вода, закрытое место; вода всегда ниже температуры тела |

## Еда

| Ситуация | Правило |
|---|---|
| Перед едой | Vyákápa shaoca; пригласить присутствующих, проверить их достаток |
| Состояние | Не есть в гневе/подавленности; в компании, не одному |
| Порция | ½ желудка еда / ¼ вода / ¼ воздух |
| Активная ноздря для еды | Правая (pingalá) |
| После вечерней еды | Короткая прогулка |
| Выбор еды | Sáttvika (тело+ум) → rájasika (переходно) → támasika (избегать) |
| Практикующим ásanas / отрёкшимся | Только sáttvika |
| Мясо | Только самцы/кастрированные; самок и мелкую рыбу — не есть |

## Пост

| Ситуация | Правило |
|---|---|
| Обязательный пост | Ekádashii (11-й день лунного месяца) |
| Отрёкшимся | Плюс púrńimá и amávasya (4 дня месяца) |
| Формат | Без еды и воды от восхода до восхода; ум — в мысли о Iishvara |
| Пропустил | Заменить предыдущим/следующим днём |
| Болезнь | Не поститься; письменное разрешение Dharma Pracára-секретаря |
| Постный день | Усиленная sádhaná (энергия освобождена) |

## Ограничение чувств

| Ситуация | Правило |
|---|---|
| Смысл brahmacarya | Ум в Brahma (не «сохранение семени») |
| Холостым | 3–4 семенных разряда в месяц — норма (naeshthika) |
| Женатым | Не чаще 4 раз в месяц (prajápatya) |
| Контрацепция с повреждением тела | Запрещена; особые случаи — разрешение ácárya (через Ácárya Board) |
| Дети | Столько, сколько можно достойно воспитать |

## Здоровье

| Ситуация | Правило |
|---|---|
| Сон | Не на мягкой кровати; не спать днём / не бодрствовать ночью |
| Волосы тела | Не стричь (особенно подмышки/лобок) |
| Опьяняющие | Támasika — отбрасывать как яд |
| Женщинам | Ежедневно воздух/солнце; правила менструации; 21 день отдыха после родов |
| Детям до 5 лет | Молоко, фрукты, корни; без мяса; щелочная еда полезна |

## Ásanas

| Ситуация | Правило |
|---|---|
| До практики | Vyákápa shaoca; пустой желудок (2,5–3 ч после еды) |
| Ноздри | Левая или обе; не правая (кроме 8 поз без ограничений) |
| Одежда/место | Муж. — kaopiina; жен. — плотное бельё; коврик, не земля, без дыма |
| После | Массаж → shavásana ≥2 мин → 10 мин без воды; práńáyáma не сразу |
| Менструация/беременность/послеродовое | Не практиковать (кроме padmásana/siddhásana/viirásana для dhyána) |
| Разрешение | Только с ácárya |

## Mudrás / Práńáyáma

| Ситуация | Правило |
|---|---|
| Mudrás vs ásanas | Как ásanas, но с идеацией; без ограничений ноздрей |
| Bandhas | Точные протоколы (sфинктеры, jalandhara, ½ мин) |
| Кому práńáyáma | Только садхакам, с разрешения ácárya/purodhá |
| Прогрессия | 3 раунда 1-я неделя → +1/нед до 7; до 4 раз в день |
| Лечебные kumbhaka | От ácárya; один вид; не за час до/после основной práńáyáma |
| Гигиена | Без пыли/дыма/дурных запахов; молочные продукты 2 месяца |
