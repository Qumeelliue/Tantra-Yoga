# Chapter 5: Devotion – the Only Path

*Дискурс 18 ноября 1978, Patna. Discourse 106 серии.*

## Core Idea

Джняни подходит близко к цели, карми ближе, бхакта доходит до цели. Джняни/карми каются; бхакта полон ананды и безразличен к боли/удовольствию. Единственный путь — преданность; цель — не просить, а служить радости Parama Purusa (gopa).

## Frameworks Introduced

- **Три помощника**: jiñána (знание) — близко; karma — ближе; **bhakti — до цели**. Джняни кается о «сухих дискурсах»; карми — о недостигнутом; бхакта без покаяния — полон блаженства, безразличен к боли/удовольствию.
- **Тщеславие джняни/карми**: в интеллектуале скрыто тщеславие («я знаю то, чего другие не знают»); карми втайне хочет газетной славы. У бхакты нечего терять: «Он — мой», потому боль/удовольствие равны.
- **История с собакой**: преданный ест рис с голодной собакой; джняни: «собака грязная, ты неприкасаемый!» Преданный: «Я — Вишну, собака — Вишну; весь мир пронизан Вишну; цветы и шипы равны».
- **Боль/удовольствие = ментальная проекция**: позитивная/негативная; равновесие сохраняется; имя/слава ничего не дают. В раю и аду Он с преданным — там киртан.
- **Мысль формирует**: думающие о деньгах — сейф/денежный мешок; о музыкальном инструменте — инструмент; о Господе — тонкость. Показная преданность/мантра без ума бесплодны (в уме план дома).
- **Путь**: единственный — преданность; цель — не просить, а служить, чтобы сделать Его счастливым; преданный счастлив Его счастьем. **Gopa** — работающий для счастья Parama Purusa — вершина.

## Key Concepts

- **jiñánii / karmii / bhakta** — три пути, бхакта у цели.
- **собака-Вишну** — образ всепроникновения.
- **боль/удовольствие как проекция** — равновесие.
- **gopa** — работающий для Его счастья.

## Mental Models

- «Думай о пути как о гонке: джняни у старта, карми на полпути, бхакта на финише».
- «Думай о мысли как о ваятеле: чем мыслишь, тем становишься».

## Anti-patterns

- **Тщеславие знания/дела** — скрытая гордость ведёт к падению.
- **Показная практика** — мантра без ума (в голове план дома).
- **Взаимные просьбы** — цель преданности — давать радость, не просить.

## Worked Example

*Преданный ест с собакой; интеллектуал возмущается. Преданный: «Я — Вишну, собака — Вишну; цветы и шипы равны». Автор: так только бхакта может. Джняни считает, карми гордится; бхакта доходит до цели, полон блаженства. Высшая ступень — gopa: служить Его радости. Это единственный путь.*

## Key Takeaways

1. Бхакта доходит до цели; джняни/карми — нет.
2. У бхакты нет тщеславия; боль/удовольствие равны.
3. «Я — Вишну, собака — Вишну» (история).
4. Мысль формирует: о деньгах — сейф; о Нём — тонкость.
5. Вершина — gopa: работа для Его радости.
