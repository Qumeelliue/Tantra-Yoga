# Chapter 14: The Psycho-Spiritual Evolution of Humans

*Дискурс 26 ноября 1978 (вечер), Bombay. Discourse 115 серии.*

## Core Idea

Метаморфоз человека: гиганты вымерли (нет интеллекта), кранuум рос, тело слабело; все — готра обезьян (касты лицемерны). Эволюция религии: природа → духовная сила → идеация на Параматму → Brahma Vijiñána → Шива. Дев-йони — посмертные состояния по амбициям. Поощряй науку.

## Frameworks Introduced

- **Метаморфоз**: гигантские животные вымерли из-за малого интеллекта; «это век не для больших животных и малых государств» (слон не прокормится; малые государства сольются). Человек ~1 млн лет; малый череп → рост черепа и интеллекта, слабость тела; **все — готра обезьян** (кастовая система лицемерна; нет «брахманских обезьян»). «Buddhiryasya balaḿ tasya» — сила в интеллекте; слонов гоняют погонщики-интеллектуалы.
- **Эволюция религии**: 1) поклонение природе (Уша-рассвет, Ваджра, гроза — «всё бог», из страха/неведения); 2) осознание духовной силы за психикой (Пракрти — подчинённое сотрудничество; «Shaktih sá Shivasya shaktih»); 3) идеация на Параматму (развивает интеллект; «поклоняешься почве — станешь почвой»); 4) **Brahma Vijiñána** (путь без возврата); 5) Шива 7000 лет назад дал процесс идеации.
- **Дев-йони** (по амбициям): yakśa (деньги), rakśa (власть), kinnara (красота), vidyádhara (добродетели), gandharva (музыка), **siddha** (оккультные силы; лучшие; помогают садхакам — вдохновение «сядь прямо сейчас»), Prakrtiliina (природа/материя — хуже всех; камень → почва → миллионы лет до человека). Сварга/небо — лишь этап между жизнями; без постоянного освобождения возврат.
- **Наука**: материальная наука → психические изменения → биологические изменения → быстрее садхана. **Поощряй науку**, не препятствуй; тепловой смерти вселенной не будет; будущее светло.

## Key Concepts

- **метаморфоз / готра обезьян** — эволюция человека.
- **эволюция религии** — природа → дух → идеация.
- **дев-йони** — семь посмертных состояний.
- **Brahma Vijiñána** — интуитивное знание без возврата.
- **наука ускоряет садхану** — поощрять.

## Mental Models

- «Думай о касте как о лицемерии: у всех предки-обезьяны».
- «Думай об амбиции как о посмертной орбите: она определяет, в какой дев-йони ты окажешься».

## Anti-patterns

- **Кастовое высокомерие** — все из готры обезьян.
- **Натуропоклонство** — опасность: «поклоняешься камню — станешь камнем».
- **Препятствовать науке** — она ускоряет духовный прогресс.
- **Довольствоваться «раем»** — он временный этап.

## Worked Example

*Почему люди сегодня не как древние? Автор: миллион лет метаморфоза — череп рос, интеллект вырос, тело слабело. Гиганты вымерли — «век не для больших тел и малых государств». Религия эволюционировала: сначала боялись природы (Уша, Ваджра — боги), потом поняли духовную силу за психикой, потом стали идеировать на Параматму; Шива дал процесс идеации. Амбиции после смерти определяют дев-йони. Наука ускоряет путь — поощряй.*

## Key Takeaways

1. Метаморфоз: череп рос, тело слабело; гиганты вымерли.
2. Все — готра обезьян; кастовая система лицемерна.
3. Религия: природа → дух → идеация → Brahma Vijiñána → Шива.
4. Дев-йони — по амбициям; сиддха лучший, пракртилина худший.
5. Поощряй науку — она ускоряет садхану.
