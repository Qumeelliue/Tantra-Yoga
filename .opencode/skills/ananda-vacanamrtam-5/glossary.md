# Глоссарий — Ánanda Vacanámrtam Part 5

**А́гама / ни́гама (ágama/nigama)** — ответы Шивы / вопросы Парвати; крылья Тантры (Ch 11, 12).

**А́ласйя (álasya)** — летаргия; порок (Ch 7).

**Аннуша́сана (anushásana)** — дисциплина с идеацией блага (Ch 12).

**Атрибутивное поклонение** — перечисление качеств Господа — бессмысленно (Ch 8).

**Атмаджияна / виджна́на (átmajiñána/vijiñána)** — знание себя; реальное знание (Ch 10, 12).

**Бхи́ша́нам бхи́ша́на́на́м (Bhiiśańaḿ bhiiśańánám)** — «страх страхов» (Ch 3).

**Ва́да/джа́лпа/витан́д́а́** — три аспекта интеллектуализма (победа в споре) (Ch 11).

**Ва́судева** — сын Васудевы = защитник созданных = Вишну (Ch 11, 12).

**Веда vs Тантра** — «лезвие бритвы» против прыжка в среду без страха (Ch 1).

**Вираача́ра / дивьяача́ра** — героическая / божественная стадия (Ch 1, 13).

**Гуру (три типа)** — шепчущий/спрашивающий/принуждающий (Ch 12).

**Дев-йони** — посмертные состояния по амбициям (якша/ракша/киннара/видьядхара/гандхарва/сиддха/пракртилина) (Ch 14).

**Джа́рмакшетра / Курукшетра** — тело (поле дхармы) / мир («делай!») (Ch 16, 17).

**Дхи́ргасу́трата́ (diirghasútratá)** — прокрастинация; порок (Ch 7).

**Дхритара́штра / Са́нджая** — слепой ум / совесть (Ch 16, 17).

**Ка́ли́ка́-шакти** — Парама Пракрти (чёрный = отсутствие цвета) (Ch 9).

**Кардинальная / не-кардинальная молитва** — об интеллекте / о вещах (Ch 8, 9).

**Ка́па́лика** — служащий ka (миру); авдхуты АМ (Ch 18).

**Ка́оси́ки́** — танец автора (6 сентября) для женщин (Ch 15).

**Klrḿ** — биджа Кришны (ka+la+anusvára) (Ch 18, 11).

**Крийя-шакти** — слепая энергия; нужен Праджня (Ch 4).

**Лакшмана и богиня сна** — не спать на духовной функции (Ch 7).

**Лила** — игра одной части Творца с другой (Ch 6, 9).

**Lokavyamohakáraka** — вводящие в заблуждение (Ch 12).

**Ма́нтра** — «Mananát tárayet»; смысл + акустический корень (Ch 18).

**Махимнабодха** — «Господь велик, как я пойду?» — ошибочно (Ch 7).

**Ota-yoga / prota-yoga** — личная / коллективная связь (Ch 4).

**Пашвача́ра / пашу** — животная стадия (Ch 1, 13).

**Пракртилина** — поклоняющиеся природе; хуже дев-йони (Ch 14).

**Prárthanárcaná mátraeva Bhramamúlam** — только молитва/поклонение — корень заблуждения (Ch 8).

**Рипу/паша** — враги/путы (Ch 1).

**Са́дхана = единственный путь** — Тантра = садхана (Ch 1).

**Са́ра-ва (sa-ra-va) = са́рва** — sentient/энергия/дхарма (Ch 4).

**Саха́ра́ра-чакра** — 1000 пропенситов (50×2×10) (Ch 12).

**Сиддха** — лучший дев-йони; помогает садхакам (Ch 14).

**Та́н́да́ва** — танец прыжка; борьба со смертью (Ch 15).

**Та́ндра́ (tandrá)** — рассеянность; порок (Ch 7).

**Хара (Hara)** — биджа Шивы (ha=эфир + ra=энергия) (Ch 18).

**«Что пришло, уйдёт» (Yah ágacchati sah gacchati)** — не привязывайся (Ch 10).

**Шесть пороков** — nidra, tandra, bhaya, krodha, alasya, diirghasutrata (Ch 7).

**Шубха-буддхи** — благодетельный интеллект (Ch 8).
