# Читшит — Ánanda Vacanámrtam Part 5

## Тантра и практика

| Ситуация | Правило |
|---|---|
| Путь Веды | «Лезвие бритвы»; избегай среды; страх уйдёт когда-нибудь |
| Путь Тантры | Прыгай в среду; страх уходит шаг за шагом |
| Стадии тантры | pashvácára → viirácára → divyácára |
| Тантра и садхана | Единственная садхана; без неё нет Тантры |
| Теория | Из практики — непогрешима в применении |

## Грех и прибежище

| Ситуация | Правило |
|---|---|
| «Я грешник» | Первертная мысль — сама делает грешником |
| Как думать | «Я был грешником, но я в прибежище» |
| Грехи | Пыль на одежде; Отец стряхнёт и возьмёт на колени |
| Что такое грех | Вред другим (не ментальные проступки сами по себе) |
| Ментальный грех | Исправляй (киртан), не наказывай, пока не стал внешним |
| Прибежище | Последнее слово: «я машина в Твоих руках» |
| Он не может | Ненавидеть; создать второго Себя |

## Преданность

| Ситуация | Правило |
|---|---|
| Кто доходит до цели | Бхакта (джняни/карми — нет) |
| Стратегия бхакты | Отдать дело Parama Purusa — победа без борьбы |
| Манго-роща | Бхакта ест плод; джняни считает листья; карми ловит отражение |
| Почему творение | Творец был одинок (лила) |
| Вершина | Gopa — работа для радости Parama Purusa |
| Интеллектуализм | váda/jalpa/vitańd́á — тщеславие («воздушный рис») |

## Пороки и комплексы

| Ситуация | Правило |
|---|---|
| Шесть пороков | Сон, рассеянность, страх, гнев, лень, прокрастинация |
| На духовной функции | Не спать (история Лакшманы) |

## Быстрые сигналы («tells»)

- «Я слишком грешен для Бога» — пыль на одежде; Отец стряхнёт.
- «Не могу, боюсь» — тантрический ответ: прыгай в среду, страх уйдёт.
- Молитва «дай мне X» — не-кардинальна, бесполезна.
- Интеллектуал гордится победой в споре — «воздушный рис» (пусто).
- «Господь далеко, я один» — махимнабодха + забвение ота-йоги.
- Просьба «уничтожь врага» — тамасика-бхакта, не получит Его.
