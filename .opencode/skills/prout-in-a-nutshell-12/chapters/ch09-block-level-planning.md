# Chapter 9: Block-Level Planning

*Дискурс 1981 года, Калькутта. Опубликован как «Inter-Block and Intra-Block Planning».*

## Core Idea

В децентрализованной экономике планирование идёт снизу вверх, начиная с блока — базовой ячейки. Четыре фактора планирования (себестоимость, производительность, покупательная способность, коллективная необходимость) и два типа планирования (intra-block и inter-block) обеспечивают самодостаточность и полную занятость.

## Frameworks Introduced

- **Четыре фактора планирования**:
  1. *Cost of production (себестоимость)*: крестьяне не считают труд семьи, инструменты, издержки — отсюда потери и низкие цены. Решение: **сельское хозяйство как организованная индустрия через кооперативную систему**; себестоимость на минимуме; себестоимость ≤ рыночной цены; каждая единица экономически жизнеспособна.
  2. *Productivity (производительность)*: экономика должна иметь врождённую способность производить больше; деньги инвестируются (keep rolling), а не прячутся; максимум производства по коллективным нуждам; никакого недогруза производственных единиц; производство там, где сырьё.
  3. *Purchasing capacity (покупательная способность)*: **per capita income — обманчивая и дефектная мера**, популярная капиталистическими экономистами; подлинный индекс — растущая покупательная способность (доступность минимума, стабильные цены, рост зарплат, рост коллективного богатства). Предела нет.
  4. *Collective necessity (коллективная необходимость)*: текущие и будущие потребности (пример: в Индии индустрии построили, а электричество отстало); максимум внимания — минимуму потребностей; не забывать meritorious и special needs.
- **Блок как базовый уровень**: планирование на уровнях блок → округ → штат → нация → глобальный; блок — основа децентрализации, закрепляется в конституции. Уровни планирования **восходящие (ascending order)**.
- **Демаркация блоков**: НЕ по политическим соображениям, а по физическим особенностям (речные долины, климат, топография, почва, флора/фауна), социально-экономическим проблемам, психофизическим устремлениям.
- **Intra-block vs inter-block**: intra — план для всестороннего роста одного блока, согласованный с планами выше. inter — сотрудничество блоков для проблем через границы: наводнения, речные проекты, коммуникации, высшее образование, лесонасаждения, воздействие на среду, ключевые отрасли, эрозия, водоснабжение, энергетика, рынки.
- **Сроки планирования (⚠ конкретика, к калибровке)**: краткосрочный ≤ 6 месяцев; долгосрочный ≤ 3 лет; планы взаимодополняющие.

## Key Concepts

- **Самодостаточность**: каждый блок экономически прочен → вся страна/федерация сильна. Уникальная черта PROUT.
- **Немедленные цели каждого уровня**: гарантия минимума потребностей, ликвидация безработицы, рост покупательной способности, самодостаточность.
- **Floating population**: организуется на уровне блока — либо оседает, либо возвращается в регион происхождения.
- **Пример различий**: Punjab (гималайские ледниковые реки, гидроэнергетика — Bhakhra Nangal) vs Cauvery Valley (реки с Гат, сезонные дожди, без гидроэнергии) — планы не могут быть одинаковыми.

## Mental Models

- «Думай о планировании как о дереве: корни — блоки, и ветки (округ/штат/нация) вырастают из них, а не наоборот».
- «Каждый план проверяй четырьмя фильтрами: себестоимость ≤ цена, производительность растёт, покупательная способность растёт, коллективная необходимость учтена».
- «Intra-block решает "внутри блока", inter-block — "через границы" (река, дорога, университет)».
- «Блок — ячейка конституции, не админделение по карте».

## Anti-patterns

- **Планирование сверху вниз** — против ascending order.
- **Границы блоков по политике** — не научно, ломает децентрализацию.
- **Per capita income как мера прогресса** — скрывает неравенство и инфляцию.
- **Себестоимость без учёта труда семьи** — крестьянская нищета и низкие цены.
- **Отсутствие inter-block планирования** — наводнение, энергетика, дороги через границы блоков не решаемы одиночкой.

## Worked Example

*План для блока у реки.* Шаг 1: пересчитать себестоимость агропродукции с учётом труда семьи и инструментов — через кооператив. Шаг 2: инвестировать деньги в рост производства (не прятать). Шаг 3: гарантировать минимум и поднимать покупательную способность (стабильные цены, рост зарплат). Шаг 4: сверить с коллективной необходимостью — например, в блоке заводы есть, а электроэнергии нет → приоритет энергетике. Разделить: внутри блока — внутриблоковый план (местная ирригация); через границы — межблоковый (общая дамба, университет, дорога). Сроки: 6 месяцев краткосрочный, 3 года долгосрочный.

## Key Takeaways

1. Блок — базовый уровень планирования; уровни восходят от блока вверх.
2. Четыре фактора: себестоимость, производительность, покупательная способность, коллективная необходимость.
3. Покупательная способность — настоящий индекс; per capita income — обман.
4. Intra-block (внутри) + inter-block (через границы) — два взаимодополняющих типа.
5. Блоки демаркируются по физическим особенностям, не по политике; самодостаточность каждого блока = сила всей страны.
