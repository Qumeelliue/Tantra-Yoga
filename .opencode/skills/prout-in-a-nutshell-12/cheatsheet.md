# Читшит — правила решений по Саркару (Prout 12)

## Экономика

| Ситуация | Правило |
|---|---|
| Оценить экономику региона | Четырёхмерный аудит: люди (минимум) → психо → коммерческая → общая |
| Кто приоритет в экономике | People's economy главенствует: гарантия минимума = конституционное право |
| Занятость в агро | 30–40% (⚠ к калибровке); меньше — запущено, больше — перегруз |
| Доля не-агро отраслей | 20–30% = баланс; <20% = сателлит; >30% = пере-индустриализация |
| Промышленность | Крупное — кооператив; ключевое — «no profit, no loss»; частное — ограничено |
| Прогресс региона | Измеряй покупательной способностью, НЕ per capita income |
| Кредиты и деньги | Только продуктивные инвестиции; нет печати без резерва |
| Бартер | Выгоден, когда много товаров немногих видов и развита логистика |

## Планирование

| Ситуация | Правило |
|---|---|
| Уровень планирования | Блок — базовый; восходящий порядок вверх |
| Демаркация блоков | По физическим особенностям, не по политике |
| Проблемы через границы блоков | Inter-block planning (реки, дороги, энергетика, университеты) |
| Сроки планов | Краткосрочный ≤ 6 мес.; долгосрочный ≤ 3 лет |
| Четыре фильтра плана | Себестоимость ≤ цена; производительность растёт; покупательная способность растёт; коллективная необходимость |

## Конституция и право

| Ситуация | Правило |
|---|---|
| Форма правления | Президентская, прямой электорат, коллективное выше индивидуального |
| Изменение конституции | Только 7/8 парламента-учредительного собрания |
| Языки | Все живые языки равны; никакой региональный язык — национальным |
| Закон | Один кодекс для всех (Indian Code), без параллельных личных кодексов |
| Право против ценностей | Кардинальные человеческие ценности выше любых прав |
| Защита природы | Флора и фауна — в конституции (Charter of Rights) |
| Право региона | Самоопределение только через плебисцит, под контролем центра |

## Этика и психология

| Ситуация | Правило |
|---|---|
| Сделал дурное | Papa; искупим = Pátaka; тяжкий = Atipátaka; с повторяющимся вредом = Mahápátaka |
| Не сделал должное | Pratyaváya — хуже Papa |
| Врождённые влечения (6 Ripus) | Регулируй, не подавляй (подавленный выстреливает через другой) |
| Внешние путы (8 Pashas) | Сопротивляйся; от страха — движением к источнику |
| Деление людей | Путь анализа = античеловечен; синтез = «сыновья одного отца» |
| Свобода | Физическая — ограничена; психическая и духовная — полная |

## Быстрые сигналы («tells»)

- «Растёт доход на душу» — маскировка: проверь покупательную способность и неравенство.
- Блоки по политическим границам — не научная децентрализация.
- Партия обвиняет других в сепаратизме — вероятно, сама на нём живёт (Ch 12).
- «Протестуем против порнографии» без создания альтернатив — не работает (Ch 1).
- Президент-«резиновая печать» — дефект, а не норма (Ch 11).
- Проценты занятости и 7/8, сроки планов — конкретика из дискурсов, ⚠ к калибровке под современность.
