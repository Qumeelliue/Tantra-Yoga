# Читшит — правила решений по Саркару (Ananda Marga Nutshell Part 10)

## Преданность и молитва

| Ситуация | Правило |
|---|---|
| Оценить молитву/намерение | Классифицируй: вредит другим (тамасики) → ничего; просит мирское себе (раджасики) → нет освобождения; «для виду» (саттвики) → Бога не хотят; «мне радостно» (рага́нуга́) → вторая ступень; «Ему радостно» (рага́тмика́) → вершина |
| Знание душит преданность | Действие − знание = бхакти; сбрось тщеславие знанием или добавь действия сверх пропорции |
| Формальная преданность не даёт слияния | Vaedhii приближает, но единство даёт только shuddhá (rágátmiká) |
| Просишь только Его | Получишь всё; просишь себя/блага — упускаешь главное |

## Силы и ум

| Ситуация | Правило |
|---|---|
| Ум фиксируется на враге/пороке | Vikśepii: ты станешь тем, о чём думаешь (yádrshii bhávaná…) → переведи идеацию |
| «Меня никто не видит» | Ávarańii самообман; всё отражается на космическом зеркале — скрыть нельзя |
| Внезапное раскаяние | Samvit — начало поворота; закрепи hládinii (устремление к благу) |
| Согласовать желания с системой | Индивидуальный поток должен войти в макрокосмическое течение, иначе «без Его одобрения нет успеха» |

## Путь (Bhágavata dharma, садхана)

| Ситуация | Правило |
|---|---|
| Проверить «путь развития» | Триада: расширение (вистара) + поток (раса) + служение без отдачи (сева) |
| Выбрать практику | Идеация на Брахму > медитация/концентрация > джапа/стути > идолопоклонство |
| Пост/омовение/паломничество | Не спасают сами по себе; полезны, если ведут внутрь (упаваса = «сидеть рядом» с Господом) |
| Минимальная квалификация | Чистое сердце; учёность и лекции не дают реализации («микрофон» не спасся) |
| Цель жизни | Идеал должен быть вне время/пространство/личность (álambana); иначе — преходящий пабулум |

## Кризис и структура

| Ситуация | Правило |
|---|---|
| Коллективная деградация не решается усилиями одиночек | Нужна специальная структура — Mahásambhúti (Táraka Brahma), а не герой-одиночка |
| Уничтожение объекта | Различай: наша (сломано), винаша (необратимо преобразовано), пранаша (вернулось к источнику) |
| Направление в медитации | Неважно — все стороны суть sambhúti Верховного |

## Обратная связь и отношение к людям

| Ситуация | Правило |
|---|---|
| Дисциплинировать/наставлять | Пять лиц Шивы: мягко → предупреди о последствиях → ласка → гроза → страх перед карой; реальная кара — крайность |
| Ненависть/презрение к кому-либо | Запрещено: всё — sambhúti; ненависть — признак отсутствия морального мужества |
| Кастовость/дискриминация | Атеизм и «враги общества»: у всех один Отец |
| Комплекс неполноценности | Ты — принц/принцесса Parama Puruśa; победа предопределена |
| Наказание Господа | Для преданного — благо (Он должен прикоснуться, чтобы наказать) |

## Быстрые сигналы («tells»)

- Молитва «пусть враг пострадает» — тамасики-бхакти, пути нет.
- «У меня нет времени на медитацию, но есть на кино» — духовная лень.
- «Я построил, я знаю, я достиг» — тщеславие карми/джнани; преданный этого не говорит.
- Ритуал ради показухи — саттвики-обман.
- Системный хаос + «нужен герой» — ожидай Mahásambhúti-структуру, а не спасителя.
- Хвалишь Бога, чтобы «люди видели» — стути, низшая ступень.
