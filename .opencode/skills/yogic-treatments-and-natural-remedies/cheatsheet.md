# Читшит — правила решений (Yogic Treatments)

## ЖКТ
| Ситуация | Правило |
|---|---|
| Несварение/кислотность/язва | Щелочная диета + пахта + старый рис; правый нос после еды; пост экадаши |
| «Бесовский голод» | Не есть — стакан воды (Ch 4) |
| Грыжа | Не набивать желудок; есть мало и часто; без натуживания |
| Дизентерия | Слизь — защита, не гасить; диета важнее лекарств; живот в тепле |
| Язва | Есть часто и понемногу; мёд 2–3 ложки/день; отдых после еды; диета ещё 2 года |

## Выделения
| Ситуация | Правило |
|---|---|
| Язвы/гной/пятна (сифилис, экзема) | Не мазать на ранней стадии — дать выйти; потом neem-oil |
| Подавленная дизентерия | Вяжущие/инъекции = отсроченная белая проказа |
| Кровотечение при геморрое | Остановить временно, но лечить печень — иначе вернётся |

## Давление и сердце
| Ситуация | Правило |
|---|---|
| Высокое давление | Больше труда, меньше белка/жира/ума; Ишвара-пранидхана до асан |
| Низкое давление | Меньше труда; молоко и соки в постные дни |
| Сердце (критика) | Только Utkśepa Mudrá + покой в Шавасане; фрукты и молоко; сон 9 ч |
| Гнев/страх/секс | Прямые враги сердца — исключить |

## Сахар
| Ситуация | Правило |
|---|---|
| Диабет | Труд физический (болезнь интеллектуалов); фрукты (банан); без мяса; пост на соке при обострении |
| Сахар «травматический» | Инсулин вреден — лечить травму органа |
| Низкий сахар | Без сахара/жира/алкоголя/животного (кроме пахты); тандава + быстрая ходьба |

## Камни
| Ситуация | Правило |
|---|---|
| Камни жёлчного/почек | Вода 4–5 сееров + лимон; пост на лимонной воде |
| Пост без воды | Запрещён при камнях |

## Половая сфера
| Ситуация | Правило |
|---|---|
| Поллюции >4/мес | Болезнь: гигиена, ранний ужин, контроль мыслей; не стыдиться |
| Импотенция/бесплодие | Наштхика-брахмачарья; лечить по типу (8 типов) |
| Воздержание после венерического | Сифилис — 1.5–2 года; гонорея — ≥3 года |

## Кожное
| Ситуация | Правило |
|---|---|
| Проказа/белая проказа | Не заразны (почти); питание + солнце + грязь; зелень ежедневно |
| Экзема | Лечить дизентерию-корень; солнце; без сладкого/мяса |
| Фурункул без отверстия | Свежий голубиный помёт вскрывает за часы |

## Дыхание/нервы
| Ситуация | Правило |
|---|---|
| Астма | Ранний лёгкий ужин; голод при атаке; молоко главным напитком |
| Паралич/эпилепсия | Аштанги + Pakśabadha пранаяма; без гхи/масла; зелень варёная |
| Тонзиллит | 3 раунда (Shivásana→Matsyamudrá→Matsyendrásana); боль в канале → гвоздика |

## Общие сигналы
- «Не гаси выделение» — универсальный закон книги.
- Корень почти всегда: печень + кислотность + запор + трата шукры.
- Асаны — только у ачарьи (предисловие автора).
- Книга 1958 года: НЕ руководство к самолечению; при острых состояниях — врач.
