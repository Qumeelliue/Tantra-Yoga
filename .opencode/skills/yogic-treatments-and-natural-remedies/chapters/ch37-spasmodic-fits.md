# Глава 37: Спазматические судороги у детей (Spasmodic Fits)

## Core Idea
У детей судороги с лихорадкой и закатившимися глазами могут быть смертельны. Лекарство — растение нагдона (Artemisia vulgaris), «нет другого средства» для этой болезни.

## Frameworks Introduced
- **Симптомы**: у ребёнка лихорадка с закатившимися вверх глазами; в итоге может умереть.
- **Средства**: (1) листья нагдоны (растение ~2 фута высотой, с шипами и очень сильным запахом; есть и безшипные сорта) растереть в пасту и дать ребёнку нюхать — судороги проходят; (2) мыть лицо, руки и ноги пациента водой, в которой только что варился картофель — тоже сдерживает судороги.
- **Бонус**: нагдона «защищает от удара молнии» (верование автора ⚠).

## Key Concepts
- Нагдона — «превосходное лекарство для нервов».

## Mental Models
- «Судорога — короткое замыкание нервов: резкий запах растения — выключатель».

## Anti-patterns
- Откладывать (болезнь может быть смертельной).
- Использовать высохшие/безжизненные листья — важна свежая паста.

## Worked Example
Свежие листья нагдоны → растереть в пасту → дать ребёнку нюхать; дополнительно — мытьё картофельной водой.

## Key Takeaways
1. Судороги с лихорадкой у детей — неотложная ситуация.
2. Паста из листьев нагдоны для вдыхания — главное средство.
3. Картофельная вода — поддерживающее средство.
4. «Нет другого лекарства для этой болезни» — по автору.
