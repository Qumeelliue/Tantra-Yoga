# Chapter 2: Happiness, Dharma, and Karma

*Сутры 2-1…2-24 (24 сутры).*

## Core Idea

Глава о человеке: счастье как созвучие волн; бесконечная жажда счастья ведёт к Brahma; устремление к Великому = dharma; душа как отражение Сознания; мир — относительная истина; закон кармы без рая и ада; устройство чувств (tanmátra и indriya).

## Frameworks Introduced

- **Природа счастья (2-1, 2-2)**: sukha = созвучие комплементарных волн: внешние волны совпадают с внутренними волнами ума. Привязанность к счастью — первичный vrtti; без счастья под угрозой само чувство существования.
- **Лестница счастья → ánanda → Brahma (2-3…2-5)**: конечное счастье не насыщает; бесконечное счастье = ánanda; «ánanda есть Brahma»; достижение Brahma утоляет всю жажду (trśńá) навсегда.
- **Dharma (2-6, 2-7)**: «жаждать и бежать за Великим» = dharma; практика = dharma sádhaná; обязательна для человека, «не практикующий не заслуживает имени человека»; животные не способны.
- **Jiivátmá / Paramátmá (2-8, 2-9)**: отражение Puruśa в уме = jiivátmá (ańu caetanya); отражатель = Paramátmá / Pratyagátmá / Bhúmá Caetanya. Всё опирается на Átman: «I know» предшествует «I am».
- **Ota/prota yoga (2-10)**: Puruśottama связан с каждым атомом (ota) и со всей совокупностью (prota).
- **Семя вселенной (2-11, 2-12)**: за пределами ума; поиск первопричины упирается в бесконечную регрессию (infinite regress), вопрос «когда и почему началось» избыточен. Творение — из Saguńa Brahma, не Nirguńa.
- **Вселенная в теле Brahma (2-13)**: manifest + unmanifest — всё в Bráhmiidehe; «посторонних» нет.
- **Абсолютная и относительная истина (2-14)**: Brahma — Satya (неизменен); мир — относительная истина, зависит от времени, места, личности.
- **Деятель и свидетель (2-15…2-17)**: Puruśa не действует, лишь свидетельствует плоды и контролирует сами guńa; buddhi/mahattattva — не деятель; aham — деятель, вкушающий плоды напрямую.
- **Karma-физика (2-18…2-20)**: citta принимает форму плодов действий; восстановление искажённого citta = phalabhoga (вкушение); рая и ада нет — среда создаётся собственными поступками.
- **Материя, tanmátra, indriya (2-21…2-24)**: пять факторов рождаются из Cosmic citta в saincara; tanmátra — волны столкновений факторов, несущие сенсорику; категория объекта определяется его грубейшей tanmátra; indriya = ворота + нервы + нервная жидкость + piit́ha (пункт присвоения в мозге).

## Key Concepts

- **sukha / ánanda / trśńá / vrtti** — счастье / блаженство / жажда / склонность.
- **dharma / dharma sádhaná** — природа вещи и практика устремления к Великому.
- **jiivátmá / Paramátmá / Pratyagátmá / Bhúmá Caetanya** — единичная душа и её отражатель.
- **ota yoga / prota yoga** — связь Сознания с единичным / совокупным.
- **satya / apekśika satya** — абсолютная / относительная истина; desha-kála-pátra (время-место-личность).
- **kartá / akartá / bhoktá** — деятель / недеятель / вкушающий.
- **karmaphala / phalabhoga** — плод действия / вкушение плода.
- **tanmátra / indriya / saḿjiñá** — тонкие волны / органы / внутреннее чувство.
- **mahábhúta** — фундаментальные факторы (см. Ch 1).

## Mental Models

- «Счастье — это резонанс: система ищет волны, созвучные её природе; бесконечное может насытить только Бесконечное».
- «Dharma — это вектор: природа вещи определяет её правильное движение; человек по природе ищет Бесконечное».
- «Различай свидетеля и деятеля: Puruśa не делает — он свидетельствует; деятель (aham) вкушает плоды».
- «Никакого внеположного рая и ада: небо и ад — среда, созданная твоими же поступками».

## Anti-patterns

- **Гедонизм**: конечные удовольствия только разжигают жажду (2-3).
- **Материализм без Сознания**: мир — не ложь, а относительная истина; но и не вечная (2-14).
- **Теизм «рай-ад, молитвы-просьбы»**: рая и ада нет (2-20); просьбы к Богу — тоуадизм (Ch 3, 3-11).
- **Считать восприятие всех «одинаковым»**: tanmátra-нагрузка факторов разная; категория — по грубейшей tanmátra.

## Worked Example

*Dharma как ненасытная жажда.* Человек хочет счастья; мало — хочет больше (лестница желаний не заканчивается). Конечный объект не может дать бесконечное счастье, значит реальная цель — ánanda = Brahma. «Бежать за Великим» сознательно = dharma; практика = dharma sádhaná. Это не ритуал, а выравнивание вектора жизни с природой человека — и потому «dharma следует практиковать всегда» (2-7).

## Key Takeaways

1. Проверяй «удовлетворяемость» цели: конечная цель разожжёт аппетит, бесконечную жажду утоляет только Бесконечное.
2. Dharma = природа вещи; природа человека — искать Великое.
3. Душа — отражение Сознания; всё опирается на «I know».
4. Мир реален, но относительно (время-место-личность); Brahma абсолютен.
5. Делатель вкушает плоды; рая и ада нет — есть среда из собственных поступков.
6. Объект опознаётся по его грубейшей tanmátra; орган — четыре компонента, не просто «глаз».
