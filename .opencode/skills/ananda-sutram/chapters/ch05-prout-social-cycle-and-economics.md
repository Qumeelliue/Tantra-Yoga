# Chapter 5: The Social Cycle and PROUT

*Сутры 5-1…5-16 (16 сутр). Публиковалась также как «The Principles of Prout» и «The Principles of Progressive Socialism». Сутры 5-12…5-16 соответствуют Five Fundamental Principles of Prout (1959).*

## Core Idea

Социально-экономическая глава: история общества как вращение sámája cakra с доминирующим классом; sadvipra в ядре цикла как контролёр; типы смены эпох; экономика: минимальные требования для всех, избыток — по заслугам, максимальное и прогрессивное использование — PROUT (Progressive Utilization Theory, Теория Прогрессивного Использования).

## Frameworks Introduced

- **Социальный цикл (5-1)**: всегда доминирует один класс: Shúdra (ручной труд) → Kśatriya (сила/смелость) → Vipra (интеллект) → Vaeshya (капитал); в конце vaeshya-эксплуатации — shudra-революция и новый цикл.
- **Sadvipra (5-2)**: сторонники строгой морали и духовности, стоящие в ядре цикла, не на периферии; их долг — силой защищать праведных и подавлять эксплуататоров, когда доминирующий класс деградировал.
- **Типы смены эпох (5-3…5-7)**: kránti (эволюция — ускорение силой; отличие от svábhávika parivarttana, естественной смены), viplava (революция — огромной силой, когда гегемония заскорузла), vikránti (контр-эволюция — возврат к прошлой эпохе силой, крайне недолговечен), prativiplava (контр-революция — обратный поворот огромной силой, ещё короче), parikránti (полный оборот цикла через shudra-революцию).
- **Разнообразие — закон природы (5-8)**: нет двух тождественных объектов; «уравнивание всего» против природы и ведёт к разрушению; равенство существует лишь в непроявленном состоянии.
- **Минимальные требования (5-9)**: пища, одежда, лечение, жильё, образование — всем; набор меняется по эпохе (велосипед vs самолёт). Девиз: «Верховное Сознание — отец, Верховный Оперативный Принцип — мать, три мира — родина».
- **Избыток — по заслугам (5-10)**: после минимумов избыток распределяется по merit (guńánupátena); лозунг «служи по способности, получай по необходимости» Саркар отвергает как нерабочий.
- **Повышение минимума (5-11)**: рост минимального стандарта = индикатор жизненности общества; процесс бесконечен.
- **Ограничение накопления (5-12)**: накопление богатства — только с одобрения коллектива; вселенная — общая собственность, права узуфрукта, без злоупотребления.
- **Максимальное использование (5-13, 5-14)**: максимально использовать грубые/тонкие/причинные потенциалы; максимальное развитие индивидуального и коллективного физического/психического/духовного потенциала; «благополучие коллектива — в индивиде, индивида — в коллективе».
- **Сбалансированное использование (5-15)**: баланс физического/умственного/духовного; люди зарабатывают минимум трудом по способности; лучший способ поднять минимум — покупательная способность; контроль общества — у духовно возвышенных + умных + смелых одновременно.
- **Прогрессивное использование (5-16)**: метод использования меняется по времени/месту/личности и должен быть прогрессивным; наука должна выжимать больше из того же потенциала; цепляние за «скелеты прошлого» отторгается живым обществом. Итог: «Это — Теория Прогрессивного Использования ради счастья и всестороннего благополучия всех».

## Key Concepts

- **sámája cakra** — социальное колесо/цикл.
- **Shúdra / Kśatriya / Vipra / Vaeshya** — классы-эпохи.
- **sadvipra** — духовный революционер в ядре цикла.
- **kránti / viplava / vikránti / prativiplava / parikránti** — пять типов смены эпох.
- **svábhávika parivarttana** — естественная (без силы) смена эпох.
- **sarvanimna prayojana** — минимальные требования; **atirikta** — избыток.
- **guńánupátena** — по степени заслуг.
- **upayoga** — использование; **pragatishiila upayoga** — прогрессивное использование.
- **PROUT (Progressive Utilization Theory)** — итоговое имя системы.
- **hararme pitá, Gaorii mátá, svadeshah bhuvanatrayam** — космополитический девиз.

## Mental Models

- «Социальная история — цикл, а не линия: доминирующий ресурс каждой эпохи порождает свой класс и свою эксплуатацию».
- «Регулятор цикла — не периферия, а ядро (sadvipra), действующее силой для защиты слабых».
- «Смена эпох бывает вперёд (kránti/viplava) и назад (vikránti/prativiplava); назад — недолговечно».
- «Экономика = минимум для всех + избыток по заслугам + постоянное повышение минимума + максимальное прогрессивное использование».
- «Природа требует разнообразия, а не тождества: уравнивание разрушает».

## Anti-patterns

- **Тотальное равенство**: против закона разнообразия (5-8) — ведёт к уничтожению.
- **Накопление без одобрения коллектива**: прямое ущемление других (5-12).
- **Эксплуатация доминанта**: деградировавший класс-хищник должен быть подавлен sadvipra.
- **Ностальгия по прошлым методам**: использование должно меняться с временем/местом/личностью (5-16).
- **Опора на одну только силу или один только интеллект**: контроль требует духовности + интеллекта + смелости вместе (5-15).

## Worked Example

*Покупательная способность как рычаг.* По 5-15, лучший способ поднять минимум — увеличить покупательную способность людей: человек зарабатывает минимум своим трудом по способности, а общество растит его возможность покупать. По 5-10 заслуги получают больше (врачу — автомобиль, пока всем — велосипед); по 5-11 минимум затем поднимается для всех. «Минимум для всех» + «избыток по заслугам» работают как двигатель роста, а не как статичная раздача.

## Key Takeaways

1. Анализируй власть через sámája cakra: какой класс на каком ресурсе доминирует и кого эксплуатирует.
2. Держи регулятора в ядре (sadvipra): защита слабых силой — легитимная функция.
3. Различай пять типов смены эпох; возврат назад всегда короткоживуч.
4. Экономический минимум — не благотворительность, а право всех; избыток идёт по заслугам.
5. Покупательная способность и максимальное использование — главные рычаги роста.
6. Использование должно быть прогрессивным и меняться по времени/месту/личности.
7. Всё вместе — это PROUT: счастье и всестороннее благополучие всех.
