# Читшит — правила решений по Ánanda Sútram

## Метафизика и космология

| Ситуация | Правило |
|---|---|
| Объяснить цикл любого процесса | Проведи ось saincara (огрубление, рост связывания) → pratisaincara (очищение, сброс) вокруг одного Нуклеуса |
| Система под давлением жёстких правил | Растёт внутреннее трение; без баланса — взрыв (jad́asphot́a); умеренный clash даёт энергию (bala) |
| Откуда берётся ум | Из материи: чрезмерный clash рождает cittáńu (ум-субстанция) |
| Что такое интеллект/интуиция | Избыток верхнего слоя «Я» над нижним: aham>citta → buddhi; mahat>aham → bodhi |
| Какой слой свидетельствует какой | Действие нижнего слоя свидетельствует верхний: citta→aham→mahat→«I know» (Puruśa) |

## Счастье и цель

| Ситуация | Правило |
|---|---|
| Понять, утолит ли цель | Конечная цель разжигает жажду; бесконечную жажду утоляет только Бесконечное (ánanda = Brahma) |
| Найти dharma человека/системы | Dharma = природа: огонь жжёт, человек ищет Великое; практика этого = dharma sádhaná |
| Проверить «духовную» механику | Критерий — идеация (bhakti), не ритуал и не лесть; просьбы-молитвы = тоуадизм |
| Оценить препятствия | Препятствия — союзники: контр-усилие доносит до цели |

## Карма и последствия

| Ситуация | Правило |
|---|---|
| Кто отвечает за результат | Деятель (aham) и есть вкушающий плоды; Puruśa — только свидетель |
| Что происходит с последствиями | Плод принимает форму citta; отложенные последствия — samskara, отрабатываются через vipáka |
| «Рай» и «ад» | Внешних рая/ада нет: среда сама становится благом или страданием от собственных поступков |
| Посмертие | Смерть = долгий сон причинного ума; бестелесный ум не чувствует ни боли, ни радости |

## Общество и власть

| Ситуация | Правило |
|---|---|
| Кто сейчас у власти | Спроси: какой класс/ресурс незаменим (сила → интеллект → капитал → число работников) |
| Доминант эксплуатирует | Смена доминанта проблему не решает; нужен регулятор в ядре (sadvipra), защищающий слабых силой |
| Классифицировать перемены | Вперёд силой = kránti; огромной силой = viplava; назад = vikránti/prativiplava (недолговечны); полный оборот = parikránti |
| Инициатива «всех уравнять» | Против закона разнообразия (5-8) — разрушительна; различай равенство возможностей и тождественность результатов |

## Экономика (PROUT)

| Ситуация | Правило |
|---|---|
| Минимальные требования | Пища, одежда, лечение, жильё, образование — всем, по эпохе (5-9) |
| Что делать с избытком | Распределять по заслугам, guńánupátena (5-10), не «всем поровну» |
| Как расти | Поднимать минимум (5-11); лучший рычаг — покупательная способность (5-15) |
| Накопление богатства | Только с одобрения коллектива (5-12); вселенная — общая собственность |
| Выбор метода | Максимальное и прогрессивное использование; метод меняется по времени/месту/личности (5-13…5-16) |
| Кому контроль общества | Духовно возвышенным + умным + смелым одновременно (5-15) |

## Быстрые сигналы («tells»)

- Текст/система обещает «полное равенство всего» → против закона разнообразия, риск разрушения.
- «Служи по способности, получай по необходимости» → Саркар прямо отвергает как нерабочий лозунг.
- Видишь «религиозный» ритуал без идеации → формальность, не преданность.
- Реформа через силу «возвращает прошлое» → короткоживуща (vikránti/prativiplava).
- Система «всех связала» без разрядки → копится внутреннее трение, жди взрыва.
- Минимум гарантирован всем, избыток по заслугам → это PROUT, а не уравниловка.
