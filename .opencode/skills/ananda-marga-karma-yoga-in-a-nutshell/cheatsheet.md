# Читшит — правила решений по Саркару (Karma Yoga in a Nutshell)

## Действие и плоды

| Ситуация | Правило |
|---|---|
| Право на результат | Нет: право только на действие; результат — в руках Пракрати |
| Освободиться от оков | Три процесса вместе: отказ от плодов + отказ от тщеславия деятеля + предание действий Брахме |
| Гордость «я сделал» | «Я — машина, Брахма — оператор»; затем «Брахма служит только Брахме» |
| Действовать из страха реакций | Нет: бездействие тоже оковы (тело/ум действуют всегда) |
| Ждать «перевеса» добра над злом | Каждая реакция исчерпывается отдельно; золотая цепь = железная |

## Яджны и служение

| Ситуация | Правило |
|---|---|
| Что такое действие | Яджна; всякое действие — приношение, психофизично (мысль → действие) |
| Служение созданиям | Bhúta yajiṋa (полив, скот, наука) |
| Служение людям | Nr yajiṋa: shúdrocita (уход), vaeshyocita (пища/деньги), kśatriyocita (защита), viprocita (знание) — по контексту |
| Служение с внутренней садханой | Adhyátma yajiṋa — 100% внутреннее, освобождающее |
| Чем сопровождать служение | Идеацией Нара́яны: «служу проявлению Брахмы»; из любви (prema), не из страха |
| Выбор вида служения | Умирающему — уход; голодному — еда; при нападении — защита; пьянице — твёрдость + наставление |

## Пути к Высшему

| Ситуация | Правило |
|---|---|
| Путь знания | Постоянная очистка: отделяй существенное от несущественного (золото из руды) |
| Путь кармы | Отвергай нечистые действия, продолжай по чистому пути; работа = Брахма |
| Путь бхакти | Прямой и блаженный: «не знаю ничего, делаю лишь чтобы порадовать Его» |
| Риск пути знания | Эго раздувается — падение; сохраняй смирение |

## Дхармы и поведение

| Ситуация | Правило |
|---|---|
| «Человек — разумное животное» | Ложь: человек — человек (jandar), не janwar |
| Следовать парадхарме | Недопустимо, даже если она легче и «постелена розами» |
| Дхарма человека | Бхагават-дхарма: Vistára (расширение) → Rasa (поток) → Sevá (служение) → Tadsthiti (установление) |
| Служение | Односторонне: «дать и не взять», пожертвовал — забудь; 100% предложение себя |
| Есть мясо без клыков | Нарушение естественной дхармы; источник болезней |

## Среда и добродетель

| Ситуация | Правило |
|---|---|
| Выбор компании | Суджана ведёт вверх, дурджана — вниз (относительно!); суди по эффекту на себя |
| Дурное общество | Оставь (mudrá-sádhaná); хорошее общество → освобождение |
| Что такое добродетель | Пу́н́ья: благо индивиду И обществу (накормить голодного — да; ритуалы — нет) |
| Оставить след | Работа, дающая впечатление на земле (Вивекананда) |
| Спасение | Борьба и в социальной/экономической сфере; вечное — только духовное |

## Быстрые сигналы («tells»)

- «Я делал ради пользы» / ждёт признания в газете — картртвабхимана, не служение (Ch 1, 2).
- «Сделаю сам, никто не поможет» — игнорирование кооперации; колодец не выкопать одному (Ch 8).
- Учёный бездельник — Рохит-синдром: знание без действия деградирует (Ch 6).
- Пожертвовал — и ждёт «взаимности» — это сделка, не служение (Ch 7).
- «Служу из страха» — бесплодно: страх не рождает любовь (Ch 2).
- Ритуал вместо пользы — пу́н́ья требует реального блага (Ch 9).
