# Chapter 3: "Kurvanneveha Karmmáńi"

*Дискурс 5 October 1979 morning, Calcutta.*

## Core Idea

Человек пришёл работать: тело — машина, ум — тоже; работу нужно вести с контролем и самодисциплиной. После смерти ничего сделать нельзя — поэтому добрые и благородные дела нужно совершать при жизни. Живи сто лет для благой работы, не для еды.

## Frameworks Introduced

- **Тело — машина (yantra)**: yantra = «то, что контролирует»; контроль достигается работой. Поэтому работа обязательна — но «с контролем и самодисциплиной»; думать — тоже действие.
- **Iha и Páratra**: тело привязано к миру → iha («этот мир»); без тела — páratra; атман существует во всех слоях. Aehik (мирской) / páratrik (потусторонний).
- **Действие только при жизни**: после смерти ум (в виде семени-самскары) привязан к атману, но не действует; бестелесные души ничего не могут. Поэтому «делай благородное, пока жив».
- **Даже боги спускаются на землю для практики**: без физического существования действие невозможно; пока жив, не простаивай ни секунды («Árám hárám hyáy» — праздность вредна).
- **Бестелесный ум и «духи»**: мозг умершего сожжён/распался → ум не функционирует; «призраков» нет. Однако мощный человек может использовать часть своего эктоплазма (cittáńu/mánasadhátu), чтобы активировать бестелесный ум согласно его самскарам — тогда кидаются кости/кирпичи, качаются кровати. Реальный «виновник» — этот живой практик (Avidyá Tantra), а не мёртвый; найдёшь и «встряхнёшь» его — феномен прекратится.
- **Направление ума определяется телом**: тело занято благородным → ум в благородных мыслях (вор в уединении думает о воровстве). Физическое действие формирует мысли.
- **Сушумна против ида/пингала**: «прямой путь (rju) лучше кривого» — путь сушумны; божественная поэма 1200-летней давности (Сараха): «вправо и влево — пропасти; иди прямо». Интуиция (bodhi) близка — не ищи за морями; «на запястье браслеты — не нужен зеркало»; «сам анализируй свой ум».
- **«Право на действие»-развёртка**: Курванневеха кармма́н́и джи́дживишеччхатам́ сама́х — «делая здесь дела, стремись жить сто лет». Сто лет — для благой работы (шлока отвергает мнение, что древние жили по сто лет; обычная жизнь была короткой и полной борьбы; 100 лет — пожелание «Shatáyurbhava»).
- **Мотив еды**: «ешь сколько получишь — нет дела выше еды» (спутник); ответ автора: «едим, взвесив и проверив, — жизнь не для еды»; «как двигателю нужно топливо, человеку нужна пища для работы, а не работа для еды».
- **Публичное благо снимает оковы**: действия для общественного блага не создают оков; «тот, кто делает ради плодов, — как купец; я не делаю ради плодов — предаю всё Ишваре»; благие дела без желания плодов не требуют перерождения.

## Key Concepts

- **Kurvan / kurvat** — «делающий» (корень kr + shatr).
- **Iha / páratra / aehik / páratrik** — мирское/потустороннее.
- **Cittáńu (mánasadhátu)** — эктоплазматическая частица ума.
- **Avidyá Tantra** — практика злоупотребления эктоплазмом (кидание кирпичей и т.п.).
- **Suśumná / id́á / piuṋgalá** — центральный/левый/правый канал.
- **«Caraeveti»** — контекст движения (вводится лейтмотив).

## Mental Models

- «Тело — машина, управляемая самодисциплиной; работа — способ управления».
- «Двигателю нужно топливо: пища — для работы, а не работа для еды».
- «Прямой путь (сушумна) безопаснее извилистого: иди прямо, интуиция рядом».

## Anti-patterns

- Праздность («Árám hárám hyáy»).
- Вера в призраков/бестелесных духов — феномены объясняются эктоплазмом живых практиков.
- Жить «ради еды» вместо работы.
- Бояться следовать «прямому пути».

## Worked Example

*Браслет на запястье.* Чтобы увидеть браслеты на руке, зеркало не нужно — «на запястье браслеты, не нужен зеркало»; так и свой ум можно анализировать самому, без чужой помощи. А ум в хорошей компании ведёт к Иште, в дурной — к падению: «па́ра гаджара» (всё кажется реальным чувствам, но ум по природе свободен; не принимай кривой путь, оставив прямой).

## Key Takeaways

1. Тело — машина; работа с самодисциплиной обязательна при жизни.
2. После смерти действие невозможно — совершай благородное сейчас.
3. Призраков нет; «чудеса» объясняются эктоплазмом живых людей.
4. Пища — топливо для работы, не цель жизни.
5. Прямой путь (сушумна) безопаснее кривого.
6. Действия для общественного блага без желания плодов не создают оков.
