# Читшит — правила решений по Саркару (Shabda Cayanika 1)

## Этимология слов

| Ситуация | Правило |
|---|---|
| Понять истинное значение слова | Разбери на корень + префикс + суффикс; сформулируй этимологию, сверь с употреблением |
| Этимология и употребление расходятся | Дай оба значения; духовный слой — третий (acyuta, aja, iti) |
| «Все знают» значение, контекст сомнителен | Проверь по корню; ищи apaváda и звуковые сдвиги |
| Слово «неправильное» | Проверь, не законное ли это исключение (apaváda), а не ошибка |

## Различения терминов

| Ситуация | Правило |
|---|---|
| Желание vs действие | icchá (внутри) → eśańá (желание + усилие формы) |
| Понял без слов vs двусмысленно | iuṋgita (жест/поза) ≠ ábhása (сумеречный язык) ≠ hábebháve (манеры) |
| Не есть vs есть плохое vs пост | anashana (невозможность) / anáhára (мусорное) / upavása (пребывание с Богом) |
| История | itikathá (хроника) ≠ itihása (воспитательная «сияющая», dharma-artha-káma-mokśa) |
| Поведение vs характер | ácarańa (часть жизни) → ácára (вся жизнь) → caritra (проявленный характер) |
| «Конец» | iti = «пусть продолжается как было»; ávetti = пауза; не «конец» |

## Слои ума и сознание

| Ситуация | Правило |
|---|---|
| Анализ психики | Три слоя: cetana (мало, вне границ) / avacetana (частично) / acetana (огромный, внутри) |
| Творчество/обучение | Обогащай сознательное сокровищами подсознательного и бессознательного |
| Мотивация | Спрашивай: конечное (sukha) или бесконечное (ánanda) удовольствие ищет человек? |
| Внезапная новость/удар | Сообщай трудное постепенно — резкий психический удар вызывает соматические расстройства |
| Состояние сна | Не верь оценке «высшего» изнутри состояния; глубокий сон — переживание отсутствия |

## История и культура

| Ситуация | Правило |
|---|---|
| Объяснить феномен через слово | Начни с этимологии: áuṋgára → уголь, ekká → транспорт, acára → португальцы |
| Оценить «свободу» | Три измерения: физическая, ментальная, духовная; смена эксплуататора ≠ свобода |
| Исторический факт автора | Сверяй с первоисточниками — биология/даты требуют калибровки (⚠) |
| Бенгальские слова | Цепочка: санскрит → пра́крита → бенгальский (Mágadhii — мать бенгальского) |

## Быстрые сигналы («tells»)

- Видишь «этимологическое значение» и «разговорное» рядом — это стиль Саркара: оба важны.
- Слово на I в этом томе — проверь раздел «различения» (I-семья слов — самая точная).
- Португальские/персидские корни в бенгальском — след культурного обмена (~450 лет назад).
- «Низшие» (itara) — не презрение; у Саркара это «публика».
- Дух-рассказчик в тексте — сигнал историко-этического нарратива, а не документа.
