# Читшит — правила решений по Саркару (A Few Problems Solved Part 2)

## Социальная динамика

| Ситуация | Правило |
|---|---|
| Анализ перелома | Триада: тезис слабеет → антитезис (может поднять интеллектуальное меньшинство) → синтез; синтез станет тезисом завтра |
| Классовый цикл | Колесо шудра→кшатрия→випра→ваешья не остановится; убери эксплуатацию, а не колесо |
| Кто должен вести | Садвипры (мораль + настройка с временем-местом-личностью + универсализм) |
| Оценить идеологию | Признаёт ли время-место-личность? Диалектический материализм — нет; PROUT — да |

## Демократия

| Ситуация | Правило |
|---|---|
| Демократия работает? | Только при образовании + морали (51% ⚠) + сознании; иначе «правление дураков» |
| Право и управление | Каждый пользуется ресурсами мира, но не каждый управляет администрацией |
| Минимум благ | Гарантировать всем и расти; корректировать по времени-месту-личности |

## Единство человечества

| Ситуация | Правило |
|---|---|
| Расовая спесь | Различия = климат (меланин), не иерархия; «чистой крови» нет |
| Различия (еда/одежда/язык/религия) | Не снимай силой — сближай естественно; поощряй единство, обескураживай разобщение |
| Язык | Все языки равны; подавление всегда провально (Будда/пали, Кабир, валлийский) |
| Религия vs dharma | Религия = страхи и ритуалы; dharma = рациональный путь к Истине; слепая вера снимается логикой, не силой |
| Вечный союз | Общая проблема объединяет до её решения; духовный сентимент — навсегда |

## Аграрная экономика

| Ситуация | Правило |
|---|---|
| Раздать землю бедным | Нет: дробит землю, плодит petit bourgeoisie; повышай продуктивность наделов |
| «Земля тем, кто пашет» | Несостоятелен (ведёт к рантье); нужен экономический надел (вход < выход) |
| Коллективизация | 4 фазы + мораль/надзор/принятие масс; насилие (СССР) разрушительно |
| Посредники | Убрать; 50% работникам, 50% владельцам; долю работников не снижать |
| Менеджмент кооператива | Только пайщики, выборные, оплачиваемые (не почётные) |
| Занятость | Сначала местные, потом приезжие; учитывать местные сентименты |
| Налоги с фермеров | Процентом натуры (в древней Индии 25% ⚠), не кэшем |

## Ценности и этика

| Ситуация | Правило |
|---|---|
| Порок/добродетель | Блокирует движение к вершине — порок; облегчает — добродетель; эксплуатация — порок |
| Наказание | 4 ступени: слова → строгие слова → предупреждение → гуманное наказание; только виновный |
| Клеймо навсегда | Запрещено: не трать жизнь на один проступок |
| Писание vs человек | Человек выше писания; писание служит прогрессу |
| Социальная vs человеческая ценность | Человеческая — фундамент; социальная без неё — ложь |

## Быстрые сигналы («tells»)

- Критик науки летает самолётами и носит фабричную ткань — лицемерие («Ганг к истоку»).
- Кандидат опирается на касту/коммуну, а не компетентность — демократия больна.
- Один роскошествует, другой голодает — «дружба невозможна, ум покупается деньгами».
- «Святое писание» выше человека — антипаттерн (храм из кирпичей дороже жизни).
- Обещают раздать землю бедным — будут плодить рантье и провоцировать захваты.
- Почти всё «своё» и «чужое» в религии — слепая вера, а не логика.
