# Chapter 4: June 6 — Free Will, Occult Powers, Seva

*Свобода воли, опасность оккультных сил, виды социальной службы.*

## Core Idea

У человека свобода только в действии, не в результатах (закон кармы). Оккультные силы — «мильные камни», использовать их нельзя, даже «во благо». Служба — половина духовной жизни, четырёх видов.

## Frameworks Introduced

- **Свобода воли = контроль действия**: «мы ответственны за действия, не за результаты». Реакции идут по закону природы, менять их нельзя. Цитаты Гита: `na kartrtwam na karmani… svabhavastu pravartate` — «всё по закону природы: действие-реакция»; `karmanyeva dhikaraste ma phalesu kadacana` — «власть только над действием». «Инструментами» мы становимся по своей неосторожности.
- **Оккультные силы (сиддхи)**: легко достижимы (месмеризм — за 6–12 месяцев ⚠ к калибровке), ценны мало. Поднимая кундалини по чакрам, садхака получает контроль над элементами (муладхара — материализация, свадхиштхана — вода, манипура — огонь, вишуддха/аджна — все пять факторов). Использование силы = начало падения: «застрянешь на миле-камне и не дойдёшь до Патны».
- **Полномочия (authority)**: применять сверхспособности для помощи людям могут только имеющие на то полномочия (гуру, Будда, Рамакришна); обычному садхаке — нельзя, это «вмешательство в закон», искажает график реакций (головную боль одну ночь превращает в десять). Закон: `avasya evam bhuktavyam` — «неотработанное остаётся в запасе».
- **Служба (сева) — четыре вида** (по делению классов): випрочит (знание/интеллект — учить), кшатриячит (защита/физическая помощь), ваешьячит (экономическая помощь — еда, одежда), шудрочит (чистая физическая работа). Выбирай по месту, времени и нужде человека (голодному — еда, не проповедь).
- **Рутина и шесть недостатков**: фрейм повседневной жизни садхаки (вставать 4:30, Гуру Шакаш, садхана, служба). Шесть помех: нидра (пересып), тандра (дремота), бхайя (страх перед делом), кродх (гнев), аласья (лень), диргхасутра (прокрастинация).

## Key Concepts

- **Samskara / reaction in potentiality** — реакции, ждущие выражения.
- **Treatak** — концентрация на точке для слабых месмерических способностей.
- **Microvita** — тончайшие сущности; Будда остановил холеру, воздействуя на их нуклеус (пример из книги).
- **Viprocit / ksattriyacit / vaeshyacit / shudrocit** — четыре типа севы.
- **Пратика** — эмблема-напоминание об идеологии (у Дада — вместо камней/колец).

## Mental Models

- «Оккультная сила — как застрять в Хаджипуре по пути в Патну: милый город, но цель не достигнута».
- «Реакции — как рана: обезболивание отодвигает боль, но не лечит; срок страдания удлиняется».
- «Служба — по погоде и почве: голодному дай хлеб, мигренознику — таблетку, потом философию».
- «Полномочия — как у магистрата: отец уважаем, но применять служебную власть может только назначенный».

## Anti-patterns

- **Желать/использовать сиддхи** — прямой путь вниз, даже «во имя добра».
- **«Мы — марионетки Бога»** — снятие ответственности; инструментом делаешь себя сам.
- **Психическое целительство обычным садхаком** — продлевает страдания вместо их исчерпания.
- **Лень/прокрастинация/гнев** — шесть помех рутины.

## Worked Example

*Пример Будды (рассказ Бабы).* В Вайшали эпидемия холеры; врачи бессильны. Будда мысленным давлением остановил поток негативных микро-вит из их нуклеуса. Вывод: это допустимо только для имеющих полномочия великих; обычный садхака действует человеческими усилиями.

## Key Takeaways

1. Свобода — только в действии; реакцию не изменить.
2. Сиддхи достижимы легко, ценны мало; использование — падение.
3. Сверхспособности применять могут только имеющие полномочия (гуру/великие).
4. Служба бывает четырёх видов; выбор — по времени, месту, нужде человека.
5. Рутина + борьба с шестью помехами — база продуктивной жизни.
