# Cheatsheet

Правила решений и быстрые справки из «When the Time Comes».

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| «Нет времени на садхану» | Минимум 1,5 ч × 2 в день; короткие сеансы по 15 мин ИП+Дхьяна. Ложь «нет времени». |
| Хочется сократить сон | Сначала медитация: только практик высыпается за 4–5 ч; иначе — по совету врача. |
| Забываешь мантру | Возврат к ней при воспоминании; знай смысл мантры (держится Иста). |
| Достиг самадхи | Продолжай практиковать самадхи ежедневно (2×); сохраняй асаны/пранаяму — иначе откат. |
| Появились сиддхи / желание их | Не желай, не используй, не хвастайся; «миле-камни» — мимо. Применение только по полномочиям гуру. |
| Думаешь «я не прогрессирую» | Сравнивай годы назад, помни о пульсации; «Чараивети» — иди, иди. |
| Помощь «энергетикой» кому-то | Нельзя без полномочий: искажает график реакций (головная боль на 1 ночь → на 10). |
| Выбор монах/семьянин | Равны в садхане; санньяса — для полной службы, без возврата, с готовностью к унижениям. |
| Семья vs служение | Семья — прямая ответственность (сначала), служение — непрямая (потом). |
| Страх, гнев, лень, прокрастинация | Шесть помех рутины; борись (нидра, тандра, бхайя, кродх, аласья, диргхасутра). |
| Ребёнок не хочет садхану | Говори о садхане регулярно, води на программы, воспитывай примером, не страхом. |
| «Всё по воле Бога» | Только при 100% сдаче; иначе — ответственность за действия. |
| Еда и кундалини | Саттвичная еда готовит нервы; вегетарианство обязательно для садханы. |
| Смерть близкого/своя | Реакции исчерпываются практикой; самадхи — «самонаказание», освобождающее от долгов. |
| Вопрос «как получить грейс гуру» | Заслуживается садханой + севой, не выпрашиванием. |
| Оккультный «лекарь» (оджа) | Низший полу-транс; без контроля — бесполезен; культивируемая связь сознательного — благо для служения. |

## Ключевые санскритские фразы

| Фраза | Смысл |
|---|---|
| `atma moksartham jagat hitayaca` | «Садхана для спасения себя, добро для блага мира» — мотто жизни. |
| `muktyakanksaya sadguru praptih` | «Из стремления к освобождению приходит садгуру». |
| `karmanyeva dhikaraste ma phalesu kadacana` | «Власть над действием, не над результатом». |
| `avasya evam bhuktavyam` | «Неотработанное остаётся в запасе» (реакции не исчезают). |
| `abhyasesu kanteya` | «Через практику» (Гита; ответ на забывчивость мантры). |
| `sah bhavati daridra yasya asha vishala` | «Беден тот, у кого велики желания». |
| `charaiveti, charaiveti` | «Иди, иди» — продолжай усилие. |
| `na kartrtwam na karmani…` | «Ничего не делает и не заставляет — всё по закону природы» (действие-реакция). |

## Критерии (для быстрой проверки)

- **Садвипра?** — действия (служба, мораль), не учёность; добр ко всем созданиям.
- **Прогресс?** — рост позыва к садхане и службе; изменение за годы, пульсация нормальна.
- **Коша сейчас?** — кама-мая (чувства) → мано-мая (обычная жизнь) → атиманаса (искусство/философия) → виджина-мая (только садхана/служба) → хирана-мая (отстранённость) → нирвикальпа. Не опускайся ниже мано-маи.
- **Мукти или мокша?** — мукти: возврат с гарантией человека; мокша: окончательное слияние (ум исчезает).
