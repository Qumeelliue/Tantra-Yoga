# Глоссарий — Subháśita Saḿgraha Part 9

**Álambana (а́ламбана)** — Supreme Desideratum: единственный объект идеации, не атакованный относительными факторами (время/пространство/индивидуальность); Parama Puruśa (ch02).

**Apara Brahma** — Supreme под метаморфозой в идеи/объекты; поклонение ему = aparábhakti, цель — вещи/власть, ведёт к деградации (ch03).

**Aśt́a pásha (ашта-паша)** — восемь fetters: ghrná (ненависть), shaunká (опасение), bhaya (страх), lajjá (комплекс стыдливости), jugupsá (подавление/скрытие), kula (гордость родом), shiila (тщеславие культурой), mána (тщеславие) (ch06).

**Avatára** — проявление Parama Puruśa в физическом объекте (ch01).

**Bhaktas / jiṋániis / karmiis** — преданные / люди знания / люди действия; у знания дефекты лень+тщеславие, у действия — тщеславие, у преданности — ни один (ch05).

**Bhaerava / shambhú / svayambhú** — стадии творения: primordial point (shambhú) → быстрая трансформация без анализа (bhaerava) → nadir crudity (svayambhú) (ch02).

**Brahmasadbháva** — идеация на Brahma; высшая практика (выше dhyána, japa, идолопоклонства) (ch04).

**Deva / Mahádeva** — индивидуальные вибрации (Deva, в пределах чувств) и их источник (Mahádeva = Parama Puruśa) (ch04, ch06).

**Fetters (pásha)** — оковы: физические, психические, духовные; списки — aśt́a pásha, шесть ripus, 50 vrttis (ch06).

**Guńátmá** — внутреннее отражение Parama Puruśa на уме (ch02).

**Iishvarakot́i / jiivakot́i** — ступени проявления божественности: развитая / неразвитая; подъём возможен практикой (ch01).

**Karma-sannyása** — слияние unit-интеллекта с Supreme Intellect; высшая точка действия; достигается через parábhakti (ch03).

**Kriid́á / liilá** — игра с видимой причиной (kriid́á) / с невидимой (liilá); творение для нас — liilá (ch06).

**Mahásambhúti** — особая структура спасения коллектива, вне jiivakot́i/Iishvarakot́i; Шива и Кршна; = Táraka Brahma (ch01).

**Nirguńa Brahma** — непроявленное Supreme; не действует, grace не даёт; идеация на Него невозможна (ch03, ch05).

**Paiṋcánana** — «Пятиликий» Шива; лица: Dakśińeshvara, Iishána, Vámadeva, Kálágni, Kalyáńasundaram (ch01).

**Para Brahma** — незатронутое Supreme; любовь к нему = parábhakti (ch03).

**Parábhakti** — высшая преданность (к Para Brahma); условие karma-sannyása (ch03).

**Pashu** — существо, ведомое немногими врождёнными импульсами; «человек-животное» (ch02, ch03).

**Prańipáta** — полное доверие и оставление всего Богу («Он мудрее меня»); осуществляется парабхакти (ch03).

**Prańásha** — разрушение с возвратом к первоисточнику (мука→пури→мука) (ch01).

**Pabulum (пиабал)** — физический/психический объект идеации; конечные пиабалы исчерпываются или утомляют (ch02).

**Śad́aripu** — шесть врагов ума: káma, krodha, lobha, moha, mada, mátsarya (ch06).

**Sambhúti** — «правильное развитие»: оригинальное творение Parama Puruśa (ch01).

**Shiva = Citi Shakti** — Когнитивная Сила; свобода = освобождение от Operative Principle (Prakrti) (ch06).

**Svayambhú** — самосозданный; также nadir crudity (ch02, ch06).

**Suxmá / suxmátisúxma** — тонкое (ум мыслит, органы нет) / тончайшее (за пределами ума) (ch06).

**Táraka Brahma** — Освободитель; Mahásambhúti; даёт grace (ch01, ch05).

**Upavása** — «сидеть рядом» (upa+vása) с Supreme, а не голодание (ch05).

**Vinásha** — трансформация без возврата (мальчик 5 → мужчина 25) (ch01).

**Vishva** — квинквелементальная вселенная; Parama Puruśa как свидетель = Vishva (ch06).
