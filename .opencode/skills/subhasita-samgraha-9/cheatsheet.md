# Читшит — Subháśita Saḿgraha Part 9

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Выбираешь высшую цель | Дезидератум = только то, что вне времени/пространства/личности (ch02) |
| «Знающий» не растёт | Ищи лень + тщеславие; добавляй действие и бхакти (ch05) |
| Хочешь понять «кризис коллектива» | Отдельные сущности не решат → нужна особая структура (Mahásambhúti) (ch01) |
| Классифицируешь изменение | sambhúti (творение) / vinásha (трансформация без возврата) / pranásha (возврат) (ch01) |
| Выбираешь форму практики | Идеация на Brahma > dhyána > japa > идолы; ритуал без идеации низок (ch04) |
| Видишь «покаяние-исповедь» | Неупсихологично: Богу известны грехи; подход «я дитя Бога» (ср. ch04, SS10 ch05) |
| Достигаешь поста/власти | Опасно: aparábhakti ведёт к деградации; цель — Para Brahma (ch03) |
| Чувствуешь незначительность | «Белый муравей равен мамонту» — никто не незначителен (ch06) |
| Оцениваешь «служение» человека | Бхакта служит без тщеславия; знание и действие несут свои дефекты (ch05) |
| Споришь о сути Бога | Трата времени: ум не может познать Supreme; путь — любовь и идеация (ch04) |

## Мини-справочник «иерархия практик» (ch04)

| Практика | Место | Замечание |
|---|---|---|
| Идеация на Brahma (brahmasadbháva) | высшая | требует satya + tapas + преданности |
| dhyána / dhárańá | вторая | медитация/концентрация |
| japa / stuti | ниже | повторение/похвала — малая польза |
| идолопоклонство | худшая | «королевство во сне»; ритуалы, пост, penance — не освобождают |
