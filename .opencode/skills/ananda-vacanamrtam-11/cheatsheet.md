# Читшит — правила решений (Ánanda Vacanámrtam 11)

## Боги и идеи

| Ситуация | Правило |
|---|---|
| Что такое тантрическое божество | Материализованная абстрактная (неинтегральная) идея |
| Можно ли поклоняться божеству | Идея — не объект поклонения; поклонение одной идее исключает остальные |
| Древние ли пуранические обряды | Нет: ≤1200–1300 лет; большинство божеств — 500–600 лет |
| Durgá-поклонение | Молодо (Pathan-период, Kamsanarayana); не встречается у Valmiiki и Tulasii Das |
| Происхождение nyása/práńáyáma | Тантрическое (Yudhiśt́hira Vidyá), не пураническое |

## Медитация

| Ситуация | Правило |
|---|---|
| Выбор объекта идеации | «Кем я стану?» — «как думаешь, так и становишься» |
| Медитация на божестве с ва́ханой | Опасно: включает медитацию на животном (сова, мышь) |
| Медитация на Га́не́ше | Leader-worship: «хобот и толстый живот» |
| Лучшая практика | Идеация на Брахма; идолопоклонство — «худшее из худших» |
| Цель практики | Только Parama Puruśa; конечная идея не даёт Макрокосмоса |

## Иконография Kálii (кодирование)

| Атрибут | Значение |
|---|---|
| Чёрный цвет | До творения цвета не было |
| Без одежд | Всепроникающее нельзя одеть |
| Стоит на Шиве | До проявления Сознание «мёртво» |
| Три глаза | Свидетель прошлого/настоящего/будущего |
| Ожерелье из 49 голов | 50 звуков a…kśa (aksamálá) |
| Меч + abhaya/vara | Борьба со злом; «не бойся, Я снова создам» |

## Быстрые сигналы

- «Древняя традиция» без первоисточника → вероятно молода; проверь редакции.
- Дорогой культ только для богатых → ищи коллективную форму (Bároiyárii → Sárvajaniin).
- Медитация на конкретном растении/животном → «становишься им»; часть не равна целому.
- Культ лидера (dalapati) — скрытая форма Га́не́ша-поклонения.
