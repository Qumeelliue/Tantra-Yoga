# Глоссарий — Subháśita Saḿgraha Part 2

*Термины по алфавиту.*

**Akśara** — неизменная часть Брахмы; знающая изменяемое (ch05).
**Anujiṋá / Anujiṋátá / Avikalpa Yoga** — три из четырёх ассоциаций Turiiya с Причинным Телом (ch05).
**Apárájiṋána** — относительное знание, подчинённое времени/месту/личности (ch02).
**Asambhúti** — страх/возможность разрушения; с Санбхути — две крайности (ch01).
**Ávarańii-подход** — (см. SS3 ch1) «покрывающая» сила неведения.
**Bharga** — белое сияние Брахмы (Гайятри: Bha-Ra-Ga) — неотделимо от Него (ch03).
**Bhiiśańam** — устрашающий аспект Puruśottama для отделившихся унит-существ (ch05).
**Brahmabhávaná** — интуитивная наука/идеация Брахмы; высшая стадия религии (ch01).
**Brahmavijiṋána** — «интуитивная наука» цикла Вед (все главы).
**Causal Body / Причинное Тело** — исходное состояние расширения (центробежного начала Saiṋcara) (ch05).
**Daehik / Brahmik Devatá** — физические / космические боги (33+33), управляющие органами и вселенной (ch02).
**Dvá suparńa** — «две птицы»: джива (ест плод) и Параматма (свидетель) (ch02, ch03).
**Garbhodaka** — «флюид творения»; макросостояние сна (ch04, ch05).
**Guhácara** — «обитатель сердца»; контролёр сердца (guha = сердце, не пещера) (ch02).
**Hirańyagarbha** — субъектив Тонкого Космического Ума; макросубъект сна; также имя Сагун́а-Брахмы (ch04, ch05).
**Iishvaragrása** — «космическая финальность»: в Turiiya даже Ишвара растворяется (ch04, ch05).
**Iishvara** — субъектив Грубого Космического Ума; «Господь» (ch04, ch05).
**Kárańárnava** — «море причин»; макросостояние глубокого сна (ch04, ch05).
**Kśara** — изменяемая часть Брахмы (ch05).
**Kśiirabdhi** — «море молока»; макросостояние бодрствования; Нараяна и Лакшми (ch04, ch05).
**Maháviśńu / Nrsiḿha / Ugra / Viira / Jvalantam / Sarvatomukham / Bhadram / Mrtyurmrtyum** — атрибуты Puruśottama из Nrsiḿha-мантры (ch05).
**Ota Yoga / Prota Yoga** — проникающее / коллективное свидетельствование Turiiya (ch05).
**Oṋḿkára (Prańava)** — четырёхсложный мантра (A-U-M + sonic dot); звук для слушания (ch04, ch05).
**Paiṋcavyuhátmaka** — «пятиядерное» поклонение (Puruśottama + подъядра) (ch05).
**Pańd́a / Pańd́ita** — «Я есть Брахма» / тот, кто этим владеет (не эрудит) (ch04).
**Parájiṋána** — духовное знание, независимое (ch02).
**Prájiṋa** — субъектив грубого унит-ума (глубокий сон); духовно спящая джива (ch04, ch05; SS3 ch1).
**Pratyabhijiṋá** — «сознание идентичности» — узнавание через сравнение (ch04).
**Puruśottama** — Космическое Ядро; владыка kśara/akśara (ch05).
**Rta / Samyak / Tathya** — «истина» (обычная) / «корректное» / «факт» — НЕ равны Satya (ch02).
**Sambhúti** — поклонение созданию (крайность учёных) (ch01).
**Satya** — неизменная истина, вне времени/места/формы (ch02).
**Sonic dot (Нада-бинду)** — четвёртая часть Oṋḿkára; символ Turiiya/Nirguńa (ch04, ch05).
**Sútreshvara** — субъектив Грубого Космического Ума (нить, связывающая всех) (ch04, ch05).
**Taejasa** — субъектив тонкого унит-ума (сон) (ch04, ch05).
**Turiiya / Kaevalya** — четвёртое состояние; единственная абсолютная истина (ch04, ch05).
**Vidyá / Avidyá** — интровертирующая / экстровертирующая силы; нужен баланс (ch01).
**Virát́a / Vaeshvánara** — субъектив Causal Cosmic Mind; макросубъект бодрствования (ch04, ch05).
**Vishva** — субъектив унит-ума в бодрствовании (ch04, ch05).
**Шестнадцать кал** — 10 органов + 5 пра́н + эго (ch02, ch03).
**Восемь паш** — ненависть, сомнение, страх, стыд, порицание, привязанность, тщеславие культуры, ложный престиж (ch04).
