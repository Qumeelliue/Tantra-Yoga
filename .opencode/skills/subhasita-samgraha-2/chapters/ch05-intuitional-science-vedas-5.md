# Chapter 5: The Intuitional Science of the Vedas – 5

*Дискурс от Аграха́ян́и Пу́рн́има́ 1956, DMC.*

## Core Idea

Вселенная — космическая система с Puruśottama в центре; центробежная (Avidyá) и центростремительная (Vidyá) силы в равновесии — это Prakrti. Путь к ядру — путь Sattva. Oṋḿkára — звук этой системы; Turiiya — её финальность.

## Frameworks Introduced

- **Космическая система**: солнце — ядро солнечной системы, земля — ядра земной, атом — ядро атомной; аналогично вселенная вращается вокруг Akśara-Puruśa как ядра. **Prakrti = равновесие центробежных/центростремительных сил**; Avidyá — центробежная (tamah), Vidyá — центростремительная (sattva). Слияние с ядром — «путь освобождения» (индивидуальность исчезает, как земля, упавшая в солнце).
- **Puruśottama = ядро**: владыка kśara/akśara; ни Сагун́а-ни-Ниргуна в чистом виде — «трансцендентный контролёр гун» (guńádhiisha). Сагун́а Брахма = Puruśottama + Его психический объект (вселенная).
- **Метры**: Гайятри (3×8 = 24 буквы) описывает Сагун́а Брахму; Ануштупа (8×8) — Puruśottama. Oṋḿkára больше Ануштупы: он — вся система, Ануштупа — только ядро.
- **Nrsiḿha-мантра как описание Puruśottama**: Ugra (милость в творении/сохранении/разрушении), Viira (храбрость перед проблемами), Maháviśńu (безграничное расширение), Jvalantam (первосияние), Sarvatomukham (всевидение — 10 направлений), Nrsiḿha (nr=человек/сознание, siḿha=Shreśt́ha — «Высший человек», НЕ получеловек-полулев), Bhiiśańam (устрашение для чувствующих унит-себя, любовь для знающих единство), Bhadram (воллощение благополучия), Mrtyurmrtyum («смерть смерти» — смерть умирает для Него).
- **Четыре ассоциации Turiiya с Causal Body**: **Ota Yoga** (проникающее свидетельствование), **Anujiṋátá Yoga** (космотеистическая позиция, пред-Turiiya), **Anujiṋá Yoga** (когнитивная медитация к бесконечности), **Avikalpa Yoga** (абсолютная идентичность — Nirvikalpa).
- **Три состояния + Turiiya (макрокосм)**: 
  - Бодрствование: коллектив — **Virát́a** (субъектив Causal Cosmic Mind), индивид — **Vishva**.
  - Сон: коллектив — **Hirańyagarbha** (субъектив Subtle Cosmic Mind), индивид — **Taejasa**.
  - Глубокий сон: коллектив — **Sútreshvara** (субъектив Crude Cosmic Mind), индивид — **Prájiṋa**.
  - Turiiya — без коллектива/индивидуальности; **Iishvaragrása** — даже Ишвара растворяется.
- **Oṋḿkára-модель**: A/бодрствование/Virát́a/Kśiirabdhi; U/сон/Taejasa+Hirańyagarbha/Garbhodaka; Ma/глубокий сон/Prájiṋa+Iishvara/Kárańárnava; sonic dot — Turiiya, «Iishvaragrása» — состояние, где не существует семени (нет начала).
- **Три состояния — относительные истины**; Turiiya — единственная абсолютная истина («fourth state is the only Truth»).

## Key Concepts

- **Сон как предсказатель**: в последней фазе сна (перед пробуждением) подсознательный ум активен, сознательный — спит; такие сны «сбываются».
- **Naciketa-сюжет** (подготовка к SS3): Yama учит Начикету.
- **Самадхи недолги**: неотработанные санскары возвращают из самадхи; Mukti — «постоянный Savikalpa», Mokśa — «постоянный Nirvikalpa».
- **Четыре состояния души**: каждая джива = бодрствование+сон+глубокий сон+сущностное Я; первые три — искажения четвёртого.

## Mental Models

- «Вселенная — маховик: спицы-существа вращаются вокруг ядра-Пурушоттамы; слияние со ступицей — покой».
- «Oṋḿkára — партитура вселенной: три ноты (A-U-M) и тишина (dot)».
- «Turiiya — фокус линзы: всё остальное — рассеянный свет».

## Anti-patterns

- **Понимать Nrsiḿha буквально** (получеловек-полулев) — «нелепая выдумка пуран»; Nrsiḿha = Puruśashreśt́ha.
- **Считать Oṋḿkára мантрой для произнесения** — это звук для слушания.
- **Бояться Брахмы** — устрашение (Bhiiśańam) касается только отделившихся унит-существ; для знающих единство — любовь.
- **Растворение вселенной** — космическая Читта конечна, но mind-stuff бесконечен (см. SS1 ch11).

## Worked Example

*Солнце-система как образ са́дханы.* Планеты не приближаются и не удаляются от солнца — центробежные и центростремительные силы в равновесии (это и есть Prakrti). Если равновесие сломано — планета падает в солнце (центростремительная сила: слияние, освобождение) или уносится вдаль (центробежная: забвение). Путь са́дхаки — «упасть» в ядро через sattva/центростремительную Vidyá.

## Key Takeaways

1. Prakrti = равновесие центробежного (Avidyá) и центростремительного (Vidyá) — космическая модель.
2. Puruśottama — ядро; Nrsiḿha — не миф, а «Высший Человек».
3. Oṋḿkára (A-U-M-dot) — звук всей системы; dot = Turiiya.
4. Turiiya — единственная абсолютная истина; первые три состояния — относительные.
5. Самадхи временны, пока есть санскары; Mukti/Mokśa — «постоянные» формы.
