# Чит-лист — Subháśita Saḿgraha Part 2

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Действие связывает/давит | Аскрипция: объект = проявление Брахмы, используй как Его дар |
| Спор «только духовность» vs «только мир» | Баланс Vidyá/Avidyá; крайности обе ведут во тьму |
| Разбираешь «факты» и «истину» | Факт=Tathya, корректность=Samyak, обычная=Rta, неизменное=Satya |
| Анализ сна/состояния сознания | Определи состояние: бодрств./сон/глуб. сон (макросубъект Virát́a/Hirańyagarbha/Iishvara); Turiiya — эталон |
| Нужно сообщить сильную новость | Подавай ступенями; резкий шок разрушает ум |
| Оценка «духовности» | Триединство: знание + преданность + действие; одно — мусор |
| «Куда человек движется» | Смотри на доминирующее желание — оно формирует следующее состояние |
| Миф/мантра читается буквально | Переведи в функции ядра (Nrsiḿha=Высший, не гибрид) |
| Желаешь выйти из цикла | Насыщенность: уничтожь желания — выйдешь из круга рождений |
| Что такое Oṋḿkára | Звук для слушания (не произнесения); A-U-M-dot = творение/сохранение/разрушение/Turiiya |
| Верить в призраков/духов | Нет: это телепатическое видение из бессознательного ума |

## Быстрая справка

- **Субъекты трёх состояний**: Бодрств. — коллектив Virát́a / индивид Vishva (Kśiirabdhi); Сон — Hirańyagarbha / Taejasa (Garbhodaka); Глуб. сон — Iishvara/Sútreshvara / Prájiṋa (Kárańárnava).
- **Три стадии са́дханы**: высшая = знание+преданность+действие; средняя = два; низшая = «только болтовня».
- **Восемь паш**: ненависть, сомнение, страх, стыд, порицание, привязанность, тщеславие культуры, ложный престиж.
- **Шестнадцать кал**: 10 органов + 5 пра́н (Práńa/Apána/Samána/Udána/Vyána) + эго.
- **Пять внешних ваю** (не в 16): Nága, Kúrma, Krkara, Devadatta, Dhanaiṋjaya.
- **Oṋḿkára**: A (sattva, бодрств., Kśiirabdhi) → U (rajah, сон, Garbhodaka) → Ma (tamah, глуб. сон, Kárańárnava) → dot (Turiiya/Nirguńa, Iishvaragrása).
- **Ключевые мантры-якоря**: «Satyameva jayate» (Satya побеждает); «Brahmavid Brahmaeva bhavati» (знающий Брахму становится Брахмой); «Mahad krpáyaeva bhagavad krpáleshádvá» (милость через преданность).
