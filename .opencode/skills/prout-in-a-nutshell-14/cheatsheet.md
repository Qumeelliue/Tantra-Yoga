# Читшит — правила решений по Саркару (Prout 14)

## Личность и мышление

| Ситуация | Правило |
|---|---|
| Оценить человека | Гений рождён, техник сделан практикой |
| Нет уверенности в себе | Твёрдая решимость «я добьюсь» + связь с Parama Puruśa |
| Критик/пародия вместо творчества | Отрицательная стадия: твори, не компенсируй критикой |
| Деление людей (расы/нации/секты) | Анализ делит → иди путём синтеза (единая цель) |
| «Это факт» / «это реальность» | Восприятие дуально → не абсолют; ищи не-пульсирующее (духовность) |
| Как спасти цивилизацию | Баланс всех сфер жизни (dharma) + знание цели |

## Политика

| Ситуация | Правило |
|---|---|
| Кому давать голос | Образованным и политически сознательным, не по возрасту |
| Партия заискивает перед криминалом | Правительство воров; «мажоритарий» может править при меньшинстве голосов |
| Проверить демократию | Независимы ли секретариат, суд, аудит от кабинета (4 компартмента) |
| «Республика» без свободы слова | Group-governed state: «пудра на угле» |
| Решение проблем демократии | Реформа ветвей + совет Sadvipra (через рациональное применение PROUT, не силой) |
| Разница стилей у лидеров | Стиль ≠ вражда; оценивай как беспристрастный судья |

## Экономика

| Ситуация | Правило |
|---|---|
| Выбрать систему производства | Кооператив > частное > испольщина > коммуна (худшая) |
| Почему коммуна провалилась | Нет личной собственности и стимулов |
| Издольщик держит больше земли | Скрытый капитализм/феодальство; земля под кооператив |
| Фермер продаёт урожай впопыхах | Distress sale: кооператив авансирует и продаёт в лучший момент |
| Устройство кооператива | Доли по земле+труду, наследуемы не передаются, резервный фонд, совет из моралистов, только местные |
| Сельское хозяйство | = промышленность: полная калькуляция + 10–15% прибыли в цене |
| Оценить богатство | Реальная ценность = покупательная способность |
| Минимальные потребности | Растут со временем; гарантия еды, одежды, жилья, образования, медицины |
| Как орошать | Колодцы — временно (30–45 лет → пустыня); реки, водохранилища |
| Товары essential | Защищай от спекуляции потребительскими кооперативами |

## Быстрые сигналы («tells»)

- Выборы «по возрасту» без проверки сознательности — демократия с первым изъяном.
- Судьи и аудиторы дают удобные партии приговоры — ветви не независимы.
- Система «без личной собственности» — коммуна: жди спада и голода.
- Одинаковые химические реакции дают разные результаты — ⚠ версия автора: разница микровит.
