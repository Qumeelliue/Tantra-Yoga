# Chapter 5: The Early Disciples

*1947–1953: цепь тайных инициаций среди железнодорожников и BMP; первый публично признанный ученик.*

## Core Idea
Как «скептик» и «козёл отпущения» становятся первыми учениками: каждый следующий вербуется через предыдущего, при строгой секретности личности гуру — и распространяется за пределы Джамалпура.

## Key Events & People
- **Пранай Кумар Чаттерджи** (2.06.1947): скептик; прикосновение к руке — «лёгкий электрический разряд»; «судьба — пропасть» → дхияна-мантра Шивы; отказ практиковать → «верни мантру»; уединённые прогулки; тапок в трикути — «молния в глазах», волна блаженства → «я сдаюсь». Инициация у тигриной могилы; яма-нияма; гурмантра; сон на могиле с головой на коленях гуру. Первый публично признанный ученик (тайна остальных сохранялась).
- **Харапрасад Хайдар**: судьба — короткая жизнь; через месяц на тигриной могиле; tantra pitha трёх пальм (Нат-йогин Prabhirnath); снятие священного шнура после касания лба; эйфория длилась недели (комнататы думали — одержимость).
- **Садхан Дей** (с ножом) «проучить» Прабхата → сам инициируется.
- **Шива Шанкар Банерджи** (полицейский, 1951): «исцеление лёгких» через пранаяму, диету, растение в молоке; условие — стать учеником. Переносит учение в Sahebganj.
- **Чандранатх Кумар** (сержант-майор BMP): святой из Gaddopur сказал «получишь, когда придёт время»; у дверей — «настало ли время?»; инициация; наставление «через поступки ученика узнают гуру».
- **Нагина Прасад Синха** (Central Excise): видение гуру; «не-вегетарианец»; «пей горячую воду» вместо лекарств → исцеление; приносит коллег.
- **Механика распространения**: цепочка «приведи искренне желающего → передай имя гуру с разрешения → адрес и время». Секретность: не знать других учеников; увидев гуру с другим — повернуть обратно.

## Frameworks & Teachings
- **Гейт секретности**: дисциплина анонимности — условие свободы работы гуру.
- **Инициация = преображение**: телесный опыт (разряд, блаженство) подтверждает «истину, которую не видно».
- **Яма-нияма до всего**: «духовные правила — не для леса, а для современной жизни»; многократные образы с поднятым пальцем «вы должны их соблюдать».
- **Конец тайны — начало организации**: по мере роста число «секретных» учеников делает тайну нежизнеспособной.

## Worked Example
Механика вербовки через передачу: Шива Шанкар → Чандранатх (Dumka) → Нагина (Бхагалпур) → Центральная акцизная → тысячи. Прабхат позже шутил: «Мой любимый способ распространения — переводить учеников по службе» (каждый перевод сеет учение в новом месте).

## Key Takeaways
1. Вербовка идёт по «цепочке доверия»: знакомый приводит знакомого; имя гуру — с разрешения.
2. Скептик обращается через опыт, а не аргументы (разряд, тапок, блаженство).
3. Яма-нияма — обязательный минимум и «входной фильтр» качества.
4. Секретность поддерживает анонимность, но уступает место организации по мере роста.
