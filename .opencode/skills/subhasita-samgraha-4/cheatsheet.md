# Читшит — правила решений (Subháśita Saḿgraha Part 4)

## Психология и поведение

| Ситуация | Правило |
|---|---|
| Человек ведёт себя иррационально («как животное») | Проверь: возница-совесть не держит вожжи-ум; лошади-органы бегут за объектами |
| Нужно сдерживать влечение | Сдерживание = разумное использование, НЕ подавление; укрепи управляемую силу |
| Выбор ограничения | Не «убивай» ресурс — иначе колесница встанет (метафора лошадей) |
| Практиковать пра́н̃а́йа́му | Только с космической идеацией (Brahmabháva); без неё — разрушительно |
| Понять, утолит ли цель | Если объект меняется от времени/места/личности — он adhruva, насыщения не даст |
| Культивировать чувство вины/«я грешен» | НЕ культивировать: «как думаешь — таким становишься»; сожги прошлое |

## Восприятие и познание

| Ситуация | Правило |
|---|---|
| Ступени осознания объекта | anubhúti (чувство) → upalabdhi (осознание) → labdhi (почти слияние) |
| Постичь Брахму | Нужен agryábuddhi (заострённый интеллект), а не книги и лекции |
| Оценить «опыт»/«транс» | Познание ≠ чувство; «бхава-самадхи» без морали = vikśipta, срыв |
| Приём информации | Происходит в паузе пульсации; беспокойство убивает ретенцию |
| Знание vs наука | Знание = отождествление с характеристикой объекта; наука = практическое знание |

## Карта восхождения

| Ситуация | Правило |
|---|---|
| Где я сейчас | Определи кошу (ка́мамайя/маномайя/атиманаса/виджнянамайя/хиранмайя) и её чакру |
| Двигаться вверх | Очищай слой за слоем; не прыгай через ступени |
| Полный контроль | Пратьяхара: йатамана → вйатирека → экендрия → вашикара (только при yama/niyama) |
| Йога без морали | Опасно; «тот же контроль благотворен для всех, но опасен без нравственности» |

## Онтология (первопричина)

| Ситуация | Правило |
|---|---|
| Время как причина | Нет — время это измерение мотивности, не творец |
| Природа как причина | Нет — природа поток гун, закон, а не создающая сила |
| Судьба/случай | Судьба зависит от доерства; случай = скрытая причина (закон причинности) |
| Элементы/дживатман | Не авторы (нет самоопределения; дживатман не контролёр) |
| Настоящая причина | Брахма = Пуруша + Пракрити; ядро — Пурушоттама |
| Цель восхождения | Кевалйа: знающий, знание и познаваемое сливаются |

## Быстрые сигналы («tells»)

- Человек объясняет поступки «это моя природа/случай» → вероятно, экстроверсия без buddhi (Ch 1, 2).
- «Я грешник, спаси меня» вместо действий → комплекс неполноценности, тупик (Ch 1).
- Восторженная набожность без самодисциплины → вероятно vikśipta, потом срыв (Ch 3).
- «Покажи мне Бога» → не насмешка, а вопрос о способе познания (аналогия с эфиром) (Ch 2).
- Свадебные «духи», «порча» → страх + подсознание, не одержимость (Ch 1).
- Спор «что больше — форма или форма» → смотри на сущность (золото), не на формы (Ch 4).
