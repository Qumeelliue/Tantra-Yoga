# Читшит — правила решений (Namámi Krśńasundaram)

## Два аспекта Кришны

| Ситуация | Правило |
|---|---|
| Индивидуальный духовный путь | Vraja Krśńa: сладость, флейта, мадхура-бхава, ota |
| Коллективный путь/борьба со злом | Па́ртхасаратхи: карма-йога, прота, дхармараджья |
| Какой опыт | Vraja → aparokśa (непосредственный); Па́ртхасаратхи → parokśa (косвенный) |
| Кто «выше» | Вопрос неважен: обе роли равны по необходимости |

## Шесть ступеней реализации

| Ступень | Признак |
|---|---|
| Салокья | Родился в одно время с Господом |
| Самиипья | Близость, личный разговор |
| Сайуджья | Почти телесный контакт |
| Сару́пья | Видишь Его во всём (любовь — сладко; вражда — мучительно) |
| Сарштхи | «Я и Ты, есть связь» (тонкий дуализм) |
| Каевалья | «Только Ты существуешь» |

## Прапатти

| Стадия | Суть |
|---|---|
| Viprapatti | Собственные усилия, джняна (короткий звук) |
| Aprapatti | «Всё делает Он, ты — инструмент» (нейтрально) |
| Prapatti | «Да будет воля Твоя» (протяжный звук pluta) |
| Финал | Сарвадхарман-шлока: одна цель — прибежище в Нём |

## Философские школы против Кришны

| Школа | Дефект |
|---|---|
| Самкхья | Пассивный Janya Iishvara, много пуруш, нет бхакти |
| Вишуддха Адвайта (Майавада) | Мир = иллюзия; самопротиворечива; ведёт к бездействию |
| Вишишта-адвайта (Махавишну) | Мир реален, но «искры» могут погаснуть |
| Двайта | Дуализм не выживает: слияние неизбежно (железо к солнцу) |
| Двайтадвайта | Не объясняет происхождение джив |
| Итог | Адваетадветадваетавада: единство → двойственность → единство |

## Ота/прота

| Ситуация | Правило |
|---|---|
| Индивидуальная забота | Ota: с каждым, без вреда коллективу |
| Коллективная забота | Prota: «страна сыта — каждый сыт»; приоритет при конфликте |

## Восемь аешварий

| Сила | Смысл |
|---|---|
| Анима | Стать малым (в уме каждой сущности) |
| Махима | Стать великим (весь мир в Нём) |
| Лагхима | Стать лёгким (как ребёнок) |
| Прапти | Знать истинные нужды, давать |
| Иишитва | Контроль |
| Вашитва | Удержание контроля (ум-лошади) |
| Пракамья | Мысли → действия (Чинтамани) |
| Антарьямитва | Знать внутреннее (ум и тело) |

## Бхакти-решения

| Ситуация | Правило |
|---|---|
| Определить бхакти | Благоговение перед величием + взаимное притяжение |
| Какой бхава | Ватсалья (родитель), мадхура (любовник, ~99%), сакхья (друг), дасья (слуга) |
| Сакхья созрела | Переходит в дасью или мадхуру |
| Мысль о мелочи | Сразу направь к Нему («как мыслишь, так становишься») |
| «Я грешник» | Дефектно: ведёт к эго; скажи «Я люблю Тебя» |
| Судить Сущность | Невозможно умом: путь — самоотдача |

## Эстетика

| Ситуация | Правило |
|---|---|
| Счастье | Анукула-ведания (конгениальные волны большой длины) |
| Страдание | Пратикула-ведания (короткие волны) |
| Нандана-виджняна | Волны: давать и получать ананду |
| Мохана-виджняна | Полное выпрямление волн: непреодолимое притяжение Сущности |
| Пять танматр | Запах (аромат), вкус (сладость), форма, прикосновение (мягкость), звук (он̭мкара) |

## Быстрые сигналы («tells»)

- Видишь «право на труд без права на результат» — эксплуататорское извращение шлоки.
- Школа не объясняет происхождение — неполна («из ничего ничего»).
- Философия ведёт к бездействию — отклоняй (Pi-pu-phi-shu).
- «Не хочу стать сахаром, хочу есть» — дуализм, обречённый на слияние.
- Слышишь «Я грешник, что будет» — направь к любви, не к эго.
- Лидер без прота-йоги заботится об индивиде за счёт коллектива — риск.
