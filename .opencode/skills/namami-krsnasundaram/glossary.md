# Глоссарий — Namámi Krśńasundaram

**Абхиишта (Abhiiśt́a)** — всепроникающий Ишта/цель (противопоставлен иште дживы) (Ch 17).

**Адваетадваета́дваетава́да** — «недуалистический дуалистический недуализм»; финальная позиция книги (Ch 22).

**Аешварьи (aeshvaryas)** — восемь оккультных сил Ишвары: анима, махима, лагхима, прапти, иишитва, вашитва, пракамья, антарьямитва (Ch 23, 24).

**Ани́ма́** — способность стать малым (скрытым в уме каждой сущности) (Ch 23).

**Антарьямитва** — знание внутреннего (ума и тела) (Ch 23).

**Апарокша́ анубху́ти** — непосредственный духовный опыт (путь Враджи) (Ch 2, 3).

**Ара́дхана́** — тотальное ментальное поглощение в Кришне; отсюда «Радха» (Ch 3, 7).

**Атман** — душа, сознание; в колеснице — седок (Ch 8).

**Бандху/сухрд/митрам/сакха́** — четыре уровня дружбы по силе любви; Арджуна = сакха (Ch 3, 9).

**Бхага (bhaga)** — шесть качеств Бхагавана: аешварьи, виирйа, йаша, шрии, джняна, ваерагья (Ch 24).

**Бхагава́н (bhagaván)** — обладатель bhaga; великий с шестью качествами; Кришна — не просто бхагаван (Ch 24).

**Бхава (bháva)** — отношение/ментальный поток преданности: ватсалья, мадхура, сакхья, дасья (Ch 3, 7).

**Бхакти** — благоговение при виде величия + взаимное притяжение дживы и Господа (Ch 21, 23).

**Вашитва** — удержание контроля (над умом-лошадями) (Ch 23).

**Виера́гья** — отрешённость: свобода от «цвета» объектов (не бегство в Гималаи) (Ch 24).

**Випрапатти** — «анти-прапатти»: опора на собственные усилия (короткий звук) (Ch 4, 5, 6).

**Виша́ла / вира́т́а** — огромное, но измеримое / неизмеримое (Ch 5).

**Вишуддха Адваетава́да** — чистый недуализм (включая Майаваду); критикуется (Ch 10–14).

**Вишишт́а́дваетава́да** — качественный недуализм (мир реален, Пуруша — ядро) (Ch 15–16).

**Вра́джа (vraja)** — дух радостного движения; vraja parikramá — радостное паломничество (Ch 21, 18).

**Vraja Krśн́а** — «лорд преданности»: сладость, флейта, мадхура-бхава (Ch 1–3).

**Гопа́ла** — «тот, кто контролирует фон выражений» (go-pála), не пастух (Ch 21).

**Дваетава́да** — дуализм: «я и мой Господь» (Ch 17–18).

**Дваета́дваетава́да** — дуалистический недуализм (начало — два, конец — одно) (Ch 19–20).

**Дхармара́джйа** — правило морализма; опирается на дхарму (Ch 9).

**Иишитва** — контроль (Ch 23).

**Каевалья** — шестая ступень: «только Ты существуешь» (Ch 3).

**Кииртана** — коллективное пение имени Господа (Ch 20).

**Лагхима́** — способность стать лёгким (Ch 23).

**Мадхура бха́ва** — романтическая сладость преданности (путь Радхи) (Ch 3, 7).

**Ма́йава́да** — доктрина иллюзии: мир = mithya; критикуется (Ch 10–14).

**Маха́вишн́ува́да** — в Вишишта-адвайте: Махавишну — ядро; дживы-«искры» (Ch 15).

**Мохана виджня́на** — супра-эстетика: непреодолимое притяжение Сущности (Ch 27).

**Нандана виджня́на** — эстетика: давать и получать ананду (Ch 25, 26).

**Ота/прота йога** — индивидуальная / коллективная ассоциация Парама Пуруши с творением (Ch 9, 26).

**Па́ин̭чаджа́нйа** — конх Кришны; символ финальной реализации (Ch 3).

**Папа / пратьявайа** — делать недолжное / не делать должное (Ch 18).

**Па́ртхасаратхи** — «колесничий Арджуны»; царь, лорд карма-йоги (Ch 1–3).

**Пра́пти** — способность получать / знать истинные нужды (Ch 23).

**Прапатти** — полная самоотдача: «я — инструмент, да будет воля Твоя» (Ch 4–6).

**Прака́мья** — материализация желаемого (мысли → действия) (Ch 23).

**Радха-бха́ва** — состояние: точка дживы, устремлённая к Нуклеусу (Ch 3, 7, 17).

**Рагануга́ / рага́тмика́ бхакти** — любовь, радующая обоих / любовь только ради Его радости (Ch 25).

**Са́локйа** — первая ступень: одно время с Господом (Ch 3).

**Самиипйа** — вторая ступень: близость/дружеский разговор (Ch 3).

**Сарштхи** — пятая ступень: «Я и Ты, есть связь» (тонкий дуализм) (Ch 3).

**Са́ру́пйа** — четвёртая ступень: видеть Его во всех направлениях (Ch 3).

**Сайуджйа** — третья ступень: почти телесный контакт (Ch 3).

**Са́м́кхйа** — школа Капилы: 24 принципа, много пуруш, пассивный Janya Iishvara (Ch 7–9).

**Са́ра́ти** — «тот, кто лелеет колесницу как дитя»; буддхи-колесничий (Ch 1, 8).

**Сарвадхарман-шлока** — «оставь все дхармы, возьми прибежище во Мне» (Ch 6, 18, 24).

**Танма́тра** — инференциальная волна (звук, прикосновение, форма, вкус, запах) (Ch 3, 25, 27).

**Та́рака Брахма** — Освобождающая Сущность; приходит в переходные эпохи (Ch 3, 7, 8).

**Упадхи / падави** — особое качество / обычное звание (Ch 14).

**Юга-сандхи** — переходная точка между эпохами (Ch 16).

**Cháрвака-материализм** — дехатмавада: «ешь-пей-веселись»; душкриты (Ch 16).
