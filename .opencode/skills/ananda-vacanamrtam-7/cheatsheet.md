# Чит-шит — Ánanda Vacanámrtam Part 7

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Куда направить привязанность | К Parama Puruśa = bhakti; к мирскому = ásakti; к физич./псих. = káma |
| Проверить честность | Три «я» (думать/говорить/делать) должны совпадать |
| Отказать нечестному человеку | Прямо: «Я не поддержу тебя», не откладывая |
| «Ничего не моё» | Правильная установка: только Parama Puruśa — моё (mamatá) |
| Видишь всех равными | Всё — выражение Viśńu: дискриминация исчезает |
| Забываешь себя в радости | Savikalpa samádhi; потеря идентичности — nirvikalpa samádhi |
| Отчаяние в глубине падения | Даже в rasátala Он с тобой; не отчаивайся |
| Вера в «Satan» | Нет второго бога; Satan = сила заблуждения (avidyá) |
| Океан прошлых грехов | Только корабль Parama Puruśa переплывает; в одиночку — акулы |
| Страх «привидений» | Проверь шагом: чаще всего куст/газ; страх беспочвенен |
| Комплекс превосходства | Эго = разрыхлённый рис; смирись ниже травы |
| Как обращаться с преступником | Хвали хорошие качества; не клейми грешником |
| Кто виноват в чужих правах | Урезающий права — против провиденциального закона |
| Выбрать путь жизни | Семья (две семьи) или санньяса (одна большая); vow в срок |
| Заработок | Только чистый, без вреда (samyak ájiiva) |
| Память | Guru mantra перед действием; забыл — повтори после; цель dhruva smrti |
| Непроизнесённая мысль | Viśńu слышит внутренний монолог — думай «веди мои мысли» |
| Немой/слабый | С милостью Parama Puruśa — заговорит и поднимется; идеируй, не проси |
| Сила без еды | Внутренняя психическая сила (от духа) несокрушима |
| Проблемы общества | В Kali Yuga — организованным телом, не в одиночку |
| Статичное общество | Yugasandhi → приход Mahásambhúti → поляризация → победа добра |
| Прогресс | Истинный — духовный; karma/jiñána — лишь опора bhakti |
| Кииртана/собрание | В Hariparimańd́ala среда сладка; бхакт не сплетничает |
| Пост | Контроль еды даёт свободу; не завись от пищи |
| Беспомощность | Никто не беспомощен; используй данную силу, потом проси |
| Идеология | Прими рано, делай универсальной |

## Восемь samyak-принципов (Buddha в изложении Саркара)

1. Darshana — правильная идеология (рано, универсальная)
2. Saḿkalpa — правильная решимость (путь + vow)
3. Vák — правильная «речь» (контроль 10 органов умом)
4. Ájiiva — правильный заработок (чистый)
5. Vyáyam — правильное упражнение (тело+ум+дух; 16 пунктов)
6. Karmánta — правильное завершение (не бросай)
7. Smrti — правильная память (guru mantra → dhruva smrti)
8. Samádhi — правильное погружение (любовь стирает всё лишнее)

## Признаки Ishvaraprema

1. Samyauṋmasrnito svánto — чистый ум, слова=мысли, без лицемерия
2. Mamatá — «только Parama Puruśa — моё»
3. Bháva — всё — выражение Parama Puruśa (cittamásrńya)

## Четыре юги

Satya (душа) → Tretá (ум) → Dvápara (тело) → Kali (еда/материя) → новый Satya (через реализацию идеологии)

## Кольцо Alarka (наставления матери)

1. Отрекись от всякого общества; если не можешь — только хорошее общество
2. Отрекись от всех желаний; если не можешь — только желание спасения
