# Читшит — A Few Problems Solved Part 8

## Планирование и экономика

| Ситуация | Правило |
|---|---|
| Децентрализованное планирование | Блок → район → штат → нация → глобально; блок базовый |
| 4 фактора планирования | Себестоимость + продуктивность + покупательная способность + коллективная необходимость |
| Транскраничная проблема (паводки, связь, энергия) | Inter-block кооперация; свой план — intra-block |
| Сроки планов | Краткосрочный ≤6 мес., долгосрочный ≤3 года (⚠) |
| Оценить экономический стандарт | Покупательная способность, НЕ per capita income |
| Блоки по каким границам | Научным (география, нужды, стремления), не политическим |

## Pramá и равновесие

| Ситуация | Правило |
|---|---|
| Диагностировать деградацию | derangement → disruption → degeneration |
| Восстанавливать баланс | Снизу вверх: сначала физический слой, потом психический/духовный |
| Балансировать слой | Дели на субтреугольники (агрономия, промышленность, торговля…) |
| Три уровня pramá | saḿvrddhi (физика) / rddhi (психика) / siddhi (дух) |
| Факторы физического слоя | Спрос+предложение (настоящее/будущее), максимальное использование земли, 5 принципов PROUT |

## Микровитум (⚠ спекулятивно)

| Ситуация | Правило |
|---|---|
| Позитивный vs негативный | Позитивный: из лунного плексуса в обе стороны; негативный: только вниз от физико-психического |
| Желание к грубости/эгоизму | Негативный микровитум |
| Желание к универсализму/космосу | Позитивный микровитум |
| Защита от «негативных» | Медитация/садхана; равновесие ума |
| Достичь вершины | Садхана + милость великого (микровитум не работает там) |
| Одинаковые формулы дают разные результаты | Разница в количестве/деноминации микровитума |

## Империализм и психология

| Ситуация | Правило |
|---|---|
| Формы эксплуатации | Один корень — психика: капитализм, лингвализм, кастизм, шовинизм |
| Лечить империализм | Нео-этика: верховное желание (Макрокосмическое Сущее) + смесь карбонического/некарбонического pabulum |
| Строить общество | Синтез (общая связь), не анализ (раздувание различий) |
| Служение или группа | Service psychology (мораль+коллектив) vs group psychology (raj без niiti) |
| Источник силы | Духовная сила, не ствол ружья |

## Конституция

| Ситуация | Правило |
|---|---|
| Лучшая форма правления | Президентская, прямое избрание, меньше индивидуальной свободы |
| Смена конституции | Только 7/8 парламента |

## Канализация желаний

| Ситуация | Правило |
|---|---|
| Капитализм | «Голодный мотив прибыли»; нарушение aparigraha = старт эксплуатации |
| Коммунизм | Тройной захват + подавление = doldrums → хаос |
| Работать с желаниями | Не подавлять и не разжигать — канализировать к одной цели |
| Итог канализации | Человек → Sadvipra; общество → Sadvipra Samáj |

## Быстрые сигналы

- Per capita income растёт, а люди беднеют — обманчивая мера; смотри на покупательную способность.
- План сверху вниз без блоков — экономика слепа к местному.
- Слой в упадке — восстановление начинается с физики, не с лозунгов.
- Язык/культуру навязывают — психологический дефект конституции («B class» граждане).
- «Разделяй и властвуй» внутри сообщества — анализ, анти-паттерн.
- Препарат одной компании эффективнее — (по автору) разница в микровитумах (⚠).
- Один кодекс для всех — кардинальные ценности, не групповая привилегия.
