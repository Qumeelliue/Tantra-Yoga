# Читшит — справка (In the Land of Hat́t́amálá Part 2)

|---|---|---|

## Сюжет одной строкой

Запрет леса → Апарна входит → тигр (дерзость) → духи → королевство демонов → баклажан высушил землю → Апарна в тюрьме → Анумай идёт (Шаккунни, кобра, тигр, духи, истории) → волшебные инструменты → баклажан срублен, озеро, вода → освобождение узников → прощение короля → дети демонов уходят → возвращение на ракете.

## Правила-решения (из сказки)

| Ситуация | Правило |
|---|---|
| Хочешь войти в опасную зону | Оцени последствия ДО (фонарик, план), а не «потеряю лицо» |
| Враг-хвастун | Смелость + уверенный тон отпугивает; не показывай страх |
| «Больной» просит помощи | Проверь: настоящая болезнь или хворост под кроватью |
| Слух о «знаменитости» | Спроси источник и биографию — факты, а не «мне сказали» |
| Чудо высасывает ресурс | Руби/останавливай; восстанавливай ресурс для всех |
| Помощник предлагает помощь | Проверь чистоту намерений (дающие с любовью не дают вредное) |
| Предатель кается | Прощай без ненависти, но проверь изменение поведения |
| Среда притесняет слабых | Выбирай доброе общество («земля для людей, не для демонов») |
| Старший брат/наставник | Уважение (ápni/tumi) — выбор, а не угождение |

## Быстрые факты ⚠ (гиперболы сказки — не факты)

- Баклажан: +5 футов за ночь, потом 10–20 в день, «до неба, корнями до преисподней».
- Анумай: «чутни из тысячи львов — как глоток»; король спрятался в рисовом мешке.
- Шуйо: «костяная болезнь» = хворост; тигр съедает её одним прыжком.
- Гандхарба Сингх — «самый любимый лидер страны», на деле осёл прачки.

## Моральные якоря

- «Я не умею ненавидеть. Я никогда не учился ненавидеть» (Анумай).
- «Думай о Parama Puruśa всё время» (Шаккунни).
- «Земля создана для людей, а не для демонов».
- «Надо было подумать об этом до того, как отправиться» (Апарна).
