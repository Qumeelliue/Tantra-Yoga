# Читшит — правила решений (Bábá's Grace)

## Преданность (бхакти)

| Ситуация | Правило |
|---|---|
| Мотив практики — «уничтожь врага» | Статическая бхакти — не бхакти |
| Мотив — «дай денег/славу» | Мутативная — не бхакти (просьба игрушек) |
| Мотив — «дай мокшу/покой» | Сентиентная — лучше, но ещё не слияние |
| Мотив — «люблю ради наслаждения любовью» | Рагаануга — не-атрибутивная, но не высшая |
| Мотив — «люблю, чтобы доставить Ему радость» | Рагатмика — единственная, ведёт к слиянию |
| «Что я получу?» | Это гауни-бхакти, не кевала |

## Выбор цели и эшаны

| Ситуация | Правило |
|---|---|
| Много желаний | Разделяй: эшана — одна, к Parama Puruśa; иначе гонка без результата |
| «Хочу Его и излечения астмы» | Двойная цель не сработает — Он слышит скрытое |
| Просишь у Бога что-то | Проси только parábhakti |
| Спор о правильном пути | Следуй практику (махаджане), не теоретику |

## Действие и карма

| Ситуация | Правило |
|---|---|
| Совершаешь служение | Служи с идеацией «объект — На́ра́йан́а»; плоды — Ему |
| Гордость «я сделал» | Отдай плоды; «я» не доер → не получатель последствий |
| Действие без любви | Показуха, бесплодно; любовь обязательна |
| Хорошие дела | Золотые цепи — их плоды тоже отдай Ему |
| Страх наказания | Не работает: сентимент из страха не рождает любовь |

## Мир и его объекты

| Ситуация | Правило |
|---|---|
| Хочешь жить в миру без самоскар | Мадхувидья: каждый объект с космической идеацией |
| Объект «красит» ум (влёк) | Пратьяхара: отдай Его цвету Ему, не краси одежду |
| Влечение к конечному / бесконечному | Конечное — ашакти; бесконечное — бхакти |
| Хочешь сбежать в Гималаи | Не беги: мир — проявление Брахмы; бегство — психическая болезнь |
| Реакции действий | Помни «проценты» випаки: время/место/личность меняются → долг растёт |

## Ум и знание

| Ситуация | Правило |
|---|---|
| Мирское знание меняется | Это «путаница знания» (физ.-психическое), не джинана |
| Память «Он свидетельствует меня» | Дхрувасмрити — духовное знание |
| Медитируешь «я грешник» | Станешь грешником; медитируй «я — дитя Великого Отца» |
| Гордость степенью/учёностью | «Первоклассный дурак»; знание — бумага под едой, выбрось |

## Оккультные силы и самадхи

| Ситуация | Правило |
|---|---|
| Получил оккультную силу | Скажи «не хочу игрушку, хочу Создателя игрушки» |
| Хочешь силу | Иди наружу; хочешь Его — иди внутрь |
| Оценить прогресс в садхане | Стадии: салокья→самийпья→сайюджья→сарупья→сарштхи→нирвикальпа |
| Думаешь, что самадхи — самоубийство | Нет: расширение души, самопреодоление |

## Быстрые сигналы («tells»)

- Слышишь «О, Лорд, уничтожь врага» → статическая бхакти, не ведись на «духовность».
- Слышишь «могу ли просить и излечение?» → двойная эшана, не сработает.
- Видишь «сверхъестественные» силы → обычная, но редкая способность (золото среди металлов).
- Видишь «власть развращает» (Гаясура, абсолютная власть) → предупреди: преданность — единственный противовес.
- Видишь ритуал с гхи ради дождя → суеверие; используй Бхута-яджну (науку).
- Видишь «учёный спорит о частностях» → «путаница знания» (спор о пальмовом плоде).
