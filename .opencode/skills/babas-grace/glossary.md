# Глоссарий (Bábá's Grace)

**Ácárya** — духовный учитель; «тот, кто учит поведением и характером».
**Adharma** — движение к несовершенству; «не-дхарма», не природа человека.
**Ánanda** — Верховное Блаженство.
**Ananda Marga** — Путь Блаженства; «Ánanda Márga alone is Dharma» (тезис дискурса 34).
**Aśakti** — привязанность к конечному миру (противопоставлена бхакти).
**Ásana** — йогическая поза; совершенствует Аннамайя-кошу.
**Avidyá** — сила, ведущая к грубости/деградации.
**Bala** — духовная сила, действующая в дживе; измеряется использованием.
**Balván** — полный духовной силы.
**Bhajan / kiirtana** — слушание имени в одиночку / пение имени (двойное наслаждение).
**Bhakti** — преданность; влечение к Верховному (paránurakti); любовь к Богу.
**Bharga** — белая радиантность Брахмы («Bha»=освещает, «Ra»=даёт счастье, «Ga»=вбирает).
**Bhava / Bháva** — состояние очищенной читты, доминирование саттвы; океан бхавы.
**Bháva-ságara** — «зазор» между саттвичным пределом и Ниракара Брахмой, проходимый только преданностью.
**Bhuta yajiṋa** — жертва-служение созданным существам (полив, уход за скотом, наука).
**Brahma** — Бог, Космическое Сознание.
**Brahmánda** — «яйцо Брахмы», конечная вселенная.
**Brahmacakra** — цикл Брахмы (тонкое→грубое и обратно).
**Cakras** — семь энергетических центров вдоль позвоночника.
**Citta** — результат «я», ментальная пластина, где отражаются танматры.
**Dagdhabiija** — «сожжённое семя»; преданный без личных боли/радости, готовый нести бремя других.
**Dharma** — природа/долг/движение к совершенству.
**Dhruvasmrti** — постоянная память «Он свидетельствует меня»; духовное знание.
**Eśańa** — стремление; правильная эшана — единственная, к Parama Puruśa.
**Gopa / Gopála** — «радующий Parama Puruśa»; контролёр индрий; не пастух.
**Guhá** — пещера ИЛИ «я существую» (тончайший ум); суть дхармы.
**Guńas** — три связывающие силы: Sattva (белый/сентиентный), Rajah (красный/мутативный), Tamah (чёрный/статичный).
**Iishvara** — контролёр; «не затронут kleśa, karma, vipáka, áshaya».
**Jiṋána** — духовное знание; субъективация внешней объективности.
**Kaola / Mahákaola** — достигшие совершенства / великие, способные оживлять мантры (purashcarańa).
**Karma / Yajiṋa** — действие/жертва-действие.
**Kevalá bhakti / Mukhyá bhakti** — не-атрибутивная высшая бхакти.
**Kulakuńd́alinii** — «свёрнутая змея», спящая духовная энергия в муладхаре.
**Liilá** — Божественная игра, вне причинности (vs kriidá — каузальное действие).
**Madhuvidyá** — «мёд-знание»: брать объект с космической идеацией.
**Mantra** — «коллекция звуков, медитация на которые ведёт к освобождению».
**Mantra caetanya / mantra siddhi** — оживление мантры / достижение через неё.
**Máyá** — операционная сила Пракрти (Вишну-йога-вишва-ану-махамайя).
**Máyádhiisha** — господин Ма́yá.
**Mokśa** — слияние ума с Ниргуна-Брахмой.
**Mukti** — слияние ума с Сагуна-Брахмой.
**Nirguńa Brahma** — непроявленное Космическое Сознание.
**Nirvikalpa samádhi / kaevalya** — финальное слияние («только»).
**Niiti** — «то, что ведёт к kśema»; ведение к благополучию.
**Nityánitya viveka** — различение вечного/временного.
**Oṋḿkára / Prańava** — первый звук; звук-Брахма; мост Ниргуна/Сагуна; для слушания.
**Parama Puruśa** — Космическое Сознание, Бог.
**Paramarasa / viśayarasa** — космический/единичный поток ментальной субстанции.
**Práńa** — жизненная энергия.
**Pratyáhára Yoga / Varńárghyadána** — отвод ума от цвета-привязанности, подношение цветов.
**Prema** — божественная любовь.
**Preya / shreya** — немедленное/высшее благо.
**Rága / anurága** — цвет/привязанность; окрашивание ума.
**Rágánugá / rágátmiká bhakti** — две фазы не-атрибутивной бхакти.
**Rudra** — «заставляющий плакать»; пять лиц-функций, центральное — благодать.
**Sádhaka** — духовный практик.
**Sádhaná** — духовная практика/медитация («усилие», «завершение»).
**Saguńa Brahma** — проявленное Космическое Сознание.
**Sálokya / Sámiipya / Sáyujya / Sárúpya / Sárśt́hi** — стадии близости к Богу.
**Samádhi** — единение с Богом; состояние блаженства.
**Saḿskára** — потенциальная реакция действия.
**Sat / Satya** — Истина; благое использование слов/ума для блага других.
**Sravańa / manana / nididhyásana** — слушание / размышление / отдача ума.
**Shabda** — звук; первая татматра.
**Shambhúliuṋga / Svayambhúliuṋga** — верхняя/нижняя точки творения.
**Shraddhá** — вера+стремление к summum bonum.
**Tanmátra** — тонкая вибрационная сущность (звук/касание/форма/вкус/запах).
**Tapah** — самоотверженное служение (часть садханы).
**Vaedhii bhakti** — ритуальная бхакти по шастрам.
**Vipaka** — реакция действия с «процентами» (время/место/личность меняются).
**Yajiṋa** — жертва; любое действие (4 вида).
