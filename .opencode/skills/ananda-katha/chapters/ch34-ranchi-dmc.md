# Chapter 34: Ananda Purnima DMC in Ranchi 1958

*12 мая 1958. Lalita Marmika kiirtan; полная сдача уничтожает недостойные желания.*

## Core Idea

В Ranchi проходит первый Ananda Purnima DMC (12 мая 1958). По просьбе преданных Бáба вводит танец — **Lalita Marmika kiirtan** (нежный духовный танец-киртан). Ученики в экстазе; один ачарья «становится Анандамурти» (Baba bhava). Позже — урок: письмо Бáбе, извещающее о желании мяса, уничтожает желание («полная сдача — с момента отправки письма желание исчезло»).

## Frameworks Introduced

- **Lalita Marmika kiirtan**: нежный танец-песнь, введённый Бáбой на Ananda Purnima DMC 1958; объединяет песню, музыку и танец в духовной практике (пересекается с теорией sahitya в Prout 1).
- **Baba bhava**: преданный «становится Анандамурти» — состояние полного слияния (см. Bindeshwariji); такие состояния нужно направлять (не садиться на место гуру без нужды).
- **Сдача уничтожает желания**: Nagina хочет мяса; подавляет дни; наконец пишет Бáбе письмо с признанием. «Пока я подавлял — желание росло; как только сдался письмом (отправил) — желание исчезло, я забыл о нём».
- **Титулы/уважение**: ачарьи, которым ученики касаются стоп, должны «следить за головой» (не гордиться); «оставь заботу о голове мне — я позабочусь о твоих стопах».

## Key Concepts

- **Lalita Marmika kiirtan** — танец-киртан, введён в 1958.
- **Ananda Purnima** — день рождения гуру; первый DMC 12.05.1958 Ranchi.
- **Baba bhava / Brahma bhava** — состояние слияния.
- **«Письмо о желании»** — механизм сдачи.
- **«Заботься о своей голове»** — предупреждение о гордости ачарьям.

## Mental Models

- «Подавление желания усиливает его; сдача ("письмо") уничтожает».
- «Киртан с танцем — цельная духовная практика, а не развлечение».
- «Уважение учеников — тест ачарьи на гордость».

## Anti-patterns

- **Подавление желаний волей** — рост; нужна сдача.
- **Гордость от почитания** («не достоин — но не следишь за головой»).
- **Имитация экстаза без готовности** — состояния по воле, не наигранны.

## Worked Example

На DMC преданные просят танец; Бáба вводит Lalita Marmika kiirtan — все танцуют в экстазе; один ачарья садится на место Бáбы, заявляя «сейчас я Анандамурти» (его уводят с почтением). Позже Nagina: желание мяса исчезает в момент отправки письма Бáбе; Бáба предупреждает ачарью «заботься о голове — стопами займусь я».

## Key Takeaways

1. Lalita Marmika kiirtan — официальный нежный духовный танец (1958).
2. Полная сдача уничтожает желание (письмо = акт сдачи).
3. Baba bhava — состояние слияния; направлять, а не поощрять подмену.
4. Почитание ачарьи — тест на гордость.
5. Экстаз — по воле гуру, не по наигрыванию.
