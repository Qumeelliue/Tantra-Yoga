## Правила духовной практики

| Ситуация | Правило |
|---|---|
| Проверить мантру | Обстоятельства инициации должны интенсифицироваться |
| Japa на ходу | Глаза открыты; дыхание синхронно с шагами |
| Садхана-среда | Фиксированное место/время/асан; непроводящий коврик |
| После садханы | Массаж колен 8–10 раз; не касаться воды 30 мин |
| Трудности концентрации | Больше времени на shuddhi (отвод чувств) |
| Guru Puja | Предложение «цвета» пропенсита гуру — освобождение от него |
| Дом/тело | «Храмы»: регулярность создаёт вибрации |

## Жизненные приёмы

| Ситуация | Приём |
|---|---|
| Сильное желание/привычка | Сдайся письменно/признанием — желание исчезает |
| Крупное решение | Сверься с наставником; подчинись («склониться, чтобы поднять оружие») |
| Демоция/потеря статуса | Не судись; прими и пройди опыт; статус вернётся |
| Препятствия перед делом | Они — фильтр искренности; не останавливайся |
| Больной/диагноз | Сначала простое предписание наставника, затем — помощь |
| Путь другого к гуру | Будь примером и медиумом; передавай просьбы честно |
| Просьба-боon | Формулируй точно с пределом, по сути, не абстрактно |
| Молитва | Говори «языком сердца», а не заклинаниями |

## Быстрые сигналы («tells»)

- «Дождь не падает на тебя, пока гуру с тобой» — признак защиты.
- Письмо приходит «в день твоего решения» — вмешательство.
- Две чёрные собаки / мотоциклисты / доктор «сами приходят» — «агенты» помощи.
- Слёзы/экстаз в присутствии гуру — пробуждение, не слабость.
- «Внешность ≠ суть»: богатый (Tyagiji), строгий (R. Prasad) — внутри преданность.
- Неинициированные входят в экстаз на DMC — общинная волна.
- Теневое тело не пьёт — способ отличить chaya murti.
- Оппозиция Марге = топливо любопытства и роста.
