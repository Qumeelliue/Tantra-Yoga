## Ключевые правила Бабы (по тексту)

| Ситуация | Правило |
|---|---|
| Работник не выполнил | Назови срок; обещай не повторять; наказание ≤ любовь |
| Отчёт | Five Common Report: единицы, книги, средства, WT/LFT, революционные браки |
| Приглашение на событие | Минимум за 24 часа |
| Подарок Бабе | Записать в реестр: что, откуда, кто |
| Время в резиденции | Быть до 10 утра; иначе — день за воротами |
| Пение | Ошибка = запрет петь перед Бабой; не поёшь — выйди из зала |
| Садаврата | Лучшие продукты, в избытке, без унижения |

## Резиденции и события

- **Lake Gardens** (Madhumalainca) — основная резиденция, сад, музей.
- **Tiljala** (Madhu Korak) — большая джагрти (500–600 мест), праздники.
- **Anandanagar** — духовная столица, вода из особого колодца.
- **Праздники**: Новый год DMC (30.12–01.01), Ваешакхи Пурнима (май/июнь), 14.09 — день Prabhat Samgiita.

## Быстрые сигналы («tells»)

- Наказание без ненависти + возврат полномочий = «метод Бабы».
- Ошибка в учёте подарка → выговор: важна точность внимания.
- Демонстрация татматр без 6-го урока → срыв: нужна подготовка.
- «Не могу» при назначении → Баба настаивает: делай, гуру гордится.
- Уход Бабы → не горевать годами, а киртан и служение миссии.
