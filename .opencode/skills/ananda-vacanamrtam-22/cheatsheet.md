# Читшит — правила решений (Ánanda Vacanámrtam Part 22)

## Киртан

| Ситуация | Правило |
|---|---|
| Психическая/физическая/духовная аффликция | Киртан — панацея; отчётливая мантра очищает органы и а́тма́ |
| Природное/рукотворное бедствие | Коллективный киртан с искренностью даёт прямое облегчение |
| Предчувствие грядущей беды | Киртан «вперед» устраняет её |
| Нет решения/тупик | Сядьте вместе и спойте киртан — сложность уйдёт, решение придёт |
| Удовлетворить Господа (Áshutośa) | 5–10 минут искреннего киртана |

## Служение и дхарма

| Ситуация | Правило |
|---|---|
| Служить Богу физически | Служи Его творениям; веди «я иду вперёд — иди со мной» |
| Четыре вида служения | Интеллектуальное, мужественное, экономическое, ручное — все ценны, служи по способности |
| Проверить «доброго» человека | Good ведёт массы; goody-goody — только вид |
| Оценить объект/человека | По dharma (сущности): молоко без белизны — не молоко |
| Временное vs постоянное спасение | tráńa временно; paritráńa — только от Parama Puruśa |
| Выбор пути при трудности | Svadharma (mánava dharma) лучше, даже с трудностями; paradharma опасна |
| Различия между религиями | Суть одна (любовь к Parama Puruśa); споры = невежество |

## Развитие и баланс

| Ситуация | Правило |
|---|---|
| Аудит развития | Три слоя: физика + психика + дух; провал любого — грубость/инертность/слабость |
| Только физика+психика | Ум становится грубым |
| Только физика+дух | Психическая инертность; коллективный прогресс остановлен |
| Развитие детей | Учёба + садхана с родителями + будущая дикша |
| Мужская практика | Táńd́ava (пожилым 2 раза в день, молодым — сколько могут) |
| Женская практика | Kaośikii nrtya (⚠ из-за физиологии); полезна обоим |
| Соревнования в практике | Поощряются везде, где есть и нет маргиев |

## Быстрые сигналы («tells»)

- Человек «добренький», но не ведёт массы — goody-goody, не good.
- Решение «спасает сегодня», но беда вернётся — это tráńa, не paritráńa.
- Проект игнорирует один из трёх слоёв — готовься к грубости/инертности/слабости.
- «Лучше жить как животное, чем страдать по-человечески» — отказ от svadharma.
- Не останавливайся: вечный путешественник не имеет права на паузу.
