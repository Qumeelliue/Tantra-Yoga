# Chapter 15: One Should Know Everything

*Дискурс от 18 мая 1979 утро, Berlin.*

## Core Idea

Знай значение имён (своих, танцоров, деревни) — расширяй радиус знания. Kaośikii изобретена 6 сентября 1978. Разбор имён: Mádhava, Prańava, Balarája, Sulocaná, Kusumitá. Материя → абстракт → астрал → духовное.

## Frameworks Introduced

- **Kaośikii**: изобретена 6 сентября 1978 (⚠ к калибровке); должны делать и мальчики, и девочки.
- **Знание имён**: «каждый должен знать значение своего имени и имени своей деревни» — расширяй радиус знания.
- **Этимологии имён**:
  - *Mádhava*: `má` (Prakrti/Operative Principle) + `dhava` (хозяин/муж) — хозяин Оперативной Принцип; энергия без интеллекта ничего систематично не делает — нужна поддержка интеллекта.
  - *Prańava*: `pra` (должным образом) + `nu` (гнать) + `al` (суффикс) — космическое акустическое выражение, ведущее к Supreme Goal.
  - *Balarája*: `bala` (верховная космическая выносливость) + `rája` (король) — «верховный король, контролирующий bala».
  - *Sulocaná*: «видящий только светлую сторону», только конструктивную критику, никогда разрушительную.
  - *Kusumitá*: `kusuma` (очаровательное выражение) + абстрактный суффикс — «очаровательное выражение» (kusumiká — маленькое).
- **Материнская/патрилинейная история**: в первичной фазе цивилизации — матрилинейный порядок; ~12000 лет назад — патрилинейный, женщины деградировали до «домашних животных»; `vidhavá` (вдова) — «чья dhava (муж) умер».
- **Материя/абстракт/астрал**: материя — грубая (сфера чувств); абстракт — эктоплазмическая сфера (ум; «доброту» не потрогаешь); астрал — «я есмь»; центр астрального существования — душа/дух; вокруг Parama Puruśa движется чистое «я».
- **Noumenal vs Phenomenal**: noumenal (старое немецкое слово) — «финальная причина»; Parama Puruśa — твоя ноуменальная причина, ты — Его феноменальное выражение.
- **Bábá náma kevalam**: «только имя той Единой сущности»; нет альтернативы — двигайся, танцуй, пой вокруг Него, как Земля, Сатурн и Марс вокруг Солнца.

## Key Concepts

- **Kaośikii** — танец (6 сентября 1978).
- **Mádhava / Prańava / Balarája / Sulocaná / Kusumitá** — имена танцоров.
- **Материя → абстракт → астрал** — слои существования.
- **Noumenal / Phenomenal** — ноуменальное/феноменальное.
- **Ánandáshru / shokáshru** — слёзы радости/горя.

## Mental Models

- «Знай значения имён — это расширяет радиус знания».
- «Различай слои: материя (грубое), абстракт (экто), астрал (я есмь), душа».
- «Ищи ноуменальную причину за феноменальным выражением».

## Anti-patterns

- **Разрушительная критика**: Sulocana видит только светлую сторону; избегай разрушительной критики.
- **Смешивать слои существования**: материя ≠ абстракт ≠ астрал.

## Worked Example

*Слои существования.* Слёзы — материальное выражение (видимы). За ними — ментальная агония (абстракт, невидима). За ней — «я есмь» (астрал). Центр астрального — душа/дух. Душа движется/танцует вокруг Parama Puruśa осознанно или нет. Noumenal причина — Parama Puruśa; ты — Его феноменальное выражение.

## Key Takeaways

1. Знай значение имён и названий — расширяй радиус знания.
2. Kaośikii — с 6 сентября 1978.
3. Имена раскрывают функции (Mádhava — хозяин Prakrti; Sulocana — светлая сторона).
4. Слои: материя → абстракт → астрал → душа.
5. Noumenal причина — Parama Puruśa; ты — феномен.
6. Bábá náma kevalam — только имя Единой Сущности.
