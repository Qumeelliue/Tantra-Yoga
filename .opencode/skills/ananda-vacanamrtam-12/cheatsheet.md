# Читшит — правила решений (Ánanda Vacanámrtam 12)

## Божественное и человек

| Ситуация | Правило |
|---|---|
| Как найти Господа | Киртан — среда божественности; Он там, где поют |
| «Почему я без благодати» | Зонт тщеславия блокирует дождь благодати; убери зонт |
| Справедливость/исключённость | Два несовершенства: не создаст второго и не может ненавидеть; никто не вне |
| Развитие общества | Единство через платформу без искусственных границ |
| Выбор окружения | Durjana (перевес зла) — избегай; са́дху — будь с ним |

## Успех и дисциплина

| Ситуация | Правило |
|---|---|
| Достичь успеха | 6 секретов: решимость→вера→гуру→равновесие→контроль→диета; седьмого нет |
| Твёрдая решимость | «Я должен преуспеть», невзирая на похвалу/осуждение/богатство/смерть |
| Диета | Сбалансированная, благая для тела/ума/духа |
| Делать добро | Kuru puńyam ahoratram — 24 часа; japa с дыханием идёт во сне |

## Действие и причинность

| Ситуация | Правило |
|---|---|
| Прогноз последствий | Реакция ≠ равна действию: TSP меняются |
| Объяснить «зло» | Ищи ноуменальную причину (вор голодал 3 дня); виновата структура |
| Прогресс | Только духовный (синтез, многие→один); техника не прогресс |
| Направление развития | Синтез, не анализ; конверсия unit→Cosmic |

## Ум и объект

| Ситуация | Правило |
|---|---|
| Управлять умом | Ум принимает форму объекта; следи за объектом идеации |
| «Призрак»/одержимость | Психическая проекция (солилоквия) — 90% эктоплазмы становится объектом |
| Преодолеть вину | Не «я грешник»; «почисти и возьми на колени»; убежище освобождает |
| Чего просить | Не проси ничего конкретного; проси только Сущего |

## Медитация и единство

| Ситуация | Правило |
|---|---|
| Медитация | «Он видит меня» — я объект, Он субъект |
| Стадии блаженства | Dashá (у статичной границы) → bháva → mahábháva → samádhi |
| Объект идеации | Только то, что вне времени/пространства/личности |
| Память | Samyak smrti → dhruvásmrti → dharmamegha samádhi |

## Быстрые сигналы

- Сердце йога закрыто — Сущий там не живёт; он живёт в пении преданных.
- «Всё случайно» — миф; всё инцидентально, причина есть.
- «Священник выдал билет в рай» — нет билетов; добрые дела и садхана.
- Sin complex («я грешник») — эксплуатируем; убежище в Сущем освобождает.
- «Меня никто не видит» — Он засвидетельствует даже эти слова.
