# Читшит — правила решений (Ánanda Vacanámrtam Part 25)

## Цель и баланс жизни

| Ситуация | Правило |
|---|---|
| Идеал жизни садхаки/проекта | Самореализация + благо мира (átmamokśárthaḿ jagaddhitáya ca) |
| Ты берёшь у мира больше, чем даёшь | Копишь долг → перерождение с процентами; возвращай служением |
| Только садхана/только служение | Одно без другого не продвигается |
| Человек «без идеала» | Хуже зверя: звери не ведут мировых войн |
| Домохозяин | Баланс малой (родня) и большой (весь мир) семьи; заброс любой = падение |

## Выбор пути (Vidyá / Avidyá)

| Ситуация | Правило |
|---|---|
| Материализм (только мир) | «Идут во тьму» (Andhaḿ tamah) |
| Эскапизм (только садхана, «мир нереален») | Лицемерие: пользуется миром; «в ещё большую тьму» |
| Правильный путь | Субъективный подход через объективную настройку |
| Оценка цели (iśt́a) | Человек становится тем, о чём думает; думающий о деньгах «станет деньгами» |
| Алкоголь | Разрушает интеллект и контроль сознательного ума |

## Этическая классификация

| Ситуация | Правило |
|---|---|
| Грех искупим возвратом/извинением | Pátaka |
| Грех неискупим, одноразов (отрезанная нога) | Atipátaka |
| Грех заразителен/повторяем (фальсификация) | Mahápátaka |
| Мысли (даже плохие) | Не наказуемы; наказуемо — пересечение границы действием |
| Перевес mahápátakiis | Gláni дхармы; нужно вмешательство высшего уровня |
| Защита общества | Учителя (samája gurus) → духовные революционеры (sadvipras) → Parama Puruśa |

## Тантра и дикша

| Ситуация | Правило |
|---|---|
| «Сверхъестественная» сила | Её нет; силы дремлют в человеке |
| Цель садханы | К Брахме (vidyá) — благо; к мирской выгоде (avidyá) — деградация |
| Высший путь тантры | Внутренний аспект (йога), не внешний (кладбищенский) |
| Лесть Пракрти | Лесть делает её гордой; поклоняйся Пуруше |
| Вход в духовную систему | Vaedikii дикша (путь) → Tántrikii дикша (метод) |
| Статус по дикше | Рождением — shúdra; дикшей — dvija; изучением — vipra; реализацией — Bráhmańa |

## Быстрые сигналы («tells»)

- Проект «только для меня» без пользы миру — эгоизм под видом духовности.
- «Мир нереален, делай только садхану», но ест/пьёт из мира — лицемерие (сова отрицает солнце).
- Практика ради «сил» и мести — авидья, путь деградации.
- Фальсификация/«схема», которую перенимают другие, — mahápátaka.
- Нет направления-идеала — нет человеческой жизни, есть «идеологический поток» в никуда.
