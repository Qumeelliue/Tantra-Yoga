# Глоссарий — Ánanda Vacanámrtam Part 34

**Ácárya** — «учащий своим поведением» (ácarańát pát́hayati); духовный учитель (Ch 19).

**Aeshvarya / vibhúti** — оккультные силы: ańimá, laghimá, mahimá, prápti, iishitva, vashitva, prákámya, antaryámitva (Ch 8).

**Apramatta** — безошибочный (не pramatta): не ошибаться в начале, середине и конце (Ch 7).

**Arańi / uttarárańi** — нижнее и верхнее дерево для добывания огня трением; метафора тела и мантры (Ch 11).

**Átman** — «Я знаю»; субъект в структуре микрокосма; знающий mahat (Ch 4).

**Átmatiirtha** — внутренний тиртха, где лежит Господь (Ch 14).

**Bhaga** — собрание шести атрибутов: aeshvarya, viirya, yasha, shrii, jiṋána, vaerágya (Ch 8, 12).

**Bhagaván** — владелец bhaga (Ch 8, 12).

**Bhakti** — преданность; результат jiṋána + karma; karma − jiṋánam = bhakti (Ch 2, 6).

**Bhágavata dharma** — правильная дхарма человека: психо-духовный подход за пределами относительности (Ch 15).

**Bharga** — божественное сияние: bha (освещает) + ra (чарует) + ga (исходит/возвращается) (Ch 3).

**Brahma sádhaka** — садхака, приписывающий объектам мира Brahma-hood (Ch 8).

**Brahmá / Viśńu / Maheshvara** — Создатель / Сохранитель / Разрушитель (Ch 7).

**Brhat / vishála** — неизмеримо большое / измеримо большое (Ch 1).

**Chanda** — ритм стиха/мантры; 7 признанных chandas (Ch 10).

**Deha** — тело как объект обожания (dih = украшать) (Ch 11).

**Deva** — божественная вибрация, «спица» космического колеса (Ch 9).

**Dharmakśetra** — человеческое тело как единственное поле практики дхармы (Ch 12).

**Dhritarastra** — слепой ум без совести (Ch 12).

**Guhá** — «I»-чувство; суть дхармы там (Ch 1, 4, 14).

**Hari** — «вор грехов» (hr = красть); крадёт грехи тайно (Ch 13, 22).

**Iishvara** — Контролёр, обладатель aeshvaryas; не затронутый saḿskáras (Ch 3, 8).

**Incantative rhythm** — акустический ритм мантры (Ch 11).

**Jiṋána / vijiṋána** — мирское / духовное знание (Ch 2).

**Jiṋánii** — садхака пути знания; «делает мало, говорит много» (Ch 6, 13).

**Káma** — желание конечного (Ch 6).

**Kiirtana** — коллективное пение имени Господа (Ch 13, 22).

**Krśńa** — «великий чарователь»; от krś (быть) — «мы существуем, потому что Ты» (Ch 8, 13).

**Kurukśetra** — мир, вечно говорящий «делай» (kuru, kuru) (Ch 12).

**Loka** — семь слоёв творения: bhú, bhuvah, svah, mahah, janah, tapah, satya (Ch 3).

**Mádhava** — «муж/владыка Пракрити» (má + dhava) (Ch 3, 8).

**Mahádeva** — Supreme Deva, hub космического колеса (Ch 9).

**Mahájana** — практический человек, материализовавший знание в действие (Ch 4).

**Mahásambhúti** — приход Táraka Brahma в теле (Ch 19).

**Maháyogi** — великий йогин (Shiva) (Ch 9).

**Mantra** — «внутреннее пение, ведущее к освобождению» (mananát tárayet) (Ch 10).

**Mokśa** — спасение: цепочка суспензий к átman (Ch 2).

**Muni** — сливший ум в Supreme (не «мудрец-малыш») (Ch 4).

**Náráyańa** — приют (ayana) Пракрити (nára) (Ch 3, 8).

**Oṋm / oṋḿkára** — prańava; a (творение) + u (поддержание) + ma (разрушение) (Ch 7, 10).

**Pańd́á / pańd́ita** — самореализация / реализовавший Себя (Ch 11, 12).

**Pandavas (5)** — пять чакр-помощников самореализации (Ch 12).

**Pashu → viira → deva** — стадии: животное → герой → бог (Ch 5).

**Prańava** — личная Iśt́a мантра; oṋḿkára (Ch 7).

**Prema** — идея за потоком bhakti (Ch 6).

**Sadáshiva** — великий йогин ~6500 лет назад (⚠ к калибровке), Maháyogi (Ch 9).

**Sádhanásamara** — «битва садханы» (Ch 4).

**Sanjaya** — совесть, различение (sam+ji) (Ch 12).

**Savitr Rk** — официальное имя «мантры Гаяттри»; chanda gáyattrii, devatá Savitá, rśi Vishvamitra (Ch 10).

**Shástra** — кодекс дисциплины, ведущий к спасению (Ch 7).

**Shrii** — активирующая привлекательность (sha + ra) (Ch 12).

**Shruti** — Веды, «услышанное» на слух (риши неграмотны) (Ch 4, 10).

**Tantra** — расширение-освобождение (tan + tra); 99% практики (Ch 4).

**Tapasya** — служение другим ценой своего комфорта (Ch 1).

**Tiira / tiirtha** — ватерлиния / стойка-переход (Ch 14).

**Vidyámáyá** — центростремительная сила притяжения (Ch 8).

**Vishvarúpa** — вселенская форма Господа (Ch 13).

**Yama / Niyama** — пять + пять моральных принципов, «внутренние оружия» (Ch 5).
