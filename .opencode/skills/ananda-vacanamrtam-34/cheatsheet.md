# Читшит — правила решений по Саркару (Ánanda Vacanámrtam Part 34)

## Преданность и знание

| Ситуация | Правило |
|---|---|
| Оценить преданность | bhakti ≈ karma (служение) − jiṋánam («я-знаю»); знатоку — больше служения |
| Путь к освобождению | Jiṋána (узнать) → karma (делать) → bhakti (вершина-результат) |
| Bhakti статичная | «Убей моего врага» — не преданность: желание было не о Господе |
| Знание без контроля | Ведёт к «грамотным зверям»; pará-дух должен управлять apará-механикой |

## Практика и метод

| Ситуация | Правило |
|---|---|
| Что такое Tantra | Расширение-освобождение (tan + tra); садхана = битва на каждом шагу |
| Держать цель | Субъективный подход (цель) + объективная подстройка (исполнение) |
| Кого слушать | Mahájanas (практиков, материализовавших знание), не теоретиков |
| Практика стала жестами | Догма: ничего внешнего духовности не требуется |
| Проверить практику | «Работает ли без внешних условий?» — нет → форма без духа |

## Стадии и состояние ума

| Ситуация | Правило |
|---|---|
| Стадия садхаки | Pashu (животное) → viira (герой) → deva (бог); Господь: Pashupati → Viireshvara → Mahádeva |
| Получил силу | Десять внутренних оружий (Yama/Niyama); внешние оружия нужны, но под контролем |
| Комплексы | Превосходство/неполноценность/страх/поражение искажают мысль и память; все — дети одного Отца |
| «Я грешник» | Самореализуется: «был грешником, но с этого момента я на коленях Отца» |
| Ум «пуст» | Не бывает: займи психическим/духовным, не психо-физическим |

## Имена и звук

| Ситуация | Правило |
|---|---|
| Понять имя Господа | Разбери корни: Náráyańa = приют Пракрити; Bhagaván = владелец 6 атрибутов; Hari = вор грехов |
| Что такое oṋm | a (творение) + u (поддержание) + ma (разрушение) = prańava = G-O-D |
| «Гаяттри-мантра» | Gáyattrii — ритм (3×8 слогов), не имя; официально — «Savitr Rk» |
| Произношение мантры | Chanda (ритм) побеждает грамматику: vareńyam → va-re-ńi-am (8 слогов) |
| У мантры | Три фактора: chanda (ритм), devatá (слово для Бога), rśi (видец) |

## Жизнь и общество

| Ситуация | Правило |
|---|---|
| Кризис/провал | Кризис — норма движения; выбирай оптимизм и миссию |
| Свободное время | Kiirtana / хорошая мысль; не критика и не праздность |
| Долголетие | Баланс труда + духовная практика; славная жизнь, а не «червь» |
| Служение уязвимым | Уважение первично (приписывание Godhood); без уважения нет служения |
| Выбор «места» | Тиртха — внутренний: держи стойку (в медитации — глубоко, в работе — практично) |
| Движение | Порядок жизни — движение; слепой ум без совести = действия вслепую |

## Быстрые сигналы («tells»)

- Видишь «жесты и позы» без содержания — вероятна догма.
- Кто-то много «знает» и мало служит — у него мало бхакти; предложи больше служения.
- Речь «я знаю это, я знаю то» — симптом «болезни интеллектуальности».
- Комплекс (страх, «я побеждён») — предвестник искажённых решений и памяти.
- «Гаяттри-мантра» как название — филологическая ошибка (это ритм).
- Ум «занят ничем» — кормится чем-то: проверь, чем.
- Внешнее паломничество/места вместо внутренней работы — трата ресурсов без продвижения.
