# Chapter 7: Prańava

*Дискурс, дата неизвестна.*

## Core Idea

Садхака — солдат со своим кодексом (shástra). Его лук — prańava (своя Iśt́a мантра / oṋḿkára), стрела — «I»-чувство, цель — Brahma. Точность требует быть apramatta.

## Frameworks Introduced

- **Shástra**: *Shásanát tárayet yastu sah shástrah parikiirtitah* — «что ведёт к спасению через кодекс дисциплины и духовный культ — shástra».
- **Пран́ава**: pra + nu (root) + al = «что помогает достичь места»; для садхаки — его личная Iśt́a мантра; в общем смысле — oṋḿkára (исходит из Supreme Nucleus; пришедший в контакт со звуком достигает источника, как пришедший к Ганге — исток Ганготри).
- **Oṋm = a + u + ma**: каждый акт имеет acoustic root (смех = ha-ha; ходьба = khat́-khat́). Творение → звук a (первая буква Tántrika varńamálá); поддержание → u; разрушение → ma (последняя буква vargiiya varńamálá). a+u = o (sandhi) → oṋm = вся система творения.
- **Brahmá / Viśńu / Maheshvara**: Brahma + a = Brahmá (Создатель); поддерживающий — Viśńu; разрушающий — Saḿhartá/Maheshvara. Первые буквы: Generator-Operator-Destructor = G-O-D.
- **Три элемента шлоки**: prańava = dhanu (лук); átma («I»-чувство) = shara (стрела); Brahma = lakśya (цель).
- **Apramatta**: pramatta — ошибающийся в начале, в процессе и в конце; садхака должен быть apramatta, тогда стрела «I»-чувства достигнет цели.

## Key Concepts

- **Prańava** — помощь в достижении; личная мантра.
- **Acoustic root (biija mantra)** — звук действия (смех, ходьба, творение).
- **Tántrika varńamálá / vargiiya varńamálá** — алфавит; a первая, ma последняя в vargiiya.
- **Apramatta** — безошибочный (не pramatta).

## Mental Models

- «Мантра — инструмент навигации: правильный звук ведёт к источнику, как Ганга к Ганготри».
- «Каждое действие имеет звук-корень; творение — звук a; поддержание — u; разрушение — ma».

## Anti-patterns

- **Pramatta (небрежность)** — ошибки в начале/середине/конце = промах цели.
- **Считать oṋm только символом** — это свод всех волн космоса.

## Worked Example

Садхака-солдат берёт лук (своя Iśt́a мантра), натягивает стрелу (чистое «I»-чувство), целится в Brahma. Он бдителен (apramatta): не ошибается в начале, процессе и финале. Стрела достигает Верховного Себя — спасение.

## Key Takeaways

1. Пран́ава — лук садхаки; личная мантра ведёт к цели.
2. Oṋm = a (творение) + u (поддержание) + ma (разрушение).
3. Brahmá → Viśńu → Maheshvara соответствуют G-O-D.
4. «I»-чувство — стрела; Brahma — цель.
5. Точность требует apramatta (безошибочности на всех этапах).
