# Chapter 3: Every Word Is Meaningful

*Дискурс, дата неизвестна.*

## Core Idea

В индийской традиции каждое слово осмысленно; имена Господа раскрывают Его природу через этимологию. Дискурс разбирает Bhárata, Náráyańa, Mádhava, Iishvara, oṋm и bharga.

## Frameworks Introduced

- **Bháratavarśa**: bhar («кормить») + al → bhara («кормящий»; saḿbhara = Supreme Feeder); tan («расширять») + d́a → ta («помогающий всестороннему расширению»). Бхарата = «тот, кто кормит и помогает всестороннему (физически, ментально, духовно) развитию». Полное имя страны — Bháratavarśa (varśa = год/сезон/страна).
- **Náráyańa**: nára (три значения: вода; преданность — Nárada = «раздающий бхакти»; Supreme Operative Principle/Mahámáyá) + ayana (приют) = «Приют Пракрити» = Puruśottama.
- **Mádhava**: má (Paramá Prakrti) + dhava (муж/владыка) = «муж Пракрити», контролёр.
- **Iishvara**: iish («контролировать») = Supreme Controller; или обладатель aeshvaryas (8 оккультных сил). Определение Патанджали: *Kleshakarmavipákáshayaeraparámrśt́ah Puruśavisheśa Iishvarah* — не затронутый волнами действий/реакций, не требующий подпитки.
- **Oṋm / a-u-m**: первое действие создаёт первый звук — «a» (первая буква Tántrika varńamálá; a = творение, u = поддержание, ma = разрушение). Семь слоёв творения: bhú, bhuvah, svah, mahah, janah, tapah, satya (lokas; тело в bhú, ум в bhuvah).
- **Bharga (Savitr Rk)**: bha (от bhásayate lokán iti — «освещает слои») + ra (от rauṋjayati — «чарует/окрашивает») + ga (от gacchati yasmin, ágacchati yasmád — «к которому возвращаются, из которого исходят») = «Божественное сияние». Тат savitur vareńyam bhargo devasya dhiimahi — «медитируем на сияние Творца, создавшего семь слоёв».

## Key Concepts

- **Tántrika varńamálá** — тантрический алфавит; первая буква «a».
- **Loka** — семь страт творения.
- **Aeshvaryas** — 8 оккультных сил (см. glossary).
- **Савitr Rk / Gáyattrii** — мантра (подробно — ch10).

## Mental Models

- «Раскрывай имена через корни: имя — сжатая доктрина, а не ярлык».
- «Первая буква алфавита неслучайна — она соответствует первому звуку творения».

## Anti-patterns

- **Произносить «Gáyattrii Mantra» как название** — gáyattrii это chanda (см. ch10).
- **Говорить просто «Bhárata»** — полное имя Bháratavarśa.

## Worked Example

Садхака разбирает имя «Náráyańa»: nára = Пракрити, ayana = приют → «Приют Оперативного Принципа» → Puruśottama. Имя «Mádhava»: «муж Пракрити». В мантре он видит bharga: bha (освещает), ra (чарует), ga (исходит/возвращается). Oṋm: a (творение) u (поддержание) ma (разрушение).

## Key Takeaways

1. Каждое имя Господа — этимологическая доктрина.
2. Bhárata = «кормящий + всесторонне расширяющий»; полное имя — Bháratavarśa.
3. Náráyańa = приют Пракрити; Mádhava = муж/владыка Пракрити.
4. Iishvara — контролёр и обладатель aeshvaryas.
5. Oṋm = a (творение) + u (поддержание) + ma (разрушение); bharga = bha-ra-ga.
