# Chapter 9: Further Names of the Supreme

*Дискурс от 8 декабря 1964, Salem.*

## Core Idea

Ещё три имени Господа через этимологию: Ráma (источник блаженства), Shiva (Сознание; имя великого йогина), Mahádeva (Supreme Deva — hub космического колеса).

## Frameworks Introduced

- **Ráma**: ram (root: наслаждаться) + ghaiṋ = «источник наслаждения» — *Rámante yoginah yasmin*; наслаждение = сверхмирское блаженство. Ráma = Supreme Consciousness.
- **Shiva**: тоже означает «Сознание». ~6500 лет назад (⚠ к калибровке) жил великий йогин Shiva/Sadáshiva; его единение с Верховным Когнитивным Принципом никогда не прерывалось мирскими вибрациями (без пауз), поэтому йогины приняли его объектом почитания, он стал Maháyogi. В позднем санскрите Shiva = Cosmic Consciousness, Cosmic blessedness, вечный океан существования.
- **Mahádeva**: вселенная — колесо; hub = Puruśottama; спицы — вибрации/звуки/светы = **deva** (божественная вибрация/сияние). Mahádeva = Supreme Deva = hub/nave колеса. Шлока: *Tava tattvaḿ na jánámi…* — «не знаю, каков Ты; но в какой бы форме Ты ни был — поклоняюсь». Mahádeva = Supreme Causal Factor (не Causal Matrix — а сам Фактор).

## Key Concepts

- **Rámante yoginah yasmin** — «в котором наслаждаются йогины».
- **Sadáshiva** — «Вечный Шива», великий йогин.
- **Maháyogi** — великий йогин.
- **Deva** — божественная вибрация-спица колеса.

## Mental Models

- «Имя через корень: Ráma = источник блаженства; Shiva = Сознание; Mahádeva = hub колеса».
- «Непостижимость не мешает поклонению: «не знаю, каков Ты — но поклоняюсь».

## Anti-patterns

- **Считать Mahádeva «Causal Matrix»** — Он Supreme Causal Factor, сам причина.
- **Приписывать Ráma мифологический образ без корня** — имя означает «источник наслаждения».

## Worked Example

Садхака произносит имена: Ráma — помнит, что это источник сверхмирского блаженства; Shiva — Сознание, чья связь с Верховным не прерывалась; Mahádeva — hub космического колеса, из которого исходят вибрации-спицы (devas). Даже не зная Его формы, он поклоняется (Tava tattvaḿ na jánámi).

## Key Takeaways

1. Ráma = источник наслаждения (сверхмирского блаженства).
2. Shiva = Сознание; имя великого йогина ~6500 лет назад.
3. Deva = вибрации-спицы колеса; Mahádeva = hub.
4. Непостижимость — не препятствие поклонению.
5. Mahádeva — Supreme Causal Factor (не Matrix).
