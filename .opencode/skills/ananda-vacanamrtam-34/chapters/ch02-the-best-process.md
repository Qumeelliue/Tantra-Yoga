# Chapter 2: The Best Process

*Дискурс, дата неизвестна.*

## Core Idea

Для освобождения (mokśa) есть практики; лучшая — bhakti. Ключевой инсайт: **bhakti — не отдельная практика, а результат jiṋána + karma**.

## Frameworks Introduced

- **Mokśa = цепочка суспензий**: (1) индивидуальное физическое чувство суспендируется в грубом уме; (2) грубый ум сливается в тонкий ум; (3) тонкий ум — в чистое «I»-чувство; (4) «I»-чувство — в átman (в пределах чистой когниции). Это и есть спасение.
- **Три практики** (шлока: индрии → citta → aham → mahat → jiivátmá → Supreme Consciousness):
  - **Jiṋána** — узнать что/как/почему делать (первая фаза). Два класса: jiṋánam (мирское знание: инженерия, медицина, искусство) и vijiṋánam (знание духовной науки).
  - **Karma** — делать практически после знания.
  - **Bhakti** — результат двух практик, их «пиннакль»; в финальной стадии — руководящий фактор.
- **Парадокс ребёнка**: мальчик 5–6 лет уже имеет bhakti без видимого jiṋána/karma — потому что сделал их в прошлой жизни.
- **Значение по стадиям**: jiṋánam ценно в базовой стадии, karma — в следующей, bhakti — в финальной. Без bhakti не прийти в контакт с Господом.

## Key Concepts

- **Mokśa** — спасение; суспензия в пределах чистой когниции.
- **Jiṋánam / vijiṋánam** — мирское / духовное знание.
- **Bhaktimána** — обладающий bhakti.

## Mental Models

- «Bhakti — вершина, а не фундамент: строй из знания и действия, увенчивай преданностью».
- «Недостаток видимой преданности у новичка ≠ её отсутствие — могла накопиться в прошлых жизнях».

## Anti-patterns

- **Практиковать karma без jiṋána** — действие без знания, что/как/почему.
- **Ожидать bhakti без двух основ** — невозможна как самостоятельная практика.

## Worked Example

Садхака узнаёт, что делать (jiṋána), затем делает (karma). Результат обоих — растущая bhakti, которая в финале ведёт его. Мальчик с детской преданностью объясняется накоплением jiṋána/karma в прошлой жизни. Итог: `Mokśakárańasamagryáḿ bhaktireva gariiyasii`.

## Key Takeaways

1. Мокша — цепочка суспензий к átman.
2. Три практики: jiṋána (знать), karma (делать), bhakti (результат).
3. Bhakti не отдельная садхана — пиннакль первых двух.
4. Виды знания: jiṋánam (мирское) vs vijiṋánam (духовное).
5. Детская преданность объясняется прошлыми жизнями.
