# Читшит — правила решений (Ánanda Vacanámrtam 17)

## Духовная карта

| Ситуация | Правило |
|---|---|
| Понять Krśńatattva | Rádhá = кундалини (kula), Krśńa = Парамашива (сахасрара); их союз = цель садханы |
| Подобрать киртан/мантру | Общая сиддха-мантра — 8 слогов (не 7, не 9) |
| Определить стадию подъёма | vraja bháva (манипура) → gopii bháva (аджня) → advaya/rádhá bháva (выше) |
| Диагностировать страдание | Мирское → меняй структуру общества; психическое → садхана; духовное → dhyána/práńáyáma |
| Контроль ума | Органы ← ум ← вайю ← пранайяма; сначала низшие чакры |

## Гиты и философии

| Ситуация | Правило |
|---|---|
| Интерпретировать шлоку Гиты | Тело = dharmakśetra, мир = kurukśetra, ум = слепой Dhritarastra, совесть = Sanjaya |
| «Моя партия»/«партия Панду» | Индрии + 100 пропенсий / 5 факторов + vidyá |
| Проверить знание | Прочное и преобразующее = jiṋána; забывается к пересдаче — не знание |
| Оценить мир | Ничто не статично; неподвижность = несуществование; «делай» (kuru) |
| Совесть в конфликте | Из битвы добра и зла рождается различение (samyak jaya) |

## Пропенсии и поведение

| Ситуация | Правило |
|---|---|
| Не можешь победить влечение | Это Duryodhana; контролируй через пранайяму и стабилизацию чакр |
| Не можешь контролировать влечение | Это Duhshasana; работай с нижними чакрами |
| Влечение управляет тобой | Ты потерял здравый смысл (как гость с 80–100 лучи) |
| Забыл «важное» | Принцип равной важности: муравей = комар = слон = три мира |
| Стыд/гордость/страх | Это комплексы; верни баланс (см. AV-16 ch3) |

## Искусство и общество

| Ситуация | Правило |
|---|---|
| Оценить произведение | Передаёт ли bháva тончайшими средствами; ведёт ли к растворению «я» в радости |
| Общество застопорилось | Нужен «молот» (Mahásambhúti); застой = разрушение |
| Малые группы/государства | Не защитят себя; объединяй под моральной идеей (dharma rájya) |
| Великая идея пришла | Ожидай полной поляризации общества |
| После «победы» | Sadvipra не спит — бдит, как часовой |

## Быстрые сигналы («tells»)

- «Мирное сосуществование» добра и зла — иллюзия/лицемерие (vidyá/avidyá несовместимы).
- Слова мира + тайная подготовка = hypocrisy, отсутствие sádhutá.
- Титул «Pańd́ita» без знания «я есть Брахма» — пустой.
- «Спокоен, потому что хорош» — часто просто неразличение.
- Списал сложности на «чёрный цвет» Кришны — у исторического Кришны комплекция иная.
- Проповедует «отдых после построенного общества» — ошибка, sadvipra обязан бдеть.
