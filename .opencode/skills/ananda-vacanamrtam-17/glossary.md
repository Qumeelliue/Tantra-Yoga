# Глоссарий — Ánanda Vacanámrtam Part 17

**Advaya bháva / Rádhá bháva** — стадия подъёма кундалини выше аджня-чакры (Ch 2).

**Aeshvarya** — оккультная сила; первый атрибут bhaga (Ch 9).

**Ádhibhaotika / ádhidaevika / ádhyátmika** — три типа страдания: мирское / психическое / духовное (Ch 2).

**Ananyapáy** — неподражаемый, бесподобный (эпитет Кришны) (Ch 2).

**Bhaga** — собрание шести атрибутов: aeshvarya, pratápa, yasha, shrii, jiṋána, vaerágya (Ch 9).

**Bhágavata dharma** — основная дхарма человека; четыре ноги: vistára, rasa, sevá, tadsthiti (Ch 11).

**Bháva** — внутреннее чувство/идея (Ch 1).

**Cakra / padma / kamala / plexus** — «подстанции» ума в теле; муладхара…аджня (Ch 7).

**Clash / cohesion** — столкновение и сплочение; двигатели общества (Ch 2).

**Devatás** — вибрационные существования, точки контроля в чакрах (Ch 7).

**Dharma rájya** — царство морали; цель объединения Индии Кришной (Ch 12).

**Dharmakśetra** — физическое тело как поле дхармы (Ch 4, 10, 11).

**Dhrtaráśt́ra** — «держащий структуру»; ум (слепой) (Ch 12).

**Duratyaya** — «почти непреодолимая» (о Майе) (Ch 3).

**Duryodhana / Duhshasana** — пропенсии, которые нельзя победить / взять под контроль (Ch 5).

**Gopii bháva** — стадия подъёма от манипуры к трикути/аджня (Ch 2).

**Guru** — «рассеивающий тьму» (gu + ru); только Брахма гуру (Ch 3).

**Indriya** — сенсорный/моторный орган (пять+пять) (Ch 4).

**Jaeva dharma** — борьба как инстинктивная природа живого (Ch 5).

**Jiṋána** — субъективация объективности; прочное знание (Ch 9).

**Jiiva → Shiva** — освобождение: в оковах — jiiva, освобождённый — Shiva (Ch 7).

**Kartrttva** — «я»-центрированное авторство действия (Ch 3, контекст).

**Krśibhúh** — «я есть, потому что Он есть»; производное существование (Ch 8).

**Kula / kulakuńd́alinii** — последний позвонок / спящая там сила («Радха») (Ch 2, 7).

**Kurukśetra** — мир (saḿsára), зовущий «делай» (kuru) (Ch 4, 10).

**Máyá (duratyaya)** — «почти непреодолимая», но «моя» Майя (Ch 3).

**Mahásambhúti** — Великое Явление Парама Пуруши в теле из пяти факторов (Ch 2).

**Manana / smarańa** — мышление / сохранение в памяти (функции ума) (Ch 4).

**Mohana / mohanavijiṋána** — воплощение очарования (Парама Пуруша) / наука сверх-эстетики (Ch 1).

**Muraliidhvani** — звук флейты Кришны у трикути (Ch 2).

**Nirvikalpa / savikalpa samádhi** — слияние с Paramátman / слияние с Его Умом (Ch 6).

**Pańd́á / pańd́ita** — ведо-светлый интеллект («я есть Брахма») / его обладатель (Ch 5).

**Pásha** — путы/оковы; семь чакр как верёвки (Ch 7).

**Paramashiva / Puruśottama** — управляющая точка сахасрары; в ваешнава-тантре «Кришна» (Ch 7).

**Práńáyáma** — контроль вайю для контроля ума (Ch 4, 7).

**Prańava** — звук «oṋm», слышимый на разных уровнях подъёма (Ch 2).

**Pratápa** — власть/управление (атрибут bhaga) (Ch 9).

**Sadhutá / saralatá** — честность / простота; против лицемерия (Ch 5).

**Sadhurátra / sadvipra** — духовный революционер; не спит (Ch 11, 12).

**Sahasrára** — тысячелепестковая чакра (шишковидная железа); «тысяча» от 1000 пропенсий (Ch 7).

**Saḿgiita** — песня, танец, инструментальная музыка (Ch 1).

**Saiṋjaya / viveka** — совесть, сила различения; samyak jaya (Ch 12).

**Siddha mantra** — «совершённая» гуру мантра; восемь слогов (Ch 2).

**Sudurácárii** — презираемый дурными; освобождается при преданности (Ch 3).

**Tejastattva** — светящийся/энергетический фактор; Arjuna (Ch 6, 12).

**Trividha páśa** — три типа страдания (см. ádhibhaotika…) (Ch 2).

**Uha / avoha** — ритм расширения/сжатия мысли (макропсихическая конация) (Ch 10).

**Vaerágya** — отрешённость от «цвета» мира; атрибут bhaga (Ch 9).

**Váyus (десять)** — жизненные потоки: práńa, apáńa, samána, udána, vyána; nága, kúrma, krkara, devadatta, dhanaiṋjaya (Ch 7).

**Vidyá / Avidyá** — центростремительная / центробежная силы (Ch 5, 6).

**Vraja bháva** — стадия подъёма у манипуры (Ch 2).

**Yasha / apayasha** — слава позитивная/негативная; атрибут bhaga (Ch 9).

**Yashokiirtana** — публичное восхваление в ритме (Ch 9).

**Yudhi + sthira** — «устойчивый в бою»; Юдхиштхира = эфирный фактор (Ch 6).

**Shrii** — шарм (sha=раджагуна + ra=энергия + ii); атрибут bhaga (Ch 9).
