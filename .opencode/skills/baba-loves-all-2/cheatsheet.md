# Читшит — Baba Loves All 2

## Дисциплина и работа

| Ситуация | Правило |
|---|---|
| Понять дисциплину | Anushásana: наставление ради блага; следуй полезному правилу (Ch 3) |
| Откладываешь задачу | «Не оставляй работу на завтра»; делай сейчас, будь alert (Ch 3) |
| Передаёшь факт | Проверь у источника; неверная новость = стыд (Ch 3) |
| Стандарт страдает | «Если стандарт нехорош, я чувствую боль» — подними его (Ch 3) |
| Мелочи вне места | Всё tip-top: ключ в одном кармане, платок в другом (Ch 3) |

## Деньги и честность

| Ситуация | Правило |
|---|---|
| Средства организации | Прозрачность, отчётность; «не капиталистическая организация» (Ch 4) |
| Донаты | Личное → минимум; всё — миссии; первый донат вдохновляет (Ch 4) |
| Гипокризия | Проповедь при нарушении разоблачается: «Деньги честные?» (Ch 4) |
| Чужой расход | Строгость к растрате, сочувствие к человеку (Ch 4) |

## Эго и вера

| Ситуация | Правило |
|---|---|
| Чувствуешь гордость | Эго — пища Брахмы; помни источник силы (Ch 5) |
| Опасность/кризис | Мысленно обратись к Бáбе, затем действуй (Ch 6) |
| Не понят чужой опыт | «Боль в ухе другого невыразима» — не суди (Ch 7) |
| Сомнение в вере | «В нужных случаях Он всегда помогает» (Ch 6) |
| Преодолеть страх | Верь до глубины подсознания — страху нет места (Ch 8) |

## Преданность
