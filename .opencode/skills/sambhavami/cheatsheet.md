## Быстрые правила

| Ситуация | Правило |
|---|---|
| Какой гуру истинный | Садгуру = Sat+гуру; выше относительности; умеет карать и миловать |
| Чудо vs установка | Маги умеют «чудо»; установить в духовной жизни — только Садгуру |
| Тест от гуру | «Потеряешь веру в Меня» — держи веру и обеты |
| Дисциплина | 16 Points — кодекс силы духа в кризисе |
| Кризис цивилизации | Разум обогнал интуицию → нужен баланс + неогуманизм |
| Универсализм | Акцент на общем (экономика, духовная цель), игнорируй различия |
| Неогуманизм | Любовь ко всему творению, включая неодушевлённое |
| Угнетение | Три формы: suppression, oppression, exploitation — все отвергнуты |
| Будущее | «Установите PROUT → начнётся Satya Yuga» |
| Сравнение Махасамбхути | Бессмысленно; каждый сыграл роль своей эпохи |
