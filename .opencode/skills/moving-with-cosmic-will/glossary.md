# Глоссарий — Moving with Cosmic Will

**Авадхута (avadhuta)** — монах-тангрик, отрекшийся от мира для духовной работы (Ch 5).

**Ачарья (acharya)** — духовный учитель, дающий инициацию; проходит тренинг (Ch 5, 6).

**Baba Nam Kevalam** — мантра «Божественное Сознание — всё сущее» (Ch 3).

**Bhava samadhi** — экстатическое состояние поглощённости (идеационной) (Ch 3).

**BABA-сны** — сны, где Баба даёт направление/утешение (Ch 11).

**Dharmacakra** — регулярная коллективная медитация марги (Ch 6).

**Дикша (diksha)** — инициация, получение мантры от ачарьи (Ch 3).

**Гуру-мантра / ишта-мантра** — личные мантры для сосредоточения (Ch 3).

**Jagriti** — медитационный центр Ананда Марга (Ch 6).

**Kapalika sadhana** — ночная медитация на кладбище/поле в новолуние (Ch 6).

**Киртан** — пение с танцем мантры (Ch 3).

**LFT (Local Full Timer)** — местный штатный работник (Ch 10).

**Мастер-юнит (Master Unit)** — эко-деревня/модельное сообщество Ананда Марга (Ch 10).

**Марги (Margii)** — практикующий Ананда Марга (Ch 2).

**Пракар (pracar)** — распространение/пропаганда (Ch 6).

**Прасад (prasad)** — благословлённая еда/предмет от гуру (Ch 4).

**PRS / SS / RS** — организационные посты (публичные/секторные/региональные секретари) (Ch 10).

**RDS (Review, Defect, Solution)** — периодическое организационное собрание секретарей (Ch 11).

**Садхана (sadhana)** — духовная практика/медитация (Ch 3).

**Санскара (samskara)** — ментальный реактивный моментум из прошлого (Ch 8, 10).

**Сатсанга (satsaunga)** — общество духовных людей (Ch 2).

**Тантра** — духовная система Шивы; практика всей жизни (Ch 6).

**Yama / Niyama** — базовые моральные принципы (внешние/внутренние) (Ch 3).

**Демонстрация samskaras** — показ Бабы психических волн на людях (Ch 8).

**Экстренный случай (Emergency)** — индийское чрезвычайное положение 1975–1977 (Ch 8).

**MISA** — акт о поддержании внутренней безопасности (аресты без суда) (Ch 8).

**AMURT** — гуманитарный отряд Ананда Марга (Ch 8).
