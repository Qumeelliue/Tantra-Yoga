## Правила решений

| Ситуация | Действие |
|----------|----------|
| Неконтролируемое событие (виза/деньги/срыв) | Прими как «космическую волю» + действуй с верой |
| Важная лекция/встреча | Идеация на Бабу 1–2 мин, затем «поток» |
| Языковой барьер | Взаимное обучение, смирение, практика |
| Мирское vs призвание | Проверь «зов», решись, доведи |
| Преследование/тюрьма | Садхана + мораль + знания; сопротивление |
| Нужно доверие сообщества | Служение (школы, медицина) → инициации |
| Срыв плана | Ретрит/обучение; «волна любви» |
| Человек «провалил» первый контакт | «Дверь всегда открыта» |
