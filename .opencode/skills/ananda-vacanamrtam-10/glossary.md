# Глоссарий — Ánanda Vacanámrtam Part 10

**Ájiṋá cakra / sahasrára cakra** — гипофиз / шишковидная железа (активируются táńd́ava).

**Akartá Puruśa** — не-деятель; свидетель (А́nanda Sútram).

**Avarńa** — бесцветный (Parama Puruśa вне цвета/tanmátras).

**Bharga** — божественный свет (bha = освещает, ra = красит блаженством, ga = движение).

**Bhát́iyáli** — песня при движении вниз по течению (без усилий).

**Bhúr/bhuvah/svah** — три «vyáhrti» = семь lok.

**Dáyabhága** — бенгальская система наследования (Jiimútaváhana): отец единственный владелец.

**Diikśá (Vaedikii/Tántrikii)** — молитва «направь ум» / направление действия.

**Durgá Saptashatii** — 700 стихов из Márkańd́eya Puráńa.

**Eka avarńo bahudhá shakti yogád** — единый бесцветный → множественность через shakti.

**Gáyattrii** — метр (8 метрических единиц/строку), не имя мантры.

**Gondwanaland** — древний континент; Ráŕh (~300 млн лет ⚠).

**Hari / Hara** — созидание / разрушение; мир через clash (Hariharátmaka).

**Játashatru** — прирождённый враг (тигр/ядовитая змея/скорпион; нет греха в защите).

**Kalá / kást́há / parákást́há** — систематический поток / линейный / финальное состояние.

**Kást́há** — укорочение kalá (линейный поток).

**Kalyáńa** — прогресс в двух сферах (физ./псих./дух.).

**Khoyái** — эрозия красной почвы (Ráŕh; у Bolepur).

**Korta / kartá (headman)** — наблюдатель на церемонии; аналогия akartá.

**Kśema** — прогресс в одной сфере; Kśemauṋkarii — имя Prakrti.

**Lamphan / ullamphan** — прыжок с контактом / с отрывом (táńd́ava).

**Márkańd́eya Puráńa** — источник Durgá Saptashatii.

**Máyá / Prakrti** — творческий акт / создающая потенция.

**Mitákśará** — североиндийская система наследования (Vyása/Manu).

**Mrga / mrgacarma** — лесные животные / шкура (не только олень).

**Nandana vijiñána** — эстетическая наука (блаженство выражений ума).

**Paiṋcagaoŕii / Paiṋcadrávid́ii** — 10 признанных брахманских классов.

**Paramacakśuśmána** — Supreme Witnessing Entity.

**Parákást́há** — финальное состояние (край греха/жадности).

**Phala = parińáma** — реакции после завершения действия.

**Phalasákśiibhútah** — свидетельствование результатов.

**Puruśa** — pure shete (лежащий в городе тела, пробуждённый).

**Ráŕhbhúm** — земля laterite (красной) почвы; 12 bhúm-княжеств.

**Sákśii / sákkhii** — Rgvedic / Yajurvedic произношение.

**Savitr Rk** — 62-я rk Rgveda III.10 (Vishvámitra), не «Gáyattrii Mantra».

**Shubha** — прогресс во всех трёх сферах.

**Tańd́ula / tańd́u** — рис / прыгать (зёрна прыгают).

**Táńd́ava** — прыжковый танец Sadáshiva; для мозга; запрещён женщинам.

**Tanmátra** — инференциальное выражение вибрации (звук/осязание/форма/вкус/запах).

**Tryáhasparsha** — встреча трёх tithiis в 24 часа (лунный календарь).

**Uha / avoha** — crest / trough (kalá).

**Ujániyá** — песня при движении вверх по течению (борьба).

**Varńa** — цвет = внешняя манифестация внутреннего; псих. цвета классов.

**Varńa vyávasthá** — система «цветов» (не каста).

**Varśa** — дождь/земля/год; Bhárata Varśa = «кормящая земля» (bhr).

**Viḿshottariiya / aśt́ottariiya** — астрология (120 / 108 лет).

**Vishvámitra** — автор Savitr Rk (грамматически «неправильно»).

**Vyághracarma** — тигровая шкура (= mrgacarma).

**Vyatireka** — стадия избирательного контроля.

**Yatamána** — стадия упорства (kalá→kást́há).

**«Na svargo na rasátala»** — нет рая/ада как фантазий (А́nanda Sútram).

**«Ámi Nader mate muti»** — вызов Navadwip-астрологам (двузначная фраза).
