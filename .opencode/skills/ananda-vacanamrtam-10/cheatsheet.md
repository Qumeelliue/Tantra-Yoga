# Чит-шит — Ánanda Vacanámrtam Part 10

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Молиться/практика | Savitr Rk: метр gáyattrii, адресат Savitá, цель — направить ум |
| После Tantric initiation | Savitr Rk не нужен: путь получен |
| Одно имя vs много | «1» собирает ум; «2+» дробит; Ekbuddhi |
| Славить божеств | Одно имя, одно направление (не перечень с «простите, если кого забыл») |
| Цвет/каста | Смотри ментальный цвет, не касту; Parama Puruśa — avarńa |
| Множественность мира | Из Prakrti/Máyá (bahudhá shakti); секрет внутренний |
| Действие без цели | Напрасный труд (лодка вниз по течению) |
| Препятствия | Друзья: выпрямляют kalá→kást́há (yatamána) |
| Контроль избирателен | Vyatireka: знай свои слабости, не раскрывай |
| Слабость великого человека | Влияй через неё (еда, вкусы) — этично |
| Táńd́ava | Упражнение для мозга (железы); запрещено женщинам |
| Борьба/смерть | Не избегай: готовь контрудар; «immortality через war с death» |
| Вменяемость действия | Только сознательное; случайное — не грех |
| Прирождённые враги | Játashatru: нет греха в защите (тигр/змея/скорпион) |
| Вегетарианство | Убеждай, не принуждай |
| «Рай/ад» | Фантазии: переживание требует тела (Na svargo na rasátala) |
| Плоды добрых дел | Отдай Lord (Юдхиштхира); не желай |
| «Mahátmá»-лесть | Обман/сикофанство; átmá ни добра, ни зла |
| Скрыть мысли | Нельзя: átmá записывает всё (две птицы) |
| Злые мысли | Вредят тебе самому (реакции через тебя) |
| Груз са́мска́ров | Нужно подходящее тело (кот/собака/человек) |
| Путь мудрых | Имя Krśńa + kiirtana; guru mantra при работе |
| Приостановленный ум | Ложная смерть (оспа/укус); раньше — тела по воде |

## А́nanda Sútram (Puruśa)

`Puruśa akartá phalasákśiibhutah bhávakendrasthitah guńayantrakashca.`
Пять сут: Puruśa не деятель · свидетель · в ядре guńas · контролирует guńas · энергия через guńas

## Уровни прогресса (ch03)

Shubha = все 3 сферы · Kalyáńa = 2 сферы · Kśema = 1 сфера

## Kalá-модель (ch04)

uha/avoha (kalá) → kást́há (укорочение) → parákást́há (финал)

## Две птицы (ch10)

Dvá suparńá: одна вкушает плод (ум), другая свидетельствует (átmá)

## Произношение (ch09)

- sákkhii (Yajurveda) / sákśii (Rgveda)
- ja→ya в середине слова (joga, biyoga, samaya); jantra (не yantra); jádevii (не yádevii)
- d́a→ŕa в середине (áśáŕha, но d́háka; áŕhambar)

## Кармические шлоки (ch10)

`Ná bhuktaḿ kśiiyate karma...` — реакции переживаются (без исключений)
`Yatha louhamayae páshae...` — цепи добрые/злые — всё равно цепи
`Phalalobhe karmakare lubdha...` — действующий ради плода — торговец
`Samarpańa kari sarva Ishvarer t́háinn` — сдаю всё Brahma
