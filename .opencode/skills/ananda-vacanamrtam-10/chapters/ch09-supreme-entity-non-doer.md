# Chapter 9: The Supreme Entity – the Non-Doer

*Дискурс 9, 22 апреля 1979, Калькутта.*

## Core Idea

`Puruśa akartá phalasákśiibhutah bhávakendrasthitah guńayantrakashca` (А́nanda Sútram). Puruśa — не деятель: как каталитический агент и headman. Ум совершает; átmá свидетельствует. Приостановленный ум — ложная смерть; нужна подходящая форма (реинкарнация); путь — имя Krśńa и kiirtana.

## Frameworks Introduced

- **А́nanda Sútram**: Puruśa не контролирует энергию; установлен в ядре guńas, контролирует их; энергия исходит через guńas; свидетель всего.
- **Произношение**: Puruśa akartá (без visarga перед a); sákkhii (Yajurveda) / sákśii (Rgveda); jantra/yantra: ja→ya в середине (joga vs biyoga; samaya); jádevii (не yádevii); d́a→ŕa в середине (áśáŕha vs d́háka, áŕhambar). Vidyasagar ставил точку под ya.
- **Puruśa** = pure shete (лежащий в «городе» тела, пробуждённый: бенгали shoyá = лёжа без сна ≠ хинди soná = спит) / purasi (перед тобой); purohitah = purasi hitam karoti. Vasu/vástu/vastu/pura этимология.
- **Каталитический агент**: помогает химической реакции без изменения (золото в makaradhvaja возвращается). **Headman (kartá)**: на церемонии наблюдает, не служит, но его присутствие всё держит.
- **Знание/восприятие**: глаз + нерв + свет, но без átmá не видит. Приостановленный ум (оспа, змеиный укус) — ложная смерть; раньше тела пускали по воде. Átmá свидетельствует и приостановленный ум («свет видит пустую сцену»).
- **Внутренний монолог записывается** (tape-recording): злые мысли вредят себе (реакции через самого себя). 
- **Реинкарнация**: ум не вернётся к норме без подходящего тела (золотых дел мастер — свой молоток); по са́мска́рам — тело (кот/собака/обезьяна/человек; жадный филантроп-«газетчик» — кот). Mind под rajoguńa ищет подходящую базу; может быть другая планета.
- **Средство**: имя Krśńa/Harinám + kiirtana (`Krśńa nám Harinám baŕai madhur, Yei jan Krśńa bhaje se baŕa catur`); два блага: отвращение к низким действиям + Lord в аду = рай. Vidyapati: «Mati rahe tuyá parasauṋga» (пусть ум останется в Тебе). Guru mantra в уме при любой работе; kiirtana громко — заняты язык/уши/ум.

## Key Concepts

- **Puruśa akartá** — не деятель (А́nanda Sútram).
- **Каталитический агент / headman** — аналогии не-деятеля.
- **Sákśii Puruśa** — свидетель.
- **Приостановленный ум** — ложная смерть.
- **Реинкарнация по са́мска́рам** — подходящая форма.
- **Harinám / kiirtana** — путь мудрых.

## Mental Models

- «Присутствие необходимо, действие — нет (катализатор)».
- «Ум совершает; átmá записывает».
- «Внутренний монолог слышен; злые мысли бьют тебя».
- «Нужно подходящее тело для возврата к норме».

## Anti-patterns

- **Произносить sákśii вместо sákkhii** — Yajurvedic стиль (по правилам).
- **Считать человека «мёртвым» при приостановленном уме** — ложная смерть.
- **Думать, что можно спрятать мысли** — всё записывается.
- **Славить «Mahátmá»** — лесть/обман (ch10 развивает).

## Worked Example

Пример-кот: жадный филантроп ждёт имени в газете (propensity of greed); «забывает» другие новости; после смерти — кот, потому что тело кота даёт возможность утолить жадность (молоко/рыба). Грех/добродетель — через подходящую форму.

## Key Takeaways

1. Puruśa — akartá, каталитический агент и headman.
2. Ум совершает; átmá свидетельствует (внутренний монолог записывается).
3. Приостановленный ум — ложная смерть; нужна подходящая форма.
4. Реинкарнация по са́мска́рам (кот/собака/человек; другая планета).
5. Путь: имя Krśńa + kiirtana; guru mantra при работе.
6. Злые мысли вредят самому себе.
