# Chapter 2: The Supreme Entity Transcends All Colours

*Дискурс 2, 11 апреля 1979, Калькутта.*

## Core Idea

«Один» = собрать все пропенситы в точку; множественность дробит ум. Parama Puruśa — avarńa (без цвета), творец всех цветов. Цвета — внешние проявления; кастовая дискриминация отвергается.

## Frameworks Introduced

- **Одноточечность**: «один» = все пропенситы в одной точке, нет места другим; «два/три/четыре» дробят ум. Для Parama Puruśa — только «1». Пример родственника: «Победа Kálii Kálighát, победа Kálii T́han T́haniá, победа Táraknáth, победа Vaidyanath, извините если кого забыл» — ум скачет, сосредоточения нет.
- **Varńa (цвет)**: из солнечного света (VIBGYOR; бенгали beniiáshkalá). Цвет — внешняя манифестация внутреннего: зелёное сияние = интеллект, красное = жестокость; каждый цвет — характеристика, психическая тенденция.
- **Псих. цвета классов**: vipra/intelligentsia — белый; kśatriya — красный; vaeshya — жёлтый; shúdra — чёрный. Это varńa vyávasthá — но не кастовая дискриминация; только ментальный цвет считать.
- **Avarńa**: Parama Puruśa без цвета, вне цвета; Он — творец, потому бесцветен. `Varńáshramábhimánena shrutidásye bhavennarah; Varńáshrama vihiinasca varttate shrutimúrdhańi.` — гордящийся кастой — раб Vedas; поднявшийся — выше Vedas. Принявший Parama Puruśa — уникален (eko avarńo).

## Key Concepts

- **Одноточечность** — единственно возможное для постижения.
- **Varńa** — цвет как внешняя манифестация психики.
- **Avarńa** — бесцветный творец.
- **Varńa vyávasthá** — система «цветов» ≠ каста.

## Mental Models

- «Множество имён/направлений — рассеяние; одно — сила».
- «Смотри на ментальный цвет, не на касту».
- «Творец вне творения: Он без цвета».

## Anti-patterns

- **Славить множество божеств вперемешку** — ум не сосредоточен.
- **Кастовая гордость** — рабство Vedas.
- **Считать цвет кожи/касту** — только психический цвет.

## Worked Example

Пример-родственник: после купания перечисляет Kálii разных мест + Táraknáth + Vaidyanath и «простите, если забыл кого». Означает ум движется к Kálighát И T́han T́haniá — концентрация невозможна. Одно имя/одна точка — путь.

## Key Takeaways

1. «Один» собирает пропенситы; «два+» дробят ум.
2. Цвет — внешнее проявление внутренней тенденции.
3. Псих. цвета: vipra-белый, kśatriya-красный, vaeshya-жёлтый, shúdra-чёрный.
4. Parama Puruśa — avarńa (вне цвета).
5. Кастовая дискриминация отвергнута; считай ментальный цвет.
