# Chapter 8: Táńd́ava Dance – What and Why?

*Дискурс 8, 20 апреля 1979, Калькутта.*

## Core Idea

Táńd́ava — прыжковый танец (ullamphan), введённый Sadáshiva: стимулирует железы → мужество, активирует шишковидную/гипофиз → память и мозг; запрещён женщинам. Символика: борьба с борьбой через Hari/Hara.

## Frameworks Introduced

- **Этимология**: tańd́u = прыгать; tańd́ula = рис (зёрна прыгают при обмолоте); dheńki (неарийская молотилка, ногой) vs udukhala (арийская, руками). **Ullamphan** (прыжок с отрывом) vs lamphan (с контактом); táńd́ava = ullamphan.
- **Зачем**: лимфатические/эндокринные железы выделяют гормоны → manliness/мужество. **Запрещено женщинам** (стимулирует мужественность). Активирует pineal (sahasrára) и pituitary (ájiñá) → память, мозг; **единственное физическое упражнение для мозга**.
- **Символы в руках**: кинжал (жизнь/борьба) + череп (смерть); днём змея (левая), ночью d́ambaru/факел (правая). Hari (созидание) vs Hara (разрушение) — движение через clash (Hariharátmaka); бутон→цветок (Hari) → увядание (Hara).
- **Одежда**: тигровая шкура (vyághracarma = mrgacarma; mrga = все лесные животные, не только олень; shákhámrga = обезьяны) или красное (mutative); **автор советует оранжевое** ⚠ (footnote редакторов).
- **Борьба**: жизнь — struggle; не уклоняйся; готовь контрудар; сила — для коллективного блага. Смерти не бояться: «immortality waging war against death»; Sadáshiva — «death of death». Стих `Mrtyu tore dive háná... Rudrer prasád`.
- **Три пути Tantra**: dakśiń, váma, madhyama; в буддизме — только middle path.

## Key Concepts

- **Tańd́ula / ullamphan** — прыгающий рис / прыжок с отрывом.
- **Железы → manliness** — причина запрета женщинам.
- **Мозг** — táńd́ava единственное его упражнение.
- **Hariharátmaka** — мир через столкновение созидания/разрушения.
- **Mrgacarma** — шкура лесного зверя (не только олень).

## Mental Models

- «Жизнь — борьба; не избегай, готовь контрудар».
- «Упражнение для мозга — táńd́ava».
- «Hari творит, Hara разрушает; движение — через clash».

## Anti-patterns

- **Боязнь столкновений** — им нельзя избежать; готовься.
- **Táńd́ava для женщин** — стимулирует мужественность, запрещено.
- **Считать mrga = олень** — все лесные животные.

## Worked Example

Пример-бутон: на растении бутон → цветок распускается (спорт Hari); лепестки вянут (спорт Hara). Мир движется через Hariharátmaka; индивид идёт через struggle, ничего не боясь.

## Key Takeaways

1. Táńd́ava = ullamphan (прыжок с отрывом), от tańd́u (прыгать).
2. Стимулирует железы → мужество; запрещён женщинам.
3. Активирует pineal/pituitary; единственное упражнение для мозга.
4. Кинжал/череп — борьба жизни против смерти.
5. Hari и Hara — созидание/разрушение; движение через clash.
6. Не бойся борьбы и смерти — «immortality через войну с death».
