# Chapter 5: The History of Bengal – 1

*Дискурс 5, 15 апреля 1979, Калькутта.*

## Core Idea

История Бенгалии как бленда трёх цивилизаций: Ráŕh (Gondwanaland), Гангетической и Монгольской (Brahmaputra). География речных долин формирует общество; Бенгалия — граница Jambudviipa/Suvarńadviipa; особые соц. системы (Dáyabhága) и солнечный календарь.

## Frameworks Introduced

- **Varśa** = дождь/земля/год. Jambudviipa (Центральная Азия → Бирма); **Bhárata Varśa** = пригодная для жизни часть (bhr = кормить; не по царю Bharata). Tibet = Kiḿpuruśa Varśa (мужчины без бород — «kiḿ puruśah?»). Suvarńadviipa = Бирма.
- **Цивилизации по речным долинам**: 500 миль вдоль — похожие; 40 миль вглубь — другие. Гангетическая долина (Gauṋgottarii → Gauṋgáságar).
- **Gondwanaland** (~300 млн лет ⚠): Ráŕh — земли к западу; реки (Suvarńarekhá, Kaḿsávatii, Damodara, Ajaya, Mayurákśii); Гималаи позже (вулканическое землетрясение) → аллювиальные равнины; восточная часть Ráŕh из аллювия. Древнейшая почва: Manbhum/Bankura/Midnapur/зап. Burdwan/Birbhum. Древнейшие рукописи бенгали (Shushunia, Beletoŕ, Abhijiṋána Patra; Shri Krśńa Kiirtana Baŕu Cańd́iidása).
- **Бленд**: Ráŕh (Gondwana) + Gangetic + Mongolian (Brahmaputra/Sang Po из Тибета) → Gaoŕiiya цивилизация; **Tantra родилась из бленда**. Aryan-критика в Karma Puráńa (еда рыбы/мяса). Allahabad (1200–1300 лет назад): 10 признанных брахманских классов — Paiṋcagaoŕii (Sárasvat, Gaoŕa, Kányakuvja, Maethil, Nágar) + Paiṋcadrávid́ii (Citpávan, Utkal, Kannad́a, Támil, Traelauṋga); бенгальские Ráŕhii/Bárendra/Dakśinátya Vaedik/Páshcáttya Vaedik — не признаны.
- **Бенгальский характер**: сентиментальность (терпят, потом восстают); массовое принятие ислама/вайшнавизма как реакция на эксплуатацию. Язык ~3500 лет (древняя структура), современный ~800–1000 лет ⚠.
- **Соц. система**: матриархальная основа (идентификация по матери; Khásiyás); наследование дяди по матери — сестринскому сыну (в отличие от севера); married daughter сохраняет связь с родом (ashaoca 3 ночи); **Dáyabhága** (Jiimútaváhana) vs **Mitákśará** (Vyása): отец единственный владелец при жизни, может лишить наследства (на севере сын имеет право с рождения).
- **6 коренных сообществ** (Kaevartta, Máháto, Gop, Namashudra, Rájvaḿshii, Cákmá) — «подсвечник»; «высшие» касты — «лампы» (паразиты). Только Vipra+Shúdra (нет kśatriya/vaeshya); Vaedya = непризнанные брахманы-аюрведисты.
- **Короли не наследственные**: 6 сообществ могли свергнуть; Бенгалия не участвовала в Kurukśetra-войне; всегда воевала с Дели.
- **Календари**: лунный (север; 354–355 дней; ekádashii по зодиаку, tryáhasparsha — пропуск dvádashii) vs солнечный (Бенгалия ~3500 лет; месяц по полнолунию в зодиаке: Vaeshákh от Vishákhá). Солнечный практичен (сельское хозяйство). Viḿshottariiya (120 лет) vs aśt́ottariiya (108). Молодой астролог Vikrampur против Navadwip (утра, «Ámi Nader mate muti»); Jayanta Páńigráhii (Contai); Chandrasekhar Samanta (Orissa); ácárya Bráhmań Bali (после казни Nandakumar). Английский календарь практичен (фиксированные дни), менее научен. Пять частей Бенгалии: Ráŕh, Borin/Barendra, Vauṋga, Samatat́ (позже Murshidabad/Nadia/Jessore/Khulna/24 Parganas/Kolkata), Cattal/Shriibhúmi (Sylhet).

## Key Concepts

- **Bhárata Varśa** — «кормящая земля», не по имени царя.
- **Ráŕh** — древнейшая почва Gondwana.
- **Gaoŕiiya бленд** — Ráŕh + Gangetic + Mongolian.
- **Paiṋcagaoŕii / Paiṋcadrávid́ii** — признанные брахманы.
- **Dáyabhága** — система наследования (отец единственный владелец).
- **Солнечный календарь** — практичный, бенгальский.

## Mental Models

- «Цивилизация течёт по речным долинам».
- «Смешение цивилизаций рождает новое (Tantra)».
- «География формирует психологию народа».
- «Корни — в 6 коренных сообществах, не в «высших» кастах».

## Anti-patterns

- **Называть Бенгалию по «царю Bharata»** — имя от bhr (кормить).
- **Верить в «высшие» касты как корни** — они — паразиты на 6 коренных.
- **Считать лунный календарь практичным** — для урожая нужен солнечный.

## Worked Example

Пример-наследование: в северной Индии имущество дяди по матери идёт родственникам отца (не сестринским сыновьям); в Бенгалии — сестринскому сыну (другая линия). Демонстрирует смешанную (матри-патри) систему Бенгалии.

## Key Takeaways

1. Бенгалия — бленд Ráŕh + Gangetic + Mongolian цивилизаций.
2. Bhárata Varśa = «кормящая земля» (bhr), не имя царя.
3. Древнейшая почва/рукописи — запад Ráŕh.
4. Tantra родилась из культурного бленда.
5. Dáyabhága: отец владелец при жизни; женщины имеют права.
6. Солнечный календарь практичнее лунного.
