# Chapter 3: Parama Puruśa – the Primordial Cause

*Дискурс 3, 12 апреля 1979, Калькутта.*

## Core Idea

Единый бесцветный (eka avarńo) создаёт множественность через Prakrti/Máyá (bahudhá shakti yogád). Везде где существование — вибрация и tanmátra; Parama Puruśa вне tanmátras. Единственная молитва — righteous intellect (shubha).

## Frameworks Introduced

- **Eko avarńo bahudhá shakti yogád**: единый бесцветный; множественность через shakti. **Prákrta shakti / Prákrta Máyá** — творческая потенция множественности; Prakrti = создающая (pra+kr); в акте творения — Máyá (Máyáshakti); dexterity/plasticity.
- **Tanmátras**: существование ↔ вибрация ↔ tanmátra (звук/осязание/форма/вкус/запах). Varńa — тоже tanmátra. Parama Puruśa — вне tanmátras, бесцветен, вне любых влияний.
- **Почему множественность?** `Varńánekán nihitártho dadháti` — секрет внутренний (nihitártha); действие может быть для Его joy (наше суждение); причина известна только Ему.
- **Vaedika молитва**: единственная — «направь наш интеллект» (dhiyo no pracodayát); цель — pinnacled intellect, контакт с nucleus. `Sa no buddhyá shubhayá saiṋjunaktu` — соедини ум с shubha.
- **Shubha/kalyáńa/kśema**: shubha = прогресс во всех трёх сферах (физ./псих./дух.); kalyáńa = в двух; kśema = в одной. Kśemauṋkarii — одно из имён Prakrti.
- **Vaedikii vs Tántrikii diikśá**: Vaedika ограничена молитвой; Tántrika даёт направление действия в трёх сферах, помогает достичь fulfilment действием. После Tántrika diikśá не нужен Savitr Rk.

## Key Concepts

- **Eka avarńo bahudhá shakti yogád** — единый → многое через shakti.
- **Prakrti / Máyá** — создающая / акт творения.
- **Tanmátra** — инференциальное выражение вибрации.
- **Nihitártho dadháti** — внутренний секрет творения.
- **Shubha / kalyáńa / kśema** — трёх/двух/односферный прогресс.

## Mental Models

- «Творец вне своего творения (вне tanmátras)».
- «Молитва — одна: righteous intellect».
- «Секрет творения — внутренний; не гадай».

## Anti-patterns

- **Считать Parama Puruśa ограниченным tanmátras** — Он вне них.
- **Гадать о причине множественности** — nihitártho (секрет).
- **Использовать Savitr Rk после Tántrika diikśá** — путь уже дан.

## Worked Example

Пример-подношение: человек мысленно подносит (tava dravyaḿ...) — He принимает без «руки» (внутренний мир). Демонстрирует: всё — в Его уме, знание/действие без органов.

## Key Takeaways

1. Parama Puruśa — eka avarńo; множественность через Prakrti/Máyá.
2. Prakrti создаёт; Máyá = творческий акт.
3. Везде вибрация ↔ tanmátra; Он вне них.
4. Причина творения — внутренний секрет.
5. Единственная молитва: righteous intellect (shubha).
6. Tántrika diikśá — действие; Vaedika — молитва.
