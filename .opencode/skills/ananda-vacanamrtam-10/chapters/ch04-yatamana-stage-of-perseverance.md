# Chapter 4: Yatamána – the Stage of Perseverance

*Дискурс 4, 13 апреля 1979, Калькутта.*

## Core Idea

Прогресс через clash/cohesion; движение — цель. Колебание (uha/avoha) — kalá; её укорочение — kást́há; полное выпрямление — parákást́há. Преобразование kalá→kást́há = yatamána (упорство); препятствия — друзья.

## Frameworks Introduced

- **Kalá/kást́há**: uha (crest) + avoha (trough) = kalá (systaltic фаза); укорочение kalá = kást́há; без дальнейшей эволюции — прямая линия = parákást́há (финальное состояние; parákást́há греха/жадности). `Kalá kaśt́hádi rúpena` (Paramá Prakrti в виде kalá/kást́há). Durgá Saptashatii = 700 стихов из Márkańd́eya Puráńa (Shrii Shrii Cańd́ii).
- **Метафора лодки**: цель обязательна (без цели труд напрасен; вниз по течению — потеря берега; вверх — напряжённый труд). **Bhát́i** (вниз): без усилий, bhát́iyáli-песня «bandhure». **Ujániyá** (вверх): борьба против течения, «hñei hñei», песни с акцентом (Káiye dhán kháilore...).
- **Nandana vijiñána** (эстетическая наука): блаженство от выражений ума в разных состояниях; влияние среды: темнота vs лунная ночь; shava sádhaná в новолуние (не в полнолуние).
- **Yatamána** (упорство): kalá→kást́há преобразование; обычный человек остаётся с kalá; упорный — постепенно выпрямляет.
- **Препятствия — друзья**: без внешних преград kalá не преобразуется; если душат/препятствуют (язык, семья) — противление ускоряет трансформацию. Не сдавайся препятствиям.

## Key Concepts

- **Uha/avoha** — crest/trough (kalá).
- **Kalá → kást́há** — систематический → линейный поток.
- **Parákást́há** — финальное состояние.
- **Bhát́iyáli / ujániyá** — песни вниз/вверх по течению.
- **Nandana vijiñána** — эстетическая наука.
- **Yatamána** — стадия упорства.

## Mental Models

- «Без цели труд напрасен; движение — единственный конец».
- «Препятствия — друзья: они выпрямляют поток».
- «Среда формирует выражение: выбирай обстановку».

## Anti-patterns

- **Плыть без цели** — унесёт вниз по течению.
- **Избегать препятствий** — kalá не выпрямится.
- **Петь «bandhure» в борьбе** — ujániyá требует усилия.

## Worked Example

Пример-лодка: вниз по течению — sail несёт, есть время петь длинно «bandhure...»; вверх — борьба, «hñei hñei», нет времени. Разные песни (bhát́iyáli/ujániyá) отражают разный труд и среду.

## Key Takeaways

1. Прогресс через clash/cohesion; цель обязательна.
2. Kalá (колебание) → kást́há (линия) → parákást́há.
3. Yatamána — стадия упорства (преобразование потока).
4. Препятствия ускоряют трансформацию — не избегай.
5. Среда влияет на выражение (Nandana vijiñána).
