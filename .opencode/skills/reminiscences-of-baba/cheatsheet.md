- **Gotheejii** — марги, получивший «PC-гаранд» перед отъездом Бáбá.

- **Dr. Sunil Sen, Dr. A.K. Vardhan, Dr. B.R. Sengupta** — врачи Бáбá.

## Быстрые правила

| Ситуация | Правило |
|---|---|
| Близость к гуру | Послушание + служба; требование не работает |
| Строгость гуру | Это забота: цель — дисциплина и исчерпание самскар |
| Желание не исполнилось | «Перед отъездом я всё улажу» — жди, продолжай работать |
| Садхана «не идёт» | kiirtana + svädhyäya + satsaunga |
| Правила (Yama/Niyama) | Без послаблений; «минимум» — запас (16 вместо 12) |
| Кризис/гонения | «Мужество побеждает»; «я всё улажу, когда выйду» |
| Забота о природе | Каждый привозит растение; редкие виды сохраняются |
| Величина программы | «Когда Бáбá даёт программу, её начинают сразу» |
| Нарушители правил | Правила едины для всех; потом — сострадание и шанс |
| Служащие тебе | Запоминай, благодари, исполняй их желания |
