# Читшит — правила решений по Caryácarya Part 1

## Церемонии

| Ситуация | Правило |
|---|---|
| Имянаречение ребёнка | 6 мес–1 год, ≥5 маргов, мантра madhu, вода+благословения, имя дают сообща; пир — по средствам, не в долг |
| Начать инициацию ребёнку | Náma Mantra с ~5 лет от родителей/опекунов; не больше 4 человек за раз |
| Взять инициацию в 12+ | Только от ácárya/táttvika/dharmamitram; бесплатно |
| Свадьба | ≥10 человек, свободная воля обоих, запрет родства в 3 поколениях, без приданого, без долгов |
| Развод | Только за безнравственность/безответственность/жестокость; 5 ответственных лиц + 6 месяцев пересмотра |
| Поездка в «неблагоприятный день» | Игнорируй звёзды; освяти путь guru mantra |
| Похороны | По воле усопшего; по умолчанию кремация; расходы и логистика — общество, не семья |
| Shráddha | Для успокоения живых; траур ≤12 дней; ácárya + ≥5 человек |

## Дисциплина

| Ситуация | Правило |
|---|---|
| Нарушил Yama-Niyama | Признайся ácárya в тот же день/на dharmacakra; наказание — служение, никогда деньги |
| Тяжёлое обвинение | Письменно → трибунал ácárya (≤3) за неделю → апелляции; ложный обвинитель — то же наказание |
| Искупление вины | Вдохнови 10 человек на духовный путь → вина снята |
| Наказание семье виновного | Нельзя — наказывается только виновный |

## Экономика

| Ситуация | Правило |
|---|---|
| Сколько отдавать обществу | Минимум 1/50 дохода на общественное служение |
| Наследование | Сыновья и дочери поровну; вдова — имущество мужа (пожизненно, без передачи); имущество женщины — всем её детям |
| Доходы уровней организации | 7/8 на местное благо, 1/8 вышестоящему |
| Искусство ради денег | Запрещено; послабление только при крайней нужде с разрешения ácárya |
| Эксплуататор богатства | Образование → давление обстоятельств → духовное руководство; только с любовью к людям |

## Организация

| Ситуация | Правило |
|---|---|
| Кто избирает bhukti pradhána / upabhukti pramukha | Sadvipras из своих рядов, на 3 года; обязателен образованный семейный человек |
| Один человек в советах | Только в одном совете; советы — 3–7 членов |
| Возрнаградить лидера | Титул за измеримый результат на полугодие; 4 полугодия → постоянный, но пост — оставить |
| Спорный вопрос в Marga | Central Purodhá Board: единогласно → связывает всех; иначе большинство; равенство → голос председателя (финал) |
| Сертификат учителя | Экзамен 5 экзаменаторам; отмена — советом; апелляция по цепочке Táttvika→Ácárya→Purodhá |

## Социальное поведение

| Ситуация | Правило |
|---|---|
| Приветствие равных/всех | Namaskára (ладони, межбровье) — всем, без поклона |
| Приветствие высокочтимого | Carańa sparsha pranáma — только тем, кого уважаешь |
| Полный прострация | Только Márga Guru |
| Рукопожатие / kurnish | Запрещены (гигиена / символ рабства) |
| Нищему | Давай еду, не наличные (не поощряй попрошайничество) |
| Женщинам вне дома | Простая приличная одежда, тело прикрыто; послабления на фестивалях/с охраной |
| Подарок в ответ на приглашение | Цветы (не обязательно); при всех — антисоциально, дари наедине/в другой день |

## Фестивали (ядро)

| Ситуация | Правило |
|---|---|
| Любой праздник | Должен давать физический рост + умственное развитие + духовный прогресс; обязательны коллективная Iishvara Prańidhána и dharmacakra |
| Ánanda Púrńimá | День рождения Саркара: купание, 2 медитации, трапезы, детский спорт, táńdava-шествие |
| Sháradotsava | 6 дней с дневными программами (дети/общество/искусства/музыка/Vijayotsava) |
| Vasantotsava (Dol) | Утром краски среди ровесников; после полудня медитация с Varnárghyadána; мужчины и женщины краски не обменивают |
