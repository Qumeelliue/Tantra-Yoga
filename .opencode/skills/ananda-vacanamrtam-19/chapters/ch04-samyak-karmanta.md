# Глава 4: Samyak Karmánta (Perfect Finish)

*Дискурс от 22 июня 1980, Mokama.*

## Core Idea

Karma (от корня `kri` + суффикс `man`) — относительное изменение положения объекта; это величайшее из человеческих качеств — человек признаётся по качеству своих действий. **Samyak karmánta** — одна из восьми шил буддизма: «совершенное завершение» — всякое начатое дело должно быть доведено до конца безупречно, без оставшихся дефектов. Человек не может всё делать сам — бери помощь, но доводи до совершенного финиша.

## Frameworks Introduced

- **Лингвистический слой (этимология)**: корень `kri` + суффикс `man` = karma; суффиксы (pratyaya) и префиксы (upasarga) меняют смысл корня. Примеры: patha → pathitam (книга прочитана), pathita (учу), pathitum; бенгали korchi (делаю сам) / karacchi (делаю через других); хинди karná/karáná/karuána. Вибрационная теория: восприятие «белого» даёт акустическую вибрацию `dhab, dhab, dhab`, откуда `dhabala` (белый) — слово как «рецептакул» глагола.
- **Karma = изменение положения**: перемещение объекта из одного места в другое за время; способность, производящая транспортировку, — karma. Karma — величайшее из качеств человека; распознавание и признание — по качеству действий.
- **Ограниченность человека и сотрудничество**: задач бесчисленно, возможности ограничены — нужна кооперация. Пример: утолить жажду — не копать колодец самому, а взять воду из чьего-то колодца или помощь других. «Или сделай сам, или добейся, чтобы сделали, — но делай». Правило универсально.
- **Витальность и действие**: невозможно быть энергичным и бездеятельным; невозможно действовать без витальности. Идеальный человек исполняет свой долг безупречно и привлекает усилия других, когда нужно.
- **Samyak karmánta**: одна из восьми шил буддизма — «совершенное завершение работы»: что бы ни было начато, заверши «методно и без изъянов», не оставляя дефектов; финиш всегда совершенен. Повторяющуюся работу никто не любит — отсюда потребность в участии; методы различаются; превосходство человека — в эффективности методов.

## Key Concepts

- **karma** — действие как относительное изменение положения (корень kri + man).
- **pratyaya / upasarga** — суффикс / префикс (изменяют смысл корня).
- **dhabala** — «белый» (от акустического корня dhab) — иллюстрация теории вибраций.
- **Samyak karmánta** — совершенное завершение (восьмая шила буддизма).
- **кооперация** — сотрудничество, т.к. человек ограничен.
- **витальность (vital energy)** — энергия жизни; без неё действие невозможно.

## Mental Models

- «Думай о действии как о механике перемещения: сделал работу = изменил положение; остальное — качество исполнения».
- «Думай о словах как о рецептакулах глаголов: за именем стоит движение (вибрация)».
- «Думай о задачах через шилу: начато = заверши безупречно (Samyak karmánta)».
- «Не всё можно сделать самому — бери помощь, но держи контроль до совершенного финиша».

## Anti-patterns

- Бросать начатое «на полпути» — нарушение Samyak karmánta.
- Отказываться от помощи (сделать всё самому) — отрицание ограниченности человека.
- Доводить «через других» без контроля качества — финиш должен быть совершенным.
- Считать действие «сделанным», если положение изменилось «в целом» — качество и безупречность обязательны.
- Игнорировать рутину «не люблю повторяющееся» — отсюда потребность в участии, а не в отказе.

## Worked Example

Автор разбирает происхождение karma: корень kri + суффикс man; поясняет функции суффиксов/префиксов на примерах чтения (patha) и личных/каузативных форм (korchi/karacchi; karná/karáná/karuána). Затем теорию вибраций (белый = dhab). Далее: человек ограничен — пример с колодцем (не копаешь сам, берёшь воду с чужого колодца/помощи). Вывод: karma — величайшее качество; задача признаётся по качеству исполнения; Samyak karmánta = совершенное завершение без дефектов (восьмая шила).

## Key Takeaways

1. Karma = относительное изменение положения; способность транспортировки.
2. Слова — рецептакулы глаголов (вибрационная теория); суффиксы/префиксы меняют смысл.
3. Человек ограничен — кооперация обязательна, но контроль за качеством остаётся.
4. Человек признаётся по качеству действий.
5. Samyak karmánta: начатое доводи до безупречного завершения (восьмая шила).
6. Идеальный человек выполняет свой долг безупречно и привлекает усилия других при необходимости.
