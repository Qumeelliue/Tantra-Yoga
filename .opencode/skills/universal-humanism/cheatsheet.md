# Читшит — правила решений по Саркару (Universal Humanism)

## Социальный анализ

| Ситуация | Правило |
|---|---|
| Определить, кто у власти | Спроси: какой класс/ресурс незаменим? (сила → интеллект → капитал → число работников) |
| Класс доминирует | Он эксплуатирует остальных → нужен независимый «страж» (садвипра), не смена доминанта |
| Кто поднимется следующим | Не большинство по доходу, а випра-/кшатрий-ментальные работники (vikśubdha shúdras) |
| Проверить равенство | Разнообразие — закон природы; цель — равенство прав, не вещей |

## Прогресс и цель

| Ситуация | Правило |
|---|---|
| Это прогресс? | Найди скрытый минус того же размера; если есть — не прогресс |
| Цель утолит? | Конечная цель разожжёт аппетит; бесконечное утоляет только Бесконечное |
| Dharma человека/системы | Dharma = природа. Огонь жжёт; человек ищет Космическое Сущее |

## Экономика и справедливость

| Ситуация | Правило |
|---|---|
| Распределение богатства | Минимум эпохи гарантируется всем; излишек — по заслугам; разрыв сужается |
| Ресурсы | Общее достояние; накопление — только с одобрения коллектива |
| Механизация | В коллективной экономике — благо (меньше труда, больше процветания) |
| Недовольство эксплуатацией | Давление обстоятельств + психо-духовное образование; не месть |
| Мир | Sentient peace (правит добро) защищается силой; static peace (правит зло) — нет |

## Правосудие

| Ситуация | Правило |
|---|---|
| Как наказывать | Корректирующе, не карательно; тюрьма — лечебница |
| Преступник | Классифицируй по корню: природа / привычка / среда / бедность / слабость момента |
| Сомнение в вердикте | Не наказывать |
| Конфликт кодексов | Моральный кодекс выше уголовного |
| Добро/зло | Относительны; имморально то, что эксплуатирует другого |

## Идеология и теория

| Ситуация | Правило |
|---|---|
| Оценить идеологию | Чем шире круг привязанности (земля→группа→люди→всё сущее), тем лучше |
| «Изм» или универсализм? | Изм делит; универсализм объединяет; неогуманизм — не изм |
| Теория сработает? | Выросла из практики? Учла время-место-личность? Не лицемерие ли это? |
| Выживет ли группа? | Проверь шесть факторов: идеал, практика, теория, братство, литература, лидер |

## Быстрые сигналы («tells»)

- Кандидат набрал <50% и «прошёл» — демократия требует проверки популярности за/против.
- Система обещает «полное равенство» — противоречит закону разнообразия (сутра 5-8).
- Реформа повышает зарплату и компенсирует налогами — не экономический прогресс.
- «Служи по способности, получай по потребности» — утопия (сутра 5-10).
- Религия заявляет «мы избранные» — communalism, а не братство.
- Богатство без использования — «враг общества»: деньги ценны в обороте, не в накоплении.
- Насилие ради раздачи (Робин Гуд) и отказ от всякой силы — равно провальны.
