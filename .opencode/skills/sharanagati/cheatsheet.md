## Правила решений

| Ситуация | Правило |
|---|---|
| Провал/неудача | Смотри «назначение»: провал у наставника = переадресация |
| Несправедливость/атака | Созидание вместо мести; идеология сильнее ответного удара |
| Наказание/коррекция | «Палка Гуру лечит» — принимай как защиту |
| Давление на коллектив | Единый кодекс сильнее раскола («Разделение не сработает») |
| Суд/спор о принадлежности | Документация (RDS, бюллетени) выигрывает |
| Одиночество/изоляция | Преврати в концентрацию (Джарва) |
| «Мелочь» в задании | Ищи большой смысл (Брахма Камал → сардар) |
| Застой практики | Смени уровень (вишша-йога), не бросай |
| Преемственность после лидера | Правила + консенсус; дверь открыта |
| Трудный проект | Экспертиза + сеть (Бходжпатра) |

## Лестница духовного пути (финал)

Шравана (слушание) → Манана (размышление) → Мантра-кайтанья → Нидидхьясана (погружение) → Слияние/Шаранагати.

## Категории (быстрые таблицы)

**Гуру**: adham (не заботится) / madhyam (следит) / uttama (не оставляет).
**Ученик**: перевёрнутый горшок / горшок с дырой / цельный горшок.
**Стадии принятия идеи**: игнорирование → сопротивление → принятие (Шопенгауэр).

- «Если ты захочешь оставить Меня, Я никогда не отпущу тебя».
- «Иногда Я приближаю, иногда отсылаю; мир не поймёт наших отношений».
- «Я сделал твою работу» (после PC-миссии).
- «Разделение не сработает, все мы следуем одному кодексу» (2003).
- «Шива принадлежит Каши, Кришна — Матхуре, Я — Ананда Нагару».
- «Шаранагати — финальное слово духовности».
- «A.M. Inc. — правовое воплощение Нью-Йоркского сектора под AMPS Central» (Денвер).
- «Дхарма защищает защитника» (Dharmo raksati raksitah).
