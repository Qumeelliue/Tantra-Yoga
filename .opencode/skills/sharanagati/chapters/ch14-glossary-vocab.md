# Глава 14: Глоссарий (гл. 45) — словарь терминов книги

*Официальный глоссарий Ананда Марги из конца книги.*

## Core Idea
Словарь ключевых санскритских терминов (гл. 45): от ачарьи до шудры — база для чтения книги и понимания терминологии Ананда Марги.

## Frameworks Introduced
- **Структура терминологии (по гл. 45)**:
  - **Субъектность**: Ахам/Ахамтаттва (делатель «Я», эго), Махаттаттва («Я есть»), Читта (делатель-«Я», ум-субстрат), Буддхи (интеллект), Атма/Параматма.
  - **Космология**: Брахма (Пуруша+Пракрти), Брахма-чакра (цикл творения через санкару/пратисанкару), Махабхута (5 факторов), Танматра (тонкие объекты: звук, осязание, форма, вкус, запах), Кала (круговой поток), Лока.
  - **Тело/ум**: Чакры (7 плексусов по сушумне), Кундалини/кулакундалини (спящая божественная сила в муладхаре), Коса (слои ума), Индрия (5 сенсорных + 5 моторных органов).
  - **Пракрти**: Саттва/Раджах/Тамах (три гуны), Парама-пракрти, Аварани/Викшепа (силы Майи).
  - **Организация**: Ачарья, Авадхута, Марги, Ананда Марга, Дикша.
  - **Этика**: Дхарма (природа/свойство/духовность), Яма/Нияма, 16 пунктов (контекст).

## Key Concepts
- **Purusottama / Parama Purusa / Paramatman** — центральное сознание / свидетель.
- **Ota yoga / prota yoga** — индивидуальная/коллективная связь с Сущим.
- **Sadguru / Taraka Brahma** — совершенный мастер (контекст книги).
- **Samskara** — реактивные моментумы (фон всех испытаний).

## Mental Models
- «Терминология — не эзотерика, а точная карта (уровни ума, центры, факторы)».
- «Чакры — концентрационные точки, а не мифология».
- «Дхарма = природа/свойство, а не только мораль».

## Anti-patterns
- Переводить термины «народно» без санскрита — теряется точность.
- Путать чакру как «энергетический центр» с концентрационной точкой (по гл. 45).
- Воспринимать «Кундалини» буквально-биологически — это «спящая божественная сила».

## Worked Example
Практический пример «точности терминов»: глаз (индрия) = сам глаз + зрительный нерв + жидкость + участок мозга, где стимул передаётся в эктоплазму (ум-субстрат). Модель: термин описывает весь процесс, а не один орган.

## Key Takeaways
1. Глоссарий — базовый словарь для книги.
2. Чакры/кундалини/танматры — точные термины, не мифы.
3. Дхарма = природа/свойство; Яма/Нияма — этический код.
4. Субъектность (ахам/читта/буддхи) — слои ума.
5. Брахма-чакра — цикл творения/растворения.
