# Глава 3: Туры с Гурудевой (1967)

*Allahabad DMC, тур 1967 (Кашмир, Джайпур, Мумбаи), Lucknow/Thanedhar.*

## Core Idea
1967 — «тур с Гуру»: автор впервые близко к Бабе. Уроки послушания (стакан для воды), стратегические идеи (KAJAHILA), культура обслуживания (холодная вода, розовая кровь) и грандиозная подготовка в Химачале.

## Frameworks Introduced
- **Урок стакана (дисциплина обслуживания)**: Баба отчитал за «стакан из спальни» для купания → урок на всю жизнь: «выполняй порученное совершенным образом и немедленно». «Баба — строгий мастер в практической жизни».
- **KAJAHILA (стратегия по Кашмиру)**: единая административная единица Jammu+Kashmir+Himachal+Ladakh для целостности границы; советы по демографии (браки кашмирских пандитов и догра); «To the Patriots» (книга Бабы); ⚠ не принято властью.
- **Урок розовой крови**: «цвет моей крови — розовый, у всех других — красный; поэтому Я чувствую сильную жару». Рамка: забота о комфорте Гуру = забота о миссии (проверка одеял для работников, холодная вода).
- **«Полевые прогулки» как исторические лекции**: Баба разбирает исторические места, указывает «искажения» (например, тантрический символ у храма Кхир Бхавани) и методы исправления.
- **Социальная инженерия**: DMC-инициатива «не-кашмирка вышла замуж за догра-брахмана» — пример «социальной инженерии» Марги (на фоне KAJAHILA).

## Key Concepts
- **KAJAHILA** — предложенная единая административная единица (акроним регионов).
- **Yuga-Purusa / Mahabharata / Mahavishva** — роль Бабы как «творца эпохи», цель — одно человечество.
- **YMSA → PMSA** — Young Men's Spiritual Association → Progressive Men's Spiritual Association (устав писал автор).
- **AMURT** — служба помощи (рельеф с 1966, засуха Бихар).
- **Juhu beach accident** — авария с Марга Матерью; Баба: «как долго Я мог спасать её».

## Mental Models
- «Каждая деталь обслуживания Гуру — духовная практика».
- «Гуру готовит кадры через постановку задач, а не лекции».
- «Исторические уроки на прогулках — форма наставничества».

## Anti-patterns
- Невнимательность к деталям («стакан») — нарушение доверия.
- Считать предложения Бабы «политическими» — это стратегия целостности.
- Скрывать неудобные темы (авария) — Баба всё видит.

## Worked Example
Кашмир: неделя PC-сессий; Баба на прогулке к храму Кхир Бхавани объясняет искажение тантрического символа; затем — предложение KAJAHILA и советы по бракам; автор внезапно получает выговор за стакан. После Мумбаи DMC — авария с Марга Матерью в Джуху; Баба спокоен: «Я уже спасал её в Праяге».

## Key Takeaways
1. Дисциплина обслуживания — основа доверия.
2. KAJAHILA — конкретный пример «стратегических» советов Бабы ⚠.
3. Полевые прогулки = исторические и стратегические лекции.
4. Роль «творца эпохи»: от Махабхараты к Махавишве.
5. Спокойствие Гуру в кризисе (авария) — модель лидерства.
