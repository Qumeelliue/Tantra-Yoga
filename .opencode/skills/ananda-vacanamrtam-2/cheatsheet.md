# Читшит — Ánanda Vacanámrtam Part 2

## Гуру и благодать

| Ситуация | Правило |
|---|---|
| Кто гуру | Táraka Brahma единственный (gu=тьма, ru=рассеивающий) |
| Ниргуна/Сагуна как гуру | Ниргуна не связан с миром; Сагуна под узами |
| Что такое krpa | Помощь тому, кто её не заслужил |
| Благодать «не доходит» | Твой «зонт тщеславия»; вина не в дожде |
| Как привлечь Его | Силой любви («Бог — моя личная собственность») |

## Знание и prapatti

| Ситуация | Правило |
|---|---|
| Основа бхакти-культа | Prapatti: всё по Космической воле |
| Успех желания | Только при совпадении с Его желанием |
| Мирское знание | Прапта-вакья: относительно (меняется) |
| Знание от Господа | Апта-вакья: абсолютно (Sixteen Points) |
| Джняни против бхакты | Джняни не сдвинет травинку; бхакта может — связью |

## Иишвара и кластеры

| Ситуация | Правило |
|---|---|
| Кто Иишвара | Не затронут klesha/karma/vipáka/áshaya |
| Клеша | Рассинхрон ментальных и нервных пульсаций |
| Пять авидья | avidya, asmita, raga, dvesha, abhinivesha |
| Реакция (vipáka) | При изменении TSP — больше/меньше («с процентами») |
| Ашая | Контейнер; у Него нет контейнера |

## Три Брахмы

| Ситуация | Правило |
|---|---|
| Кшара | Метаморфозное, смертное; медитация огрубляет |
| Акшара (Hara) | Нетленное; занят заботами Кшары |
| Ниракшара (Táraka Brahma) | Контролирует оба; единственный объект поклонения |
| Метод | Абхидхьяна: отозвать пропенситы к Нему |
| Цель | Освобождение от Vishvamáyá |

## Практика

| Ситуация | Правило |
|---|---|
| Карма/тапас/йога/джняна без любви | Бесполезны или вредны (соль любви) |
| Хатха-йога | Опасна; не ведёт к освобождению |
| Тип бхакти | Саттвики (цель — Он Сам), не тамаси/раджаси |
| Пратьяхара | Только с дхараной; отзыв без направления опасен |
| Лестница ума | Пропенситы → citta → ahaḿtattva → mahattattva → Познание |
| Медитация на Субъекте | Думай «Он видит меня» |
| Japa/smrti | Только на Единой Сущности |

## Окружение и этика

| Ситуация | Правило |
|---|---|
| Дурджана | Чей результирующий демерит > твоего мерита (относительно) |
| Садху | Внутренний; белое + «dása»; вегетарианец; поднимает других |
| Пунья/папа | Благо/вред общему делу; делай пунью ahorátram |
| Помнить | Всё преходяще (nityamanityatám) |
| Просить у Него | Не вещи, а Его Самого («Ты будь моим») |

## Быстрые сигналы («tells»)

- Жалоба «мне не везёт» — проверь зонт тщеславия.
- «Столица — X» в старой книге, Y в новой — прапта-вакья, не доверяй слепо.
- Практик без любви «каменеет» — признак хатха-подхода.
- Кто-то «знает, но делает» — абхинивеша, опаснейшая авидья.
- Реакция «равна действию» — миф: TSP меняет сумму.
- Говорят «это естественно» — природа лишь стиль Пракрти, не сущность.
