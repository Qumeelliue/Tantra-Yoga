# Chapter 20: The Difference between Macrocosm and Microcosm

*Дискурс 28 сентября 1978, Patna. Discourse 57 серии.*

## Core Idea

Разница макрокосма и микрокосма — атрибутивная (upádhi), временная, не реальная. Микрокосм состоит из панчакоша-тела, созданного реактивными моментами; по своим желаниям (bhávaná) он получает следующее тело. Стирание атрибутивных уз — и есть садхана.

## Frameworks Introduced

- **Атрибутивная разница**: «Tayorvirodhayam upádhi kalpito...» — разница в атрибутах; атрибуты временны («сегодня есть, завтра нет»). «Páshabaddho bhavejjiivah, páshamukto bhavecchivah» — под путами — jiiva, свободный — Shiva.
- **Происхождение миров**: из связующего влияния Оперативного Принципа на Макрокосм — квинквелементальная вселенная, физический и метафизический миры. Микрокосм — панчакоша-а́тмака тело (малое тело и грубый ум: kámamaya, manomaya, atimánas и др.) — творение реактивных моментумов микрокосма.
- **Закон желаний**: «Yádrshii bhávaná yasya siddhirbhavati tádrshii» — по желанию плоды. Обжора после смерти может получить тело свиньи; мечтающий бегать как олень — тело оленя. Микрокосм создан «по твоим реактивным моментам, по твоим прошлым желаниям».
- **Снятие атрибутов**: убери атрибутивный макрокосм у Парама Пуруши и атрибутивный микрокосм у дживы — разницы нет: джива станет Шивой. Пример: человек + королевство = «царь»; человек + дубинки = «борец»; убери атрибуты — X станет Y. «Стирать атрибутивные узы — садхана, духовная практика».

## Key Concepts

- **upádhi** — атрибутивный признак.
- **paiṋcakośátmaka** — пятикоша-состав микрокосма.
- **yádrshii bhávaná** — закон «по желанию — плод».
- **стирание атрибутов = садхана**.

## Mental Models

- «Думай о себе как о человеке с титулами: корона/дубинки — атрибуты; сними — останется человек».
- «Думай о желаниях как о чертеже будущего тела: чем грезишь, тем и становишься».

## Anti-patterns

- **Считать разницу макро/микро реальной** — она атрибутивна и временна.
- **Культивировать грубые желания** — по закону бхаваны они материализуются в следующем теле.
- **Не практиковать снятие атрибутов** — садхана и есть это стирание.

## Worked Example

*В чём разница между Всевышним и мной? Автор: только в атрибутах. Царь = человек + королевство; борец = человек + дубинки; сними атрибуты — оба просто люди. Так и джива (атрибутивный микрокосм) и Шива (атрибутивный макрокосм): убери атрибуты — станут одним. Желания формируют тела: обжора — свинья, бегун — олень. Садхана = стереть атрибутивные узы.*

## Key Takeaways

1. Разница макро/микро — атрибутивная и временная.
2. Под путами — джива; свободный — Шива.
3. Панчакоша-тело создано реактивными моментами микрокосма.
4. По желаниям — плоды (свинья/олень/тело).
5. Садхана = снятие атрибутивных уз.
