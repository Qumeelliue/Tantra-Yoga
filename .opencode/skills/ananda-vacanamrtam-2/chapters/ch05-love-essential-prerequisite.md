# Chapter 5: Love – the Essential Prerequisite

*Дискурс 13 сентября 1978, Patna. Discourse 42 серии.*

## Core Idea

Любовь — «соль» всех практик: карри без соли невкусно. Карма без преданности механична, тапас без любви — трата времени, йога без любви превращает пропенситы в «железо», джняна без Параматмы — «кожура банана». Цель — только sáttvikii bhakti.

## Frameworks Introduced

- **Метафора соли**: все усилия соединить конечное и бесконечное без преданности проваливаются.
- **Karma без бхакти**: механическая; рудиментальная интроверсия исчезает, движение становится чисто экстровертным; «существование становится машиной».
- **Tapasyá** (свободное страдание ради быстрой цели) без любви — злоупотребление временем; плохо влияет на тело и психику.
- **Yoga** = «yogascittavrtti nirodhah» (приостановка пропенситов). Без любви приостановленные пропенситы превращаются в грубую материю («железо, дерево, песок»). Такая йога — **hat́ha yoga**: насильственный контроль ума физической силой (ha = сурья-нади, физическая сила; t́ha = чандра-нади, ум); практикующий не достигнет освобождения.
- **Jiñána без Параматмы** — кожура банана: не настоящий банан. Это aparávidyá (относительное знание грубого материализма), а не parávidyá; «за последнее столетие такой материализм превратил людей в животных».
- **Океан молока**: после пахтания преданные получают масло, джняни — сыворотку; спорят о ней, пока она не протухнет.
- **Три типа bhakti**: **támasii** (статическая — желание уничтожить врагов; цель не Господь, Господа не получишь), **rájasii** (мутативная — желание имущества; возможно богатство, но не Господь), **sáttvikii** (сентентная — цель Сам Parama Purusa; единственно верная).

## Key Concepts

- **hat́ha yoga** — насильственная йога (ha+t́ha).
- **parávidyá / aparávidyá** — высшее/низшее знание.
- **támasii / rájasii / sáttvikii bhakti** — типы преданности.
- **океан молока** — образ раздела знания.

## Mental Models

- «Думай о любой практике как о карри: без соли-любви она "несъедобна", сколько ни старайся».
- «Думай о йоге без любви как о заморозке: приостановленное без опоры каменеет».

## Anti-patterns

- **Практика без любви** (любая: карма, тапас, йога, джняна) — бесполезна или вредна.
- **Hat́ha-йога** — «опасна для подъёма человека».
- **Стремиться к бхакти тамаси/раджаси** — цель не Господь, Господь не получится.
- **Жить на материалистичном (апара) знании** — оно «превратило людей в животных».

## Worked Example

*Четыре практика. Карма-йог без любви — механизм. Аскет без любви — тратит время и вредит себе. Йог, подавивший пропенситы силой без любви, — заморозил их в грубую материю (hat́ha). Джняни без Параматмы — ест кожуру банана. А преданный, чья цель — Сам Господь (саттвики-бхакти), получает масло из океана молока. Вывод: соль любви меняет всё.*

## Key Takeaways

1. Без любви-преданности все практики проваливаются.
2. Hat́ha-йога (насильственный контроль) опасна и не ведёт к освобождению.
3. Джняна без Параматмы — «кожура банана», материализм.
4. Преданные берут масло, джняни спорят о сыворотке.
5. Стремись к sáttvikii bhakti — цель Сам Parama Purusa.
