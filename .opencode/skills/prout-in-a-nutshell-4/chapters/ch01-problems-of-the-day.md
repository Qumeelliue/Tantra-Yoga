# Chapter 1: Problems of the Day

*Молодёжная конференция, Trimohan (район Бхагалпур), 26 января 1958 — на инаугурации Renaissance Club (Renaissance Universal основан 27.01.1958).*

## Core Idea

Диагностика «проблем дня» и радикальный рецепт: мир — совместная семья с общим достоянием; капитализм искореняется эскалацией давления; лидерство общества — у sadvipra; цель — мировая организация и универсализм; демократия — лишь «лучшая из плохих».

## Frameworks Introduced

- **Совместная семья и общее достояние (Dáyabhága)**: вселенная — мыслепроекция Брахмы; собственность ничья → общая; частная собственность — дело «корыстных оппортунистов»; кто берёт сверх минимума — бедствие для других. Капитализм — анти-дхарма, антисоциален.
- **Эскалация эрадикации капитализма**: дружеское убеждение (редко и медленно) → сильные меры/страх закона (обходы: black marketing, adulteration) → **circumstantial pressure** с применением силы. «Ненасилие без силы» = провал. Уничтожение эксплуататоров — грех: их лечат психо-духовным образованием (после слома «клыков» давлением).
- **Социализация (не национализация)**: владеют люди, не государство и не «трудящиеся» как класс. Компенсация отклонена; пенсии/стипендии — вдовам, старикам, несовершеннолетним, всем без средств.
- **Экономика**: децентрализация в самообеспечивающиеся единицы (essential товары; при войне — независимость); малые + крупные производства (прядильные фабрики кормят домашние кооперативы ткачей); продвинутая механика (не хвалить гур против сахара и khadi против фабрик); механизация в капитализме = безработица, в коллективной системе = меньше труда и больше достатка (до 5 минут работы в неделю); профсоюзы — с **правом рабочих участвовать в управлении**, без доминирования партийных лидеров; всё — через кооперативы, кроме слишком малых/сложных (индивидуально) и слишком крупных/сложных (госвласть региональная, не центр/мир).
- **Sentient/static peace**: борьба vidya/avidya вечна; peace относителен; абсолютен только индивидуально через sadhana («pralaya индивидуальной жизни»). Сентентный мир требует силы («козлы среди тигров»); прощение — только индивидуально; преступления против групп прощать нельзя.
- **Универсализм**: все ism (nationalism/communalism/casteism/provincialism) — один дефект; универсализм вне ism. Право рождения — селиться где угодно («все страны — моя родина»). **Мировое правительство** шагами: закон-оформляющее тело → две палаты (нижняя по населению, верхняя по странам; верхняя отклоняет, но не инициирует) → страны только с административной властью. **Мировой язык** = самый распространённый (vishva bhasha; языки смертны), **мировой скрипт** — Roman (по выбору народов), **мировой одежды нет**. Одна культура; местное — материал для **социального синтеза** («букет»; Dhrupada → Kheyal).
- **Партийная политика опаснее микробов**: развращает ум, служба себе выше службы людям. Достойные образуют **советы для служения (boards)**, но не идут на выборы; голосуют за **достойных людей**, не за партийный билет.
- **Демократия — «лучшая из плохих»**: кандидат с <50% голосов проходит повторный тест (за/против); без безальтернативных выборов (один кандидат → тест популярности, провал = запрет на довыборы); **объявленная политика обязательна** (нарушение, доказанное в суде = отмена избрания); seat reservation — только по явному требованию общины (двухступенчатый отбор); **необразованные без права голоса** (политическое сознание); бесплатное образование; в образовании — никакой ism кроме универсализма.
- **Социальный цикл и sadvipras**: см. SKILL.md (kránti/yuga saḿkránti/parikránti, viplava/vikránti/prativiplava, систальтичность, sadvipra как лидер и «все классы в одном»).
- **Прочее**: психическая болезнь накопительства (товары ограничены, потребность общая); причинная борьба за peace (нет мира без борьбы с нарушителями); права женщин (экономическая независимость; проституция — от несправедливости; приданое исчезнет с независимостью); население — не проблема в коллективной экономике (освоение земель, химическая еда, другие планеты; никаких деформирующих методов); наука вперёд (долголетие, лабораторные дети — только с духовным развитием); Ananda Marga идеология = «философский камень» для любой проблемы.

## Key Concepts

- **Parama Puruśa / Paramá Prakrti** — Отец/Мать всех; **Ánanda Parivára** — «блаженная универсальная семья».
- **vidyá / avidyá** — интроверсивная/экстроверсивная силы, их борьба вечна.
- **sáttvikii shánti / támasikii shánti** — sentient/static peace.
- **sadvipra** — established в Yama & Niyama, imbued Cosmic ideation.
- **vishva bháśá** — мировой язык; **kránti, yuga saḿkránti, parikránti, viplava, vikránti, prativiplava**.
- **samája cakra** — социальное колесо; **varńa** — «психический цвет» класса (shudra=черный, kshatriya=красный, vipra=белый, vaeshya=жёлтый).

## Mental Models

- «Мир — совместная семья: излишек одного = лишение другого».
- «Peace — не отсутствие конфликта, а победа vidya: тишина при сильной власти = sentient, при слабой = static».
- «Эскалация: слово → закон → обстоятельственное давление → сила; параллельно — перевоспитание».
- «Социальное колесо — реле: shudra → kshatriya → vipra → vaeshya → shudra revolution → новый kshatriya».
- «Волна: давишь контракцию — получишь скачок; растягиваешь экспансию — наживёшь инерцию».
- «Классовая борьба вечна — мечта о бесклассовом сне утопична; спасает только ядро sadvipra».

## Anti-patterns

- **«Ненасилие» как неприменение силы**: не спасает свободу и не даёт sentient peace.
- **Денонсация капитализма без конструктивной идеологии**: только настораживает капиталистов.
- **Прощение преступлений против группы** отдельным представителем: вне юрисдикции.
- **Безальтернативные выборы и «непроверенная популярность»**: дорога манипуляциям богатых.
- **Национальная культура как отдельные культуры / запрет местных обычаев**: разжигает недоверие и насилие.
- **Мечта о классе без борьбы и о «бесконечном отдыхе»** лидеров.

## Worked Example

Ткач в системе двух масштабов: крупная прядильная фабрика (large-scale) обеспечивает пряжу; вокруг неё — кооперативы ткачей, работающих дома (small-scale). Ткач не уезжает на чужбину, отрасль выживает даже в войну — всё в пределах досягаемости. Демократия: кандидат набрал 40% голосов — назначают повторный тест «за/против»; единственный кандидат (других запугали) обязан пройти тест популярности перед публикой, иначе все снявшиеся теряют право на довыборы.

## Key Takeaways

1. Собственность мира общая; частный капитализм — антисоциален; переход — через социализацию, а не национализацию.
2. Sentient peace требует силы и активности; статический мир («молчать и не вмешиваться») — зло.
3. Общество ведёт не класс, а sadvipra — люди Ямы и Ниямы с Cosmic ideation.
4. Любая ism-верность (национализм, коммунализм, кастизм) — тот же дефект; выход — универсализм и мировая организация.
5. Демократия нуждается в жёстких гарантиях: пере-тест, явные платформы, образованные избиратели, бесплатное образование.
6. Экономика строится на децентрализации, кооперативах, участии рабочих в управлении и механизации на благо всех.
7. Борьба vidya/avidya вечна; личное освобождение — через sadhana.
