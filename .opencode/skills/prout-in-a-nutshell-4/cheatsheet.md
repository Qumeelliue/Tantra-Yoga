# Читшит — правила решений по Саркару (Prout 4)

## Экономика и собственность

| Ситуация | Правило |
|---|---|
| Кто владеет миром | Никто: всё — общее достояние (common patrimony); частная собственность = эксплуатация |
| Передать собственность коллективу | Социализация (народ владеет), НЕ национализация и НЕ «класс-трудящиеся» |
| Платить ли капиталисту | Компенсации нет; пенсии/стипендии — вдовам, старикам, детям; доход — работоспособным |
| Промышленность | Децентрализация в самообеспечивающиеся единицы; малые + крупные (фабрики пряжи → домашние кооперативы ткачей) |
| Механизация | В капитализме = безработица; в коллективе = меньше труда, больше достатка |
| Профсоюзы | Право рабочих участвовать в управлении; не отдавать партийным лидерам |
| Управление | Кооперативы; слишком малое/сложное — индивидуально; слишком крупное/сложное — региональная власть, не центр |

## Борьба и мир

| Ситуация | Правило |
|---|---|
| Искоренить капитализм | Убеждение → сильные меры → обстоятельственное давление (сила) + долгосрочное перевоспитание |
| «Ненасилие = не применять силу» | Провал: никакую проблему так не решить |
| Уничтожать эксплуататоров | Нет: лечить, это члены семьи |
| Тишина при сильной власти | Sentient peace (sáttvikii shánti) — здорово, требует силы |
| Тишина при слабой власти | Static peace (támasikii shánti) — зло; «козлы среди тигров» |
| Простить преступника против группы | Нельзя: прощение только индивидуально; насилие над группой — преступление без амнистии |
| Достичь абсолютного мира | Только индивидуально через sadhana; в коллективе — относительный |

## Общество и власть

| Ситуация | Правило |
|---|---|
| Кто ведёт общество | Sadvipra (Yama + Niyama + Cosmic ideation), а не классы |
| Смена классовой эпохи | Неизбежна (shudra → kshatriya → vipra → vaeshya → shudra revolution) |
| Вернуть прошлую эпоху силой | Vikránti/контр-революция: недолговечно |
| Партийная политика | Опаснее микробов: советы (boards) служат, но не идут на выборы |
| Голосовать | За достойных людей, не за партийный билет |

## Демократия

| Ситуация | Правило |
|---|---|
| Кандидат набрал <50% | Повторный тест «за/против» перед объявлением избранным |
| Один кандидат | Тест популярности; провал = запрет на довыборы |
| Нарушил обещания | Объявленная платформа обязательна; доказано в суде — избрание отменяется |
| Резервирование мест | Только по явному требованию общины; двухступенчатый отбор |
| Необразованный избиратель | Без права голоса (нет политического сознания); образование бесплатно |
| Образование | Никакой ism, кроме универсализма; курсы — у educationist'ов, не у власти |

## Наука, история, ism

| Ситуация | Правило |
|---|---|
| Критикуют науку | Симптом статичности; «развернуть Ганг к Gangotri» нельзя |
| Кто направляет науку | Надзор sadvipra; наука не меняет samskaras — только sadhana |
| Оценить «историю» | Itihása (воспитательная) ≠ itivrtta (хроника) ≠ purána (мораль без фактов) |
| Проверить претензию касты/крови | Все люди от одного получеловеческого клана; «чистая кровь» — миф |
| Спор «Рама или Кришна» | Одинаковый референт (Puruśottama) — спор из-за незнания этимологии |
| Изменился контекст ism | Ism устарел безвозвратно; восстановить параллелизм нельзя |
| Внедрить суеверие | Возможно только при сниженной ментальной скорости — разгоняй ум |

## Садхана и преданность

| Ситуация | Правило |
|---|---|
| Три фактора прогресса | Физический клаш + психический клаш + притяжение Великого |
| Клаш | Утончает ум (прядение хлопка); психический клаш ради славы огрубляет |
| Влечение | К конечному = káma; к Космической Сущности = prema (истинная преданность) |
| Стадии преданности | sáttvikii → rágánuga → rágátmiká → kevalá bhakti |
| Движение против Cosmic will | Pralaya (аннигиляция); садхана = ускорение потока Vidya |
| Цель жизни | Безличная, вне времени и пространства; изменяемое целью быть не может |

## Быстрые сигналы («tells»)

- «Не вмешивайтесь, это внутреннее дело» в случае насилия — поддержка static peace.
- Риторика «наши/чужие», «избранный народ», превосходство культуры — работают восемь пут.
- Человек критикует сахар, но пьёт чай с сахаром — статичность с лицемерием.
- «Это исконно наша земля/кровь/бог» — сигнал ism; проверь происхождение и этимологию.
- Кандидат без конкурента на выборах — сигнал манипуляции; нужен тест популярности.
- Награда/престиж «во имя группы» — культурное превосходство (shiila) или родовая гордость (kula).
