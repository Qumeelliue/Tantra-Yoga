# Читшит — правила решений по Shabda Cayaniká Part 5

## Этимология и значение

| Ситуация | Правило |
|---|---|
| Понять слово | Найди корень (dhátu) → семантическое ядро → пучок значений (не список переводов) |
| Сомнение в значении | Проверь суффикс: `-ka` отношение, `-in/-inii` принадлежность, `-kyap` материал, `-ghain` орудие |
| Фонетика | d́a в середине слова → ŕa, кроме случаев после antahstha (ya/ra/la/va): kud́ya не kuŕya |
| Двойные согласные | kárttika/várttika с двумя tt; одно tt меняет смысл (krtiká/vrta) |
| «Принято по популярности» | nipatana siddha — допустимо, но помечай как исключение из грамматики |

## Истина и этика

| Ситуация | Правило |
|---|---|
| Различить факт и «правду ради блага» | satya = с благом для других; rta = факт независимо от блага |
| Оценить обман | pratáraka/shat́ha — обман через доверие (Равана-садху); осуждаемо с древности |
| Оценить человека по рождению | Не унижать: рождение не может быть виной (Карна/Кунти) |

## Экономика

| Ситуация | Правило |
|---|---|
| Проверить баланс региона | Сельское хозяйство 30–40%; agro ~20%; agrico ~20%; торговля ~10%; интеллект ~10%; non-agro промышленность 20–30% |
| Меньше 20% промышленности | Страна неразвита: низкая покупательная способность, импортный индекс ниже экспортного, спутник |
| Больше 30% промышленности | Переиндустриализация: захват рынков, «психическая эпидемия», войны |
| Внешние рабочие в регионе | Хронический дефицит продовольствия, нет выгод индустриализации (Howrah) |
| Цены на продукцию фермера | Должны покрывать издержки, не «бросовые» (риск долгов) |

## Медицина

| Ситуация | Правило |
|---|---|
| Начать лечение | Лестница: голодание → свет/воздух/вода/земля → травы внешне → внутрь → таблетки → массаж → авалеха → анупана → асува/аришта → кватх → порошки |
| Больной без аппетита | Не кормить насильно — против природы |
| Пост | Только добровольный (svecchá-anashana); навязанный — вреден |
| Животные лекарства | Не убивать естественных друзей человека; допустимо — врагов |
| Мозоль (kuvala) | Не срезать самому: лекарство или хирург |

## Социальная система

| Ситуация | Правило |
|---|---|
| Статус по рождению без заслуг | Антипаттерн kuliina: ведёт к вырождению и порокам |
| Брачная инженерия | Принудительные браки для статуса → демографическая катастрофа |
| Образование | Учитель до 24 лет, безусловная поддержка; не служить «измам» |
| Лидер | kulála: ведёт к действию, создаёт себя сам; не «срезает серпом» готовое |

## Вода и инфраструктура

| Ситуация | Правило |
|---|---|
| Русло выше котловины | Драгировать дно ИЛИ строить дайк (stara-báṋdh); Дамодар/Арамбагх |
| Защита от моря | Дайки + ветряные мельницы (Голландия, Contai, Diamond Harbour) |
| Верхнее течение | Дамба (jalabandha, топит); начало равнины — барраж (без затопления) |
| Судоходный канал | Нужны глубина и течение (nao-kulyá); ирригационный — шлюзы (seca-kulyá) |
| Водохранилище Ráŕh | báṋdh-резервуар с высокими берегами, ломать для ирригации |

## Быстрые сигналы («tells»)

- Слово начинается с `ku-` в этой части — это словарь части 5; другие буквы — другие части серии.
- «Кривое/непрямое» в корне → вероятные значения: дерево, гора, крепость, ловкач.
- Видишь «подделка/фольга» → корень kupya/kurúpya/kuvala (неблагородное, имитация).
- «Лягушка в колодце» → догма (kuńd́akiit́a), а не просто география.
- «Сладость» при объяснении любопытства → kutuka/kutuhala (желание знать с приятным итогом).
- Река названа «разгневанной» → kupita-корень (Kopái, Kupái).
- Одежда по длине: не длиннее локтя/колена = kurpara; длинный рукав = kurbásika.
