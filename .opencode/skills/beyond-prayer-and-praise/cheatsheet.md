# Читшит — краткая справка (Beyond Prayer and Praise)

## Правила решения
| Ситуация | Правило |
|---|---|
| Отношение к божественному | Не проси («No prayers»), не восхваляй («No stuti»), не дави на ум — сдайся (Ch 5) |
| «Почему нет милости?» | Убери «зонтик тщеславия» — садхана = снятие зонтика (Ch 13) |
| Самопознание | Отдели «знающего» от знания; знающий один во всех полях (Ch 2) |
| Идеал/цель | Только Господь; не проси «сделай как Арджуну» — вдруг Он хочет больше (Ch 7) |
| Зло/давление | Моральная сила + несотрудничество; не берись за оружие (Ch 11) |
| Сорванные планы | «Встряска» готовит ум; возможно сжигает санскары (Ch 1, 14) |
| Указание без пользы | Выполняй настойчиво; смысл откроется позже (Ch 14) |
| Практика (садхана) | Проста, без учёности; возвращение домой к Высшему (Ch 7) |
| Инициация | Строго персональна; не копируй чужие процессы (Ch 15) |

## Уровни пути автора
1. Традиционное поклонение (Дурга, Гаятри, Гиты) — «давай-бери», недовольство (Ch 2).
2. Опыт Knower (Наваратри 1958) — первый проблеск себя (Ch 2).
3. Поиск гуру в Гималаях — не удовлетворён (Ch 3).
4. Инициация у Ачарьи Лаллана (Ch 3).
5. Встреча с Ba'ba' (Джамалпур/Мунгер 1962) — экстаз, сдача (Ch 4, 5).
6. Подтверждение Ba'ba' («Ты познал Идеал»), Neem Karoli (Ch 7, 8).
7. Microvita-садхана — «Он дышит во мне» (Ch 15).
8. После ухода Ba'ba' — связь вечна (Ch 16).

## Ключевые места
- **Джамалпур** — город, где жил Ba'ba'; тигровая могила, поле, «Долина смерти» (Ch 4, 16).
- **Мунгер** — первое событие и даршан (Ch 4).
- **Кота** — три визита Ba'ba'; пещеры (7–8 тыс. лет), проводы (Ch 9).
- **Удайпур** — духовно плодотворные годы, встреча с Аути (Ch 10).

## Ключевые люди
- **Ba'ba' (П.Р. Саркар)** — гуру, рассеиватель тьмы.
- **Мангал Бихари** — автор, IAS-чиновник.
- **Сарла** — жена, от страха к экстазу (Ch 6).
- **Ачарья Лаллан** — «посланник гуру», инициатор (Ch 3).
- **Аути Ананда Бхаратиджи** — первая саньясини (Ch 10).
- **Теж Каран** — родственник, «моральная сила» (Ch 11).
- **Neem Karoli Baba** — подтверждение выбора гуру (Ch 8).

## Что «не проверено» (⚠)
Даты жизни, суммы (₹2,3 lakh), число языков Ba'ba' (~200), диагнозы/медпрактики, количество растений в саду — по памяти автора; эзотерическая механика microvita-садханы изложена в книге лишь частично.
