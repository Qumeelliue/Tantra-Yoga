# Chapter 4: Jamalpur

*Первая встреча с Ba'ba' в Мунгере; экстаз собравшихся; решение остаться.*

## Core Idea

Первая поездка в Джамалпур (лето 1962) была рядом «встрясок» (сорванный поезд, жара, неустроенный ашрам), а сама встреча с Ba'ba' — «сумасшедшим домом» экстатических реакций, которые автор не мог понять, пока не встретил высоких чиновников, объяснивших норму таких даршанов.

## Key Events

- **Дорога**: сорвался поезд в Агре (висел на раскалённой ручке двери), неудобства — «шоковая терапия» для ума; по прибытии ашрам в Джамалпуре полупустой/недостроенный; узнали, что событие в Мунгере.
- **Мунгер**: дхарамшала, купание в Ганге; рикша-каликананд (по описанию — Ка́ликананд, один из первых учеников Ba'ba', живущий святым инкогнито) исчез без платы.
- **Первый даршан**: треть собравшихся (мужчины/женщины всех возрастов) — крик, смех, экстатические движения, почти обмороки; автор в замешательстве.
- **Встреча с чиновниками**: офицер таможни Прасад («Ты тоже будешь плакать однажды»), полицейский Ахори («это выражение преданности») — все подтвердили: нормальная реакция на даршан.
- **Джамалпур (Ачарья Биндешвариджи)**: гостеприимство; ежедневные дискурсы Ba'ba' (не только философия, но география, лингвистика, история, экономика); вечерние прогулки к «тигровой могиле» (памятник солдату и тигру); 4 ученика на прогулку.

## Key Takeaways

1. Первое впечатление может быть отталкивающим («сумасшедший дом») — не суди по первому даршану.
2. Уважаемые люди среди экстатических реакций — аргумент для рационального ума.
3. Ba'ba' говорит на «смешанное блюдо» тем — глубина знаний поражает.
4. «Тигровая могила» — место силы и наставлений (см. Ch 5, 16).
