# Чит-лист — Subháśita Saḿgraha Part 1

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Нужно понять, кто у власти и что дальше | Найди незаменимый ресурс эпохи → его владелец доминирует → большинство поднимется против |
| Оценить объект/человека | Определи доминирующую гуну (sattva/rajah/tamah); все три всегда есть |
| Действие тревожит/связывает | Три отказа: плод → тщеславие → «делает Брахма» |
| Жить в миру и не запутаться | Madhuvidyá: каждый объект — проявление Брахмы |
| Помогаешь кому-то | Идеация Náráyańa: служу Ему Его руками, из любви, не страха |
| Какую помощь выбрать | Голод→еда; угроза→защита; болезнь→уход; невежество→знание |
| Привязанность к человеку пугает | Люби «Брахму в форме...»; káma против prema |
| Философия/идея «застряла» | Найди её кошу: материализм=Kámamaya, сектантство=Manomaya |
| Отличие истины от мнения | Satya не меняется от времени/места/формы; иначе — относительная истина |
| Узнать уровень преданности | 8 типов: Kevalá (без объекта) > Jiṋánamishrá > саттвика > раджасика > тамасика |
| Моральный выбор в служении | Ценность услуги — по времени/месту/обстоятельствам, не по статусу |
| Стоит ли бежать из мира «отречься» | Нет: вайрагья — непривязанность в действии, не бегство |
| Понимаешь «карму» наказанием | Не суди чужую карму; ищи, как послужить |

## Быстрая справка

- **Гуны**: Sattva=белый/знание/свет; Rajah=красный/действие; Tamah=чёрный/инертность.
- **Цикл**: Saiṋcara (тонкое→грубое, tamah) / Pratisaiṋcara (грубое→тонкое, sattva).
- **Пять кош** (снизу вверх): Annamaya → Kámamaya → Manomaya → Vijiṋánamaya → Hirańmaya.
- **Семь лок**: Bhúrloka → Bhuvarloka → Svarloka → Maharloka → Janarloka → Taparloka → Satyaloka.
- **Восемь ступеней**: а́саны→Annamaya; Yama/Niyama→Kámamaya; пра́н́а́я́ма→Manomaya; пратьяха́ра→Atimánas; дха́ра́н́а́→Vijiṋánamaya; дхья́на→Hirańmaya; дхьяна-самадхи→душа.
- **Четыре йаджиньи**: Bhúta (создания), Nr (люди), Pitr (предки/мудрецы), Adhyátma (внутренняя).
- **Четыре услуги**: Shúdrocita (телом), Vaeshyocita (еда/деньги), Kśatriyocita (защита), Viprocita (знание).
- **Ключевые мантры-якоря**: «Karmańyevádhikáraste» (право только на действие); «Mana eva kárańam bandha mokśayoh» (ум — причина и связанности, и свободы); «Sa tu bhavati daridra yasya áshá vishálá» (беден тот, у кого много желаний).
