# Читшит — Tattva Kaomudii Part 3

## Бхакти и грация

| Ситуация | Правило |
|---|---|
| Что есть бхакти | Идеация на Высшее; стути (лесть) и арчана (ритуал) — не бхакти |
| Грация | Через пробуждённую преданность; права связаны с обязанностью идеации |
| Кто может спастись | Любой, независимо от образования/богатства/прошлого; суд по внутреннему |
| Прошлое тянет? | Нет: «глаза спереди» — строй будущее настоящим |
| Слабость | Грех; ненависть к себе = ненависть к Богу |
| Стадии бхакти | Ниргуна → (не ваэдхи/джинанамишра) → ра́га́тмика → кевала |

## Мировоззрение и выбор

| Ситуация | Правило |
|---|---|
| Интегральное vs неинтегральное | «Всё — одно, все родня» vs «есть нечто сверх», деление людей |
| Ложный учитель | Делит человечество, пугает, «религиозные купцы» — неинтегрален |
| Выбор объекта | Анализируй до принятия: шрея (вечное) или прея (временное)? |
| Кама vs према | Тяга к физическому исключает Сознание; любовь к Бесконечному — путь |
| Путь познания | Шравана → манана → нидидхьясана; интроверсия, не экстраверсия |

## Самадхи

| Ситуация | Правило |
|---|---|
| Сампраджинята | Викалпа приостановлена, самкалпа активна |
| Савикальпа | Чувство «второго»; самкалпа номинальна |
| Нирвикальпа | Обе приостановлены; полная безмысленность; ум из сахасрары не возвращается |
| Бхава-самадхи | Малое «Я» ведомо большим; дрожь блаженства; в 4 нижних чакрах |
| Дхармамегха | «Облако дхармы» у анахаты; садхак падает на землю |
| Ра́га́нуга́ vs ра́га́тмика | «Получить» vs «дать» радость; гопи-бхава — не финал |
| Путь к абхедаджинане | Иишвара-пранидхана + анудхьяна = абхидхьяна |

## Единство и различия

| Ситуация | Правило |
|---|---|
| Причина мира | Один стал многим; материя←энергия←идея←Пуруша |
| Материализм | Видимое = реальное — глубокое невежество |
| Различия людей | Разные наборы сан̇ска́р; одинаковые тянут к слиянию |
| Почему не все сливаются разом | Мгновенное извлечение сан̇ска́р = растворение творения |
| Метафора | Ювелир видит золото; географ — один океан |

## Быстрые сигналы («tells»)

- «Люблю, потому что получаю радость» — ра́га́нуга́, ещё не ра́га́тмика (Ch6).
- «Наш бог единственный» — неинтегральное мировоззрение, источник войн (Ch3).
- «Хочу быть сахаром, а не пробовать» — отказ от слияния, гопи-бхава (Ch6).
- «Я недостоин» / «я грешник» — комплекс неполноценности, «слабость — грех» (Ch1).
- Видишь «20 миль = чужбина» ⚠ — узкий ум, отсутствие абхедаджинаны (Ch3).
