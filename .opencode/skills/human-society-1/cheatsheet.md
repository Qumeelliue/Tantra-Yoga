# Читшит — правила решений по Саркару (Human Society Part 1)

## Общество и мораль

| Ситуация | Правило |
|---|---|
| Прогресс «заморожен» | Подавление удлиняет сжатие и ускоряет расширение — строй новое |
| Оценить учение/заявление | Рациональность > авторитет: «слова ребёнка» принимай, «слова Творца» — если рациональны |
| Религия обещает «вечное» | Статичность = эксплуатируемость; мораль ведёт, религия замораживает |
| Общество/прогресс | Прогресс = мораль → всеобщий гуманизм; общество = коллектив этого усилия |

## Образование

| Ситуация | Правило |
|---|---|
| Учить детей | Игра и сказки (история, география, универсализм) |
| Учить подростков | Идеализм (мечта будущего) |
| Учить молодых взрослых | Идеализм + реализм |
| Дисциплина | Не страхом: жажда знания; страх-знание испаряется |
| Кто учитель | Samája guru: характер + лидерство, зарплата как судья, политику школы делают педагоги |
| Кто воспитывает мораль | Родители (самообладание + здравое суждение, без лжи); учителя вторичны |
| Медиа/кино/радио | Только неполитические культурные советы |
| Языки | Родной + мировой (английский); не нагружай пятью языками |

## Социальная справедливость

| Ситуация | Правило |
|---|---|
| Строить институт | Координационная кооперация, не субординация (господин-слуга) |
| Права женщин | Признавать, не даровать; свобода ≠ вседозволенность |
| Наследование | Равные права + патрилинейность + охрана мира в семье |
| Приданое | Экономическая проблема, не вопрос правосудия |
| Оценить «образованность» | Много узнать + запомнить + применить; спесь = банкротство |
| Ресурсы | Общее достояние всех; равные права + мотивирующие исключения |
| Менять несправедливость | Отвергни грабёж, воззвания, насилие → давление + нравственное воспитание |
| Доля зол общества | 75% — межличностные несправедливости |

## Правосудие

| Ситуация | Правило |
|---|---|
| Карать или корректировать | Никто не вправе карать — только корректировать; при сомнении не наказывай |
| Конфликт кодексов | Моральный кодекс > уголовный |
| Судья | Сила характера; отличник юрфака ≠ справедливый судья |
| Присяжные | Только честность; без бизнесменов и политиков |
| Врождённый преступник | Болезнь → лечить и изолировать; тюрьма = больница |
| Привычный преступник | Моральное образование + строгая среда; судить строго |
| Из-за среды | Убрать из среды; «от 7 до 70 меняет компания» |
| Из-за бедности | Вина структуры; суд бессилен — решает экономика |
| Добро/зло | Относительны; зло = эксплуатация |
| Кодексы | Единый мировой кодекс от признанной глобальной организации |

## Профессии и экономика

| Ситуация | Правило |
|---|---|
| Юристы | Нужны для защиты, но число сокращать; приоритет — науке |
| Врач | Служение, не бизнес; лечит природа, вера пациента — сила |
| Лекарства/банки/стройматериалы | Автономные органы и кооперативы; не бизнес |
| Бизнесу | Роскошь и необязательное; закрыть спекулятивные рынки |
| Артисты/кино/театры | Залы — автономные органы; зарплата по способностям и нуждам |

## Быстрые сигналы («tells»)

- «Так было всегда» — застывший кодекс эпохи; меняй.
- «Учитель пугает и бьёт» — знание уйдёт со страхом; буди жажду.
- «Свобода женщин» на словах + purdah дома — права подменены риторикой.
- Суд без учёта бедности/среды — создаст привычных преступников.
- Еда на складах спекулянтов при голоде — распределение отдать потребительским кооперативам.
- Артист «110% бизнес-ориентированный» — искусство в рабстве у Лакшми.
