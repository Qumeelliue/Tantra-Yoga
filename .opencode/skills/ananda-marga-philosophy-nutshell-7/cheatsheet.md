# Читшит — правила решений по Саркару (AMPN 7)

## Анализ философских утверждений

| Ситуация | Правило |
|---|---|
| Проверить тезис «X реален, всё остальное иллюзия» | Трёхчастный шаблон: этимология → логика (вторая сущность?) → практика (что делать?) |
| Тезис объясняется «Майей/upádhi» | Это вторая сущность → монизм рушится; если «нереальна» → аргумент пуст |
| «Мир иллюзорен» | Замени: мир — относительная истина, всегда движущаяся (jagat) |
| Аналогия с иллюзией (змея/мираж) | Прототип должен существовать → иллюзия не доказывает нереальность |
| «Разница только в upádhi» | Убрав атрибуты, получишь двух безымянных, а не одного (барабанщик/косарь) |

## Божество и лидерство

| Ситуация | Правило |
|---|---|
| Судить о великой личности | Три канала: сказал / сделал / умолчал |
| Божество/лидер «пассивно» | Это Janya Iishvara-катализатор, не Táraka Brahma — не вдохновляет |
| Оценить Пурушоттаму | Должен быть ota (с каждым) + prota (со всеми); иначе — «звезда-зритель» |
| Моральные нормы без основы | Не стоят — нужен дхармический фундамент (dharmarájya) |
| Кооператив спасает? | Спасает от хищников, но злые вожди разворовывают — нужны моральные лидеры |

## Отношения с Центром (bháva)

| Ситуация | Правило |
|---|---|
| Мотивация человека к идеалу | Определи bháva: ватсялья (родительская) / мадхура (влюблённость) / сакхья (дружба) / дасья (служение) |
| Созревание дружбы | Sakhya → dásya (величие) или madhura (близость) — по направлению осознания |
| Радха как личность? | Это состояние однонаправленного ума, не персона |

## Майя и реальность

| Ситуация | Правило |
|---|---|
| Уводит от центра | Авидья-майя: vikšepa («мир — всё») + ávaranii (завеса) |
| Приводит к центру | Видья-майя: sambit («ничто не вечно») + hládinii (радость) |
| Майя — «нереальна»? | Нет: она мощная сила (pracanda), Майя Парама Пуруши; прибежище в Нём побеждает её |
| Брахма одинок | Нет: Брахма = Пуруша + Практи (avinábhávi, стороны листа) |

## Практика и социальное

| Ситуация | Правило |
|---|---|
| Философия «всё нереально» | Непоследовательна: не ешь/не дыши/не служи — абсурд; «Pi-pu-phi-shu» |
| Благополучие системы | Покрыть три сферы: физическую, психическую (свобода от догм), духовную |
| Планировать время | «Живи в настоящем» (Varttamánesu vartteta): решай текущее, держи ум на тонком |
| Догма мешает | Проверяй фактами; догма = мёртвый груз на уме |
| Дефектный порядок | Губит даже хороших (голод → жадность санньясинов) — строй dharmarájya |

## Быстрые сигналы («tells»)

- Философия требует второй сущности для объяснения — монизм сам себе могильщик.
- «Чистое золото без применения» — красивая, но бесполезная доктрина.
- Великий человек «принимает поклонение, но ничего не делает» — не Пурушоттама.
- Утверждение, что «upádhi не существует», а потом «уберите upádhi» — внутреннее противоречие.
- Пример для «иллюзорности мира» взят из мира — сам себя опровергает.
