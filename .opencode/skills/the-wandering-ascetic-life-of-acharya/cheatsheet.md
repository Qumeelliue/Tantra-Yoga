# Краткая справка (The Wandering Ascetic Life of Acharya)

## Ситуация → Правило

| Ситуация | Правило |
|----------|---------|
| Желание уйти от мира | Служение обществу важнее побега; спроси «эгоистично ли это?» |
| Разговор с Гуру о правилах | Обсуждай практичность; Гуру гибок, но правила — защита |
| Клевета/обвинения | Прими ради организации; доверься трибуналу и Гуру |
| Страх/паника толпы (астрология) | Проверяй фактами; Гуру рисует схему; раздавай листовки |
| Массовое религиозное давление | Дебаты логикой и языком оппонента; кабиган |
| Война/опасность | Иди по слову Гуру («без страха»); разумная осторожность |
| Кандидат в wholetimers | Требуй письменное разрешение родителей/жены |
| Желание оккультных сил | Нельзя без зрелости (8 оков, контроль вритти) — иначе проклятие |
| Стадии тантра-садханы | Животное → шакта → вайшнав → шайва (порядок строгий) |
| Панчамакара | Духовные практики (нектар, речь, дыхание, сат-санга, единение кундалини) |
| Выбор места практики | Питха Гуру — лучшая; оставляй питху «живой» (вибрация) |
| Правила авадхуты | Не принимай служение, если здоров; но отказ смягчай тактом |
| Чистота жизни | Отказ от взяток; не есть у не-марги капиталистов |
| Сроки/обязательства | «Работай как машина»; ничего на завтра |
| Тщеславие дарами | Падение; «гуру сердит — никто не спасёт» |
| Враждебные воздействия | Пуджа/медитация; «кого спасает Господь — никто не убьёт» |
| Цель жизни | Суррендер, Sadvipra Samaj, семь добродетелей |

## Ключевые шлоки и формулы

- **Авадхута**: «Shmashäne vä grhe... viräje avadhüto dvitiiyo maheshah» — равенство всего, второй Шива.
- **Гуру**: «Nigrahanugrahe shakta gururityabhidhiyate» — способен наказать и помиловать.
- **Йога**: «Samyogo yoga ityukto jiivatma paramatmana» — единение дживатмы с Параматмой.
- **Будда**: «Два глаза всегда смотрят» — сокрытие греха невозможно.
- **Кришна**: «Nimitta matra bhava» — будь инструментом.
- **Кундалини**: «Мантра — жизнь, кундалини — душа, тело — инструмент».
- **Семь добродетелей**: терпение-отец, прощение-мать, мир-жена, истина-друг, доброта-сестра, контроль ума-брат, земля-кровать, небо-одежда, знание-пища — «для такого нет страха».
