# Читшит — правила решений (Ananda Marga Philosophy Part 6)

## Ум и объекты (vyatireka)

| Ситуация | Правило |
|---|---|
| Ум «висит»/не может безобъектным | Ум всегда при объекте (как ayogaváhá-буква); выбери объект осознанно |
| Лечить зависимость | Смена среды + вовлечение в другое; НЕ «не делай» (запрет впрыскивает объект) |
| Раскол ума (два объекта) | Одна задача — один объект; иначе ничто не делается хорошо |
| Долгая мысль | Материализуется — не держи ум на нежелаемом |
| Лучший объект | Самый большой, постоянный, любящий: Высший |

## Стадии прогресса

| Ситуация | Правило |
|---|---|
| 1-я стадия | Yatamána: усердие с санкцией ума и Атмана (Part 5) |
| 2-я стадия | Vyatireka: осознание, что ум привязан к объекту |
| 3-я стадия | Ekendriya: однонаправленность на Высшее; расширение ума |
| 4-я стадия | Vashiikára: полная власть через само-вручение |
| Успех движения | Только с фиксированной целью (лодочник без назначения — впустую) |

## Ekendriya

| Ситуация | Правило |
|---|---|
| Расширение ума | Как облако: эктоплазменная сфера захватывает объекты |
| Vidyá vs avidyá тантра | К Высшему (оживляет) vs к грубому (огрубляет); средний путь — единственный |
| Догма как цель | Отвергни: догма расширяется при разрезании |
| Негативный ekendriya | Контроль одного органа при разгуле остальных — не финал |
| Иерархия контроля | Тело → индрии → ум → прана; успокой дыхание — успокоишь ум |

## Девайони (чем станешь по идеации)

| Доминирующая идеация | Результат после смерти |
|---|---|
| Деньги | Yakśa |
| Музыка/искусство как всё | Gandharva |
| Красота/одежда | Kinnara |
| Книжное знание без практики | Vidyádhara |
| Грубая идеация | Prakrtiliina (стать материей) |
| Вечная погоня | Videhaliina |
| Тщеславие практика | Siddha (помощник садхак) |

## Познание

| Ситуация | Правило |
|---|---|
| Уровень знания | ava (поверхность) → upa (психический пласт) → samyak (полная) |
| Источники | Восприятие/инференция/авторитет ненадёжны |
| Постоянное знание | Только через направление ума на Высшее (dharmamegha) |

## Самадхи на объектах

| Ситуация | Правило |
|---|---|
| Фактор («я — земля») | Kśitibhaetik samádhi (теряется практический интеллект) |
| Танматрасы (роза) | Tanmátrik samádhi |
| Индрии | Выше танматрас |
| Деньги как объект | «Самадхи» со смертельным финалом при крахе |

## Оккультные силы

| Ситуация | Правило |
|---|---|
| Уровень сил | iishvarakoti — на индивидов; brahmakoti — на вселенную (prota) + индивида (ota) |
| Увлечение силами | Тормозит полное выражение потенциала |
| Raḱśasii vidyá | Положительные галлюцинации (не «духи»); против них — раздражение (ломает концентрацию) |

## Кришна-модель

| Ситуация | Правило |
|---|---|
| Стиль лидерства | Vraja (сладость/любовь) vs Párthasárathi (суровость/объединение); вопрос «кто выше» иррелевантен |
| Угроза прогрессу (Kamsa) | Нужна жёсткость, не только сладость |
| Четыре фактора | Самость + тело-колесница + buddhi-возница + ум-поводья; развивай все |
| Virúpa vs vimukha | Временное неудовольствие терпимо; «повернутый спиной» — невыносимо |

## Стадии реализации (Кришна-3)

| Стадия | Суть |
|---|---|
| Sálokya | Живу в эпоху Господа |
| Sámiipya | Близость, личный диалог |
| Sáyujya | Почти телесный контакт |
| Sárúpya | Вижу Его во всём (из любви — истинно; из страха — безумие) |
| Sárśt́hi | Тонкая двойственность («вкушать сахар») |
| Kaevalya | Только Ты существуешь (не-двойственность) |
| Пути | Vraja — сладость; Párthasárathi — борьба (может перескакивать стадии) |

## Быстрые сигналы («tells»)

- «Не пей!» в лечении зависимости → впрыскивает объект; среда — решает.
- Ум в Джайпуре думает о Халдибари → раскол: ничто не делается хорошо.
- «Я брошу с понедельника» → объект в уме, бросить нельзя.
- Человек «стал деньгами» → prakrtiliina, деградация.
- «Альманах предсказывает дождь, но выжать ни капли» → vidyádhara (знание без практики).
- «Догма разрезана — стала шире» → не спорь, не бери за цель.
- Видишь 20 «Раван» → чья-то raḱśasii-майя: разозли, чтобы разбить иллюзию.
- Лодочник без назначения → движение впустую: нужна цель.
