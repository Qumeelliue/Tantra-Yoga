# Master Samskrta Glossary — сводный санскритский глоссарий Ананда Марги

**Источник**: Electronic Edition 7.5 (Ananda Marga Pracaraka Samgha (Central), 2009).
**Состав**: 269 терминов с определениями — единый словарь, охватывающий всю идеологию.

## Как пользоваться этим скиллом

- **Значение термина** — назови санскритский/бенгальский термин (например, «sadvipra», «kula-kuńd́alinii», «abhimána»); я дам определение из глоссария.
- **Слово из книги** — если термин встретился в тексте и его значение неясно, сверься с глоссарием.
- **Обзор** — «какие термины в глоссарии?» → загружу список.

Полный список терминов — в файле `glossary.md` рядом с этим файлом.
