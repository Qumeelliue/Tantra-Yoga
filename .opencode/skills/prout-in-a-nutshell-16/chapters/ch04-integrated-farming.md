# Chapter 4: Integrated Farming

*Дискурс от 20 февраля 1988, Calcutta.*

## Core Idea

Фермерство — интегрированная система самодостаточности: агрономия + садоводство + цветоводство + шелководство + лаковая культура + пчеловодство + молочное животноводство + орошение + рыбоводство + защита растений + удобрения + кустарные промыслы + энергия + исследования + водосбережение. Главная цель — self-reliance: не зависеть от внешних ресурсов.

## Frameworks Introduced

- **Севооборот выбора сорта**: при наличии раннего/среднего/позднего сорта сажай сначала ранний; при провале — средний, затем поздний. Поздний в начале сезона и его провал = потерянный сезон.
- **Запас экстренного выживания**: обязательные культуры любого проекта — овощи, бобовые, картофель, корм для молочных коров; запускать немедленно.
- **Орошение только поверхностными водами**: подземные воды не тревожить (падение уровня воды-таблицы); собирать дождь там, где он падает; не эксплуатировать водоносные слои пустынь. Пустыни полезны экологии: сухой воздух поднимается → вакуум → влага с моря → дождь.
- **Экологическая защита растений**: не использовать вредные пестициды там, где в полях рыба; neem-paste пестицид (+ urea); минимум медного купороса; iishanmula и соли меди — змеи боятся. Рыба — корм птиц/зверей, а не человека: поддерживает экобаланс.
- **Удобрения**: бактерии — «скрытое звено»; органика (bio-фертилайзер) — только положительная функция; овечьи моча и навоз — лучшие; биогаз-материалы — коровий навоз (лучший), гиацинт. Химические удобрения истощают «жизненную энергию» земли — решает только кооператив; ротация с паром более невозможна.
- **Энергия малого масштаба**: солнечная, тепловая, биогаз, малая гидроэнергия, пневматическая (дёшево; ветреные места). Slurry (биогазовый осадок) — удобрение: распад ~неделя против 6 месяцев.
- **Приоритет исследований**: 1) агрономия, 2) биология (зоология → ботаника), 3) химия. Полное использование ресурса (пример okra: масло из семян, волокно, корм, удобрение, бумага, топливо; 40 дней роста).
- **Солнечный календарь**: бенгальские месяцы — солнечные и сезонные; лунный (хинди) не годится; солнечный год 365 против лунного 355 дней; hathiya (солнце+луна в Рыбах и дождь) — отличный урожай; «лунные» растения (базилик) растят отдельно.
- **Особые элементы мастер-юнитов**: мукомолка, пекарня, дешёвый центр семян (sulabha biija vitarańa kendra), центр бесплатной раздачи растений, шелководство, биогаз, солнечная энергия, пчеловодство, школа и дом детей.

## Key Concepts

- **master unit** — модельный сельский многопрофильный центр развития (минимум PROUT: пища, одежда, жильё, образование, лечение).
- **sericulture / lac culture / apiculture** — отрасли на насекомых: шелководство (тутовое garad/matka; нетутовое muuṋgá/tasar/endy), лаководство, пчеловодство (rock bees не приручаются, bush bees — да).

## Mental Models

- «Ферма — закрытая система: всё, что потребляет проект, проект и производит; входы извне = уязвимость».
- «Вода: дождь — клад, который надо собрать где упал; подземелье — резерв, который лучше не тревожить».
- «Каждый ресурс используй целиком, как okra: еда, волокно, масло, бумага, топливо».

## Anti-patterns

- **Подземное орошение** — падение уровня грунтовых вод.
- **Химические пестициды в полях с рыбой** — убивают рыбу и отравляют воду.
- **Интенсивные химические удобрения без кооператива** — земля мёртвая.
- **Лунный календарь для земледелия** — нельзя; нужны солнечные месяцы.
- **Слабая агротехника семян**: сладкие — сеять после проращивания (муравьи); редис — семена за 3 мили от поля (болезни).

## Worked Example

Замкнутый цикл экстренной самодостаточности: проект сразу запускает минимальный набор (овощи, бобовые, картофель, корм). Параллельно: пруд с рыбой очищает воду; в рисовые поля в сезон дождей подселяют мелкую рыбу (не ловить, пока рис растёт; без ядохимикатов) — рыба кормит птиц. Отходы коров → биогаз → slurry → удобрение полей → больше корма → цикл замкнут.

## Key Takeaways

1. Интеграция отраслей — путь к самообеспечению; никакой зависимости извне.
2. Орошение только поверхностными водами; подземные — не трогать.
3. Органика + биогаз-удобрения сохраняют землю; химия истощает — нужен кооператив.
4. Запас экстренного выживания обязателен на каждом проекте.
5. Календарь земледелия — солнечный; hathiya — знак отличного урожая.
6. Исследования: агрономия → биология → химия; ресурс использовать целиком.
