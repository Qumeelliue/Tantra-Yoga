# Читшит — правила решений по Саркару (Prout 16)

## Догма и рациональность

| Ситуация | Правило |
|---|---|
| Оценить учение/правило/механику | Спроси «где логика?» — нет логики = догма; собрание догм = ism |
| Заменить догму | Только не-догмой (рациональностью/пропенсити); не догмой на догму |
| Догма «богат во благо, беден во грех» | Оправдание неравенства — блокирует восстание против эксплуатации |
| Ism → универсализм | Снять все барьеры периферии = неогуманизм; чувства ко всем живым |
| Отлучение/смерть-как-наказание | Воспитательное: убедить → потребовать → предупредить → мера; не сгоряча |

## Общество и закон

| Ситуация | Правило |
|---|---|
| Вредный закон | Следуй пока действует; сотри и прими новый — но снова подчиняйся |
| Неповиновение «во имя истины» | Дураграха: растит психологию нарушения → «закон большой рыбы» |
| Единство общества | Общая идеология + бескастовость + коллективные функции + отказ от смертной казни |
| Мир/покой | Только paramártha (садхана) снимает страдание навсегда; artha — временно |

## Экономика

| Ситуация | Правило |
|---|---|
| Выбрать устройство производства | Производство для потребления, не для наживы |
| Капитализм vs коммунизм | Оба централизованы = «плоды одного сорта»; децентрализация — максимум |
| Уровень производства | Село → блок → выше только при необходимости (сталь/железо) |
| Ключевые отрасли | Контроль государства/сообщества, никогда у капиталистов |
| Города растут вокруг заводов | Цена централизации: нищета периферии + пороки городов |

## Три кардинальных принципа

| Ситуация | Правило |
|---|---|
| Отобрать профессию | Только с альтернативной занятостью; отменять обещанное постепенно |
| Обращение в религию | Никогда насильно; религия на логике не требует конверсии |
| Родной язык | Никогда не подавлять — удушение и раздел (урду/Пакистан) |
| Много языков/групп | Швейцарская модель: признать все, не навязывать доминант |
| Раскол мнений (4 vs 3) | Решение, безопасное для всех, а не для большинства |
| Защита принципов | Сила + сначала поднять сознательность масс об эксплуатации |

## Быстрые сигналы («tells»)

- Учение грозит «вечным проклятием» или «командами во сне» — догма с корыстным мотивом.
- «Бескровная вооружённая революция» — самообман: shastra/astra = прямые пути с кровью.
- Один завод в глуши + нищета региона — децентрализация не сделана.
- Подавленный язык («хинди-империализм») — готовится восстание.
- «Умрём за Maethilii», а толпа выбрала «умереть в Kashi» — массы не осознали эксплуатацию.
