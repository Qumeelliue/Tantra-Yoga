# Глоссарий — Prout in a Nutshell Volume 4 Part 16

**Адитьямик / Дхармик дживика (Adhyátmik / Dharmic jiivika)** — духовная занятость; садхана, дхьяна, джапа (Ch 8).

**Артха / Парамартха (artha / paramártha)** — временное прекращение страданий через психо-физические блага vs постоянное — через садхану (Ch 2).

**Бхагават Дхарма (Bhágavata Dharma)** — человеческая дхарма, Adi/Sanátan/Eternal Dharma; без делений по верам; четыре аспекта (Ch 1).

**Вистава / раса / сева / тадстхити (vistara / rasa / seva / tadsthiti)** — четыре аспекта Bhágavat Dharma: расширение, поток, служение, верховное состояние (Ch 1).

**Гадд (gad́d́)** — глагол «делать без логики»; корень слова «догма» (Ch 5).

**Гипокритская догма (hypocrites' dogma)** — сознательное следование догме, зная её ложность; двигатель — корысть (Ch 5).

**Гондвана (Gondwanaland)** — древнейший континент, по народу гондов; родина человечества (Ch 3).

**Дживика (jiivika)** — занятие/образ жизни; три типа: физический, психический, духовный (Ch 8).

**Догма (dogma)** — движение без логики и разума; заменяется только не-догмой (Ch 5).

**Дураграха (duragraha)** — «принуждение во зло»; неповиновение как инструмент разрушения (Ch 6).

**Изъм (ism)** — собрание догм; не построит универсализм (Ch 5).

**Исправительное наказание** — не отлучает, а возвращает (вернуть 10 человек на путь духовности); 4 стадии Caryácarya (Ch 2).

**Кардинальные социально-политические принципы** — занятость, вера, родной язык (Ch 9).

**Ключевые отрасли (key industries)** — под контролем государства, не капиталистов (Ch 7).

**Мастер-юнит (master unit)** — модельный сельский центр развития; минимум PROUT (Ch 4).

**Мелбандхан (Melbandhan)** — «связующие сообщества» вместо отлучения (Ch 9).

**Неогуманизм (Neohumanism)** — ism с очищенной периферией → универсализм; чувства ко всем живым (Ch 5).

**Парадхарма (paradharma)** — дхарма растений/животных для человека; следовать запретно (Ch 1).

**Партикуляризм (parochialism)** — корень религиозной догмы (Ch 5).

**Прана Дхарма (Práńa Dharma / Jiivan Dharma)** — общие атрибуты всех живых существ: безопасность, размножение, смерть, пища и вода (Ch 1).

**Production for consumption** — «производство для потребления, а не для наживы»; максим PROUT (Ch 7).

**Ра́рх (Ráŕh)** — древнейшая часть Гондваны, родина человечества (Ch 3).

**Раса-лила (rása liilá)** — космический танец Parama Purusa (Ch 1).

**Самгаччхадхвам (Sámgacchadhvam)** — «двигаемся вместе»; мантра церемоний (Ch 2).

**Сама́скары (saḿskaras)** — реакции на прошлые действия; никто не разделит чужие (Ch 5).

**Сатиаграха (satyagraha)** — «держание истины»; имя гражданского неповиновения (Ch 6).

**Три дхармы (plant / animal / human dharma)** — три уровня природы живого мира (Ch 1).

**Шастра / шастра / астра (shástra / shastra / astra)** — убеждение vs сила vs оружие (Ch 5).

**Швейцарская модель** — четыре гос. языка при большинстве одного; образец учёта всех групп (Ch 9).

**Яндар / январ (jandar / janwar)** — «обладающий жизнью» vs «животное» (Ch 1).
