# Читшит — правила решений по Саркару (Prout 6)

## Социальные изменения

| Ситуация | Правило |
|---|---|
| Прогнозировать революцию | Есть ли некупимые ментальные кшатрии/випры среди шудр? Нет — движения не будет |
| Тип смены эпохи | Естественно → svábhávika; силой → kránti; колоссально → viplava; вспять → vikránti; колоссально вспять → prativiplava; полный круг → parikránti |
| Эпоха деградирует в эксплуатацию | Садвипры применяют силу (ядро колеса, не периферия) |
| Система не служит благу всех | Жди антитезиса; синтез станет тезисом следующей эпохи |
| Настройка на время-место-личность | Только принявшие Верховное Сущее целью (садвипры) |

## Экономика

| Ситуация | Правило |
|---|---|
| Распределение богатства | Минимум всем; излишек — достойным по заслугам; минимум растёт |
| Накопление богатства | Только с одобрения коллектива; иначе — антисоциально |
| «Служи по способности, зарабатывай по потребности» | Отвергнуто: минимум зарабатывается трудом |
| Управление | У духовно возвышенных + умных + смелых вместе |
| Наука | Ниже цивилизации; гармония ускоряет духовный прогресс |

## Демократия и власть

| Ситуация | Правило |
|---|---|
| Успех демократии | Образование (не грамотность!) + мораль (≥51%) + сознательность |
| Голоса продаются | Нет морали → лидерами станут безнравственные |
| Городская теснота разлагает мораль | Децентрализация производства и культуры в деревни |
| Лучший строй | Просвещённая благожелательная диктатура; до неё демократия — меньшее зло |

## Прогресс

| Ситуация | Правило |
|---|---|
| Оценить «прогресс» меры | Плюсы минус минусы; физический/интеллектуальный баланс ≈ 0 |
| Подавление чувств | Прорвётся позже — не путь |
| Нигилизм («мир иллюзорен») | Самообман — отвергнут |
| Цель движения | Dharma и Mokśa (Caturvarga), не Káma и Artha |
| Защита от реакций | Поглощать грубые волны тонкими |

## Теория и выживание

| Ситуация | Правило |
|---|---|
| Материализуется ли теория | Следует за практикой — да; предшествует — может никогда |
| Четыре причины краха | Лицемер / теоретик / неэффективное применение / чуждая среда |
| Оценить выживание группы | Шесть факторов: идеология, культ, соц-теория, братство, шастра, наставник |
| Культура под давлением | Ищи подрыв через образование/идеологию (опаснее прямого удара) |

## Быстрые сигналы («tells»)

- «Высокие речи» без намерения воплощать — лицемерие.
- «Повысили зарплаты, налоги съели прибавку» — ложная математика прогресса.
- Ментально шудровое большинство + купленные лидеры — революции не будет.
- Класс «ни индийцев, ни англичан» — продукт чуждой образовательной системы.
- Рост числа недовольных (vikśubdha) — ранний признак революции.
