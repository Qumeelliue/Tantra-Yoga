# Chapter 3: Chapter 5 (Ánanda Sútram)

*Глава 5 книги Ánanda Sútram, 1962; в сборнике озаглавлена «Chapter 5». Пять принципов Prout даны в санскритской форме (сутры 5-12…5-16); впервые на английском — в Idea and Ideology, 1959.*

## Core Idea

Шестнадцать сутр задают формальный каркас социального цикла и экономики Prout: колесо классов вращается всегда; садвипры в ядре ускоряют или разворачивают его силой; экономика строится на гарантированном минимуме, излишке по заслугам и прогрессивном использовании по времени-месту-личности.

## Frameworks Introduced

- **Сутры социального цикла (5-1…5-7)**:
  - **5-1** — в движении колеса всегда доминирует один класс (Shúdra → Kśatriya → Vipra → Vaeshya → шудра-революция → второй Kśatriya Age).
  - **5-2** — садвипры (стойкие моралисты-духовники, применяющие силу) стоят в ядре колеса и управляют им.
  - **5-3 krántih** — ускорение колеса силой = «эволюция»; отличие от svábhávika parivarttana (естественного изменения) — только в применении силы.
  - **5-4 viplavah** — ускорение колоссальной силой / смена эпохи в краткий срок = «революция».
  - **5-5 vikrántih** — возврат к предшествующей эпохе силой = «контр-эволюция»; крайне недолговечна.
  - **5-6 prativiplavah** — возврат колоссальной силой = «контр-революция»; ещё короче.
  - **5-7 parikrántih** — полный оборот колеса, завершающийся шудра-революцией = «периферическая эволюция».
- **Сутра природы (5-8)**: разнообразие, а не тождество, — закон Природы; нет двух одинаковых объектов/умов/атомов; уравнители идут против Высшего Управляющего Принципа и обречены.
- **Сутры экономики Prout (5-9…5-16)**:
  - **5-9** минимум эпохи — всем: еда, одежда, лечение, жильё, образование; минимум растёт с эпохой (велосипед → самолёт).
  - **5-10** излишек — достойным по мере заслуг (врачу — автомобиль, когда всем нужен велосипед); «служи по способности, зарабатывай по потребности» бесплодно.
  - **5-11** повышение минимума — признак жизненности общества (велосипеды всем → автомобили достойным → автомобили всем → самолёты достойным…).
  - **5-12** накопление физического богатства — только с явного одобрения коллектива; иначе ущемление удобств других, антисоциально.
  - **5-13** максимальное использование и рациональное распределение всех мирских, надмирских и духовных потенций.
  - **5-14** максимальное использование физических, метафизических и духовных потенций единичных и коллективных тел.
  - **5-15** должная настройка между всеми использованиями: люди зарабатывают минимум трудом по способности (иначе иждивенчество); у духовно развитых берут больше духовной службы, у интеллектуалов — интеллектуальной; управление — у духовно возвышенных, умных и смелых одновременно.
  - **5-16** метод использования меняется по времени-месту-личности и прогрессивен; цепляющиеся за «скелеты прошлого» отвергаются. Провозглашение **Pragatishiila Upayogatattva** — Прогрессивной Теории Использования.

## Key Concepts

- **samája cakra** — социальное колесо/цикл.
- **kránti / viplava / vikránti / prativiplava / parikránti** — пять видов изменений колеса.
- **svábhávika parivarttana** — естественное изменение (без силы).
- **Дополнение 1989** (сноска): минимум для всех → особые удобства для талантов → максимум удобств для всех — три неубывающих процесса.

## Mental Models

- «Пять кнопок смены эпох: естественно, силой, колоссально, вспять, колоссально вспять — обратные ходы короткоживущи».
- «Экономика — три полки: минимум всем → излишек достойным → рост минимума; и так без конца».
- «Накопление богатства — заём у коллектива: без его согласия — антисоциально».
- «Разнообразие — закон: "сделать всех равными" бьётся о Природу».

## Anti-patterns

- **Уравнительство** — против закона разнообразия, ведёт к разрушению.
- **Накопление без одобрения коллектива** — антисоциально.
- **«Служи по способности, зарабатывай по потребности»** — бесплодно, губит инициативу.
- **Методы прошлых эпох** в век развитой науки — не прогресс.
- **Ставка на одно качество** — управлять должны духовное + интеллектуальное + смелость вместе.

## Worked Example

Общество в Vaeshya Age (5-1). Садвипры в ядре видят деградацию, колоссальной силой ускоряют колесо — viplava (5-4); полный оборот завершается — parikránti (5-7). В новом строе всем гарантирован минимум (5-9); врач за заслуги получает автомобиль, когда у всех велосипеды (5-10); со временем велосипед становится минимумом всех (5-11). Накопление сверх — только с санкции коллектива (5-12); излишек по заслугам (5-13); духовная служба ценится выше интеллектуальной (5-15). Использование пересматривается по времени-месту-личности (5-16).

## Key Takeaways

1. Колесо вращается всегда; один класс доминирует в каждый момент.
2. Садвипры в ядре: ускорять (kránti/viplava), разворачивать (vikránti/prativiplava — недолговечно), завершать круг (parikránti).
3. Разнообразие — закон природы; уравнительство обречено.
4. Экономика: минимум всем → излишек по заслугам → рост минимума — бесконечно.
5. Накопление богатства — только с одобрения коллектива.
6. Пять принципов Prout = сутры 5-12…5-16; использование — прогрессивное.
