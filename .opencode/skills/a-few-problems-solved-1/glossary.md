# Глоссарий — A Few Problems Solved Part 1

**А́лапа (álápa)** — вступление к классическому произведению; непосвящённому — «пралапа» (бред) (Ch 1).

**«Ана́рья» (Anárya)** — «неарии»: общее имя коренных жителей Индии — монголоидов, австриков, дравидов (Ch 2).

**«Art for art's sake»** — отвергнутый девиз; правильный — «Art for service and blessedness» (Ch 1).

**А́рша Дхарма (Árśa Dharma)** — «религия мудрецов» — идеология rshi в кшатрийскую эпоху ариев (Ch 2).

**Арьи (Aryans)** — кочевники из северной Средней Азии, пришедшие в Индию через северо-запад; дали язык и политическое господство (Ch 2).

**Бхава (bháva)** — чувство/смысл, «душа» песни (упоминается в контексте giita) (Ch 1).

**Ва́дья (vádya)** — инструментальная музыка, составляющая saḿgiita (Ch 1).

**Веды (Vedas)** — Rgveda (неиндийская), Yajurveda (Иран/северо-запад), Atharvaveda (Индия, влияние Тантры), Sámaveda (сборник музыкальных частей) (Ch 2).

**Гений (genius)** — врождённый мощный духовный голод; не создаётся трудом, но может разжечься духовным стремлением (Ch 1).

**Ги́та (giita)** — песня; **самги́ита (saḿgiita)** = giita + vádya + nrtya (Ch 1).

**Драма (nát́áyana)** — высокая пьеса, требующая ума; в отличие от box-office play (Ch 1).

**Ка́рана → ка́рья (kárańa → kárya)** — причина → следствие; связь этих звеньев даёт читателю симпатическую связь с автором (Ch 1).

**Кави (kavi)** — провидец истины (Ch 1).

**Катха́ / катха́ника́ / катха́ня́са** — длинный рассказ / короткий рассказ / роман (Ch 1).

**Кулакундалини (kulakuńd́alinii)** — дремлющая единичная сила (jiivashakti), пробуждаемая тантрической садханой (Ch 2).

**Мисофобия (mysophobia)** — ханжеское избегание «грязного» в искусстве; правый тупик (Ch 1).

**Му́дра́ (mudrá)** — жест; язык + жест = успешная игра; в танце без слов выражает чувство (Ch 1).

**Нртья (nrtya)** — танец; ритмический (без жеста — физкультура) и жестовый (без ритма — пантомима) (Ch 1).

**Прала́па (prálápa)** — «бред»; то, чем кажется алапа непосвящённому (Ch 1).

**Рши (rshi)** — мудрец-интеллектуал кшатрийской эпохи ариев (Ch 2).

**Са́хитья (sáhitya)** — литература как «движение вместе с течениями жизни» + «сосуществование с благом» (sa + hita) (Ch 1).

**Са́хитьика (sáhityika)** — творец с мыслью о благе всех; «маяк настоящего, менестрель прошлого, вестник будущего» (Ch 1).

**Самскара (saḿskára)** — ментальный реактивный моментум, влияющий на проявление таланта (Ch 1).

**Сва́бха́ва (svábháva)** — истинная природа человека, выражаемая через insight + expression + boldness (Ch 1).

**Срин́ти (shruti)** — «услышанное»: веды, передававшиеся на слух до изобретения письменности (Ch 2).

**Тантра** — не религия, а образ жизни / наука садханы; старше вед; едина для хинду и буддистов (Ch 2).

**Шива (Sadáshiva)** — неарийский систематизатор Тантры; изобретатель садханы, танца, музыки, медицины; «отец» человеческой цивилизации (Ch 2).

**Шива-лиун̇га (Shiva-liuṋga)** — философский символ Сущности, из которой всё происходит (Ch 2).

**Шре́я / пре́я (shreya / preya)** — блаженный духовный союз / чувственное наслаждение; их союз — эволюция литературы (Ch 1).

**Шудра-варна (Shúdra Varńa)** — четвёртое сословие, созданное ариями из побеждённых неариев (Ch 2).

**Эпохальная / прибрежная литература** — yuga (движется с эпохой) / tat́astha («на берегу» между временным и вечным) (Ch 1, сноска).
