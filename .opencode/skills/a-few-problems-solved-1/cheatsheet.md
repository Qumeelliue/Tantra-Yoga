# Читшит — правила решений по Саркару (A Few Problems Solved Part 1)

## Литература и искусство

| Ситуация | Правило |
|---|---|
| Оценить произведение | Тест сахитьи: всестороннее развитие + движение с народом + радость + связь причин/следствий |
| «Искусство для искусства» | Отвергнуто: искусство оправдано служением — «Art for service and blessedness» |
| Дело о пристойности | Середина: ни ханжество (мысофобия), ни спекуляция на низком; суди по мотиву и эффекту |
| Автор не может писать «грязно» | Художник обязан сочувствовать всем, включая «падших»; не изображай человека объектом насмешки |
| Понять, утолит ли конечная цель | Конечное только разжигает аппетит; бесконечное насыщает лишь Бесконечное |

## Форма и жанр

| Ситуация | Правило |
|---|---|
| Кому пишется | Массам — эпохальный язык (yuga), знание проблем эры; ценителям — драма/nát́áyana |
| Время дорого | Короткие форматы; соединяй пьески; suspense после введения в сложный сюжет |
| Оценить поэзию | Поэзию поймёшь, коснувшись сердцем сердца поэта; эпос устарел |
| Детская литература | Кристальная простота + воображение; никакого страха (даже в колыбельных) |
| Натуральность в искусстве | Не абсолют: тонкие чувства требуют особого языка/жестов; живость подачи важнее |

## Экономика творцов

| Ситуация | Правило |
|---|---|
| Как издаваться | Авторские кооперативы; не монополисты-издатели, не государство |
| Кто поддерживает художников | Общество; в демократии — государство как представитель народа |
| Как поддержать театр | Гос. театры без налогов на развлечения + гонорар за дни показов |
| Как поддержать живопись/скульптуру | Галереи-библиотеки (выдача оригиналов), выставки, свобода от канонов |
| Награды | Только неполитический совет; гос. награды = пропаганда |
| Критика | Компетентна + сочувствующая; за авторитет — ответственность |

## История / Тантра

| Ситуация | Правило |
|---|---|
| Происхождение вед | Rgveda — неиндийская; Atharvaveda — под влиянием Тантры; Sámaveda — сборник |
| Что такое Тантра | Наука садханы, не религия; хинду и буддийские тантры — одно разными словами |
| Кто «отец» цивилизации Индии | Шива (неарийский тантрик), не арийский бог |
| Подавление культуры | Смешение неизбежно и полезно; «чистота крови» — миф |

## Быстрые сигналы («tells»)

- Видишь награду от государства/партии за творчество — вероятна пропаганда, а не искусство.
- Текст «взахлёб» эксплуатирует низкое — коммерческая спекуляция («мухи на гное»), не сахитья.
- Критик, не создавший ничего, разносит всех — выдаёт собственные провалы.
- Произведение на шаг-два впереди народа — здорово; на сто шагов — оторвано.
- Слабое «динамичное» слово — скорость без движения («бык на маслобойне»).
- «Чистюля» избегает болезненных тем — ханжество (правый тупик).
- Доказывают «чужой бог = наш» — признают его силу (Шива-аргумент).
