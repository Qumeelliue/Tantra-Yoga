# Chapter 7: The Hub of Universal Activities

*Дискурс от 22 февраля 1979, DMC Bhopal.*

## Core Idea

Вселенная — собрание волн, всё пульсирует (systaltic), ничего линейного. Всё эманирует из nucleus — **Hub of Universal Activities** (Puruśottama). Микрокосмы вращаются вокруг Него по орбитам; две силы (centripetal/centrifugal = vidyá/avidyá shakti) управляют радиусом. Sádhaná = сокращение радиуса до нуля — слияние.

## Frameworks Introduced

- **Волновая модель**: вселенная — набор волн различной длины; не только tanmátras, но каждая манифестация вибрационна. «Ничего линейного; всё пульсирует». Действия = физические, интеллектуальные, экзистенциальные — все из nucleus.
- **Орбитальная иерархия**: атом (nucleus+электроны; разбаланс → fusion/fission) → молекула → земля/луна → солнечная система → космологический порядок (не круглый/овальный, неправильной формы). 
- **Конечность вселенной**: не ananta — создана статическим принципом → имеет форму и границы; конечна, хоть и огромна. Nucleus = **Puruśottama**.
- **Две силы**: центробежная (**avidyá shakti** — радиус растёт) и центростремительная (**vidyá shakti** — радиус падает); движение не прекращается. «Убежать нельзя: что вне Его?»
- **Ájiiva / ábhoga** (см. ch03): физическое занятие / психический пиабал — все существа с ними вращаются.
- **Rásaliilá**: движение — «танец» (ритмическая вибрация); при гигантских волнах — **táńd́ava**. Parama Puruśa — «rasa vae sah» (поток personified). Человек — «идеологический поток», не «разумное животное».
- **Brahmacakra**: вращение всех существ; сокращение радиуса поднимает по ступеням: растения → животные → человек → mahápuruśa → слияние («Brahmavid Brahmaeva bhavati»). 
- **Sádhaná = сокращение радиуса**: систематическое усилие уменьшить разрыв; обязательно для всех (молодой/старый, мужчина/женщина).
- **Мысль и память**: как функции ума; с идеацией «от Него» — dhruva smrti (постоянная память).
- **Конец движения**: пока думаешь «я и Господь отдельны» — вращаешься; момент «я и мой Творец — одно» — слияние (mokśa).
- **Наука слияния**: учится только у Него; «Muktyákaunkśáyá sadgurupráptih» — сильное стремление → приходит Sadguru; «Brahmaeva gururekah náparah».

## Key Concepts

- **Малый «я» и большой «Я»**: в каждом два «я»; конфликты людей — из-за малого «я».
- **Gurur Brahmá, Gurur Viśńu…** — «Tasmae Shrii Gurave namah» — Господь приходит в форме прецептора.
- **Dharma sádhaná** — стремление к бессмертной позиции; достижение высшего ранга = mokśa.
- **Смерть тела** — «мёртвое тело всё равно движется» (вращается с вселенной).

## Mental Models

- «Ум — планета: чем ближе к Солнцу (Puruśottama), тем короче орбита; садхана — включить двигатели внутрь».
- «Движение = танец: даже падение — часть ритма; главное — направление к nucleus».
- «Слияние — не взлом, а учеба: секрет преподаёт Сам Sadguru».

## Anti-patterns

- **Считать вселенную бесконечной** — она конечна (статический принцип).
- **Пытаться «выйти из орбиты»** — некуда; «что вне Его?»
- **Забывать о сокращении радиуса** — «идёшь с закрытыми глазами — радиус растёт, деградация».
- **Конфликтовать из-за малого «я»** — «большой "Я" один на всех».

## Worked Example

*Разбор автора — радиус и рождение.* По своему пиабалу существо получает следующее тело: обжора → тело свиньи; гневливый → тело буйвола (аллегория); стремящийся к близости → развитое человеческое тело. Сокращение радиуса поднимает по ступеням существования; при нуле — слияние с Puruśa. Если человек с закрытыми глазами движется «от Него» — радиус растёт и происходит деградация. Задача садхаки — систематически сокращать радиус; этот процесс — садхана.

## Key Takeaways

1. Всё — волны из nucleus (Hub); ничто не линейно.
2. Вселенная конечна; орбитальная модель справедлива от атома до космоса.
3. Centrifugal (avidyá) увеличивает радиус; centripetal (vidyá) — уменьшает.
4. Sádhaná = сокращение радиуса до нуля (слияние, mokśa).
5. Секрет слияния преподаёт Sadguru (Brahmaeva gururekah).
6. Пока есть «я и Он отдельны» — движение; осознание единства — конец движения.
