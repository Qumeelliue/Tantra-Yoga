# Читшит — Subháśita Saḿgraha Part 11

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Выбираешь объект вовлечённости | Личный (с любовью/nucleus) > безличный («судья-машина»); Táraka Brahma — личный (ch02) |
| Оцениваешь метод/решение | Сверь по иерархии: суть > медитация > повторение > форма; форма без идеации = показная (ch01, ch08) |
| Хочешь понять, что тормозит человека | Пройди 14 оков (6 внутренних + 8 внешних) (ch03) |
| Подбираешь меру ответственности | По фазе: pashvácára (внешний контроль) → viirácára (внутренний+внешний) → divyácára (чисто внутренний) (ch04) |
| Оцениваешь профессию/доход | Sentient livelihood: не на раздоре, вере, смерти, процентах (ch03) |
| Реагируешь на «самоистязание» | Penance без идеации — пытки; с идеацией — Господь направляет (ch05) |
| Человек чувствует «Он слишком велик» | Маhimnabodha: лечи «Он — Отец, я — ребёнок»; капля — часть океана (ch05) |
| Думаешь «время придёт, спасёмся» | Пассивность/лень; спасение — через sharańágati и действие сейчас (ch02, ch06) |
| Ищешь, кого считать «святым» | Садху = чистота + сострадание («как моя жизнь дорога мне»), не одежда (ch06) |
| Видишь «грешника» | Не ненавидь: никто не oblivious к высшему; Hari крадёт грехи (ch03, ch10) |
| Оцениваешь близость к цели | Орбитальная модель: radius падает (vidyá/садхана) или растёт (avidyá/эго)? (ch07) |
| Сомневаешься в «пути» | «Mahájano yena gatah sa panthá» — иди по стопам великих (ch08) |

## Мини-справочник «фазы духовного прогресса» (ch04)

| Фаза | Характер | Обращение к Господу |
|---|---|---|
| Pashvácára | животная; внешнее давление | Pashupati |
| Viirácára | героическая; внешнее + внутреннее | Viireshvara |
| Divyácára | божественная; чисто внутренний контроль | Mahádeva |

## Мини-справочник «ошибки путей» (ch05, ch08)

| Ошибка | Суть ошибки |
|---|---|
| Бесцельные добрые дела | движение без направления |
| Penance без идеации | телесные пытки без пользы |
| Ритуал/форма без сути | механика, идеация забыта |
| Подавление (йога-сушка) | «сон не йога»; пропенсы вернутся |
| Знание без любви | «человек знания — 100% провал» |
