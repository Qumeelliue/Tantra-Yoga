# Глоссарий — Subháśita Saḿgraha Part 11

**Ájiiva (аджива)** — физическое занятие/средства существования; должно быть sentient (не юрист-«стравливатель», не торговец религией, не «торговец смертью», не ростовщик) (ch03).

**Ábhoga** — психический пиабал (см. SS8 ch05); объект, которым занят ум (ch03, ch07).

**Aśt́apásha (ашта-паша)** — восемь внешних пут: ghrná, shaunká, bhaya, lajjá, jugupsá, kula, shiila, mána (ch03).

**Bhavámbodhipotam** — «корабль на океане bhava»: Supreme как спасительное судно через океан неотработанных самскар (ch01).

**Bhiiśańa** — «Устрашающий»: из страха перед Ним природа соблюдает порядок; также Darpahárii — «Вор тщеславия» (ch01).

**Brahmacakra** — космический цикл вращения микрокосмов вокруг Puruśottama (ch07).

**Divyácára** — третья фаза духовного прогресса: чисто внутренняя, контроль пропенс; практикующий становится deva → Mahádeva (ch04).

**Ekabuddhi** — однонаправленный ум; движение к единственному desideratum (ch09).

**Gopii bháva** — «привычка радовать Parama Puruśa»: действие ради Его удовольствия, а не своего (ch05, ch08).

**Hari** — «вор грехов» (harati pápán): крадёт грехи без спроса, освобождая от цикла рождений (ch10).

**Jada-sphot́a** — материальный взрыв небесного тела, рождающий новые звёзды/планеты (ch03).

**Japa** — повторение слова с пониманием его значения; идеация впечатывается, пропенсы интровертируются (ch01).

**Liilá** — божественная игра/драма; мир как сцена, актёры играют роли (ch09, ch10).

**Liilánanda / nityaananda** — блаженство в transitory состоянии творения / в Eternal Stance (ch10).

**Mahádeva** — Supreme Controlling Faculty вибраций; цель divyácára (ch04).

**Mahimnabodha** — чувство «Он слишком велик и мудр для меня»; inferiority complex, увеличивающий радиус (ch03, ch05).

**Muktidátá** — даритель liberation; истинный — Táraka Brahma (ch06).

**Pashupati / Viireshvara / Mahádeva** — имена Господа по фазам практики: Lord животных / Lord героев / Lord богов (ch04).

**Pashvácára / viirácára / divyácára** — три фазы Тантры: животная / героическая / божественная (ch04).

**Paritrána vs trána** — облегчение постоянное vs простое (ch06).

**Puruśottama** — nucleus вселенной, Supreme Culminating Point (ch03, ch07).

**Rásaliilá** — вечное движение микрокосмов вокруг Puruśottama; танец (ch07).

**Śad́aripu** — шесть внутренних врагов: káma, krodha, lobha, moha, mada, mátsarya (ch03).

**Sadhguru** — компетентный духовный прецептор; приходит при сильном стремлении (Muktyákaunkśáyá sadgurupráptih) (ch07, ch08).

**Saḿyoga** — реальный йога: слияние jiivátma и Paramátma (ch05).

**Sentient livelihood** — правильные средства существования (ср. samyak ájiiva восьмеричного пути) (ch03).

**Sharańágati** — полное прибежище/самоотдача; «единственный ответ на все духовные вопросы» (ch06).

**Táraka Brahma** — Освободитель (trae+ńak); личный Бог, любящий Отец, muktidátá (ch02, ch06).

**Vaekuńt́ha** — состояние без психического сжатия; «не идеал» по сравнению с местом, где поют kiirtana (ch03).

**Yugasandhi / yuga** — критический переход эпохи; момент прихода Táraka Brahma (ch02, ch06).

**Yogashcittavrttinirodhah** — «подавление пропенс = йога» — критикуется: подавление не освобождает (ch03, ch05, ch08).
