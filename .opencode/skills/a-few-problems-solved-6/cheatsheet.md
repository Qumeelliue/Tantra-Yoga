# Cheatsheet — A Few Problems Solved Part 6

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Боишься гибели цивилизации | Asti/Bhati/Ananda; человечество перейдёт на другие планеты |
| Оценка общества/движения | Проверь 6 факторов (идеология, культ, соц-экон теория, взгляд, shástra, предшественник) |
| «Научный прогресс» объявлен | Прогресс = движение к Shubha; плюсы/минусы балансируются |
| Повысили зарплату, налоги тоже | Не прогресс: покупательная способность не выросла |
| Теория красивая, не работает | Четыре причины: лицемерие, отрыв теоретика, неэффективность, неверная среда |
| Новый продукт | Сначала практика (яблоко упало) → потом теория |
| «Культурно продвинутый» народ | Проверь цивилизацию (refinement + judgement) |
| Нация/каста делит людей | Общество = движение вместе; права и обязанности — всем |
| Сообщество деградирует | Проверь 3 причины греха: нехватка pabulum / пере-накопление / застой |
| Сравнение религий | Ищи противоречия логике; проверяй практическую применимость |
| Культурная экспансия/образование | Берегись подрыва Práńa Dharma нации |

## Пять чувств (проверка прогресса)

1. Anukulavedaniiyam — приятное.
2. Pratikulavedaniiyam — неприятное (балансирует первое).
3. Avedaniiyam — отрицание (неестественно).
4. Nirapekśavedaniiyam — подавление (неестественно).
5. Aplutavedaniiyam — духовное (только плюсы, реальный прогресс).

## Caturvarga (цели)

Káma (физическое) / Artha (интеллектуальное) — «прогресс» с минусами; Dharma (психо-духовное) / Mokśa (духовное) — настоящий прогресс. Целься в Dharma и Mokśa.

## Четыре причины провала теории

1. Психология лицемера (теория для вида).
2. Психология теоретика (башни в небе).
3. Неэффективность применения.
4. Экологическая трудность (неверная среда).

## Три причины греха → решения

1. Нехватка pabulum → гарантировать минимум.
2. Пере-накопление не используется → интеллектуальная пропаганда.
3. Застой → «sadvipras с молотом» (движение).

## Шесть факторов выживания

Идеология → культ (sádhaná) → соц-экон теория → социальный взгляд → shástra → предшественник.

## Sadvipra-пра́на́я́ма

Вдохни вселенную (purak) → удержи (kumbhak) → выдохни с благом (recak).
