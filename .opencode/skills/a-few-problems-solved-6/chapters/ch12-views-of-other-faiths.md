# Chapter 12: Views of Other Faiths

*Классы, 1957, Jamalpur.*

## Core Idea

Обзор важных вер/философий мира, сгруппированных по сходству: (1) Буддизм и Шанкара; (2) Pátaiṋjala и Sáḿkhya; (3) Семитские веры (не обсуждаются); (4) Árya Samája; (5) Марксизм. Саркар анализирует сильные и слабые стороны каждой с точки зрения практической применимости и логики.

## Frameworks Introduced

- **Группы**: (1) Buddhism + Shaḿkara; (2) Pátaiṋjala + Kápila Sáḿkhya; (3) Semitic (Judaism/Christianity/Islam) — не обсуждаются; (4) Árya Samája; (5) Marxism.
- **Буддизм**: `átman` — непрерывный поток знания (vinána в пали). Будда не использовал слово átman → разногласия bhikśus → три конференции → Tripit́aka (Vinaya/Sutta/Abhidhamma). Ститвы: Sthaviravádii (Theraváda, юг) vs Mahásáḿghika (Mahayana, север). Pali — «деревенский язык». Четыре школы Máyáváda: saotántrika, vaebháśika, mádhyamika (shúnyaváda), Baoddha yogácára (kśańika vijiṋánaváda). Четыре благородные истины; atisukhaváda — искажение. Вопрос «есть ли Бог» — Будда молчал.
- **Charvaka**: материализм (caturbhúta — 4 элемента); нет átman/Paramátman/Vedas; «живи счастливо, ешь масло в долг». Принимает только pratyakśa как pramáńa.
- **Śad́adarshana** (шесть школ): Kápila Sáḿkhya (puruśa + Prakrti, без Paramátman), Pátaiṋjala (много puruśas + Prakrti, есть Бог), Gaotama Nyáya, Kańáda Nyáya (Vaesheśika), Jaemini Púrva Miimáḿsá (ритуалы), Uttara Miimáḿsá (Vedánta, Brahma, не верит в átman/jagat).
- **Shaḿkara**: Nirguńa Brahma; «Brahma satyaḿ jaganmithyá»; критика: кто видит иллюзию? как Nirguńa «видит» (видение — качество)? Mayá не может быть отдельной сущностью в advaetaváda; победил буддистов «игрой слов». Jayanta Bhatta — главный критик.
- **Pátaiṋjala + Sáḿkhya**: много puruśas; Prakrti создаёт мир для удовлетворения puruśas (нелогично — у puruśas нет ума); Prakrti отдельна (иллюзорно — она энергия Puruśa); Sáḿkhya — без Бога (niriishvaraváda), Pátaiṋjala — с Богом (seshvaraváda); оба поддерживают идолопоклонство.
- **Árya Samája**: jiivas/jagat/Brahma — все anádi (нет необходимости sadhana); yajiṋas как поклонение (без рационального смысла); pralaya — иррационально.
- **Марксизм**: «равенство» только теоретическое (люди неодинаковы); живёт на эксплуатации бедности; нет терпимости к другим; цель — мнимое равенство; существует на насилии.

## Key Concepts

- **Tripit́aka** — Vinaya/Sutta/Abhidhamma.
- **Sthaviraváda / Maháyána** — ветви буддизма.
- **Shúnyaváda / Vijṋánaváda** — школы Máyáváda.
- **Caturbhúta / paiṋcama bhúta** — четыре/пятый элементы.
- **Śad́adarshana** — шесть теистических школ.
- **Brahma satyaḿ jaganmithyá** — формула Шанкары.
- **Pramáńa** — три вида валидации: pratyakśa, anumána, ágama.

## Mental Models

- «Думай о философиях как о инструментах: каждый хорош для своей задачи, но не для всех».
- «Проверка: кто совершает садхану в системе без jiivas? (Шанкара) — дыра».
- «Дуализм (dvaeta) vs монизм (advaeta) — спорить о природе Prakrti/Puruśa».

## Anti-patterns

- **Материализм без духа** (Charvaka, Марксизм) — «сознание из четырёх элементов — как красный цвет из бетеля».
- **Нигилизм (shúnyaváda)** — «всё из ничего» — логически уязвим.
- **Теоретическое равенство без практики** (Марксизм) — «равенство только на словах».
- **Молчание о Боге** (Будда) — оставило почву для разногласий.

## Worked Example

*Спор Шанкары с shúnyavádiis.* Они: «вселенная — из ничего и в ничего; всё — сон». Шанкара: «если сон, должен быть тот, кто видел сон». «Нет сновидца», — отвечают. «Тогда как иллюзия верёвки-змеи возможна? Нужна верёвка (субстрат) и человек, который ошибается». Шу́ньявадины не смогли ответить. Вывод Шанкары-критика: его победа — «игрой слов», а не фактом.

## Key Takeaways

1. Буддизм: átman как поток знания; раскол на Sthaviraváda/Maháyána.
2. Charvaka — чистый материализм без духа.
3. Шанкара победил буддистов логикой «кто видит сон», но сам уязвим (Mayá).
4. Sáḿkhya/Pátaiṋjala — дуализм puruśa/Prakrti с логическими дефектами.
5. Árya Samája — anádi всё: садхана не нужна — иррационально.
6. Марксизм — теоретическое равенство, эксплуатация бедности, насилие.
