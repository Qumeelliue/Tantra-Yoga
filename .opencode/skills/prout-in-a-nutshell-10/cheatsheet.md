# Читшит — правила решений по Саркару (Prout 10)

## Музыка и гармонизация

| Ситуация | Правило |
|---|---|
| Собрать инструмент ума/команды | Сангиита-триединство: песня (идея+bháva), инструмент (вибрация состояния), танец (жест/архетип) |
| Проверить песню | Есть ли ритм + мелодия + глубокая идея (bháva)? Без bháva — нет сладости |
| Проверить инструмент | Держит ли параллелизм с чувством (bháva)? Потерял — бесполезен |
| Выбрать танец/форму | Ки́ртан — lalita mármik (не утомляет); борьба с разрушением — дух táńd́ava |
| Связать дыхание и движение | Svara Shástra: ритм песни/танца/инструмента с вдохом-выдохом |

## Эстетика и супра-эстетика

| Ситуация | Правило |
|---|---|
| Отличить эстетику от супра-эстетики | Эстетика = удовольствие «мне»; супра-эстетика = потеря «я» в источнике (mohanavijiṋána) |
| Оценить произведение по адресату | Радость людям — эстетика; радость Парама Пуруше (киртан) — супра-эстетика |
| Удержать аудиторию | Дай тонкое переживание: к грубому не вернутся («talkies» побеждают немое кино) |
| Направление эволюции | Грубое → тонкое → тончайшее; предел — «некому вкушать» |

## Искусство и наука

| Ситуация | Правило |
|---|---|
| Классифицировать деятельность | Искусство = тонкий стиль чувства; наука = цепь причины и следствия |
| Найти причину | Всё причинно («Kárańábhávát káryábhávah»); ищи причину за следствием |
| Оценить «знание» | Субъективизация объекта — тень (умбра/пенумбра); знание субъекта — Átmajiṋánam |
| Куда идти «по святым местам» | Высший тиртха — Атман внутри «я существую», не внешние паломничества |
| Минимальная квалификация духовной науки | Человеческая форма + преданность; без каст, рас и дипломов |

## Контроль и дисциплина

| Ситуация | Правило |
|---|---|
| Спроектировать контроль сфер | Физическая — страж/механизм; психическая — философия; духовная — стремление |
| Построить долговечную систему | Пара «совершенный текст + неопороченный блюститель»; дефект любого — смертелен |
| Понять, почему философии вредят | Дефект психических влечений топит всё сообщество надолго |
| Победа над силой | Не мечом и не мускулами — богореализацией («Ámrái jay kariba…») |

## Преданность и ритуал

| Ситуация | Правило |
|---|---|
| Освобождение | Только Brahmaniśt́há (полная преданность Брахме); не толкования, не ритуалы |
| Оценить ритуал | Ум течёт к сути или к форме? Форма без направленного ума пуста (vidhipújana) |
| Путь к цели | niśt́há → Brahma sádhaná → Brahmasadbháva |
| Найти Брахму | Púrńa: целостный, бездефектный, безмерный; великий, возвеличивающий других |

## Быстрые сигналы («tells»)

- Видишь «изысканность» без глубокой идеи — украшение, не эстетика.
- «Виртуозность» без связи с чувством — вадья, потерявшая свойство.
- Ритуал с проверкой реквизита и голодным исполнителем — ум течёт к форме, не к иште.
- Идеология «мы — избранные, остальные прокляты» — дефектная философия, маркер Саркара.
- Философия «всё — материя» — редукция человека до земли и камня.
- После тонкого опыта возврат к грубому «не продаётся» — ты на верном пути утончения.
