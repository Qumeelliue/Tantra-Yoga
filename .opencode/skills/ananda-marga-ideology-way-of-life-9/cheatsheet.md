# Читшит — правила решений по Саркару (Ideology and Way of Life Part 9)

## Космология и шакти

| Ситуация | Правило |
|---|---|
| Откуда вселенная | Guńakśobha (потеря баланса в треугольнике сил) → biija bindu → náda → kalá |
| Что значит «бесконечность» Citi Shakti | Не «без конца», а «не имеющая свидетеля»; ум не может её охватить |
| Энергия vs материя | Форма в абстрактном = энергия; в материальном = материя; энергия — стадия до факторов |
| Статический принцип | Единственный создатель форм/демаркаций; sentient/mutative не объективизируют |
| Куда движется микрокосм | Подъём kúlakúńd́alinii = конверсия ума в Сознание; внизу — okovы (jiivabháva) |

## Ум и практика

| Ситуация | Правило |
|---|---|
| Определить уровень ума | citta-управляемый (животное) / aham-управляемый (человек, интеллект) / mahat-управляемый (интуиция) |
| Ум не концентрируется | Диагностируй: kśipta/múŕha/vikśipta; только ekágra ведёт к самадхи |
| Много пропенсити | Развитие интуиции уменьшает их до одной — ánanda vrtti |
| Различение átman vs ego | Viveka khyáti; постоянство = dharmamegha samádhi (нужны vaerágya + abhyása) |
| Отречение | Ваерагья (отсутствие привязанности), НЕ отвращение (двeша — тоже п.аб.ум) |

## Самадхи

| Ситуация | Правило |
|---|---|
| Самадхи в первых трёх состояниях ума | Ложное (jaŕa samádhi: ум → материя) |
| Samprajiṋáta samádhi | 4 ступени: savitarka → savicára → sánanda → sásmita |
| Asamprajiṋáta / nirvikalpa | Приостановка в Cognitive Faculty; puruśa-khyáti |
| Путь к savikalpa / nirvikalpa | Iishvara pranidhána (japa) для savikalpa; dhyána — для asamprajiṋáta |
| «Негативные» самадхи (ничто) | Prakrtiliina/videhaliina — латентное семя перерождения; дефективные |
| Mokśa | Постоянный nirbiija samádhi через садхану Puruśa |

## Тантра

| Ситуация | Правило |
|---|---|
| Что такое Тантра | Практика освобождения от статики и расширения; теория вторична |
| Мантра не «работает» | Нет diipanii (активации) или mantra caetanya (понимания духа) |
| Критика «5 M» | Касается только грубой формы; тонкая — гормоны/дыхание/речь/компания/kundalinii |
| Оценить гуру | Три уровня: говорит / учит и проверяет / принуждает к практике (superior) |
| Уровень практика | pashvácára (внешнее давление) → viira (внутренний порыв) → divya |
| Поклонение идолу | Самое грубое средство; идеация на Brahma — лучшее |

## Карма

| Ситуация | Правило |
|---|---|
| Свободный выбор | Исходное действие (pratyayamúlaka) — прямая воля, творит самскары |
| Механическое действие | Реактивное (saḿskáramúlaka) — плод прошлых исходных действий |
| Оценить действие | Цвета: белое (приятное), чёрное (болезненное), смешанное, ни белое/чёрное (духовное) |
| Боль сегодня | Реакция на прошлое действие; не вини Бога (adrsta/drśt́a vedanīya) |
| Как освободиться | Заполни vásanábhánd́a Сознанием: Brahmacarya + аштанга-йога (anubhava → prájiṋa → puruśa-khyáti) |
| Думаешь о вреде, не делаешь | Мысль тоже создаёт самскары; следи за мыслями |

## Быстрые сигналы («tells»)

- «Он знает, но не практикует» — pandits и buttermilk (суть — у йогов).
- Гордость относительным знанием — «знание» стало статичным; bookworms не джиняни.
- Трясущаяся рука при первом грехе — гармония ещё не нарушена; закоренелый — «адаптировался».
- «Я хочу стать богатым, но не стараюсь» — pra-vrtti без усилия; не сработает.
- Министр/лидер без личной садханы — «обычно деградирует».
- После инициации — внезапная радость/мука: самскары истощаются; оставайся равнодушным к обоим.
- «Мантра повторена миллиард раз» без идеации — «не принесёт плода».
