# Читшит: правила решений

## Мантра и звук

| Ситуация | Правило |
|----------|---------|
| Гаяттри называют мантрой | Это чанда (ритм): 3 строки × 8 слогов = 24 слога |
| Конфликт чанды и грамматики | Побеждает чанда (va-re-ñi-am, не va-re-ñyam) |
| Нужна тройка факторов мантры | chanda + devatá + rshi |
| Слышен звук действия | Ищи бӣджа-мантру (акустический корень) |
| Творение / сохранение / разрушение | a / u / ma → oṋm (prańava) |
| Хочешь смысл «G-O-D» | Generation, Operation, Destruction |

## Инициация

| Ситуация | Правило |
|----------|---------|
| Vaedikii дӣкша | Просить Бога показать путь |
| Tántrikii дӣкша | Двигаться по пути самому |

## Dharma и Бхагаван

| Ситуация | Правило |
|----------|---------|
| Что главное в жизни | Dharma (опора), затем — всё остальное |
| Dharma сместилась с места | dharmasya glánih → Бог «создаёт Себя» |
| Защита разовая / постоянная | tráńa / paritráńa |
| Разрушение простое / к источнику / специальное | násha / pranásha / vinásha |
| Возврат на место vs размещение | saḿsthápana vs sthápana |
| Садху по одежде или по делу | По делу: «делай другим, что хочешь себе» |
| Кто такой король (bhárata) | Кормит жизнь физически, ментально, духовно |
| Знание (jiṋána) | Субъективизация объектива |
| Отречение | Не бегство: жить полной жизнью без привязанности |

## Атрибуты Бхагавана (пять)

| Атрибут | Значение |
|---------|----------|
| Aeshvarya | Все оккультные силы |
| Yasha | Признание величия (не всеми) |
| Shrii | Притяжение |
| Jiṋána | Знание (субъективизация) |
| Vaerágya | Не-привязанность в миру |
