# Паттерны и приёмы анализа

## Разбор ведической мантры
**Когда использовать:** при анализе любого сакрального текста или мантры.
**Как:** (1) определи чанду (ритм, число строк × слогов); (2) найди девату (слово-обращение); (3) назови рши (созерцателя); (4) при конфликте ритма и грамматики следуй чанде.
**Компромиссы:** упрощение может потерять детали; для точного слогового счёта нужен оригинал.

## Поиск акустического корня явления
**Когда использовать:** для понимания природы любого действия/явления в учении Саркара.
**Как:** действие → вибрация → звук; отождестви звук с бӣджа-мантрой; для макрокосма: a=творение, u=сохранение, ma=разрушение.
**Компромиссы:** символический уровень; не путать физическую акустику с духовным звуком.

## Анализ социального кризиса через dharma
**Когда использовать:** при оценке общественной или исторической ситуации.
**Как:** найди, что смещено со своего места (dharmasya glánih); определи вид разрушения (násha/pranásha/vinásha); реши, нужна ли помощь разовая (tráńa) или постоянная (paritráńa).
**Компромиссы:** категории нормативны; не каждый конфликт — «смещение dharma».

## Оценка «по функции, а не по форме»
**Когда использовать:** при определении садху, короля, знания.
**Как:** садху = следующий dharma (не одежда); bhárata = кормящий жизнь (не титул); jiṋána = субъективизация (не количество информации).
**Компромиссы:** требует личного суждения; внешние маркеры удобнее, но обманчивы.
