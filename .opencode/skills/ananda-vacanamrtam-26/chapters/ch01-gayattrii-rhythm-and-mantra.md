# Chapter 1: Gáyattrii Rhythm and the “Gáyattrii Mantra”

*Дискурс от 8 декабря 1964, Salem.*

## Core Idea

Гаяттри — это не название мантры, а название **чанды (ритма)**. Мантра «Тат Савитур варен́йам» — официально «Savitr Rk» — сочинена в гаяттри-чанде: три строки по восемь слогов (24 слога). Понимание структуры ведической мантры раскрывает механику звука и вибрации, включая бӣджа-мантры a, u, ma и prańava (oṋm).

## Frameworks Introduced

- **Три сущности ведической мантры**: каждая мантра имеет (1) **chanda** — ритм, в котором сочинена; (2) **devatá** — слово-обращение к Богу (здесь «Savitá»); (3) **rshi** — созерцатель («draśt́a» = увидевший истину). Здесь: чанда — гаяттри (24 слога, 3×8); девата — Savitá; рши — Вишвамитра (3-я ман́д̣ала Ригведы).
- **Чанды Вед (7)**: га́яттри, ус́н́ик, триш́т́уп, ануш́т́уп, джагати, брхатии, паункти.
- **Правило «чанда побеждает грамматику»**: при конфликте ритма и грамматики прав ритм — va-re-ñyam читается va-re-ñi-am для сохранения восьми слогов.
- **Правило «где действие — там звук»**: каждое действие создаёт вибрацию, каждая вибрация — звук; этот звук — «акустический корень» действия, называемый **бӣджа-мантра** (khat́-khat́ — ходьба, há-há-há — смех).
- **Акустические корни творения**: **a** — корень творения (первая буква письменностей: a/alpha/aliph), **u** — сохранения, **ma** — разрушения (sarvalaya, prańásha). Сумма a-u-m → **oṋm = prańava**, активированное Сознание; G-O-D = Generation-Operation-Destruction.
- **Шрути vs письменность**: ведические рши были неграмотны (без письменности), мантры заучивались на слух (shruti = «ухо»); у санскрита нет собственного письма — разные регионы пишут его разными алфавитами.
- **Vaedikii vs Tántrikii дӣкша**: первая — «попросить Бога показать путь», вторая — «двигаться по пути».

## Key Concepts

- **gáyattrii** — ритм из 24 слогов (3 строки × 8); этимология: «тем, кто повторяет, открывается путь освобождения».
- **Savitr Rk** — официальное имя мантры (по девате Savitá).
- **bīja mantra** — семенной/акустический корень действия.
- **prańava / oṋm** — активированное Сознание; a-u-mma.
- **manana** — внутреннее/мысленное повторение; мантра = «то, что при внутреннем повторении освобождает» (mananát tárayet).
- **draśt́a rshi** — «созерцатель» мантры, увидевший истину.

## Mental Models

- «Думай о мантре как о конструкции из трёх опор: ритм + адресат + созерцатель».
- «Используй правило "действие → вибрация → звук", чтобы находить акустический корень любого явления».
- «При конфликте правил (ритм vs грамматика) держись структурного закона (чанда), а не поверхностной нормы».

## Anti-patterns

- **Называть чанду мантрой**: гаяттри — ритм, не имя мантры.
- **Ошибка слогов**: считать 7 слогов в первой строке — ритм требует растяжения (va-re-ñi-am).
- **Приравнивать письменность к языку**: санскрит не имеет собственного письма; не путать Devanagari с языком.

## Worked Example

*Разбор мантры из трёх строк.* «Тат Савитур варен́йам» — строка 1; «бхарго девасйа дхиимахи» — строка 2 (8 слогов); «дхийо йо нах прачодайат» — строка 3 (8 слогов). Первая строка считается 8 слогами только через чтение va-re-ñi-am. Полная мантра начинается с oṋḿ bhúr bhuvah svah (позднее добавление, не часть оригинала). Вывод: ритмическая структура определяет произношение.

## Key Takeaways

1. Три сущности любой ведической мантры: чанда, девата, рши.
2. Гаяттри-чанда = 3×8 = 24 слога; чанда важнее грамматики.
3. Каждое действие имеет акустический корень (бӣджа-мантру).
4. a = творение, u = сохранение, ma = разрушение; их сумма — oṋm.
5. Ведическая традиция была устной (shruti); письменность пришла позже.
6. Дӣкша = два духа: просить путь и идти по пути.
