# Читшит — правила решений по Саркару (Neohumanism 2)

## Равновесие (pramá)

| Ситуация | Правило |
|---|---|
| Оценить систему/общество | Разложи на 3 пласта (физич./психич./духовн.); найди, где потерян баланс |
| Найти стадию распада | Расстройство → разрушение → вырождение; восстановление — в обратном порядке |
| С чего начать восстановление | С физического пласта (иначе антисоциальные элементы возьмут верх) |
| Как чинить баланс | Субтреугольники: субпласт → баланс; с/х на принципе потребления, а не прибыли |
| Можно ли баланс локально | Нет: «свет и тьма не стоят рядом» — нужен достаток для всего мира |
| 4 фактора физич. пласта | Спрос сейчас+будущее, предложение сейчас+будущее, макс. использование земли, 5 принципов PROUT |

## Путь прогресса

| Ситуация | Правило |
|---|---|
| Достичь цели | Три йоги: karma→jiñána→bhakti; до цели доходит только бхакти |
| Оценить «прогресс» | Физич./психич. улучшения относительны; истинный прогресс — духовный |
| Укрепить путь | Карма и джина не заменяют бхакти, а делают его солиднее |
| Держать ум в движении | Без идеологии и ускорения ум грубеет до «пыли» |

## Единство общества

| Ситуация | Правило |
|---|---|
| Система делит людей | Проверь по 7 основаниям: богатство, идеология, раса, каста, религия, нация, язык — деления несостоятельны |
| Эксплуатация | Фундаментальная болезнь: убрав её, убираешь деления и почву оппортунистам |
| Идеи | Различия допустимы (clash & cohesion развивают ум); вредные идеи — нет |
| Язык | Подавление запрещено; различия лишь в двух из шести стадий; все языки — языки Парама Пуруши |
| Паспорта/визы | Отменять — инструменты деления единого общества |

## Догма и знание

| Ситуация | Правило |
|---|---|
| Проверить на догму | Религия/коммунизм/капитализм/«измы»; где догма — даже физический баланс невозможен |
| Оценить «писание» | Шастра = дисциплинирует и ведёт к духовному пути; что давит мышление — не шастра |
| Правильный интеллект | Единственная молитва — направить buddhi к shubha; тщеславие ума ведёт к падению |

## Этика и экология

| Ситуация | Правило |
|---|---|
| Выбор пищи | Минимум сознания (овощи перед животными); проверяй необходимость; умеренность (pramitáhára) |
| Химса vs оборона | Намерение решает: оборона, врачевание, жизнь — не химса |
| Слабость перед злом | Обретай силу и сопротивляйся; «ненасилие из слабости» — маскировка |
| Экология | Всё связано — «общее общество»; перестраивай планы по диктату экологии; руководство — «вселенная наша» (люди+животные+растения) |
| Жестокость | Человек жесточе стервятника: убивает из жадности «во имя религии» — нетающим сердцем |

## Практика ума

| Ситуация | Правило |
|---|---|
| Шесть факторов успеха | Убеждённость «я преуспею», shraddhá, наставник, samatábháva, контроль чувств, pramitáhára |
| Психическая фаза | Prańipáta (самоотдача) → pariprashna (расспрос) → sevá (служение) |
| Служение vs сделка | Служение односторонне; возврат = коммерция. Коммерция для хлеба, служение для духа |
| Паломничество | Истинный тиртха внутри (Átmátiirtham): внешние места без самоотдачи не дают прогресса |
| Вершина | Контакт с kaośikii shakti → слияние с guńatrikońa через локатрикону трёх pramá |

## Быстрые сигналы («tells»)

- Система «богатых ресурсов, бедных людей» — отсутствие pramá при щедрой природе (Ра́р́х, Орисса).
- Запрет процента при наличии банков — саморазоблачение догмы.
- «Подставь другую щеку» при участии в войнах — лицемерие догмы.
- Религия обещает рай и грозит адом — догма, а не духовность (духовность индивидуальна, самадхи коллективен невозможен).
- Коллега по профессии назван «лучшим другом» — это mitram, а не bandhu.
- Ум «без идеи» в застое — ретардация, ведущая к огрублению.
- Благоразумный вопрос к новой идее: «это служит всем или одной группе?» — тест неогуманизма.
