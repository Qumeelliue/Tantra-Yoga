# Глоссарий — A Few Problems Solved Part 5

**Agryábuddhi** — «пиннаклированный»/заострённый интеллект; состояние ума, центрированного на Parama Puruśa, где нет места добру и злу.

**Anurága** — «окрасить свой ум цветом» Parama Puruśa; путь любви к Нему.

**Bhagavad Dharma / human dharma** — единая dharma человечества (на логике, без делений).

**Bhávajad́atá** — санскритское название догмы как «тяжести/косности чувств».

**Devayoni** — «светящиеся тела»: yakśa, siddha, gandharva, kinnara, vidyádhara, Prakrtiliina, videhaliina.

**Dolyátrá** — бенгальский духовный весенний фестиваль Кришны (не Холи/Пхагуйя).

**Gopiibháva** — идеация преданной (гопи), полная нежности и покоя.

**Karma-phala** — «реакция действия»; расплата за поступки.

**Kevala bhakti** — чистая преданность: «ничего не прошу, делай, что хочешь».

**Kiirtana** — громкое прославление Господа.

**Mayá** — имманентная сила Parama Puruśa; источник препятствий.

**Maolik / vimishra sabhyatá** — простая / смешанная цивилизация.

**Neohumanism** — «новообъяснённый гуманизм»: собрание всех естественных выражений человека, флоры и фауны; культ (подход), цель — совершенная духовность.

**Pháguyá** — бихарский весенний фестиваль (восточная ветвь Холи).

**Pinnacled intellect** — см. agryábuddhi.

**Práńa dharma** — жизненная сущность/жизненный корень.

**Preśitamánas** — «рекреированный ум»: временное ментальное тело умершего из эктоплазмы живого.

**Rága** — цвет, который красит другое; ра́га как любовь/привязанность.

**Rágánuga bhakti** — преданность, выражающая внутреннюю любовь через «окраску» ума.

**Saḿskara** — реактивное ментальное импульс.

**Systalsis** — пульсирующее движение (появление/исчезновение) волн.

**Tanmátra** — тончайшая часть фактора материи, «инференциальная волна».

**Utsava** — фестиваль: «рождение заново», свежее вдохновение жить.

**Ádhibhaotika / ádhidaevika / ádhyátmika** — три вида препятствий: физические (пространство-время-личность), психо-духовные, метадуховные. Синонимы: metaphysical/metapsychic/metaspiritual.

**Trifarious expression** — тройное выражение: физический, психический, духовный слои.
