# Cheatsheet — A Few Problems Solved Part 5

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Идею нельзя обсуждать | Догма; проверь логику и свободу принятия |
| Грех «неискупим» | Ум — причина оков; pointed mind = нет добра/зла |
| Что считать реальным | Реальность пульсирует и двойственна; не абсолютна |
| Материализм кажется базой | Его «реальность» дефектна; духовность — прямая линия |
| Сопротивление проекту | Препятствие = признак движения; встречай и борись |
| Команда в усталости | Устрой фестиваль (utsava): доступный, спонтанный |
| Пропаганда «разоружения» | Не верь «на словах»; нужны образование + практика |
| Культура региона | Определи стадию реки (hill/plain/delta) и слияния |
| Учение выглядит духовным | Проверь 4 слоя на семя догмы; Neohumanism — cult, духовность — цель |
| Оценка прогресса | Движение к Shubha = прогресс; удобство ≠ прогресс |

## Лестница преданности

1. Kevala bhakti — «ничего не прошу».
2. Rágánuga bhakti — «окрашен Его цветом, рад Его радости».
3. Высшая — «Его радость — моё единственное желание».

## Три вида препятствий

- Ádhibhaotika (метафизические): время/пространство/личность.
- Ádhidaevika (метапсихические): психо-духовные.
- Ádhyátmika (метадуховные): духовные.

## Цивилизация как река

- Hill stage — рождение (родники/водопады).
- Plain stage — развитие (притоки доминируют).
- Delta stage — созревание (ответвления важнее; впадение в море).
- Слияние рек = слияние культур → смешанные (vimishra) цивилизации.

## Три слоя выражения

Физический → контролируется психическим → духовный. Ускорение духовного слоя поднимает всё.

## Проверка псевдодуховности

Где псевдодуховность — там семя догмы; она вредит во всех 4 слоях и не ведёт к коллективному благу.
