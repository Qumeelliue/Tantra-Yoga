# Chapter 8: Unit Spirit and Cosmic Spirit

*Дискурс 21 октября 1971, DMC, Эрнакулам. На английском.*

## Core Idea

Вселенная велика, но не бесконечна — она vishála (ограниченная) в отличие от virát́a (безграничного Парама Пуруши). Время, пространство и личность — творения ума, поэтому причинность применима только внутри их границ. Разница между дживой (unit) и Космическим Духом — лишь в upádhis (объективности). Девиз: Átmamokśártham jagat hitáya ca.

## Frameworks Introduced

- **Unit vs Cosmic**: автор намеренно говорит «Cosmic Spirit», не «universal» — вселенная не бесконечна. Три фундаментальных связывающих принципа (sattva/rajas/tamas); где статический принцип — там границы → объективность ограничена → не бесконечна. Овальная форма → **Brahmáńd́a** (Brahma + ańd́a, «овальное творение Брахмы»).
- **Творения unit vs Cosmic**: творение Космического — внешняя физичность для всех; творение дживы — её личный психический мир, недоступный другим. Для Космического всё внутренне/психично — «Ему не нужно познавать, ибо ничего внешнего нет».
- **Две птицы (Mundakopaniśad)**: одна вкушает сладкие плоды, другая только свидетельствует. Джива хочет наслаждаться творением; Единый остаётся свидетелем, всегда в равновесии.
- **Ajá (некаузальность)**: Космическая Когнитивная способность и Космическая Связывающая способность некаузальны — их причина вне времени-места-личности, вне ума. Цитата «Ajámekám lohitashuklakrsńám» — Пракрти из трёх цветов (красный/белый/чёрный = раджас/саттва/тамас) создаёт вариации по волнам из Космического Ядра.
- **Причинность (Kánada)**: «Kárańábhávat káryábhávah» — где нет причины, нет следствия; работает только в рамках трёх относительности. Время, пространство, личность — творения Космического ума (психические), не вечны.
- **Пространство не бесконечно**: творение статического принципа имеет границы. Vishála = «большое, но с границами»; virát́a = «большое без границ» — только Парама Пуруша.
- **Время = психическое измерение скорости действия**: земля/солнце движутся + человеческий ум измеряет → «год = 365 дней», «лунный месяц 29–30 дней» — всё измерения ума. В изначальной фазе без существ не было и времени.
- **Eka — единственная нумеральная для Него**: числа — ментальные проекции (mánasika saḿkalpa tatha vikalpa); для Него нет разницы 1/2/1000. Но когда ум пинпоинтится и приходит в контакт с Субъективностью, Он — Один: «Eko'haḿ bahu syám». Ноуменальная причина одна, феноменальные эффекты многи.
- **Upádhi — ключ различия**: разница unit/Cosmic — в объективности. «Tayorvirodho'yam upádhikalpito» — различие навязано упа́дхи (отличающими признаками), не субстанцией. Пример: король с королевством и воин с дубиной — убери атрибуты, и различить трудно. Для Космического наш мир «чисто воображаем»; для дживы до реализации называть мир иллюзией — лицемерие.
- **Nirguńá через отвод ума**: Космический, отводя Себя от объективности, становится nirguńa; джива, отводя ум от своего мира, тоже становится nirguńa — «Brahmavid Brahmaeva bhavati». Это и есть садхана.
- **Sahasrashiirśa Puruśah**: у Него бесчисленные головы/глаза/ноги; человек — «малая волна из великого хаба». Интеллектуальный бой с Космическим — гарантированное поражение; мудрый — преданный, не логик.
- **Puruśa** (две интерпретации): «pure shete yah sah Puruśah» — свидетель во «граде» (pura) физического/психического; «Purasi shete yah» — свидетельствует перед тобой. Он всезнающ — для Него всё внутренне. Прошлое и будущее знает; «настоящего в духе kala нет» — «настоящее» = удобное слияние ближайшего прошлого и близкого будущего в малый отрезок (в rk слово vartamána не использовано).
- **Два «не могу» Бога**: (1) не может создать второго Парама Пурушу; (2) не может ненавидеть — «ты можешь ненавидеть, Он нет; в этом ты Его больше». Следовательно папии внутри Его ума — как и пуньяваны; Он не ненавидит никого.
- **Átmamokśártham jagat hitáya ca**: девиз — освобождение себя + благо мира; без служения обществу нельзя приблизиться к Нему, без медитации нельзя служить.
- **Прозрачность и штиль**: как увидеть предмет в воде — вода должна быть чистой и без движений (акаин̭кала). Для этого: концентрация (убрать движение) + самоотверженное служение (очистить ум).
- **Отношение — семейное**: джива — ребёнок, Космос — Отец; не судья и преступник; «Грешник для общества ненавистен, для Него — любимый сын».

## Key Concepts

- **Brahmáńd́a** — «овальное творение»; большая, но ограниченная вселенная.
- **Noumenal subjectivity vs phenomenal objectivity** — ноуменальная субъективность (Единый) vs феноменальная объективность (мир).
- **Prakrti / Paramá Prakrti** — Оперативный Принцип / Верховный Оперативный Принцип.
- **Saḿkalpa / vikalpa** — психическая интериоризация / экстериоризация.
- **Avara / para** — «дополнительная» / «высшая» (parávare).

## Mental Models

- «Вселенная — большой овал с границами; безграничен только Он».
- «Причинность — инструмент ума в границах времени-места-личности; за ними — ajá».
- «Время — внутренний спидометр ума; без ума нет времени».
- «Разница дживы и Бога — не в сути, а в сцене (упа́дхи): король и воин».
- «Бой умом с Ним — заранее проигранный; мудрый выбирает преданность».
- «Две невозможности Бога: второго Бога и ненависть — отсюда Его универсальная любовь».

## Anti-patterns

- **Считать пространство/время вечными или бесконечными** — дефектная идея; они творения ума/статического принципа.
- **Именовать единый Дух «universal»** — вселенная конечна.
- **До реализации называть мир иллюзией** — лицемерие (для Космоса да, для дживы нет).
- **Интеллектуально бросать вызов Нему** — гарантированное поражение.
- **Думать, что Он ненавидит грешников** — не может; папия в Его уме, как пуньяван.

## Worked Example

Автор разбирает возражение «Где же настоящее, если Он знает прошлое и будущее?». Ответ: в духе kala настоящего нет — когда я говорю, для тебя это будущее (звук ещё летит), для меня уже прошлое. «Настоящее» — маленький отрезок, где ближайшее прошлое и близкое будущее легко ассимилируются умом. Поэтому в rk «Puruśa evedaḿ sarvam yad bhútam yacca bhavyam» слово vartamána (настоящее) не употреблено. Вывод: всезнание охватывает всё; границ для Него нет.

## Key Takeaways

1. Вселенная vishála (с границами); virát́a — только Парама Пуруша.
2. Время = психическое измерение скорости действия; пространство/время не вечны и не бесконечны.
3. Причинность работает в рамках времени-места-личности; Космическое и Пракрти некаузальны.
4. Разница джива/Космос — только в упа́дхи; сняв их, «микрокосм становится Макрокосмом».
5. Бог не может создать второго Бога и не может ненавидеть — отсюда универсальная любовь.
6. Девиз: Átmamokśártham jagat hitáya ca; медитация и служение взаимозависимы.
7. Ум-озеро должен быть чистым и без волн — концентрация + самоотверженное служение.
