# Читшит — правила решений по Саркару (Subhasita Samgraha 21)

## Цель и реальность

| Ситуация | Правило |
|---|---|
| Оценить ценность объекта/цели | Спроси: dhruva (неизменное) или adhruva (преходящее)? Вечная ценность — только в dhruva |
| Не получаешь ответа из данных | Интровертируй: знание-«понимание» приходит субъективизацией, не расширением внешнего сбора |
| Подобрать метод к объекту | Грубым не измерить тонкое; психическое — умом, познавательное — точечным интеллектом |
| Понять, «утолит» ли достижение | Преходящее не насыщает бесконечную жажду — ищи цель вне времени-места-личности |

## Этика и поведение

| Ситуация | Правило |
|---|---|
| Определить папа/пунья | По эффекту на других: развивает — пунья, вредит — папа; не по книжному «греху» |
| Оценить человека | Считай сальдо праведности (праведность − неправедность), не абсолют |
| Реформировать кого-то | Не в одиночку при слабом сальдо: возьми коллектив моралистов |
| Кто durjana для тебя | Тот, чей контакт вызывает твою деградацию; он же может быть не-дурджаной для другого |
| Niiti vs dharma | Niiti — ворота (делай+не делай, ведёт к благу); dharma — дом (только делай, практика поведения) |
| Куда идти за сутью дхармы | Не в Гималаи и не в пустыню: суть в твоём «Я есть»; компас — практики-садхаки (mahájanas) |

## Дхарма человека

| Ситуация | Правило |
|---|---|
| Отличить уровни | vastu (физика, авто) → jaeva (биология, авто) → Bhágavata (человеческое, требует воли) |
| Человек не следует Bhágavata | Хуже животного: животное не знает правил, он знает и не следует |
| Назвать что-то «служением» | Служение одностороннее (даёшь без ответа); всё взаимное — бизнес (vyavasáya) |
| Определить варну человека | По guna+karma (действие и качества), не по рождению/комплекции |
| Vaerágya — что это | Не отречение: ментальное равновесие в миру при атаках объектов |

## Путь и мотивация

| Ситуация | Правило |
|---|---|
| Выбрать путь к цели | Действие и знание «могут и не привести»; целостная преданность цели — гарантирует |
| Оценить качество мотивации | 5 ступеней: месть → вещи → покой → любовь-ради-себя → любовь-ради-блага (rágátmiká) — только последняя объединяет |
| Определить yoga | Унификация малого «Я» с великим «Я»; НЕ остановка ума и НЕ бе́змыслие |
| Найти своё «Я» | Лестница: глаз → мозг → деятель → «существую» → «знаю, что существую» → Вселенское «Я» |
| Устойчивая мотивация команды/себя | Смести фокус с «что получу» на «что доставлю благо» |

## Быстрые сигналы («tells»)

- «Мне нужен Ты, но дай астму вылечить» — разрыв мысли и речи; суть не в словах, а в полном устремлении.
- «Мы служим нации 50 лет» с прейскурантом — бизнес, не сева.
- Награда/покой/слава как мотив — нижние ступени бхакти, не цель.
- Спор о «правильном направлении» (восток/запад/север) — ниитивадис ссорятся; дхармик молчит: «между ними равновесие».
- Имя, которое «включает» энергию, — личная мантра; чужие имена для садхаки не работают.
- «Я не могу, Он — за границей причинности» — первая причина вне ума: не борись логикой, стань преданным.
