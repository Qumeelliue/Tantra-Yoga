# Читшит — правила решений (Ánanda Vacanámrtam 15)

## Пути развития

| Ситуация | Правило |
|---|---|
| Выбрать стратегию развития | Три пути: знание (анализ), действие (шаг за шагом), преданность (служение) — весы к бхакти |
| Путь знания | Отсевай ложное «переплавкой», как золото из руды; остерегайся раздувания эго |
| Нечистое действие | Отбрось сразу: если работа нечиста и не радует — оставь |
| Действие = | Изменение положения объекта; сегмент вечного потока времени |

## Право и результат

| Ситуация | Правило |
|---|---|
| У меня право | На действие, не на плоды; результат — в руках Prakrti |
| Тревога о последствиях после действия | Бессмысленна: реакция приходит по закону природы |
| Беда случилась | Не вини Náráyańa — «что посеешь, то пожнёшь» |
| Перед действием | Думай тщательно: плод нельзя отозвать |

## Комплексы

| Ситуация | Правило |
|---|---|
| Чувствую себя хуже | Inferiority — ты дитя высочайшей семьи, никто не ниже |
| Чувствую себя лучше | Superiority — все — творение Отца, никто не ниже тебя |
| Боюсь | Fear — Сущий всегда рядом; не бойся людей/догм |
| Думаю «поражение» | Defeatist — путь к Сущему открыт; поражение невозможно |
| Проверка догмы | Догма = идея с чертой; не подчиняйся слепо |

## Садхана (4 стадии)

| Ситуация | Стадия |
|---|---|
| Практика влияет на тело/ум | 1. Физико-психическая (práńáyáma) |
| Внутренняя работа (мантра) | 2. Психическая |
| Расширение к Бесконечному | 3. Психо-духовная |
| Слияние unit с cosmic / Self | 4. Духовная |

## Yuga (стадии пробуждения)

| Состояние | Yuga |
|---|---|
| Спит во тьме, статичная сила | Kali |
| Совесть пробудилась, чувствует долг | Dvápara |
| Встал и двинулся | Tretá |
| Реально идёт вперёд | Satya |

## Дхарма

| Ситуация | Правило |
|---|---|
| Что есть svadharma человека | Mánava dharma (Bhágavata dharma), не религия |
| Столпы mánava dharma | Vistára (расширение), rasa (растворение), sevá (служение), tadsthiti (утверждение) |
| Комфорт в paradharma | Отвергни: лучше умереть в своей дхарме, чем спуститься к животной |
| Служение | Служение человечеству = служение Parama Puruśa — высшая идеология |

## Та́н́д́ава / тантра

| Ситуация | Правило |
|---|---|
| Та́н́д́ава | Танец силы/жизни (Шива); «культ жизни, не смерти» |
| Tála | = tá (та́н́д́ава) + la (лалита); основа восточной музыки |
| Mantra | Повторение, освобождающее ум |
| Tantra | Расширение + освобождение |
| Жить в настоящем | Решай насущные проблемы параллельно с духовным путём |

## Быстрые сигналы

- Видишь «пандита» с титулом, но без реализации — это Pandey-фамилия, не пандит.
- Ум «в контракции» при встрече с богатым/учёным — inferiority; это не Vaekuńt́ha.
- «Есть — высшее дело» — ложь; жизнь для благородных дел, а не для еды.
- Призраки/полёты вещей — не мертвецы, а живой человек с эктоплазмой (Avidya Tantra); ищи виновника среди живых.
- Лицо работающего до пота «безупречной красоты» — даже Индра ищет его дружбы.
