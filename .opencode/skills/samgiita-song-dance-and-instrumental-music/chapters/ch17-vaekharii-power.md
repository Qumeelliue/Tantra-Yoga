# Chapter 17: Vaekharii Power

*Дискурс 2 апреля 1989, Калькутта (Shabda Cayaniká Part 21, «Galavaekharii», Discourse 167).*

## Core Idea

Согласно науке акустики, семя слова пребывает в латентном состоянии в пара́-шакти. Шесть стадий: pará → pashyanti → madhyamá → dyotamáná → vaekharii → shrutigocará. Vaekharii shakti проявляется через uvula (язычок); контроль над ней — ваехарии сиддхи; способность командовать — galavaekharii.

## Frameworks Introduced

- **Шесть стадий звука/слова**:
  1. **Pará** — латентное/спящее состояние слова в пара́-шакти (первичное желание выражения); «семя слова».
  2. **Pashyanti** — слово визуализировано внутренним оком (женский род от pashyat + shatr).
  3. **Madhyamá** — непрерывное усилие от пупка к голосовым связкам для превращения визуализированного слова в выразимое/язык.
  4. **Dyotamáná** — стадия толчка/шевеления uvula (язычка).
  5. **Vaekharii** — превращение в слышимый звук с помощью uvula.
  6. **Shrutigocará** — звук, выносимый uvula между расступившимися губами.
- **Vaekharii power manifest через uvula** (lambiká, kushańd́iká, alijihvá, galashuńd́iká). Контроль через духовную садхану = vaekharii siddhi; частичный контроль — через обычную практику.
- **Galavaekharii** — сила отдавать команды/приказы; усиливает глубину звука и добавляет дрожь в голос. Сладость голоса требует концентрации в kúrma nád́ii (близко к центру vaekharii). «Если сладости в vaekharii мало, в kúrma nád́ii её не будет».
- **Опасность ваехарии без знания**: «эр>удиция без знания» — учёные побеждают в логике грубой силой слова; но «просто игра слов… не даёт спасения» (шлока: бхуктайе на ту муктайе).

## Key Concepts

- **Pará / pashyanti / madhyamá / dyotamáná / vaekharii / shrutigocará** — шесть стадий слова.
- **Paráshakti** — первичное желание выражения.
- **Uvula (lambiká и др.)** — язычок; инструмент ваехарии.
- **Vaekharii siddhi** — контроль над ваехарии через садхану.
- **Galavaekharii** — сила приказа/команды.
- **Kúrma nád́ii** — каналы голосовых связок.

## Mental Models

- «Думай о речи как о конвейере: латентное → образ → усилие → дрожь → звук → звук между губ; понимание стадий = понимание голоса».
- «Используй vaekharii для объяснения и "силы слова" и "пустословия": без знания — игра, не спасение».
- «Помни: сладость голоса растёт из kúrma nád́ii, не из внешней техники».

## Anti-patterns

- **Побеждать в логике одной риторикой (vaekharii) без знания** — «бхuktа́йе, не мукта́йе»: временное удовлетворение ума, не спасение.
- **Пренебрегать kúrma nád́ii** — сладость голоса не придёт.
- **Путать стадии**: vaekharii (слышимый звук) vs shrutigocará (звук между губ).

## Worked Example

*Команда с дрожью.* Сила приказа (galavaekharii) углубляет звук и добавляет дрожь. Но для сладости голоса нужна концентрация ума в kúrma nád́ii (рядом с центром ваехарии). Даже если сладости в ваехарии мало, в kúrma nád́ii она есть — практика открывает её.

## Key Takeaways

1. Слово проходит шесть стадий от латентного к звуку между губ.
2. Vaekharii — слышимая стадия, проявляется через uvula.
3. Vaekharii siddhi — контроль через садхану.
4. Galavaekharii — сила приказа; сладость голоса — из kúrma nád́ii.
5. Риторика без знания — игра, не спасение («бхуктайе на ту муктайе»).
