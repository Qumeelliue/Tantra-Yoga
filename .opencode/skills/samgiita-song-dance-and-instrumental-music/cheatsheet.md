# Читшит — правила решений (Saḿgiita: Song, Dance and Instrumental Music)

## Классификация и терминология

| Ситуация | Правило |
|---|---|
| Песня + инструменты + танец | Это saḿgiita (музыка) |
| Песня + инструменты, без танца | Это giita, не saḿgiita |
| Оценить песню | Нужны ритм + мелодия + bháva (чувство); без чувства — нет сладости |
| Оценить инструментальную музыку | Vádya вибрирует эктоплазм с параллелизмом bháva; без него — бесполезно |
| Назвать певца | saḿgiitajiṋa (виртуоз), не shilpii (ремесленник — создаётся руками) |
| Южная школа музыки | Carnatic = Kodańd́a = Deccan (одна школа) |
| Западный звукоряд | octave (8 нот, первая повторяется); индийский — surasaptaka (7) |

## Эстетика и сверх-эстетика

| Ситуация | Правило |
|---|---|
| Произведение «даёт радость людям» | Эстетическая наука (nandana vijiṋána) |
| Исполнитель «теряет себя» в источнике радости | Сверх-эстетика (mohana vijiṋána) |
| Оценить киртан | Категория mohana; цель — радость Бога; лучший среди всех форм saḿgiita |
| Эволюция вкуса | После тонкого грубое не принимается |

## Киртан — практика

| Ситуация | Правило |
|---|---|
| Нужен помощник садханы | Киртан — садхана-сахаякам (лучший помощник) |
| Тройные страдания (физич./психич./духов.) | Киртан — панацея на всех трёх уровнях |
| Природные/рукотворные бедствия | Коллективный киртан снимает; работает и превентивно |
| Ограничения киртана | Нет ограничений времени, места, лица, образования |
| Вопрос «где Господь?» | Там, где поют преданные (hariparimańd́ala) |

## Танец и жест

| Ситуация | Правило |
|---|---|
| Жест без ритма | Пантомима, не танец |
| Ритм без жеста | Физкультура, не искусство |
| Танец мужской энергии/борьбы | Táńd́ava (колени: пупок=Brahma, грудь=Viśńu, горло=Rudra) |
| Танец радости (в киртане) | Lalita (Па́рват́ии) |
| Женщинам táńd́ava | Запрещён (стимулирует мужественность) |
| Метр (tála) | = tá (tándava) + la (lalita) |

## Музыкальная физиология

| Ситуация | Правило |
|---|---|
| Голос и 16 звуков | 7 нот + 7 ведических svarapráńa + 2 качества (viśa/amrta) через kúrma nád́ii |
| Шесть стадий слова | pará → pashyanti → madhyamá → dyotamáná → vaekharii → shrutigocará |
| Сладость голоса | Из kúrma nád́ii, не из внешней техники |
| Риторика без знания | «Бхуктайе на ту муктайе» — игра, не спасение |

## Инструменты

| Ситуация | Правило |
|---|---|
| Первый природный инструмент | Бамбуковая флейта (báṋshii) |
| Первый струнный | ektárá → viiń/viińá Шивы (настроен на surasaptaka) |
| Инструменты гармонии | ekaváda: harmonium, tamboura (и сверчок, сова, лягушка, шакал) |
| Происхождение | sitar — Персия; violin — Италия; tabla — из mrdauṋga (не из Персии) |

## Жизненные метафоры

| Ситуация | Правило |
|---|---|
| Жизнь как струна | Слишком слабая — безжизненно; перетянутая — рвётся; идеал — средний путь |
| Правила в системе | Жёсткость даёт престиж, но ведёт к угасанию; свобода (kheyál) оживляет |

## Быстрые сигналы («tells»)

- Слышишь «модный» трудный ра́ги́н́ий, которого избегают певцы → вероятна подмена подлинного похожим стилем.
- Музыка «продаёт себя за золото», играет напоказ без мастера → обесценивание.
- Песня без чувства (bháva) → нет сладости, не коснётся души.
- Искусство без духовного идеала → «дрейфующий парусник».
- Религия, запрещающая эстетику → инерция, комплексы, насилие.
