# Читшит — The Golden Lotus of the Blue Sea

| Ситуация | Правило | Почему |
|---|---|---|
| Встретил нуждающегося на пути | Помоги конкретно и лично (накорми, напои, прочитай, вылечи) | Спасённый = надёжный союзник (стебель-жезл) |
| Гонишься за целью (вор/результат) | Действуй тихо, без свиты и афиши | «Сеть ставят тайно»; шум = провал |
| Ночь перед важным событием | Бодрствуй и наблюдай | Сон при опасности = потеря цели |
| Оппонент даёт «выгодное» условие | Проверь на ловушку (рабство/потерю) | Условие демона: 4 дня → вечное рабство |
| Тебя искушают роскошью | Проверь, кто за кулисами ест и страдает | Пир демона: прислуга ест чёрствый рис |
| Власть делит народ религией/иерархией | Разоблачай как разделение | «Голодаете из-за грехов прошлых жизней» = ложь |
| Предлагают «терпи молча, обретёшь силу» | Отклони: это капитуляция | «Пока демоны живы, мир бесполезен» |
| Просят взятку на границе | Откажись | Взятка = утрата независимости |
| Перед ударом | Дай шанс исправиться (переговоры) | Неуспех переговоров легитимирует борьбу |
| После победы | Не казни — отправь в центры исправления | Истинное ненасилие: защита безобидных, борьба с угнетателями |
| Провинившийся раскаивается | Прости и прими обратно | Фея-воровка: крала для подношения, прощена |
| Нужна массовая поддержка | Требования: еда, кров, медицина, образование, достоинство | Слоган восставших объединил всех |

**Запомнить:** младший принц побеждает через **помощь + тайну + бодрствование + ненасилие**; старшие — через **престиж + шум + сон**.
