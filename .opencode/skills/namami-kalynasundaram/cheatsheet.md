## Правила решений

| Ситуация | Правило |
|---|---|
| Скрываешь проступок | Признай — давление спадает; всё уже видно |
| Интеллектуал «много знает» | Увеличь долю действия/служения |
| Просьба о чуде/исцелении за деньги | Гуру не продаётся; подношение бескорыстно |
| После исправления | Не возвращайся в старые круги (регресс) |
| Кастовая/ин. дискриминация | Не компрометируй; «даже один — сражайся» |
| Прошлая слабость | Понять причину, но не оправдывать |
| Желание освобождения | Искреннее желание приводит садгуру |
| Оккультные силы | Не демонстрируй; Vidya — к Богу, Avidya — вниз |
| Капалика-садхана | Регулярность; не критикуй практику |
| Детские желания | Не игнорируй — невинность притягивает grace |

## Быстрые сигналы («tells»)

- «Человек в dhoti-kurta» в момент спасения = Баба (мотив повтора).
- «Кино на стенах» = демонстрация проступков без проектора.
- «Письма получены» = доказательство омнисценции на первой встрече.
- Роза от авидья-тантрики = попытка саммохани-видьи; Баба нейтрализует.
- Баба «жаждет воды»/«теряет дорогу» = организует даршан для бедного.
- Две птицы на дереве = индивидуальная душа и Свидетель.
- Слабость Бога: «не может ненавидеть» — опора для кающегося.
