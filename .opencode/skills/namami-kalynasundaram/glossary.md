# Глоссарий — Namami Kalynasundaram

**Авидья-тантра (Avidya Tantra)** — тангрический путь к оккультным силам ради выгоды; запрещена; кладбищенские практики (Ch 10).

**Аманда сутра (Ananda Sutram)** — главная книга афоризмов Бабы; 3-8: «желание освобождения приводит садгуру» (Ch 10).

**Ачарья (Acarya)** — духовный учитель, даёт инициацию и уроки медитации (Ch 1).

**Бабалогия** — собрание анекдотов/агиографий о Бабе (весь сборник).

**Бхакта (bhakta)** — преданный; бхакти — преданность (Ch 5).

**Варабхайя мудра (Varabhaya Mudra)** — жест благословения (обе ладони открыты: левая — vara, правая — abhaya) (Ch 5, Ch 10).

**Видя-тантра (Vidya Tantra)** — тангрический путь к освобождению; все садханы Бабы — её часть (Ch 10).

**Гопи Враджи (Vrja-gopi)** — коровницы Вриндавана, идеал безусловной преданности (Ch 9).

**Гуру-пуджа** — подношение гуру (цвета/цветы ума) (Ch 7).

**Даршан (Darshana)** — лицезрение гуру (Ch 5).

**Дхарма** — праведность/природа вещи (Ch 2).

**Дхармасамикша (Dharma Samiksha)** — духовный «аудит» ученика Бабой (Ch 7).

**Инициация (Diiksha)** — получение мантры и техники медитации (Ch 1, Ch 10).

**Ишта (Ishta)** — личная цель/божество; ишта-мантра (Ch 10).

**Капалика-садхана (Kapalika)** — медитация в крематории в новолуние для санньяси (Ch 10).

**Кундалини (Kundalini)** — спящая энергия в муладхаре; пробуждается мантрой (Ch 10).

**Лила (Liila)** — божественная игра/драма (Ch 3, Ch 5).

**Мадхура-садхана (Madhura)** — садхана для полностью преданных (bhakti bhava) (Ch 10).

**Мантра** — звук, повторяемый в медитации (Ch 10).

**Махасамбхути (Mahasambhuti)** — Тарака Брахма в теле из пяти элементов (Ch 7, Ch 10).

**Махапраян (Mahaprayana)** — «Великий уход», уход Бабы 21.10.1990 (Ch 9).

**Микрочита (Microvita)** — тонкие существа между физическим и ментальным миром (Ch 2, Ch 10).

**Мукти / освобождение** — выход из самскар (Ch 3, Ch 10).

**Парама Пуруша (Parama Purusha)** — высшее сознание (Ch 10).

**Пракати (Prakrti)** — Оперативный Принцип; «машина» причины/следствия (Ch 7).

**Пранама (Pranama)** — поклон; sashtanga — полное простирание (Ch 1).

**ПРОУТ (PROUT)** — теория прогрессивного использования (Ch 6).

**Садгуру (Sadguru)** — истинный гуру, ведущий к Sat (Ch 10).

**Садхака/садхана** — практикующий/медитация (Ch 10).

**Самадхи (Samadhi)** — погружение ума в Абсолют; savikalpa (с атрибутами) / nirvikalpa (без) (Ch 10).

**Саммохани-видья (Sammohani vidya)** — оккультная способность очаровывать/управлять человеком (Ch 10).

**Самскара (Samskara)** — психическая реакция прошлых действий (Ch 3, Ch 7).

**Сиддхи** — оккультные силы (Ch 3, Ch 10).

**Тантра** — tan (расширение) + tra (освобождение); наука расширения ума (Ch 10).

**Тарака Брахма (Taraka Brahma)** — Брахма в спасающем аспекте (Ch 7, Ch 10).

**Татматра (Tanmatra)** — тонкая волна органа чувств (Ch 10).

**Таттвика (Tattvika)** — знаток философии, дающий инициацию (Ch 1).

**Чакра (Cakra)** — психо-духовный центр тела (муладхара→сахасрара) (Ch 10).

**Четвёртый/шестой урок** — ступени садханы (4-й — пранаяма, 6-й — дхьяна) (Ch 10).

**Шатрипу (shat ripu)** — шесть врагов ума: желание, гнев, жадность, привязанность, тщеславие, зависть (Ch 10).

**Шауча-манджуша (shauca manjusha)** — бутылочка с водой для гигиены (Ch 8).

**Шила (shila)** — правило поведения (15 шил) (Ch 7).

**ЭКАРА (ERAWS)** — секция образования/помощи/благосостояния (Ch 8).
