## Тип → признак (диагностика)

| Тип | Признак |
|---|---|
| Самскараджа (из прошлого) | Сюжет из личной памяти; повторяемость; разрядка меняет сюжет |
| Джнянаджа (глубокое знание) | Точная информация, проверяемая после (ключ, билет) |
| Пратисамведаника (реактивный) | Возникает на психо-физических реакциях; может плодить новые самскары |
| Татьяанубхути (реальное событие) | Совпадение во времени + точные детали + подтверждение (письмо/телеграмма) |
| Эктоплазмическая проекция | Страх/горе перед явлением; форма «холодная», исчезает после услуги; может запечатлеться на фото |
| Групповое видение | Один источник (аве́ша) + «заражение» остальных галлюцинацией |

## Правила решений (по автору)

- Встретил «призрака» → вопрос не «кто это?», а «какое состояние ума (kośa) его создало?».
- Рассказ о «совпадении» → собери три улики татьяанубхути (время + детали + подтверждение) до классификации.
- Испугался в «страшном месте» → проверь себя, сохраняй движение и человеческий контакт; бесстрашие меняет сюжет.
- «Дух» что-то делает → помни Videhiimánasa: развоплощённый ум инертен; «активность» — от живых умов (preśita mánas) или микровит.
- Явление просит не трогать его границу → отойди; уважение границы разряжает ситуацию.
- Помощь незнакомца в уязвимости → проверь после (куда исчез? откуда узнал?); страх проецирует «помощников».
- Оцениваешь рассказ → проверь, есть ли авторское объяснение; история 11 без объяснения — не додумывай.

## Быстрые сигналы («tells»)

- «В ту же ночь» + точные детали → татьяанубхути (не совпадение).
- Форма меняется на глазах (ребёнок→козёл) → клеточная суггестия, не сущность.
- Холодные руки / молчание / исчезновение → эктоплазмическая структура.
- Сюжет из личной памяти и повторяется → самскара.
- Точная подсказка, проверяемая в реальности → джняна.
- Страх и одиночество в предистории → почва для проекции (bhaya).
