# Chapter 1: Some Specialities of Prout's Economic System

*Дискурс, июнь 1979, Calcutta.*

## Core Idea

PROUT-экономика имеет семь специальностей: гарантированные минимумы, растущая покупательная способность, кооперативы, промышленное развитие, децентрализация, развивающее планирование и особый подход к торговле/налогам/банкам.

## Frameworks Introduced

- **Гарантированные минимумы**: еда, одежда, жильё, лечение, образование — каждому; излишек — людям с особыми качествами (врачи, инженеры, учёные), играющим роль в коллективном развитии; квант минимумов прогрессивно растёт. «Равное распределение» — утопия и «умный лозунг обмана»; вместо — максимальное использование и рациональное распределение (стимул производства).
- **Растущая покупательная способность** — контролирующий фактор экономики; сначала максимизировать производство essential-товаров, не роскоши; восстановить паритет производства и потребления.
- **Кооперативная система**: лучшее для производства/распределения; кооперативы, управляемые моралистами, защищают от эксплуатации; посредники исключены. Причины провалов кооперации — «разнузданная аморальность капиталистических эксплуататоров». Успех = мораль + сильная администрация + принятие народом. Модели успеха демонстрируются и пропагандируются. Новейшая технология и в производстве, и в распределении. Менеджеры избираются из пайщиков. Дивиденды агро-кооперативов: по земле + по труду; сперва 50/50 (50% зарплаты, 50% по земле) ⚠; местные — приоритет. Поэтапная социализация земли через агро-кооперативы (не в руках отдельного человека/группы).
- **Промышленное развитие**: три части — key industries (непосредственное правительство), кооперативы, частные. >45% населения в агрономии — неправильно ⚠; в деревнях — агро-/агри-индустрии. Агрономия = статус индустрии. Зарплата — деньгами, товарами или услугами (постепенно увеличивать товарную часть). Максимальная модернизация без роста безработицы; полная занятость через прогрессивное сокращение рабочих часов (невозможно при капитализме).
- **Децентрализация**: социально-экономические единицы по общим экономическим проблемам, единым потенциальностям, этническому сходству, географическим чертам, сентиментальному наследию. Каждая единица свободна в своём плане. Внутри — блок-планирование. Один политический орган может содержать несколько единиц (Бихар → Angadesh, Magadh, Mithila, Bhojpuri, Nagpuri; вся Индия → 44 единицы ⚠). Единицам гарантируется свобода достижения самодостаточности. Местные сентименты учитываются при найме; максимум агро-/агри-индустрий; surplus labour регионы → немедленная занятость. Каждый регион → самодостаточность → страна → самодостаточность.
- **Развивающее планирование**: 4 фактора (себестоимость, продуктивность, покупательная способность, коллективная необходимость) + природные ресурсы, география, климат, реки, транспорт, промышленные потенции, культурное наследие. Ошибки планирования: стальные заводы без дешёвой энергии; нефтепереработка Mathura/Barauni без сырья в 1000 миль ⚠; история джута: сырой джут из Бенгалии в Dundee → заводы закрылись, когда поставки прекратились; сегодня Бенгалия импортирует сырой джут. Решение для джута: сократить число заводов до предложения сырья, закрыть/перепрофилировать, производить нить для фермеров через джут-кооперативы, экспорт излишка. Централизованное планирование провалилось; нужен скоординированный план единицы на основе блок-планирования + суб-планы (western Ráŕh: Bankura/Purulia; Jalpaiguri/Coochbehar/Siliguri/Goalpara).
- **Торговля, налоги, банки**: распределение essentials — только через потребительские кооперативы; бартер — основа торговли между самодостаточными единицами; essentials полностью без налогов; нет подоходного налога — налоги в точке производства; банки — кооперативы; центральный банк — у непосредственного правительства. Максима: «Повысить покупательную способность простых людей превыше всего».

## Key Concepts

- **Минимумы (minimum requirements)** — еда, одежда, жильё, лечение, образование.
- **Покупательная способность (purchasing capacity)** — контролирующий фактор.
- **Key industries** — ключевые отрасли у правительства.
- **Блок-планирование** — низший уровень планирования.
- **Агро-/агри-индустрии** — переработка/производство на базе земледелия.

## Mental Models

- «Минимумы гарантированы, излишек — талантам; равенство без распределения по вкладу — утопия».
- «Сначала необходимое, потом роскошь: производство essentials повышает покупательную способность».
- «Кооператив — лучший посредник: без него — капиталист и посредник».
- «Регион самодостаточен → страна самодостаточна; планируй от блока вверх».

## Anti-patterns

- **Равное распределение** — «умный лозунг обмана», убивает стимулы.
- **Per capita income как мера** — скрывает эксплуатацию (см. Part 8).
- **Заводы без сырья/энергии** — примеры стальных заводов и Mathura/Barauni.
- **Экспорт сырья и импорт готового** — Dundee-урок.
- **>45% в агрономии** — избыточное давление на землю (⚠).

## Worked Example

Джут Бенгалии: когда-то сырой джут из Бенгалии шёл в Dundee (Британия), строилась британская промышленность; когда поставки остановились — заводы Dundee закрылись. Сегодня Бенгалия не может даже снабдить свои фабрики сырьём и импортирует его; профсоюзные лидеры наживаются на депрессии, рабочие страдают. Решение: сократить число заводов до предложения сырья; закрытые/лишние — перепрофилировать в другие essentials; оставшиеся производят нить; нить — фермерам и ткачам через джут-кооперативы; спрос Бенгалии на нить удовлетворён, излишек экспортируется; доходы распределяются среди местных — эксплуатация жадных торговцев заканчивается.

## Key Takeaways

1. Семь специальностей: минимумы, покупательная способность, кооперативы, индустрия, децентрализация, планирование, торговля/налоги/банки.
2. Минимумы гарантированы всем; излишек — одарённым; рост минимумов постоянный.
3. Кооперативы с моральным управлением — лучшая форма; посредников нет.
4. Три яруса промышленности: key / кооперативы / частные.
5. Децентрализация по единицам; планирование от блока; регион самодостаточен.
6. Налоги в точке производства; essentials без налогов; бартер между единицами.
