# Chapter 5: Socio-Economic Movements

*Дискурс, 31 декабря 1984, Calcutta.*

## Core Idea

Движения на анти-эксплуатационных и универсальных сентиментах поднимают подавленных; шесть пунктов: 100% занятость местных, максимальная промышленность по местному сырью, отказ от импорта готового, родной язык в обучении и коммуникации, локальные требования.

## Frameworks Introduced

- **Зачем движения**: экономически привилегированные эксплуатируют отсталых; движение — человеческий долг; против движения = защита реакционных сил. PROUT против всех видов эксплуатации, приоритет — экономической (жизнь и существование людей). Движения — на анти-эксплуатационных и универсальных сентиментах + практические программы благосостояния.
- **6 пунктов**:
  1. **100% занятость местных**: базовое право — минимумы через гарантированную занятость, не welfare/dole. Местный = сливший индивидуальные интересы с интересами единицы (независимо от цвета/веры/языка/места рождения). Зарабатывает в единице, тратит вне = не-местный (дренаж капитала). Спекулятивные рынки — закрыть. Краткосрочный план: трудо-интенсивные индустрии на минимумах (потребление); долгосрочный: капитало-интенсивные; трёхъярусная структура (частные малые, кооперативы, key industries правительства); сокращение рабочих часов при росте технологии. Понять surplus/deficit труда (пример: surplus мануального — Северный Бихар; surplus интеллектуального — Калькутта). Растения для самодостаточности: подбор под почву/климат, рефорест, Puranica/папоротник «притягивает облака» ⚠.
  2. **Максимальное промышленное развитие** по доступности сырья или местного потребления. Кооперативы (агро-, producer, consumer) — «кооперативный динамо». Королларии: (a) сырьё локально, не импорт (пример: каучук для шин); причины — дёшево, близость, безопасность планирования, против капиталистов, блокирующих местные отрасли (пример: Австралия импортирует из Японии товары из австралийского сырья); (b) сырьё не экспортировать — только готовые товары (сырьё на спекулятивных рынках манипулируется; готовое лучше по цене, сохраняет bullion); (c) импорт готового только если нет потенциала; бартер между единицами без потерь.
  3. **Не импортировать чужие готовые продукты**: поддерживай местное даже менее качественное — иначе местная индустрия закроется, безработица. Пробуждай сентименты «покупай местное». Пример: соляной марш Ганди (бойкот британской соли; цена упала, занятость, сознание народа, поляризация про/анти-Британ).
  4. **Родной язык как язык обучения** (primary → tertiary): культура = сумма выражения; местный язык даёт самоуважение; неродной язык обучения = подавление культуры, комплексы, пораженчество; контроль институтов (пример: Бенгалия/Chattisgarh — институты у не-местных с культурными предрассудками).
  5. **Родной язык как средство коммуникации** в гос./негос. офисах: британцы концентрировали экономику (Bombay, Calcutta, Delhi, Madras), готовили тысячи английских клерков; требование местного языка вытесняет не-местных из контроля местной промышленности.
  6. **Локальные социально-экономические требования**: специфичны — объединение разделённых наций (Германия, Ирландия, Корея), мосты/дороги для сырья, малая ирригация для земледелия.

## Key Concepts

- **Местный человек (local people)** — сросшийся с интересами единицы.
- **Surplus/deficit труд** — избыток/дефицит рабочей силы.
- **Кооперативный динамо** — движущая сила кооперативов.
- **Puranica fern** — растение, «притягивающее облака» (⚠).
- **Трёхъярусная структура** — частные малые, кооперативы, key industries.

## Mental Models

- «Занятость — через работу, не раздачу; 100% для местных».
- «Сырьё перерабатывай дома: не экспортируй сырьё, не импортируй готовое».
- «Покупай местное даже менее качественное — индустрия растёт к качеству».
- «Язык обучения и работы — родной; это культурная безопасность и контроль».

## Anti-patterns

- **Welfare/подачки вместо занятости** — не решают безработицу.
- **Заработок в единице, трата вне** — дренаж капитала, «не-местные».
- **Экспорт сырья на спекулятивные рынки** — манипуляция ценами.
- **Импорт готового при местном потенциале** — закрытие местных заводов.
- **Неродной язык обучения** — подавление культуры и психики.

## Worked Example

Британское правление: Индия импортировала соль, хотя могла производить сама. Ганди организовал гражданское неповиновение — соляной марш, местное производство, бойкот британской соли. Движение завоевало народ: цена соли упала, создана местная занятость, остановлен дренаж богатства британцам, поднято сознание народа, поляризация про/анти-Британ. Урок: «покупай местное» + движение = экономическое освобождение.

## Key Takeaways

1. Движения — на анти-эксплуатационных и универсальных сентиментах.
2. 100% занятость местных через работу, не подачки; спекулятивные рынки закрыть.
3. Промышленность — по местному сырью; сырьё не экспортировать.
4. Местное поддерживать даже при меньшем качестве; импорт готового — только без потенциала.
5. Родной язык — обучение и коммуникация; контроль институтов.
6. Локальные требования — специфичны для региона.
