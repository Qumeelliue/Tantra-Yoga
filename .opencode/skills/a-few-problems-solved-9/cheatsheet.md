## Динамика и гибкость

| Ситуация | Правило |
|---|---|
| Причина депрессий | Концентрация богатства + замороженные деньги (статичность) |
| Лечить депрессию | Катить деньги, увеличивать производство и покупательную способность |
| Избыток производства | Free trade + переработка + новые стили потребления |
| Пятый принцип | Метод меняется с временем/местом/личностью; использование прогрессивно |
| Гибкость vs догма | Догма = смерть; гибкая резинка живёт |
| Равный доход всем | Коммуна — тупик: нет стимулов, гений без простора |

## Быстрые сигналы

- Считают прогресс по доходам на душу — сомнительно; проверяй покупательную способность.
- Интеллектуал не делится знаниями — интеллектуальный капитализм.
- СМИ/образование у капиталистов — психо-экономическая эксплуатация.
- Национальный язык навязан силой — лингвистический империализм.
- Экспорт сырья при бедности региона — дренаж капитала (Orissa-урок).
- «Покупай импортное, а не местное» — разрушает местные отрасли.
- Паника перенаселения при нераспределённой пище — конспирация.
- Строгое следование догме — статичность, смерть системы.
- ⚠ Геологические/антропологические данные книги — непроверяемы.
