# Паттерны — A Few Problems Solved Part 9

## Экономика PROUT: аудит минимумов
**Когда использовать**: оценка экономической справедливости системы/платформы.
**Как**: (1) минимумы гарантированы всем (еда/одежда/жильё/лечение/образование); (2) излишек — одарённым, с ростом кванта; (3) покупательная способность растёт (не per capita income); (4) производство essentials прежде роскоши.
**Компромиссы**: «равное распределение» утопично — нужна дифференциация по вкладу.

## Дизайн кооператива
**Когда использовать**: организация производства/распределения в сообществе.
**Как**: морально управляемый кооператив без посредников; менеджеры из пайщиков; местные приоритет; 50/50 дивиденды (зарплата/доля) ⚠; поэтапная социализация земли; успех = мораль + администрация + принятие народом.
**Компромиссы**: требует сильной моральной культуры; посредники сопротивляются.

## Противодействие психо-экономической эксплуатации
**Когда использовать**: анализ контроля «ума» аудитории (СМИ, образование, культура).
**Как**: 8 методов (язык, псевдокультура, женщины, образование, секуляризм, касты, контроль рождаемости, СМИ) → сперва ослабление психики, потом ограбление. Контрмера: интеллектуалы спускаются к народу, чистый ум, анти-эксплуатационные движения.
**Компромиссы**: требует самоочищения элиты; не мгновенно.

## Группировка по 5 критериям
**Когда использовать**: проектирование границ сообществ/регионов.
**Как**: общие экономические проблемы → единые потенциальности → этничность → сентиментальное наследие → география. Максима: знай область, готовь план, служи людям. Слияние равных, разделение неравных.
**Компромиссы**: критерии конфликтуют (этничность vs экономика) — нужен приоритет по контексту.

## Языковая политика
**Когда использовать**: выбор языка для интерфейсов, контента, образования.
**Как**: родной язык — везде; лингва-франка — не подавляя; не навязывать региональный как «национальный»; национальный язык — естественная эволюция.
**Компромиссы**: техническая необходимость общего языка — допустима при просторе другим.

## Движение «покупай местное»
**Когда использовать**: поддержка локальной экономики.
**Как**: 100% занятость местных через работу (не welfare); сырьё локально; не экспортировать сырьё — только готовое; импорт готового лишь без потенциала; поддерживать местное даже менее качественное.
**Компромиссы**: бартер и свободная торговля между единицами сбалансированы локальным приоритетом.

## Контроль населения (рамка автора)
**Когда использовать**: анализ демографических паник.
**Как**: проблема в распределении, не рождаемости; 4 фактора естественного баланса (свобода, здоровье, покой, интеллект); вредные методы контроля — против людей.
**Компромиссы**: ⚠ позиция «стерилизации дефектных» контроверсивна — не применять без этического разбора.

## Экономическая динамика
**Когда использовать**: прогнозирование кризисов/инфляции.
**Как**: следи за статичностью (длинные паузы, замороженные деньги, концентрация); депрессия = взрыв эксплуатации; лечи качением денег, производством, покупательной способностью; избыток → free trade + переработка + новые стили потребления.
**Компромиссы**: предсказания сроков ⚠; системные меры медленнее, чем хотелось бы.

## Тест пятого принципа (гибкость vs догма)
**Когда использовать**: оценка жизнеспособности любой идеологии/продукта.
**Как**: проверь гибкость применения (время/место/личность) при устойчивости принципов; догма = статичность = смерть; равенство без дифференциации вклада = тупик (коммуна).
**Компромиссы**: грань «принцип vs применение» субъективна — обсуждай явно.

## Антропологическая рамка (⚠)
**Когда использовать**: исторические/культурные обсуждения — только как справочный материал автора.
**Как**: единство в разнообразии рас; различия внешние; Ráŕh — колыбель цивилизации; семиты — смешанная раса.
**Компромиссы**: ⚠ все цифры и классификации непроверяемы; не использовать как научный источник.
