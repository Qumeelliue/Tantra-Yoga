# Читшит — правила решений (A Guide to Human Conduct)

## Yama Sádhaná

| Ситуация | Правило |
|---|---|
| Оценить поступок как hiḿsá | Смотри на НАМЕРЕНИЕ, а не на факт уничтожения жизни |
| Агрессор (átatáyii) угрожает | Применение силы — доблесть; воздержание — трусость |
| Слаб против сильного агрессора | Сначала наберись сил («Rajput folly» — бой без оценки сил); настигает — ударь |
| Выбор пищи | Меньшее развитие сознания (овощи); животных — только если нельзя иначе |
| Правда причинит вред | Satya ≠ rta: с духом блага — умолчи/обмани агрессора, спаси невинного |
| Тяжёлая новость | Подготовь по времени и способу (мать за едой) |
| Мелкая «социальная» кража | Безбилетный проезд, обман богатых/государства — asteya |
| Оценить «честную покупку» | Принятие в честном обмене — не кража; двойные стандарты — против asteya |
| Brahmacarya | «Быть в Брахме», видеть Брахму в каждом объекте; НЕ воздержание семени |
| Брак | Естественен, свобода выбора; контроль, но не подавление |

## Niyama Sádhaná

| Ситуация | Правило |
|---|---|
| Очистить ум (зависть/гнев/жадность) | Противоположная идеация: жадному — давать, гневливому — вежливость |
| «Помог, а неблагодарны» | Мотив был корыстным (аванс под проценты) — это не служение |
| Сколько жертвовать | Aparigraha: минимум себе/семье, излишек — на общее благо |
| Довольство | Доходы обычного труда; права защищай — но без жадности |
| Кому служить (tapah) | Сначала проверь нужду; ответственность к НИЗШИМ, не к высшим |
| Аскеза с корыстью | Вся tapah теряется в момент |
| Чтение писаний | Схвати идею/смысл, потом слова; ритуал-замена — подмена |
| Термин/контекст (surá) | Значение зависит от контекста; остерегайся искажений «профессионалов» |
| Выбор japa | Мысленный (mánasika) — идеал; шёпот — лучше; громкий — бесполезен |
| Оккультные признаки | Не бояться, не подавлять, не акцентировать |
| Коллективная практика | Dharmacakra ускоряет проявление признаков — не упускай |

## Жизнь в обществе

| Ситуация | Правило |
|---|---|
| Крупная трата сверх бюджета | Разрешение а́cárya/секретаря; заём — тоже |
| Видишь нарушение принципов | Исправь мягко/жёстко — взаимный контроль укрепляет общество |
| Долг и общество | Общество помогает и контролирует; «потратил сам — просишь всех» — не поощрять |
| Оценить комфорт (aparigraha) | Время/место/личность: самолёт обычному человеку — против; поезд — нет; гур в век сахара — бессмыслица |

## Быстрые сигналы («tells»)

- Человек «свято» уверен в своём воздержании — спроси, выдержит ли он 200 000 рупий, если не выдержал 2 ⚠ (из книги).
- «Я не ворую, но езжу без билета» — это asteya (лишение должного).
- Проповедник «целомудрия», подавляющий желания — рискует гневом и грубостью тела; истинное brahmacarya — идеация Брахмы.
- Критик/моралист, который «списывает» мелкое — не проверяй слова, смотри на траты и долги.
- Служитель, жалующийся на неблагодарность — лечи его от корысти, а не хвали за щедрость.
- «Прочитал трижды книгу, коснувшись головой» — svadhyaya подменена ритуалом.
- Громкая молитва «для толпы» — шум, а не Iishvara pranidhana.
