## Схема практик

| Практика | Кто/когда | Символика |
|---|---|---|
| Kiirtan (Bábá Nám Kevalam) | все, с 1970 | очищение ума |
| Tándava | мужчины, с 1971 | череп=смерть, кинжал=борьба |
| Kaosikii | все, с 6.09.1978 | расширение ума, 22 болезни |
| Lalita mármika | при киртане | духовный танец |
| Varábhaya mudrá | конец DMC | милость+бесстрашие, микровита |

Порядок: Lalita → Sádhaná → Ásanas → Kaosikii → (муж.) Tándava.

## Различения

| Термин | Значение |
|---|---|
| DMC vs DMS | DMC — с varábhaya mudrá, ~350; DMS — только 3 |
| nigraha vs anugraha | наказание vs милость |
| Sadvipra Samáj vs Ráj | общество vs правительство |
| hiḿsá vs pratirodha | насилие vs самооборона |
| kaola vs Mahákaola | кундалини себе vs другим |
| kaosikii vs lalita vs tándava | психо-духовный / духовный / физико-психо-духовный |

## Правила-напоминания

- «Мораль — база, садхана — средство, Божественная жизнь — цель».
- «Átmamokśárthaḿ Jagaddhitáya ca» — идеология: освобождение себя + благо вселенной.
- «Тяни повозку; победа побежит за тобой».
- «Скорость без системы опасна; система без скорости бесполезна».
- «На 10 частей строгости — 11 частей любви».
- «Когда моя работа сделана, я уйду немедленно».
