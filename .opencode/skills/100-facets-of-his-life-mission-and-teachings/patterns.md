# Паттерны и уроки

## Хронологическая навигация по жизни
**Когда использовать:** вопрос о событии/дате/периоде жизни Бабы.
**Как:** определи фазу: детство (1–8) → колледж/инициация/ж-д (9–14) → основание (15–18) → символы/сообщество (19–26) → трактаты/брак/VSS/Ánanda Nagar (27–36) → семья/организация (37–44) → демонстрации/Филиппины (45–49) → kiirtan/практики (51–53) → гонения/тюрьма (54–61) → освобождение/kaosikii (62–65) → мировые туры (66–78) → поздние годы (79–87) → организация (88–92) → наследие/уход (93–100).
**Компромиссы:** фасет 50 отсутствует в печатной версии; для точных дат сверяться с источниками.

## Мораль-база-садхана-цель
**Когда использовать:** вопросы о правилах практики, Yama-Niyama, допустимости.
**Как:** мораль — фундамент (не вершина); без неё садхана невозможна; мораль относительна (время-место-личность), цель (единение с Brahma) абсолютна.
**Компромиссы:** моральный кодекс различается по контексту, но идеал един.

## Тантрический гуру: nigraha + anugraha
**Когда использовать:** вопросы о поведении гуру, наказаниях, тестах, экзаменах ачарьев.
**Как:** идеальный гуру умеет и наказывать, и миловать; тесты — для преодоления слабостей; «на 10 частей строгости — 11 частей любви»; наказание для коррекции, не для кары.
**Компромиссы:** жёсткость может выглядеть жестоко; критерий — цель исправления и духовного роста.

## Извлечение «как устроено» из фасетов
**Когда использовать:** вопрос об институтах (ERAWS, VSS, WT, DMC, RDS, Gurukula), их устройстве.
**Как:** ERAWS = образование+relief+welfare; DMC = конгресс с varábhaya mudrá; RDS = review-defect-solution; WT — санньяси-кадры, семейные ачарьи их поддерживают.
**Компромиссы:** фасеты дают структурные описания, но не полные уставы.

## Различение «официальная дата / событие»
**Когда использовать:** проверка дат (рождение, основание, арест, освобождение, уход).
**Как:** рождение 11.05.1922 (или 21.05.1921); AMPS 1.01.1955; арест 29.12.1971; отравление 12.02.1973; освобождение 2.08.1978; kaosikii 6.09.1978; Maháprayán 21.10.1990.
**Компромиссы:** год рождения спорен (книга даёт обе версии).

## Ответ о философии по трактатам
**Когда использовать:** теория — Prout, Neohumanism, Microvita, Ánanda Sútram.
**Как:** отнеси к трактату: samája shástra (Caryácarya), darshan shástra (Ánanda Sútram), dharma shástra (Subháśita Saḿgraha, Ánanda Vacanámrtam и др.); Prout/Neohumanism/Microvita — с конкретными годами введения.
**Компромиссы:** краткие фасеты не заменяют полные тексты трактатов.

## Отражение агиографической рамки
**Когда использовать:** вопросы о тюрьме, суде, чудесах, событиях спорной интерпретации.
**Как:** помни: книга издана P.R. Sarkar Institute, факты поданы в марговской перспективе; для юридически/исторически нейтральной подачи сверяться с внешними источниками.
**Компромиссы:** числа (350 DMC, 5018 песен, 22 болезни kaosikii) — по книге, помечать как «по книге».
