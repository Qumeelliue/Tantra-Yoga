# Краткая справка (The Supreme Friend)

## Ситуация → Правило

| Ситуация | Правило |
|----------|---------|
| Смертельная опасность (поезд, океан) | Мысленный призыв к Бабе с полной верой; имя/Иста |
| Начало любого действия | Вспомни «второй урок» (идеацию Исты) |
| Хула на Гуру | Не слушай — протестуй словом и логикой |
| Боль и страдания | Принимай как путь к Богу; не проси боль бездумно |
| Ошибка (указанная с юмором) | Не обижайся; извлеки урок, смейся вместе |
| Работа с дедлайном | Делай немедленно; ничего на завтра; «как машина» |
| Непроверенная новость | Проверь, прежде чем передавать |
| Вопрос о квалификации/еде другого | Не спрашивай — это смущает; лучше «Ты ел?» |
| Место медитации | Выбирай по вибрации; siddha piitha — сила |
| Ночная тантра-медитация | Только для тантриков; не бери не-тантриков |
| Приоритеты дня | Садхана → сева → ванна → еда; срочное дело важнее |
| Сомнение в Гуру | «Дай мне смерть, прежде чем усомниться»; проверяй веру временем |
| Разлука с Гуру | Он в сердце; «Я не ушёл далеко — Я стал ещё ближе» |
| Цель жизни | Парама Пуруша как Полярная звезда; полный суррендер |

## Ключевые даты (⚠ к калибровке)

- 1963 — инициация автора, сервис-камп в Ананданагаре, первая встреча с Бабой
- Декабрь 1966 — Баба покидает Джамалпур, переезжает в Ананданагар
- 1967 (5 марта) — инцидент в Ананданагаре (контекст знамений)
- 1979 — пост шрамана в Швеции
- Декабрь 1989 — встреча с больным Бабой в больнице Вудлендс
- Октябрь 1990 — shraddhänjali (поминальная церемония)
- Январь 1991 — сны после ухода Бабы, стихотворение «Я не ушёл далеко»

## Метафоры Бабы

- **bel-фрукт** — строгость снаружи, сладость внутри
- **Хануман и белка** — ценность по жертве, не по размеру
- **Полярная звезда** — цель-Парама Пуруша
- **Птица поёт — каждый слышит своё** — ум берёт значение по своей психологии
- **Удар цветами** — наказание, принятое радостно, не болит
- **Слон ест, тигр смотрит** — «Khäoyäbe hätir bhoge dekhbe bägher cokhe» — дисциплина для тренера
