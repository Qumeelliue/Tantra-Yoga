# Глоссарий — Prout in a Nutshell Volume 4 Part 20

**Агрико-индустрии (agrico-industries)** — переработка сельхозсырья на месте (масло, мука, бумага, цемент из шелухи) (Ch 1, Ch 2).

**Агро-индустрии (agro-industries)** — промышленность, снабжающая сельское хозяйство (техника, удобрения, насосы) (Ch 2).

**Аман (aman)** — зимний рис, выращивается рассадой и посевом; шелуха — цемент лучшего качества (Ch 1).

**Аус (aus)** — осенний рис на сухой липко-песчаной почве; не требует пересадки (Ch 1).

**Аффорестация** — посадка защитной лесной полосы (~1 миля) вдоль берега как стены от циклонов и размыва (Ch 5).

**Багари (Bágri)** — разговорное имя Южной Бенгалии (Саматaт) (Ch 4).

**Блок-планирование (block-level planning)** — крупный план региона, разбитый на планы блоков по почве и климату (Ch 1, Ch 5).

**Боро (boro)** — летний рис, требует в 3 раза больше воды, чем пшеница (Ch 1).

**Бхагирати (Bhagirathi)** — река, образованная древним каналом «Бхаги»; источник сладкой воды для десалинации (Ch 4).

**Вапна (vapana)** — посев семян; **ропана (ropana)** — пересадка рассады (Ch 1).

**Гидроэнергия** — дешёвый источник энергии больших рек региона; предпочтительнее солнечной (Ch 3).

**«Голубиная» культура (páyrá phasal / pigeon crop)** — мелкая вторичная культура, чьи семена разбрасывают по полю главной, как корм голубям; земля работает круглый год (Ch 1).

**Десалинация** — подача сладкой воды по подземным трубам из рек Ráŕh в пруды, каналы и реки Южной Бенгалии (Ch 4).

**Джут (mestá pát)** — «джут», не настоящий джут (patta / kaśt́á); источник бумаги, rayon, nylon, пластика (Ch 1).

**Дья́ра (diyára)** — прибрежный речной аллювий Северной Бенгалии (Ch 3).

**Кан́али (káńali)** — «средняя» земля, держит воду дольше барренной (Ch 1).

**Ка́лпатару (kalpataru)** — санскритское название кокоса (Ch 1).

**Кантхи (Káṋthi)** — бенгальское имя Контай, от kaṋthiká (Ch 5).

**Кхойа́и (khóái)** — крупномасштабный размыв почвы; лечится корнями деревьев (Ch 5).

**Кооперативы производителей / потребителей (producers / consumers cooperatives)** — снабжают село техникой и семенами / товарами повседневного спроса (Ch 2).

**Минимальные требования (five minimum requirements)** — еда, одежда, жильё, образование, медицина; критерий социальной защищённости (Ch 1, Ch 2).

**Микровиты негативные (negative microvita)** — вредные микроорганизмы, порождаемые гниением (сушёная рыба с запахом) (Ch 5).

**Мутативное питание (mutative, rajah)** — возбуждающее (Coca-Cola, пиво из свежей пшеницы) (Ch 1).

**Наделы экономичные / неэкономичные (economic / uneconomic holdings)** — рентабельный / нерентабельный (цена ниже себестоимости) земельный участок (Ch 2).

**Переходный период** — фазы 1–4 внедрения кооперативной системы; требует психической подготовки (Ch 2).

**Производство на основе потребления** — производить по потребностям людей, а не только ради прибыли (Ch 2).

**Психо-экономика (psycho-economy)** — оценка производств и пищи по эффекту на человека (sattva/rajah/tamas), а не только по прибыли (Ch 1, Ch 5).

**Ра́рх (Ráŕh)** — древняя возвышенность (~300 млн лет), липкая почва, пруды, танки; главная житница и промзона Бенгалии (Ch 1).

**Саматaт (Samatat)** — древнее имя Южной Бенгалии («солёная Бенгалия»); земля «Marine Bengal» (Ch 4).

**Сентиентное питание (sentient, sattva)** — свежее, лёгкое, дающее ясность ума: семена злаков, свежая пшеница (Ch 1).

**Статичное питание (static, tamas)** — оцепеняющее: алкоголь, перебродившее, гнилое (Ch 1).

**Тала (t́ál)** — крупная полоса равнинного аллювия Северной Бенгалии (Ch 3).

**Танр (táńr)** — высокая сухая земля, не держит воду; культуры засухоустойчивые (Ch 1).

**Товарные культуры (cash crops)** — культуры на рынок (джут, шелк, кешью, кокос, бетель) (Ch 1, Ch 5).

**Тус (tus)** — рисовый шелух; цемент из него — лучшего качества (Ch 1).

**Харид дханья (Harit Dhánya)** — «земля обильной зелени» → Харьяна (Ch 1).

**Четыре фазы кооперативной реформы** — неэкономичные наделы (50/50) → экономичные (25/75) → рациональное распределение (100% членам) → отсутствие конфликтов собственности (Ch 2).
