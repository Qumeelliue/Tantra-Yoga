# Читшит — правила решений по Саркару (Prout 20)

## Региональная экономика

| Ситуация | Правило |
|---|---|
| Оценить устойчивость региона | Проверь обе опоры: минимум жизни на месте + прибыльные товарные культуры/промышленность |
| Минимум жизни | Еда, одежда, жильё, образование, медицина; самодостаточность по каждому |
| План для территории крупнее района | Разбей на блоки по почве/климату; единица планирования — блок |
| Завод разместить | Строй у источника сырья, а не вози сырьё к заводу |
| Экспорт ресурса | Сначала переработка: сырьё на экспорт без переработки = потеря стоимости |

## Земля и кооперативы

| Ситуация | Правило |
|---|---|
| Земельная реформа | 4 фазы: неэкономичные (50/50) → экономичные (25/75) → рац. распределение (100%) → нет конфликтов |
| Неэкономичный надел пустует | В кооператив; владелец остаётся владельцем и членом |
| Размер кооператива | Решают сами фермеры; гигантизм (колхозы) — неуправляемый дефект |
| Внедрять систему | Только с психической подготовкой (внутренний порыв + внешнее давление); принуждение отвергается |
| Доля населения в сельском хозяйстве | Не более 30–45%; большинство — в промышленности |

## Вода, пища, среда

| Ситуация | Правило |
|---|---|
| Орошение | Поверхностная вода: пруды-танки, shift-and-lift, малые плотины; глубокие скважины истощают горизонт |
| Поле между урожаями пустует | «Голубиная»/ассоциативная культура; бобовые дают азот (пшеница 90/10 с бобовыми) |
| Классифицировать пищу | sattva (свежее) — продвигать; rajah (мутатив) — аккуратно; tamas (алкоголь, гнилое) — сворачивать |
| Свернуть вредное производство | Сначала альтернативный доход работникам, потом остановка |
| Солёный прибрежный регион | Десалинация: сладкая вода по подземным трубам в пруды/каналы/реки |
| Циклоны и размыв берега | Полоса леса ~1 миля (shishu, кешью, джекфрут, сосна); дюны — лианы дынь/тыкв |
| Энергия побережья | Приливы + ветряки; гидроэнергия дешевле солнечной там, где есть реки |

## Быстрые сигналы («tells»)

- Видишь глубокие скважины как основную ирригацию — вероятно истощение водоносного слоя.
- План региона один на все районы — забыто блок-планирование.
- «Сначала промышленность, потом рынки» — без порта/дорог экономика не двинется.
- Завод без сырья рядом — заложены лишние перевозки.
- Резкое закрытие статичного производства без замены дохода — раненная община в будущем.
- Экспорт сырья без переработки (шкуры, джут) — утечка валюты.
- Реформа земли за один день — принуждение, а не переходный период.
