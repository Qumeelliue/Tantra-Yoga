# Читшит — A General Guidebook for Táttvikas

| Ситуация | Правило |
|---|---|
| Нужно оценить идеологию/движение | Проверь оба полюса: духовная цель (нет → аморальность) и материальная скорость (нет → бездействие) |
| Выбор «духовное или материальное» | Бери синтез: материя — проявление духа, дух — сущность материи |
| Любое действие таттвики | Задай два вопроса: mould unit life? re-mould collective life? |
| Социальный порок (приданое, касты) | Лечи два корня: суеверие речью, экономику — конструктивной работой |
| Хочешь убрать приданое | Дай девушкам возможность зарабатывать — суеверие уйдёт само |
| Хочешь убрать касты | Стирай суеверие речью; экономический фактор — вторичен |
| Вдохновляешь людей работать | Сам следуй дхарме, учи живых (ÁPANI ÁCARI DHARME, JIIVE SHIKHÁIVE) |
| Relief work | Уход за больными, кремация, вода, дороги; это форма садханы |
| Работа с женщинами | Стирай суеверия, убирай неграмотность, dharmacakra, поднимай уровень жизни, давай заработок вдовам |
| Экономика страны/мира | Богатство мира — общая собственность; баланс централизации и децентрализации |
| Создаёшь литературу/искусство | Пиши на языке народа, используй Jan Kalá; орнаментальный стиль бессмыслен для массы |
| Нужны квалифицированные кадры | Центральный совет: тест → экзамен → сертификат → ревизия литературы |
| Кто входит в Центральный совет | Таттвики-dharmamitram, владеющие тремя языками |
