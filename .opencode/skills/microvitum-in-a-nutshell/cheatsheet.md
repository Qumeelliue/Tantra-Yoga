# Читшит — правила решений по Саркару (Microvitum in a Nutshell)

## Классификация сущностей

| Вопрос | Правило |
|---|---|
| Что такое микровит? | Наименьшая живая сущность; «серебряная линия» между материей и идеей; не углеродная |
| Как увидеть микровит? | Микроскоп (грубые) → инференции (тонкие) → особая духовная перцепция (тончайшие) |
| Друг или враг? | Не по природе, а по контролю/поведению: враг под контролем добрых — друг |
| Положительный или отрицательный? | +: про-эктоплазменный, от ума к материи; −: про-материальный, от материи к уму |

## Плекси и баланс

| Ситуация | Правило |
|---|---|
| Откуда желание богатства/эгоизма? | Отрицательные микровиты |
| Откуда универсализм/всестороннее освобождение? | Положительные микровиты |
| Отрицательные могут выше? | Нет, выше физико-психического плексуса — только с силой (русти — вредно) |
| Положительные доходят до? | Оккультного плексуса (крпа); выше — каруна; выше всего — милость |
| Как защититься? | Медитация (дхьяна), добрые мысли, хорошая компания, киртан |
| Перевес отрицательных в мире? | Дегенерация; перевес положительных — духовная революция |

## Носители (инференции)

| Носитель | Тип |
|---|---|
| Звук | Самый тонкий; предпочитают положительные (если идея тонкая) |
| Осязание, форма, вкус | Промежуточные |
| Запах | Самый грубый; предпочитают отрицательные |
| Гниль/порча | Отрицательные микровиты |
| Синтез/свежесть | Положительные микровиты |

## Практические правила

| Ситуация | Правило |
|---|---|
| Болезнь | Лечится ростом числа положительных (дхьяна, мысли, садхана); медицина лишь снимает боль |
| Получатель положительных микровитов | Мужчина ≥24 (стандарт 30), вегетарианец; не дети/женщины/животные/растения |
| Исследование микровитов | Внешние лаборатории (грубая часть) + психо-духовная практика (тонкая часть) |
| Империализм/доминирование | Психическая болезнь карбонической пабулы; лечится нео-этикой (баланс пабулы) |
| Оккультные силы | Не гнаться: придорожная пыль; цель — Parama Puruśa |
| Оценка качества «одинаковых» объектов | Число микровитов (MV) — новая переменная |
| Материя | «Известное Я», не упакованная энергия; энергия слепа, микровиты «с совестью» |

## Быстрые сигналы («tells»)

- Видишь «успех в мирских делах → эгоизм» — отрицательные микровиты.
- «Терпимость к несправедливости» — отрицательные; «неприятие несправедливости» — положительные.
- Слабый/непроверенный перенос микровитной теории в продукт — пометить «⚠ теория Саркара, не проверено».
- Одно и то же желание в двух направлениях: к грубому — враг, к тонкому — друг.
