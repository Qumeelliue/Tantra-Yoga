# Читшит — правила решений по Саркару (Yoga Psychology)

## Память и ум

| Ситуация | Правило |
|---|---|
| Вспомнить давнее событие этой жизни | Церебральная память: ищи внешние якоря (место, запах) |
| Всплыло «чужое» воспоминание (прошлая жизнь) | Экстра-церебральная память из причинного ума; активно в детстве, гаснет к ~5 годам |
| Хочется «вспомнить все прошлые жизни» | Не делай: риск двойной личности и духовного застоя; цель впереди |
| Понять, где хранится память | В citta (экто-плазменном веществе ума), не в мозге; мозг — машина воспроизведения |
| Оценить сон | Мусорный (после еды/болезни, бессвязный) = оректический, без значения; спокойный о важном = супраментальное видение |

## Восприятие и «сверхъестественное»

| Ситуация | Правило |
|---|---|
| «Вижу то, чего нет» | Положительная галлюцинация (мыслеволна создала образ) |
| «Не вижу то, что есть» | Отрицательная галлюцинация (мыслеволна погасила сигнал) |
| Медиум/кристалл/зеркало «предсказывает» | Почти всегда проекция его самскар; 1–2% попаданий — статистика |
| Рассказ про полтергейст | Авидъя-тантрик через эктоплазму, или прешитаманас, или твоя галлюцинация — не дух |
| Испугался «призрака» | Сделай кииртану/гуру-мантру 1 минуту — явление исчезнет |
| Светящееся тело ночью | Деваяони (7 типов); не призрак, не галлюцинация; сиддха — лучший |

## Психическое здоровье

| Ситуация | Правило |
|---|---|
| Повторяющийся образ из страха | Фобия: контролируй объективированный ум; медитация |
| Повторение одного из слабости | Мания (в т.ч. touch-mania) |
| «Все меня избегают», уныние | Меланхолия (риск суицида) — лечи, не игнорируй |
| Чувство превосходства / неполноценности | Раздутый / сжатый объективированный ум; выравнивай умом и уверенностью |
| Болезнь целого народа | Коллективная психическая болезнь (комплекс неполноценности) — нужны сильные личности |

## Био-психология

| Ситуация | Правило |
|---|---|
| Стыдливость/бесстыдство | Простата: норма — стыд; пере-секреция — меланхолия; недо-секреция — страх |
| Жестокость у подростка | Недо-секреция тестиса — не патология, а железа; лечи питанием/асанами |
| Страх публичных выступлений | Слабая манипура; маюрасана (давление) устраняет |
| Любовь к детям у животного/человека | Солнечное сплетение; его отделение = мгновенная смерть |
| Духовная жажда в 13 лет | Питуитарная; направь через гуру, не через плохую компанию |
| Волосы подмышек/суставов | Не удалять: перегрев лимфы → слабый тироид |
| Питание для ума | Саттвика (рис, бобовые, фрукты, молочное) утончает; тамасика (лук, мясо, рыба, вино) грубит |
| Среда | Сатсанга/хорошая среда — позитивный катализатор лимфы; кино/плохие книги — негатив |

## Духовная практика

| Ситуация | Правило |
|---|---|
| Выбрать определение йоги | Слияние дживатмы и Параматмы (сахар+вода); не подавление пропенсивностей |
| Асаны | Асаны→железы→гормоны→пропенсивности; выбирай по давлению/разрядке |
| Пранаяма | С идацией и фиксацией (Yudhiśt́hira), а не хатха без идации |
| Джапа | Только верхние чакры (анахата, вишуддха, аджина); гуру-чакра — для дхьяны |
| Утро | Сразу после сна: гуру-медитация в гуру-чакре — освящает день |
| Цель медитации | Не оккультные силы; слияние с Высшим; «два господина» = раздвоенный ум |
| Знать Высшего Субъекта | Идейно держать «Он наблюдает за мной»; напрямую — нельзя |

## Эволюция и общество

| Ситуация | Правило |
|---|---|
| Оценить «грандиозное» (гигантское) | В фазе интроверсии крупное уступает малому и умному (динозавры вымерли) |
| Теория против психологии человека | Обречена (пример автора — марксизм): учитывай urge/passion/vrtti/sentiment |
| Планировать страну/политику | Не иди против психологии владения (фермер и земля) и локальных психологий |
| Проверить авторитет | Здравый смысл → логика → человечность; логика мальчика > нелогичность «Брахмы» |
| Смена панны ума | Риск ~25% ⚠: нужна пранна-регулировка; иначе безумие или смерть (для души — дни) |

## Быстрые сигналы («tells»)

- Сон после жирной еды и бессвязный — не «вещий»: это шум нервов.
- Медиум хвастается силой — кандидат в деваяони (скрытое желание), не источник истины.
- «Вспоминаю прошлую жизнь» после 12–13 лет — тревожный знак двойной личности.
- Философ проповедует мрачность — вероятно, его меланхолия (простата), а не истина.
- Подросток мучает животных — подозрение на недо-секрецию тестиса, а не «злость».
- Культ проповедует неравенство — не мораль; мораль — единство всех живых.
- «Я всё знаю» / «я ничтожен» — раздутый/сжатый объективированный ум.
