# Читшит — правила решений по Саркару (Prout 13)

## Экономика

| Ситуация | Правило |
|---|---|
| Оценить экономику | Растёт ли покупная способность простых? Производятся ли essentials? Деньги катятся или лежат? |
| Минимум для людей | Гарантированный минимум всем (пища, одежда, жильё, лечение, образование); излишек — талантам/навыкам |
| «Равное распределение» как лозунг | Отвергнуто: это обман; вместо этого максимум использования + рациональное распределение |
| Организовать производство | Кооператив (мораль + администрация + принятие народом); без посредников |
| Масштаб промышленности | Малый — частный, средний — кооператив, крупный (key industry) — локальное правительство |
| Налоги | Essentials — tax-free; без подоходного; налог у точки производства |
| Банки | Кооперативные; центральный — у локального правительства; деньги с bullion-обеспечением |
| Деньги без золотого покрытия | Печать немедленно прекратить; новые ноты — с bullion-стоимостью |

## Socio-economic units

| Ситуация | Правило |
|---|---|
| Делить территорию | По 5 критериям: экономические проблемы, потенциал, этнос, сентименты, география |
| Планировать регион | Снизу вверх: блок → единица; внешние грандиозные планы запрещены |
| Один регион — разные проблемы | Дели на отдельные единицы (пример: Chotanagpur vs северный Бихар) |
| Единицы выровнялись по развитию | Сливать в большую единицу → один мир + мировое правительство |
| Разделяющие сентименты | Отвергать; объединяющие — поощрять |
| Отток капитала из региона | Не допускать; экспорт сырья = утечка развития |

## Эксплуатация

| Ситуация | Правило |
|---|---|
| Диагностировать несправедливость | Ищи цепочку: подавление → комплекс → слабость → экономическая эксплуатация |
| Капитализм | Действует в 3 сферах: физической, интеллектуальной, духовной |
| Интеллектуалы | Интеллект чистый + служение людям; иначе — интеллектуальный капитализм |
| Духовный капитализм | Знание духовности скрыто от людей; девиз: «Самореализация и служение человечеству» |
| Лидерство в духовной революции | Нужны sadvipras — духовно сильные лидеры |

## Язык

| Ситуация | Правило |
|---|---|
| Полноценный ли язык | 5 основ (глаголы, падежи, местоимения, лексика, литература) / 8 факторов |
| «Диалект» чужого языка | Проверь факторы; неполнота = Upabháśa, полнота = язык |
| Среда обучения/институтов | Родной язык; чужие языки — только для расширения кругозора |
| Lingua franca | Допустим, если не подавляет ни один язык; сегодня — английский |
| Спешка с языковой политикой | Недопустима: эволюция, а не навязывание |

## Население и движение

| Ситуация | Правило |
|---|---|
| «Угроза перенаселения» | Проверь: пища и пространство достаточны? Дефицит = сломана система, не природа |
| Естественный уровень населения | 4 условия: экономическая свобода, здоровье, покой ума, интеллект |
| Контроль рождаемости | Деформирующие/принудительные методы — запрещены; добровольный — личный выбор |
| Безработица | 100% занятость местных через работу, а не пособия |
| Импорт готового вместо местного | Запрещён, если местное производство возможно; покупай местное даже при низшем качестве |
| Сырьё | Перерабатывать локально; экспортировать только изделия |

## Динамика

| Ситуация | Правило |
|---|---|
| Депрессия | Причины: концентрация богатства + блокировка обращения денег |
| Статичность | Ведёт к депрессии; пауза — естественна, затяжная пауза — смерть |
| Перепроизводство | 3 меры: свободная торговля, сохранение/переработка, диверсификация потребления |
| Дефицит продовольствия | Cordon (запрет перевозок) не вводить — усугубляет голод |
| Изменение практики | Принцип держи, применение адаптируй (время-место-личность) |
| Судьба теории без гибкости | Отвергнута, как резинка без упругости |

## Быстрые сигналы («tells»)

- «Национализируем! Прекратим локаут!» без анализа сырья — шум, не план (джутовый пример Ch 2).
- Деньги не инвестируются «из-за низкой прибыли» — это блокировка обращения → грядущая депрессия.
- Регион экспортирует сырьё и импортирует изделия — нездоровая экономика.
- «Диалект» с собственным фольклором — на самом деле полноценный язык.
- Хочешь понять «местный ли человек» — спроси, где он тратит заработанное.
- Равная плата умному и обычному — сигнал коммунальной стагнации без стимулов.
