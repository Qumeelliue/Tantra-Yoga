# Читшит — правила решений (Namah Shiváya Shántáya)

## Различение Шивы и культов

| Ситуация | Правило |
|---|---|
| «Что значит shiva?» | Три уровня: благополучие → зенит познания → исторический Садашива |
| Шиваитская практика/образ | Определи слой: прижизненный/ведический/джайнский/буддийский/пуранический/лаокик |
| Какой биджи ждать | При жизни нет; ведический m; джайна/будд. aeḿ; пуранический haoḿ |
| Шива-лиунга от Шивы? | Нет: введена ~2500 лет назад под влиянием джайнизма |
| Бур́о Шива / На́тха-Шива? | Буддийский/синтетический образ, ≠ Садашива |

## Проверка родства богов и богинь

| Ситуация | Правило |
|---|---|
| «Дурга — жена Шивы?» | Нет: 10 рук, культ ~1300 лет |
| «Кали — жена Шивы?» | Жена (2 руки, неарийка) ≠ богиня (4 руки, ~1600–1700 лет) |
| «Сарасвати — дочь Шивы?» | Ведическая Сарасвати = река; богиня с книгой = позже письменности |
| «Лакшми — дочь Шивы?» | 4 варианта (миф/Махалакшми/Камала/лаокик), ни одна не дочь |
| «Ганеша — сын Шивы?» | Доисторический лидер клана, не сын |

## Изречения Шивы (Shivokti)

| Ситуация | Правило |
|---|---|
| Жить во времени | Varttamáneśu vartteta — живи в настоящем; прошлое — материал, будущее — план |
| Работать без знания | Рабство; знание (3 источника) освобождает |
| Семья | Муж = bharttá (кормилец), жена = kalatra; брак = ответственность |
| Гнев | Krodha — великий враг тела, ума и садханы |
| Жадность | Lobha — корень всех грехов |
| Гордыня | Ahaḿkára — корень падения (exhibitionism + asmitá) |
| Успех | Без parishrama успех невозможен |
| Истина | Нет дхармы без satya; лжец всегда несчастен |
| Грех | Пути греха извилисты; возвращается бумерангом |

## Наставления (Shivopadesha)

| Ситуация | Правило |
|---|---|
| Освобождение | Только самопознание (слияние с Сознанием); не аскеза, не посты, не ритуалы |
| Оковы | Физические (с догмами-подвидом) / психические / духовные |
| Аскеза | Tapah ради других — благо; ради себя — вред |
| Пост | Гигиена и близость к Богу; не валюта спасения |
| Идолы | Из страха/жадности — «воображение воображений»; не спасают |
| Шастра | Освобождает через дисциплину; нужен и гуру/проповедник |
| Тиртха | Настоящая — в сердце; внешние паломничества — иллюзия |
| Единое | Всё из Меня, в Меня, к Меня — Брахман без второго |

## Философские школы

| Школа | Дефект |
|---|---|
| Самкхья | 24 принципа, пассивный Janya Iishvara, не объяснил мокшу |
| Патанджали | Принял Ишвару, но не связь джива–Ишвара; сухая йога |
| Ваешешика | Причинность без объяснения Ишвары → дуализм |
| Майавада | Мир = иллюзия; забыл Шиву, любившего мир |
| Буддизм | Мораль есть, нет цели/среды; дукха = пессимизм |
| Джайнизм | Ахимса без практичности (запрет земледелия) |
| Чарвака | Материализм без морали; только восприятие — опасен |

## Символы Шивы

| Символ | Смысл |
|---|---|
| Пять лиц | Пять выражений одной личности; центр = Кальянасундарам |
| Три глаза | Око знания (доступ к бессознательному) |
| Тигровая шкура | А́сана/одежда (непроводник); НЕ дигамбара |
| Полумесяц | 16-я доля луны (ама-кала), сосновый нектар, Бхоланатх |
| Тришула/молния/верёвка | Исправление грешников и защита добрых |
| Три жены | Па́рвати (арийка), Кали (неарийка), Гаунга (монголка) = единство рас |
