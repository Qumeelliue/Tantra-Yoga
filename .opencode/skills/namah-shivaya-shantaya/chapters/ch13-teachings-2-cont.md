# Chapter 13: Shiva's Teachings – 2 (continued) (Shivopadesha 2)

*Дискурс 13, 25 июня 1982, Патна.*

## Core Idea
«Самопознание — истинное знание; всё остальное — тень знания». Разбор процесса познания, пара/апара видьи и определения сущности (sárátsára).

## Frameworks Introduced
- **А́tmajiṋánaḿ vidurjiṋánaḿ** — самопознание — реальное знание; другое знание — avabhása (тень). Этимология: jiṋá (корень) → знание; «know» от старолатинского keno.
- **Процесс познания**: «субъективизация объективностей». Всё вне экзистенциального «Я» — объективность; познаваемая. Но может ли «Я» познать высшее? Свидетель «Я существую» — это «Я знаю», тоньше первого уровня ума (Citisattá). Познать Сознание = слиться с Ним (соляная кукла в океане).
- **Сakala/Niśkala Citisattá**: проявленное (свидетельствует первую стадию ума, теоретическая связанность) / непроявленное. Pratyagátmá — свидетельствование в отношении Макрокосма.
- **Parávidyá vs Aparávidyá**:
  - **Parávidyá** (субъективное знание): от аналитического спуска к синтетическому восхождению; 4 стадии: изучение для устранения дефицита знания → рациональный анализ → консолидация через pariprashna (духовный запрос) → самоотдача Сознанию. Ведёт к «золотым вратам» мокши.
  - **Aparávidyá** (объективное знание): изучение для блага мира → рациональный анализ → применение для блага мира. Необходима для jagaddhitáya.
  - Баланс: только pará → «черви эгоизма»; только аpara → слабость при служении. Поэтому формула átmamokśárthaḿ jagaddhitáya ca.
- **Тень (umbra/penumbra)**: ráhu (umbra — полная тень) и ketu (penumbra — полутень); по тени нельзя судить об оригинале. Всё прочее «знание» — penumbra (нельзя составить точное представление).
- **Sára → Sárátsára**: sára (эссенция) в обыденных смыслах (удобрение, ступица колеса, суть дискурса) — не истинное; восходя к тончайшему в объективном мире: Макрокосмический Ум и Пра́ Пракрити (достигаются только через гуна-рождённую силу — садхану); Парама Пуруша — Sárátsára (Квинтэссенция). Реализация — не сухим знанием, а любящим сердцем и сладким интеллектом.

## Key Concepts
- **Citisattá** — Познавательная Способность, свидетель первой стадии ума.
- **Рáhu / ketu** — астрономические «теневые планеты» (umbra/penumbra).
- **Четыре варги**: káma, artha, dharma, mokśa — базовые драйвы человека.
- **Pariprashna** — духовный запрос (важен в Namámi Krśńasundaram, ch22/24).

## Mental Models
- «Субъективизация объективностей = знание; но высшее познаётся только слиянием».
- «Проверяй тип знания: pará (для самореализации) или аpará (для блага мира) — оба нужны».
- «Не суди по тени: без прямого контакта представление неверно».
- «Иди от эссенции к Квинтэссенции — sára → sárátsára».

## Anti-patterns
- **Знать только аpará-видье** — мир без духовной цели.
- **Знать только pará-видье** — эгоизм «чистого» аскета.
- **Интеллектуальная «экстраваганза» для Верховного** — не достигает ни на йоту.
- **Судить о вещи по тени (penumbra)**.

## Worked Example
*Соляная кукла.* Кукла из соли пошла измерить глубину океана; входя в воду, она растворялась и не вернулась рассказать. Так познание Сознания — слияние с ним (self-knowledge). Это единственное реальное знание; всякое объективное знание — только тень, из которой нельзя составить точную картину оригинала.

## Key Takeaways
1. Самопознание = слияние с Сознанием; остальное — тень.
2. Pará + аpará видья нужны вместе: самореализация и благо мира.
3. Четыре стадии pará-видьи: изучение → анализ → pariprashna → самоотдача.
4. По тени (umbra/penumbra) нельзя судить об оригинале.
5. Sára → Sárátsára: квинтэссенция достижима только садханой и любовью.
6. Реализация — любящее сердце, а не интеллект.
