# Chapter 17: Shiva's Teachings – 2 (continued) (Shivopadesha 6–8)

*Дискурс 17, 22 июля 1982, Патна.*

## Core Idea
Идол, созданный воображением, не может дать спасение (как царство во сне не делает царём); поклонение идолам без самопознания — мучение; четыре состояния ума выражаются Верховным Сознанием.

## Frameworks Introduced
- **SHIVOPADESHA 6 — Manasá kalpitá múrttih... svapnalabdhena rájyena rájánah mánavástathá**: «Если идол из воображения может дать спасение, то человек может стать царём, создав царство во сне».
- **Четыре типа мыслей**: (1) о существующей среде; (2) о прошлой среде; (3) без среды (мечты в беде); (4) фантастические (комбинация частей реальных объектов — «goosepine» из гуся и дикобраза). Материалы мыслей — всегда из внешнего мира (величайшее несовершенство ума). Макрокосм мыслит оригинально (каждая мысль нова); нет двух идентичных сущностей.
- **Идолы из страха/жадности**: тигр-бог, крокодил-бог, змеи-бог, богиня богатства, богиня знаний — продукты страха и лени; не имеют даже та́нматрического существования; «воображения воображений».
- **Ум = причина рабства и освобождения**: Mana eva manuśyánáḿ kárańaḿ bandhamokśayoh; рабство = привязанность к объектам; свобода = свобода от привязанности. Слияние с Космическим Умом → нет внешнего → блаженство.
- **Сон**: мышление во сне; без сопротивления реальности — большое ускорение; сны сбываются в ~5% (по автору, ⚠). Ответы из бессознательного приходят во сне при концентрации.
- **SHIVOPADESHA 7 — Mrcchiládhátudárvádi múrttáv... jiṋánaḿ viná mokśaḿ na yánti te**: те, кто считает Бога заключённым в идолах из глины/камня/металла/дерева, мучают себя — не получат спасения без самопознания. «Бог спит!» — абсурд. Vyasa (главный автор пуран) сам извинился: «Я дал форму бесформенному, ограничил всепроникающего».
- **SHIVOPADESHA 8 — Jágratsvapnasuśuptyádi caetanyam yad prakáshate... Tad Brahmáhaḿ**: три состояния (бодрствование, сон со сновидениями, глубокий сон) выражены Сознанием; четвёртое — турия (слияние в Космическом Сознании, без самкальпы/викальпы).
- **Психология состояний**: бодрствование — максимум использования ума, восприятие через афферентные/эфферентные нервы; гипнотизм (месмеризм) — влияние на нервные клетки другого; сон — отдых нервных клеток; слишком много сна = «другая форма смерти». Шесть дефектов: nidrá (сон), tandŕa (дремота), álasya (лень), bhaya (страх), krodha (гнев), diirghasútratá (промедление).

## Key Concepts
- **saḿkalpa / vikalpa** — экстраверсивный/интроверсивный поток ума; мокша — состояние без них.
- **Пять ментальных процессов**: kśipta (беспокойство), múd́ha (привязанность), vikśipta (рассеянность), ekágratá (концентрация), nirodha (психическая остановка).
- **Пять пропенситивностей**: áhár (еда), nidrá (сон), bhaya (страх), maethuna (продолжение рода), dharma sádhaná (духовная практика — неограничена).

## Mental Models
- «Мысли — комбинация внешнего опыта: нельзя изобрести по-настоящему новое; только Макрокосм — творец».
- «Проверяй идола: создан из страха/жадности → нет реальности, а только "воображение воображения"».
- «Ум — дверь: привязанность к объектам = рабство; слияние = свобода».
- «Четыре состояния: бодрствование используй; сон для отдыха, не для побега».

## Anti-patterns
- **Поклоняться идолам из страха/выгоды** — «воображение воображений».
- **Спать больше нужного** — «сон = смерть на 23/24 часа».
- **Думать «я грешник»** — отвлекает ум от Парама Пуруши к эго (см. ch26 Namami).
- **Приписывать богам «сон» или «приёмы пищи»** — абсурд, деградация концепции.

## Worked Example
*Царство во сне.* Человек во сне создал четыре дворца и сел на золотой трон — он «монарх» во сне. Проснулся — на рваной циновке с рваным одеялом. Так же идолы из воображения: существуют, пока ум желает их; не могут освободить ум от самкальпы/викальпы и слить с Верховным Сознанием.

## Key Takeaways
1. Идол из воображения не даёт спасения — как сон не делает царём.
2. Мысли собираются из внешнего мира; истинное новое — только у Макрокосма.
3. Ум — причина рабства и освобождения.
4. Четыре состояния ума; турия — слияние без самкальпы/викальпы.
5. Поклонение идолам без самопознания — пустое мучение.
6. Шесть дефектов (включая сон и промедление) — препятствия развития.
