# Глоссарий — Shabda Cayaniká Part 2

**Авидья-тантра (Avidyá Tantra)** — путь к миру (preya); использование оккультных сил ведёт к деградации/крудификации; противовес Vidyá Tantra (Ch 2, 7).

**Анима-сиддхи (ańimá)** — первая из восьми сил: уменьшение и вхождение в другого; гипноз/телепатия — её ветви (Ch 2, 7).

**Ападевата (apadevatá)** — существо противоположной богам природы (призрак/демон); не путать с upadevatá (Ch 3).

**Арана (arańi / arańya / ban / samidha)** — горючие дрова / лес с ними / обычный лес / жертвенные дрова (Ch 1).

**Аст́асиддхи (aśt́asiddhi / aeshvarya)** — восемь сил: ańimá, laghimá, mahimá (garimá), iishitva, vashitva, prápti, prakámya, antaryámitva; «сила не лучше пепла» (vibhúti) (Ch 2, 7).

**Бхага (bhaga)** — шесть атрибутов: aeshvarya, viirya, yasha, shrii, jiṋána, vaerágya; владелец — Bhagaván/Iishvara (Ch 2).

**Бха́рья (bháryá)** — жена без религиозных и соц. прав мужа, «для продолжения рода» (Ch 6).

**Варги́я-ба / антахстха-ва** — две буквы (b/v), слившиеся в начертании бенгальского; Саркар требует разделить (Ch 8).

**Веды (Veda)** — «знание» (vid + al); rk → súkta → mańd́ala; три части — Rk, Yajuh, Atharva; Samaveda — собрание песен, не Веда (Ch 5).

**Ви́на (viińá)** — древнейший струнный инструмент Шивы (7500 лет, ⚠); из неё — ситар, эсрадж, тамбура, скрипка (Ch 6).

**Вья́са (vyása)** — наследственный титул, не имя; разделитель Вед — Krśńadvaepáyańa Vyása (Ch 5).

**Га́яттри (gáyattrii)** — метр (8 слогов × 3); НЕ имя мантры; «Savitr Rk» — имя по обращению «Savitá» (Ch 3, 5).

**Джа́йя (jáyá)** — жена с соц. правами, без религиозных; дети наследуют от отца (Ch 6).

**Ид́а́ / пингала́ / сушумна́** — левый/правый/центральный каналы; suśumná — «прямой путь» (Ch 1, 5).

**Иикша́на-видья (iikśańa-vidyá)** — наука предсказания «в стадии исследования»; астрология по чертам/имени, гипноз, нумерология — её ветви (Ch 2).

**Иира́ (irá)** — «течь»; вода, воздух, деньги, знание, речь; «ценность в циркуляции» (Ch 1).

**Ииш́вара (iishvara)** — «тот, чья природа — править» (iish + varac); невыразимый, воплощение божественной любви; свободен от klesha-karma-vipáka-áshaya (Ch 2).

**Ииш́вара как «покойный»** — nádabindu (৺) перед именем умершего читается iishvara; не путать с candrabindu (Ch 2, 8).

**Ииш́та (Iśt́a)** — единственный духовный дезидератум; в психическом мире желаний много, их совокупность — abhiiśt́a (Ch 1).

**Ита́ра (itara)** — «народ/масса», а не «низкий»; Aetareya — «созданное для народа» (Ch 7).

**Итиха́са (itihása)** — история с обучающей ценностью; itikathá — хроника фактов; «история Англии» = itikathá (Ch 7).

**Калатра (kalatra)** — жена без прав; дети наследуют материнскую готру/касту; не признанный брак — дети vrátya (Ch 6).

**Крукша (rkśa)** — «медведь» (rś = царапать); гора; разорённая страна — «долг праведных умножать её богатство» (Ch 5).

**Муни (muni)** — «растворивший ум в Парама Пуруше»; не то же, что rśi (Ch 5).

**На́дабинду (nádabindu)** — точка + полумесяц (на́да): связь выраженного с Nirguńa; у имени умершего — «iishvara» (Ch 2, 8).

**Нийога (niyoga)** — дети от социально непризнанного «niyoga pati»; Пандавы — niyoga putras; рост kuliinas при падении качества (Ch 6).

**Ока (oka)** — «собираться вместе» (uc): дуб; «дом» (chátráoka, vishrámaoka) (Ch 8).

**Ом (Om)** — a (творение) + u (поддержание) + m (растворение-возврат) = Saguńa Brahma (Ch 8).

**Оша́дхи (ośadhi)** — «приносящее тепло жизни»: лекарство; «мать умирает при рождении» (банан, краб); злаки — не ośadhi (Ch 8).

**Оша́дхипати (ośadhipati)** — луна: качество лекарств по лунным дням (Ch 8).

**Па́тни (patnii)** — жена с равными религиозными и соц. правами; хранительница огня (Ch 6).

**Прана́ша (prańásha)** — растворение как возврат к источнику, «не смерть» (Ch 8).

**Пратилома / анулома** — брак «мать выше отца» / «отец выше матери»; pratiloma породила сотни каст (Ch 6).

**Рарх (Rarh)** — регион западной Бенгалии; «колыбель цивилизации» в схеме автора (Ch 2, 3, 6).

**Рдж́у (rju)** — «прямой»; rju-márga = suśumná-путь; «не сходи с прямого пути» (Sarahacharya) (Ch 5).

**Рн́а (rńa)** — «долг»; четыре непогашаемых: отцу, матери, ачарье, гуру (Ch 5).

**Рта / сатья (rta / satya)** — факт vs истина-ради-блага; «выбирай satya» (Ch 5).

**Рту (rtu)** — сезон/период времени «в своём ритме» (Ch 5).

**Рши (rśi)** — «поднимающийся вверх»; maharśi, devarśi, rájarśi, brahmarśi; draśt́á-rśi — «увидевший истину» (Ch 5).

**Сав́итри-рк (Savitr Rk)** — Ргведа 3.62.10, метр gáyattrii; с mahávyáhrti (bhúr-bhuvah-svah) из Атхарваведы (Ch 3, 5).

**Сама́веда (Samaveda)** — собрание песенных частей трёх Вед, не Веда (Ch 5).

**Са́ндха́ва-лаван́а (saendhava lavańa)** — глубинная морская соль (йод, кости); karkaca — выпаренная; bádár — местная (Ch 7).

**Си́надха-тадбха́ва (snigdha tadbhava)** — «усыновлённые потомки» ведических: тайский, индонезийский, малайский, тагальский (Ch 6).

**У́д́ха / вью́д́ха (úd́ha / vyúd́ha)** — женат / женат при свидетелях (≥5); buŕo Shiva — из vyúd́ha, не vrddha (Ch 4).

**У́та (úta)** — «сотканное» (vein+kta) и «ад/движение к аду» — из-за сегрегации женщин-ткачих (Ch 4).

**У́ха (úh)** — «жениться» (звук боли распутников, принуждённых Шивой к браку) (Ch 4).

**Ула́ка (uluka / ulluka)** — сова (самолюб) / умная обезьяна; не путать написания (Ch 3).

**Упа́де́ша / нирде́ша / а́де́ша** — совет / указание / приказ; приказ без обоснования — насилие (Ch 3).

**Упа́дева́та (upadevatá)** — «почти бог»: народные боги страха/нужды; не для медитации (Ch 3).

**Упа́на́яна (upanayana)** — ведическое посвящение через Savitr Rk; «Vedic» vs «Tantric initiation» (Ch 3, 5).

**Упа́нья́са (upanyása)** — «класть рядом»: подать еду, предисловие; НЕ «роман» (роман — kathányása) (Ch 3).

**Эка́ (eka)** — «остриё иглы» (in + kan) — «один»; ekáuṋga = Меркурий (Ch 6).

**Эка́ва́да (ekaváda)** — гармоничный инструмент (harmonium, tamboura); samaváda = ekatárá (Ch 6).

**Эка́рши (ekarśi)** — священный огонь, хранимый одним рши; суеверие класть огонь в рот покойнику — «издевательство над историей» (Ch 6).
