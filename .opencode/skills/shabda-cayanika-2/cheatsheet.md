# Читшит — правила решений по Саркару (Shabda Cayaniká Part 2)

## Этимология и язык

| Ситуация | Правило |
|---|---|
| Объяснить слово | Корень + суффикс → этимологическое значение → разговорное → региональные синонимы |
| Выбрать написание | По деривации, не по привычке (uluka ≠ ulluka, ucit, Kalikata ≠ Calcutta) |
| Слитые буквы ba/va | Требуй раздельные символы: орфография следует фонологии |
| Чужие звуки (q, z, f, lra) | Вводи буквы qa/qha/za/fa/lra — иначе теряется произношение |
| Роман/новелла по-бенгальски | `kathányása`, а не `upanyása` (upanyása = «класть рядом», подать еду/предисловие) |
| Веды | rk → súkta → mańd́ala; Samaveda — не Веда (собрание песен) |
| Гаятри | Это метр (8 слогов × 3), не имя мантры; мантра — «Savitr Rk» (по обращению «Savitá») |

## Истина и оценка

| Ситуация | Правило |
|---|---|
| Факт против блага | rta = факт; satya = «ради блага людей»; выбирай satya (укрой беглеца) |
| Оценить «историю»/учебник | Есть обучающая ценность — itihása; хроника фактов — itikathá |
| Народ/масса | itara = «общее население», не «низкий» |
| Знание/деньги застыли | Застой = гниение; ценность в циркуляции (irá) |

## Силы и духовное

| Ситуация | Правило |
|---|---|
| Силa/технология/влияние | Проверь направление: к Богу/благу (Vidyá) или к миру (Avidyá); внешнее использование — деградация |
| Восемь siddhi | ańimá, laghimá, mahimá, iishitva, vashitva, prápti, prakámya, antaryámitva; «сила не лучше пепла» (vibhúti) |
| Цель садханы | Только Парама Пуруша; вторая цель (сиддхи) — crudiфикация (история Кхагена) |
| Духовный фокус | Один Iśt́a; мирские желания — многие (abhiiśt́a) |

## Институты и история

| Ситуация | Правило |
|---|---|
| Анализировать брак/касту | Перечисли права: patnii (все) → jáyá (соц.) → bháryá (род) → kalatra (без прав) |
| Последствия смешанных браков | anuloma — дети в готре отца; pratiloma — только готра отца, без касты → сотни каст |
| Понимать «традицию» | Сверь первоначальный смысл (огонь рши) с поздней практикой (огонь всем) — суеверие эскалируется |
| Сегрегация женщин/шу́др | Корень эксплуатации, империализма и колониализма — борись с ней |
| Долги | Четыре непогашаемых: отцу, матери, ачарье, гуру; гасятся служением людям |

## Практика слов-классов

| Ситуация | Правило |
|---|---|
| Соль | saendhava lavańa — глубинная морская (йод, кости); karkaca — выпаренная; bádár — местная |
| Сахар | aekśava — только из тростника (сок, molasses, сырой, рафинад); свекольный — НЕ aekśava |
| Вино | Различай ферментированное (táŕi, dheno mad, ámáni) и дистиллированное (aereya, изобретение Shukracharya/Nagarjuna); вино разрушает интеллект |
| Лекарственные растения | ośadhi — «мать умирает при рождении»: банан, краб; злаки — нет |
| Планеты | graha = вокруг звезды, upagraha = вокруг планеты; ekáuṋga = Меркурий (без спутников) |

## Быстрые сигналы («tells»)

- Видишь два похожих слова с разной деривацией — проверь написание: `uluka` (сова) vs `ulluka` (обезьяна).
- Слышишь «древний обычай, который обязателен для всех» — почти наверняка поздняя ритуализация личного обряда.
- Сила/влияние растут без контроля направления — жди деградацию носителя.
- Поглощённость «сиддхами» при разговоре о духовности — признак Avidyá-пути.
- «История» без урока — itikathá, а не itihása.
- Исчезающий вид/язык/обычай — признак хищничества человека; охраняй заранее.
- Слово «дом/дуб» у Саркара — `oka`: оба от корня «собираться вместе» (uc).
