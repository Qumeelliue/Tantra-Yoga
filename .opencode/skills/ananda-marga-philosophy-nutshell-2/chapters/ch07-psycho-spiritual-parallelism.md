# Chapter 7: Psycho-Spiritual Parallelism

*Дискурс 4 июня 1959, Jamalpur.*

## Core Idea

Когда ум принимает átman как свой объект (только через полное предание), психические волны постепенно «выпрямляются» до бесконечной длины волны и ум становится átman — это samádhi. Психо-духовная параллельность = idea (bháva); на психическом уровне — ideology (это НЕ партийная доктрина). Психо-физическая параллельность = artha (значение слова). Brahmacarya ≠ целибат, а ассимиляция психической волны в вечные волны Макрокосма. Полное развитие личности (физическое+ментальное+духовное) обязательно.

## Frameworks Introduced

- **Samádhi как параллельность**: психические волны совпадают с духовными волнами átman → ум превращается в átman. Это «идея»/bháva. Идея, зачатая на психическом уровне, = ideology.
- **Корректность термина «ideology»**: включает духовный смысл (параллельность с Духовной Сущностью); называть материалистические/политические принципы «идеологией» — неверное употребление.
- **artha = психо-физическая параллельность**: слово — психическая волна; значение — параллельность с физическим концептом (ребёнок: слово «cat» + увиденная кошка). Бывает прямой и непрямой (через самскары/описание).
- **Brahmacarya ≠ целибат**: ассимиляция психической волны в вечные волны Макрокосма; метод — bháva sádhaná (духовная автоподсказка) при действии. Спасает психические волны от огрубления (psycho-physical parallelism всегда огрубляет).
- **Три тела личности**: физическое (jad́ádhára), ментальное (bhávádhára), духовное/сверхментальное (cetanádhára). Полное развитие каждого необходимо для совершенной духовной реализации.
- **Питание тела**: физическое — правильное питание + физический труд (чистит структуру); ментальное — физический и психический struggle + «ментальная пища» (новые прогрессивные мысли, а не слепая вера в древность); духовное — тоска по Великому (настоящая bhakti). Цитата Shankaracharya: bhakti — лучший путь к mokśa.

## Key Concepts

- **bháva** — «идея»: психо-духовная параллельность.
- **ideology** — концепция идеи на психическом уровне (духовный смысл).
- **artha** — значение слова (психо-физическая параллельность).
- **Brahmacarya** — ассимиляция психической волны в макрокосмические волны.
- **samádhi** — выпрямление психических волн до параллельности с átman.
- **jad́ádhára / bhávádhára / cetanádhára** — физическое/ментальное/духовное тела.
- **bháva sádhaná** — автоподсказка идеи в действии.

## Mental Models

- «Психическая волна → параллельность с духовной = samádhi; параллельность с физической (объект) = значение слова».
- «Каждое слово делает ум грубее (psycho-physical parallelism) — если не возвысить физическую волну духовной надстройкой».
- «Полная личность = три тела, развитые вместе; пренебрежение любым — неполнота».

## Anti-patterns

- **Называть партийную/материалистическую доктрину «идеологией»**: термин подразумевает духовную параллельность.
- **Считать Brahmacarya целибатом**: это ассимиляция психической волны с макрокосмическими волнами.
- **Слепо держаться древних верований**: ментальная пища — новые прогрессивные мысли, борьба с иррациональным.

## Worked Example

*Ребёнок и кошка (разобран автором).* Ребёнок слышит слово «cat», видит кошку; мать говорит: «Это кошка, что пила твоё молоко». Мальчик связывает психическую волну слова с физической волной кошки — устанавливает психо-физическую параллельность = значение. Так слово (психическая волна) обретает artha.

## Key Takeaways

1. Samádhi = психические волны совпали с волнами átman (bháva/idea).
2. Ideology на психическом уровне; неверно применять к материалистическим доктринам.
3. Значение слова (artha) — психо-физическая параллельность.
4. Brahmacarya = ассимиляция психической волны в макрокосмические волны (метод — bháva sádhaná).
5. Личность = физика+ментал+дух; полное развитие всех трёх обязательно.
6. Питание: физическое — пища+труд; ментальное — новый прогресс; духовное — тоска по Великому (bhakti).
