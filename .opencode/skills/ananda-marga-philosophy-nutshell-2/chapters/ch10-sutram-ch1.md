# Chapter 10: Ánanda Sútram — Chapter 1 (сутры 1-1 … 1-25)

*Из «Ánanda Sútram», 1962. Полное изложение — в скилле `ananda-sutram`.*

## Core Idea

Сутры 1-й главы: космология и цикл творения. Brahma = Shiva + Shakti (неразделимы). Prakrti — сила Shiva, работает в рамках полномочий Puruśa. saincara (центробежно, под guńa) и pratisaincara (центростремительно, при ослаблении guńa). Эволюция ума: citta → aham → mahat → buddhi → bodhi. Кульминация: savikalpa/nirvikalpa samádhi, Táraka Brahma как мост.

## Frameworks Introduced

- **1-1…1-4**: Brahma = Shiva+Shakti; Shakti — сила Shiva; Puruśa — material и главный efficient cause, Prakrti — linking force; Puruśottama/Paramashiva — Нуклеус Brahma Cakra.
- **1-5/1-6**: saincara — экстроверсия под ростом guńa (pra vrtti); pratisaincara — интроверсия при убывании guńa (nivrtti); ступени: Mahattattva (sattva), Ahaḿtattva (raja), citta (tamah).
- **1-7**: drk Puruśa (субстанция-свидетель) vs darshanam Shakti (акт видения). Лестница свидетелей: material waves → citta → Ahaḿtattva → Mahattattva → «I know».
- **1-8**: guńa = связывающий принцип; чем сильнее узы — тем грубее; пять факторов. Attributional capacity постоянна (100 звука в эфире → звук+касание в воздухе, сумма та же). ⚠ метафора «100» к калибровке.
- **1-9/1-10**: чрезмерное давление guńa → jad́asphot́a (взрыв, negative saincara); clash факторов → bala/práńa.
- **1-11/1-12**: внутренняя равнодействующая формирует ядро = práńáh (10 вайю, множественное число); чрезмерный clash → cittáńu (mind-stuff) из материи.
- **1-13…1-17**: эволюция ума: citta (done «Я») → aham (raja доминирует) → mahat (sattva) → buddhi (когда aham больше citta) → bodhi (когда mahat больше aham).
- **1-18…1-20**: у низших организмов — только citta; у развитых — citta+aham; у человека — все три.
- **1-21/1-22**: savikalpa samádhi (слияние citta→aham→mahat; saguńásthiti); nirvikalpa samádhi (mahat сливается в átman; nirguńásthiti).
- **1-23/1-24**: nirvikalpa — за пределами ума; остаточное блаженство после vacuity — доказательство состояния.
- **1-25**: Táraka Brahma — мост между Nirguńa и Saguńa; в saguńa форме — Mahásambhúti.

## Key Concepts

- **Brahma Cakra / Srśt́i Cakra** — Космический цикл.
- **guńa** — связывающий принцип (sattva/raja/tamah).
- **Mahattattva / Ahaḿtattva / citta** — «Я существую» / Doer «Я» / done «Я».
- **drk** — субстанция-свидетель; **darshanam** — акт видения (Shakti).
- **bala / práńa / práńáh** — энергия/сила/витальная энергия.
- **cittáńu** — mind-stuff/эктоплазмические частицы.
- **buddhi / bodhi** — интеллект / интуиция (по превосходству aham/mahat).
- **savikalpa / nirvikalpa samádhi** — детерминированная / недетерминированная абсорбция.
- **Táraka Brahma** — мост; **Mahásambhúti** — Его воплощение.

## Mental Models

- «Свидетель — вершина лестницы: каждое "действие" имеет свидетеля на уровень выше, вплоть до "I know" (drk)».
- «Узы огрубляют: сила guńa определяет грубость фактора; сброс уз возвращает к тонкому».
- «Два уровня samádhi: слияние в макрокосмическом махате (savikalpa) и полный выход (nirvikalpa)».

## Anti-patterns

- **Путать «знание» (buddhi) с «интуицией» (bodhi)**: buddhi — при доминанте aham над citta; bodhi — при доминанте mahat над aham.
- **Считать vacuity сном**: в vacuity ум уничтожен полностью; в сне работает бессознательный ум.
- **Думать, что инкарнация — «прямой спуск»**: возвышение всегда постепенное (сутры 1-4/1-6).

## Worked Example

*Эволюция ума в сутрах.* Низшие организмы: citta (done «Я») без aham/mahat → растение/лиана. Развитые: citta+aham. Человек: mahat+aham+citta. Практикой: citta сливается в aham, aham в mahat → savikalpa samádhi (saguńásthiti). Когда mahat сливается в átman — nirvikalpa samádhi (nirguńásthiti), за пределами ума, с доказательством в виде остаточного блаженства.

## Key Takeaways

1. Brahma = Shiva+Shakti; Puruśottama — Нуклеус цикла.
2. saincara под ростом guńa, pratisaincara при их убывании.
3. Лестница свидетелей заканчивается «I know» (drk).
4. Эволюция ума: citta → aham → mahat → buddhi/bodhi.
5. Savikalpa/nirvikalpa samádhi — два финала практики.
6. Táraka Brahma — мост Nirguńa/Saguńa.
