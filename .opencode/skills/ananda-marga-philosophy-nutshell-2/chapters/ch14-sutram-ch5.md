# Chapter 14: Ánanda Sútram — Chapter 5 (сутры 5-1 … 5-16)

*Из «Ánanda Sútram», 1962. Также в «Universal Humanism» как «The Principles of Progressive Socialism», в Proutist Economics — «The Principles of Prout». Полное изложение — в скилле `ananda-sutram`.*

## Core Idea

Сутры о социальном цикле и экономике Prout. В движении социального цикла один класс всегда доминирует (Shúdra → Kśatriya → Vipra → Vaeshya → shúdra revolution → цикл). Sadvipras — в центре цикла, контролируют его, пресекая эксплуатацию (вплоть до силы). Разнообразие — закон природы; минимальные требования гарантируются всем, излишек — по заслугам; минимум постоянно поднимается. Пять принципов Prout.

## Frameworks Introduced

- **5-1**: эпохи: Shúdra (ручной труд) → Kśatriya (сила) → Vipra (интеллект) → Vaeshya (капитал) → shúdra revolution → второй Kśatriya Age. Цикл вращается.
- **5-2**: sadvipras — моралисты+духовники в центре (nucleus) цикла; их долг — пресекать эксплуатацию силой (защищать праведных, укрощать эксплуататоров).
- **5-3/5-4**: kránti — ускорение цикла силой (эволюция); viplava — революция (огромная сила, короткий срок).
- **5-5/5-6**: vikránti — обращение цикла силой (counter-evolution, крайне недолговечно); prativiplava — контрреволюция (сила, короткий срок, ещё менее долговечна).
- **5-7**: parikránti — полный оборот цикла (завершение shúdra revolution).
- **5-8**: разнообразие — закон природы; уравнивание — против Prakrti, ведёт к разрушению. «Бог-Отец, Prakrti-Мать, три мира — родина».
- **5-9/5-10**: минимальные требования (еда/одежда/медицина/жильё/образование) гарантируются всем по веку (велосипед vs самолёт ⚠); излишек распределяется по заслугам (врачу — машина ⚠). Критика «служи по способности, получай по необходимости».
- **5-11**: повышение минимального уровня — признак жизненности общества (велосипед → мотор → самолёт для всех, эндлесс).
- **5-12…5-16** (пять принципов Prout): (1) накопление — только с одобрения коллектива; (2) максимальное и рациональное распределение всех потенциалов (crude/subtle/causal); (3) максимальное использование потенциалов единиц и коллектива (физика/ментал/дух); (4) правильная состыковка использований (минимум через труд, покупательная способность; баланс взятия физического/интеллектуального/духовного служения; контроль — у духовно+интеллектуально+храбро развитых); (5) метод меняется по time/space/person, прогрессивность (научные исследования вместо одной кувалды).

## Key Concepts

- **samája cakra** — социальный цикл.
- **sadvipra** — морально-духовный контролёр цикла.
- **kránti / viplava / vikránti / prativiplava / parikránti** — типы изменений.
- **vaecitryaḿ prákrtadharmah** — разнообразие — закон природы.
- **sarvanimnaprayojanam** — минимальные требования для всех.
- **atiriktaḿ pradátavyaḿ guńánupátena** — излишек по заслугам.
- **pragatishiila upayogatattva** — Прогрессивная теория использования (Prout).

## Mental Models

- «Социальный цикл нельзя остановить — можно только контролировать (sadvipra в центре) и ускорять/обращать».
- «Минимум — право всех; максимум — усилие: излишек по заслугам, разрыв сокращать».
- «Разнообразие — закон: уравнивание разрушает; настройка по time/space/person — прогресс».

## Anti-patterns

- **Уравниловка**: против закона природы (5-8), ведёт к разрушению.
- **Накопление без одобрения коллектива**: урезает права других (5-12).
- **«Служи по способности, получай по необходимости»**: не работает в реальности (5-10).
- **Застой минимума**: без подъёма минимума общество нежизнеспособно (5-11).
- **Клингing к прошлому (национализм/предки)**: против принципа изменчивости метода (5-16).

## Worked Example

*Минимум и излишек (разобран автором).* В век велосипеда ⚠ минимум для всех — велосипед; врачу нужна моторная машина (заслуга/необходимость службы) ⚠. Усилие общества — поднять минимум: всех снабдить мотором, затем каждому заслуженному — самолёт, затем всех — самолётом и т.д. На этом бесконечном подъёме минимума — жизненность общества.

## Key Takeaways

1. Цикл эпох: Shúdra → Kśatriya → Vipra → Vaeshya → shúdra revolution → повтор.
2. Sadvipra в центре цикла пресекает эксплуатацию силой.
3. Kránti/viplava — ускорение; vikránti/prativiplava — обращение (недолговечно); parikránti — полный оборот.
4. Разнообразие — закон природы; уравнивание разрушает.
5. Минимум гарантируется всем; излишек — по заслугам; минимум поднимается постоянно.
6. Пять принципов Prout: коллектив-одобрение, макс. распределение, макс. использование, состыковка, прогрессивность по time/space/person.
