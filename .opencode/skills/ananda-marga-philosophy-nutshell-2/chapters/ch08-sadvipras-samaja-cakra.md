# Chapter 8: The Place of Sadvipras in the Samája Cakra

*Дискурс 4 июня 1959, Jamalpur. Из Idea and Ideology / Prout in a Nutshell.*

## Core Idea

Социальная эволюция проходит цикл эпох: Shúdra → Kśatriya → Vipra → Vaeshya → (shúdra revolution) → новый цикл. Смена эпох — эволюция (kránti); полный оборот — parikránti; насильственное обращение — vikránti/prativiplava. В центре цикла — sadvipra: морально-духовный революционер по Yama/Niyama, чей долг — не дать доминирующему классу эксплуатировать остальных (включая применение силы по типу эпохи).

## Frameworks Introduced

- **Эпохи и классы**: Shúdra Age (все — ручной труд), Kśatriya Age (сила/оружие, геркулесовы гиганты), Vipra Age (интеллект; «интеллектуальные паразиты», кастовая система как орудие), Vaeshya Age (капиталисты, laissez-faire→капитализм, «жажда приобретения»). Shúdra revolution → лидеры-kśatriya → второй цикл.
- **Термины смены**: evolution (kránti) — постепенная смена; yuga saḿkránti — переходный век; parikránti — полный оборот; vikránti — обращение цикла силой (counter-evolution, недолговечно); prativiplava — контрреволюция (сила + короткий срок). Аналогия с negative pratisaincara Brahma Cakra.
- **Сadvipra**: духовные революционеры, работающие на продуманной основе в физической/метафизической/духовной сферах, соблюдая Yama и Niyama. В центре цикла (samája cakra), не на периферии.
- **Yama (5)**: ahiḿsá (не причинять страдания безвредным существам мыслью/словом/делом), satya (помощь в реальном смысле), asteya (не-кража, включая умственную: отказаться от желания чужого), aparigraha (без излишеств для сохранения жизни), Brahmacarya (ощущение Его присутствия в каждой объективности).
- **Niyama (5)**: shaoca (чистота физическая/ментальная), santośa (довольство результатом своего труда), tapah (усилия вопреки дискомфорту), svádhyáya (изучение писаний и ассимиляция духа), Iishvara prańidhána (автоподсказка «я — инструмент Всевышнего», вера в счастье и в несчастье).
- **Долг sadvipra**: не дать доминирующему классу эксплуатировать. Тип действия по эпохе: kśatriya-эксплуататоры → физическая сила; vipra-доминирование → революция в интеллектуальном поле; vaeshya-доминирование → выиграть выборы (демократия — их инструмент накопления).

## Key Concepts

- **samája cakra** — социальный цикл/колесо.
- **sadvipra** — морально-духовный революционер в центре цикла.
- **shúdra / kśatriya / vipra / vaeshya** — классы эпох.
- **kránti / parikránti / vikránti / prativiplava** — типы смены цикла.
- **yuga saḿkránti** — переходный век.
- **Yama / Niyama** — 5+5 морально-духовных правил.
- **Stagnancy means death** — застой = смерть; цикл нельзя остановить, только ускорить/замедлить.

## Mental Models

- «Социальный цикл вращается всегда: нельзя остановить, можно только ускорить/замедлить; застой = гибель».
- «Доминирующий класс всегда склонен к эксплуатации; роль садвипры — стоять в центре и не пускать эксплуатацию».
- «Тип силы садвипры соответствует типу эпохи: физика — kśatriya, интеллект — vipra, выборы — vaeshya».

## Anti-patterns

- **Верить в «вечное» доминирование класса**: цикл неизбежно продолжается (shúdra revolution → kśatriya → …).
- **Считать эксплуатацию «естественной»**: это деградирует и эксплуататора (излишества), и эксплуатируемого (грубые волны).
- **Думать, что sadvipra — «неактивный свидетель»**: они активные участники, вплоть до физической силы.

## Worked Example

*Vaeshya-эпоха (разобран автором).* Капиталисты (vaeshya) накапливают средства производства; большинство (shúdras) становится наёмными рабами. Внутренний clash и динамика психологии общества → недовольство → shúdra revolution, возглавляемая физически/умственно лучшими (тоже kśatriya). После хаоса — второй Kśatriya Age, и цикл повторяется.

## Key Takeaways

1. Цикл эпох: Shúdra → Kśatriya → Vipra → Vaeshya → (shúdra revolution) → повтор.
2. Kránti — ускорение/эволюция; parikránti — полный оборот; vikránti/prativiplava — насильственное обращение (недолговечно).
3. Sadvipra — духовный революционер по Yama/Niyama, в центре цикла.
4. Yama: ahiḿsá, satya, asteya, aparigraha, Brahmacarya; Niyama: shaoca, santośa, tapah, svádhyáya, Iishvara prańidhána.
5. Долг садвипры — блокировать эксплуатацию доминанта силой, соответствующей эпохе.
6. Цикл нельзя остановить; застой = смерть.
