# Chapter 3: Kośa

*Дискурс 31 мая 1959, Jamalpur.*

## Core Idea

Ум действует через органы и нервы, получая/излучая tanmátras. Пять kośa — стадии crudification citta: hirańmaya → vijiṋánamaya → atimánasa → manomaya → kámamaya. Семь loka — макрокосмические миры, где обитают kośa и свидетели. Даётся полная таблица соответствий kośa / mind / witnessing entity / deha / loka.

## Frameworks Introduced

- **Три агента ума**: моторные/сенсорные органы — прямые агенты; афферентные/эфферентные нервы — прямые агенты органов; нервы, связывающие ум с объектами, — непрямые агенты.
- **Отражение vs преломление tanmátras**: отражение → объект в сфере ощущения/восприятия/концепции; преломление — частично; ни отражения ни преломления — вне чувств.
- **Точность восприятия**: зависит от здоровья объекта, ворот, tanmátras, нервов, citta и готовности ego. Глаукома — пример: отложение жидкости в оптическом нерве → белые лучи кажутся спектральными.
- **Пять kośa**: hirańmaya (самый тонкий), vijiṋánamaya, atimánasa, manomaya, kámamaya (самый грубый). kámamaya — crude mind (sthúla manah); manomaya — subtle mind (súkśma manah); три остальных — causal/astral mind. «Сознательное/подсознательное/бессознательное» — некорректная номенклатура.
- **Makroкосм vs микрокосм**: kámamaya Макрокосма выражен через пять факторов (включая annamaya единицы). Единый causal mind во вселенной; различие micro/macro — лишь «семя прошлых действий».
- **Тела**: Макрокосм — kámamaya = crude body Paramátman; остальные kośa = subtle body; aham/mahat = astral/causal body. Единица: annamaya = sthúla deha; kośa = súkśma deha; выше hirańmaya до Puruśottama = sámánya deha.
- **Свидетели**: Макрокосм — causal: Virát́a/Vaeshvánara; subtle: Hirańyagarbha; crude: Iishvara. Микрокосм — causal: Vishva; subtle: Taejasa; crude: Prájiṋa.
- **Семь loka**: bhú (физический), bhuvah (crude mental), svah (subtle mental), mahah (supramental), janah (subliminal), tapah, satya. Макрокосм только; единицы kośa не loka.

## Key Concepts

- **kámamaya kośa** — crude mind; контролирует физические желания.
- **manomaya kośa** — subtle mind; recollection/contemplation (smarańa, manana).
- **atimánasa / vijiṋánamaya / hirańmaya** — causal/astral mind.
- **annamaya kośa** — тело (только у единицы).
- **Virát́a / Hirańyagarbha / Iishvara** — свидетели макрокосмических умов.
- **Vishva / Taejasa / Prájiṋa** — свидетели микрокосмических умов.
- **loka** — макрокосмические миры (7).
- **sámánya deha** — тело между hirańmaya и Puruśottama.
- **Puruśottama** — Нуклеус, свидетель causal ума.

## Mental Models

- «Думай о кос́ах как о луковице: сними грубый слой — увидишь тоньше; субъект вживается только по мере удаления грубых слоёв».
- «Каждому слою ума — свой свидетель; на разных уровнях Puruśottama отражается под разными именами».
- «Каузальный ум един во вселенной — различие единиц лишь в "семени" прошлых действий».

## Anti-patterns

- **Приравнивать kośa к conscious/subconscious/unconscious**: Саркар называет это номенклатурой некорректной.
- **Считать loka местом «после смерти» как буквальные миры**: loka — состояния/сферы Cosmic Mind, а не география загробного мира.
- **Ожидать, что у единицы есть отдельный causal mind**: теоретически отдельного causal нет — он един с Cosmic causal.

## Worked Example

*Глаукома (разобран автором).* У пациента глаукома — жидкость откладывается в оптическом нерве, свет рассеивается внутри; белые лучи кажутся спектральными. Восприятие неверно, хотя объект здоров. Вывод: точность восприятия зависит от всей цепи (объект → ворота → tanmátras → нервы → citta → ego).

## Key Takeaways

1. Пять kośa — стадии crudification citta; kámamaya грубейший, hirańmaya тончайший.
2. kámamaya+manomaya = crude+subtle mind; остальные — causal mind.
3. Семь loka — миры Макрокосма; каждому kośa — свой свидетель.
4. Восприятие верно только при здоровой всей цепи (объект→ego).
5. Единого causal ума в отдельности нет — он един с Cosmic causal.
6. Таблица kośa/loka/deha/witnessing — ключевая справка дискурса.
