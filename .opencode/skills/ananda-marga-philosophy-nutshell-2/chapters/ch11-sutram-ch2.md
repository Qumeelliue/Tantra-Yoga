# Chapter 11: Ánanda Sútram — Chapter 2 (сутры 2-1 … 2-24)

*Из «Ánanda Sútram», 1962. Полное изложение — в скилле `ananda-sutram`.*

## Core Idea

Сутры о счастье, dharma и психологии восприятия. Счастье — контениальное психическое ощущение (совместимые волны самскар). Привязанность к счастью — первичная vrtti. Бесконечное счастье = ánanda = Brahma. Томление по Бесконечному — dharma; dharma следует практиковать всегда. Психология: jiivátma — отражение Puruśa в объекте; ota/prota yoga; познание через tanmátras; нет рая/ада.

## Frameworks Introduced

- **2-1…2-5**: счастье — контениальный психический контакт волн (ануку́лаведанийям); первичная вртти — привязанность к счастью (самопохранение); бесконечное счастье = ánanda = Brahma (единственный безграничный объект); его достижение гасит всю жажду.
- **2-6/2-7**: томление за Бесконечным = dharma; сознательная попытка + молитва = dharma sádhaná. dharma следует практиковать всегда (животные не могут, человек — обязан).
- **2-8**: jiivátmá — отражение Puruśa в объекте/уме; Paramátmá = Bhúmá Caetanya. Сумма микрокосмов = Макрокосм.
- **2-9**: всё укоренено в átman: объект → citta → aham → mahat → «I know» (átman).
- **2-10**: ota yoga (связь с единицами) + prota yoga (связь с коллективом) = Puruśottama.
- **2-11/2-12**: семя вселенной — за умом (махат); бесконечный регресс причин неприемлем; творение из Saguńa Brahma.
- **2-13/2-14**: вселенная — в Bráhmiidehe (Космическом теле); Brahma = Абсолютная Истина; мир = относительная истина (time/space/person).
- **2-15…2-19**: Puruśa — не деятель, свидетель и контролёр guńa; buddhitattva/mahattattva не действует; aham — деятель и пожинатель; citta принимает форму результата (karmaphala); процесс возврата деформированного citta = переживание результатов.
- **2-20**: нет рая/ада (svarga/rasátala): среда вокруг праведного — «рай», вокруг злого — «ад».
- **2-21…2-24**: пять факторов из Cosmic citta (субтара); tanmátra — волны от clash факторов, распознают факторы (по грубейшей); indriya = ворота + нервы + нервная жидкость + piit́ha (точки в мозге); práńendriya соединяет объективность с mind-stuff.

## Key Concepts

- **anukúlavedaniiyaḿ sukham** — контениальное ощущение = счастье.
- **ánanda** — бесконечное счастье = Brahma.
- **dharma sádhaná** — практика dharma (томление за Бесконечным).
- **jiivátmá / Paramátmá / Bhúmá Caetanya** — отражение/источник.
- **ota / prota yoga** — связь с единицами / с коллективом.
- **Bráhmiideha** — Космическое тело.
- **karmaphala** — результат действия (citta принимает форму).
- **tanmátra / piit́ha** — волны/точки восприятия.
- **svarga / rasátala** — «рай/ад» как состояния среды.

## Mental Models

- «Счастье — резонанс волн: совпадают самскары и волны окружения — хорошо; нет — "душно"».
- «Единственный безграничный объект — Brahma; только он утоляет жажду».
- «Действие деформирует citta; возврат к форме — переживание результата (без рая/ада)».

## Anti-patterns

- **Считать «существование» переводом sat**: sat = неизменное (см. Ch 5).
- **Верить в загробные рай/ад**: среда здесь и сейчас — «рай»/«ад».
- **Искать причину творения во времени**: за махатом — бесконечный регресс, вопрос избыточен.

## Worked Example

*Слово и кошка (сутра-контекст, ср. Ch 7).* Ребёнок слышит «cat», видит кошку — устанавливает психо-физическую параллельность (значение). В сутре 2-22: tanmátras — волны от объекта к воротам органов, через нервы — к точкам мозга; citta принимает форму → восприятие. Индрия = ворота+нерв+жидкость+точка (2-24).

## Key Takeaways

1. Счастье = контениальный резонанс волн; привязанность к нему — первичная vrtti.
2. Бесконечное счастье = ánanda = Brahma; dharma — томление за Ним, практиковать всегда.
3. jiivátma — отражение Puruśa; Puruśottama связан ota+prota.
4. Puruśa — свидетель/контролёр; aham — деятель; citta — форма результата.
5. Рая/ада нет: среда — «рай»/«ад» здесь.
6. Восприятие: tanmátra → ворота → нервы → piit́ha → citta.
