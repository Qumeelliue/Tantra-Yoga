# Читшит — правила решений по Саркару (Nutshell 2)

## Восприятие и ум

| Ситуация | Правило |
|---|---|
| Почему сигнал не доходит | Проверь всю цепь: объект → ворота/органы → нервы → точки в мозге → citta → ego + пауза пра́н́endriya |
| Активность мешает восприятию | Пра́н́endriya в расширенной фазе блокирует входные волны; нужна пауза/контроль |
| Оценить ум | Ум = mahat + aham + citta; тот же «stuff», что у Cosmic Mind |
| Инстинкты | Sentiment через подчинённые железы = instinct (не «накопленный sentiment») |
| Vrtti | 1000 vrtti = 50 × 2 × 10 ⚠; контроль sahasrára = nirvikalpa samádhi = mokśa |

## Kośa и loka

| Ситуация | Правило |
|---|---|
| Слои ума | 5 kośa (от тонкого): hirańmaya → vijiṋánamaya → atimánasa → manomaya → kámamaya (+annamaya — тело) |
| Миры Макрокосма | 7 loka: bhú → bhuvah → svah → mahah → janah → tapah → satya |
| Свидетели макро | Iishvara (crude) / Hirańyagarbha (subtle) / Virát́a-Vaeshvánara (causal) |
| Свидетели микро | Prájiṋa (crude) / Taejasa (subtle) / Vishva (causal) |

## Карма, жизнь, смерть

| Ситуация | Правило |
|---|---|
| sat/cit/ánanda | sat=неизменное, cit=сознание, ánanda=блаженство (НЕ «существование/знание/блаженство») |
| Реакция на действие | citta принимает форму результата; возврат = переживание (karmaphala) |
| Смерть | Потеря параллельности психических/физических волн; 9 вайю уходят, dhanaiṋjaya остаётся |
| Неотработанные реакции | Saḿskára → перерождение в подходящем теле (подбирает Prakrti/макрокосм) |
| Рай/ад/призраки | Нет: без мозга нет ощущений; «рай/ад» — среда здесь |

## Социальный цикл

| Ситуация | Правило |
|---|---|
| Кто доминирует | Один класс всегда доминирует; цикл: Shúdra → Kśatriya → Vipra → Vaeshya → shúdra revolution → повтор |
| Как назвать смену | Kránti — ускорение; viplava — революция; vikránti/prativiplava — обращение (недолговечно); parikránti — полный оборот |
| Пресечь эксплуатацию | Sadvipra в центре: физика (kśatriya), интеллект (vipra), выборы (vaeshya) |
| Цикл нельзя остановить | Застой = смерть; можно только ускорить/замедлить/контролировать |

## Экономика (Prout)

| Ситуация | Правило |
|---|---|
| Минимум для всех | Еда/одежда/медицина/жильё/образование гарантируются по веку |
| Излишек | По заслугам/таланту; разрыв с минимумом постоянно сокращать |
| Подъём уровня | Минимум поднимать постоянно (жизненность общества) |
| Накопление | Только с одобрения коллектива |
| Уравниловка | Против закона природы (разнообразие); ведёт к разрушению |
| Метод | Меняется по time/space/person; прогрессивность обязательна |

## Тантра-космология (быстрая справка)

| Ситуация | Правило |
|---|---|
| Начало творения | Anucchúnyá → треугольник сил → kámabiija (семя желания) → náda → kalá → sadrsha parińáma |
| Имена Prakrti/Puruśa | Shivánii/Shiva → Bhaeravii/Bhaerava → Bhavánii/Bhava |
| Путь к mukti | Пересечь Avidyámáyá под Vidyámáyá (к слиянию) |
| Путь к mokśa | Только негативный: подъём kulakuńd́alinii от му́ла́дха́ры |

## Быстрые сигналы («tells»)

- «Всё настроено, но не воспринимается» → ритм пра́н́endriya (пауза против расширения).
- Доктрина называет себя «идеологией» без духовного смысла → неверное употребление (Саркар).
- Обещание награды «после смерти» → проверь наличие работающего ума/мозга.
- Гарантия минимума без труда → риск «психологии лени».
- «Сделаем всех равными» → против закона природы (разнообразие), разрушение.
- Доминант-класс у власти → ожидай склонности к эксплуатации; нужен контролёр (садвипра).
