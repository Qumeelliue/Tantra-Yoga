# Паттерны — Ananda Marga Philosophy in a Nutshell Part 2

## Анализ восприятия через волны
**Когда использовать**: разбор UX/коммуникации/восприятия (почему сигнал не доходит).
**Как**: проверь всю цепь: источник (здоров), ворота/органы, нервы, точки в мозге, citta (форма), готовность ego, ритм пра́н́endriya (пауза vs расширение). Сбой любого звена = сбой восприятия.
**Компромиссы**: физиологическая модель Саркара; современная наука требует уточнений, но «проверь всю цепь» универсально.

## Диагностика «паузы пра́н́endriya»
**Когда использовать**: почему качество восприятия/понимания падает при активности.
**Как**: если «все нервы» заняты (бег, многозадачность), пра́н́endriya в расширенной фазе — входные волны блокируются; для точного восприятия нужна пауза/контроль (ср. медитация, single-tasking).
**Компромиссы**: не все виды восприятия страдают одинаково; применяй как объяснение «расфокуса», не как закон.

## Анализ личности как трёх тел
**Когда использовать**: оценка развития человека/команды/продукта.
**Как**: проверь три измерения — физическое (тело/здоровье/труд), ментальное (новые прогрессивные мысли, борьба с иррациональным), духовное (тоска по Великому/цель выше себя). Развитие каждого необходимо; недоразвитие любого = неполнота.
**Компромиссы**: «духовное» для секулярных команд → высшие цели/миссия; следи за балансом.

## Цикл социальных эпох
**Когда использовать**: анализ власти/неравенства/динамики любой системы.
**Как**: определи, какой ресурс доминирует (сила → интеллект → капитал → число работников); ожидай, что доминант склонен к эксплуатации; предскажи, какой класс поднимется следующим (после капиталистов — шудра-революция с кшатрий-лидерами). Цикл нельзя остановить — можно только контролировать.
**Компромиссы**: четырёхклассная схема упрощена для смешанных экономик; применяй как каркас вопроса.

## Роль «садвипры» (контролёр цикла)
**Когда использовать**: проектирование механизмов против злоупотребления властью.
**Как**: нужен независимый морально-духовно сильный центр, который блокирует эксплуатацию доминанта силой, соответствующей эпохе (физика/интеллект/выборы). Без такого контролёра цикл эксплуатации повторяется.
**Компромиссы**: «сила» опасна — требуется институционализация (правила Yama/Niyama), а не произвол.

## Экономика минимума/максимума (Prout)
**Когда использовать**: распределение ресурсов, соц. политика, экономика платформы.
**Как**: (1) минимум (еда/одежда/медицина/жильё/образование) гарантируй всем по веку; (2) излишек — по заслугам/таланту; (3) постоянно поднимай минимальный уровень (а не раздувай излишек); (4) избегай «психологии лени» (минимум через труд по способности); (5) накопление — с одобрения коллектива.
**Компромиссы**: требует меры «заслуги» и контроля накопления — конфликтует с либеральными нормами; калибровать.

## Разнообразие — закон природы
**Когда использовать**: дизайн политик/продукта (унификация vs кастомизация).
**Как**: не уравнивай всех — разнообразие природно (по time/space/person); настраивай метод/опыт под контекст; «одинаковость» разрушает систему.
**Компромиссы**: разнообразие ≠ неравенство в правах; баланс между гарантией минимума и свободой различий.

## Идеология с духовным смыслом
**Когда использовать**: выбор терминов/принципов для коллектива.
**Как**: не называй материалистическую/партийную доктрину «идеологией» (Саркар): ideology = концепция идеи с духовной параллельностью. Для продукта: идеология = набор принципов, соединённых с высшей целью, а не лозунги.
**Компромиссы**: терминологический сдвиг; в светском контексте замени «духовное» на «ценностное».

## Анализ «рай/ад здесь»
**Когда использовать**: оценка наград/наказаний и обещаний «после».
**Как**: если нет работающей среды (ум/мозг) в «после» — обещание нереалистично; среда вокруг действия сама становится «раем»/«адом». Дизайн систем — создавай среду, а не обещания.
**Компромиссы**: метафора; в институциях «после» может существовать (суд, карма-система).

## Сутры как компактный рефрейминг
**Когда использовать**: сложение сложной системы в краткие правила.
**Как**: формулируй принцип одной фразой с pуrport-объяснением (механика + граница); каждая сутра — решающее правило для ситуации. Используй для конституций/манифестов/правил платформы.
**Компромиссы**: сутры требуют толкования — держи purports, иначе двусмысленность.
