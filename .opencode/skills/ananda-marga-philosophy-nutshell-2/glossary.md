# Глоссарий — Ananda Marga Philosophy in a Nutshell Part 2

**Anucchúnyá Prakrti** — латентная Prakrti в Nirguńa; причинная стадия трёх выраженных принципов (Ch 2).

**Avidyámáyá / Vidyámáyá** — сила неведения (экстроверсия к грубому) / сила знания (интроверсия к Puruśottama) (Ch 4).

**Átman (unit consciousness)** — свидетель ума; ultimate knowership/doership/existence; не деятель (Ch 4, 5).

**Bhava / Bhavánii** — Puruśa/Prakrti в стадии кривизн (sadrsha parińáma); «bhava» = стать/создание (Ch 6).

**Bhaerava / Bhaeravii** — Puruśa/Prakrti в стадии náda (прямая линия) (Ch 6).

**Bháva (idea)** — психо-духовная параллельность (Ch 7).

**Bháva sádhaná** — автоподсказка идеи в действии (метод Brahmacarya) (Ch 7).

**Brahmacarya** — ассимиляция психической волны в вечные волны Макрокосма; НЕ целибат (Ch 7, 8).

**Buddhi / Bodhi** — интеллект / интуиция (по превосходству aham над citta / mahat над aham) (Ch 10).

**Citta** — done «Я»/mind-stuff; принимает форму результата действия (karmaphala) (Ch 10, 11).

**Cittáńu** — mind-stuff/эктоплазмические частицы, рождённые из материи (Ch 10).

**Guńa** — связывающий принцип Prakrti: sattva/raja/tamah (Ch 6, 10).

**Ideology** — концепция идеи на психическом уровне; содержит духовный смысл (Ch 7).

**Indriya** — органы: 5 сенсорных + 5 моторных; ум — хозяин (Ch 1).

**Instinct** — sentiment, затрагивающий подчинённые железы (Ch 2).

**Jad́ádhára / Bhávádhára / Cetanádhára** — физическое/ментальное/духовное тела личности (Ch 7).

**Jad́asphot́a** — взрыв (негативный saincara), распад до пяти факторов (Ch 1).

**Jiivátman** — единичный свидетель (отражение Puruśottama) (Ch 5).

**Kalá** — первая кривизна (kriyá shakti) (Ch 6).

**Káma-piitha** — арена кулакун́да́лини (Ch 6).

**Karmaphala** — результат/реакция действия; citta принимает форму результата (Ch 5, 11).

**Karmáshaya / saḿskára** — реакция в потенциальности (Ch 5, 12).

**Kámamaya kośa** — crude mind (Ch 3).

**Kośa** — слои ума: hirańmaya, vijiṋánamaya, atimánasa, manomaya, kámamaya (+annamaya — тело) (Ch 3, 12).

**Kránti** — ускорение социального цикла силой (эволюция); **parikránti** — полный оборот; **vikránti** — обращение силой; **prativiplava** — контрреволюция; **viplava** — революция (Ch 8, 14).

**Kút́astha** — Нуклеус-сознание (между бровями в единице) (Ch 4).

**Kulakuńd́alinii** — «свёрнутая змея»; фундаментальная негативная сила единицы в му́ла́дха́ре (Ch 6, 13).

**Loka (7)** — миры Cosmic Mind: bhú, bhuvah, svah, mahah, janah, tapah, satya (Ch 3, 12).

**Mahápuruśa** — возвышенное существо (Ch 4).

**Mahattattva / Ahaḿtattva** — «Я существую» / Doer «Я» (Ch 2, 10).

**Nirguńa / Saguńa Brahma** — неквалифицированное / квалифицированное Сознание (Ch 4).

**Ota / Prota yoga** — связь Puruśottama с единицами / с коллективом (Ch 4, 11).

**Paramátman** — Puruśottama + ota/prota yogas; «сознающий творение» (Ch 4).

**Práńa / Práńáh** — энергия / витальная энергия (10 вайю) (Ch 2, 5, 10).

**Práńendriya** — «шестой орган» в сердце (anáhata cakra); пульсирующий (Ch 2).

**Psychic dilation** — психическое расширение ума (ср. Part 1, Ch 7) (Ch 4).

**Sadvipra** — морально-духовный революционер в центре социального цикла (Ch 8, 14).

**Sádhaná** — ускорение pratisaincara; критерий «я стремлюсь к Нему» (Ch 4).

**Samája cakra** — социальный цикл (Ch 8, 14).

**Sat / Cit / Ánanda** — неизменное / сознание / блаженство (не «существование/знание/блаженство») (Ch 5).

**Sahrda parińáma** — гомогенезис: последовательность схожих кривизн (Ch 6, 13).

**Svarúpa parińáma** — гомоморфная эволюция: обмен идентичностей guńa (Ch 6, 13).

**Shambhúliuṋga / Svayambhúliuṋga** — корни фундаментальной позитивности / негативности (Ch 6, 13).

**Shiva / Shivánii (Kaośikii)** — Puruśa/Prakrti в теоретической стадии треугольника (Ch 6, 13).

**Tanmátra** — микроскопическая фракция волны (звук/касание/форма/вкус/запах) (Ch 1, 11).

**Táraka Brahma** — мост между Nirguńa и Saguńa; Mahásambhúti — Его воплощение (Ch 4, 10).

**Vrtti** — способ выражения ума (любовь/ненависть/страх); 1000 (50×2×10) ⚠ (Ch 2).

**Yama / Niyama** — 5+5 морально-духовных правил садвипры (Ch 8).

**Jad́ádhára/Bhávádhára/Cetanádhára** — см. три тела (Ch 7).

**Shukra** — финальная эссенция тела (лимфа → сперма/яйцеклетка → семенная жидкость) ⚠ (Ch 5).
