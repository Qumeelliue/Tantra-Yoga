# Chapter 2: Material and Abstract in Knowledge

*Дискурс 4.05.1980, Калькутта.*

## Core Idea

Обычное знание — «счастливое смешение» материального и абстрактного, при этом большая часть процесса материальна, малая — абстрактна. Память (smrti) — воспроизведение ранее воспринятого; устойчивая спонтанная память (dhruvásmrti) — основа духовного блаженства.

## Frameworks Introduced

- **Материальный канал познания**: объект → вибрация (звук/прикосновение/форма/вкус/запах) → indriya (ворота органа чувств) → нервная система → мозг → отпечаток. Пример: кислый вкус тамаринда/сливы/тыквы — разные отпечатки, разные вибрации ума.
- **Абстрактный канал**: отпечаток создаёт вибрацию в уме; ритмическая вибрация «растёкся» по уму, может опуститься к эфферентным нервам (ноги двигаются под музыку — бессознательно).
- **Иерархия интроспекции** (цитата): мудрый сводит indriyas → citta → aham → mahat → jiivátmá → Supreme Consciousness.
- **Память (smrti)**: Anubhútaviśayásampramośah smrtih — «воспроизведение уже воспринятого». Механизм: образ слона запечатлён → при похожем животном → сравнение → «это слон». Память = способность воссоздать вибрацию-копию.
- **Dhruvásmrti**: память устойчивая, безошибочная, спонтанная — обязательное условие samádhi/блаженства.
- **Две тенденции ума**: приобретение и жертвенность. Эволюция усиливает жертвенность: хочется разделить удовольствие с другими (хозяин угощает гостя rasagollá и мысленно переживает его удовольствие).

## Key Concepts

- **indriya** — ворота органов чувств.
- **tanmátra** — вибрации чувств (звук, прикосновение, форма, вкус, запах).
- **Отпечаток (impression)** — след вибрации в мозгу/уме.
- **Двойное удовольствие** — от еды + от воспоминания о еде (пример сладкоежек и хозяев).
- **Ра́га ásoyárii** — пример узнавания через сравнение вибраций.
- **citta / aham / mahat / jiivátmá** — уровни психики (объективный ум, эго, «Я есмь», индивидуальная душа).

## Mental Models

- «Познание — двухэтажное: внизу отпечаток, наверху вибрация ума».
- «Память — не архив, а способность заново создать вибрацию».
- «Зрелость ума = рост жертвенности над приобретением».

## Anti-patterns

- **Смешение психической и мозговой болезни** (развито в Ch 4).
- **Считать знание чисто абстрактным** — основная масса процесса материальна.

## Worked Example

*Сравнение вибраций.* Три кислых продукта дают три разных отпечатка → три вибрации ума. Съев вторую сливу, ум сравнивает вибрации и различает степень кислинки. Узнавание ра́ги ásoyárii: музыкальная вибрация ударила в барабанную перепонку → через ушные нервы → отпечаток в мозге → при повторном звучании ум «танцует» на той же волне и заключает: «это ásoyárii». Материальное → абстрактное.

## Key Takeaways

1. Знание = материальное + абстрактное, «счастливое смешение».
2. Материальная часть процесса доминирует по объёму.
3. Smrti = воспроизведение вибрации; dhruvásmrti — спонтанное, для samádhi.
4. Две тенденции ума: приобретение и жертвенность.
5. Рифмованная вибрация «сводит» ум вниз к ногам — физическое проявление ума.
