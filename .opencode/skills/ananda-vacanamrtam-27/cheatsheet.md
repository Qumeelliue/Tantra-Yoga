# Читшит: правила решений

## Svadharma и dharma

| Ситуация | Правило |
|----------|---------|
| Что такое dharma человека | Свойство (guńadharma), а не религия: стремление к Parama Puruśa |
| Еда/выживание стали главным | Это pashu dharma (paradharma) → падение |
| Лучше умереть по svadharma или жить по paradharma | Svadharme nidhanaḿ shreyah (лучше умереть человеком) |
| Человек боится «я слишком грешен» | Ничье будущее не запечатано: mokśa возможна для каждого |

## Приоритеты жизни

| Ситуация | Правило |
|----------|---------|
| Средства для са̄дханы (еда, одежда, кров) | Необходимы, но вторичны |
| Стиль еды/смеха/омовения | Упадхармы (вторичные свойства) |
| Главная вр̣тти | Mámekaḿ sharańaḿ vraja — прибежище в Нём одном |

## Социальный сдвиг

| Ситуация | Правило |
|----------|---------|
| Общество замедлилось | Нужен «большой молот» — сильный толчок, не малый |
| Кто наносит удар | Садвипра (духовный революционер) |
| Садвипры сами застряли | Нисходит Táraka Brahma (Parama Puruśa) |
| Сильное общество | Много са̄дханы + сплочённость + hariparimańd́ala |

## Майя и прибежище

| Ситуация | Правило |
|----------|---------|
| Майя кажется неодолимой | Это Его собственная Майя — под Его контролем |
| Кто пересекает мир Майи | Mámeva ye prapadyante (прибегнувшие к Нему) |
| Бремя преданного | Несёт Сам Господь |
| Обещание Господа | Ahaḿ tváḿ sarvapápebhyo mokśayiśyámi — «Я спасу» |
