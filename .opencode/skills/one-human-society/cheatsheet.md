# Читшит — правила решений по Саркару (One Human Society)

## Единство человечества

| Ситуация | Правило |
|---|---|
| Оценить расовую/этническую теорию | Все расы от одного корня; различия — продукт среды; инстинкты универсальны |
| Построить справедливое общество | Поощрять стороны единства, обескураживать стороны разъединения |
| Религиозный/культурный конфликт | Дхарма рациональна и едина; религия — чувство+ритуал+традиция, часто на страхе |
| Различия (еда, одежда, язык) | Не уничтожать силой — устраняются естественным слиянием |
| Подавление языка | Никогда: все языки равны; подавление порождает бунт |

## Социальная психология (единство/безопасность/мир)

| Ситуация | Правило |
|---|---|
| Обеспечить единство | Общий идеал + бескастовость + коллективные функции + отказ от смертной казни |
| Обеспечить безопасность | Нет несправедливости (эконом./половой/расовой) + дисциплина |
| Наказать провинившегося | Коррекционно, без клейма; иждивенцев не наказывать |
| Конфликт «закон vs разум» | Сначала послушание, потом аргументированное изменение закона |
| Обеспечить мир | Духовные практики (постоянное освобождение) + борьба с суевериями |
| Суеверия в обществе | Убирать наукой и гуманизмом, не силой («удар по чувству укрепит его») |

## Космическое Братство и PROUT

| Ситуация | Правило |
|---|---|
| Глобальная интеграция | Четыре фундамента: общая философия, конституция, уголовный кодекс, минимум жизненно необходимого |
| Индивидуальная свобода | Духовная/ментальная — безгранична; физическая — ограничена, если вредит другим |
| Распределение благ | Минимум каждому + покупательная способность + вознаграждения таланту со сжатием разрыва |
| Экономика | Проверяй по 5 принципам PROUT (утилизация, распределение, настройка, прогрессивность) |
| Накопление богатства | Не допускается без согласия коллектива |

## Произвольные деления

| Ситуация | Правило |
|---|---|
| Национальность/границы | «Меняется за ночь» → несостоятельна; паспорта/визы подлежат отмене |
| Деление на богатых/бедных | Обратимо; фундаментальная болезнь — эксплуатация, не сам факт богатства |
| Идеологические различия | Сосуществовать; вредные идеологии «сопротивляться железной рукой» |
| Язык как основа деления | Различаются только стадии 5–6 (Vaekharii, Shrutigocará); не основание |
| Каста/варна | «Чистый обман» в интересах групп; шудры — из святых стоп Парама Пуруши |

## Быстрые сигналы («tells»)

- Речь о «чистой крови» расы — ложь по этнологии; все смешаны.
- «Национальная гордость» без ущерба для других — допустима; с лишением прав — сепаратизм.
- Религия обещает рай и страшит адом — страх-комплекс, не духовность.
- Гарантия минимума без условий — вырастит лень; добавь условия и сжатие разрыва.
- Паспорт/виза как основа статуса — «мелкий национализм», подлежит отмене.
