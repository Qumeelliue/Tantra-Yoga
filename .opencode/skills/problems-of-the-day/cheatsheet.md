# Читшит — правила решений по Саркару (Problems of the Day)

## Собственность и экономика

| Ситуация | Правило |
|---|---|
| Кто владелец всего? | Брахман; люди — пользователи общего достояния (Dáyabhága) |
| Оценить систему | Каждому минимум для здорового тела и ясного ума |
| Национализация vs социализация | Социализация (народ) — да; национализация и выкуп — нет |
| Управление предприятием | Кооператив — норма; исключения: мелкое — частник, крупное+сложное — ближайшая власть |

## Борьба с эксплуатацией

| Ситуация | Правило |
|---|---|
| Выбор метода | Убеждение → давление обстоятельств → сила; параллельно — духовное образование |
| «Ненасилие = без силы» | Заблуждение: пассивность не решает проблем |
| Простить обидчика | Прощение — только в личной жизни; за группу — нельзя |

## Мир и справедливость

| Ситуация | Правило |
|---|---|
| «Мир! Мир!» без борьбы | Пусто; мир — борьба с факторами беспорядка |
| Тишина в стране | Sentient peace = сильное правосудие (хорошо); static peace = страх (плохо) |
| Тирания группы/страны | Добрые обязаны сопротивляться силой (sentient peace) |
| Проституция, приданое | Корень — экономическая несамостоятельность женщин; лечить независимостью |

## Универсализм и миропорядок

| Ситуация | Правило |
|---|---|
| Национализм/коммунализм/кастизм | Дефект одного типа (ism); шире круг — меньше зло, тип дефектен |
| Альтернатива ism | Универсализм — не ism; «все свои» |
| Мировое правительство | Двухпалатное, начни с закон-фрейминга; странам — только администрация |
| Мировой язык | Самый распространённый язык века (сейчас английский, не вечно) |
| Культуры | Одна культура; синтез через смешение, не нивелировку |

## Политика, демократия, образование

| Ситуация | Правило |
|---|---|
| Партийная политика | Опаснее микробов; честным — в стороне |
| Объединение честных | Доски социального служения; не для выборов |
| Голосование | За достойного человека, не за партийный «фонарный столб» |
| Кандидат <50% голосов | Повторное голосование за/против |
| Кандидат нарушил декларацию | Доказано в суде → аннулирование мандата |
| Кто голосует | Образованные, с сознанием; необразованная демократия — фарс |
| Образование | Финансирует государство, программы — университеты; бесплатное; без партий и ism |

## Социальный цикл и садвипры

| Ситуация | Правило |
|---|---|
| Порядок веков | Shúdra → Kśatriya → Vipra → Vaeshya → (shúdra-революция) → новый Kśatriya |
| Кто лидер общества | Садвипры (Yama-Niyama + Cosmic ideation), а не классы |
| Класс у власти | Эксплуатирует не-своих; садвипры не дают абсолютной власти |

## Быстрые сигналы («tells»)

- «Мир! Мир!» от угнетателя — уловка, не sentient peace.
- «Ненасилие» как отказ от силы при тирании — прикрытие слабости.
- Кандидат без оппонента — подозревай подкуп соперников.
- Голод в одной стране при изобилии в другой — «капитализм» в масштабе мира.
- Лозунг «наша земля, наша нация» — ism; расширяй до «все свои».
