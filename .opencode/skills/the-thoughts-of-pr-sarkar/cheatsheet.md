# Читшит — правила решений по Саркару (The Thoughts)

## Духовное направление

| Ситуация | Правило |
|---|---|
| Понять цель жизни | Движение к совершенству = dharma; остановка = adharma; покой — грех |
| Кого слушать в духовности | Практического демонстратора (йога/гуру), не книги/кодексы/интеллектуалов |
| Хочешь оккультных сил | Иллюзия: «Хочу Тебя, не Твои силы»; силы отвлекают от Supreme |
| Комплекс превосходства/неполноценности | Оба — психическая болезнь; лечи поведением |
| Хочешь мира | Конверсия себя в бесконечное объективное, не «проповеди мира» |
| Действуешь в миру | Космическая идеация (Madhuvidya): служи проявлению Supreme в каждом объекте |

## Ментальное и этическое

| Ситуация | Правило |
|---|---|
| Оценить лидера/человека | A/B/C: совпадение мысли-слова-дела; C — опасен |
| Возникло препятствие | Борьба = суть жизни; думай о цели, не о камнях |
| «Попробую» | «I will», не «I will try» — вопрос быть, не пытаться |
| Помочь человеку | По потребностям, понемногу; сверх — сделаешь инвалидом |
| Служение vs бизнес | Обмен = бизнес; дать без взятия = служение |
| Медитация на «я грешник» | Запрет: ум становится объектом; медитируй «я дитя Отца» |

## Социальная экономика

| Ситуация | Правило |
|---|---|
| Собственность | Природа не назначала никому; избыток одного = голод других |
| Деньги | Ценны в использовании; залежи = ответственность за голодных |
| Гарантировать блага | Минимумы (пища, одежда, медицина, образование, жильё + покупательная способность), но не без труда |
| Разнообразие талантов | Спец-вознаграждения + постоянное сокращение разрыва с минимумами |
| Свобода индивида | Психическая/духовная — безгранична; физическая — ограничена |

## Эксплуатация и справедливость

| Ситуация | Правило |
|---|---|
| Эксплуатация невидимая | Психо-экономическая: через догму/комплексы; опаснее экономической |
| Доминирующий класс | Эксплуатирует → садвипры не дают шанса |
| Преступник | Больной, не враг: лечить, не казнить; исправлять систему (голод), не только вора |
| Наказание | Коррекция, не кара; 4 стадии: сладкие слова → жёсткие → объявить → меры |
| Три причины греха | Нехватка ресурсов; неиспользование избытка; стагнация |

## Демократия и лидерство

| Ситуация | Правило |
|---|---|
| Успешная демократия | Публичное образование + мораль ≥51% населения (⚠) |
| Голоса продаются | Нет морали → нет демократии; лидеры из безнравственных |
| Лидер без самоподготовки | «Игра в лидера» ведёт к катастрофе общества |
| Моральная сила | Приходит извне правительства; любое правительство без неё — тирания |
| Садвипра | Мораль + устремление к Supreme + борьба; не допускать эксплуатации |

## Культура и наука

| Ситуация | Правило |
|---|---|
| Искусство | «Искусство для служения и блаженства», не «для искусства» |
| Художник | Духовный искатель + страж общества + «вестник масс» |
| Механизация в капитализме | Безработица; в коллективизме — отдых (удвоение продуктивности = вдвое меньше часов) |
| Город vs деревня | Не лозунг «назад в деревню»; нужны работа, энергия, механизированные промыслы |
| Образование | Знание прав + применение = наука; ведёт к освобождению; «изм» — только универсализм |

## Человеческие ценности

| Ситуация | Правило |
|---|---|
| Ценность человека | Человеческая ценность предшествует социальной; право рождения каждого на прогресс |
| Достоинство деньгами | Табу: «богатые купили мозги» — противостоять |
| Власть | Только моральным (Yama-Niyama); некомпетентный у власти ведёт общество к гибели |
| Кризис цивилизации | Не пессимизм: «ты — факелоносец»; миссия — спасти человечество |
| Вселенский дух | Отсутствие универсализма — корень всех зол; объединяйся против угнетателей |

## Быстрые сигналы («tells»)

- Видишь «привилегированную касту/класс» с внутренней иерархией — вероятна психо-эксплуатация через догму.
- «Только голые проповеди/речи о мире» без действий — нет борьбы с причинами.
- Лидер с «партийным штампом важнее способностей» — политикан, не садвипра.
- Образование без «что я есть и что делать» — грамотность, не образование.
- Тюрьмы без лечения и гуманной среды — «бессмысленный фарс».
- Искусство без трансцендентного стержня — не искусство по Саркару.
- Молитва-просьба («дай мне») — неуважение к закону; истинная — контемпляция.
- Специальные вознаграждения, растущие без контроля разрыва, — путь к олигархии.
