# Читшит — правила решений по Саркару (Prout 5)

## Социальный цикл и власть

| Ситуация | Правило |
|---|---|
| Определить, кто у власти | Какой класс/ресурс незаменим в эпоху? (сила → интеллект → деньги → численность) |
| Класс доминирует | Он эксплуатирует остальных; смена доминанта проблему не решает |
| Цикл «застрял» | Цикл неостановим (стагнация = смерть); ускоряй движение, не жди |
| Средство против доминанта | Kshatriya → физическая сила; vipra → интеллектуальная революция; vaeshya → победа на выборах |

## Мораль и опекуны

| Ситуация | Правило |
|---|---|
| Кто может быть опекуном общества | Только садвипры: Yama/Niyama + свобода от эго + Brahma как цель |
| Проверить лидера | По поведению/служению/силе характера, не по речам |
| Кто даст моральную силу | Не демократическое правительство; политически образованная группа (средний класс, студенты) |
| Принцип против коррупции | «Защищай добродетельных; наказывай злых»; если persuasion не помог — сила |

## Нация и единство

| Ситуация | Правило |
|---|---|
| Есть ли нация | Есть ли общее чувство (sentiment)? Факторы (язык/раса/религия) несущественны |
| Объединить разнородных | Анти-эксплуатационная (экономическая) борьба, не политическая за посты |
| Удержать единство надолго | Анти-чувство умрёт с врагом — сразу якорь: духовное наследие + Космическая идеология |
| Провинции/регионы | По экономике, не по языку; национальный язык не навязывать |

## Экономика

| Ситуация | Правило |
|---|---|
| Чьё производство | Мелкое — индивидам; ключевое — местному правительству; среднее — кооперативам |
| Кооперативы против частников | Защитная броня (налоговые льготы), снимать постепенно, только для жизненно важного |
| Рационализация и безработица | В коллективной структуре сокращают часы, не людей |
| Мотивация рабочих | Сдельная работа + бонусы; право управления рабочих |
| Социализм в демократии | Невозможен: «социальные образцы» — обман (show-boys) |

## Распределение

| Ситуация | Правило |
|---|---|
| Минимальные потребности | Гарантировать всем (еда, одежда, жильё, медицина, образование) + покупательная способность |
| Стимулы талантам | Специальные удобства (special amenities); разрыв с минимумом сокращать бесконечно, до нуля не сойдёт |
| Товар есть, люди голодны | Проблема — покупательная способность (пример Shayesta Khan) |
| Свобода | Полная в психическом/духовном; ограничена коллективным интересом в физическом |

## Борьба и ненасилие

| Ситуация | Правило |
|---|---|
| Ahiḿsá vs non-violence | Ahiḿsá = не вредить; ненасилие = не применять силу (противно дхарме) |
| Крики о мире | Мир — результат борьбы; «мода на мир» — политика, не принцип |
| Прощение | Индивидуальный атрибут; прощать вред коллективу — социальное преступление |
| Убеждение vs сила | Persuasion — первая ступень; без силы против тигра не работает |

## Быстрые сигналы («tells»)

- Провинции делят по языку — ожидай борьбы за районы и комплексы меньшинств.
- Лидеры борются за министерские посты, а не за экономику — готовится раскол.
- Движение «за мир» без борьбы с эксплуатацией — защищает капиталистов.
- Поклонение лидеру (махатме) вместо идеологии — идея умрёт.
- Критикуешь капитализм без конструктивного идеала — помогаешь капиталистам.
- Студентов зовут в партию — их энергию эксплуатируют; нужен беспартийный студент-лидер.
- Проповедь «доверенности» капиталистов народу — психологический дефект гандизма.
