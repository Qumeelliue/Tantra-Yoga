# Паттерны — Ánanda Vacanámrtam Part 8

## Диагностика исключений (vyatikrama)
**Когда использовать:** при поиске новаторов или оценке отклонений.
**Как:** спроси «что здесь исключение из правила?». Исключения — preplanned двигатели эволюции (виды, языки, религии). Цени тех, кого зовут «безумцами», но кто строит новое; будь исключением с идеологией.
**Компромиссы:** не всякое отклонение ценно — нужно соответствие идеологии и конструктивность.

## Ментальная арифметика vrttis
**Когда использовать:** при анализе сложности психики/организации.
**Как:** 50 vrttis × 2 (внутр./внеш.) × 10 направлений = 1000 (sahasrára). Число vrttis растёт с усложнением общества (хитрость → виды хитрости). Судьба/оценки относительны (время/место/лицо).
**Компромиссы:** схема упрощает; конкретный набор vrttis у автора не исчерпывающе перечислен.

## Контроль экстернализации мыслей
**Когда использовать:** при самоконтроле, управлении эмоциями.
**Как:** мысли — сев действий; внешняя проекция — «utkepan» (как выброс масла). Контролируй момент, когда внутреннее становится внешним; используй эмоции (даже гнев) контролируемо для блага, а не импульсивно.
**Компромиссы:** подавление внешнего без работы с внутренним — путь к взрыву (дамба); направь поток.

## Проверка благополучия (hita/kalyáńa/kśema)
**Когда использовать:** при оценке действий, политик, практик.
**Как:** спроси: ведёт ли действие к физ.+псих.+дух. благополучию (hita)? Только псих.+дух. (kalyáńa)? Только дух. (kśema)? Действие, деградирующее любой уровень, — pápa.
**Компромиссы:** трёхуровневая схема требует различать уровни; не всегда просто применить на практике.

## Диагностика pápa по компенсируемости
**Когда использовать:** при этической оценке проступков.
**Как:** pátaka (компенсируемо — вернуть + проценты) < atipátaka (некомпенсируемо — отрезал пальцы) < mahapátaka (recurring влияние — фальсификация; Равана). Также: pratyaváya — не сделать добро (хуже по логикам). Puńya: прямое + косвенное (recurring).
**Компромиссы:** для mahapátaka нет атонения — только жизнь ради благой цели; не смешивать с осуждением человека (см. ch08).

## Правило Раваны (тайминг действий)
**Когда использовать:** при принятии решений, приоритизации.
**Как:** добро делай немедленно (Shubhasya shiighram); зло откладывай (ashubhasya kálaharańam) — ум может перемениться. Проверь: откладываю ли я добро («завтра»)? Тогда это порок. Откладываю ли зло? Тогда добродетель.
**Компромиссы:** требует честной классификации «добро/зло»; избегай самообмана.

## Работа со страхом
**Когда использовать:** при парализующем страхе.
**Как:** страх растёт при уступке; проверь шагом вперёд («удар по призраку» — куст/стул). Различай положительную/отрицательную галлюцинацию; пять состояний ума (kśipta…nirodha). Shelter в Parama Puruśa — корень.
**Компромиссы:** реальные угрозы требуют осторожности, а не только «шага вперёд».

## Шесть привычек — аудит
**Когда использовать:** при личном/командном развитии.
**Как:** проверь сон (избыток), вялость, страх, гнев, лень (3 уровня; духовная — худшая), откладывание. Примени Равана-тайминг к последней.
**Компромиссы:** шесть пунктов — целостная система; аудит по одному пункту за раз.

## Пять состояний ума
**Когда использовать:** при оценке ментального состояния.
**Как:** kśipta (почти безумный) → múrha (глупый) → vikśipta (рассеянный) → ekágra (почти сосредоточенный) → nirodha (однонаправленный). Цель — nirodha через dhyána (приостановка vrttis + направление).
**Компромиссы:** состояния не всегда различимы на практике; используй как направление.

## Медитация как канал, не дамба
**Когда использовать:** при обучении сосредоточению.
**Как:** приостановка vrttis опасна без направления (дамба лопнет). Dhyána = приостановка + направление к Supreme. Kiirtana — путь занятости всех органов божественным (сладкий звук mrdauṋga).
**Компромиссы:** нужна практика; абстрактная «приостановка» вредит без канала.

## Слияние через kośas и diikśá
**Когда использовать:** при объяснении очищения ума.
**Как:** diikśá = diipajiñána + pápakśayam; mantraghat будит kulakuńd́alinii; ум поднимается через kośas (kama-maya…hiranyamaya); átman отделяется как масло. Hari крадёт грехи, когда бхакт не отдаёт.
**Компромиссы:** эзотерика; применяй на уровне принципов, не догмы.

## Четыре юги как состояния ума
**Когда использовать:** при оценке активности/инерции.
**Как:** лежит = Kali; проснулся = Dvápara; встал = Tretá; движется = Satya Yuga. Судьба следует за движением. Move on, не живи прошлым.
**Компромиссы:** метафора мотивации; не заменяет анализ объективных условий.
