# Глоссарий — Ánanda Vacanámrtam Part 8

**Abhidhyána** — отозвание 10 органов и ума от объектов к Parama Puruśa.

**Ahorátra** — сутки от восхода до восхода (dinamána + rátrimána).

**Ajapá siddhi / ajapá gáyattrii** — спонтанная мантра, синхронизированная с дыханием (идёт и во сне).

**Akśa málá** — алфавит из 50 акустических корней.

**Ananyabhák** — неделённое внимание (на Parama Puruśa).

**Apaváda** — исключение (хинди); в бенгали — «порицание».

**Apratyakśa puńya** — косвенная добродетель (recurring: посадка баньяна).

**Atipátaka** — некомпенсируемый грех (отрезал пальцы).

**Biija mantra / акустический корень** — звук каждого действия/существования.

**Bhárata** — кормящий и расширяющий (bhr+ta); обращение к царю-представителю.

**Dharma (dhrti)** — «держатель»; характеристика, удерживающая проявления.

**Dhii** — благожелательный интеллект (иначе демоничен).

**Dhyána** — приостановка vrttis и направление ума к Supreme.

**Diirghasútratá** — откладывание; откладывать добро = порок, зло = добродетель.

**Diipajiñána / pápakśayam** — свет знания / исчерпание са́мска́ров (части diikśá).

**Durjana** — чей контакт деградирует (относительное понятие).

**Ekágra / nirodha** — состояния почти сосредоточенного / однонаправленного ума.

**Ekameva suhrddharma** — единственный верный друг — dharma.

**Ganábharana** — «украшенный преданными» (Sadáshiva).

**Gáuṋgádhara** — Shiva, контролирующий id́á nád́ii / саhasrára.

**Gunáhiina** — вне всех качеств (guńa = вид bondage).

**Hara (ha+ra)** — отзыватель/пересоздатель мира (эфир + энергия).

**Hari** — крадущий грехи (Harati pápáni); очищающий ум через kośas.

**Hita / kalyáńa / kśema** — три уровня благополучия (физ.+псих.+дух. / псих.+дух. / дух.).

**Indriyanigraha** — контроль 10 органов умом/а́tman.

**Iśt́a niśt́á** — преданность цели; «что бы ни делал — порадовать Parama Puruśa».

**Kośas** — слои ума: kamamaya, manomaya, atimanasa, vijiñánamaya, hiranyamaya.

**Kśipta / múrha / vikśipta** — состояния ума (безумное/глупое/рассеянное).

**Mahásambhúti / Táraka Brahma / mahasadvipra** — инициатор великих изменений.

**Mahapátaka** — recurring грех (фальсификация; Равана).

**Mánava dharma (Bhágavata dharma)** — dharma человека: vistára, rasa, sevá.

**Mantraghat / mantra caetanya** — удар мантры в kulakuńd́alinii / движение после.

**Mahimnabodh** — чувство малости перед величием Parama Puruśa.

**Move on** — принцип постоянного движения вперёд.

**Pápa / pátaka / pratyaváya** — грех / действие-зло / не-сделанное добро.

**Prapatti / prapattiváda** — тотальная сдача Supreme (основа bhakti).

**Pratyakśa puńya** — прямая добродетель (накормить голодного).

**Puńya** — действие к благополучию (физ./псих./дух.).

**Rasa** — поток; rasasamudra — слияние с космическим потоком.

**Sadhvipra / sadhvi** — лидер адаптации к изменениям.

**Satsauṋga / asatsauṋga** — общество добродетельных / дурных.

**Sentient anger** — показ гнева против зла (допустим) vs static anger (инстинкт, опасен).

**Shánti / prashánti / átyántikii shánti** — мир / постоянное спокойствие.

**Sharańágati** — 100% зависимость от Parama Puruśa (финальное достижение).

**Shamana / Yama** — контролёр (внешний контроль; Бог смерти).

**Silákantha** — общий предок рыб.

**Sudurácárii** — «грешник из грешников» (Гита).

**Tandra** — вялость/тупость (контракция импульса).

**Tanu / shariira** — тело до 39 (расширяющееся) / после (изнашивающееся).

**Utkepan** — внешняя проекция внутренней мысли.

**Vistára** — расширение (тела/ума/духа).

**Viśa / amrta** — трудно подавляемые чувства (гневное несогласие / глубокая любовь).

**Vrtti** — психическое побуждение; 50 у человека.

**Vyatikrama** — исключение, отход от обычного.

**Yadá yadá** — «в подходящий момент» (при деградации dharma).

**«Shubhasya shiighram ashubhasya kálaharańam»** — добро немедленно, зло отложить.
