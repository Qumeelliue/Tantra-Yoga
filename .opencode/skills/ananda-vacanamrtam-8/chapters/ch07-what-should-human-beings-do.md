# Chapter 7: What Should Human Beings Do?

*Дискурс 160, 8 февраля 1979, Мератх.*

## Core Idea

Четыре заповеди: избегай дурных людей, общайся с садху, делай добро день и ночь, помни о непостоянстве. Добро (puńya) = делать добро другим + бороться против зла.

## Frameworks Introduced

- **Три уровня благополучия**: hita (физ.+псих.+дух.), kalyáńa (псих.+дух.), kśema (дух.). Durjana — тот, чьё присутствие деградирует других (отклонение от самосовершенствования).
- **Durjana относителен**: вор не durjana для честного (тот нейтрализует), но для обычного человека — да. Сильные псих./дух. не поддаются; слабых злой легко увлекает. Трансформировать злого может только тот, у кого большая псих. сила — иди с 5–10 друзьями (коллективная сила).
- **Sadhu**: чьё общество ведёт к hita; `Játascha eva jagati jantavah sádhu jiivitáh` — только честные от рождения; прочие — «ослы в человеческой форме». Satsauṋga (общество добродетельных) = mukti; asatsauṋga = bondage.
- **Kuru puńyam ahorátram**: добро вокруг часов; virtue = делать добро другим (`Paro'pakárah puńyáya pápáya parapiiŕańam` — делать добро — благочестие, вредить — грех). Не только пассивное добро: добрые должны и бороться со злом (иначе злодеи вернут общество на 2 шага назад); активное противостояние — тоже puńya.
- **Smara nityamanityatám**: помни о непостоянстве; жизнь коротка; делай добрые дела. Tulsi: «когда пришёл — мир смеялся, ты плакал; живи так, чтобы уходя ты смеялся, а мир плакал».

## Key Concepts

- **Durjana / sadhu** — деградирующий / ведущий к hita.
- **Hita / kalyáńa / kśema** — три уровня благополучия.
- **Satsauṋga / asatsauṋga** — общество добродетельных / дурных.
- **Paropakára / parapiiŕańa** — добро другим / вред другим (Vyása).

## Mental Models

- «Избегай дурных; общайся с садху».
- «Добро = польза другим + борьба против зла».
- «Не ходи к злому один — бери 5–10 друзей».
- «Живи так, чтобы уйти смеясь».

## Anti-patterns

- **Пассивная доброта без борьбы со злом** — не двигает прогресс.
- **Прямая конфронтация с лицемером в одиночку** — временное безразличие лучше.
- **Игнорировать непостоянство жизни** — «завтра» может не быть.

## Worked Example

Пример-лицемер: человек громко говорит об улучшении экономики бедных, но ничего не делает. Не конфронтируй напрямую — будь временно безразличен; позже с 10–20 людьми веди его на правильный путь (коллективная сила).

## Key Takeaways

1. Избегай durjana (деградирующих), общайся с sadhu.
2. Durjana относителен: сильный нейтрализует, слабый увлекается.
3. Добро = польза другим + борьба со злом (оба — puńya).
4. Трансформируй злого коллективно, не в одиночку.
5. Помни о непостоянстве; живи так, чтобы уйти смеясь.
