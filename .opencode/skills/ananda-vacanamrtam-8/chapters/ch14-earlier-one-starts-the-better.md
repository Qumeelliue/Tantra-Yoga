# Chapter 14: The Earlier One Starts Dharma Sádhaná the Better

*Дискурс 167, 21 февраля 1979, Бопал.*

## Core Idea

Стремление к счастью — источник dharma. Конечное счастье непостоянно; только бесконечный объект даёт вечное. Начинай sádhaná с 5–6 лет (пример Dhruva); только dharma сопровождает после смерти; для всех варн обязательно.

## Frameworks Introduced

- **Счастье → dharma**: `Sukhaḿ váiṋchati sarvo hi tacca dharma samudbhútah`. Животное счастливо телом; человек — интеллект, ищет вечное. Rasagolla-удовольствие конечно («Yah ágacchati sah gacchati» — пришедшее уходит). Только бесконечный объект даёт бесконечное счастье.
- **Brahmavidya = vijiñána**: интуитивное знание безгранично; книжное (даже 2 млрд книг) ограничено; прочее — avidyá.
- **Раннее начало**: `Durlabhaḿ mánuśaḿ janma tadapyadhruamurthadam` — человеческое тело редко; смерть может быть в 25; sádhaná не зависит от возраста; начинай в 5–6. Dhruva (5 лет): «некоторые умирают юными; человеческое тело редко; почему ждать?». Животные не чувствуют необходимости духовности; люди — да.
- **Ekameva suhrddharma**: единственный верный друг — dharma; богатство не уйдёт с тобой, dharma — да.
- **Для всех варн**: интеллектуалы — поймут; ksatriya (красный) — физическая сила угасает; vaeshya — богатство не вечно; shudra — тело может не вернуться (козёл/собака/вол). «Tasmáddharmah sadákárya sarvavarńae prayatnatah».

## Key Concepts

- **Durlabham mánuśam janma** — человеческое тело редко.
- **Ekameva suhrddharma** — только dharma — верный друг.
- **Brahmavidya / vijiñána vs avidyá** — безграничное vs книжное знание.
- **Dhruva-принцип** — начинай рано, не жди старости.

## Mental Models

- «Конечное счастье конечно; бесконечное — от бесконечного».
- «Начинай sádhaná рано: жизнь не гарантирует старости».
- «Человеческое тело — редкий шанс; не трать его».
- «Dharma — единственный спутник после смерти».

## Anti-patterns

- **Откладывать sádhaná до старости** — можно умереть в 25.
- **Полагаться на богатство** — не уйдёт с тобой.
- **Считать sádhaná уделом только интеллектуалов** — обязательна всем.

## Worked Example

Пример-Dhruva: мальчик 5 лет медитирует; старшие боятся его прогресса; Narada советует подождать. Dhruva: «Некоторые умирают молодыми; человеческое тело редко; животные не знают необходимости духовности, а я знаю — зачем ждать?» Narada был неправ.

## Key Takeaways

1. Счастье — мотиватор dharma; конечное счастье обманчиво.
2. Только бесконечный объект даёт вечное счастье.
3. Brahmavidya безгранична; книжное знание ограничено.
4. Начинай sádhaná с детства (5–6 лет); жизнь не гарантирована.
5. Dharmа — единственный друг после смерти.
6. Sádhaná обязательна для всех варн.
