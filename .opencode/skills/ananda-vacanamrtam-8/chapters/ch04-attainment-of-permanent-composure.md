# Chapter 4: The Attainment of Permanent Composure

*Дискурс 157, 13 января 1979, Калькутта.*

## Core Idea

Постоянное спокойствие (átyántikii shánti) достижимо только познанием Shiva/Parama Puruśa — иного пути нет. Разбираются история Vedas, происхождение семи музыкальных нот, смысл shánti/shamana и этимология «know» из «jiñá»/«keno».

## Frameworks Introduced

- **История Vedas**: «vid» = знать (не «jiñá»); Rk Veda начат ~15000 лет назад, сочинялся 10000 лет (до ~5000); затем Yajurveda, Atharvaveda; музыкальные части собраны в Sáma Veda («sáma» = песня). ⚠ датировки из дискурса, к калибровке.
- **Музыка из звуков животных**: 7 нот от 7 животных: peacock (śaŕaja), ox (rśabha), goat (gándhára), horse (madhyama), cuckoo (paiṋcama), ass (dhaevata), elephant (niśáda) → śa-re-gá-má-pá-dhá-ni. Семь метров Vedic poetry (gáyatri, anuśt́up, tiśt́up, brhatii, jagatii, paunkti, uśńiik — самый трудный).
- **Семь вибрационных звуков**: omn, hum, phat, vaośat́, váśat, sváha, namah — произносить перед соответствующим действием. Namah = от «nam» (сдаюсь); идеация важнее звука.
- **Шестнадцать звуков голосовых связок**: 7 акустических + 7 нот + **viśa** (гневное несогласие) + **amrta** (глубокая привязанность) — самые трудные для подавления. Происхождение звука — не в голосовой щели, а в múládhára: стадии слова (para → pashyantii → dyotamána → vaekharii → shrutigocara).
- **Shánti / Shamana**: sham+ktin = shánti (мир); sham+anat = shamana. Shamana (Яма, God of Death) — контролирует всех, регулирует популяции (аннигилирует грешников при перенаселении). «Samanam karoti yah sah shánta» — установивший контроль — shánta. Постоянное спокойствие = prashánti / átyántikii shánti (не теряется). Война даёт временный покой (jaya), не постоянный (vijaya). Путь — познать Shiva: `Jiṋátvá Shivaḿ shántimatyantáti`.
- **Shiva**: «well-being», «consciousness» (Shiva shaktyatmakam Brahma), «мёртвое тело». В шлоке — Parama Puruśa/Supreme Consciousness.
- **Этимология know**: jiñá → keno (Old Latin) → know (Modern English); буква «k» не произносится, но сохранена.

## Key Concepts

- **Prashánti / átyántikii shánti** — постоянное, не теряемое спокойствие.
- **Viśa / amrta** — два трудно подавляемых чувства (гневное несогласие/глубокая любовь).
- **Стадии слова** — para → pashyantii → dyotamána → vaekharii → shrutigocara.
- **Shamana (Yama)** — контролёр, аннигилирующий грешников.

## Mental Models

- «Постоянное спокойствие — не отсутствие проблем, а познание Shiva».
- «Временная победа (jaya) ≠ постоянная (vijaya)».
- «Звук рождается в múládhára, не в горле».

## Anti-patterns

- **Довольствоваться временным спокойствием** — война даёт jaya, не vijaya.
- **Считать интонацию случайной** — viśa/amrta выдадут чувство даже у актёра.

## Worked Example

Пример-интонация: «Не буду есть сегодня» (болен) vs «Не буду есть сегодня!» (зол) — разные тоны; viśa и amrta трудно скрыть даже актёрам. Показывает: звук несёт ментальное состояние.

## Key Takeaways

1. Постоянное спокойствие — через познание Shiva; иного пути нет.
2. Vedas: Rk ~15000 лет назад; Sáma = сборник музыкальных частей.
3. 7 нот из звуков животных (śa-re-gá-má-pá-dhá-ni).
4. Слово рождается в múládhára; стадии — от para к shrutigocara.
5. Viśa/amrta трудно скрыть — звук выдает чувство.
6. Jaya ≠ vijaya: только постоянная победа даёт prashánti.
