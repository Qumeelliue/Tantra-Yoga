# Chapter 5: Bad Habits Which Should Be Given Up

*Дискурс 158, 16 января 1979, Улуберия.*

## Core Idea

Шесть вредных привычек (`Nidrá-tandrá-bhayaḿ-krodhah-álasyam-diirghasútratá`) должны быть отброшены ищущими благополучия. Каждая — порок и болезнь; преодолевшего их не остановит ничто.

## Frameworks Introduced

- **1. Nidra (сон)**: избыточный сон → потеря ориентации («день/ночь?»), снижение памяти, тупость, отсутствие мужества. Сон — временный «отход для разгона» (армия, бегун); автор спит ~4 часа ночами месяцами ⚠. 80 лет жизни, 40 во сне — мало времени.
- **2. Tandra (вялость/тупость)**: контракция, потеря импульса. Глаза читают, ум на площадке; экзаменационный студент забывает за 2–3 дня. Из-за желёз/болезней/врождённо (врождённая — ранняя смерть в подростках). Лечится психическими упражнениями.
- **3. Bhaya (страх)**: чем больше уступаешь, тем больше (как сон и еда). Пять состояний ума: kśipta (почти безумный), múrha (глупый), vikśipta (рассеянный), ekágra (почти сосредоточенный), nirodha (однонаправленный). Призраки — положительная галлюцинация (психическая проекция); избавляйся отрицательной галлюцинацией. Лекарство: идеация на Parama Puruśa + шаг вперёд («удар по призраку»). Тирана/эксплуататора победить, собрав смелость.
- **4. Krodha (гнев)**: agitation нервных клеток (вспомнил обиду 15-летней давности). Тело дрожит, цвет кожи меняется; теряешь контроль → поражение. Buddha: `Akkodhena jine kodham` — гнев побеждается безгневием; нечестный — честностью; скупой — щедростью (будучи свободным от болезни сам). Пример скупца Soma/Somii.
- **5. Alasya (лень)**: три вида. *Духовная* (худшая): используется 1–2% потенциала, великие ~10% ⚠; игнорирование желания идеации (с 14–15 лет). *Психическая*: кастовость всеми понимается как зло, но не отвергается (отсутствие морального мужества). *Физическая*: руины сообществ, «лежат в постели без еды».
- **6. Diirghasútratá (откладывание)**: откладывать доброе = порок; злое = добродетель. Равана (предсмертный совет Раме): `Shubhasya shiighram ashubhasya kálaharańam` — добро немедленно, зло задержи (мысль может перемениться). Пример: Равана не построил лестницу в рай (откладывал), а похищение Sita сделал мгновенно (не отложил зло).

## Key Concepts

- **Kśipta/múrha/vikśipta/ekágra/nirodha** — пять состояний ума.
- **Положительная/отрицательная галлюцинация** — призрак создаётся/разрушается психической проекцией.
- **Sentient vs static** — (в ch12) показ гнева против зла vs гнев-инстинкт.
- **Равана-правило** — ускорение добра, задержка зла.

## Mental Models

- «Сон — инструмент разгона, не образ жизни».
- «Страх кормит себя сам; шаг вперёд развеивает призрак».
- «Побеждай гнев безгневием; нечестность — честностью».
- «Лень — три уровня; духовная — самая вредная».
- «Добро — немедленно; зло — отложи (ум переменится)».

## Anti-patterns

- **Избыточный сон** — тупость и потеря времени жизни.
- **Вялость** — ум «не здесь» (студент забывает всё за 2–3 дня).
- **Уступать страху** — страх растёт; паралич.
- **Поддаваться гневу** — поражение; дрожь и потеря контроля.
- **Откладывать добрые дела** — «завтра» крадёт жизнь.
- **Откладывать злые дела = задержка** — зло, наоборот, откладывай.

## Worked Example

Пример-Равана: Рама просит совета умирающего Раваны. Тот: добро делай немедленно («я откладывал лестницу в рай — не успел»); зло откладывай («я не отложил похищение Sita — теперь умираю»). Kabir: «Yo kál kare so áj kar... Palme pralay hoyegii» — сделай сегодня/сейчас.

## Key Takeaways

1. Шесть привычек: сон, вялость, страх, гнев, лень, откладывание — пороки.
2. Сон — для разгона, не сверх меры.
3. Страх побеждается шагом вперёд и shelter в Parama Puruśa.
4. Гнев побеждается безгневием (Buddha).
5. Духовная лень — худшая (1–2% потенциала ⚠).
6. Добро — немедленно; зло — отложить (правило Раваны).
