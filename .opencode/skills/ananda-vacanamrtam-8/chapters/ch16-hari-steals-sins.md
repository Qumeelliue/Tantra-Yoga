# Chapter 16: He Who Steals Others' Sins Is Called Hari

*Дискурс 169, 22 февраля 1979 (утро), Бопал.*

## Core Idea

Diikśá = diipajiñána (свет знания) + pápakśayam (исчерпание са́мска́ров). Реакция действий растёт с задержкой («проценты»); diikśá останавливает проценты, а Hari крадёт грехи, потому что бхакты не отдают их добровольно.

## Frameworks Introduced

- **Diikśá**: «dii» (первая буква diipajiñána — свет знания) + «kśa» (первая буква pápakśayam — исчерпание са́мска́ров). Путь во тьме с камнями требует лампы. После diikśá — движение через **mantra caetanya** (понимание смысла мантры) и **mantraghat** (удар заклинания в спящее божество — kulakuńd́alinii). До diikśá прогресс невозможен (нет света).
- **Реакция с процентами**: по естественному закону действие → равная противоположная реакция при неизменных времени/месте/лице. Но факторы почти всегда меняются → реакция больше (интерес). Долг в 1000 рупий: верни сразу — без процентов; через годы — с процентами. Некоторые страдают мгновенно, некоторые через 100 лет, некоторые через 20 жизней.
- **Хари — вор грехов**: «Harati pápáni ityarthe» — крадёт са́мска́ры. Странно (против asteya), но Он вынужден: бхакты отказываются отдать («сладости — да, грехи — нет»), а груз неподъёмен. После кражи — исчерпание са́мска́ров (pápakśayam) → душевный покой, продвижение по жизни. Diikśá — вход в shelter Supreme Father; кража грехов — Его обязанность → «Kuryát Pápakśayaḿ tatah».
- **Равенство всех**: нет людей без грехов; все равны перед Parama Puruśa (па́takii/atipátakii/mahapátakii); грешники — Его дети на коленях. Общество дискриминирует женщин, Он — нет. Сегодняшний бхакт мог быть злым вчера.

## Key Concepts

- **Diipajiñána / pápakśayam** — свет знания / исчерпание са́мска́ров.
- **Mantraghat / mantra caetanya** — удар/движение мантры.
- **Реакция с «процентами»** — задержка увеличивает реакцию.
- **Hari** — вор грехов (Harati pápáni).
- **Kulakuńd́alinii** — спящая змеиная сила.

## Mental Models

- «Чем дольше откладываешь реакцию, тем больше платишь».
- «Diikśá — это вход в shelter и остановка «процентов».
- «Бхакты не отдают грехи — Hari крадёт их».
- «Грешник и святой равны перед Ним».

## Anti-patterns

- **Не брать diikśá** — без света знания нет прогресса.
- **Носить груз са́мска́ров самому** — 20 жизней страданий.
- **Дискриминировать (женщин, грешников)** — He не дискриминирует.

## Worked Example

Пример-займ: взял 1000 рупий. Вернул через месяцы/годы — с процентами; вернул сразу — только сумму. Аналогично реакция действий: при изменении времени/места/лица реакция растёт («интерес»). Diikśá позволяет платить «равно-противоположно» без интереса.

## Key Takeaways

1. Diikśá = diipajiñána + pápakśayam; нужна для прогресса.
2. Реакция действий растёт с задержкой («проценты»).
3. Hari крадёт грехи, т.к. бхакты отказываются их отдать.
4. После кражи — исчерпание са́мска́ров, покой ума.
5. Все равны перед Parama Puruśa; дискриминация — людская.
