# Чит-шит — Ánanda Vacanámrtam Part 8

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Оценить отклонение/новатора | Исключение — двигатель эволюции; «безумцы» строят историю |
| Сложность ума | 50 vrttis × 2 × 10 = 1000 (sahasrára) |
| Контроль мыслей | Держи экстернализацию (utkepan) под контролем; направь поток |
| Оценить действие | Ведёт ли к hita (физ.+псих.+дух.)? Иначе — pápa |
| Классифицировать грех | pátaka (компенсируемо) → atipátaka (нет) → mahapátaka (recurring) |
| Не сделал добро | Pratyaváya — грех (логики: порицаемее pátaka) |
| Время действия | Добро — немедленно; зло — отложить (правило Раваны) |
| Страх | Шаг вперёд развеивает призрак; shelter в Parama Puruśa |
| Сон | Для разгона, не сверх меры (~4 ч автору ⚠) |
| Гнев | Побеждай безгневием; sentient anger (против зла) — ок, static — нет |
| Лень | Три уровня; духовная — худшая (1–2% потенциала ⚠) |
| «Я грешник» | Запрещено: «я принадлежу Paramátma» |
| Груз са́мска́ров | Hari крадёт их; diikśá останавливает «проценты» |
| Реакция действия | Растёт с задержкой (время/место/лицо меняются) |
| Сделать добро круглосуточно | Привяжи мантру к дыханию (ajapá siddhi) |
| Устал на любом пути | Sharańágati — 100% сдача; финальное достижение |
| Спросить «почему мне роль?» | Право есть: голосовые связки даны для этого |
| Общество дурных людей | Избегай (durjana); трансформируй коллективно (5–10 друзей) |
| Оценка культуры | Культура = сумма выражений жизни |
| Уважать непризнанных | «Amáninama mána deyam» — признай их людьми |
| Время/красота | Относительны (время/место/лицо); не суди по стандарту дня |
| Начать sádhaná | С 5–6 лет; человеческое тело редко; dharma — единственный друг |
| Определить человека | Mánava dharma: vistára (расширение) + rasa (поток) + sevá (служение) |
| Служить Parama Puruśa | Служи Его детям; не различай рай/ад (пастухи Вриндавана) |
| Просить силу | Только после полного использования данной |
| Лень/застой | Move on: судьба движется с тобой; юги — состояния ума |

## Пять состояний ума

kśipta (почти безумный) → múrha (глупый) → vikśipta (рассеянный) → ekágra (почти сосредоточенный) → nirodha (однонаправленный)

## Шесть привычек (шлока)

Nidra (сон) · Tandra (вялость) · Bhaya (страх) · Krodha (гнев) · Alasya (лень) · Diirghasútratá (откладывание)

## Виды pápa и puńya

- Pápa: pátaka (сделал зло, компенсируемо) / atipátaka (некомпенсируемо) / mahapátaka (recurring) + pratyaváya (не сделал добро)
- Puńya: pratyakśa (прямое) + apratyakśa (косвенное, recurring)

## Косы очищения (ch03/ch16)

kama-maya → mano-maya → atima-nasa → vijiñánamaya → hiranyamaya → átman отделяется (масло из пахты)

## Десять wonts dharma (ch12)

Dhrti (терпение) · Kśama (разрыв цепи реакций) · Damah (damanam/контроль) · Asteya (не-воровство) · Shaoca (внеш./внутр.) · Indriyanigraha (контроль органов) · Dhii (благожелательный интеллект) · Vidyá (духовное знание; науку не отменять) · Satyam (истина) · Akrodha (sentient vs static)
