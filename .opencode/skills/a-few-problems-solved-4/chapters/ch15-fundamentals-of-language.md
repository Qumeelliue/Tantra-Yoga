# Chapter 15: The Fundamentals of Language

*Дискурс от 1 ноября 1979, Kullu.*

## Core Idea

Отдельный язык определяется пятью признаками. По ним Páháŕii — самостоятельный язык, а не диалект хинди. Навязывание чужого языка — психо-экономическая эксплуатация: комплекс неполноценности → экономическая зависимость.

## Frameworks Introduced

- **Пять признаков языка**:
  1. **Собственные глагольные формы** (Ram is going / Ramah gacchati).
  2. **Падежные окончания существительных** (Ram's / Ramasya / Ram ki / Ram rii).
  3. **Собственные местоимения** (he / vah / sah / sao).
  4. **Собственный словарь** (wheat = gehun hindi / kanaka páháŕii / godhúma sanksrit).
  5. **Собственная литература** (классическая или народная; напр., песни фермеров на páháŕii).
- **Вывод**: Páháŕii — полноправный язык; Dogrii — тоже. «Кричащие "Hindi, Hindi!" хотят навязать Hindi, чтобы Páháŕii-говорящие стали рабами» — так англичане навязывали английский.
- **Психо-экономическая эксплуатация**: говоря на чужом языке, человек делает грамматические ошибки → чувствует неполноценность → эксплуататор пользуется этим → «сначала принижают психику, потом эксплуатируют экономически».
- **Сценарии Páháŕii**: Táḿrii (популярный), Dogrii, Sirmaorii. Devanágarii — не местный (он из Гуджарата); санскрит не имеет собственного сценария — пишется местными письменами.

## Key Concepts

- **Five characteristics** — критерии отдельного языка.
- **Psycho-economic exploitation** — эксплуатация через язык.
- **Páháŕii** — язык Химачал-Прадеш (из Paeshácii Prákrta).
- **Táḿrii / Dogrii / Sirmaorii scripts** — местные письменности.
- **Bhákhá** — презрительное название народного языка.

## Mental Models

- «Думай о языке как о здании с пятью колоннами: нет одной — здание рушится».
- «Представляй язык как свободу: твой язык — твоя граница и твоя крепость».
- «Метафора эксплуатации: сначала принижают твой язык (психику), потом твой кошелёк».

## Anti-patterns

- **Навязывание чужого языка** — психо-экономическая эксплуатация.
- **Признание «диалекта» без проверки** — проверяй по 5 признакам.
- **Devanágarii для всего** — ошибочный миф; санскрит пишется местными сценариями.

## Worked Example

*Психо-экономическая эксплуатация.* Хинди-шовинист говорит с тобой на хинди; ты отвечаешь на неродном языке, ошибаешься, чувствуешь неполноценность. Хинди-говорящие думают «какой дурак, не может говорить грамматически», у них — комплекс превосходства. Твоя слабость даёт им экономическое преимущество. Требование: Páháŕii в судах, школах, колледжах, официальной переписке, аэропортах, радио.

## Key Takeaways

1. Язык = 5 признаков: глаголы, падежи, местоимения, словарь, литература.
2. Páháŕii и Dogrii — самостоятельные языки, а не диалекты хинди.
3. Навязывание языка — психо-экономическая эксплуатация (психика → экономика).
4. Свой сценарий — часть языкового суверенитета (Táḿrii).
5. Санскрит не имеет собственного письма — он пишется местными сценариями.
6. Защита языка — борьба против комплекса неполноценности.
