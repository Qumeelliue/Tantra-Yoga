# Cheatsheet — A Few Problems Solved Part 4

## Ситуация → Правило

| Ситуация | Правило |
|---|---|
| Конфликт групп/идеологий | Путь синтеза, а не анализа; единая цель |
| Идею нельзя обсуждать | Догма → бороться («Dogma — No More») |
| Оценка искусства/музыки | Движется ли от грубого к тонкому? |
| Индивид ведёт себя по инстинктам | animal dharma; не следовать paradharma |
| Хочешь узнать себя | Átmajiṋánam = видеть субъект Сознанием |
| Язык считают «диалектом» | Проверь 5 признаков: глаголы/падежи/местоимения/словарь/литература |
| Навязывают чужой язык | Психо-экономическая эксплуатация — сопротивляйся |
| История только про царей | Предвзята; нужна история масс |
| Застой в любой сфере | Освобождение; движение = жизнь |
| Интеллект блокируется | Освобождать от догм; agryábuddhi = вершина |
| Принятие важного решения | Сначала равновесие ума (samatábhávo) |
| Страх/превосходство/поражение | Комплексы — не поощрять; ты дитя Parama Puruśa |

## Мини-шпаргалка по языку

- 5 признаков языка: verb forms, case endings, pronouns, vocabulary, literature.
- Срок жизни языка ≈ 1000 лет; сценарий появляется ≈ через 2000 лет.
- Paháŕii — отдельный язык (не диалект хинди). ⚠ к калибровке: даты и числа из книги.

## Уровни освобождения

1. Экономическое/политическое/социальное рабство → борьба.
2. Психическое рабство → освобождение ума.
3. Интеллектуальное рабство (догмы) → pactless fight.

## Четыре аспекта Bhagavata Dharma

Vistára (расширение) → Rasa (поток) → Sevá (служение) → Tadsthiti (высшая позиция).
