# Глоссарий — Ánanda Vacanámrtam Part 4

**А́гама / ни́гама (ágama/nigama)** — ответы Шивы / вопросы Парвати; два крыла Тантры (Ch 17).

**А́кшама (kśamá)** — прощение взвешенное: не слепое, не безжалостное (Ch 19).

**А́кродха (akrodha)** — свобода от гнева; разгневанный проигрывает (Ch 19).

**А́кшама (damana / shamana)** — контроль себя / контроль других (Ch 19).

**А́ртха / парамартха (artha/paramártha)** — временное облегчение (деньги) / постоянное прекращение тройных страданий (Ch 10).

**А́птакама (áptakáma)** — получивший прямо от Господа (ápti), в отличие от прапти (Ch 18).

**А́стейя (asteya)** — не-воровство: внешнее и внутреннее (Ch 19).

**Бха́ва (в Part 4)** — тончайшая параллель человеческого существования и духовного потока (Ch 4).

**Бха́гавата-дхарма** — vistára + rasa + sevá; человеческая дхарма (Ch 12).

**Бхакти (степени)** — тамасика (враги), раджасика (процветание), саттвики (мокша), рага́нуга («делать Твоё дело»), рага́тмика («дать Тебе радость») (Ch 16).

**Вайрагья (vaerágya)** — неокрашиваемость цветами объектов; свободна от страха (Ch 18).

**Вашика́ра (vashiikára)** — четвёртая стадия: контроль всех пропенситов (Ch 15).

**Видж́ая / дж́ая (vijaya/jaya)** — постоянная / временная победа (Ch 18).

**Видья / авидья (vidyá/avidyá)** — знание, ведущее к парамартхе / к мирскому (Ch 19).

**Вии́ра (viira)** — герой; стадия между pashu и devatá (Ch 13).

**Вирагья в гухе (guhá)** — полость «я», где корень дхармы (Ch 11).

**Дхармика (dhármika)** — десять качеств: dhrti, kśamá, dama, asteya, shaoca, indryanigraha, dhii, vidyá, satya, akrodha (Ch 19).

**Дхрува́смрити (dhruvásmrti)** — фиксированная память цели 24 часа (Ch 3, 19, 20).

**Индра (в Ch 18)** — энергия (внешняя волна), vs deva — тонкая супраментальная волна (Ch 18).

**Кали/двапара/трета/сатья-юга** — состояния: сон → пробуждение → подъём → шаг (Ch 22).

**Карма / кри́я (karma/kriyá)** — действие без формы / финализированное действие (Ch 1).

**Карма́дхьякша (Karmádhyakśa)** — Высший Супервайзер действий (Ch 1).

**Мадха́ласа** — давшая сыну два наставления (компания; желания) (Ch 20).

**Мокша/мукти/вимукти** — спасение / свобода / постоянная свобода (Ch 17).

**О́та-йога / про́та-йога (ota/prota)** — индивидуальная / коллективная связь (Ch 20, 21).

**Пра́пти / а́пти (prápti/ápti)** — через структуры / прямо от Него (Ch 18).

**Прани́пата / парипрашна / се́ва (prańipáta/pariprashna/sevá)** — самоотдача / действенный вопрос / одностороннее служение (Ch 2).

**Пра́на-дхарма** — жизненная динамика (Ch 22).

**Раджа-Раджа** — буквальность желаний («хотел быть царём» — фамилия Раджа) (Ch 16).

**Ра́га́нуга / ра́га́тмика бхакти** — «хочу делать Твоё дело» / «дать Тебе радость» (Ch 16).

**Са́кша́/чета (sákśii/ceta)** — свидетель / высшая отражающая пластина (Ch 1).

**Сат́я (satya)** — неметаморфозная истина = Parama Purusa; благо для других (Ch 18, 19).

**Са́дхак (sádhaka)** — практикующий; квалификация — тело человека (Ch 17).

**Свадхарма** — человеческая дхарма (не религия по имени) (Ch 12).

**Тантра** — освобождение от инертности (ta) + расширение (tan) (Ch 14).

**Хари (Hari)** — крадущий грехи (Ch 5).

**Шраддха́** — «shrat»+«dha»: направленность к цели (Ch 19).

**Шрея / прея (shreya/preya)** — путь блага / путь падения (Ch 11).

**Юга-переход** — не мифическая эпоха, а промежуточный период между эпохами (Ch 22).
