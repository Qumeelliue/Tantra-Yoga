# Читшит — Ánanda Vacanámrtam Part 4

## Знание и практика

| Ситуация | Правило |
|---|---|
| Квалификация садханы | Тело человека (не возраст/учёность/пол) |
| Условия духовного знания | Самоотдача + действенный вопрос + одностороннее служение |
| Самопознание | «Я» внутри «я» = знание Брахмы = спасение |
| Мокша | Постоянное освобождение; рай/сварга — лишь этап между жизнями |
| Дхармик | Десять качеств (терпение… безгневие) |

## Бхакти и желания

| Ситуация | Правило |
|---|---|
| Желание | Исполняется буквально — осторожно с формулировкой |
| «Уничтожь врагов» | Тамасика-бхакта: не получит Его |
| «Дай процветание» | Раджасика: вещь может получить, не Его |
| «Хочу мокшу» | Саттвики: хочет свободы, не Его |
| Рага́нуга | «Хочу делать Твоё дело, любить» |
| Рага́тмика (вершина) | «Дам Тебе радость, неважно что со мной» |
| Если просить | Только «направь мой интеллект к благу» |

## Прогресс

| Ситуация | Правило |
|---|---|
| Три стадии | pashu → viira → devatá (Pashupati → Viireshvara) |
| Четыре стадии | yatamána → vyatireka → ekendriya → vashiikára |
| После вашикары | Сдай душу с силами Параматме (иначе эго) |
| Тантра | Освобождение от инертности (ta) + расширение (tan) |
| Движение | Жизнь; статичность — смерть; после застоя — акселерация |
| Юги | Сон (кали) → пробуждение (двапара) → подъём (трета) → шаг (сатья) |

## Мир и отношения

| Ситуация | Правило |
|---|---|
| Друг | В мире — только mitram; Он — bandhu/suhrda/sakhá |
| Артха/парамартха | Материя — временно; постоянное — парамартха; нужны обе (PROUT) |
| «Я грешник» | Первертная мысль; думай «я дитя на коленях Отца» |
| Страх | Прибежище — единственное лекарство; ота/прота-йога |
| Воплощение | При демонах — Yadá yadá... |
| Свадхарма | Человеческая Bhágavata dharma (не религия по имени) |
| Шрея/прея | Благо/падение; корень дхармы — в «я»; путь великих |
| Сатья | Благо для других; временная победа (jaya) vs постоянная (vijaya) |

## Быстрые сигналы («tells»)

- «Я стараюсь» годами — yatamána-задержка; нужна решимость.
- Просит «уничтожь врага» — тамасика-бхакта, не получит Его.
- «Всё по природе» — природа слепа; божественная сила за ней.
- Боишься «контролёров» — Он Махешвара, Господь господ.
- Лёгкая «дхарма» (есть/спать) — парадхарма, ведёт вниз.
- «Это естественно/само собой» — проверь, не статичность ли это.
