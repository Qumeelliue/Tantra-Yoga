# Chapter 17: The Minimum Qualifications for a Sádhaka

*Дискурс 9 ноября 1978 (вечер), Kolkata. Discourse 96 серии.*

## Core Idea

Как для работы нужны минимальные квалификации, так для садханы: первая и единственная — человеческое тело (контроль врождённых инстинктов интеллектом). Самопознание («я» внутри «я») = спасение. В PROUT: духовный служитель не сидит в пещерах — служит обществу.

## Frameworks Introduced

- **Минимальная квалификация**: как «требуется: мать», так и садхана требует тело человека; не всё учить всех; «ворону не научишь говорить как майна».
- **Агама/нигама** (повтор): вопросы Парвати — нигама; ответы Шивы — агама (из первых букв строк). Первый ответ: квалификация — человеческое тело.
- **Джияна/самопознание**: знание = внутреннее усвоение внешнего объекта (лангра vs химасагар манго); самопознание — усвоение «я» внутри «я» — реальное знание (Brahma там); «познавший себя — спасён».
- **Мокша**: mukti = освобождение от уз; vimukti/mokśa = постоянное. Сварга/рай — не отдельный мир: «наслаждение плодами добродетели» между жизнями; без исчерпания моментумов возвращаешься (дог, человек). Небесное наслаждение не даёт бессмертия («старое бенгальское стихотворение»).
- **Человек = существо, ведомое интеллектом**: pashu ведом инстинктами. Пример козы и человека у рынка: коза тянется к капусте, не проверяя карманы; человек проверяет монеты. Контроль инстинктов интеллектом — вот человек.
- **PROUT**: духовное служение обществу обязательно; «медитация в гималайских пещерах без служения» — запрещено; «мир нереален» — отговорка не принимается; паразитизм прошлого кончился.

## Key Concepts

- **минимальная квалификация** — тело человека.
- **nigama / ágama** — вопросы/ответы (Парвати/Шива).
- **самопознание** — «я» внутри «я» = Brahma.
- **mukti / vimukti / mokśa** — свобода / постоянная свобода / спасение.
- **контроль инстинктов интеллектом** — человек vs pashu.

## Mental Models

- «Думай о человеке как о козе с проверкой карманов: инстинкт есть, но решает интеллект».
- «Думай о мокше как о полной расплате: пока моментумы не погашены, счёт продолжается».

## Anti-patterns

- **Ведомость одними инстинктами** — pashu, не человек.
- **Искать «рай» добрыми делами** — не даёт бессмертия.
- **Садхана без служения обществу** — в PROUT запрещено (пещеры не работают).
- **Учить всех всему** — по квалификации.

## Worked Example

*Кто достоин садханы? Автор: у кого есть тело человека (квалификация №1; всё остальное — нет). Тело человека — для контроля инстинктов интеллектом: коза не проверяет карманы перед капустой, человек — проверяет. Самопознание — «я» внутри «я» — ведёт к мокше (постоянной свободе). При этом духовный служитель обязан служить обществу — PROUT это требует.*

## Key Takeaways

1. Единственная квалификация садханы — человеческое тело.
2. Самопознание («я» в «я») = знание Брахмы = спасение.
3. Человек контролирует инстинкты интеллектом; pashu — нет.
4. Рай/сварга — не мир, а этап между жизнями; не бессмертие.
5. Духовный служитель служит обществу (PROUT).
