# Chapter 2: The Three Prerequisites for Spiritual Knowledge

*Дискурс 24 октября 1978, Patna. Discourse 81 серии.*

## Core Idea

Духовная наука редка, аспиранты реже, учителя ещё реже. Минимальная квалификация — человеческое тело. Три условия: prańipáta (самоотдача), pariprashna (вопросы с действием), sevá (одностороннее служение).

## Frameworks Introduced

- **Редкость**: «Shravańáyápi bahubhir...» — очень немногие получают духовное знание, ещё меньше — практическую тренировку.
- **Минимальная квалификация**: человеческое тело; образование/статус не нужны.
- **Три условия**:
  1. **Prańipáta** (pra-ni-pat-al): искреннее желание знать Его, готовность пожертвовать всем; полная самоотдача; отозвать пропенситы от грубого к Высшему.
  2. **Pariprashna** (pari + pracch): вопрос с намерением действовать по ответу; не из любопытства, не для обмана, не бессмысленный.
  3. **Sevá** (одностороннее служение): коммерция взаимна (дал — получил); служение односторонне. Чтобы получить «самый дорогой товар» (духовное знание), платишь собой. Удовлетворить Господа — служа Его детям (весь мир — Его дети).

## Key Concepts

- **prańipáta** — самоотдача.
- **pariprashna** — действенный вопрос.
- **sevá** — одностороннее служение.
- **коммерческая транзакция** — анти-паттерн взаимности.

## Mental Models

- «Думай о духовном знании как о самом дорогом товаре: его нельзя купить деньгами — только собой».
- «Думай о вопросах как о действиях: вопрос без намерения действовать — пустой звук».

## Anti-patterns

- **Вопросы из любопытства/для обмана/бессмысленные** — не pariprashna.
- **Ожидать знание в обмен на что-то** — не коммерция; платишь собой.
- **Считать образование квалификацией** — только тело человека.

## Worked Example

*Как получить духовное знание? Автор: оно редко и дорого. У тебя есть тело — этого достаточно. Но нужны три условия: полностью отдайся (пранипата), спрашивай так, чтобы действовать по ответу (парипрашна), и служи односторонне — без возврата (сева). Довольство Господа достигается служением Его детям. Знание придёт.*

## Key Takeaways

1. Духовная наука, аспиранты и учителя редки.
2. Квалификация — человеческое тело, не образование.
3. Самоотдача + действенные вопросы + одностороннее служение.
4. Знание — «самый дорогой товар»: платишь собой.
5. Удовлетворить Его = служить Его детям.
