# Chapter 4: The Role of the Cosmic Puruśa

*Дискурс 26 октября 1978, Patna. Discourse 83 серии.*

## Core Idea

Puruśa = «центральная точка всех деятельностей» = Высшее Познание. Он — akartá (не-делатель): Сам не делает, но всё делает через Пракрти (как владелец кондитерской). Он — свидетель крии (kriyásákśiibhúta), центр бхавы (bhávakendrasthita), Господь гун (guńádhiisha).

## Frameworks Introduced

- **Puruśa**: «Pure shete yah sah Puruśa» (центральная точка) / «Purasi asti yah» (впереди всего) = Познание.
- **Akartá**: не пассивен; «делает через других» — как владелец кондитерской не готовит расоголу сам, но всё по его указанию. Он получает всё сделанным через Пракрти.
- **Kriyásákśiibhúta**: свидетель финализации действий; без Его свидетельства ничто не становится крия.
- **Bhávakendrasthita**: бхава = тончайшая параллель человеческого существования и духовного потока (у бхавы — динамическая сила; не «abstract»); Он — нуклеус бхавы.
- **Guńádhiisha**: гуны работают по Его желанию; дживы — guńádhiina (под гунами); чтобы выйти из-под гун — прибежище Его; альтернативы нет.

## Key Concepts

- **Puruśa** — центральная точка = Высшее Познание.
- **akartá** — не-делатель (получает всё сделанным).
- **kriyásákśii** — свидетель финализации.
- **bhávakendra** — центр бхавы.
- **guńádhiisha / guńádhiina** — господин гун / под гунами.

## Mental Models

- «Думай о Нём как о владельце кондитерской: не лепит сладости, но всё — по его указанию».
- «Думай о гунах как о служащих: у них нет свободы, есть инструкции».

## Anti-patterns

- **Считать akartá пассивностью** — Он активен через других.
- **Считать действия без свидетельства возможными** — без Него нет крии.
- **Пытаться выйти из-под гун без прибежища** — нет альтернативы.

## Worked Example

*Что делает Парама Пуруша? Автор: Он — центр; не делает Сам, но всё через Пракрти (akartá). При этом Он свидетель каждого финализированного действия. Он — нуклеус бхавы. Гуны — Его инструменты; дживы под гунами. Чтобы освободиться — только прибежище в Нём.*

## Key Takeaways

1. Puruśa — центральная точка = Высшее Познание.
2. Akartá — не-делатель, но активный: всё через Пракрти.
3. Он — свидетель финализации действий.
4. Бхава имеет центр — Он.
5. Гуны — Его инструменты; освобождение — только прибежищем.
