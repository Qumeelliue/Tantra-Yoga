# Chapter 13: The Three Stages of Spiritual Progress

*Дискурс 6 ноября 1978 (утро), Kolkata. Discourse 92 серии.*

## Core Idea

Все рождаются pashu (инфантильная животность); при пробуждении духовного голода становятся viira (герои, борющиеся с препятствиями); утвердившись — devatá (божественность). Господь меняет имя по стадии: Pashupati → Viireshvara → (Mahádeva). Не используешь потенциал — будешь рождён ещё ниже.

## Frameworks Introduced

- **Три стадии** (Rudrayámala Tantra): 
  - **Pashu**: инфантильность; нет развитого суждения; как ребёнка, прощают (мочеиспускание/кал — как у животного). Не вставший на духовный путь, имея тело, — «не лучше животного»; Господь — **Pashupati**.
  - **Viira**: приходит с пробуждением (вайдики-дикша → гаятри «направь ум»; тантрики-дикша = Iśt́a mantra; «Гуру — Иишвара»); препятствия (даже семья) — бороться; «без борьбы победы нет»; герой не терпит греха/несправедливости; Господь — **Viireshvara**.
  - **Devatá**: kramena devatá bhavet — из виира-бхавы → divyabháva; благородное поведение; «шиваподобный»; однажды слияние с Parama Purusa.
- **Потенциал**: невысоко развитые всё же имеют потенциал высоты эволюции; использующие — умны; неиспользующие — родятся «ещё ниже».
- **Долг садхаки**: пропагандировать дхарму, чтобы люди не ошибались; это врождённая природа.

## Key Concepts

- **pashu → viira → devatá** — три стадии.
- **Pashupati / Viireshvara** — имена Господа по стадии.
- **Vaidiki/Tantrikii diikśá** — две инициации.
- **viirabháva / divyabháva** — героическое / божественное состояние.

## Mental Models

- «Думай о духовном пути как о спорте: сначала ребёнок, потом борец, потом чемпион-божество».
- «Думай об имени Господа как о зеркале твоей стадии: Pashupati для спящих, Viireshvara для героев».

## Anti-patterns

- **Оставаться pashu при наличии тела** — «не лучше животного».
- **Избегать борьбы** — «победы без борьбы не бывает».
- **Не использовать потенциал** — следующее рождение ниже.

## Worked Example

*Ребёнок делает глупости — прощают (нет суждения). Так и духовный невежда. Затем вайдики-дикша (молитва о правильном пути), тантрики-дикша (Iśt́a mantra; гуру = Иишвара). Появляются препятствия — viira борется; Господь — Viireshvara. Утвердившись — devatá (divyabháva), благородство, позже слияние. Кто не использовал потенциал — упадёт в следующем рождении.*

## Key Takeaways

1. Все рождаются pashu; стадии — pashu → viira → devatá.
2. Пробуждение — через две дикши; гуру = Иишвара.
3. Без борьбы нет победы (viirabháva).
4. Devatá — благородное поведение и слияние.
5. Неиспользованный потенциал ведёт вниз.
