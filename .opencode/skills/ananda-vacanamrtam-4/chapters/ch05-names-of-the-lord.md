# Chapter 5: Names of the Lord

*Дискурс 27 октября 1978, Patna. Discourse 84 серии.*

## Core Idea

Имена Господа — формулы: Gopála (хранитель органов-«го»), Govinda (помощник проявлений), Krśńa (притягивающий; источник «я есмь»), Náráyańa (прибежище Пракрти), Mádhava (супруг Пракрти), Hari (крадущий грехи), Ráma (блаженство/блистание/смерть Раваны).

## Frameworks Introduced

- **Gopála**: go = моторные и сенсорные органы; pála = хранитель. Без а́тмана органы не работают; Gopála = дживатман/единичное сознание.
- **Govinda**: go (органы) + vinda (помогающий правильным проявлениям) — тоже единичное сознание.
- **Krśńa**: krś = притягивать — притягивает всё к Нуклеусу; также «я есмь»-чувство: «из-за Его присутствия я чувствую, что существую».
- **Náráyańa**: nára (вода / преданность / Оперативный Принцип) + ayana (прибежище) = прибежище Оперативного Принципа = Parama Purusa.
- **Mádhava**: ma (не/Пракрти) + dhava (белый/супруг) = супруг Космической Пракрти.
- **Hari**: «pápáni harati» — крадёт грехи. Преданный отказывается отдать грехи («это был бы ещё грех») — и Господь крадёт их без разрешения.
- **Ráma**: (1) Rámante yoginah yasmin — объект удовольствия йогинов; (2) Ráti mahiidharah — самый блистательный; (3) Rávańasya marańam — смерть Раваны (десятиглавого ума в десяти направлениях); прибежище убивает злые наклонности.

## Key Concepts

- **go / pála / vinda** — органы / хранитель / помощник.
- **krś = притягивать** — основа имени Кришна.
- **nára / ayana** — Пракрти / прибежище.
- **ma / dhava** — Пракрти / супруг.
- **hari / harati** — кража грехов.
- **Rávańa** — десятиликий ум.

## Mental Models

- «Думай об имени как о паспорте: разобрав слоги, увидишь функцию Господа».
- «Думай о грехе как о вещи, которую можно украсть: Он забирает её, даже если ты не отдаёшь».

## Anti-patterns

- **Принимать имена за просто прозвища** — каждое — формула.
- **Хотеть нести грехи самому** — Он крадёт их из любви.
- **Считать Рама-яну историей** — Равана — мифология десятиглавого ума.

## Worked Example

*Почему у Господа столько имён? Автор: каждое — функция. Гопал хранит органы; Говинда помогает их правильным проявлениям; Кришна притягивает всё к Себе и даёт «я есмь»; Нараяна — прибежище Пракрти; Мадхава — её Супруг; Хари крадёт грехи преданных; Рама — блаженство йогинов, самое блистательное и смерть десятиглавого ума. Все — Он.*

## Key Takeaways

1. Гопал/Говинда — единичное сознание, хранитель органов.
2. Кришна — притягивающий к Нуклеусу; источник «я есмь».
3. Нараяна = прибежище Пракрти; Мадхава = её Супруг.
4. Хари крадёт грехи без разрешения.
5. Рама — блаженство, блистание, смерть Раваны.
