# Читшит — правила решений по Саркару (Prout 17)

## Вода и экология

| Ситуация | Правило |
|---|---|
| Водный кризис | Лови дождь там, где падает: малые пруды, плотины, озёра, резервуары; поверхностная вода > подземная |
| Колодцы / глубокие скважины | Только временная мера: опускают горизонт, засаливают, иссушают соседей |
| Опустынивание | Аффорестация: быстрорастущие + долгоживущие деревья вместе, по берегам всех водных систем |
| Река на границе стран | Совет экспертов всех трёх стадий; согласование, не односторонняя эксплуатация |
| Засуха | Причины: вырубка (устранима), зоны низкого давления (частично управляема), небесные тела (неуправляема) |

## Экономика PROUT

| Ситуация | Правило |
|---|---|
| Решить неравенство | Тройная гарантия: минимум всем + особые удобства способным + максимум удобств всем; всё растёт |
| Разрыв богатых и бедных | Мост: поднимай минимум, не сноси максимум |
| Максимум элиты чрезмерен | Немедленно поднимай минимум обычным (машина у способного → мопеды обычным) |
| Уравниловка | Отвергнута: убивает стимул, ведёт к утечке мозгов |
| Коммунизм «по потребности» | Кооператив «по способности» стимулирует труд и производство |

## Психика и идеология

| Ситуация | Правило |
|---|---|
| Уму не дают расширяться, выходы закрыты | Подавление (pradamana) |
| Выражение чувств наказывается, подсознание травмируется | Вытеснение (avadamana) → комплекс неполноценности |
| Наказание за сделанное/желаемое убивает желание достойного | Угнетение (damana) |
| Анализ идеологии | Сравни скорости: материя > психика/дух → демоны; психика > дух → догма; дух задаёт темп — норма |
| Вакуум после краха идеологии | Заполни PROUT/своей идеей быстро, иначе его займёт демоническая теория |

## Язык

| Ситуация | Правило |
|---|---|
| Выбор языка-связки | Нужен lingua franca (сейчас английский), но без навязывания и без вечного закрепления |
| Статус языков страны | Равный статус всех живых языков в конституции; общий язык как связь, не привилегия |
| Навязывание национального языка | Отвергнуто: создаёт привилегированный класс и «второсортных граждан» |
| Подавление родного языка | Запрещено: = подавление человеческих чувств |
| Санскрит | Мать индийских языков; поощрять, но не навязывать; не иностранный |
| Хинди/урду | Хинди должен следовать санскритскому руслу, не урду |

## Скорость и изменения

| Ситуация | Правило |
|---|---|
| Исторические изменения | Волны + галлипирующие скачки; не равномерно, готовься к скачкам |
| Грядущие климатические изменения | Третий ледниковый период: смена сезонов, сдвиг полюсов, подъём уровня океана — быть готовым |
| Перемены | Естественны, не катастрофа; готовность — интеллектуальный долг |
| Один момент времени | = 100 лет ценности; действуй с ускорением |

## Быстрые сигналы («tells»)

- Много глубоких скважин как «решение» — вероятно, путь к опустыниванию.
- «Равное богатство всем» — фикция (ресурсы конечны).
- Элита получает максимум, обычные — нет: немедленно поднимай минимум.
- Репрессивная система: проверь, какие из трёх бедствий (подавление/вытеснение/угнетение) активны.
- «Сокровища прошлого» в образовании — классические языки должны быть связью, а не музеем.
- Общий язык, который доступен только элите, — привилегия и империализм.
