## Core Idea

16 вопросов и ответов по кооперативной экономике, микро-витам, математической природе PROUT, политическим механизмам и условиям настоящего благополучия. Стержень: только кооперативная система решает социальные, культурные и национальные проблемы; ключевой показатель благополучия — растущая покупательная способность; движение PROUT — омни-динамическое с составным ускоренным прогрессом.

## Frameworks Introduced

- **Акции в кооперативах**: фермерские кооперативы — фазовая социализация земли; в переходный период акции распределяются по вложенной земле; после полной социализации — без различия землевладельцев. **Запрещены процентные (приносящие прибыль) акции** — акции по производству земли. Процентные акции будут проданы на фондовом рынке, капиталисты купят, цены зафлуктуируют, кооператив станет коммерческим. В промышленных кооперативах — только дивидендные акции (по чистой прибыли). Привилегированные (preferential) акции — фиксированный интерес независимо от прибыли/убытка (как sonja-система арендаторов) — запрещены. Акционеры должны быть высокой морали. **Голосование — по человеку, не по акциям** («в капиталистических странах голоса покупаются»).
- **Сервис-кооперативы**: тип культурных кооперативов для профессионалов без капитала (пример: врачи 5–10 человек — intellectual service cooperative; решает безработицу, открывает исследования; «работа доктора на 99% практическая»). Прочие типы: farmers, producer, consumer, banking, housing, family annuity.
- **Микро-виты**: верхний плексус — обитель положительных микро-витов (подход синтеза); нижний плексус — отрицательных (подход анализа); коммунисты работают с нижними плексусами → умы грубеют. Духовные устремлённые — синтетический подход («видят одно во многих»); положительные микро-виты важнее для установления PROUT.
- **Меньшинства и вес**: minority — менее 40% населения; strong minority — 40–50%. **Weightage** — преференциальное выделение мест сверх пропорции (для успокоения неполноценности); пример Бенгалии — ошибка: strong minority получила weightage.
- **Математическая природа PROUT**: omni-static = нигилизм/цинизм; static-dynamic и dynamic-static — сдержанные/дегенеративные; **omni-dynamic** — непрерывное движение от грубости к тонкости, «вечный прогресс и сияние духовности» — природа PROUT.
- **Природа прогресса PROUT**: simple / accelerated; внутри accelerated: simple accelerated, progressive accelerated, **compound accelerated** (не равно compound interest — это progressive accelerated). Прогресс PROUT — compound accelerated.
- **Четыре условия утоления микро-психических чаяний** (даже при изобилии земли и высоком доходе — не гарантия): (1) психо-духовное образование (иначе балканизация); (2) правление моралистов; (3) сбалансированная socio-экономическая структура; (4) **постоянно растущая покупательная способность** (доход 50 000 рупий при цене риса 80 000 за квинтал — плохо).
- **Организация сторонников**: 50% общества хорошие, 25% обычные, 25% злые; организуй 50+25=75% → PROUT побеждает.
- **Тоталитаризм vs демократия**: тоталитаризм — сильное правительство, но подавлен публичный голос; демократия — сознательность людей, но при её отсутствии — «простая фарса».
- **Бартер**: подходит развивающейся стране с избытком товаров (Бангладеш — джут и шкуры); не нужен при малом числе излишков.
- **Мировая милиция**: нужна при мировом правительстве (межпланетная борьба).
- **Bonus и piece-work системы**: капитализм — производство ради прибыли, бонус фиксирован, реальная прибыль скрыта; коммунизм — производство для государства, нет чувства сопричастности; PROUT — производство для потребления, прибыль минимизирована. **Bonus** = по сэкономленному времени. **Piece-work**: P = C + Y (цена = себестоимость + рациональная прибыль ~15%), Y распределяется между производителями → стимул производства.
- **Экономическая децентрализация**: поддерживаем власть на местах там, где она касается экономической децентрализации.
- **Коллективная психология**: средний психе-моментум из единичных психе-моментумов; его проявления — события истории.

## Key Concepts

- **Dividend shares vs preferential/profit shares** — дивидендные против привилегированных/процентных акций.
- **Sonja system** — аренда с фиксированной долей землевладельцу независимо от урожая.
- **Service cooperatives** — сервис-кооперативы профессионалов.
- **Microvita (positive/negative)** — микро-виты; верхний/нижний плексус.
- **Minority / strong minority / weightage** — меньшинство / сильное меньшинство / «взвешенные» места.
- **Omni-dynamic movement** — омни-динамическое движение.
- **Compound accelerated progress** — составное ускоренное развитие.
- **Ever-increasing purchasing power** — постоянно растущая покупательная способность.
- **P = C + Y, rational profit ~15%** — формула цены piece-work системы.
- **Collective psychology** — средний психе-моментум общества.

## Mental Models

- «Думай о кооперативе как о системе, защищённой от капитализации: без процентных акций и голосования по акциям он остаётся кооперативом».
- «Проверяй благополучие четырёхчленно: психо-духовное образование + правление моралистов + баланс структуры + покупательная способность».
- «Покупательная способность — отношение дохода к ценам, а не абсолютный доход».

## Anti-patterns

- **Процентные/привилегированные акции в кооперативах**: путь к фондовому рынку и капиталистам.
- **Голосование по числу акций**: купленные голоса (как в «демократии» капиталистических стран).
- **Путать compound accelerated с compound interest**: это разные стадии ускорения.
- **Считать высокий доход гарантией благополучия**: при дорогом рисе (80 000 за квинтал) доход 50 000 бесполезен.
- **Weightage для strong minority**: преференции вместо пропорциональности.
- **Фиксированные стимулы (state capitalism)**: стимулы должны быть привязаны к производству, а не к зарплате.

## Worked Example

*Проектирование кооператива.* Создаём фермерский кооператив. В переходный период акции — по вложенной земле; после полной социализации — без различия. Запрещаем процентные акции (иначе фондовый рынок), разрешаем только дивидендные по чистой прибыли. Голосование — по человеку. Параллельно врачи-без капитала объединяются в сервис-кооператив — решают безработицу и начинают исследования. Проверка благополучия региона: психо-духовное образование + правление моралистов + сбалансированная структура + растущая покупательная способность (доход против цен).

## Key Takeaways

1. Кооперативы: только дивидендные акции, никаких процентных/привилегированных; голосование по человеку.
2. Сервис-кооперативы решают безработицу профессионалов (врачи, интеллектуалы).
3. PROUT — омни-динамичен; прогресс — compound accelerated, не compound interest.
4. Четыре условия утоления микро-психических чаяний, включая растущую покупательную способность.
5. Weightage оправдан только для настоящих меньшинств (<40%), не для strong minority.
6. Стимулы (bonus по сэкономленному времени; piece-work P=C+Y с ~15% прибылью) — привязаны к производству.
7. Организуй 75% (50+25) общества — PROUT побеждает.
