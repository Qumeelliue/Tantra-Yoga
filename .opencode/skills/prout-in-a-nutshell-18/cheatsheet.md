# Читшит — правила решений по Саркару (Prout 18)

## Личность и миссия

| Ситуация | Правило |
|---|---|
| Начало пути с идеологией | Миссия трёхсоставна: мораль+практика → объединение моралистов → борьба с грехом |
| Проверить, настоящее ли усилие | Санкция ума + санкция Атмана (цель — всеобщее благо); страх/принуждение = не yatamána |
| Цель идеации | Высшее Сознание, не враг (иначе ум примет качества врага) |
| Противники прогресса | Два фронта: кровососы (экономика) и интеллектуальные сатаны (догма) |

## Знание и истина

| Ситуация | Правило |
|---|---|
| Оценить источник знания | Относительное (prápta: восприятие/инференс/авторитет) ненадёжно; абсолютное (ápta) — прямое и всеобщее |
| Допустимо ли относительное знание | Пока не конфликтует с универсальным гуманизмом; конфликт = запрет |
| Распознать ápta vákya | Универсально + рационально + психологично |
| Три пути благополучия | Сила / разум / духовное лидерство — действует только духовное лидерство |

## Эксплуатация

| Ситуация | Правило |
|---|---|
| Найти скрытую эксплуатацию | Смотри не на экономику: слои — физический, психический, духовный; невидимое жертве опаснее |
| Механизм эксплуатации | Догма + комплексы (неполноценности/превосходства/страха) → потом сбор |
| «Нельзя» без объяснения | Догма; требуй «почему» — это освобождение интеллекта |
| Воспитать духовного искателя | Путь: Karma Yogi → Bhakti Yogi → Parama Puruśa; активность, не статика |

## Философия и идеология

| Ситуация | Правило |
|---|---|
| Классифицировать идеологию | Центр: догма / материя / себя / Бог; вред: догмо > материе > само; Бого-центричная не льёт кровь |
| Проверить «божественное откровение» | Скорее догмо-центричная эксплуатация («Бог явился во сне») |
| Старая система умерла | Заполняй вакуум немедленно (интеллектуально-интуитивной силой), иначе — демоническая теория |
| Собрать большинство | 50% хороших + 25% обычных = 75% → победа PROUT |

## Образование

| Ситуация | Правило |
|---|---|
| Цель образования | «Са видья я вимуктае» — образование освобождает; трёхстороннее развитие (тело+психе+дух) |
| Три фундамента | Фактуальность без догмы + жажда знания + уравновешенный ум |
| Когда формировать ум | В раннем возрасте (kindergarten, «зелёный бамбук»); позже — не переформовать |
| Оценить «учёного» | Прочитать + понять + запомнить + действовать; все четыре обязательны |
| Пра́н́а дхарма | Укрепляй кардинальную черту народа; тончайшая вражда — лишить её свободы |
| Управление школой | Совет учителей, вне политики, бесплатно; учителя по характеру и служению |
| Устойчивый мир | Двухсоставный подход: Неогуманистическое образование + духовная практика |

## Экономика и политика

| Ситуация | Правило |
|---|---|
| Кооператив | Только дивидендные акции; запрет процентных/привилегированных; голосование по человеку |
| Стимулы рабочим | Bonus по сэкономленному времени; piece-work P=C+Y (рациональная прибыль ~15%) |
| Проверить благополучие | 4 условия: психо-духовное образование + правление моралистов + баланс структуры + растущая покупательная способность |
| Покупательная способность | Доход против цен (50 000 при рисе 80 000/квинтал = плохо), а не абсолют |
| Власть и экономика | Централизация политическая + децентрализация экономическая |
| Меньшинства/квоты | Меньшинство <40%; strong minority 40–50%; weightage только настоящим меньшинствам |
| Коммунализм | Искусственное деление; критерий — отсталость, не каста; лекарство — политическое образование |

## Быстрые сигналы («tells»)

- «Мой Бог единственный истинный» — догмо-центричная пропозиция.
- «Бог велел во сне» — приём эксплуатации, не духовность.
- Фиксированный бонус без привязки к производству — капитализм, скрывающий прибыль.
- «Мы — любимые дети Бога, остальные прокляты» — санкция ума без санкции Атмана.
- Резервирование мест по общине с перекосом к 40–50% группе — weightage сильному меньшинству.
- «Восток и Запад никогда не встретятся» — ложная дихотомия, отрицающая единое человечество.
- Слова о разоружении при готовности к худшему оружию — «порох держи сухим»: лицемерие.
