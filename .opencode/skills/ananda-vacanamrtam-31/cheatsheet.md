# Читшит: правила решений

## Грех и искупление

| Ситуация | Правило |
|----------|---------|
| Обычный грех, есть искупление | Pátaka |
| Неискупимый (отрубленная рука) | Atipátaka → служение обществу извне |
| Вред повторяется (фальсификатор) | Mahápátaka → изобрети повторяющееся добро |
| Против vidhi («делай») | Pratyaváya (напр., не служишь больным) |
| Против niśedha («не делай») | Pápa (напр., украл) |

## Rectification

| Ситуация | Правило |
|----------|---------|
| Встреча со злодеем один на один | Опасно: durjana относителен |
| Исправление злодея | С 2–3 спутниками, суммарная заслуга > демерит |
| Критерий puńya | Ускорение коллективного прогресса |

## Шесть дефектов

| Дефект | Контрмера |
|--------|-----------|
| Nidrá (сон) | Спи, чтобы работать, не для удовольствия |
| Tandrá (инертность) | Начни, прогони неуверенность |
| Álasya (лень) | Двигайся вперёд |
| Bhaya (страх) | Будь смел |
| Krodha (гнев) | Сдерживай |
| Diirghasútratá (прокрастинация) | Доброе — немедленно; злое — откладывай |

## Четыре типа прогресса

| Тип | Природа |
|-----|---------|
| Физический | Нервы/клетки; объективный |
| Психический | Автономное мышление; объективный; сдерживание = догма |
| Психо-духовный | К тонкому; субъективный; блаженство по тонкости объекта |
| Духовный | Лучший; марш к высшей мудрости; субъективный |

## Стадии медитации

| Стадия | Признак |
|--------|---------|
| 1. Трудность | Ум — дикие лошади; давление родни |
| 2. Начало успеха | Краткий контроль; слёзы блаженства |
| 3. Силы | Опасность: опьянение силой; молись Сознанию |
| 4. Завершение | Слияние с Брахмой |

## Идеал и сдача

| Ситуация | Правило |
|----------|---------|
| Выбор идеала | Только совершенный: Господь (не Арджуна/Судама) |
| Мера преданности | Количество безусловной сдачи |
| Молитва | «Сделай меня тем, чем Ты хочешь» |
| Эго не сдано | Господь создаст обстоятельства для сдачи |

## Смежные решения

| Ситуация | Правило |
|----------|---------|
| Мера жертвы | Обстоятельства (последний кусок в голод > обряд) |
| «Кто ты?» | Не имя/работа/возраст — сущность; знание через погружение |
| Постоянный адрес | Вселенная |
| Слышать prańava | Поза + концентрация + стадии (сверчки→колокольчики) |
| Свобода от догм | Гибкие границы идей; движение к Ядру (Vidyá) |
| dharma-са̄дхана | Знай природу → практикуй; мораль — фундамент |
