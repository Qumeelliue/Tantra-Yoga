# Глоссарий

**Abhidhyána** — настойчивая погоня за Parama Puruśa («не отпущу, пока не поймаю»).

**Abhidhyána samádhi** — поглощение, где объект воспринимается всё тоньше (пыль → частицы → сознание).

**Ácárya** — духовный учитель; учит примером поведения.

**Ahorátra** — сутки (от восхода до восхода).

**Antaryámitva** — способность входить внутрь вещей (знать и контролировать).

**Atipátaka** — неискупимый грех; искупление — служение обществу извне.

**Bhúmadrśt́i** — Космическое видение (отсутствие — корень психических болезней).

**Brahmabháva** — идеация на Верховном Сознании.

**Brhat / Brahma** — «неизмеримо великий» / Тот, кто делает великими других.

**Darpahárii** — «Похититель гордыни» (Parama Puruśa не терпит эго).

**Devásura saḿgráma** — война божественной и злой сил в уме.

**Dharma sádhaná** — «завершить путешествие по своей природе».

**Dhrtáráśt́ra** — слепой ум (без вивеки).

**Durjana** — человек, контакт с которым ведёт к падению (относительно).

**Ekabuddhi** — единая устремлённость (к единственному Дезидератуму).

**Guhá** — «пещера, где живёт Бог» / «Я есть» (I-ness) в сердце.

**Hari parimańd́ala gośt́hi** — круг преданных вокруг Космической идеологии.

**Hirańmaya kośa** — тонкий причинный слой ума (пятый «ворот»).

**Kulakuńd́alinii** — «спящая божественность», поднимаемая через 5 чакр.

**Mahápátaka** — великий грех с повторяющимся вредом.

**Maharshi Kanada** — теория причинности (эффект → причина).

**Nidrá / tandrá / álasya / bhaya / krodha / diirghasútratá** — шесть дефектов (сон/инертность/лень/страх/гнев/прокрастинация).

**Pátaka / atipátaka / mahápátaka** — три уровня греха.

**Paramahaḿsa** — микрокосм, ставший одним с Макрокосмом.

**Prańava dhvani** — божественный звук oṋḿkára (слышимый в медитации).

**Pratyaváya** — грех против vidhi (неделание предписанного).

**Samyak** — «правильный» (восемь пунктов).

**Sanjaya / viveka** — различение добра и зла (колесничий слепого ума).

**Saḿkalpa** — воля Макрокосма (не пропенсити).

**Satsauṋga** — компания Истины (внутренняя — любовь к Нему; внешняя — добрые люди).

**Satyameva jayate** — «истина побеждает».

**Vaerágya** — не-привязанность (принятие мира с ощущением вечного).

**Vashiikára / ekendriya / vyatireka / yatamána** — стадии са̄дханы.

**Vidhi / niśedha** — «делай» / «не делай» (социальные предписания).

**Árádhaná** — самозабвение в погоне за Господом.
