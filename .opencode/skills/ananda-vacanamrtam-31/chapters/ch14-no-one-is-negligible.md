# Chapter 14: No One Is Negligible

*Октябрь 1969, Ranchi.*

## Core Idea
Духовный потенциал у всех равен; различие — лишь в пробуждённости. Ты не имеешь права ненавидеть кого-либо (и сам Господь не может ненавидеть и не может создать другого Parama Puruśa). Смотри вперёд, не назад. Никто не ничтожен: Господь действует через каждого.

## Frameworks Introduced
- **Равный духовный потенциал**: у всех одинаковая потенциальность; у одних пробуждена, у других нет. Нет «развитых/неразвитых» как сущностной разницы.
- **Ненависть запрещена**: всё — выражение Божественного; ненависть к кому-либо = ненависть к себе/Ему. Parama Puruśa не может ненавидеть (нет второго объекта) и не может создать второго Parama Puruśa.
- **Satsauṋga**: некоторые пробудятся в компании пробуждённых — важность хорошей компании.
- **Три типа людей по времени мысли**: ordinary (прошлое + будущее), medium (только будущее), **siddha** (ни прошлого, ни будущего — только Господь). Не оглядывайся: прошлое в сравнении с Терминусом бледнеет.
- **Господь видит свет, не тело**: авадхута увидел «красивый свет» вокруг марги; Paramátmá не смотрит на руки/ноги/лицо — видит свет. Грех — думать о себе как о грешнике/деграданте.
- **Antaryámitva-демонстрации**: авадхута видел прошлые жизни людей (тигры, насекомые, нецивилизованные) — «вы были детьми Господа и остаётесь».
- **Все формы — для вас**: человеческое существование — полностью ментальная структура по психическим моментам (са̄мска́рам); всё — cinmaya (из сознания), ничего — mrnmaya (из земли). Принимай своё.

## Key Concepts
- **siddha** — совершенный (мыслит только о Господе).
- **satsauṋga** — хорошая компания.
- **cinmaya / mrnmaya** — из сознания / из земли-материи.
- **Terminus** — цель/Господь.

## Mental Models
- «Смотри вперёд: прошлое — трата времени для глупцов».
- «Никто не ничтожен: Господь действует через каждого».
- «Господь видит свет в человеке, не тело».

## Anti-patterns
- **Думать «я грешник/деградант»** — само по себе грех.
- **Ненависть к кому-либо** — ненависть к Себе (Его выражению).
- **Оглядываться на прошлое** — трата времени.

## Worked Example
Авадхута, медитируя, видит вокруг марги «красивый свет». Вывод: Paramátmá видит свет, не внешность. Затем демонстрация: прошлые жизни — тигры, насекомые, люди. «Вы были детьми Господа и остаётесь». Вывод: ваша ценность от Господа, не от прошлого.

## Key Takeaways
1. Духовный потенциал равен у всех.
2. Ненавидеть нельзя: это ненависть к выражению Господа.
3. Господь не может ненавидеть и создать второго Господа.
4. Siddha мыслит только о Господе; смотри вперёд.
5. Господь видит свет, не тело.
6. Всё — cinmaya; твоя форма — для тебя.
