# Chapter 8: Sleep and Inertia

*14 января 1979, Barrackpur.*

## Core Idea
Кто хочет процветать и всестороннего развития — должен уничтожить шесть дефектов: nidrá (чрезмерный сон), tandrá (инертность), álasya (лень), bhaya (страх), krodha (гнев), diirghasútratá (прокрастинация). Доброе — немедленно, злое — «убивай время».

## Frameworks Introduced
- **Шесть дефектов (shloka)**: Nidrá tandrá bhayaḿ krodha álasyaḿ diirghasútratá; Śad́odośáh puruśeńeha hántavyáh bhútimicchatá. Тот, кто желает своего блага, обязан их устранить.
- **Nidrá (сон)**: слишком много сна = половина жизни потеряна; сон нужен, чтобы потом больше работать, не для удовольствия.
- **Tandrá (инертность/неуверенность)**: рождается из неуверенности («сможу ли я?»), недостатка мужества взять на себя инициативу, отсутствия самоуверенности.
- **Правило действия**: «доброе желание — делай немедленно, не докладывая мне; злое — убивай время как можно дольше».
- **Цель**: избавившись от шести дефектов, становишься сильным нести идеи и идеалы Ананда Марги по всему миру.

## Key Concepts
- **nidrá / tandrá / álasya / bhaya / krodha / diirghasútratá** — шесть дефектов.
- **bhúti** — процветание.

## Mental Models
- «Сон — топливо для работы, не цель; время жизни коротко».
- «Инертность — от неуверенности: начни, судьба двинется».

## Anti-patterns
- **Считать «больше сна = лучше для здоровья»** — ошибка.
- **Откладывать доброе / ускорять злое** — наоборот правило.

## Worked Example
Желание сделать добро — если спросить семью, отговорят («сколько их всех оденешь?»); если откладывать — желание угаснет. Поэтому: доброе немедленно, злое — тяни с вопросом «стоит ли?». Вывод: время — рычаг воли.

## Key Takeaways
1. Шесть дефектов блокируют прогресс: сон, инертность, лень, страх, гнев, прокрастинация.
2. Чрезмерный сон — потерянная половина жизни.
3. Инертность растёт из неуверенности.
4. Доброе — немедленно; злое — откладывай.
5. Свобода от шести дефектов — сила нести идеи.
