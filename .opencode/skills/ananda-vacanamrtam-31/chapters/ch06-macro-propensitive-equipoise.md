# Chapter 6: Macro-Propensitive Equipoise and Non-Propensitive Desideratum

*Дата не указана.*

## Core Idea
Пропенсити — пища единичного ума; их результат — санскара с импульсом. Макрокосм не нуждается в пище (всё в Нём) — у Него не пропенсити, а saḿkalpa (воля). Цель микрокосма — Non-Propensitive Desideratum (путь nivrtti), где «я» сливается в Космический океан.

## Frameworks Introduced
- **Saṅskára и импульс**: результирующее пропенсити (выраженных чувств) = санскара; её импульс заставляет единицу двигаться; это причина всех будущих последствий. Создавай благочестивые моменты; при переживании реакций не создавай новых.
- **Три аспекта пропенсити**: физическое [желание], психический импульс (может быть возвышающим или деградирующим), духовное [стремление] (сбалансированное — не даёт ни добра, ни зла).
- **Макрокосм vs микрокосм**: у микрокосма есть внешний мир → его атакуют вибрации → неравновесие. Макрокосм содержит всё → вечное равновесие (macro-propensitive equipoise). Пропенсити Макрокосма — не пропенсити, а saḿkalpa: весь Космос — Его saḿkalpa.
- **Творение**: вибрации Макрокосмической психики создают (акустический корень **a**); столкновение/сплочение → диссоциация/ассоциация слов → **vyaiṋjana** (согласные); первая — **ka** (акустический корень); служить ka-deva = служить всей манифестации Космоса → **kápálika**.
- **Oṋḿkára**: толчок Трансцендентальному — звук oṋḿkára (в буддийском тантре — prabhá svara shúnyatá); shúnya = «вакуум» без физичности и психического выражения — только духовность; Шанкара: «шу́нья Будды = Брахма».
- **Pravrtti / nivrtti / saḿvrtti**: pravrtti — движение вовне (через Творческий Принцип); nivrtti — от физического к психическому к духовному; saḿvrtti — баланс (невозможен как цель: динамизм присущ микрокосму). Vedas: «двигайся»; Yuga-шкала (Kali→Satya).
- **Путь nivrtti**: не-пропенситивный; последняя точка — Non-Propensitive Desideratum (высшая цель). Сведите ум в одну точку; pointed «I» сливается в Космический океан; после слияния Творческий Принцип не нужен; состояние — Niśkala Brahma.

## Key Concepts
- **saḿkalpa** — воля Макрокосма (не пропенсити).
- **prabhá svara shúnyatá** — «ясный звук пустоты» (будд. тантра).
- **Niśkala Brahma** — Брахма без семени/атрибутов.
- **kápálika** — служитель всей манифестации.

## Mental Models
- «Отличай волю Макрокосма (saḿkalpa) от пропенсити микрокосма (санскара)».
- «Двигайся по pravrtti или nivrtti; saḿvrtti (баланс) — не цель для динамичного существа».

## Anti-patterns
- **Создавать новые санскары, переживая старые реакции**.
- **Считать shúnya (пустоту) нигилизмом**: это отсутствие физичности при чистой духовности = Брахма.
- **Ставить целью saḿvrtti** (баланс): динамизм присущ микрокосму.

## Worked Example
Микрокосм переживает реакцию прошлого. Если при этом он создаёт новые реактивные моменты — импульс растёт. Правильно: переживать, не создавая нового; направляясь по nivrtti к Не-пропенситивному Дезидератуму. Вывод: цель — слияние pointed «я» с Космическим океаном.

## Key Takeaways
1. Пропенсити = пища ума; санскара = результат с импульсом.
2. Макрокосм в вечном равновесии; у Него — saḿkalpa, не пропенсити.
3. Пропенсити трояки: физические, психические, духовные.
4. Творение — вибрации; первый звук a, первая согласная ka.
5. Oṋḿkára = prabhá svara shúnyatá = Брахма (Шанкара).
6. Цель — Non-Propensitive Desideratum (nivrtti), не saḿvrtti.
