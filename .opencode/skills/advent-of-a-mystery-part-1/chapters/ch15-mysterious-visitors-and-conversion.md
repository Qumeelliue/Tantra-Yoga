# Раздел 15: Таинственные посетители, обращение скептика и «Корабль» (1955–1957)

*«Сумасшедший» Keshavpur; сиддха-йоги; Тотапури; скептик Суреш; корабль Амульяратана; «два зорких ока».*

## Core Idea

Таинственные духовные посетители у Tiger's Grave, обращение скептика Суреша, видение «корабля» Амульяратана и моральный «надзор» Бабы за учениками.

## Frameworks Introduced

- **Таинственные посетители**: с 1940-х к Бабе приходили неузнаваемые великие садхаки (нищие/мудрецы/сиддхи) — «Сумасшедший» Keshavpur («Господь Вселенной родился в Джамалпуре»), сиддха-йог из Виратнагара (Непал) — пришёл пешком за разрешением «оставить тело»; правило: «пока садгуру жив на планете, продвинутый садхака должен лично получить разрешение». Новое правило Бабы: **служение обязательно для освобождения** (было можно только садханой; теперь — сначала социальное служение; пример: 3 дня служения вместо месяцев). Урок: мокша требует вклада в общество.
- **Mahamrityu** — «смерть от духовной причины» (уход великих душ не похож на обычную смерть).
- **Тотапури**: известный садху, в 1961 пришёл за разрешением уйти из тела; Баба просил сначала служение; Тотапури торговался (3 дня → согласился). Урок: даже освобождённые подчиняются правилам садгуру.
- **Обращение скептика Суреша**: студент-скептик, «не приму Бабу как гуру» → в DMC случайное касание колена — блаженство → «он спрашивал обо мне» → в Джамалпур не называл имени (проверка: «знает ли он меня?») → Баба называет по имени → «пойдём, Суреш» → массаж рук (тело мягкое, без костей, сандаловый аромат) → объятие, слёзы → «Бабà — отец, я — твой сын» → «я хочу только твою идеацию». Урок: скептицизм разбивается личным переживанием.
- **Корабль Амульяратана**: проект-инженер; видение корабля в медитации → дискурс «Tvamekam nidhanam...» («мы бежим в убежище единственного надёжного корабля — Всевышнего») → «Баба сканирует умы и говорит о моём вопросе» → PC: «понял ли ты значение корабля?». Урок: гуру отвечает на внутренние вопросы, «сканируя умы».
- **Моральный надзор («два зорких ока»)**: две недели Баба «наблюдал» за учениками; нарушения — наказания (khaini у Дашаратха, собака у Сукумара, snuff у Нитьянанды). Дашаратх: выговор во сне; Сукумар: удар собаке → мгновенное падение (травма) — «наказание за животное»; Нитьянанда: Баба вошёл в Двараканатха (другое тело) → выговор. Урок: мораль проверяется и карается/исправляется напрямую.

## Key Concepts

- **Tiger's Grave** — место встреч с посетителями.
- **Сиддха-йоги / «Сумасшедший» Keshavpur** — скрытые великие души.
- **Mahamrityu** — духовная смерть.
- **Тотапури** — известный садху (1961).
- **Суреш** — обращённый скептик.
- **Амульяратан** — «корабль» в медитации.
- **Два зорких ока** — период морального надзора.
- **«Сканирование умов»** — метод дискурса Бабы.

## Mental Models

- «Мокша требует служения: сначала обществу, потом уход (новое правило)».
- «Великие души приходят незаметно, как нищие — не суди по одежде».
- «Скептицизм преодолевается опытом, не аргументами».
- «Гуру видит и отвечает на внутренние вопросы (сканирование)».
- «Моральная дисциплина проверяется напрямую, исправление — немедленно».

## Anti-patterns

- **Скептицизм-гордыня** (Суреш: «не приму гуру») — ломается личным опытом.
- **Нарушение морали** (khaini, snuff, жестокость) — немедленное исправление.
- **Слишком большая любознательность** (маги Марги хотят поймать посетителей) — «не ходи туда, куда не звали».
- **Запрет любопытства** (про посетителей) — часть тайны.

## Worked Example

*Сценарий сиддха-йога из Виратнагара.* На прогулке марги видят нищего у дороги → Баба просит всех уйти («он прошёл долгий путь пешком из Непала») → марги планируют перехватить → посетитель исчезает (и Баба) → «даже 300 человек не поймали бы его» → позже: «он завершил садхану, хотел уйти; я попросил сначала служение; договорились на 3 дня» → через несколько дней найдено тело старого садху у ж/д туннеля. Урок: духовная реальность имеет свои правила; служение — обязательное условие освобождения.

## Key Takeaways

1. Мокша требует служения обществу (новое правило Бабы).
2. Великие души ходят в облике нищих — не суди по внешности.
3. Скептик обращается личным опытом (Суреш).
4. Гуру «сканирует умы» и отвечает на внутренние вопросы.
5. Моральный надзор — часть метода (наказание/исправление).
6. Тотапури и сиддха-йоги подчиняются садгуру.
