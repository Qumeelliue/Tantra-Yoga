# Раздел 16: Открытие третьего глаза и проверки веры (1955–1957)

*Dasharath — медиум демонстраций; ajina chakra; проверки веры (sharanagati); астральные визиты.*

## Core Idea

Dasharath становится главным медиумом демонстраций Бабы; учение о «третьем глазе» (ajina chakra); проверки веры учеников (самая трудная — «отнятие веры»), астральные визиты Бабы.

## Frameworks Introduced

- **Демонстрации как метод**: Баба «оживлял» философию практикой (см. Ch12). Диапазон: подъём kundalini, samadhi, out-of-body, вход в умы, видение прошлого (динозавры, Кришна), microvita (в поздние годы).
- **Медиум (Dasharath)**: подготовка через трудные тесты, устранение слабостей; демонстрации начинаются прикосновением к ajina chakra или затылку (или одной командой). Урок: медиум — инструмент, требующий смирения.
- **«Третий глаз» (ajina chakra)**: физическое расположение ума — между межбровьем и затылком; развитие чакры = пробуждение интуиции («всезнающий»). Изображения Шивы с третьим глазом — символ открытой интуиции, а не буквальный глаз. Урок: символы нужно читать духовно.
- **Проверки веры (Dasharath)**: периоды отнятия веры (месяцы тьмы, отвращение к Бабе/садхане) → возврат → вновь → «нет avidya tantric способен навредить моим детям» → в конце прикосновение к ajina → исцеление → «вы создали кризис, чтобы я проверил sharanagati (полную сдачу)». Урок: самая трудная проверка — отнятие веры; единственный выход — sharanagati («не отпущу твои стопы»).
- **Проверка гордыни**: Dasharath хвастался выступлением → на следующем «сила ушла» → «Arjuna не мог поднять Gandiva, когда Krishna убрал силу, чтобы снести гордыню» → «Parama Purusha = Darpahari (разрушитель гордыни)». Урок: гордыня — барьер к расширению ума.
- **Проверка гнева**: Dasharath хотел проклясть соседей → Баба видел намерение (поднял палку) → «ты не имеешь права желать зла; Nature накажет справедливо» → урок «сдерживай гнев через guru mantra».
- **Астральные визиты**: Баба приходил «в тонком теле» (дверь заперта), посещал 27 мест за полчаса; объяснение: «в тонком теле нет преград; в ещё более тонкой форме я везде». Урок: гуру доступен духовно независимо от расстояния.
- **Omkara / ароматы / звуки в садхане**: космический звук (сверчок→колокольчики→флейта→волны→гонг→чистый omkara) — стадии садханы; ароматы высших желёз.

## Key Concepts

- **Ajina chakra / третий глаз** — центр интуиции.
- **Dasharath** — медиум демонстраций (с 1957).
- **Sharanagati** — полная сдача гуру.
- **Darpahari** — «разрушитель гордыни» (имя Парама Пуруши).
- **Khaini** — табачная смесь; проверка дисциплины.
- **Астральный визит** — тонкое тело.
- **Omkara** — звуковые стадии садханы.
- **Microvita** — теория позднего периода.

## Mental Models

- «Демонстрации — живой метод передачи философии».
- «Интуиция развивается через ajina chakra; символы — духовны, не буквальны».
- «Самый трудный тест — отнятие веры; выживает только sharanagati».
- «Гордыня и гнев — барьеры; их снимает Парама Пуруша (Darpahari)».
- «Гуру вездесущ в тонком теле — расстояние не преграда».

## Anti-patterns

- **Гордыня о знаниях** — сила уходит (Arjuna/Gandiva).
- **Гнев/проклятие** — «святотатство» для садхака; Nature накажет.
- **Сомнение в вере** — проходит проверкой; выход — сдача.
- **Недоверие к символам** — «третий глаз» как буквальный.

## Worked Example

*Сценарий проверки веры.* Dasharath месяцами теряет веру/блаженство → садхана механическая → молитвы без ответа → трижды просит совета (ишта/guru мантры) → без результата → «нет avidya tantric может навредить» → прикосновение к ajina → исцеление → осознание «это был тест Бабы» → умоляет «обещай не отнимать веру снова» → Баба: «никогда не оставлю тебя» → позже: «Садгуру испытывает учеников; отнятие веры — труднейший тест; проход через sharanagati». Урок: кризис веры — проверка на глубину сдачи; выход — держаться стоп гуру.

## Key Takeaways

1. Демонстрации — живой метод (от kundalini до microvita).
2. «Третий глаз» = открытая интуиция (ajina chakra), символ Шивы — не буквален.
3. Отнятие веры — самый трудный тест; выживает sharanagati.
4. Гордыня (Darpahari) и гнев — барьеры, снимаемые духовно.
5. Гуру доступен в тонком теле — расстояние не преграда.
6. Садхана: от звуков (сверчок→омкара) к глубокому опыту.
