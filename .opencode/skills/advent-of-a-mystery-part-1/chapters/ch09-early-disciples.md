# Раздел 9: Ранние ученики (1947–1953)

*Пранай, Харапрасад, Садхан Дей, Шива Шанкар, Чандранатх — первые посвящённые.*

## Core Idea

Классические случаи «привлечения» первых учеников: скептик Пранай (свет из глаз → самадхи), Харапрасад (продление жизни вопреки предсказанию смерти), разбойник Садхан Дей, астматик Шива Шанкар, искатель Чандранатх.

## Frameworks Introduced

- **Привлечение через внутреннее переживание (Пранай)**: скептик-циник, попросил прочитать ладонь → Prabhatda оттолкнул руку молча (ощущение блаженства) → позже предупредил о «неминуемой гибели» → дал Shiva Dhyana Mantra (Пранай бросил, вернул) → в офисе Prabhatda прикоснулся к межбровью → взрыв света → самадхи → «я ошибался, есть духовный мир» → инициация у Tiger's Grave → «зовись Baba» (объяснение имени). Первый публично признанный ученик.
- **«Тест на готовность»**: Prabhatda «звал» Праная на прогулки годами, пока ум не созрел («в моём плане всё предрешено — что, когда, как, почему»).
- **Продление жизни (Харапрасад)**: Prabhatda предсказал смерть через месяц (25 мая 1950) → Харапрасад в ужасе, семья считает Бабу «злым тантриком» → 25 мая прошло → встреча у Tiger's Grave в назначенный день → «твоя судьба изменилась, жизнь продлена для духовной цели» → отказ от кастового шнура, инициация → «Бог-без-касты». Урок: судьба изменяема через контакт с гуру.
- **Разоружение нападающего (Садхан Дей)**: Садхан с ножом шёл «наказать тантрика» за Харапрасада → Prabhatda приветствует по имени, знает семью/деревню (Noakhali), говорит на диалекте → у Tiger's Grave: «ещё нужен нож?» → разоружён, инициирован. Урок: знание + тепло разоружают враждебность.
- **Исцеление через йогу (Шива Шанкар)**: тяжёлая астма, «вылечу, но прими меня как гуру» → медитация + вегетарианство + травы → вылечен за дни → перенёсся в «коррумпированный» коллиерский пост → остался честным (yama-niyama), просил перевод.
- **Поиск гуру (Чандранатх)**: 6 лет искал, святой Maharaj сказал «samay ayii ta, miili» («придёт время — получишь гуру») → 1953, Шива Шанкар (переведён под Чандранатха) → приводит → «Has the time come?» → посвящение, отказ от sacred thread (Kshatriya), «проведи эту жизнь в духовности; через поведение ученика познаётся гуру».
- **«Гуру-дружелюбие»**: Prabhatda привлекал не угрозами, а знанием, теплом и демонстрацией власти (множественные формы вокруг Праная при yama-niyama: «ты должен следовать!»).

## Key Concepts

- **Tiger's Grave** — место инициации/встреч.
- **Shiva Dhyana Mantra** — первая мантра для Праная.
- **Yama-Niyama** — 10 принципов морали садхака.
- **Guru mantra / second lesson** — вторая ступень садханы.
- **Sacred thread (upavita)** — кастовый символ, отменялся при инициации.
- **Sadguru / Baba** — гуру; обращение «Baba» (корень «bapra» — «кого любишь»).
- **Kalikananda** — первый тайный ученик (разбойник), см. Ch04.

## Mental Models

- «Гуру привлекает терпением и временем — готовность созревает, а не навязывается».
- «Судьба не жёсткая: контакт с совершенным гуру может изменить её (продление жизни)».
- «Враждебность разоружается знанием и любовью, а не силой».
- «Поведение ученика — визитка гуру («через поведение ученика познаётся гуру»)».

## Anti-patterns

- **Скептицизм-гордыня** (Пранай: «не верю в духовное») — разбивается личным опытом.
- **Недоверие к гуру как «злому тантрику»** (семья Харапрасада) — меняется после опыта.
- **Нежелание бросить кастовый шнур** (Харапрасад, Чандранатх) — преодолевается объяснением «все дети Бога».
- **Корысть/нечестность** (чиновники) — контраст с честностью Шива Шанкара.

## Worked Example

*Сценарий Праная.* Скептик просит прочитать ладонь → Prabhatda молча отталкивает руку (волна блаженства) → «неминуемая гибель» → мантра (брошена) → в офисе прикосновение к межбровью → взрыв света, самадхи → «тысячи солнц» → признание духовного мира → вечером инициация у Tiger's Grave → через несколько дней yama-niyama: вокруг Праная появляются множественные формы Prabhatda с пальцем «должен следовать!» → сдаётся → guru mantra → сон с головой на коленях гуру → «не знай гуру по имени — зови Baba». Урок: духовное пробуждение — вопрос времени и личного опыта, а не аргументов.

## Key Takeaways

1. Первые ученики — люди «обычные»: скептики, больные, искатели, даже нападавшие.
2. Гуру ждёт созревания (годы прогулок с Пранаем).
3. Судьба изменяема через контакт с садгуру (Харапрасад).
4. Исцеление — часть метода (йога + диета + медитация).
5. Обращение «Baba» — отношение любви, а не формальность.
6. Каста и ритуалы — барьеры, снимаемые при инициации.
