# Читшит — Advent of a Mystery, Part 1 (быстрые справки)

## Духовные состояния

| Ситуация | Правило |
|---|---|
| Понять разницу samadhi | Savikalpa = ум с Cosmic Mind (3 принципа активны, тело живо); Nirvikalpa = ум с Nirguna Brahma (тело-«труп», жёсткость 1–2 сек) |
| Как достичь nirvikalpa | Нужен Taraka Brahma (в теле — Sadguru); садханой до этого не дойти (мантры — в сфере принципов) |
| Мукти vs Мокша | Mukti = постоянный savikalpa; Moksha = постоянный nirvikalpa (без перерождения) |
| Понять «третий глаз» | Ajina chakra = открытая интуиция/всезнание; символ Шивы — духовный, не буквальный |
| Продвинутая душа без завершения | Vajra Bhairava: временное тело из 5 факторов для садханы |
| Уйти из тела (продвинутый садхака) | Сначала попросить разрешение садгуру + выполнить служение |

## Жизнь и смерть

| Ситуация | Правило |
|---|---|
| Что такое жизнь/смерть | Параллельность волн ума и тела; разрыв = смерть |
| Страх смерти | Иррационален: смерть «как сон», не болезненна |
| Клиническая смерть | Prana «подвешена» — обратима; признак «мертвости» не всегда точен |
| Похороны vs кремация | Кремация безопаснее (исключает «оживление в гробу») |
| Дети и прошлая жизнь | Помнят до ~5 лет; помочь «забыть» до 11–12 (две личности не сосуществуют) |

## Организация

| Ситуация | Правило |
|---|---|
| Миссия организации | Atma Mokshartham Jagat Hitayacha: самоосвобождение + благо всех |
| Социальные церемонии | Простые, без священников/долгов, на местном языке, с коллективной ответственностью |
| Кастовые символы | Отменяются при инициации (все дети Бога) |
| Святость ашрама | Дисциплина обязательна; гуру видит всё |
| Служение | Обязательное условие освобождения (садхана + служение) |

## Личная практика

| Ситуация | Правило |
|---|---|
| Кризис веры/депрессия | Тест на sharanagati (полную сдачу); держись «стоп гуру» |
| Зависимость (алкоголь/табак) | Садхана + повышение sentient-влияния; не откладывай «на завтра» |
| Вегетарианство | Внутренний сдвиг садханы, не навязывается извне |
| Гордыня | Снимается (Darpahari); сила — от Всевышнего |
| Гнев/проклятия | Недопустимы для садхака; Nature накажет справедливо |

## Мир и история

| Ситуация | Правило |
|---|---|
| Расовое «превосходство» | Миф: все расы смешаны; «чистоты крови» нет |
| Тантра и мир | dhyana→chan→zen; tantra→tao; одна традиция — разные имена |
| Запад и духовность | Западяне rajoguni (активны) — быстрый прогресс возможен |
| Коммунизм/нацизм | Обречены: основаны на ненависти/материализме; выживает любовь |
| Судьба тиранов | Вмешательство возможно при угрозе масс (Cosmic Scissors) |

## Быстрые сигналы («tells»)

- «Обычный клерк» с феноменальным знанием — маска экстраординарного (уважай, не суди по форме).
- Скептик, получивший личный опыт, обращается навсегда (Суреш, Пранай).
- «Завтра брошу» — самообман; зависимость лечится практикой и физиологией.
- «Организация из овец и шакалов» — предупреждение против слабой дисциплины.
- Сиддха-йоги приходят «как нищие» — не суди по одежде.
- Кризис веры без причины — вероятный тест на сдачу.
- Материалистические идеологии — «фейерверки»: блеснут и исчезнут.
