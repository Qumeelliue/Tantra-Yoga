# Читшит — правила решений по Саркару (Subhasita 18)

## Успех и продвижение

| Ситуация | Правило |
|---|---|
| Начать/оценить миссию | Шесть требований: решимость, шраддха, гуру-пуджа, уравновешенность, самоконтроль, умеренная «диета»; седьмого нет |
| Нарушено равновесие | Определи уровень: физика / психика / дух; восстанови немедленно (Pramá) |
| «Желание мешает» | Не подавляй — перенаправь правртти к тонкому (иначе каменение или хаос) |
| Ум не ускоряется | Торможение → деградация к материи; добавь ускорение (усилие + милость) |

## Служение и мотивация

| Ситуация | Правило |
|---|---|
| Оценить вклад/отношения | Односторонний поток = служение (sevá); взаимный = сделка (vyavasáya); не путай |
| Проверить объект притяжения | Не-интегральный (деньги/слава) → кама/а̄сакти; интегральный (благо всех) → према/бхакти |
| «Дал — жду обратно» | Это бизнес, а не служение; для духовного прогресса нужна односторонность |

## Практика ума

| Ситуация | Правило |
|---|---|
| Выбрать объект концентрации | Не Кшара (станешь им), не Акшара (транзакции с миром), а Ниракшара — третий |
| Джапа/повторение | Слово и мысль параллельны (иначе «Mara», не «Ráma»); лучшая форма — мысленная |
| Оценить состояние ума | Kṣipta/Múŕha/Vikśipta/Ekágra/Nirodha; цель — направленный Nirodha, не подавление |
| Йога без любви | Не работает: без бхакти кундалини не пробуждается («кузнец без золота») |
| Хатха-силовое подавление | Это не йога; настоящая — направление к Параматману с целью |

## Знание

| Ситуация | Правило |
|---|---|
| Оценить источник данных | Изменится со временем/местом/личностью? Да → «путаница знания», относись смиренно |
| «Знаю всё по книгам» | Физико-психическое знание дефектно; истинное — dhruva smrti («Он видит меня») |
| Поведение «как животное» | Доминируют клеточные умы; верни доминанту коллективному уму |

## Оковы и милость

| Ситуация | Правило |
|---|---|
| Постоянное освобождение | Только в духовной сфере; физика и интеллект дают временные свободы |
| Победа над Майей | Не борьбой — преданием себя; подавленное прорывается сильнее |
| Гордость успехом | Prapatti: усилие твоё, успех — Его; «Он — machine-man, я — машина» |

## Быстрые сигналы («tells»)

- Ум «плывёт» от объекта к объекту до истощения → Vikśipta («колыбельная»), лечи сосредоточением.
- «Что дадут, то и съем» → пренебрежение «диетой» ума; жди дефектных «клеток».
- Спор о том, чьё имя/бренд лучше → потеря фокуса; дух один (Ch 11).
- «Мы их объединили» → проверить: песок+сахар (единство) или сахар+вода (унификация)?
- Гордишься знанием из старой географии → «первоклассный дурак» (Ch 13).
- Дал и ждёшь возврата → сделка, а не служение.
