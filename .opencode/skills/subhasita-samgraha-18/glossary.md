# Глоссарий — Subháśita Saḿgraha Part 18

**Авінāбха́ви (Avinábhávii)** — неразделимость Познавательного и Оперативного принципов (Ch 10).

**Аклайшта / Клишта-вртти (Akliśt́á/Kliśt́á)** — пропенсивности «без боли/с болью» в начале и конце; 4-членная градация (Ch 12).

**Ан́има (ańimá)** — оккультная сила «в точку» (Ch 6).

**Антарьямитва (antáryámitva)** — вхождение в структуры других (Ch 6).

**Анудхьяна (Anudhyána)** — ментальная погоня за Господом; вторая стадия абхидхьяны (Ch 10).

**Анумана (Anumána)** — инференция («дым → огонь»), источник доказательства (Ch 12).

**Ачара (ácáráńát dharmah)** — «дхарма — совокупность поведения» (контекст книги).

**Бхагава́н (Bhagaván)** — обладатель шести качеств (bhaga) (Ch 11, в контексте имён; полное изложение — книга 19, гл. 11).

**Бхакти-мост (Bhakti-Rúpa Setu)** — преданность как мост джива→Шива (Ch 9).

**Викальпа (Vikalpa)** — вербальная конструкция без объекта; одна из пяти главных вртти (Ch 12).

**Випаряя (Viparyaya)** — ошибочное знание; главная вртти (Ch 12).

**Гуру (Guru)** — «рассеивающий тьму» (gu=тьма, ru=рассеиватель); Brahmaeva Gururekah (Ch 2, Ch 7).

**Джапа (Japa-kriya)** — повторение; три вида: вачаника (громкая), упамсу (шёпот), манасика (мысленная — лучшая) (Ch 10).

**Дхрува смрити (dhruva smrti)** — постоянное осознание «Параматман видит меня» — истинное знание (Ch 13).

**Ишта-мантра (Iśt́a mantra)** — личная инкантация садхаки (Ch 11).

**Кара/Карья Брахма (Kárańa/Karya Brahma)** — причинная/эффективная форма Брахмы (Ch 8).

**Кама vs Према (Káma/Prema)** — притяжение к не-интегральному/интегральному (Ch 10).

**Кшара/Акшара/Ниракшара (Kṣara/Akṣara/Nirakṣara)** — превращённый/свидетель/контролирующий (Ch 10).

**Кшетра/Кшипта (Kṣipta)** — беспокойное состояние ума (Ch 12).

**Кулакундалини (Kulakuńd́alinii)** — «свёрнутая змея»; потенциальная энергия восхождения (Ch 1, Ch 8).

**Лила́ vs Крида́ (Liilá/Kriidá)** — безпричинный спорт Бога / причинная игра (Ch 4, Ch 5, Ch 8).

**Ма́йя** — Оперативный/Творческий принцип в рамках Сознания; фазы: Вишну-, Йога-, Маха-, Ану-, Вишва-майя (Ch 10).

**Микровиты (microvita)** — позитивные/негативные; выполняют работу по воле Господа (Ch 2).

**Нивртти (Nivrtti)** — «серебряная линия раздела» между правртти и самвртти; высшее равновесие (Ch 3).

**Нидра́ (Nidrá)** — сон/пустота ума; главная вртти (Ch 12).

**Прама (Pramá)** — психическое равновесие; триада: самвриддхи/рддхи/сиддхи (Ch 1, Ch 3).

**Прамана (Pramáńa)** — доказательство: пратьякша/анумана/агама (Ch 12).

**Пранидхана (Pránidhána)** — сведение 1000 пропенсивностей в точку + параллелизм слова и мысли (Ch 10).

**Прапатти (Prapatti)** — 100% опора на милость Парама Пуруши (Ch 2).

**Правртти/Самвртти (Pravrtti/Saḿvrtti)** — экстроверсиальные/интроверсиальные пропенсивности (Ch 3).

**Пропенсивности (Vrttis)** — 50×2×10=1000 (Ch 3, Ch 10).

**Сагана/Ниргуна (Ságuńa/Nirguńa)** — квалифицированная/неквалифицированная позиция (контекст Ch 10; детали — книга 17).

**Самадхи (Samádhi)** — состояние слияния; стадии по кундалини: Салокья/Самипья/Саюджья/Сарулья/Саршти/Каевалья (Ch 12).

**Сева (Sevá)** — одностороннее служение всем существам (Ch 1); транзакция при преме (Ch 10).

**Смрити (Smrti)** — память; главная вртти (Ch 12).

**Таттвабхава (Tattvabhávát)** — атрибутирование Брахма-сущности каждому объекту (Ch 10).

**Хатха-йога** — силовое подавление нервов; ≠ настоящая йога (Ch 12).

**Шра́ддха (Śraddhá)** — движение к Высшей Истине (Ch 1).

**Экагра (Ekágra)** — однопоинтовое состояние ума (Ch 12).

**Юньдж vs Юдж (yunj/yuj)** — унификация (сахар+вода) vs сложение (песок+сахар) (Ch 4, Ch 10, Ch 12).
