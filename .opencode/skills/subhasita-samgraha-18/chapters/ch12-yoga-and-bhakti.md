# Глава 12: Yoga and Bhakti

*Дискурс от 26 декабря 1965 DMC, Gazipur.*

## Core Idea

Если йога — «yogashcittavrtti nirodhah» (приостановка пропенсивностей), то что делает бхакти? Без бхакти йога невозможна: кундалини не пробуждается и не поднимается; йог без бхакти — «кузнец без золота». Бхакти — суть; знание и действие — помощники.

## Frameworks Introduced

- **Yogashcittavrtti Nirodhah**: йога = приостановка (channelisation) пропенсивностей ума. Пять состояний ума: Kṣipta (беспокойное, транзиторная концентрация), Múŕha (зацикленное на привязанности/страхе), Vikśipta (скачет между объектами до истощения — «колыбельная»), Ekágra (однопоинтовая концентрация), Nirodha (изъятие из объектов, направление к безобъектному).
- **Пять главных вртти (Mukhyá vrtti)**: Pramáńa (доказательство), Viparyaya (ошибочное знание), Vikalpa (вербальная конструкция без объекта), Nidrá (сон/пустота), Smrti (память). Все остальные вртти зависят от этих.
- **Pramáńa — три источника**: Pratyakśa (прямое восприятие), Anumána (инференция, «дым → огонь»), Ágama (авторитет, «Лондон существует»). Чарвака (только Pratyakśa) опровергнут: воздух невидим, но существует.
- **Клишта/Аклишта-градация вртти** (4 типа): Kliśt́á (боль в начале и конце — безбилетник), Akliśt́á (нет боли ни там, ни там — садхака с бхакти), Kliśt́akliśt́á (боль в начале, радость в конце — студент), Akliśt́akliśt́á (радость в начале, боль в конце — взяточник). Где цель — Параматман, вртти «Akle sántika» (приятна в конце); где цель — материя, «Kle sántika» (больно в конце). Контроль главных вртти автоматически контролирует зависимые.
- **Тантрическое определение йоги**: «Saḿyoga yoga ityukto jiivátmá-paramátmanah» — объединение/унификация дживатмана с Параматманом. Луна в небе = Параматман, отражение в пруду = дживатман; слияние = йога.
- **yuj vs yunj**: сложение/единство (песок+сахар) vs унификация (сахар+вода). Садхака — унификация.
- **Хатха-йога ≠ йога**: forced stopping нервных клеток/волокон (хатха = balena, силой) — временное подавление, «senselessness», не настоящий vrttinirodha. Настоящий — направление ума к Параматману с целью (иначе suspension невозможен).
- **Кундалини и самадхи**: возвышение Кула-кундалини по чакрам — Sálokya (Свадхистхана: «Он далёк, но видим»), Sámiipya (Манипура: «Он близко»), Sáyujya («близость, соединение»), Sárúpya («я сам — цель»), Sárśt́i (Аджна: «мы одно»), Kaivalya (утрата «Я», nirgunásthiti). Без бхакти — ни пробуждение, ни подъём невозможны.
- **Jiṋána и Karma**: Jiṋána Sádhaná — «почувствовать Параматмана во всех объектах» (достижение: все объекты = Он). Karma Sádhaná — работа больше для других, чем для себя (обычный реформатор использует ~10% потенциала, 90% — впустую; 5–10 минут на других в день — «животная тенденция»). Работа только для себя — животное; для других — великий. Karmasiddha — работающий только для других.
- **Соотношение Jiṋána : Karma**: садхана кармы должна превышать садхану знания (иначе пробуждается тщеславие). Бхакти пробуждается, когда карма > знания.
- **Бхакти как конечная цель**: из знания и действия рождается бхакти; бхакти ведёт йога к Параматману.

## Key Concepts

- **Kṣipta/Múŕha/Vikśipta/Ekágra/Nirodha** — пять состояний ума (из «колыбельной» метафоры).
- **Ábhoga** — ментальный «пабулюм» (пища ума); vrtti = ментальный пабулюм.
- **Taela-dharāvat** — «как струя масла» — образ непрерывной дхьяны.
- **Bekhudii** — утрата «Я»-чувства; Kaivalya.
- **«Ишвара-пранидхана»** — в контексте Ananda Marga — пранидхана, не просто джапа.
- **Шанкарачарья**: «Mokśakárańasamagryaḿ bhaktireva gariiyasii» — «из всех средств мокши бхакти величайшее».

## Mental Models

- «Думай о йоге как о реке с целью: без Параматмана как цели suspension невозможен — только бессознательность».
- «Используй карту пяти состояний ума для диагностики: на каком ты сейчас?»
- «Думай о бхакти как о воде, Iśt́a-mantra как о семени, сердце как о почве — без воды семя в пустыне бесполезно».
- «Помни пропорцию: karma-садхана > jiṋána-садхана, иначе придёт тщеславие».

## Anti-patterns

- **Хатха-йога как замена йоги**: силовое подавление — не настоящая йога.
- **Джапа без цели/любви**: пустая акустика.
- **Знание больше действия**: тщеславие и падение.
- **Работа только для себя** — животная тенденция (5–10 минут в день на других).
- **Идти к самадхи без бхакти** — «вол в маслобойне», хождение по кругу.

## Worked Example

*Тест йоги.* Йог без бхакти пытается достичь кундалини силой (хатха). Подавление нервных клеток даёт временную бессознательность — это не vrttinirodha. Возвышение Кула-кундалини требует желания Параматмана: без любви пробуждение невозможно, подъём по чакрам (салокья → самипья → саюджья → сарулья → саршти → каевалья) невозможен. Соотношение: джинана+карма пробуждают бхакти; карма должна превышать джинану; тогда — «йог с бхакти становится маха-йогом даже без учёности».

## Key Takeaways

1. Йога = приостановка пропенсивностей, но только с целью (Параматман), иначе — бессознательность.
2. Пять состояний ума и пять главных вртти — инструменты диагностики.
3. Хатха-йога (силовое подавление) ≠ йога; унификация (сахар+вода) — единственная настоящая.
4. Кундалини не пробуждается и не поднимается без бхакти.
5. Karma-садхана должна превышать jiṋána-садхану, иначе тщеславие.
6. Бхакти — финал: из знания и действия рождается бхакти; она ведёт к Каевалье.
