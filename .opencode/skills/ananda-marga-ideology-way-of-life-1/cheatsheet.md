# Читшит: правила решений

| Ситуация | Правило |
|----------|---------|
| Оцениваешь действие | Идёт с законами Prakrti + проясняет отражение Сознания? → uttama karma. Иначе — зло |
| Вредный объект (алкоголь, соблазн) | Ищи правильное использование (vaerágya); не отрекайся насильно |
| Страх «наказания» / вера в судьбу | Реакции неотвратимы; меняйся срок (ускорь садханой), не само существование |
| Хочешь молитвой/жертвой «смыть» карму | Не работает: реакции независимы; откажись от зла и извлеки урок |
| Выбираешь между молитвой и преданностью | Bhakti — да; prayer/stuti — бесполезны |
| Ищешь гуру | Разожги жажду освобождения; распознавай по свободе от 6 врагов/8 пут, не по силам |
| Слышишь о «сверхспособностях» садхаки | Использование сил = Avidyámáyá = деградация; демонстрация = самозванец |
| Страх отказа от мира | Avidyámáyá идёт за умом; садхана возможна дома, с семьёй |
| Сомнение «поздно начинать» | Смерть не ждёт; юный бамбук гнётся, зрелый ломается |
| Страх потерять удовольствия | Садхана сама уводит ум от грубых привязанностей |
| Анализ общества/власти | Кто владеет незаменимым ресурсом эпохи → кого эксплуатирует → кто поднимется |
| Видишь классовое доминирование | Любое доминирование → эксплуатация; цель — общество без делений |
| Слышишь о кастовых делениях | Варна = цвет-гуна ума, не каста; Ананда Марги — без каст |
| Веришь, что «здесь плохое место для практики» | Деление мест = деление Брахмы; практика возможна везде |
| Грустишь о «недостатке» | Принцип довольства: беден тот, у кого много желаний |
| Думаешь, что конечный объект даст счастье | Конечное — относительная истина; вечное блаженство только в Satya |
| Споришь об истине события | Проверь зависимость от времени/места/наблюдателя; время = ментальное измерение действия |
| Боишься действий из-за реакций | Предай действия Брахме (3 тиага) — тогда реакции Его; бездействие невозможно |
| Действуешь ради плода или похвалы | Phalákáḿkśá и kartrtvábhimána создают самскары; откажись от обоих |
| Ешь/делаешь обычное дело | Madhuvidyá: бери объект с космическим чувством (Брахма в форме ребёнка/земли) |
| Слышишь призыв к идолопоклонству | Идол конечен — противоречит всепроникающему Брахме; ум становится тем, чему предан |
| Ум «ловит тени» удовольствий | Поверни ум к Puruśa — наслаждение тенями иллюзорно |
