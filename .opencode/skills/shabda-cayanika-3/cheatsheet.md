# Читшит — правила решений по Саркару (Shabda Cayanika 3)

## Этимология

| Ситуация | Правило |
|---|---|
| Объяснить слово | Корень + суффикс → этимологическое → разговорное → культура |
| Слово на ka | Проверь ka = «вода» и ka = «голова»; потом акустический корень |
| Неверная народная этимология | Исправь через корень (aopanyásika = «подающий документы», не романист) |
| Оценить творца | Тест kavi: внутреннее зрение + мысль о благе; «стихи о сигаретах» — не поэзия |
| Разделить близкие слова | Сравни корни: karuńá/dayá/krpá; kambu/kambú; nyátá/netá; орхидея/паразит |

## История и общество

| Ситуация | Правило |
|---|---|
| Вектор культуры региона | Река несёт цивилизацию; слияние = смешение культур |
| Арийское влияние в Индии | 4 фазы: Пенджаб → Харияна → Праяг → Каши; % ведийской лексики убывает |
| Происхождение purdah | Семитский обычай эпохи Патанов; НЕ арийский, НЕ универсальный |
| Права женщин в истории | Матриархат → патриархат → товаризация; aodváhika = остаток права наследования |
| Оценить касту/профессию | «Нечистые»: религиозный торгаш, ростовщик, смутьян, «профессии смерти»; каста исчезает |

## Космология и акустика

| Ситуация | Правило |
|---|---|
| Смысл буквы ka | Первый звук алфавита; объективированный Разум; вода; голова |
| Затмение (миф) | Раху (голова) глотает солнце/луну; Раху/Кету = тени, не планеты |
| Тип эпохи | Йуга: satya (практика) → treta (бхакти) → dvapara (карма) → kali (слова>дела) |
| Пять видов действия | Направление потока (грубое↔тонкое, внутрь↔наружу, спонтанное); самскара-действия без отдачи |

## Природа и земледелие

| Ситуация | Правило |
|---|---|
| Повысить плодородие | Голубиная жатва: сей семена в мокрые рисовые поля |
| Различить растения | Орхидея = свои корни, автономна; паразит = без корней, губит хозяина |
| Сезонные предсказания | Журавль уходит перед замерзанием; ласточки летят на запад — к дождям |
| Грибы в питании | Kabaka = тамас-еда: интеллектуалам не есть |
| Горчица | 3 сорта: rái, t́ori, жёлтая (самая выгодная); kaŕuyá = горчичное масло |

## Язык и письмо

| Ситуация | Правило |
|---|---|
| Порядок алфавита | ka первым; иначе грамматика и фонетика «рассыпаются» |
| Конъюнкты | Зубной+зубной ок (nda); зубной+церебральный нет (ńa+da) |
| Классификация языков | Санскрит-потомки и «приёмные» (заимствующие лексику); пракриты → современные языки |

## Быстрые сигналы («tells»)

- Видишь слово с ka: думай «вода/голова» и проверяй корень, а не только обиходный смысл.
- «Стихи о сигаретах и закусках» — анти-пример kavi, даже если рифмуются.
- Mleccha = морально отклонившийся, НЕ «не-ведиец» — следи за употреблением.
- Purdah у «древних ариев» — анахронизм.
- Числа/сроки книги (годы, проценты, сроки жизни животных) — «⚠ к калибровке», сверяй с первоисточниками.
