# Глоссарий — Shabda Cayanika Part 3

**Акустический корень (acoustic root)** — звук, несущий космологический смысл: ka (объективированный Разум), om (свидетель ka, непроявленное), huḿ (битва). Ch 16, 18, 20.

**Аодвахика (aodváhika)** — имущество/украшения, которые женщина наследует как личное (остаток права наследования матриархата). Ch 15.

**Аоктха (aoktha)** — «о уктхе» (собранные части Самаведы); aokthaka = пандит Самаведы; aokthika = правила об аоктхе. Ch 15.

**Арийское влияние, 4 фазы** — Пенджаб (Синдху-Совира) → Харияна → Праяг → Каши; % ведийской лексики убывает. Ch 17.

**Арьаварта** — северная Индия; граница двигалась от Саруджу (восточный берег = неарийский) до Гандаки; за Саруджем — сараюпарии-брахманы. Ch 17.

**Аюрьеда / дхату** — три элемента здоровья: ва́yu, pitta, kapha. Ch 17.

**Варга (varga)** — группа звуков алфавита (ka, ca, t́a, ta, pa); порядок диктуется взаимной заменой и акустикой. Ch 16.

**Ведийская хронология** — Веды ~15 000–5 000 лет назад; алфавит ~7 000; письменность изобретена позже; shruti = «слышимое». ⚠ к калибровке. Ch 15.

**Винная/ритуальная** — kalya = ритуальное вино (мадья, мадира, мадху, сомараса) или святая вода. Ch 19.

**Вода/голова (ka)** — два главных разговорных значения ka как основы многих слов. Ch 16, 18, 20.

**Голубиная жатва (pigeon-harvest)** — посев семян (горох, рапс, кхесари) в мокрые рисовые поля; второй урожай, повышение плодородия. Ch 17.

**Деньги** — kaparda = монета; kapardaka = каури (наименьшая единица обмена); káhan = мера (1280). Ch 17, 20.

**Джхамму/Дугара** — Jambushilá (золото) → Jambudvipa; Dvigartabhuumi → Duggardesh; Dogri (шарада-сценарий). Ch 20.

**Доместикация** — овца, лошадь, собака → як → корова (сама пришла) → буйвол (позже). Ch 15.

**Журавль/ласточка** — животные как предсказатели сезона (журавль уходит перед замерзанием, ласточки — перед дождями). Ch 18.

**Затмение** — Раху (голова) «глотает» солнце/луну; Раху/Кету = тени (umbra/penumbra), не планеты. Ch 18, 20.

**Йуги** — satya (садхана) → treta (бхакти) → dvapara (карма) → kali (слова>дело). Ch 19.

**Кабала (kabala)** — глоток/пасть; «в тигриной пасти». Ch 20.

**Кабалика (kabaliká)** — защита от удара энергии: ткань, повязка, ножны, оковы самскары. Ch 20.

**Кабандха (kabandha)** — череп; обезглавленное тело; барраж; Кету; шарф-знак дхармы; рубашка; задержка мочи. Ch 18.

**Кавака (kabaka)** — гриб (из земли); тамас-еда — «интеллектуалам не есть». Ch 17.

**Кавара (kavara)** — «покрывающее воду/голову»: пучок волос, шапка, сплав, смесь, крышка, инкрустация, водный гиацинт, слива. Ch 20.

**Кавача (kavaca)** — защитник: щит, амулет, оружие, барабан; метафора внутренней твёрдости. Ch 19.

**Каджала/каджвала** — облако (вода→пар) vs сурьма (чёрный блеск). Ch 16.

**Када (kada)** — обманчивое (расписание поездов); от корня «обманывать». Ch 16.

**Кадамба (kadamba)** — цветок/роща/зелёная куркума/горчица/скопление; корень «разбухать». Ch 16.

**Кака (káka)** — ворон; 32 значения (бесстыдный, сварливый, дядя-káká, тилак, мера, юрисдикция...). Ch 20.

**Калатры (kalratra)** — «спасающая звуком»: крепость, город, жена (в голосовом бою). Ch 19.

**Кали (kali)** — 4-я йуга: «в основном звук», слова без дел. Ch 19.

**Калрila (kalrila)** — наименьшая единица; точка уравнивания материи и познания. Ch 19.

**Камала (kamala)** — от kam («нравиться»): лотос, ведро, медь, лекарство, олень; kamalinii = лотосовая роща (не «маленький лотос»). Ch 18.

**Камандалу (kamańd́alu)** — традиционный водный кувшин отшельников/учеников (из тыквы/кокоса). Ch 17, 18.

**Камата (kamat́a)** — бамбуковый побег, черепаха, кувшин, акула, демон, большие волны. Ch 18.

**Кандара (kandara)** — пещера. Ch 16.

**Кандарпа (kandarpa)** — «сжигающий существование мирскими мыслями»; бог любви. Ch 17.

**Капota (kapota)** — голубь/горлица; голубиная почта; додо вымерло ~100 лет назад. Ch 17.

**Кара (kara)** — «делающий»: рука, луч, налог, хобот. Ch 18.

**Карана (karańa)** — «инструмент»: станок, органы, ум (11-й орган), офис, кайастха. Ch 18.

**Каруна (karuńá)** — сострадание к духовному невежеству с помощью; ≠ dayá (таять от боли) ≠ krpá (способность блага). Ch 19.

**Капала (kapála)** — ворон, судьба, череп, вода/заграждение; «лоб» (бенг.) vs «голова» (бходжп.). Ch 17.

**Кашти (kashti)** — испытание огнём, суд, пробный камень для золота; от kaś («тереть»). Ch 20.

**Каури (kapardaka)** — ракушка как наименьшая валюта. Ch 17.

**Метод Саркара (vyutpatti)** — корень + суффикс = слово; этимологическое vs разговорное значение. Все главы.

**Млеччха (mleccha)** — «отклонившийся от морали»; НЕ «не-ведиец». Ch 19.

**Орхидея (kákarúhá)** — имеет корни, автономна, не убивает хозяина; ≠ паразит (bendá). Ch 20.

**Пракриты** — Páshcátya, Paeshácii (→ пушту, панджаби), Magadhi, Shaoraseni; предки современных языков. Ch 16, 17.

**Пурдах** — семитский занавес-затворничество, пришёл с Патанами; не арийский обычай. Ch 17.

**Раху/Кету** — теневые планеты (голова/тело обезглавленного асуры). Ch 18, 20.

**Речные цивилизации** — реки несут культуру; слияние = смешение; Тамза/Ганг как пример. Ch 17.

**Самскары (saḿskára)** — реактивные моменты; пра́рабдха = их проявление; «оковы» — kabaliká. Ch 19, 20.

**Священные растения** — yajińa-d́umura (31 слово), вакul (артрит), дурман (Шива), калке (лекарство). Ch 17, 18, 19.

**Таттва (tattva)** — сущность вещи; tattvadraśt́á = провидец сути = kavi. Ch 20.

**Четыре фазы арийцев** — см. арийское влияние.

**Шрути (shruti)** — «слышимое»; устная передача Вед. Ch 15.

**Этимологическое vs разговорное** — ключевое различие метода (aopanyásika = подающий документы, а не романист). Ch 15.
