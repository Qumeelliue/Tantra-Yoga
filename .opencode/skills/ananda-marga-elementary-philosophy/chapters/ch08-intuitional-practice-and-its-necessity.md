# Chapter 8: Intuitional Practice and Its Necessity

*Дискурс 1955.*

## Core Idea

Са́дхана — всестороннее усилие освобождения от оков Пракрати. Освобождение возможно (пример: Prajápati стал Hiranyagarbha). Садхана — война против Бесконечной Пракрати, требующая гуру-садгуру; сверхсилы использовать нельзя.

## Frameworks Introduced

- **Са́дхана = освобождение**: каждое действие — проявление квалификации Пракрати; отступление: citta → ahaḿtattva → mahattattva → unit consciousness.
- **Savikalpa samádhi**: остаётся только mahattattva — «Я есмь То», неотличимое от Космического «Я».
- **Nirvikalpa samádhi**: mahattattva растворяется в unit consciousness; полное освобождение от квалификации Пракрати.
- **Бесконечная Пракрати**: единичная пракрити слабее единичного сознания; единичное сознание квалифицирует Бесконечная Пракрати → садхана — битва с Бесконечной силой, потому трудна.
- **Сосредоточение = садхана**: концентрация ума возможна только по мере освобождения citta → ahaḿtattva → mahattattva от влияния Пракрати.
- **Ма́yá и два её инструмента**: Avidyámáyá (затягивает в грубое) и Vidyámáyá (ведёт к субтильному) — два иллюзорных противопоставления, созданных Пракрати.
- **Сверхсилы — ловушка и богохульство**: победив Пракрати, нельзя использовать силу для демонстрации (тщеславие → Avidyámáyá), для «лечения» (вмешательство в кармический урок страдания) или чудес (нарушение dharma воды/огня). Использование — вызов Богу и путь вниз.
- **Гуру необходим**: узник не освободит себя сам; искусству садханы учит прецептор. Свободен только muktapuruśa; sadguru = воплощение Saguńa Brahma.
- **Sadguru узнаётся не по чудесам**: демонстрация сил = самозванец («избегай как ядовитой змеи»). Признак — свобода от шести врагов и восьми оков, жизнь в Vidyámáyá, viveka и vairágya.
- **Равное право на садхану**: у всех людей — полное отражение сознания; sadguru доступен тем, у кого есть пылкое желание освобождения.
- **Препятствия — хороший знак**: Avidyámáyá (как несносный жилец) сопротивляется; боль/блаженство в начале садханы — признак ускоренного исчерпания самскар.

## Key Concepts

- **Muktapuruśa** — освобождённый, добровольно принявший влияние Пракрати на срок ради других (см. ch03).
- **Karmaphala и садхана** — желающие mukti исчерпывают реакции в этой жизни быстро.
- **Śad́ripu / aśt́apásha** — на садгуру не влияют (см. ch06).
- **Guru как Bhagaván incarnate**: Сагун́а Брахма бесформен и должен принять человеческую форму для помощи единицам.

## Mental Models

- «Садхана — извлечение себя из Prakrti слой за слоем: citta → ahaḿtattva → mahattattva → слияние».
- «Сверхсила — трофей, которым нельзя пользоваться: использование возвращает под контроль Пракрати».
- «Учитель — тот, кто уже снаружи тюрьмы: sadguru, а не демонстратор чудес».

## Anti-patterns

- Использовать садхана-силы (исцеление, чудеса, демонстрация) — богохульство.
- Искать гуру по чудесам — так узнают самозванца.
- Полагаться на «милость гуру» без собственных усилий (садгуру не пасёт «коров»).
- Ждать, что без садханы будет mukti; без гуру садханы не будет.

## Worked Example

*Расшифровка процесса.* Ум — внешний слой (citta) → втягивание в ahaḿtattva → в mahattattva. На стадии savikalpa samádhi остаётся чистое «Я есмь». Дальнейшая садхана растворяет mahattattva в unit consciousness — nirvikalpa samádhi. Практически: препятствия при начале практики (потеря интереса, страдания) — признак того, что Avidyámáyá «выселяют из дома».

## Key Takeaways

1. Садхана необходима и возможна; освобождение — через неё.
2. Цель — последовательно отступить citta → ahaḿtattva → mahattattva → сознание.
3. Сверхсилы не использовать: это богохульство и падение.
4. Гуру (sadguru) необходим; распознают его по добродетелям, а не по чудесам.
5. Препятствия в садхане — положительный признак исчерпания самскар.
6. Право на садхану — у всех; желание освобождения надо создавать усилием.
