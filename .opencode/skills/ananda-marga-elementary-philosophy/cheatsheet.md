# Читшит — правила решений по Саркару (Elementary Philosophy)

## Природа и цель

| Ситуация | Правило |
|---|---|
| Найти dharma человека/системы | Dharma = природа. Огонь жжёт; человек ищет Космическое Сущее |
| Понять, утолит ли цель | Цель конечна → разожжёт аппетит; бесконечное насыщает только Бесконечное |
| Человек ведёт себя «как животное» | Не использует отражённое сознание — не заслуживает звания человека |

## Космология

| Ситуация | Правило |
|---|---|
| Что такое Брахма | Puruśa + Prakrti, неразделимы (как огонь и жжение); оба бескаузальны |
| Высшее состояние | Nirguńa (Brahmasvarúpa); Bhagaván = Saguńa — ступень, не финал |
| Откуда творение | Менее сконденсированное сознание квалифицируется Пракрати → Saguńa |
| Что такое мир | Мысле-проекция Saguńa Brahma; ни реален, ни ложен — относительная истина |
| Как понять грубость | Чем больше танматр — тем грубее; субтильное танматр не имеет |

## Действие и последствия

| Ситуация | Правило |
|---|---|
| Любое действие (в т.ч. мысль) | Создаёт реакцию (karmaphala), которую испытывает сам деятель |
| Смерть | Ум без мозга не работает → перерождение для исчерпания самскар |
| Рай/ад, призраки | Ложь: ум после смерти нефункционален |
| «Погасить зло добром» | Невозможно: каждая реакция исчерпывается отдельно |
| «Отменить судьбу» (грахашанти и т.п.) | Меняет только график/порции, не сам долг |
| Молитва / stuti | Бесполезны (обвинение/лесть); работает bhakti |

## Как жить

| Ситуация | Правило |
|---|---|
| Что такое добро | uttama karma: законы Пракрати + расширение отражения сознания |
| Как использовать вещи | Vairágya: правильно, не порабощая ум; viveka различает |
| Что держит ум | Шесть врагов + восемь оков (Avidyámáyá); они исчезают с садханой |
| Цель человечества | Mokśa (слияние с Nirguńa), а не mukti (с Saguńa) |

## Практика

| Ситуация | Правило |
|---|---|
| Нужна ли садхана | Да, всем; без неё нет освобождения |
| Порядок практики | Отступить citta → ahaḿtattva → mahattattva → слияние (nirvikalpa) |
| Сверхсилы | Не использовать: богохульство и падение (демонстрация = самозванец) |
| Кто учитель | Sadguru = muktapuruśa; узнаётся по свободе от врагов/оков, не по чудесам |
| Препятствия в практике | Хороший знак: Avidyámáyá сопротивляется, самскары исчерпываются |
| Начинать | Сейчас, а не в старости: «молодой бамбук» гнётся |

## Быстрые сигналы («tells»)

- «Начну практику, когда выйду на пенсию» — отсрочка под ложным предлогом (Ch 9).
- Кто-то хвастается чудесными силами — вероятный самозванец, а не гуру (Ch 8).
- Молитва «дай мне…» — обвинение Господа в пристрастности (Ch 6).
- Амулет/грахашанти «отменяет судьбу» — ложь; меняется только график реакций (Ch 6).
- «Мир нереален» — ошибка: мир — относительная истина (Ch 3).
- Отказ от действия из-за страха реакции — тоже действие, и оно тоже творит самскары (Ch 5).
